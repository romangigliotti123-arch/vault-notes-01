# vault-mentor

> The vault mentor: works alongside the user on whatever job they are doing (designing, scripting, monetising, advertising, running a project, using agents, coding with AI, research) with the combined knowledge of every creator in the Roblox Dev Mastery Vault and the AI Library Vault, and proactively suggests the right kit skill, agent, vault note or creator method at each step. Answers 'what would <creator> do'. Use when the user says /vault-mentor, mentor me, work with me using the vault, what should I do next, suggest things as I work, what would Nate Herk / Tizzy / Karpathy do, or wants an adviser that knows the whole vault.
