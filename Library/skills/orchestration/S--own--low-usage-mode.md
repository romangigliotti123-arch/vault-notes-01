# low-usage-mode

> Keep Claude in low usage mode for the rest of the session and every later one until turned off: cheapest model that fits, no opus, one subagent at most, short replies, small tool output, and every reply starts with 'low usage mode enabled.'. Use when the user says /low-usage-mode, low usage mode, save usage, stretch my limit, or stop burning my usage. '/low-usage-mode off' ends it, '/low-usage-mode status' reports it.
