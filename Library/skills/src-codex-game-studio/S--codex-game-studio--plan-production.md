# Plan Production

## 目标

把当前设计状态转成可执行的生产顺序。

## 何时使用

- 已有设计，但执行顺序不明确
- 需要里程碑计划
- 需要做版本裁剪或分阶段上线

## 工作流

1. 定义目标版本
2. 区分必须做和以后再做
3. 按依赖排序里程碑
4. 把技术细节交给 `tech-director`

## 输出要求

- 目标版本
- Scope In
- Scope Out
- 里程碑
- 风险点
- 下一步交接对象
