# Start Game Project

## 目标

把一个模糊的游戏想法整理成可执行的项目 brief，并把项目导向下一阶段。

## 何时使用

- 项目还停留在创意阶段
- 用户希望从零开始推进

## 工作流

1. 抓出一句话定位
2. 明确平台、玩家和体验目标
3. 给出一个受控的初始范围
4. 推荐下一步角色或流程

## 输出要求

- 项目 brief 草稿
- 初始范围
- 关键待解问题
- 下一步交接对象
