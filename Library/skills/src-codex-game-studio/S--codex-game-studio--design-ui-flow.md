# Design UI Flow

## 目标

把 UI 页面和流程梳理清楚，使实现和美术规划都能顺利展开。

## 何时使用

- 需要新增页面流程
- UI 层需要线框图和资产规划

## 工作流

1. 明确页面目标
2. 梳理用户操作和状态变化
3. 识别所需资产
4. 把原型交给 `ui-ux-designer`，把资产需求交给 `visual-artist`

## 输出要求

- 页面目标
- 流程结构
- 状态说明
- 资产需求
- 下一步交接对象
