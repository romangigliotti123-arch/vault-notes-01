# Define Game Concept

## 目标

明确游戏是什么、面向谁，以及为什么这个体验值得玩。

## 何时使用

- 概念还比较模糊
- 核心钩子不够强
- 在写详细设计之前需要先把方向立住

## 工作流

1. 明确目标用户
2. 明确幻想感和玩法钩子
3. 明确目标体验
4. 把系统细化工作交给 `game-designer`

## 输出要求

- 目标用户
- 幻想感
- 玩法钩子
- 体验目标
- 下一步交接对象
