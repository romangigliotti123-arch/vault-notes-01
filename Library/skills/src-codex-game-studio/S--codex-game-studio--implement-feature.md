# Implement Feature

## 目标

把一个功能从设计推进到可实施的开发切片。

## 何时使用

- 某个功能已经设计好，准备开始开发
- 团队需要角色分工清楚的实现推进方式

## 工作流

1. 重述功能目标
2. 区分设计、技术和编码任务
3. 识别所需资产或 UI 依赖
4. 把技术工作交给 `tech-director`，把编码工作交给 `gameplay-programmer`

## 输出要求

- 功能目标
- 实现切片
- 依赖项
- 风险点
- 下一步交接对象
