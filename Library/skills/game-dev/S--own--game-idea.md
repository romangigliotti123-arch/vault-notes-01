# game-idea

> Run /game-idea to get ONE short, evidence-backed Roblox game idea that fits what is working on Roblox right now. It checks live sources (official Charts/Discover, RoMonitor/Rolimons-style stats, recent trend write-ups; date-stamped) plus the vault's case studies and benchmarks, then returns one idea: hook, core loop at 30 seconds / 5 minutes / a session, progression and monetisation fit, why it works now, a buildable solo scope (kit systems and /rbx skills to use) and its critic idea score. Weak ideas are iterated until they pass the idea gate. Then offers 'start it' into /game-dev-workflow. Use when the user says give me a game idea, what should I make, what is hot on Roblox, or has no idea yet. Optional argument: a genre or seed.
