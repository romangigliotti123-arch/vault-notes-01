# Game trailer / short script

Output: 3 script variants with a shot list, on-screen text, audio notes, and a posting plan. Draft only; Roman approves before anything is posted or paid for.

1. Hook (0-2 s): the most striking real gameplay moment or a clear question/promise the game actually delivers. No intro logo, no slow fade.
2. Proof (2-20 s): 3-5 fast beats showing the loop (action, reward, progression, social moment), each beat under 4 s, cut on action. Show real footage only; no fake UI, no features that do not exist.
3. Payoff (last 3-5 s): the funniest/biggest moment or a clear result, then the call to action: game name spoken and on screen, how to find it ("search the name on Roblox" or link in bio).
4. Format: vertical 9:16, captions on (most views are muted), text large and inside safe margins, legible on a phone; loop-friendly ending.
5. Audio: trending-safe or royalty-free music only, with licence noted; a short voice or sound cue on the hook.
6. Variants: A = gameplay-first, B = funny/relatable situation, C = "can you beat this" challenge. One variable different per variant so results are comparable.
7. Posting plan: platform, caption, 3-5 relevant hashtags, time, and the metric to read after 48 h (3-second hold, average watch time, profile/link clicks, installs/visits). Follow each platform's rules for kids' content and disclosures; no engagement bait that breaks platform policy.
8. Capture checklist: clean recording settings, hide debug UI and private info, record 2x more footage than needed.
