# Game update announcement

Input: the changelog or commit list, the date, anything players asked for. Output: patch notes plus short versions per channel. These are drafts; posting as Roman needs his approval.

1. Order by player value: headline feature, new content, balance changes, fixes, known issues. Cut internal refactors.
2. Patch notes template: title with version and date; one-sentence hype line; bullets starting with a verb; numbers for balance changes (before -> after); thanks to reporters; "known issues" honestly; what is next.
3. Tone: friendly, short sentences, age-appropriate, no clickbait or false urgency, no promises with dates unless certain.
4. Channel versions: Roblox group/experience update post (2-3 sentences + 3 bullets), Discord (formatted, emoji sparingly, pin-worthy), X/Twitter (under 280 chars + image idea), in-game "What's new" popup text (under 40 words).
5. Include a visual list: 1-3 screenshots or a GIF to capture, with the exact scene.
6. Check facts against the changelog; do not announce things that are not in the shipped build. Flag anything uncertain for Roman.
