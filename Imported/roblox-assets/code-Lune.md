# Lune (library)

Standalone Luau runtime for scripts outside Roblox

- Path: `~\roblox-assets\code\Lune\`
- Source: https://github.com/lune-org/lune @ `0ea48037a3`
- License: MPL-2.0
- Size: 2.0 MB
- Searchable as: scripting tools, runtime, build scripts

## How it helps
Run build scripts, tests and tooling in Luau on the PC.

## How to use
- Wally-compatible libraries: add to `wally.toml` or copy the module folder (usually `src/` or `lib/`) into the project via Rojo.
- Check the license terms (MPL-2.0) before shipping; keep the license file with copied code.
- Tools (Rojo, Wally, StyLua, Selene, Lune, luau-lsp, Rokit) are source checkouts; prefer installing releases with Rokit over building them.
