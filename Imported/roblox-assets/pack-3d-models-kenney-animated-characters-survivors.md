## Import into Roblox Studio
Studio > Home > Import 3D (or Asset Manager > Bulk Import), pick the .fbx/.obj/.glb from the pack's FBX/OBJ/GLB folder. Kenney packs share one colormap texture: keep it next to the mesh so the importer links it, or apply it as a SurfaceAppearance/TextureID. Kenney units are metres: set import scale about 3.5 (1 stud = 0.28 m) so a person is about 5 studs tall.
