# Clip! Color Contrast Best Practices with BitwiseAndrea, ControlCoreAngel, Dspav & WooleyWool

[Watch](https://youtu.be/syQcaeRqqc4) | RobloxCreators | 788 views | 2023-04-13

## Summary
Panel on color contrast for accessibility in Roblox/UI design. Covers WCAG contrast guidelines, keeping contrast while preserving palette aesthetics, and testing for color blindness using grayscale (monochrome) checks and Adobe's color tools. Low Roblox-specific monetisation or growth content.

## Tips
- [0:07](https://youtu.be/syQcaeRqqc4?t=7) **[[building-art-and-assets]]** Follow WCAG contrast guidelines for UI text: check foreground/background contrast with a calculator; larger text can use lower contrast.
- [1:31](https://youtu.be/syQcaeRqqc4?t=91) **[[building-art-and-assets]]** Don't abandon your palette for contrast; tweak shades (e.g., darker blue behind white text) so contrast fits the game's look.
- [2:06](https://youtu.be/syQcaeRqqc4?t=126) **[[building-art-and-assets]]** Add outlines or secondary colors (e.g., white outline around a circle) so key elements stand out for colorblind players without hurting aesthetics.
- [3:35](https://youtu.be/syQcaeRqqc4?t=215) **[[playtesting-and-feedback]]** Test colors by converting to grayscale (monochrome); if elements are indistinguishable, colorblind players will likely struggle too.
- [4:16](https://youtu.be/syQcaeRqqc4?t=256) **[[building-art-and-assets]]** Red-green is not the only deficiency; use brightness differences, since greens/browns and blues/purples blend for different deficiency types.
- [5:37](https://youtu.be/syQcaeRqqc4?t=337) **[[ai-and-tools]]** Use Adobe's color tools (color picker with contrast suggestions) to find contrasting color pairs quickly.
