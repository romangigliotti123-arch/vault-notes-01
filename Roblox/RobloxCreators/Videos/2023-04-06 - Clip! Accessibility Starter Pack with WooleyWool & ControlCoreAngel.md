## Summary
Short accessibility starter talk between WooleyWool and ControlCoreAngel. Covers visual accessibility basics: colour contrast, readable UI and text size/placement, and font choice. Mostly opinion and banter; no Roblox metrics or platform specifics.

## Tips
- [0:30](https://youtu.be/uumqDp020jk?t=30) **[[building-art-and-assets]]** Start accessibility with visuals: ensure colours contrast with each other and avoid bad combinations like white text on yellow.
- [1:10](https://youtu.be/uumqDp020jk?t=70) **[[building-art-and-assets]]** Make UI text large enough and placed sensibly so it is readable; tiny or oddly positioned text hurts players.
- [1:35](https://youtu.be/uumqDp020jk?t=95) **[[building-art-and-assets]]** Choose font carefully; some fonts make text unreadable. Speaker says sans-serif is generally easier than serif and that Comic Sans is dyslexia-friendly.
