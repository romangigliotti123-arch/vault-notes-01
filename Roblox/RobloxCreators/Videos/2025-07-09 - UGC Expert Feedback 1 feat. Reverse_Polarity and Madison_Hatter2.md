## Summary
Blender mentorship for a beginner modeling a low-poly flower for a Roblox UGC flower crown. Covers triangle budgeting, joining vs. collections, origin and pivot fixes, backface and normal issues, mark-sharp shading, and UV unwrapping before texturing. Workflow-focused; no Roblox business or monetisation content.

## Tips
- [4:47](https://youtu.be/dlMWNO5iiGU?t=287) **[[building-art-and-assets]]** Keep flower petals as low-poly as possible; petals use most of the UGC triangle budget. Start from a basic plane shape and add geometry only as needed.
- [6:08](https://youtu.be/dlMWNO5iiGU?t=368) **[[building-art-and-assets]]** Unwrap UVs early, before subdivision and final edits, because unwrapping later is much harder.
- [10:07](https://youtu.be/dlMWNO5iiGU?t=607) **[[building-art-and-assets]]** Use M to move objects into collections for organisation only. Use Ctrl+J to actually join meshes, since each exported model must be one mesh.
- [11:29](https://youtu.be/dlMWNO5iiGU?t=689) **[[building-art-and-assets]]** Keep bulb and petals as separate objects until late in the process; joining them early makes later edits messy.
- [16:17](https://youtu.be/dlMWNO5iiGU?t=977) **[[building-art-and-assets]]** Build models centred at the scene origin (Shift+S, cursor to selected) so transforms and rotations behave predictably.
- [18:20](https://youtu.be/dlMWNO5iiGU?t=1100) **[[building-art-and-assets]]** Set origin to Volume (Object > Set Origin) so rotation pivots at the model centre. Use Ctrl+A to apply location if you moved it in object mode.
- [31:37](https://youtu.be/dlMWNO5iiGU?t=1897) **[[building-art-and-assets]]** Track triangles with the Statistics overlay. A 12-triangle petal times five petals is about 60 triangles; hats have a 4,000-triangle limit.
- [33:12](https://youtu.be/dlMWNO5iiGU?t=1992) **[[building-art-and-assets]]** Check for missing faces by enabling back face culling in the viewport overlay options, and flip normals (Alt+N) if petals show only one side.
- [36:32](https://youtu.be/dlMWNO5iiGU?t=2192) **[[building-art-and-assets]]** After auto smooth, mark hard edges as sharp (Ctrl+E > Mark Sharp) so flat petal edges stay crisp rather than shading oddly.
- [37:39](https://youtu.be/dlMWNO5iiGU?t=2259) **[[common-mistakes]]** Moving objects in object mode shifts their origin. Fix it by right-clicking to cancel, then applying location with Ctrl+A.
- [49:53](https://youtu.be/dlMWNO5iiGU?t=2993) **[[building-art-and-assets]]** Unwrap all parts into one UV layout with room left for the ring. You can start texturing from there, before the crown band is modeled.
