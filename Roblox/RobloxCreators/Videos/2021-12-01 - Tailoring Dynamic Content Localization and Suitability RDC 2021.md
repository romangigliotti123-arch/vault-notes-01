# Tailoring Dynamic Content: Localization and Suitability | RDC 2021

[Watch](https://youtu.be/ZhtTkuaSyVs) | RobloxCreators | 717 views | 2021-12-01

## Summary
Roblox RDC 2021 talk by Matthew Dean (PM, Creator Cloud) and Alli Dolphin (eng lead, content suitability) on dynamic content: automatic cloud translation of game text (11 languages machine translation, collaborator overrides), planned locale analytics, metadata translation, runtime UGC translation API, and experience guidelines/policy APIs that let experiences be tailored per region and age instead of building separate builds.

## Tips
- [4:31](https://youtu.be/ZhtTkuaSyVs?t=271) **[[development-process-and-speed]]** Industry localization is slow (weeks to find translators); Roblox auto-scrapes game text to its cloud, so you can enable machine translation without manual string extraction.
- [3:43](https://youtu.be/ZhtTkuaSyVs?t=223) **[[retention-d1-d7]]** Localize more languages: Roblox says translated experiences see longer engagement time because players understand them better (internal experiments, no figures given).
- [5:43](https://youtu.be/ZhtTkuaSyVs?t=343) **[[development-process-and-speed]]** Use machine translation as default and override specific languages with human translators via developer portal collaborators (individuals or groups) where quality matters.
- [6:24](https://youtu.be/ZhtTkuaSyVs?t=384) **[[titles-descriptions]]** Translate title, description and thumbnail text too; localized metadata tells players the game works for them and helps attract players.
- [16:48](https://youtu.be/ZhtTkuaSyVs?t=1008) **[[common-mistakes]]** Answer the experience guidelines questionnaire accurately; it sets descriptors, compliance countries and age recommendation that restrict where your game is available.
- [19:07](https://youtu.be/ZhtTkuaSyVs?t=1147) **[[common-mistakes]]** Use policy APIs to swap restricted features per player (e.g., replace skeletons in China with robots, realistic guns with toy guns for kids) instead of maintaining separate builds.
- [21:07](https://youtu.be/ZhtTkuaSyVs?t=1267) **[[game-ideas-and-genres]]** Experiences rated 17+ can use content like voice chat and looser text filters, since availability is restricted to matching audiences and voice chat can be assumed enabled.
