# What are Game Expansions? with Dspav

[Watch](https://youtu.be/UL4QaSbfyC4) | RobloxCreators | 7,341 views | 2021-07-22

## Summary
Dspav (RDC 2021) explains live ops and game expansions: content cadence vs. expansions vs. quality-of-life updates, building expansions around the core loop, avoiding "tumors" that compete with it, making expansions renewable, and catalogue of social, competitive, achievement and live-event systems.

## Tips
- [2:46](https://youtu.be/UL4QaSbfyC4?t=166) **[[updates-live-ops]]** Run weekly or biweekly content cadence (cosmetics, pets, furniture, event content) reusing existing systems to keep the base from decaying between expansions.
- [2:46](https://youtu.be/UL4QaSbfyC4?t=166) **[[updates-live-ops]]** Target at least one game expansion per quarter for a live game, sized to your team's real bandwidth.
- [4:14](https://youtu.be/UL4QaSbfyC4?t=254) **[[updates-live-ops]]** Ship quality-of-life updates (bug fixes, UX polish) to build player goodwill and loyalty.
- [5:16](https://youtu.be/UL4QaSbfyC4?t=316) **[[development-process-and-speed]]** Don't spend 1-3 months of team resources on a feature you'll ship and abandon; build expansions to be evergreen and roll them into content cadence later.
- [8:51](https://youtu.be/UL4QaSbfyC4?t=531) **[[core-loops-and-game-design]]** Ask first how any new feature enhances the core loop; integrate content into the loop rather than alongside it.
- [9:41](https://youtu.be/UL4QaSbfyC4?t=581) **[[core-loops-and-game-design]]** A core loop is the minute-to-minute action repeated every session and the engine for all progression; if it isn't fun, nothing else will save the game.
- [15:54](https://youtu.be/UL4QaSbfyC4?t=954) **[[core-loops-and-game-design]]** Avoid tumors: systems that compete with the core loop for attention. They split the player base and create update debt for a small subset of players.
- [16:38](https://youtu.be/UL4QaSbfyC4?t=998) **[[core-loops-and-game-design]]** Don't offer an opt-out alternative to the core activity (e.g. fight club vs class); a 50/50 split typically tilts to 10/90, leaving one side empty.
- [18:45](https://youtu.be/UL4QaSbfyC4?t=1125) **[[updates-live-ops]]** Plan a feature across the next two updates and years ahead, and brainstorm holiday and themed variants during design.
- [20:58](https://youtu.be/UL4QaSbfyC4?t=1258) **[[social-features-and-virality]]** Build social systems (guilds, trading, friend gifts, housing parties, collaborative building) since Roblox is the most social platform and these drive retention.
- [27:06](https://youtu.be/UL4QaSbfyC4?t=1626) **[[social-features-and-virality]]** Use leaderboards and community voting competitions as evergreen content; competition need not be combat (fashion, decor, cooking, races).
- [29:17](https://youtu.be/UL4QaSbfyC4?t=1757) **[[retention-d1-d7]]** Use daily login rewards, daily quests and achievements to create a habit of returning and to expose players to systems they'd otherwise skip.
- [29:57](https://youtu.be/UL4QaSbfyC4?t=1797) **[[monetisation-gamepasses]]** Season passes are cheap to maintain (refresh rewards each season) and create purchase moments at start and end of the season for catching up.
- [32:10](https://youtu.be/UL4QaSbfyC4?t=1930) **[[updates-live-ops]]** Use live events, map overhauls and timed rare spawns to create gathering moments and viral, shared experiences.
- [34:33](https://youtu.be/UL4QaSbfyC4?t=2073) **[[updates-live-ops]]** Keep content cadence running while programmers build the big update; dropping cadence means the expansion launches to a shrunken base (e.g. 500 vs 1000 CCU).
- [35:55](https://youtu.be/UL4QaSbfyC4?t=2155) **[[core-loops-and-game-design]]** If the core loop isn't fun, fixing it is the top priority, even if it means treating a major expansion as a redo of the core experience.
- [37:17](https://youtu.be/UL4QaSbfyC4?t=2237) **[[updates-live-ops]]** To fix a tumor, either bake it into the core loop (e.g. fight club as an end-of-day class) or rip it out, prioritizing long-term game health.
- [39:19](https://youtu.be/UL4QaSbfyC4?t=2359) **[[core-loops-and-game-design]]** Keep the core loop simple and easy to enter; the systems around it create the memorable moments like boss fights with dodge and heal choices.
- [40:43](https://youtu.be/UL4QaSbfyC4?t=2443) **[[core-loops-and-game-design]]** Focus on a single core loop; parallel loops create an unintentional rift where players effectively play different games.
- [41:24](https://youtu.be/UL4QaSbfyC4?t=2484) **[[core-loops-and-game-design]]** Let players create their own side experiences (e.g. trading for profit) but don't build dedicated content for emergent behaviours of a minority.

## Numbers
- [2:46](https://youtu.be/UL4QaSbfyC4?t=166) Expansion release cadence: **At least one per quarter for a live game** (Speaker's suggested minimum for game expansions)
- [34:33](https://youtu.be/UL4QaSbfyC4?t=2073) Illustrative CCU scaling: **1000 CCU to 3000 with expansion; 500 to 1500 if cadence dropped** (Hypothetical example; content cadence keeps base steady)
- [35:14](https://youtu.be/UL4QaSbfyC4?t=2114) Illustrative tumor split: **Best case 50/50; realistic 10% class vs 90% fight club** (Hypothetical example of an opt-out tumor)
- [4:14](https://youtu.be/UL4QaSbfyC4?t=254) Expansion effort: **1 to 3 months of team resources** (Speaker's typical build time for an expansion)

## Games
- **World Zero** [9:41](https://youtu.be/UL4QaSbfyC4?t=581): Core loop is killing monsters for loot, upgrading, then progressing to harder worlds; boss-fight moments built on that simple loop.
- **Robloxian High School** [11:12](https://youtu.be/UL4QaSbfyC4?t=672): Every system (explore, attend class, customize) augments the core loop; class activities added as an expansion to make classroom meaningful.
- **Red Manta (Robloxian High School dev)** [15:10](https://youtu.be/UL4QaSbfyC4?t=910): Grade system rewards exploring, attending class and customizing, lifting engagement and monetisation.
- **Jailbreak** [32:52](https://youtu.be/UL4QaSbfyC4?t=1972): Blew up the world in an event so players returned to a whole new map, creating a viral moment.
- **Adopt Me** [25:21](https://youtu.be/UL4QaSbfyC4?t=1521): Pet trading between players keeps collecting engaging.
- **Blox Burg (Bloxburg)** [26:43](https://youtu.be/UL4QaSbfyC4?t=1603): Collaborative building is one of its most popular social features.
- **a dot me** [35:55](https://youtu.be/UL4QaSbfyC4?t=2155): Parent/child core loop was broken; team reworked the core loop via an expansion, producing the pet update.
