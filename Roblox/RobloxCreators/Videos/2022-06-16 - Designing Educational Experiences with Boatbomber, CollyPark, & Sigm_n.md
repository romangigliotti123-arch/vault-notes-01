# Designing Educational Experiences with Boatbomber, CollyPark, & Sigm_nd

[Watch](https://youtu.be/hCT9zCJ1M5c) | RobloxCreators | 1,318 views | 2022-06-16

## Summary
Level Up roundtable on educational Roblox games with Boatbomber (Lua Learning), Sigmund (Untamed Planet) and Colin (Filament Games, RoboCoach Sports League). Covers defining educational games, pedagogy via interaction, turning learning objectives into mechanics, designing for age groups, helping struggling players, and using analytics.

## Tips
- [27:19](https://youtu.be/hCT9zCJ1M5c?t=1639) **[[core-loops-and-game-design]]** Let players conclude the lesson: give about 95% and let them reach the last 5% themselves. This aids retention and satisfaction.
- [28:45](https://youtu.be/hCT9zCJ1M5c?t=1725) **[[core-loops-and-game-design]]** Make learning interactive rather than read-only; interaction is where knowledge sticks for players.
- [28:45](https://youtu.be/hCT9zCJ1M5c?t=1725) **[[common-mistakes]]** Intrusive fact pop-ups that block movement felt like a nuisance and taught little. Remove them or make them non-blocking.
- [30:08](https://youtu.be/hCT9zCJ1M5c?t=1808) **[[playtesting-and-feedback]]** Iterate fast on live play: observe what fails and pivot the design, rather than locking content like a printed textbook.
- [32:20](https://youtu.be/hCT9zCJ1M5c?t=1940) **[[common-mistakes]]** Don't make it education-first. If players aren't engaged, nothing gets taught; build learning objectives into already-engaging mechanics.
- [34:23](https://youtu.be/hCT9zCJ1M5c?t=2063) **[[game-ideas-and-genres]]** Map learning objectives to a gameplay verb, an empowered identity, or an interactive system with moving parts.
- [36:27](https://youtu.be/hCT9zCJ1M5c?t=2187) **[[core-loops-and-game-design]]** Simplify building tools for mobile while keeping enough possibility space for players to be expressive.
- [42:40](https://youtu.be/hCT9zCJ1M5c?t=2560) **[[mindset-and-strategy]]** Design for single-player fun first. Trying to make every feature work for a multiplayer crowd caused circular discussions and slow decisions.
- [44:03](https://youtu.be/hCT9zCJ1M5c?t=2643) **[[analytics-metrics]]** Target one clear audience; a broad 'under 18' audience ended up hitting everyone and no one.
- [46:49](https://youtu.be/hCT9zCJ1M5c?t=2809) **[[core-loops-and-game-design]]** Offer optional hints and encouragement for struggling players, plus glossaries or visual analogies, rather than rewriting lessons (rewrites multiply dev time).
- [49:33](https://youtu.be/hCT9zCJ1M5c?t=2973) **[[core-loops-and-game-design]]** Use a guide character who asks questions to model reasoning, so the player still makes the decision.
- [52:59](https://youtu.be/hCT9zCJ1M5c?t=3179) **[[first-session-onboarding]]** Visualize steps in 2D that map to the 3D action so players figure out the process without long text boxes.
- [57:44](https://youtu.be/hCT9zCJ1M5c?t=3464) **[[analytics-metrics]]** Track per-lesson failure rates, tries to pass, drop-off points and time by device; rework lessons with high first-try failure.
- [57:44](https://youtu.be/hCT9zCJ1M5c?t=3464) **[[retention-d1-d7]]** Mark the last lesson used so players can resume where they left off; this also reveals how long since a topic was last practiced.
- [59:47](https://youtu.be/hCT9zCJ1M5c?t=3587) **[[core-loops-and-game-design]]** After high failure rates, reword the concept with real-world metaphors; failure rates dropped afterward.
- [1:00:44](https://youtu.be/hCT9zCJ1M5c?t=3644) **[[scripting-and-performance]]** Measure FPS and memory and optimise so the game runs on old low-end devices, widening accessibility.
- [1:02:09](https://youtu.be/hCT9zCJ1M5c?t=3729) **[[analytics-metrics]]** Track which activities and pets players choose, then A/B test onboarding (forced vs optional) and compare attention between groups.
- [1:02:50](https://youtu.be/hCT9zCJ1M5c?t=3770) **[[scripting-and-performance]]** Avoid unnecessary network requests and design new meshes and assets with performance on every device in mind.
