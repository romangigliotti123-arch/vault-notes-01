# How to sell assets on the Creator Store

[Watch](https://youtu.be/qNocmxFyfxs) | RobloxCreators | 7,293 views | 2026-04-17

## Summary
Tutorial on importing, packaging, publishing and listing assets for sale on the Creator Store. Covers asset privacy settings, Studio import settings (Creator set to me), SurfaceAppearance PBR setup, asset pack folder structure with ReadMe and thumbnail camera, and store page setup, distribution toggle, pricing and data sharing.

## Tips
- [0:41](https://youtu.be/qNocmxFyfxs?t=41) **[[common-mistakes]]** Set account uploads to Restricted privacy before selling; otherwise other creators can use your asset without permission, including purchasers.
- [0:00](https://youtu.be/qNocmxFyfxs?t=0) **[[common-mistakes]]** Group-owned assets cannot be distributed or priced on the Creator Store; paid content must be uploaded by an individual account.
- [2:07](https://youtu.be/qNocmxFyfxs?t=127) **[[building-art-and-assets]]** When importing, set Creator to 'me' in Studio; assets listed under a community cannot be sold on the Creator Store.
- [3:12](https://youtu.be/qNocmxFyfxs?t=192) **[[building-art-and-assets]]** Organise packs into folders Workspace, Server Storage and Server Script Storage, and include a ReadMe script with setup instructions for buyers.
- [3:53](https://youtu.be/qNocmxFyfxs?t=233) **[[thumbnails-icons]]** Copy a Camera into the model, rename it 'thumbnail camera', so the default store thumbnail matches your Studio framing.
- [4:57](https://youtu.be/qNocmxFyfxs?t=297) **[[titles-descriptions]]** Write a store description answering likely buyer questions; add preview video or images and up to three social links such as a DevForum thread.
- [5:37](https://youtu.be/qNocmxFyfxs?t=337) **[[building-art-and-assets]]** Set up a Roblox preview experience so buyers can try the asset as it works in the engine before purchasing.
- [5:37](https://youtu.be/qNocmxFyfxs?t=337) **[[monetisation-other]]** Free assets can serve as demos for larger paid systems; choose preset USD prices from the dropdown after enabling distribution.
- [5:37](https://youtu.be/qNocmxFyfxs?t=337) **[[business-and-payouts]]** Paid assets can opt out of data sharing for AI training; free assets are fair use for Roblox AI training.
