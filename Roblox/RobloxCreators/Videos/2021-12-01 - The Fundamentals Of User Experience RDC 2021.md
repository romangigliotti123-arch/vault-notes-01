# The Fundamentals Of User Experience | RDC 2021

[Watch](https://youtu.be/cY1B5_x4RoU) | RobloxCreators | 1,393 views | 2021-12-01

## Summary
UI/UX fundamentals talk at RDC 2021 by Bella (visual designer, Cinder Studios) and Tyler (UI/UX designer, Moonbeam). Covers UX definition, usability/accessibility/desirability, wireframing, common UI mistakes (overwhelming users, inconsistency, layout, visuals), micro-animations, probing user questions, and a live before/after UI makeover.

## Tips
- [1:26](https://youtu.be/cY1B5_x4RoU?t=86) **[[first-session-onboarding]]** Treat UX as core to the whole game: poor UX lowers average playtime, costs revenue, and hurts ratings.
- [2:48](https://youtu.be/cY1B5_x4RoU?t=168) **[[first-session-onboarding]]** Check three UX factors: usability (straightforward flow, no second-guessing), accessibility (color contrast, readable text), desirability (clear purpose for each click).
- [3:31](https://youtu.be/cY1B5_x4RoU?t=211) **[[development-process-and-speed]]** Wireframe UI before building it; it communicates to teammates, exposes issues early, and saves hours of rework.
- [4:15](https://youtu.be/cY1B5_x4RoU?t=255) **[[common-mistakes]]** Avoid overwhelming players with too much HUD text, too many buttons, or oversized close buttons; keep the layout navigable.
- [5:37](https://youtu.be/cY1B5_x4RoU?t=337) **[[common-mistakes]]** Keep fonts, font weights, icons, and colors consistent with one palette and theme; inconsistency is the easiest mistake to make.
- [6:18](https://youtu.be/cY1B5_x4RoU?t=378) **[[common-mistakes]]** Keep padding and alignment consistent; alignment improves readability and makes elements feel related.
- [6:59](https://youtu.be/cY1B5_x4RoU?t=419) **[[common-mistakes]]** Set visual hierarchy so important buttons are sized and placed by importance; an oversized Done button or scattered elements distract.
- [7:39](https://youtu.be/cY1B5_x4RoU?t=459) **[[common-mistakes]]** Don't over-decorate: ensure buttons and icons contrast with their frame so confirm buttons don't blend into the background.
- [7:39](https://youtu.be/cY1B5_x4RoU?t=459) **[[common-mistakes]]** Use familiar icons that players understand without second-guessing their meaning.
- [8:19](https://youtu.be/cY1B5_x4RoU?t=499) **[[core-loops-and-game-design]]** Tune micro-animations: too fast goes unnoticed, too slow and players leave before it finishes; well-timed animations add polish.
- [8:40](https://youtu.be/cY1B5_x4RoU?t=520) **[[playtesting-and-feedback]]** Ask probing questions about your user during design and development to surface problems before release.
- [10:34](https://youtu.be/cY1B5_x4RoU?t=634) **[[building-art-and-assets]]** Add consistent padding (about 15px) around all element edges as a baseline polish step.
- [11:09](https://youtu.be/cY1B5_x4RoU?t=669) **[[building-art-and-assets]]** Pick one limited color palette with gradients and apply it across all UI to boost readability and consistency.
- [11:48](https://youtu.be/cY1B5_x4RoU?t=708) **[[building-art-and-assets]]** Standardise corner radius across all UI frames (example used 6px) for a unified look.
- [12:09](https://youtu.be/cY1B5_x4RoU?t=729) **[[building-art-and-assets]]** Simplify overwhelming UI by enforcing consistency first, then remove or repurpose elements that add clutter.
