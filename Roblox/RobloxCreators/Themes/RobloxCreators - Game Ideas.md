## [[core-loops-and-game-design]]
- 2021-07-22 [8:51](https://youtu.be/UL4QaSbfyC4?t=531) Ask first how any new feature enhances the core loop; integrate content into the loop rather than alongside it. ([[2021-07-22 - What are Game Expansions with Dspav|What are Game Expansions? with Dspav]])
- 2021-07-22 [9:41](https://youtu.be/UL4QaSbfyC4?t=581) A core loop is the minute-to-minute action repeated every session and the engine for all progression; if it isn't fun, nothing else will save the game. ([[2021-07-22 - What are Game Expansions with Dspav|What are Game Expansions? with Dspav]])
- 2021-07-22 [15:54](https://youtu.be/UL4QaSbfyC4?t=954) Avoid tumors: systems that compete with the core loop for attention. They split the player base and create update debt for a small subset of players. ([[2021-07-22 - What are Game Expansions with Dspav|What are Game Expansions? with Dspav]])
- 2021-07-22 [16:38](https://youtu.be/UL4QaSbfyC4?t=998) Don't offer an opt-out alternative to the core activity (e.g. fight club vs class); a 50/50 split typically tilts to 10/90, leaving one side empty. ([[2021-07-22 - What are Game Expansions with Dspav|What are Game Expansions? with Dspav]])
- 2021-07-22 [35:55](https://youtu.be/UL4QaSbfyC4?t=2155) If the core loop isn't fun, fixing it is the top priority, even if it means treating a major expansion as a redo of the core experience. ([[2021-07-22 - What are Game Expansions with Dspav|What are Game Expansions? with Dspav]])
- 2021-07-22 [39:19](https://youtu.be/UL4QaSbfyC4?t=2359) Keep the core loop simple and easy to enter; the systems around it create the memorable moments like boss fights with dodge and heal choices. ([[2021-07-22 - What are Game Expansions with Dspav|What are Game Expansions? with Dspav]])
- 2021-07-22 [40:43](https://youtu.be/UL4QaSbfyC4?t=2443) Focus on a single core loop; parallel loops create an unintentional rift where players effectively play different games. ([[2021-07-22 - What are Game Expansions with Dspav|What are Game Expansions? with Dspav]])
- 2021-07-22 [41:24](https://youtu.be/UL4QaSbfyC4?t=2484) Let players create their own side experiences (e.g. trading for profit) but don't build dedicated content for emergent behaviours of a minority. ([[2021-07-22 - What are Game Expansions with Dspav|What are Game Expansions? with Dspav]])
- 2021-08-05 [9:09](https://youtu.be/pSjFYDEgRxs?t=549) Before balancing, define how often players engage with a feature (daily, per session, weekly) and how long it should last. ([[2021-08-05 - Balancing Game Expansions with Dspav|Balancing Game Expansions with Dspav]])
- 2021-08-05 [17:09](https://youtu.be/pSjFYDEgRxs?t=1029) Add currency or resource sinks (repeatable spend items) to pull inflated economies back toward balance over time. ([[2021-08-05 - Balancing Game Expansions with Dspav|Balancing Game Expansions with Dspav]])
- 2021-08-05 [18:32](https://youtu.be/pSjFYDEgRxs?t=1112) Cap currencies and resources (e.g. 99 wood) so players spend rather than hoard and you can require more in future content. ([[2021-08-05 - Balancing Game Expansions with Dspav|Balancing Game Expansions with Dspav]])
- 2021-08-05 [04:21](https://youtu.be/pSjFYDEgRxs?t=261) Consider how a feature changes the economy: what resources it creates or sinks and which existing systems it affects. ([[2021-08-05 - Balancing Game Expansions with Dspav|Balancing Game Expansions with Dspav]])
