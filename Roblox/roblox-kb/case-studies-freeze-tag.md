# Case study: Freeze Tag

**Genre:** Rescue-tag / starter game

A simple rescue-tag game used as a mechanical reference, a starter-project concept, and a retention comparison point against Hot Potato.

## What creators say about it
- Freeze Tag is a mechanical reference for rescue-tag gameplay. ([1Coal 2024-03 0:23](https://youtu.be/gWNOANEPYLY?t=23))
- A simple, small game concept is suitable as a starter project. ([SmartyRBX 2024-09 2:15](https://youtu.be/59AbBgxhfTA?t=135))
- Freeze Tag was used to compare player retention against Hot Potato, so simple games can be benchmarked on retention. ([SmartyRBX 2025-06 16:11](https://youtu.be/skcp4P68i84?t=971))

## Transferable patterns
- Scope a first project to a simple, small mechanic
- Benchmark retention against comparable simple games
- Use well-known mechanics as a design reference
