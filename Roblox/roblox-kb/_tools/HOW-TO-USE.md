# How to use the Roblox agents (for Roman, phone-readable)

Just message the manager in plain words. It picks the right specialist, reads the Roblox knowledge base (516 sources, official docs and 25 creators), and answers with sources. Official Roblox advice beats creator advice; creator numbers are labelled "indie, self-reported".

## What to say, who handles it

| You say | Handled by | You get |
|---|---|---|
| "Give me game ideas for 2 people, 3 weeks" / "design doc for X" | roblox-game-designer | scored ideas, GDD, first-2-minutes script, economy |
| "Price my gamepasses" / "audit my monetisation" | roblox-monetization-consultant | offer list with Robux prices, when to show each, 3 price tests |
| "Plan a $100 ad test" / "thumbnails and title for X" / "Discord launch plan" | roblox-launch-marketing-manager | ad plan with budget math, thumbnail and icon brief, launch calendar |
| "My game has 8% D1 and 3 min sessions, what do I fix?" | roblox-game-doctor | numbers vs benchmarks, ranked fixes, 14-day test plan |
| "Plan my updates and events" | roblox-liveops-planner | 12-week calendar sized to your team |
| "Write the purchase script" / "fix this Luau" | roblox-luau-engineer | secure, checked code |
| "Am I ready to launch?" | roblox-launch-checklist | tick-box checklist for your game |
| "What do top creators say about X?" | roblox-kb-answer | short cited answer |
| anything bigger or mixed | roblox-studio-lead | runs several specialists, merges one plan |

## Tips

- Give numbers when you have them (D1, D7, session length, payer conversion, daily players, budget). Missing ones are listed as "needed next", never guessed.
- Say your team size, weeks available and audience age; plans scale to them.
- Every claim has a link with a timestamp. "official" = Roblox docs or Roblox sessions. "indie" = a creator's own figures.
- The KB grows daily; quick-reference files in this folder (BENCHMARKS, DECISION-RULES, CHECKLIST-launch, CHECKLIST-monetization, PRICE-LADDER, AD-PLAYBOOK) are rebuilt from it. Gaps (for example D30 and bounce benchmarks) are called out as "KB gap".
- Agents only plan and advise. They never spend Robux or money, post, or publish; those steps come back to you for approval.

## Studio control

Reading and editing a real place needs Roblox Studio open and signed in to you, with the built-in MCP server switched on (Assistant, three dots, Manage MCP Servers, Enable Studio as MCP server). See `claude-library/mcp/roblox-studio-mcp.md`.

## For the manager

Rebuild the quick references after the KB changes: `python ~/claude-library/tools/roblox-kb/build_tools.py` (about 30 s). Search the KB cheaply: `python ~/claude-library/tools/roblox-kb/kbq.py route|find|num|section|case|docs "<query>"`. Presets are generated by `tools/roblox-kb/gen_presets.py`.
