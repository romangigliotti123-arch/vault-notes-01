# Case study: Pet Simulator X

**Genre:** Simulator / collection

Pet collection simulator with coin-earning core loop, egg unlocks, area walls and collect-all long-term goals. Predecessor to Pet Simulator 99 and a reference for pet progression and gacha-style design.

Also referred to as: Pet Simulator X!

## Numbers
- No CCU or revenue figures given in the input; 'about 50% of combined pets' is a balance claim (Roblox Creators, G512)

## What creators say about it
- Show a clear long-term goal from spawn (collect all pets), with area walls and egg unlocks as mid-term goals and coins as the core loop (Roblox Creators). ([Roblox Creators 2021-12 8:43](https://youtu.be/hD2Ive5RqtE?t=523))
- Pay-to-win-adjacent progression works if no single pet is overpowered; the balance point was about 50% of combined pets (Roblox Creators). ([Roblox Creators 2023-01 0:00](https://youtu.be/YdplC2WVkWc?t=0))
- Gacha-style pet gambling is core to the design (CORSO), but it's a sensitive area. Daily quests and playtime rewards give a reliable currency drip (Roblox Creator Docs; Stewiepfing). ([CORSO 2023-10 5:50](https://youtu.be/H9MoA94zKdc?t=350), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/game-design/introduction-to-quest-design), [Stewiepfing 2024-02 0:42](https://youtu.be/v8tFfBTr6M8?t=42))
- Autofarm scripts are the main exploit vector in simulators (DevForum). Clones copy the UI and main server script but many features break (TheDankDeveloper). ([Roblox DevForum 2023-08](https://devforum.roblox.com/t/securing-your-anticheat-common-bad-practices-and-how-powerful-are-exploiters-guide-on-handshakes/2519952), [TheDankDeveloper 2023-11 0:00](https://youtu.be/fqMj_b2m-Ik?t=0))
- Trading and pet transfer features carried into Pet Simulator 99 (Mulch), showing predecessor mechanics persist. ([Mulch 2024-12 0:00](https://youtu.be/tdnhCXx3srA?t=0))
- Remix of Pet Simulator 2 with strong numbers (rasdev, 2026-10; figure not specified). ([rasdev 2026-10 2:51](https://youtu.be/e4o-ECkzDoI?t=171))

## Transferable patterns
- State a collect-all goal from the first minute.
- Keep any single item from dominating the economy.
- Use daily quests as a predictable currency drip.
- Guard simulators against autofarm exploits early.
