# Case study: DONT SPLASH

**Genre:** Obby / platformer (eerie runner)

Eerie obby/runner inspired by Poolrooms and House of the Locust atmosphere. Tracker and Roblox API snapshots report about 143-144K concurrent by Oct-Nov 2026.

Also referred to as: DONT SPLASH

## Numbers
- ~144K concurrent by Oct 2026 (RoWatcher, tracker blog) G2273
- 143K concurrent and 119M visits within ~15 days (Roblox public API) G2730
- 144,092 players; #1 trending and #11 top-playing on snapshot (Roblox public API) G2715

## What creators say about it
- Atmosphere-led obby: a recognisable eerie reference (Poolrooms, House of the Locust) gave the game its identity and was cited as its hook. ([RoWatcher (tracker blog) 2026-10](https://rowatcher.com/games/10771421858/dont-splash), [Roblox public API 2026-11](https://www.roblox.com/games/119958473240233/))
- Fast scale is possible for a short obby: ~143K concurrent and 119M visits in ~15 days per the Roblox API. Treat as platform-reported snapshot data, not long-run retention. ([Roblox public API 2026-11](https://www.roblox.com/games/119958473240233/), [Roblox public API 2026-11](https://www.roblox.com/discover#charts-20261101))
- Trending and top-playing rank can be reached quickly (#1 trending, #11 top-playing on one snapshot) without a long history on the platform. ([Roblox public API 2026-11](https://www.roblox.com/discover#charts-20261101))

## Transferable patterns
- Choose a clear mood reference so an obby is instantly identifiable
- Keep a short, repeatable obby/runner loop that new players grasp at once
- Track trending and top-playing ranks as early signals of traction
