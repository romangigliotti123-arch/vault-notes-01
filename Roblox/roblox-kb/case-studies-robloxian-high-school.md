# Case study: Robloxian High School

**Genre:** Social life sim / roleplay

A Roblox school roleplay game built on an explore, attend class and customise core loop. Adds a battle pass 'Grades', mini-games, class activities and seasonal content.

## What creators say about it
- Every system (explore, attend class, customise) augments one core loop; many systems tie back to it. ([Roblox Creators 2021-07 11:12](https://youtu.be/UL4QaSbfyC4?t=672), [Roblox Creators 2022-01 4:12](https://youtu.be/bROouMt1b3g?t=252), [Roblox Creators 2022-06 9:19](https://youtu.be/Mep4_w8qxeE?t=559))
- A battle pass 'Grades' with exclusive rewards and daily star caps drove heavy monetisation and more classroom social play. ([Roblox Creators 2021-07 0:20](https://youtu.be/Gv5OVVyWM10?t=20))
- Class attendance felt boring, so the team added mini-games and a season pass, and class activities as an expansion to make class meaningful. ([Roblox Creators 2022-06 9:19](https://youtu.be/Mep4_w8qxeE?t=559), [Roblox Creators 2021-07 11:12](https://youtu.be/UL4QaSbfyC4?t=672))
- Seasonal content gives a limited-time cadence if the season suits the audience. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/game-design/content-updates))

## Transferable patterns
- Tie every system back to one core loop
- Battle pass with daily caps to pace spending
- Add mini-games to fix a boring core activity
- Match seasonal themes to the audience
