# Trailers And Video Marketing

_trailers, TikTok/Shorts, gameplay clips, social media content, video production for games._

Evidence base: 113 extracted items from 49 videos by #7Phantom, Cumin, Deconstructor of Fun, Duckable, Erthlord, GamesBeat, ItsZyonic, Last Level Studios, Lnor Roblox, LovJak, Matt The Method, Platform Aeronaut (transcript), Raul, Roblox, Roblox Creator Docs, Roblox DevForum, Roblox Investor Relations, Roblox Newsroom, SmartyRBX, TheDevBacon, VuukStudios, eGamers, janisjanis01, rasdev, studio rook., {EISABOOS} "RBX" (2017-11-29 to 2026-10-28). ## Overview
Trailers and video marketing for Roblox games rest on a few principles. Show real, current in-game footage of the core loop, and hook viewers in the first seconds. Tell a story with pacing in limited playback time, and structure external trailers as hook, features, then title card with CTA. Capture clean footage with freecam and upload gameplay videos as files via Creator Hub. Short-form (TikTok first, then Shorts and Reels) works as acquisition: start early, post consistently, prioritize quality over volume, and budget realistic production time. Track your over-1,000-view pattern and repeat it. Moments is now a major discovery surface. It sits directly beside playable games, mixes game captures with influencer video, and supports avatar item purchases and comments from videos. A trailer cannot save a bad game.

## Where creators agree
- rasdev and Roblox DevForum (official) agree on real in-game footage over cinematic/animated trailers.
- rasdev, Duckable, Lnor Roblox, studio rook., and the DevForum creators agree that early devlog/gameplay posting builds awareness.
- VuukStudios, rasdev and TheDevBacon agree that TikTok/short clips drive organic discovery.
- janisjanis01, #7Phantom and VuukStudios agree on consistent posting.
- rasdev and Roblox agree gameplay previews/video help players judge a game before clicking.
- Platform Aeronaut, GamesBeat and Roblox Investor Relations all describe Moments moving toward gameplay-linked video, with game clips and playable games sitting alongside creator video (T17502, T17534, T17551).

## Where creators disagree
- **Volume vs quality**
  - VuukStudios: post short-form daily and long-form weekly.
  - janisjanis01 (June 2025): higher-effort, fewer videos outperformed volume, though earlier in May 2025 and elsewhere he stressed consistency.
  - #7Phantom: invest in good ads but also post 2-3x/week minimum.
- **Trailer CTA/title card vs platform rules**
  - rasdev recommends a title card with call to action and 60-90s trailer.
  - Roblox DevForum: on-platform videos must not have promo text, voiceover or cinematic styling, so rasdev's structure applies only to external trailers.
- **Speed of devlog payoff**
  - Duckable: one devlog reached 100k views in a month.
  - rasdev: YouTube devlogs build interest over time but grow slowly.
- **How early to ramp promo around launch**
  - Cumin (T17806): start trailers earlier than other promo, but go to full promo speed only near release.
  - Existing knowledge-file rule 'Start posting short-form promo early, even when the game is rough': begin short-form posting early regardless of polish. Not a direct conflict. Cumin refines the timing of paid or full-tempo promo, not whether to post early.

## Instructions for an agent using this file
- If asked to make a trailer for the Roblox game page, then use only real current gameplay, no voiceover, narration, promo text, lyrics music or cinematic scenes.
- If the user has a YouTube-embedded game video, then tell them embeds were removed September 30, 2026 and to upload a file via Creator Hub > Configure > Places > Videos.
- If making an external trailer, then use 60-90s, a 5-10s action hook, features in 15-20s, title card with CTA, and on-beat music.
- If the game is weak or unfinished, then advise improving the game before heavy trailer investment, though devlogs and rough clips are fine for early awareness.
- If planning social content, then recommend TikTok/Shorts, a first-seconds hook, and a consistent cadence; track videos over 1,000 views and repeat the common element.
- If the user needs cinematic screenshots or footage, then give the freecam shortcuts and settings (hidden UI, FOV, roll, Stiffness, post-processing, Player Lock).
- If quoting indie view or subscriber figures, then label them self-reported and unverified.
- If measuring creator or video campaigns, then use at least a 7-day click window.
- If the game has a notable update, then submit a Today's Picks nomination with a trailer and core-mechanic footage.
- If the audience is mainly non-English, then make content in that language.
- When advising on Moments, prefer the official Roblox Investor Relations update (T17551) over indie claims, and say which source is official.
- When citing Platform Aeronaut or eGamers figures (T17502, N7239), label them indie self-reported and do not present them as benchmarks.
- If a creator asks how to get into Moments, cover the Experience Details Page route (T17534) and the preview and clip quality rules before any platform-specific tactics.
- Do not invent retention percentages. The only Moments retention evidence is qualitative.
- When a creator's clip is for Moments, check that the first seconds show the game itself, not only creator commentary.
- When writing promo copy for YouTube, X, or Discord, include the game's Details Page URL so viewers can play directly (T17662).
- When advising on Moments, state that the feature is announced and verify rollout status first (T17681).
- When recommending Details Page or Moments clips, lead with gameplay because Moments clicks go to play (T17681).
- If the task is launch promo timing, then schedule creator videos 1-2 weeks before launch and reserve full promo tempo for the weeks near release (T17806).
- If the task is paid Meta or Google ad creative, then use polished cinematics and looping motion graphics rather than lo-fi footage (T17951).
- If the task is TikTok-style organic short form, then favor lo-fi developer diaries and organic storytelling over polished ad styling (T17951, Q1839).
- If an existing rule says to post short-form early and a source says to ramp full promo near release, then keep early organic short form for acquisition and save paid or full-tempo promo for near launch (T17806).
- If you cite the 15202-view figure (N7715), then state that it is self-reported and that the video and timeframe are unknown.
- If you report indie figures from these sources, then label them self-reported and low-advice where tagged (T17951, Q1839).
- If a user asks how long to make Shorts from long videos, suggest about 10-20 seconds with the hook in the first two seconds (T18608, self-reported).
- If a user is a beginner who hesitates to post dev content, encourage starting now and note they only need to be a few steps ahead of viewers (T18580, Q1900).
- If a user is building brand assets, recommend a durable style guide covering logos, lockup, and character art (T18680).
- Label all of these items as indie, self-reported advice, not platform ground truth.
- Do not treat the 10-20 second length as an official platform rule.
- If a developer asks how to build hype before launch, suggest a recurring YouTube build-series in addition to short-form, and label the traffic claim as indie self-reported.
- Do not treat a single devlog as a series; advise a regular, numbered cadence if the developer wants the hype effect.
