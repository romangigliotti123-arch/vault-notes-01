# Case study: Obby

**Genre:** Obstacle course / platformer (genre, not one named game)

Obstacle-course genre. Notes cover rising-difficulty sections, a kill brick with random collision-off parts for chaos, a sponsored ad with weak returns, and Roblox's student obby as a first Studio project. No single game is named.

Also referred to as: Obby (generic), Obby (creator's unnamed game), Obby (creator's own, unnamed), Obby (example course), Obby (template), Obby

## Numbers
- 6.1K starting visits on a sponsored 'Obby' ad; low CTR and few visits for 999 Robux spend (janisjanis01, G645; self-reported)
- Sponsored 'Obby' ad: 6.1K starting visits; low CTR and few visits for 999 Robux spend (janisjanis01, self-reported) [G655]

## What creators say about it
- A repetitive core task stays fun when new sections with rising difficulty appear as players progress. ([Roblox DevForum 2020-07](https://devforum.roblox.com/t/how-to-make-a-successful-roblox-game/690805))
- A kill brick paired with random collision-off parts and an end reward makes a simple obby feel chaotic and fun (creator's own game, self-reported). ([ByteBlox 2024-03 0:00](https://youtu.be/lJ_ZwfNHkQU?t=0))
- A sponsored ad returned low CTR and few visits for 999 Robux spend, despite 6.1K starting visits (self-reported). ([janisjanis01 2023-10 0:59](https://youtu.be/5E5pj7CB4mM?t=59))
- Roblox docs use the classic obby as the first student project: students build jumping-puzzle obstacle courses. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/education/lesson-plans/build-an-obby-lesson), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/education/lesson-plans/digital-citizenship/intro-to-roblox))
- Pairing a kill brick with random collision-off parts and an end reward makes a simple obby feel chaotic and fun. ([ByteBlox 2024-03 0:00](https://youtu.be/lJ_ZwfNHkQU?t=0))
- A sponsored ad for a generic obby returned low CTR and few visits for 999 Robux (creator-reported). Test small before committing large ad budgets. ([janisjanis01 2023-10 0:59](https://youtu.be/5E5pj7CB4mM?t=59))
- Students commonly build jumping-puzzle obstacle courses as a first Roblox Studio project, so obbies are a common beginner exercise. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/education/lesson-plans/build-an-obby-lesson), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/education/lesson-plans/digital-citizenship/intro-to-roblox))

## Transferable patterns
- Escalate difficulty in sections
- Add chaos modifiers to a simple core loop
- Verify ad ROI on a small spend before scaling
- Use obby as a beginner build project
- Escalate difficulty in new sections as players progress
- Add randomised hazards and rewards to make simple mechanics feel chaotic
- Test paid ads on a small budget before scaling
