# Case study: Mining Simulator

**Genre:** Simulator / mining

An early Roblox simulator where players mine rocks, sell them, and track leaderstats. Its first version was basic and later remade and improved. Mentioned as possibly the first top-played Spanish-localized game.

## What creators say about it
- A group-only item tells players to join the fan group, building early connections. ([Roblox 2018-07 13:20](https://youtu.be/4rvzuYMtSlA?t=800))
- Mentioned as possibly the first top-played game localized to Spanish with the Roblox system. ([Roblox 2018-07 15:18](https://youtu.be/qoWMP-AFT08?t=918))
- Ship a basic first game (mine, sell, leaderstats), then remake and improve it later. ([JustDucksey 2025-04 0:47](https://youtu.be/qxE7JhikvwY?t=47))

## Transferable patterns
- Gate exclusive items behind joining a group
- Localize early using the Roblox localization system
- Ship a basic core loop first, then remake it
