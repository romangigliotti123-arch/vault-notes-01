# Case study: Mansion of Wonder

**Genre:** Roblox Education template / tutorial game

Official Roblox Education template. A fox NPC (Freddie) hands out redeemable challenge codes, carnival rides let players defend carts with magic blasters, and arrow beams guide new players around the world.

## Numbers
- No CCU or revenue figures in the notes

## What creators say about it
- Arrow beams guide new players around a world. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/education/landing-pages/build-it-play-it))
- An NPC hands out a redeemable code for completing a challenge, rewarding players with an item and badges. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/challenge-checkpoint), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/challenge-checkpoint-2))
- Build the blast and explosion VFX from three particle images, as in the official carnival ride template. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/curriculums/artist/work-with-particle-emitters), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/become-an-artist))

## Transferable patterns
- Arrow-beam wayfinding for new players
- NPC-redeemed codes for challenge rewards
- Three-particle VFX kit for cheap effects
- Educational templates as learning vehicles
