# Case study: Squishmallows

**Genre:** Collection and combination game (Roblox Creator Docs example)

Collection game used as a Roblox Creator Docs example. Covers contextual tutorials, the three-merge at a combination station, a campsite quest for exploration and a VIP pack subscription.

## What creators say about it
- A contextual tutorial fires after two identical items are collected, teaching the three-merge at the combination station. ([Roblox Creators 2023-12 1:23](https://youtu.be/dXqZC4x2Vn8?t=83))
- A quest surfaces a campsite location, encouraging exploration of the map. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/game-design/introduction-to-quest-design))
- Shown as an example of a VIP pack subscription. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/game-design/subscription-design))
- Contextual tutorials trigger on state (duplicate items, first marketplace discovery) instead of in an upfront onboarding flow. Most recent guidance (2026-10). ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/game-design/onboarding-techniques))

## Transferable patterns
- Trigger tutorials from player state, not upfront onboarding.
- Use quests to point players to map locations.
- Offer subscription VIP packs as a recurring purchase.
