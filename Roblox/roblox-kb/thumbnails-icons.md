## Overview
Creators agree that packaging (icon, thumbnail, title) decides whether players click. The newest indie guidance (2026) says to design and test the icon before building the game. Practical workflow: render clean transparent icons at 1000×1000 and downscale to the 512×512 upload spec, test 3–5 icon/title variants against trending front-page icons, and run monthly ASO tests. 2024 Studio-based thumbnail guides add specifics: expressive poses, FOV around 30, sun-lit subjects, soft shadows, sparing glow, and text-colour tests. All sources are indie and self-reported. Newer advice conflicts with the existing "fix the product before polishing" rule, the 1920×1080 design spec, and the "avoid plain backgrounds" rule for item icons.

## Rules and findings
- **Treat packaging as gating every other signal** (multiple-creators): Click/play-through rate gates all other signals; weak icon/title/thumbnail means no impressions regardless of game quality. Roblox says poor icons/thumbnails can cost up to 4–5x recommended players. Optimize packaging as part of the game. - **Show real gameplay honestly; avoid clickbait** (multiple-creators): Thumbnail, icon, title and description must match actual gameplay. Clickbait lowers qualified playthrough rate because players must stay and act, and mismatched content is detected and filtered (2025). Show what players will actually do. - Thumbnails should be accurate to gameplay (Roblox staff; Tizzy on feeling).
- Keep consistent theme/recognizable style (Roblox, MoseyTube).
- Simple, single focal point (Roblox, MoseyTube, Tizzy).
- Real, current gameplay in thumbnails and videos is required; cinematic, altered or misleading visuals are rejected (T3758, T3759, T3860, T3865).
- Simple, bold, high-contrast, colourful visuals readable at a glance perform best (T3400, T3509, T3540, T4889).
- Thumbnails and icons are a discovery and conversion lever tied to play-through; packaging comes before other fixes (T3576, T4812, T3815).
- Distinct games and distinct thumbnails help discoverability; reusing your own old thumbnail is not penalised (T4474, T3600).
- Test many creatives, then scale or disable based on per-creative results (T4293, T4862, T3800).
- Packaging (icon, thumbnail, title) is the first lever when CTR is low; the 2026 rasdev and janisjanis posts both say so, with rasdev citing the 3% threshold.
- One clear focal point, high contrast and minimal text are the core design rules across rasdev, bubDEV and janisjanis.
- Thumbnails are built in-engine in Studio and then polished, rather than rendered in 3D tools (janisjanis 2025–2026, bubDEV).
- Test multiple variants and compare them with data rather than judging by eye.
- Icons must be checked at phone size and against competitors.
- Thumbnails and icons are a main driver of clicks and discovery (GnomeCode, VuukStudios, PineappleDev, Matt The Method, Raul).
- Test thumbnails and ad creatives before committing spend (1Coal, VuukStudios, Raul, Arow).
- Make thumbnails and icons on-brand and clear, not just attention-grabbing (GnomeCode, VuukStudios).
- Packaging quality, meaning icon and thumbnail, is the main lever on clicks: RoyalDev says thumbnails hold the game back, with icon and title next, and the 2026 sources agree that the icon is the first thing players see.
- A strong icon drives sponsored-tab clicks (BubuTheDev, T16146), consistent with RoyalDev on icon priority (T16709).
- Creatives decay and should be refreshed regularly (Mulch T16210; LovJak commissioning gave a measurable lift, T16475).
- RoyalDev (Q1824) supports the existing rule that solo developers can make their own thumbnails without outsourcing.
- Packaging drives clicks more than game quality (rasdev, janisjanis Q1927, SmartyRBX on positioning).
- Cutouts need a clean outline or stroke (BloxianCode T18427, SmartyRBX T18491, Stewiepfing T18508).
- Test several icon or thumbnail variants before committing (GameMakers T18452, rasdev T18698, janisjanis T18598).

- Keep visuals simple and uncluttered (rasdev T18690, SmartyRBX T18496/T18498).

## Instructions for an agent using this file
- If a user's game has low CTR/PTR vs genre peers, then redesign thumbnails first and run multiple variants in an ad test.
- If designing a thumbnail, then use one big focal subject, high contrast, large text, and preview at phone size.
- If asked how many thumbnails, then give 3–5 for personalization and 10+ for ad tests, noting current Ads Manager caps should be verified.
- If testing, then change one element, equal budget and duration, and promote the winner.
- If a thumbnail wins now, then keep rotating new candidates and refresh when QPTR declines.
- If asked about clickbait, then advise against it citing QPTR and filtering.
- If shipping an update, then refresh icon/thumbnail with a variation and marker, max once a week, revert if dip.
- If benchmarking CTR, then use <1.5% poor, 2.5% average, 3.5%+ great, labeled as indie self-reports.
- If asked about preview video, then require authentic in-engine footage without CGI or overlays.
- If conflicts on mechanics arise, then prefer official Roblox statements.
- If a thumbnail is not exactly 16:9 1920×1080 under 3 MB, re-export before upload; otherwise the platform will crop or stretch it.
- If a personalized game has fewer than 2 active thumbnails, add until there are 2–5 active; never run with one.
- If essential text or a logo sits in the bottom edge, move it up out of the player-count area.
- If the game icon is default auto-generated or ambiguous, replace it with a custom 512×512 square that shows theme and genre.
- If the footage contains voiceover, narration, lyric music, promo text, cinematic trailer styling or over-enhanced visuals, rebuild the video from real in-game capture.
- If three video thumbnail uploads have been used this month, defer further uploads until the quota resets.
- If a campaign creative underperforms its peers, disable it and test a replacement; keep the campaign at up to 10 creatives.
- If badge, pass or product icon content extends outside the circle, move it inside before upload.
- If an event is live, use a unique event thumbnail that differs from your experience thumbnails.
- If CTR is near 0.5% (about 200 impressions per click), treat it as a packaging problem and repackage before changing gameplay; target about 5% (self-reported benchmark).
- If the icon fails the half-second glance or one-sentence test, redesign it before spending on ads.
- If the icon is a raw in-game screenshot or AI-generated art, replace it with a composed image (newest guidance, 2026).
- If Creator Hub CTR is below 3%, fix icon, title and thumbnail before changing anything else.
- If CTR is high but players or PTR are low, fix the game and retention before scaling ads.
- For sponsored ads, produce a 16:9 thumbnail as well as the square icon.
- Compare thumbnails by per-asset ThumbnailQualifiedPTR, not CTR alone, and export data within 30 days.
- Keep at least two variants per game; replace underperformers and keep winners.
- Use one focal subject, large face or hook object, and at most 1–2 words of text.
- For horror games, use mood and mystery, not oversaturated brights.
- Reject referenced-character or brainrot-style clickbait that does not match the game.
- If the user is publishing a Marketplace asset (accessory, model, etc.), create the custom thumbnail with the Custom Thumbnail Tool before publishing, because it cannot be changed afterward.
- If the user asks how to test thumbnails or icons, prepare two thumbnails plus an icon and run about $20 per variant as ad tests.
- If the user reports a CTR figure, compare it to the 2026 minimum of 3-4% and flag below 1.5% as a weak signal to fix.
- If the user wants to change the icon, advise small, controlled changes so existing players still recognise the game.
- If the user wants to change a thumbnail on a running ad, explain it cannot be swapped and recommend a new ad creative.
- If the user asks for variant generation, suggest a thumbnail generator (RoThumb's) and say to verify output with a real test.
- If the user has no visual direction, start from a colour palette and a conceptual art summary.
- When citing benchmarks, name the source and date, and prefer the newest figure over older ones.
- Treat indie CTR figures as self-reported; treat Roblox Creator Docs figures as official.
- Do not cite the Robux-cost upload fee as current without verification.
- If sponsored-tab CTR is weak, test a stronger icon first, then 16:9 variants, and compare results.
- If ad CTR is below about 1.5%, check targeting and campaign settings before replacing the thumbnail.
- If a creative uses a trending meme, plan a refresh within about one month.
- If producing vertical video creatives, composite at 800x1000 and keep canvas size to avoid stretching.
- If a screenshot looks soft, sharpen lightly (up to about 2.5) or upscale 2x (strength 0.5) before posting.
- If the item or game feature is weak, fix it before polishing the presentation.
