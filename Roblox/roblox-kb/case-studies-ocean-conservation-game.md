# Case study: Ocean Conservation Game

**Genre:** Educational / immersive learning

An educational Roblox experience with an in-Roblox museum teaching ocean conservation. Frequently cited as a popular educational example that offers private servers.

## What creators say about it
- Educational showcase: an in-Roblox museum teaching ocean conservation is an example of immersive learning. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/education/educator-onboarding/5-next-steps))
- Listed as a popular example of an educational game offering private servers. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/education/support/private-servers-for-classroom-use))
- Featured as an example educational game in the Creator Docs intro. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/education/educator-onboarding/1-intro-to-roblox))

## Transferable patterns
- Use immersive spaces (like museums) to teach real-world topics
- Offer private servers for educational experiences
