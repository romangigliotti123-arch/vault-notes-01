# Case study: Fish It

**Genre:** Fishing simulator (luck-based, idle-friendly)

Click-to-charge fishing sim: cast, catch, sell fish for coins, buy rods to unlock zones. Simplified, AFK-enabled mechanics drew casual players. Cited as the first-to-market fishing game that was later cloned and remixed.

Also referred to as: Fish It!, Fish It! (Fish Atelier)

## Numbers
- ~2.7M peak CCU, attributed to simplified mechanics (RoWatcher tracker blog, 2026-00)
- Original outperformed its clone ~2:1 in players (MonarchDev, 2026-09)
- 1M+ fish variations, seasonal expansions, tiered gamepads (Roblox public API, 2026-11, listed as Fish It! (Fish Atelier))

## What creators say about it
- Simplifying fishing into a luck-based, AFK-enabled, click-to-charge core reached ~2.7M peak CCU and was credited with sparking a fishing genre boom. ([RoWatcher (tracker blog) 2026-00](https://rowatcher.com/news/fish-it-reels-in-270k-players-inside-roblox-s-most-addictive-casual-game-of-2026), [RoWatcher (tracker blog) 2026-03](https://rowatcher.com/news/the-10-fastest-growing-roblox-games-in-march-2026), [Roblox public API 2026-11](https://www.roblox.com/games/121864768012064/))
- Progression through rarer fish and rod upgrades keeps players grinding. ([Ventures 2025-12 6:28](https://youtu.be/Nb50UhXcpRM?t=388), [TheDankDeveloper 2026-01](https://youtu.be/BYhhm9o3H_E))
- A first-to-market game saturates the fantasy; the original outperformed its clone ~2:1 in players. ([Tizzy 2026-06](https://youtu.be/dUmh6GAvJ-E), [MonarchDev 2026-09 4:44](https://youtu.be/haYW1hXahOM?t=284))
- Remixing a proven idea (derived from Fishing Simulator) can succeed. ([rasdev 2026-10 2:51](https://youtu.be/e4o-ECkzDoI?t=171))
- Seasonal expansions and tiered gamepads sustain long-term engagement. ([Roblox public API 2026-11](https://www.roblox.com/games/121864768012064/))

## Transferable patterns
- Simplify mechanics to widen the casual audience
- AFK-enabled idle loops for retention
- Rarity tiers and tool upgrades as grind hooks
- Clone risk: originals keep most of the player base
