# Case study: Bee Swarm Simulator

**Genre:** Collect-and-upgrade simulator

Simulator built on a simple collect-honey-and-sell loop, with complexity added later. Feedable bees and slower progression feel deeper than Pet Simulator, though one reviewer found it too static without a goal.

## Numbers
- No CCU or revenue figures in the notes

## What creators say about it
- Start with a simple collect-and-sell core loop; complexity can come later. ([Roblox Creators 2021-11 21:26](https://youtu.be/rVr0IyfYkPg?t=1286))
- A simple loop with a daily reason to return succeeds without top-tier graphics. ([SmartyRBX 2025-03 0:26](https://youtu.be/_wqZyaTEsHQ?t=26))
- Pets that work constantly are cited as cruel, which inspired a pet-as-player concept. ([ByteBlox 2025-01 0:40](https://youtu.be/RkgxOf3iZfA?t=40))
- Slower progression and feedable bees feel deep, but a static design with no goal weakens the hook. ([Cumin 2025-04 9:15](https://youtu.be/YmAwFbqUA0U?t=555))
- Complementary passes sold side by side (Bee Pollen Pass and Honey Speed Pass). ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/game-design/contextual-purchases))

## Transferable patterns
- Simple loop with a daily return reason
- Add a goal or endpoint to avoid a static feel
- Complementary passes sold together
- Pets-as-players as a concept idea
