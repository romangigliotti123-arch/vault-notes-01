# Case study: Beyond the Dark

**Genre:** Sci-fi environment showcase (space station)

Official Roblox Creator Docs showcase: a sci-fi Kerr-Newman DSR-14 space station used to demonstrate modular building, trim sheets, diegetic UI, ambience, and NPC audio for high-fidelity environments.

Also referred to as: Beyond the Dark (Kerr-Newman DSR-14 station), Beyond the Dark (showcase)

## Numbers
- Roblox-authored (2026-10): triangle reductions measured with mesh LOD on and off, but no figure is given in the notes.

## What creators say about it
- Build from modular packages and trim sheets so layout and art can change during playtests without rebuilding each asset. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/resources/beyond-the-dark/building-architecture), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/resources/the-mystery-of-duvall-drive/materialize-the-world))
- Use diegetic UI: an in-world map built from SurfaceGuis, toggled with ProximityPrompt, with a tweened reveal instead of a flat HUD. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/resources/beyond-the-dark/user-interface), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/resources/the-mystery-of-duvall-drive/immersive-narrative))
- Spot ambiences in distinct areas keep each entry fresh. Layered loops add variety at low cost. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/resources/beyond-the-dark/sound-design))
- Deliver lore through NPC dialogue using periodic positional audio so story arrives through the world. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/use-case-tutorials/audio/add-3D-audio))
- Measure LOD impact: Roblox compared triangle counts with the mesh LOD system on and off. ([Roblox 2026-10 21:21](https://youtu.be/OToDz3Ghpjo?t=1281))
- Official showcases combine modular building, custom characters, layered clothing, SoundService, and UI techniques. Use them as build references, with free model packs as asset quality reference. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/resources/beyond-the-dark), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/art/overview-studio), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/resources/the-mystery-of-duvall-drive))

## Transferable patterns
- Modular kit with trim sheets for fast iteration
- Diegetic in-world UI via SurfaceGui and ProximityPrompt
- Spot ambience and layered audio loops for variety
- Positional-audio NPC dialogue for lore delivery
