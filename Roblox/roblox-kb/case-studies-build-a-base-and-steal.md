# Case study: Build a Base and Steal

**Genre:** PvP build-and-steal

Tizzy's PvP build-and-steal Roblox game: raid bases, collect pets and blocks, with free private servers and daily patches. Creator-owned (co-owned hit); figures are creator self-reported.

## Numbers
- 38K CCU peak and 30% console players (Tizzy, self-reported; G1899).

## What creators say about it
- A base-raid loop with pet and block collection, plus free private servers, drove retention. ([Tizzy 2026-07](https://youtu.be/nggNvUILQ1I), [Tizzy 2026-07](https://youtu.be/LZOohZHsJus))
- The tutorial starts with locking your base, so players learn defence first. ([Tizzy 2026-07](https://youtu.be/nggNvUILQ1I))
- A cutscene showing a pet stolen before the tutorial sets stakes immediately. ([Tizzy 2026-07](https://youtu.be/FnsIL4zPCQg))
- Voxel building felt clunky on mobile; test building controls on mobile. Newer (2026-08) advice: a build mode for players without private servers lets them build in peace, so building no longer depends on private servers. ([Tizzy 2026-07](https://youtu.be/FnsIL4zPCQg), [Tizzy 2026-08](https://youtu.be/TVdqb9O0RMw))
- Update cadence (daily patches) and a core-playtester process support ongoing quality. ([Tizzy 2026-07](https://youtu.be/LZOohZHsJus), [Tizzy 2026-08](https://youtu.be/TVdqb9O0RMw))

## Transferable patterns
- PvP steal loop combined with collection
- Stakes-first cold-open cutscene
- Mobile-first control testing for building
- Daily patch cadence with core playtesters
