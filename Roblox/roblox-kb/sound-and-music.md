# Sound And Music

_sound design, music, audio implementation, mixing, licensing, audio assets._

Evidence base: 171 extracted items from 46 videos by ArTheDev, ByteBlox, Crusherfire, Duckable, GnomeCode, Roblox Creator Docs, Roblox DevForum, SimTek Game Development, janisjanis01, mats-dept2 (2019-04-01 to 2026-10-28). Roblox changes quickly: check the date on each source and see Date context below.

## Overview
Sound and music for Roblox experiences: build on Audio objects for new work, choose positional or non-positional audio by role, and use volumetric emitters for areas. Keep a constant ambient bed with subtle detail layers, and drive zone and event audio from LocalScripts with Ended-based debounce. Mix with SoundGroups or AudioFader, compressors, and EQ, reverb and pitch effects. Accessibility matters: per-category volume, per-trigger mute, distinct per-object sounds, directional captions and visual pairing. Licensing and upload rules from 2022 are historical and must be verified before reuse.

## Rules and findings
- **Prefer Audio objects over legacy Sound and SoundGroup for new work** (one-creator-repeated): The official docs say the newer Audio objects give more control and robust use cases, and that the legacy Sound system is superseded. SoundGroup is explicitly discouraged for mixing and effects. Several official items still describe Sound/SoundGroup workflows (T7289, T7290, T7440, T9449-T9454), so translate those to Audio object equivalents rather than copying them literally. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/sound), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/sound/groups), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/sound), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/sound), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/use-case-tutorials/ui/interactive-ui). Newest source 2026-10-28.
- **Use 3D (positional) audio for sounds tied to a place or object** (one-creator-repeated): Use 3D audio when the sound should be spatial. Audio object route: AudioPlayer plus AudioEmitter on the 3D object, wired together, with AudioEmitter.DistanceAttenuation controlling falloff. Legacy route: parent the Sound to a 3D object or Attachment so it is heard only near that position. For looping 3D sounds, parent to a part inside the object so the sound has a real location. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/sound), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/audio/objects), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/resources/beyond-the-dark/sound-design), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/art). Newest source 2026-10-28.
- **Use 2D (non-positional) audio for global sounds** (one-creator-repeated): Global sounds such as UI, music, narration and omnipresent ambience should be non-positional. Audio object route: wire AudioPlayer to AudioDeviceOutput under SoundService (Wire with SourceInstance = player, TargetInstance = output). Legacy route: insert the Sound directly into Workspace or SoundService. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/sound), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/audio/objects), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/art). Newest source 2026-10-28.
- **Set the listener deliberately** (one-creator-repeated): SoundService.ListenerLocation accepts Default, Character, Camera or None; use None when creating the listener by script. The Creator Docs also say to set DefaultListenerLocation to Character so each player gets an AudioListener under their HumanoidRootPart for positional 3D audio. The two items use different property names (T7629 vs T10021), so confirm the exact property in Studio. - **Keep a constant ambient bed so the game never feels silent** (multiple-creators): A constant ambient layer keeps idle players engaged, and silence can disorient them. The official guide recommends a looping 2D background track or a 2D omnipresent soundbed as the base layer. Duckable adds that per-area atmospheric music should complement gameplay rather than dominate it. - **Give every interaction a feedback sound** (multiple-creators): Pair each player interaction with a sound so it feels responsive. DevForum example: play a tick sound as each crate passes the centre line during a spin. Duckable makes the same point as a general design principle. This is community and indie advice rather than platform mechanics. - **Make seamless loops at a zero crossing** (one-creator-repeated): Match the end and start points of a loop at a zero crossing in an editor such as Reaper or Audacity so the loop point does not click. The official docs also cover this for ambience, music and effects under a staff technique. Start from a clean edit before tuning volumes or effects. - **Layer loops of different lengths to avoid obvious repetition** (one-creator-repeated): Combine two or more loops of different lengths instead of one long loop. Combined variety is the least common multiple of the lengths: 6s and 5s loops only repeat every 30 seconds. Reuse layered source recordings across areas (a river sound reused in a rainforest) to get more mileage from one asset. - **Build spot ambiences on top of a 2D bed** (one-creator-repeated): Use a 2D omnipresent soundbed as the base, then add 3D sounds attached to objects (spot ambiences) to pull the player's attention around the space. Q1118 also says a distant, intriguing sound should be present wherever the player is in the house. - **Use volumetric emitters for large or area sounds, including region ambience** (multiple-creators): Use volumetric audio for rain, rooms, waterfalls, cities and oceans so the sound comes from the whole surface, not the part centre. Disabling volumetric audio collapses the sound to one point. With it enabled, a sound inside a part is heard only once the camera is inside that part, which suits region-based ambience. Crusherfire gives the same advice, but its default-state claim is dated (see next rule). - **Set falloff with RollOffMin and RollOffMax distances** (one-creator-repeated): For legacy Sound, RollOffMinDistance sets full-volume range and RollOffMaxDistance sets silence. The docs example for looping rain on a car part used 15 and 60 studs. For AudioEmitter, the example curve halves volume at 50 studs and reaches zero at 70 studs. Tune both to the real play space. - **Duck low-priority audio with a sidechain compressor** (one-creator-repeated): Nest SoundGroups or audio buses into a priority tree (GUI, weapons, dialogue above music and ambience). Put a CompressorSoundEffect on the low-priority group with Sidechain set to the high-priority Sound or group, so loud local sounds duck the ambient bed. The sidechain must be set on the low-priority group. - **Tune compressor settings by ear, per source; use AudioCompressor for consistent volume** (one-creator-repeated): Threshold (-80 to 0 dB) sets where compression starts; lower values trigger on quieter signals. Ratio (1 to 50) sets ducking strength. Attack and Release (0.001 to 1 s) set how fast ducking starts and how slowly it recovers. Values depend on source levels, so presets from one project will not transfer. AudioCompressor also keeps volume consistent between quiet and loud recordings and caps a sound's maximum volume. Playtest and adjust. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/resources/the-mystery-of-duvall-drive/design-dark-soundscapes), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/sound/groups), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/resources/beyond-the-dark/sound-design), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/resources/beyond-the-dark/sound-design), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/audio/effects). - **Use SoundGroups for balance and organisation (legacy)** (one-creator-repeated): SoundGroup.Volume is a 0 to 10 multiplier for testing balance without editing each Sound; child volumes multiply (a 0.5 Sound in a 0.5 group plays at 0.25). Keep all SoundGroups under SoundService and nest them by category (player abilities versus environment). Assign sounds through the Sound's SoundGroup property; parenting in Workspace does not assign a group. This is legacy guidance, so use Audio object equivalents in new projects. - **Muffle sound with EqualizerSoundEffect or AudioEqualizer** (one-creator-repeated): Use an equalizer to muffle a sound, such as rain, or cut high frequencies for an underwater feel on one layer. To muffle all game audio while a player is underwater, apply AudioEqualizer to the output. Equalizer and reverb effects are the main tools for changing how a sound reads in space. - **Add reverb to interior spaces and pitch down for scale** (one-creator-repeated): Add ReverbSoundEffect or AudioReverb to interiors for realistic reflections. Pitching a recording down and adding reverb implies a larger space, and reverb can make an area feel like a cave. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/sound), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/audio/objects), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/resources/beyond-the-dark/sound-design). - **Use AudioPitchShifter for scale without changing speed** (single-mention): Pitch down a small sound to make it feel huge. Pitch up an explosion to make it lighter. AudioPitchShifter does this without changing playback speed, unlike a simple playback-rate change. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/audio/effects). Newest source 2026-10-28.
- **Mind effect order, reuse effect instances, and use Chorus lightly on synths** (one-creator-repeated): Insert effects between the audio player and the output; unwired streams play the original recording unchanged. Effect order changes the sound, so Chorus then Distortion can differ from Distortion then Chorus; test both. Wire several audio players through one effect instance rather than duplicating identical effects. For otherworldly synth loops, the docs example used ChorusSoundEffect with Rate 16 and Depth 0.21, a mild setting that keeps some original character. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/audio/effects), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/audio/effects), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/audio/effects), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/resources/beyond-the-dark/sound-design), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/resources/beyond-the-dark/sound-design). - **Keep Volume at about 2 or below for loud sources** (one-creator-repeated): Volume is multiplicative, so 4 is four times as loud as 1. Range is 0 (silence) to 10 (booming); 2 or below is usually enough. If the source is already loud, lower Volume first rather than pushing it higher. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/sound/objects), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/sound/objects). Newest source 2026-10-28.
- **Raise RollOffMaxDistance for Inverse and Linear modes** (one-creator-repeated): Low RollOffMaxDistance values make audio cut off abruptly at max distance. Set a higher value for Inverse and Linear rolloff. The 30-stud value in the tutorial is an example only; tune per source. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/sound/objects), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/use-case-tutorials/audio/in-game-sounds). Newest source 2026-10-28.
- **Use a gradual AudioEmitter attenuation curve** (single-mention): Use DistanceAttenuation for a smooth falloff instead of a hard cutoff. The official waterfall sample is {0:1},{20:0.8},{40:0.4},{80:0}: full volume under 20 studs, falling every 20 studs to silence at 80. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/use-case-tutorials/audio/add-3D-audio), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/use-case-tutorials/audio/add-3D-audio). Newest source 2026-10-28.
- **Keep background music Sound objects in one place under SoundService** (one-creator-repeated): Background music plays at the same volume everywhere, so keep its Sound objects together under SoundService. Use non-positional Audio for background music, UI sounds and voiceover cutscene dialogue; reserve positional audio for in-world sources. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/sound/objects), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/use-case-tutorials/audio/add-3D-audio). Newest source 2026-10-28.
- **Set SoundService.DefaultListenerLocation to Character** (single-mention): Setting this to Character auto-creates an AudioListener under each player's HumanoidRootPart. This is a concrete way to implement the listener rule without manual placement. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/use-case-tutorials/audio/add-3D-audio). Newest source 2026-10-28.
- **Sync visual effects to audio with TimePosition in a Heartbeat loop** (single-mention): Read the track's TimePosition each frame in a Heartbeat loop and trigger effects, such as enabling a ParticleEmitter, during a specific window of the track. This keeps visuals locked to the audio. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/sound/objects). Newest source 2026-10-28.
- **Run zone and looping ambience from a LocalScript** (multiple-creators): Each client should play only its own zone's sounds. Call AudioPlayer:Play() from a LocalScript so looping ambience starts on join and stops on leave. Stop the previous zone's sound before starting a new one. Sources: [SimTek Game Development 2022-12 5:39](https://youtu.be/c1jFXwmRtzI?t=339), [SimTek Game Development 2022-12 12:36](https://youtu.be/c1jFXwmRtzI?t=756), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/use-case-tutorials/audio/add-3D-audio). Newest source 2026-10-28.
- **Use AudioPlayer.Ended and a debounce for volume triggers** (multiple-creators): IsPlaying reliably fires only false-to-true because of replication timing, so do not rely on true-to-false for state changes. Listen to AudioPlayer.Ended, debounce false, true, false after audio ends, and call Play only if the sound is not already playing. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/use-case-tutorials/audio/add-3D-audio), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/use-case-tutorials/audio/add-3D-audio), [SimTek Game Development 2022-12 12:36](https://youtu.be/c1jFXwmRtzI?t=756). Newest source 2026-10-28.
- **Play weather sounds on the client when weather starts** (single-mention): Store a hasSound flag and a sound reference per weather type. Play the sound only on the client when that weather begins, so each player hears a consistent cue without server-side playback. Sources: [ArTheDev 2026-04 4:30](https://youtu.be/CnZEnFVAFSw?t=270). Newest source 2026-04-03.
- **Use audio cues to direct players toward objectives** (one-creator-repeated): Use 3D audio for situational events, such as a door opening after an objective completes, so players know where to go regardless of their position. Audio cues should guide players toward what they need to do to succeed. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/audio), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/use-case-tutorials/audio/add-3D-audio). Newest source 2026-10-28.
- **Use Echo for caves and walls** (one-creator-repeated): EchoSoundEffect repeats delayed sound with diminishing volume, which suits walls and caves. Use Reverb for large interiors such as gymnasiums or stadiums, and Echo for surfaces that reflect sound back. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/sound/dynamic-effects), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/sound/dynamic-effects). Newest source 2026-10-28.
- **Swap soundscapes per area or state with volumetric audio** (single-mention): Use SoundService with volumetric audio to create distinct soundscapes per area or state, for example a normal world vs a corrupted one. Switch the active set when the state changes. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/resources/the-mystery-of-duvall-drive), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/sound/objects). Newest source 2026-10-28.
- **Layer a quiet ambient base with combat stingers and a music spike on key moments** (one-creator-repeated): Keep a quiet ambient base running during play. Add combat stingers when fights start. Trigger a music cue that spikes when the player picks up a key, to add tension. This extends the existing ambient-bed and progression-priority rules rather than replacing them. Sources: [mats-dept2 2026-10 1:31](https://youtu.be/Y5QtYzd95v8?t=91). Newest source 2026-10-10.
- **Reserve a loud climax track for the escape or peak moment** (single-mention): Save the loudest, most intense music track for the escape moment. Play it over a night-wind ambience with crisp sound effects. The creator says this raises perceived quality. Keep the source's Volume within the existing guidance (about 2 or below for loud sources). Sources: [mats-dept2 2026-10 2:08](https://youtu.be/evyIBvylLdc?t=128). Newest source 2026-10-10.
- **Seed math.random with tick() for varied random sounds** (single-mention): Seeding with tick() is meant to make random sound selection differ between sessions. Confirm whether Luau already seeds math.random at startup before relying on this (see gaps). Sources: [Crusherfire 2024-05 10:13](https://youtu.be/NsPL5yDY5cE?t=613). Newest source 2024-05-22.
- **Cache GetChildren() when picking random sounds** (single-mention): Store script:GetChildren() in a variable once instead of calling it on every random pick. Refresh the cache only if the children change. Sources: [Crusherfire 2024-05 11:34](https://youtu.be/NsPL5yDY5cE?t=694). Newest source 2024-05-22.
- **Gate random sound picks on Sound.Ended** (single-mention): Wait for Sound.Ended before playing the next random sound so clips do not overlap when a clip runs longer than the wait interval. This is the legacy Sound pattern; for Audio objects, use AudioPlayer.Ended (see the existing debounce rule). Sources: [Crusherfire 2024-05 12:58](https://youtu.be/NsPL5yDY5cE?t=778). Newest source 2024-05-22.
- **Muffle audio underwater with a live EqualizerSoundEffect** (single-mention): Lower the EqualizerSoundEffect high gain while the camera is underwater to muffle sound. Update it live when the camera enters or leaves water. The source is tagged low-advice, so verify the approach before shipping. Sources: [ByteBlox 2025-01 16:34](https://youtu.be/29B9AV_xM_k?t=994). Newest source 2025-01-22.
- **Make your own sound effect when stock sounds are poor** (single-mention): If library or Creator Store sounds do not fit the game, create the SFX yourself instead of continuing to search. The creator says this can be quicker than hunting through libraries. Use it for signature or identity-defining sounds. Tools and method are not specified in this source. Sources: [janisjanis01 2025-01 8:35](https://youtu.be/EpPU3Am8lgE?t=515). Newest source 2025-01-05.

## Checklist

- [ ] Set SoundService.ListenerLocation (or DefaultListenerLocation) to Character for standard per-player listeners; verify the property name in Studio.

## Where creators agree
- Duckable (T6100, indie) and the official docs (T8424, T9569) agree that the game should never feel silent: a constant or atmospheric music layer should sit under gameplay.
- Crusherfire (T5868, indie) and the official docs (T8423) agree that large sources like oceans, waterfalls, rain and cities should be volumetric rather than point sounds.
- Duckable (T6100) and DevForum (T5083) agree that every interaction should get a feedback sound.
- The official docs agree internally that positional audio is for world-placed sources and 2D audio is for global sounds (T6988, T7288, T7289, T10384).
- All official sources agree on sidechain ducking of low-priority audio under high-priority audio (T8426, T9453, T9610).
- Audio should serve both immersion and feedback: Roblox Creator Docs (T14874) and the DevForum ambience advice (T11647) both say so.
- Client-side playback for zone or looping ambience: SimTek (T11514) and Roblox Creator Docs (T15401) both use LocalScripts.
- Avoid restarts and duplicate playback: SimTek (T11515) and Roblox Creator Docs (T15404) both check state before Play and debounce triggers.
- Accessibility benefits from distinct sounds and visual pairing: DevForum (T11085, T11086) and Roblox Creator Docs (T15402) agree.

## Where creators disagree
- **Volumetric audio default state**
  - Crusherfire (T5867, Jan 2024, indie): default Automatic equals Disabled; must set Enabled manually; the planned 2023 update did not ship (N2465).
  - Official docs (T8423, 2026-10): volumetric emitters are presented as a working, recommended technique with no default warning. Prefer the official docs and verify the current default in Studio.
- **Volumetric shape restriction**
  - Crusherfire (T5870, 2024, citing 2022 release notes): only block, cylinder and ball parts benefit.
  - Official docs (T8423): no shape restriction stated. Unresolved; confirm against current release notes.
- **Sound/SoundGroup versus Audio objects**
  - Official docs (T7287, T9448): Audio objects are preferred; SoundGroup is discouraged.
  - Official docs (T7290, T7440, T9449-T9454): still give SoundGroup-based organisation, volume and ducking steps. Same creator, different guidance; treat the SoundGroup items as legacy.
- **TTS voice count**
  - Official docs (N3183): 30 voice IDs.
  - Official docs (N3951): 19 voices. Same month; unresolved. Check the VoiceID options in Studio.
- **Background music volume**
  - Official docs (T9569, N3789): about 0.2.
  - Low-advice video (T9731): about 0.25. Minor; use 0.2 as the official example.
- **Listener property name**
  - T7629: SoundService.ListenerLocation (Default, Character, Camera, None).
  - T10021: SoundService.DefaultListenerLocation set to Character. Likely the same setting under different names; verify in Studio.

## Instructions for an agent using this file
- If the task is new audio work, then use Audio objects (AudioPlayer, AudioEmitter, AudioDeviceOutput, AudioCompressor, AudioReverb, AudioEqualizer, AudioFader) and not Sound or SoundGroup.
- If an existing project uses Sound or SoundGroup, then keep it working and translate to Audio object equivalents when you touch that system.
- If a sound has a world position (fire, NPC, waterfall, object), then use 3D: AudioPlayer plus AudioEmitter on the object, or a Sound parented to a part or Attachment.
- If a sound is global (UI, background music, narration, omnipresent ambience), then use 2D: wire AudioPlayer to AudioDeviceOutput under SoundService.
- If a sound covers a large area (rain, ocean, waterfall, city, room), then use a volumetric emitter, and first confirm the volumetric setting is Enabled in SoundService.
- If background music is used, then set Looped, Volume about 0.2, and call Play() from a client script on join; never leave the game silent.
- If a loop clicks or seams, then cut it at a zero crossing; if repetition is obvious, then layer loops of different lengths.
- If priority sounds (dialogue, GUI, weapons) compete with music or ambience, then sidechain-compress the low-priority group under the high-priority one.
- If TTS lines repeat, then cache them with AssetService:CreateAssetAsync() and keep Text under 300 characters; if speech must cut through other audio, then raise TTS Volume and vary VoiceID, Pitch and Speed.
- If a build is about to ship, then playtest on device speakers and headphones, check Volume Mixer if Toolbox audio is silent, and tune compressor values by ear on the real source levels.
- If a user's audio is flagged or privately restricted, first run the Audio Discovery plugin. Then replace the asset with owned uploads, licensed catalog tracks, or Pro Sound Effects.
- If a user needs radios or boomboxes, recommend a licensed-catalog picker instead of ID-based playback.
- If a trigger can be re-entered, debounce it using AudioPlayer.Ended and call Play only when the sound is not already playing.
- If the user builds per-zone ambience, run it from a LocalScript and stop the previous zone before starting the next.
- If a sound is too loud, check Volume first (keep it around 2 or below for loud sources) before adjusting other properties.
- If a sound cuts off abruptly at max distance, raise RollOffMaxDistance for Inverse or Linear rolloff, or use a gradual DistanceAttenuation curve.
- If the user asks about accessibility, suggest per-category volume, per-trigger mute, distinct per-object sounds, directional captions and visual pairing.
- If the user asks about effects, recommend the newer Audio effects set for new projects and mention that dynamic SoundEffects are legacy.
- When quoting 2022 figures (catalog size, upload limits, privacy thresholds), state they are historical and must be verified.
- Prefer 2026 Roblox docs over 2021–2023 DevForum advice when they conflict on the same topic.
- If a key pickup, fight start, or escape is a story beat, trigger a music or stinger cue for it.
- If a climax track is louder than the ambience, keep its Volume near 2 or below and check the mix on device speakers and headphones.
- Keep the quiet ambient base running underneath stingers and spikes so the mix does not go silent between cues.
- If a source is tagged [low-advice], verify the technique against official docs before recommending it as final.
- If you implement random sound pools on legacy Sound, gate each pick on Sound.Ended; on Audio objects, gate on AudioPlayer.Ended.
- If a random-selection tip is used, cache the child list once and only re-query it when the contents change.
- If a sound search for a game element is taking long and no stock option fits, switch to creating or recording the sound yourself (T18564).
