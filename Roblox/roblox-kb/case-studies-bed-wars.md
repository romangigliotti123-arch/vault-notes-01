# Case study: Bed Wars

**Genre:** Competitive team PvP

Team PvP game where players defend their bed while eliminating rivals, with battle-pass ranks and seasons. Cited for competitive retention and a dedicated team-strategy community.

Also referred to as: Bedwars, BedWars, Bed Wars

## What creators say about it
- Battle pass ranks show skill and social status as a visible goal (Roblox Creators, 2021-12). ([Roblox Creators 2021-12 14:29](https://youtu.be/hD2Ive5RqtE?t=869))
- Balance season XP so the average player finishes in a set number of days (Roblox Creators, 2021-12). ([Roblox Creators 2021-12 15:18](https://youtu.be/XTZxQvh1qkc?t=918))
- Competitive matches where players rarely leave before the result keep the game sticky (Roblox DevForum, 2023-12). ([Roblox DevForum 2023-12](https://devforum.roblox.com/t/understand-the-roblox-algorithm/2772921))
- Base protection plus competitive dominance feeds confidence and a dedicated competitive community (SmartyRBX, 2025-07; RoWatcher, 2026-03). ([SmartyRBX 2025-07 2:43](https://youtu.be/zXzXOw5605E?t=163), [RoWatcher (tracker blog) 2026-03](https://rowatcher.com/news/top-10-roblox-games-by-players-march-2026-data-breakdown))
- Novelty can come from familiar layouts: floating islands and bridge-separated plots are familiar, mixed in for novelty (Tizzy, 2026-06). ([Tizzy 2026-06](https://youtu.be/4ms4cp2mrtM))
- Discord server tags reveal what other games your core audience plays (Tizzy, 2026-08). ([Tizzy 2026-08](https://youtu.be/TVdqb9O0RMw))

## Transferable patterns
- Season XP pacing with target completion days
- Status ranks as a visible goal
- Competitive match design that keeps players in-match
- Discord server tags as audience research
