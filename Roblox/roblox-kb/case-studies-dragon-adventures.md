# Case study: Dragon Adventures

**Genre:** Open-world dragon / flight

Open-world dragon game with hatching, raising and flight. Built by Twin Atlas; used in Roblox demos for global chat, commerce integration and season-pass mechanics.

## Numbers
- No CCU or revenue figures given in the input.

## What creators say about it
- Open world: place core interactables first, keep the social hub uncluttered, and use big assets to encourage exploration (Roblox Creators). ([Roblox Creators 2022-03 2:55](https://youtu.be/czVxazdl0kg?t=175))
- Launch without monetisation, then add it once the game is playable and enjoyable (Roblox Creators). ([Roblox Creators 2023-01 0:00](https://youtu.be/YdplC2WVkWc?t=0))
- Limited-stock items drew strong negative reaction; limited-time is safer (Roblox Creators, 2023). Newer guidance uses rotating stock with daily and weekly missions (Roblox Creator Docs, 2026-10), so the rotating approach supersedes limited stock. ([Roblox Creators 2023-01 19:12](https://youtu.be/vQNJztcS2AI?t=1152), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/game-design/monetization-foundations))
- Shop UI should be bright and premium with clear currency icons to invite exploration without click friction (Roblox, 2023). ([Roblox 2023-09 12:23](https://youtu.be/9eaev-ypgWo?t=743))
- Season pass with quest-based missions tied to hatching and raising dragons, an exclusive final-dragon reward and HUD surfacing (Roblox Creator Docs). ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/game-design/introduction-to-quest-design), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/game-design/season-pass-design))
- Enlarge and pad the highest-value coin bundle to prioritise it over smaller bundles (Roblox Creator Docs). ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/game-design/ui-ux-design))

## Transferable patterns
- Delay monetisation until the core loop is fun.
- Use rotating or time-limited stock rather than hard stock caps.
- Build season passes around quest missions tied to core actions.
- Highlight the top bundle visually to steer purchases.
