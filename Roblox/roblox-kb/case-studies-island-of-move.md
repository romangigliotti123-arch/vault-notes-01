# Case study: Island of Move

**Genre:** Animation course sample (official)

Roblox Creator Docs official animation course sample: a track-based movement game with a golem NPC handing out a redeemable code. Used as the base template for the beginner animation tutorial.

## Numbers
- No commercial figures; course example only (Roblox Creator Docs, 2026-10).

## What creators say about it
- The official sample includes a finished animation example; a golem NPC is where the redeem code is entered. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/challenge-checkpoint-2), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/challenge-checkpoint-3), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/challenge-checkpoint))
- Sources differ on the reward: StrikeAPose code (G2455) versus Speedy Shades plus Get Moving badge (G2511). Verify the in-game reward directly. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/challenge-checkpoint-2), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/challenge-checkpoint-3))
- Use the Roblox-provided track template, where players move to earn stars, as a starting point for animation lessons. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/curriculums/animator/get-started), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/curriculums/animator))
- Animation project idea: build a simulator where players move to gain points, such as swimming through the air or dancing along a track. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/education/landing-pages/build-it-play-it))

## Transferable patterns
- Start teaching projects from an official template
- Movement-to-points loop as a simple simulator
- Code-redeem rewards tied to course progress
- Finished examples to show animation in context
