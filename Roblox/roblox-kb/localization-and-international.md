# Localization And International

_localization, translation, regional pricing and markets, international growth._

Evidence base: 138 extracted items from 27 videos by ContextLost, Deconstructor of Fun, GameMakers, Last Level Studios, Roblox, Roblox Creator Docs, Roblox DevForum, TanookiAlex, TheDevKing (2018-03-07 to 2026-10-30). Roblox changes quickly: check the date on each source and see Date context below.

## Overview
Creators and Roblox docs teach that localization is a growth lever: most of the world is non-English, so go beyond English. Workflow: set the source language, add source text to the localization table (Automatic Text Capture, Studio capture, manual entries, or CSV), add translations (human translators, native speakers, or Roblox auto-translation), test with Player Emulator, then enable Use Translated Content. Human translators are preferred for quality, because machine translation lacks context and hurts reputation. Prioritize languages by where your players come from. Design UI for longer text and avoid text baked into images. Handle dynamic text with parameters, FormatByKey and real-time translation. Use Context, Key and Example to disambiguate. Watch for auto-translation overriding manual work. Test new countries with paid UA first. Older 2018-2021 tooling advice is partly superseded by the 2026 docs.

## Rules and findings
- **Localize beyond English** (multiple-creators): The US is under 5% of world population and English is spoken by under 20%. The fastest-growing game markets are non-English. Localizing also improves accessibility for international players. Sources: [Roblox 2018-07 17:00](https://youtu.be/EDY-8V943IE?t=1020), [Roblox 2018-07 17:00](https://youtu.be/EDY-8V943IE?t=1020), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/creator-programs/standout-games), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/first-experience). Newest source 2026-10-28.
- **Prioritize languages by player geography** (one-creator-repeated): Check which countries your players come from. Translate the most-played countries first, then add others. You control which languages you add and need not support all of them. This saves money. Sources: [Last Level Studios 2021-07 15:09](https://youtu.be/qJx27G0N9kE?t=909), [Last Level Studios 2021-07 10:24](https://youtu.be/qJx27G0N9kE?t=624), [Last Level Studios 2021-07 10:24](https://youtu.be/qJx27G0N9kE?t=624). Newest source 2021-07-02.
- **Prefer human translators over machine output** (multiple-creators): Auto-translation lacks context and can produce wrong or inappropriate strings. Bad translations hurt the developer's reputation, and players leave. Hire professionals or bilingual speakers if the game earns money. Roblox itself encourages developers to hire translators. Use machine translation only as a first pass. Sources: [ContextLost 2018-03 2:43](https://youtu.be/wKjTYdVi4KE?t=163), [TanookiAlex 2021-02 6:06](https://youtu.be/ZEQmRsvDIAg?t=366), [Last Level Studios 2021-07 5:32](https://youtu.be/qJx27G0N9kE?t=332), [Last Level Studios 2021-07 13:11](https://youtu.be/qJx27G0N9kE?t=791), [TanookiAlex 2021-02 8:48](https://youtu.be/ZEQmRsvDIAg?t=528). Newest source 2026-10-30.
- **Use auto-translation only as a stopgap, and mind quota** (multiple-creators): If you can't afford translators, enable it briefly while humans correct the strings. Smaller developers may benefit from free auto-translation for reach, while larger ones should prefer human localization. Quota is per character per language: 'hello' into 10 languages = 50 characters, so plan the initial quota. Sources: [Last Level Studios 2021-07 14:28](https://youtu.be/qJx27G0N9kE?t=868), [TanookiAlex 2021-02 7:27](https://youtu.be/ZEQmRsvDIAg?t=447), [Last Level Studios 2021-07 14:28](https://youtu.be/qJx27G0N9kE?t=868), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/first-experience), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/automatic-translations). Newest source 2026-10-30.
- **Audit auto-translated strings before and after shipping** (multiple-creators): Some strings were mistranslated, untranslated strings leaked into the UI, and players switched back to English. The string table can balloon (Circus Trip went from ~800 to over 10,000 strings, indie-reported), so delete unwanted strings. Sources: [TanookiAlex 2021-02 4:42](https://youtu.be/ZEQmRsvDIAg?t=282), [Last Level Studios 2021-07 11:06](https://youtu.be/qJx27G0N9kE?t=666), [Last Level Studios 2021-07 11:06](https://youtu.be/qJx27G0N9kE?t=666), [Roblox DevForum 2026-10](https://devforum.roblox.com/t/auto-translation-overrides-manual-translations/4958947). Newest source 2026-10-26.
- **Auto-translation never overrides manual translations (per official docs)** (multiple-creators): It only fills blank entries. Clearing an entry tells the tool you don't want it translated. Manual translations show even if the player has auto-translation on. Lock approved entries, and moderation still applies. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/automatic-translations), [TanookiAlex 2021-02 6:06](https://youtu.be/ZEQmRsvDIAg?t=366), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/manual-translations), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/automatic-translations), [TanookiAlex 2021-02 6:06](https://youtu.be/ZEQmRsvDIAg?t=366). Newest source 2026-10-30.
- **Check per-language Automatic Translation if manual text is overridden in-game** (single-mention): A 2026 DevForum report says auto translation overrode manual text in-game while the table was correct. Disabling it for that language (e.g. Russian) restored the manual text. This conflicts with the official claim, so verify in-game. Sources: [Roblox DevForum 2026-10](https://devforum.roblox.com/t/auto-translation-overrides-manual-translations/4958947), [Roblox DevForum 2026-10](https://devforum.roblox.com/t/auto-translation-overrides-manual-translations/4958947), [Roblox DevForum 2026-10](https://devforum.roblox.com/t/auto-translation-overrides-manual-translations/4958947), [Roblox DevForum 2026-10](https://devforum.roblox.com/t/auto-translation-overrides-manual-translations/4958947). Newest source 2026-10-26.
- **Set source language and supported languages first** (multiple-creators): Set the game source language and target languages before adding translations or inviting translators. Add source text before collaborators add translations. Auto-translation supports only source strings in the source language. Sources: [TheDevKing 2020-04 2:07](https://youtu.be/QWdyxoni7aw?t=127), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/work-with-translators), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/add-source-content), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/automatic-translations), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/localize-with-scripting). Newest source 2026-10-30.
- **Collect strings with Automatic Text Capture** (multiple-creators): ATC is the fastest way to collect GUI text as users play. Studio text capture during playtests gets strings in within 1-2 minutes, while ATC can take days. Toggle capture off when done and keep translated content off until strings are filled. Sources: [ContextLost 2018-03 0:41](https://youtu.be/wKjTYdVi4KE?t=41), [TheDevKing 2020-04 2:16](https://youtu.be/QWdyxoni7aw?t=136), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/add-source-content), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/automatic-translations), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/automatic-translations). Newest source 2026-10-30.
- **Manually add text ATC misses** (one-creator-repeated): Add rarely seen text such as complex conversation trees. ATC can't capture default leaderboards/chat, player-owned items, images with embedded text, or badge/pass names. Handle those with localization scripts. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/add-source-content), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/automatic-translations). Newest source 2026-10-30.
- **Exclude text that shouldn't be translated** (multiple-creators): Uncheck Auto Localize or set AutoLocalize=false on usernames and player-entered content. Remove such strings from the table. For TextBox only PlaceholderText is captured. Sources: [TheDevKing 2020-04 7:04](https://youtu.be/QWdyxoni7aw?t=424), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/automatic-translations), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/automatic-translations), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/manual-translations). Newest source 2026-10-30.
- **Enable Use Translated Content after filling the table** (one-creator-repeated): Green rows are translated and gray rows are untranslated and fall back to source. Enable the setting so translations reach players by region or language. Sources: [TheDevKing 2020-04 6:21](https://youtu.be/QWdyxoni7aw?t=381), [TheDevKing 2020-04 4:31](https://youtu.be/QWdyxoni7aw?t=271), [TheDevKing 2020-04 2:16](https://youtu.be/QWdyxoni7aw?t=136). Newest source 2020-04-29.
- **Use Context to disambiguate identical strings** (multiple-creators): Enter the full object path in Context when one string has several meanings (e.g. 'back' button vs body). The closest right-to-left context match wins. Source+Context pairs must be unique. Use Example to tell translators where the string appears. Sources: [ContextLost 2018-03 1:21](https://youtu.be/wKjTYdVi4KE?t=81), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/add-source-content), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/manual-translations), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/localize-with-scripting), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/manual-translations). Newest source 2026-10-30.
- **Respect table constraints** (one-creator-repeated): Source is required and never empty. Entries are case-sensitive, so add each casing separately. Keys must be unique. Leave Key empty unless you use FormatByKey. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/manual-translations), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/add-source-content), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/manual-translations), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/manual-translations), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/add-source-content). Newest source 2026-10-30.
- **Use CSV for bulk edits and fields the portal can't change** (one-creator-repeated): Download the Cloud Localization Table CSV, edit, then upload. Key/Context/Example are editable only via CSV or by re-adding the entry. Limits: 10,000 entries, 2 MB, 1,000 changed per upload. CSV edits lock entries as manual. Deleting a source via CSV does not delete the entry. Asset IDs can also go in via CSV. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/add-source-content), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/add-source-content), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/add-source-content), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/add-translations), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/add-translations). Newest source 2026-10-30.
- **Design UI for longer text** (one-creator-repeated): Plan for maximum text space, not English length. Spanish averages ~30% longer and German is longer still. Use Player Emulator Pseudolocalize and Elongate to find untranslated strings and UI breaks. Replace unneeded text with icons. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/curriculums/user-interface-design/choose-an-art-style), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/studio/testing-modes), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/studio/testing-modes), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/curriculums/user-interface-design/choose-an-art-style). Newest source 2026-10-28.
- **Keep translatable text out of baked images** (multiple-creators): Use TextLabels over images, and TextLabels instead of text images in BillboardGui bubbles. Image text can't be translated automatically. If images are unavoidable, localize them via asset IDs. Sources: [ContextLost 2018-03 4:06](https://youtu.be/wKjTYdVi4KE?t=246), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/resources/the-mystery-of-duvall-drive/immersive-narrative), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/localize-with-scripting), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/automatic-translations). Newest source 2026-10-30.
- **Handle rich text and animations in scripts** (multiple-creators): Automatic replacement handles text effects poorly. Localizing removes rich text tags, so re-apply formatting to each localized string. Sources: [ContextLost 2018-03 4:06](https://youtu.be/wKjTYdVi4KE?t=246), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/ui/rich-text). Newest source 2026-10-28.
- **Use parameters for dynamic strings** (one-creator-repeated): Use placeholders like {Player_Name}, keeping names identical across locales. Use :translate to translate the value (it must match a Source row). Use num/fixed so separators follow locale. Don't mix string and number parameters in one entry. Pass parameter tables to FormatByKey. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/manual-translations), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/localize-with-scripting), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/translate-dynamic-content), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/translate-dynamic-content), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/translate-dynamic-content). Newest source 2026-10-30.
- **Use LocalizationService scripting robustly** (one-creator-repeated): Wrap GetTranslatorForLocaleAsync/GetTranslatorForPlayerAsync in pcall. Centralise fallbacks in a TranslationHelper ModuleScript. Re-translate scripted images/sounds on LocaleId change, since auto-translation updates but scripted assets don't. Don't match system messages by localized string; use Metadata. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/localize-with-scripting), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/localize-with-scripting), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/localize-with-scripting), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/localize-with-scripting), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/localize-with-scripting). Newest source 2026-10-30.
- **Use real-time translation for dynamic or player text** (one-creator-repeated): The standard workflow only catches frequently viewed strings. Pass player.LocaleId as the target language. Real-time translation supports 17 locale codes. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/auto-translate-dynamic-content), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/auto-translate-dynamic-content), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/auto-translate-dynamic-content). Newest source 2026-10-30.
- **Test translations as the locale's player** (multiple-creators): Set the play-mode language in the plugin or Player Emulator and play. Verify displayed in-game text, not just table entries. Sources: [ContextLost 2018-03 3:25](https://youtu.be/wKjTYdVi4KE?t=205), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/studio/testing-modes), [Roblox DevForum 2026-10](https://devforum.roblox.com/t/auto-translation-overrides-manual-translations/4958947). Newest source 2026-10-28.
- **Localize store presence** (one-creator-repeated): Keep the game name unchanged across languages. Translate descriptions, thumbnail text, and gamepass/devproduct thumbnails. Up to 10 localized thumbnails per language. Saving an empty Name/Description marks it manual, so players see the source text. Sources: [TheDevKing 2020-04 5:00](https://youtu.be/QWdyxoni7aw?t=300), [TheDevKing 2020-04 6:21](https://youtu.be/QWdyxoni7aw?t=381), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/add-translations), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/add-translations), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/add-translations). Newest source 2026-10-30.
- **Use Global vs locale-specific translations wisely** (single-mention): Put universal translations in Global. Add locale-specific ones (en-gb, fr-ca, etc.) only where regional terms differ, since they override Global. 8 locale-specific variants are supported. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/add-translations), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/add-translations). Newest source 2026-10-30.
- **Manage translators via Roblox tools** (multiple-creators): Invite translators as users or groups for permissions and analytics, share the Translator Portal link, and download reports. For outside translators, export CSV (analytics won't track them). Translator credit reports are available. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/work-with-translators), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/work-with-translators), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/work-with-translators), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/localization/work-with-translators), [TheDevKing 2020-04 8:26](https://youtu.be/QWdyxoni7aw?t=506). Newest source 2026-10-30.
- **Vet translators yourself; Notable Translators is deprecated** (single-mention): Roblox doesn't guarantee quality, payment or completion and doesn't endorse any translator. Protect yourself contractually. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/creator-programs/notable-translators), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/creator-programs/notable-translators), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/creator-programs/notable-translators), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/creator-programs/notable-translators), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/creator-programs/notable-translators). - **Localize for feel, and handle hard terms** (multiple-creators): Aim for native feel, not literal translation. Genre terms (e.g. tycoon) may lack equivalents, so use workarounds. Sources: [ContextLost 2018-03 4:47](https://youtu.be/wKjTYdVi4KE?t=287), [ContextLost 2018-03 4:47](https://youtu.be/wKjTYdVi4KE?t=287), [Last Level Studios 2021-07 4:54](https://youtu.be/qJx27G0N9kE?t=294). - **Check compliance and test new markets with paid UA** (single-mention): Developers choose which countries to publish in, and Roblox enforces local compliance only there. Use the content checklist. Test a new country with paid UA first (CPI, retention, ROI); go always-on creator campaigns only if it performs well. Sources: [Roblox DevForum 2020-02](https://devforum.roblox.com/t/about-our-upcoming-global-compliance-system/461447), [Roblox DevForum 2020-02](https://devforum.roblox.com/t/about-our-upcoming-global-compliance-system/461447), [Roblox DevForum 2020-02](https://devforum.roblox.com/t/about-our-upcoming-global-compliance-system/461447), [Roblox DevForum 2020-02](https://devforum.roblox.com/t/about-our-upcoming-global-compliance-system/461447), [Deconstructor of Fun 2026-06 30:49](https://youtu.be/2BsMLCk8FEU?t=1849). Newest source 2026-06-01.
- **Write Quick Words in English only** (single-mention): Roblox auto-translates them into each user's chat language. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/chat/quick-words). Newest source 2026-10-28.
- **Build a localization portfolio and join a team** (single-mention): For translators: the speaker got big jobs through a team vouching for them (indie, self-reported). Sources: [Last Level Studios 2021-07 16:26](https://youtu.be/qJx27G0N9kE?t=986). Newest source 2021-07-02.
- **Offer regional day-one spend paths when top items are grind-gated** (single-mention): If top-tier items are gated behind long grinds, high-value players in East Asian markets may churn. Consider a paid or faster route to those items from day one in those regions. Source is one indie developer's self-reported experience, so verify with your own churn data. Sources: [GameMakers 2024-08 40:18](https://youtu.be/gp_hDijjC4U?t=2418). Newest source 2024-08-12.
- **Measure conversion and ARPU per region, not globally** (single-mention): The same game can convert very differently by market. One indie reported under 2% paying conversion in the US versus over 10% in China, in a pay-to-win-leaning game. Segment conversion and ARPU by region before setting pricing or monetization for a market. Do not assume the US pattern applies elsewhere. Sources: [GameMakers 2024-08 42:19](https://youtu.be/gp_hDijjC4U?t=2539). Newest source 2024-08-12.

## Checklist
- [ ] Set source language and target languages
- [ ] Add source text before inviting translators
- [ ] Enable ATC and run Studio playtests to capture strings
- [ ] Manually add rare text; set AutoLocalize=false on usernames
- [ ] Use Context/Example/Key via CSV where needed
- [ ] Use TextLabels, not text in images; use icons where possible
- [ ] Reserve space for longer text (Spanish +30%, German more)
- [ ] Rewrite dynamic strings with parameters (num/fixed/translate)
- [ ] Wrap async translator calls in pcall with fallbacks
- [ ] Reapply rich text formatting per locale
- [ ] Hire or vet native translators; use contracts
- [ ] Use auto-translation only as a stopgap and audit it
- [ ] Test with Player Emulator Pseudolocalize/Elongate and per-locale play
- [ ] Enable Use Translated Content
- [ ] Localize description and up to 10 thumbnails; keep the name
- [ ] Verify in-game text per language for auto-translation overrides
- [ ] Check player geography to prioritize languages
- [ ] Download translation reports
- [ ] Test new markets with paid UA before scaling
- [ ] Segment paying conversion and ARPU by region (for example US vs China) before changing monetization for a market.
- [ ] Check whether top-tier items are grind-gated. If they are and you target East Asian markets, evaluate a day-one spend path for those regions.
- [ ] Monitor churn of high-value players separately by region after adding regional spend paths, and compare against the unchanged baseline.

## Where creators agree
- ContextLost, TanookiAlex and Last Level Studios agree machine translation lacks context and human or bilingual translators are better.
- TheDevKing, ContextLost and Roblox Creator Docs agree on using text capture to populate the table.
- ContextLost and Roblox Creator Docs agree on using Context to disambiguate and TextLabels instead of baked image text.
- Roblox (TanookiAlex quote) and Roblox Creator Docs agree auto-translation is additive and doesn't override human translations.

## Where creators disagree
- **Whether auto-translation is acceptable**
  - TanookiAlex: fine for small developers wanting free reach, big games should hire humans.
  - Last Level Studios: only briefly as a stopgap, never long-term.
  - Roblox Creator Docs: recommends enabling it to reach a global audience.
- **Does auto-translation override manual translations?**
  - Roblox Creator Docs and TanookiAlex quote: never overrides.
  - Roblox DevForum 2026-10 report (indie, low-advice): it overrode manual translations in-game; fixed by disabling it per language.

## Instructions for an agent using this file
- If starting localization, set the source language first, then add source text, then invite translators.
- If the game earns money or is large, then recommend human or native translators and treat auto-translation as temporary.
- If strings aren't in the table, then use Studio playtest capture (1-2 min) rather than waiting for ATC.
- If text shows in the wrong language despite a correct table, then check per-language Automatic Translation and verify in-game.
- If a string has several meanings, then set Context via CSV, not Location.
- If text is dynamic or player-generated, then use real-time translation with player.LocaleId or parameter formats.
- If UI text is in images, then move it to TextLabels or localize the image via asset IDs.
- If choosing languages, then rank by player country data first.
- If the user asks about Notable Translators, then say it is deprecated and advise independent vetting.
- If expanding to a new country, then run a paid UA test before always-on campaigns.
- If a game has grind-gated top items and targets East Asian markets, then propose a regional day-one spend path and track high-value player churn in those regions.
- If conversion or ARPU data is available by region, then analyze each region separately before changing global monetization.
- If the game is not pay-to-win-leaning, then treat the US vs China conversion gap as a hypothesis to test, not a benchmark.
