# Case study: Laser Tag

**Genre:** Team shooter / sample game

Roblox's official Server Authority example and sample template. Shows state-driven ScreenGuis and combat sound cues for positional awareness.

Also referred to as: Laser Tag (sample game, Roblox UI curriculum), Laser Tag (template)

## What creators say about it
- Laser Tag is an official Server Authority example place for learning the pattern. ([Roblox DevForum 2025-12](https://devforum.roblox.com/t/studio-beta-build-fair-responsive-games-with-server-authority/4139157))
- Five disabled ScreenGuis (HUD, PickABlaster, ForceField, OutState, RoundResults) appear contextually based on round state. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/curriculums/user-interface-design/implement-designs-in-studio))
- Blaster pop and reload beep sounds give positional awareness of nearby combat. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/use-case-tutorials/audio/add-3D-audio))

## Transferable patterns
- Use server authority for combat validation
- Toggle UI contextually by round state instead of showing everything
- Use distinct sound cues for nearby combat awareness
