# Roblox Platform Changes

_platform policy/feature changes (e.g. algorithm updates, new payout rules) and their effects._

Evidence base: 91 extracted items from 48 videos by CaberJaber, Crusherfire, Cumin, Deconstructor of Fun, Emancyphur, Erthlord, GameMakers, Izzzyzzz, Last Level Studios, LovJak, MonzterDEV, Raul, Roblox, Roblox Creator Docs, Roblox Creators, Roblox DevForum, Stewiepfing, TheNexusAvenger, Tizzy, janisjanis01 (2018-07-24 to 2026-10-30). Roblox changes quickly: check the date on each source and see Date context below.

## Overview
Creators and Roblox staff describe a platform that changes constantly: discovery/algorithm shifts, age-gating of new games, payout programs (Engagement-Based Payouts replaced by Creator Rewards, DevEx +8.5%), affiliate program, anti-cheat/modified-client enforcement, moderation/ratings, and many API deprecations (RenderStepped/Stepped, HapticService, Avatar API V1-V3, AvatarUnificationMode, TextChatService migration). Official sources give dates and mechanics; indie creators report effects (e.g. games dying after algorithm changes, audience loss from 16+ gating), which are unverified. Core advice: expect staged rollouts, watch announcement threads, migrate before deadlines, test new systems early, and diagnose impression drops against seasonality, competitors and algorithm changes before blaming your game.

## Rules and findings
- **Expect staged rollouts and plan for rule changes** (multiple-creators): Roblox releases features to a small group first and expands over time. Publishing, moderation and discovery changes have caused friction and Roblox says it iterates quickly. Don't assume a feature seen in beta or a thread is live; check announcement threads. Sources: [Roblox 2023-09 12:04](https://youtu.be/8R136Y_T5G4?t=724), [Roblox 2026-09 2:06](https://youtu.be/53dj7AG3foA?t=126), [Emancyphur 2020-08 0:23](https://youtu.be/ScdTM3ju-yk?t=23), [Roblox DevForum 2026-04](https://devforum.roblox.com/t/full-release-the-future-of-character-movement-character-controller-library/4565267). Newest source 2026-09-17.
- **Plan for the 16+ gate on new games (since May 19, 2026)** (multiple-creators): New games are shown only to 16+ users until they reach 500 highly engaged players. Plan launch audience, marketing and external traffic around this gate. Age-rule changes can sharply cut reachable audience (indie-reported). Sources: [Tizzy 2026-06 2:39](https://youtu.be/Rkgbcv6omPg?t=159), [Raul 2026-06 2:14](https://youtu.be/vnpCimQkHoQ?t=134), [Tizzy 2026-05 17:05](https://youtu.be/owMnhg3fn_M?t=1025). Newest source 2026-06-30.
- **Know the 'highly engaged player' definition** (multiple-creators): Anyone who made a minimum platform purchase anywhere on Roblox in the last 60 days. They need not spend in your game. Sources: [Tizzy 2026-06 5:46](https://youtu.be/Rkgbcv6omPg?t=346), [Tizzy 2026-06 6:29](https://youtu.be/Rkgbcv6omPg?t=389), [Tizzy 2026-06 6:29](https://youtu.be/Rkgbcv6omPg?t=389). Newest source 2026-06-01.
- **A paid pre-launch fast-track is being explored** (single-mention): Roblox is exploring a paid pre-launch review (higher upfront fee, recoupable if standards met) to reach kids before the 500-player threshold. Not confirmed; indie-reported. Sources: [Tizzy 2026-06 4:01](https://youtu.be/Rkgbcv6omPg?t=241). Newest source 2026-06-01.
- **Release to all ages has strict requirements** (one-creator-repeated): Requires 2FA, age verification, and either 2 consecutive months of Premium or a one-time fee, plus Kids/Select review. Requirements apply to every update, new version, Publish As and audience change, not just first release. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/publishing/publish-games-and-places), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/publishing/publish-games-and-places). Newest source 2026-10-28.
- **Mind release limits and review timing** (one-creator-repeated): Up to 5 never-before-released free games per day (resets daily). Expedited review lasts 48 hours; minor violations restart the clock on resubmission. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/publishing/publish-games-and-places), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/publishing/publish-games-and-places). Newest source 2026-10-28.
- **Diagnose impression changes before blaming your game** (multiple-creators): Impression shifts can come from seasonality (weekly peak Saturday, summer, holidays), competitor improvements, or algorithm changes. One indie creator (LovJak, unverified) says algorithm changes killed his game after a 200 CCU peak even with all-ages availability. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/discovery-faq), [LovJak 2026-07 0:00](https://youtu.be/Y602HH_KdOc?t=0), [LovJak 2026-07 0:00](https://youtu.be/Y602HH_KdOc?t=0). Newest source 2026-10-28.
- **Don't build strategy around Engagement-Based Payouts** (multiple-creators): Deprecated July 24, 2025, replaced by Creator Rewards. DevEx rate rose 8.5% and payouts shift toward monetizing new players over engagement, favoring monetization-driven games (Deconstructor of Fun, indie analysis). Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/monetization/engagement-based-payouts), [Deconstructor of Fun 2025-09 11:11](https://youtu.be/8pruyZlxMI4?t=671), [Deconstructor of Fun 2025-09 9:49](https://youtu.be/8pruyZlxMI4?t=589), [Deconstructor of Fun 2025-09 11:11](https://youtu.be/8pruyZlxMI4?t=671). Newest source 2026-10-28.
- **Use the affiliate program correctly** (one-creator-repeated): Pays 50% of new users' Robux purchases within 6 months of account creation, capped at $100 per user; users must be brand new with no alternate accounts. Pilot through end of 2024, wider expansion by mid-2025 per announcement cited. Source is low-advice; MonzterDEV notes most players already play Roblox, so new-user attraction is limited. Sources: [MonzterDEV 2024-09 0:00](https://youtu.be/wbDsGk-Te14?t=0), [MonzterDEV 2024-09 0:00](https://youtu.be/wbDsGk-Te14?t=0), [MonzterDEV 2024-09 0:00](https://youtu.be/wbDsGk-Te14?t=0), [MonzterDEV 2024-09 4:24](https://youtu.be/wbDsGk-Te14?t=264), [MonzterDEV 2024-09 0:36](https://youtu.be/wbDsGk-Te14?t=36). Newest source 2024-09-23.
- **Avoid paid access games** (single-mention): Red Manta's paid access made no money and kept players out; going free attracted content creators who won't cover paid-access games (official 2021 case study). Sources: [Roblox Creators 2021-07 1:21:29](https://youtu.be/Gv5OVVyWM10?t=4889). Newest source 2021-07-16.
- **Expect content restrictions and use content ratings** (one-creator-repeated): Roblox enforces content rules globally; mature themes (gore, drugs, undead) may be removed, some regions ban loot boxes. Developers can rate their own games' age appropriateness. Sources: [Roblox Creators 2022-12 8:39](https://youtu.be/0PEBFsguCdw?t=519), [Roblox Creators 2022-12 8:39](https://youtu.be/0PEBFsguCdw?t=519). Newest source 2022-12-01.
- **Moderation policy is easing for good-faith creators** (one-creator-repeated): Roblox expects ~40% fewer content violation strikes for good-faith creators (policy change Sept 2026) and reports harmful content reaching young players down 99.5% since kids/select account rollout (Roblox-reported). Sources: [Roblox 2026-09 14:06](https://youtu.be/53dj7AG3foA?t=846), [Roblox 2026-09 11:20](https://youtu.be/53dj7AG3foA?t=680), [Roblox 2023-09 28:51](https://youtu.be/8R136Y_T5G4?t=1731). Newest source 2026-09-17.
- **Do not use modified clients/binaries** (one-creator-repeated): Since May 8, 2025 Roblox may take automated action up to account termination for modified binaries or runtime-modified clients. Tools using only official OAuth/analytics APIs are unaffected. Creators testing in their own place (edit permission) are exempt from May 30, 2025. Sources: [Roblox DevForum 2025-05](https://devforum.roblox.com/t/an-update-on-automated-action-against-modified-clients/3640609), [Roblox DevForum 2025-05](https://devforum.roblox.com/t/an-update-on-automated-action-against-modified-clients/3640609), [Roblox DevForum 2025-05](https://devforum.roblox.com/t/an-update-on-automated-action-against-modified-clients/3640609). Newest source 2025-05-06.
- **Invest in server-authoritative anti-cheat** (single-mention): Roblox is rolling out easier server-authoritative tooling; anti-cheat consumes most dev time per Jandelle. Sources: [Roblox 2025-09 49:39](https://youtu.be/6iB5__RCQDc?t=2979). Newest source 2025-09-05.
- **Migrate off deprecated Run service events** (single-mention): RenderStepped and Stepped are deprecated; use PreRender and PreSimulation. Sources: [Crusherfire 2025-03 27:36](https://youtu.be/0jAZOpNHqv8?t=1656). Newest source 2025-03-22.
- **Replace HapticService with HapticEffect** (single-mention): HapticService is deprecated; use HapticEffect for new rumble code and check docs. Sources: [Stewiepfing 2025-04 5:13](https://youtu.be/e48wgHQll2Y?t=313), [Stewiepfing 2025-04 5:13](https://youtu.be/e48wgHQll2Y?t=313). Newest source 2025-04-27.

Sources: [Roblox DevForum 2026-10](https://devforum.roblox.com/t/weekly-recap-october-26-30-2026/4966810), [Roblox DevForum 2026-10](https://devforum.roblox.com/t/weekly-recap-october-26-30-2026/4966810). Sources: [Roblox DevForum 2026-10](https://devforum.roblox.com/t/weekly-recap-october-19%E2%80%9323-2026/4953263), [Roblox DevForum 2026-10](https://devforum.roblox.com/t/weekly-recap-october-19%E2%80%9323-2026/4953263). Sources: [Roblox DevForum 2026-06](https://devforum.roblox.com/t/improved-animationconstraint-stable-mass-independent-tracking-for-physically-simulated-joints/4700211), [Roblox DevForum 2026-06](https://devforum.roblox.com/t/improved-animationconstraint-stable-mass-independent-tracking-for-physically-simulated-joints/4700211), [Roblox DevForum 2026-06](https://devforum.roblox.com/t/improved-animationconstraint-stable-mass-independent-tracking-for-physically-simulated-joints/4700211). July 2025 license manager gives licensed IP access in days/hours (low-advice). - **Cross-game pass sales ended May 30, 2026** (single-mention): Cross-game pass sales disabled on that date. Sources: [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/monetization/passes). Newest source 2026-10-28.
- **Ads delivery is smoother after pacing/bidding changes** (multiple-creators): Roblox improved pacing and bidding over ~1.5 months to remove CCU and spend spikes (June 2025). Ad data is slow to update (Tizzy). Sources: [Roblox Creators 2025-06 56:35](https://youtu.be/D_YmdVZxIZw?t=3395), [Tizzy 2026-05 17:05](https://youtu.be/owMnhg3fn_M?t=1025). Newest source 2026-05-23.
- **Off-site links on Details page unsupported; mark bug reports Fixed only after publishing** (single-mention): Instagram and other off-site links aren't supported on the Details page (2023 statement; revisit was on the roadmap, check current). Separately, mark DevForum bug reports Fixed only after the fix is published; the banner returns if the issue is detected again. Sources: [Roblox 2023-09 20:53](https://youtu.be/yUDvI8mGnn8?t=1253), [Roblox DevForum 2026-09](https://devforum.roblox.com/t/players-can-now-find-in-game-items-outside-your-game/4888425). - **Design chat and social features around same-age groups** (one-creator-repeated): After age estimation, kids can only chat with peers. Kid-to-adult chat is blocked until 'trusted connections' ships. Don't build features that assume kids can message or party with adults, and don't rely on cross-age chat for core loops. Sources: [Roblox 2026-01 21:32](https://youtu.be/m5vqnNSCFCI?t=1292), [Roblox 2026-01 21:32](https://youtu.be/m5vqnNSCFCI?t=1292). Newest source 2026-01-07.
- **Check DevForum for platform-wide release problems first** (single-mention): If performance drops after a release, search DevForum for reported Roblox issues before rewriting code. One indie creator attributed poor performance partly to a reported platform problem with new releases. Self-reported, single source. Sources: [janisjanis01 2025-11 16:47](https://youtu.be/iEvgIId-8Uw?t=1007). Newest source 2025-11-23.
- **Expect algorithm shifts to favor bigger projects** (single-mention): One indie creator (Dec 2025) reported a Roblox algorithm shift and concluded to focus on bigger, better projects. No metric or magnitude was given. Confirm with your own impression and retention data before pivoting strategy. Sources: [janisjanis01 2025-12 17:10](https://youtu.be/JYvGdKRzwEo?t=1030). Newest source 2025-12-13.
- **Track 16+ trial progress against the 500-user threshold** (single-mention): Per one speaker (June 2026), a new game must reach 500 unique highly engaged 16+ users over 60 days to exit the 16+ lock. Unverified against official docs. Track the count against this figure if you are under the lock. Sources: [Cumin 2026-06 4:24](https://youtu.be/FpC7qnwDMDQ?t=264). Newest source 2026-06-18.
- **Plan a Roblox Plus runway before requesting a non-16+ rating** (single-mention): One speaker (June 2026) says a non-16+ rating requires at least 2 months of Roblox Plus, plus ID verification for the new game rating. Treat as unverified and schedule the runway early if you plan a lower rating. Sources: [Cumin 2026-06 3:01](https://youtu.be/FpC7qnwDMDQ?t=181). Newest source 2026-06-18.
- **Pick the target age band before choosing content maturity** (single-mention): Per one speaker (June 2026): Roblox Kids covers ages 5 to 8 with mild-rated games only, and Roblox Select covers ages 9 to 15 with content up to moderate. Verify band names and limits against official docs before relying on them. Sources: [Cumin 2026-06 1:05](https://youtu.be/FpC7qnwDMDQ?t=65). Newest source 2026-06-18.

## Checklist
- [ ] Check DevForum announcement threads for each feature you depend on
- [ ] Plan launch for the 16+ gate until 500 highly engaged players
- [ ] Audit use of RenderStepped/Stepped and migrate to PreRender/PreSimulation
- [ ] Replace HapticService with HapticEffect
- [ ] Migrate Avatar API V1-V3 calls to V4 before Dec 11, 2026
- [ ] Update AvatarUnificationMode usage before Dec 1, 2026
- [ ] Test TextChatService before May 2027
- [ ] Verify 2FA, age verification and Premium/fee for all-ages release
- [ ] Set content ratings and review content for restricted themes
- [ ] Avoid modified clients or unofficial tools
- [ ] Before diagnosing a drop, check seasonality, competitors and algorithm changes
- [ ] Enable required Studio Beta Features (Video Uploads, CCL)
- [ ] Do not rely on Engagement-Based Payouts; model Creator Rewards
- [ ] Review library dependencies for dynamic updates
- [ ] Test visuals/lighting at low graphics settings
- [ ] Verify whether Phase 2/3 dates (Jul 21, Sep 15, 2026) have happened
- [ ] Use ListUserRestrictions for place-level bans
- [ ] Check whether a social feature requires kid-to-adult communication; if so, redesign it for same-age peers.
- [ ] Confirm the current status of 'trusted connections' on the Roblox developer announcements page before shipping any cross-age social feature.
- [ ] After an unexplained post-release performance drop, check DevForum bug reports for a platform-side issue before changing code (T18604).
- [ ] If your game is under the 16+ lock, log the count of unique highly engaged 16+ users over rolling 60-day windows against 500 (N8013, unverified).
- [ ] Before requesting a non-16+ rating, confirm Roblox Plus status and ID verification, and allow about 2 months (N8016, unverified).
- [ ] Map your target audience to age bands (Kids 5 to 8 mild; Select 9 to 15 up to moderate) and check the official definitions (N8015, unverified).
- [ ] Compare impression and retention data before shifting strategy toward larger projects in response to reported algorithm changes (Q1908).
