# Case study: BotClash Simulator

**Genre:** Battle/simulator UI (Roblox Creator Docs example)

Roblox Creator Docs example for UI and monetization surfaces: a shop badge, a separate season pass, and clearly interactive buttons.

Also referred to as: Bot Clash Simulator

## What creators say about it
- Show a shop badge in the UI to signal purchase opportunities. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/game-design/contextual-purchases))
- Present the season pass separately from the shop, with stated time remaining and descriptive rewards. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/game-design/monetization-foundations))
- Use button containers and shadows so buttons read as interactive. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/game-design/ui-ux-design))

## Transferable patterns
- Give purchase surfaces (shop, pass) their own visible entry points
- Show time remaining on limited-time passes
- Use containers and shadows to mark interactive elements
