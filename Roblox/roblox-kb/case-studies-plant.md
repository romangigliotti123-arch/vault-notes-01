# Case study: Plant

**Genre:** Farming tycoon / microgame (official reference)

Roblox Creator Docs reference microgame (plant, water, harvest, sell) plus tycoon onboarding examples. Official teaching material, not a commercial case study.

Also referred to as: Plant (reference project), Plant (sample)

## Numbers
- No commercial figures. Onboarding funnel drop-off is qualitative: largest at step 2, Plant Seed (Roblox Creator Docs; G2508).

## What creators say about it
- Track plants harvested per player per day, broken down by plant type, to see which content players prefer. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/analytics/custom-events))
- Map the onboarding funnel (In Farm, Plant Seed, Water Plant). The largest drop-off was at Plant Seed, so fix that step first. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/analytics/funnel-events))
- Show timed hints (highlighted button, arrow at a marketplace stall) only after most players have completed the task. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/game-design/onboarding-techniques))
- Store seed purchase price and maximum plant size per pot as attributes so they are tunable custom properties. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/scripting/attributes))
- Give plant, water, harvest and place actions distinct sounds so each interaction feels reinforced. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/use-case-tutorials/audio/add-3D-audio))
- Use the plant, water, harvest and sell microgame to demonstrate project architecture patterns. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/resources/plant-reference-project))

## Transferable patterns
- Funnel-step analytics to locate drop-offs
- Gate hints on task-completion rates
- Attributes as designer-tunable values
- Per-action audio feedback
