# Case study: Please Donate

**Genre:** Donation-based social game

Donation game where players give Robux to others, solving the problem of players without Robux. Donation booths and offline FOMO drive spending. Frequently copied by fake clones.

## Numbers
- janisjanis01 (2024-06, speaker-reported, unverified): reached about 100 CCU without ads.
- AlvinBlox (2025-04, creator-reported, unverified): grew from about 100 players to tens of thousands over months.

## What creators say about it
- Solve a real player problem (no Robux) with a simple mechanic, which reached about 100 CCU without ads (janisjanis01, 2024-06; speaker-reported). ([janisjanis01 2024-06 4:14](https://youtu.be/NWyK_PbFdxE?t=254))
- An instantly understandable concept has mass appeal, and donations create FOMO even while offline (AlvinBlox, 2025-06). ([AlvinBlox 2025-06 1:15](https://youtu.be/Y93DRfB-Deo?t=75), [AlvinBlox 2025-06 1:15](https://youtu.be/Y93DRfB-Deo?t=75))
- Organic snowball from a fun core loop: growth from about 100 to tens of thousands of players over months (AlvinBlox, 2025-04; self-reported). ([AlvinBlox 2025-04 4:25](https://youtu.be/Le4QhC3dDGk?t=265), [AlvinBlox 2025-04 4:25](https://youtu.be/Le4QhC3dDGk?t=265))
- Earnings depend on voice-chat relationships and are not guaranteed (PolarBear, 2024-07). Newer 2025 note says it is now saturated, though still a top earner, so the older advice is outdated. ([PolarBear 2024-07 0:44](https://youtu.be/yYp23GK9RI4?t=44), [PolarBear 2025-01 0:41](https://youtu.be/H-RzwPKCqf0?t=41))
- Fake clones copy the map and claim a booth to add donations, showing how easily the concept is copied (TheDankDeveloper, 2023-11). ([TheDankDeveloper 2023-11 2:57](https://youtu.be/fqMj_b2m-Ik?t=177))
- A stand that sells other creators' game passes can be built by querying public games and passes via API (SimTek, 2024-02). ([SimTek Game Development 2024-02 2:45](https://youtu.be/V65oLE0Wbuc?t=165))

## Transferable patterns
- Remove player-side friction with a simple mechanic
- Instantly understood concepts for mass appeal
- Organic snowball from a fun core loop
- Cross-promotion stands via public API
