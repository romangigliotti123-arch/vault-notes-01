# Case study: Plane Crazy

**Genre:** Plane / flight game (genre inferred from title)

Plane game cited by Roblox Creator Docs as an example of private servers for classroom use and featured in the Roblox education intro. A 2026 moderation example tags each plane with its creator's UserId.

## Numbers
- No CCU, revenue or visit figures in source notes

## What creators say about it
- Tag each spawned instance with its creator's UserId so moderation knows whose content is flagged. ([Roblox 2026-10 18:44](https://youtu.be/LPMDPxViGYI?t=1124))
- Use the moderation callback to hide flagged planes and send the offending player a nudge message instead of silently breaking their session. ([Roblox 2026-10 18:44](https://youtu.be/LPMDPxViGYI?t=1124))
- Private servers suit classroom use; Roblox Creator Docs cite this game as a popular example and in the education intro. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/education/support/private-servers-for-classroom-use), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/education/educator-onboarding/1-intro-to-roblox))

## Transferable patterns
- Tag user-generated instances with the creator's UserId
- Moderate by hiding flagged content and nudging the player
- Offer private servers for education use
