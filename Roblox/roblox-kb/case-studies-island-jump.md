# Case study: Island Jump

**Genre:** 3D platformer (official tutorial project)

Roblox Creator Docs tutorial 3D platformer built from the Baseplate template. Covers greybox, Core Building and Scripting assets, and a finished Final version with sea-stack height tiers and coin-based jump upgrades.

Also referred to as: Island Jump - Final, Island Jump - Final (sample), Island Jump - Building

## Numbers
- No CCU, revenue or visit figures in source notes; official tutorial sample (Roblox Creator Docs)
- Seven escalating sea-stack height levels (Roblox Creator Docs, G2595)

## What creators say about it
- Start from the Baseplate template and greybox the level first; the official curriculum builds the 3D platformer this way before art polish. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/curriculums/core/building/create-a-project), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/curriculums/core/building/apply-polished-assets))
- Apply the Core Building and Scripting asset library to the greybox to get working gameplay before polishing visuals. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/curriculums/core/building/apply-polished-assets))
- Terrain only needs to support gameplay; it does not need to match the sample's look exactly. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/curriculums/core/building/create-an-environment-with-terrain))
- Place a giant flare on the tallest platform as a focal point that draws players to climb toward it. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/curriculums/core/building/create-basic-visual-effects))
- Set mood cheaply with atmosphere settings: cool ocean palette, hard shadows and atmosphere tuning, as shown in the Final sample. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/curriculums/core/building/customize-global-lighting))
- Seven escalating sea-stack height levels with coin-based jump upgrades give a clear progression loop for climbing players. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/curriculums/core/building/greybox-a-playable-area))
- Structure a jumping course as seven escalating sea-stack height levels so difficulty and vertical progress rise in clear steps. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/curriculums/core/building/greybox-a-playable-area))
- Gate jump upgrades behind coins so players earn better jumping ability through play. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/curriculums/core/building/greybox-a-playable-area))
- A giant flare placed on the tallest platform makes it a focal point that draws players to climb toward it. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/curriculums/core/building/create-basic-visual-effects))
- The official sample uses a cool ocean palette, hard shadows and atmosphere settings to set the mood of the scene. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/curriculums/core/building/customize-global-lighting))

## Transferable patterns
- Greybox the layout and get scripts working before art pass
- Use one tall landmark as a visual goal
- Build mood with lighting and atmosphere rather than heavy assets
- Gate height tiers behind a currency-based upgrade
- Break vertical progression into discrete height tiers instead of one continuous climb.
- Use a collectible currency to unlock movement upgrades such as higher jumps.
- Place a tall, visually distinct landmark at the top of a climb to act as a goal and direction cue.
- Use lighting, shadow and atmosphere settings together to establish a consistent visual mood for an outdoor map.
