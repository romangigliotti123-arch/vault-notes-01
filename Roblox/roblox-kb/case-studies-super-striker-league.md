# Case study: Super Striker League

**Genre:** Sports (soccer)

Roblox soccer game with stadium releases, two-thumb controls, possession-based contextual buttons, and onboarding HUD prompts. Also used by Roblox Creator Docs as a UI example.

## What creators say about it
- Place main actions in thumb zones with context-sensitive buttons, since players use two thumbs (Roblox Creators, 2023-02). ([Roblox Creators 2023-02 19:43](https://youtu.be/BsyU-SJ9L-c?t=1183))
- Contextual buttons swap by possession, cutting clutter. Newer 2026 note: sprint and tackle without the ball, deke and pass with the ball (Roblox Creators, 2023-08; Roblox Creator Docs, 2026-10). ([Roblox Creators 2023-08 2:37](https://youtu.be/lOOvOIJoMi4?t=157), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/game-design/ui-ux-design))
- Show unusual controls on the HUD during onboarding (Roblox Creators, 2023-08; Roblox Creator Docs, 2026-10). ([Roblox Creators 2023-08 4:10](https://youtu.be/XfxbdKtSbOI?t=250), [Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/game-design/onboarding))
- Poor layout hurts hierarchy when elements are scattered across a corner (Roblox Creators, 2021-12). ([Roblox Creators 2021-12 6:58](https://youtu.be/cY1B5_x4RoU?t=418))
- Lobby 3D objects advertise sales, and interacting with them opens the main shop (Roblox Creator Docs, 2026-10). ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/production/game-design/contextual-purchases))
- Stadium releases act as cadence content built on existing systems (Roblox Creators, 2021-09 and 2021-10). ([Roblox Creators 2021-09 3:46](https://youtu.be/kQIyqMdh7Os?t=226), [Roblox Creators 2021-10 3:13](https://youtu.be/d4g30UupgKw?t=193))

## Transferable patterns
- Thumb-zone layout with contextual buttons
- Onboarding HUD for unusual controls
- 3D lobby billboards linked to shop
- Cadence content built on existing systems
