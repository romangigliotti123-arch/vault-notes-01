# Case study: Gold Rush

**Genre:** Official Roblox sample game (tutorial)

Roblox's official tutorial sample game. Used to teach data saving with an enhanced GoldManager (UI and auto-save), a global ordered-data-store leaderboard, and a gold score HUD.

Also referred to as: Gold Rush (tutorial sample game)

## What creators say about it
- Test data saving with an enhanced GoldManager that includes UI and auto-save. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/use-case-tutorials/scripting/intermediate-scripting/save-data))
- Gold collection can feed a global ordered-data-store leaderboard. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/use-case-tutorials/data-storage/create-leaderboard))
- Build a gold score bar HUD with a crown icon and score text as a reference layout. ([Roblox Creator Docs 2026-10](https://create.roblox.com/docs/tutorials/use-case-tutorials/ui/create-a-score-bar))

## Transferable patterns
- Centralize currency in a manager module with auto-save
- Use ordered data stores for global leaderboards
- Show score in a HUD bar with icon and text
