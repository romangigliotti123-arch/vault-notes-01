## Tips
- [32:18](https://youtu.be/3h25HUtBHFk?t=1938) **[[scripting-and-performance]]** Pre-generate AI assets (e.g., fish) at game start so generation latency is hidden; then use mini-games or engaging UX while waiting for slow generations.
- [31:36](https://youtu.be/3h25HUtBHFk?t=1896) **[[ai-and-tools]]** Put an LLM check in front of generated objects to reject off-theme items (e.g., 'is this a spooky swampy object?') to keep the game aesthetic.
- [8:11](https://youtu.be/3h25HUtBHFk?t=491) **[[ai-and-tools]]** Ask the NPC's LLM to reply in JSON with a fixed action set (small talk, claim quest) so your script can parse and map responses to game actions.
- [10:50](https://youtu.be/3h25HUtBHFk?t=650) **[[building-art-and-assets]]** Use the bounding-box option when generating 3D models over gray-box placeholders so output matches the intended footprint and aspect ratio.
