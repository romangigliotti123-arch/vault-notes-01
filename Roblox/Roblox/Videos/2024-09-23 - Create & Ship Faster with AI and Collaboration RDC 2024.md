## Summary
RDC 2024 keynote on Roblox Studio AI tools (Assistant, Code Assist, Material and Texture Generators) and creator collaboration features (activity history, annotations, file sync, Open Cloud testing and publishing). Includes a live demo of an AI-built game and a fireside chat with a developer on AI workflows, NPCs and IP.

## Tips
- [1:42](https://youtu.be/XrxUy51NsvI?t=102) **[[ai-and-tools]]** Use Assistant actions for bulk, tedious Studio edits like placing hundreds of trees, renaming, grouping into folders, or selecting by property criteria, instead of doing them manually.
- [9:45](https://youtu.be/XrxUy51NsvI?t=585) **[[ai-and-tools]]** Write detailed pseudo-code-style prompts for Assistant; a ~10-line prompt can yield ~100 lines of script, per the speaker.
- [11:49](https://youtu.be/XrxUy51NsvI?t=709) **[[building-art-and-assets]]** Use the texture generator to make variants of one asset (e.g. lightning and fire pillars), then have Assistant attach an attribute and script to change gameplay per variant.
- [4:51](https://youtu.be/XrxUy51NsvI?t=291) **[[ai-and-tools]]** Gen tools feel like a slot machine without control; the speaker says direct region selection and image inputs are coming to reduce re-rolling.
- [16:18](https://youtu.be/XrxUy51NsvI?t=978) **[[team-and-budget]]** Use Studio activity history and annotations so teammates see package changes and creative intent in-Studio instead of sharing screenshots.
- [17:42](https://youtu.be/XrxUy51NsvI?t=1062) **[[development-process-and-speed]]** Use Studio file sync to edit scripts in VS Code with bidirectional sync, instead of a separate tool like Rojo.
- [18:23](https://youtu.be/XrxUy51NsvI?t=1103) **[[development-process-and-speed]]** Once Open Cloud testing lands, write Luau test cases and run them in GitHub Actions CI/CD for automated testing of packages like a spaceship model.
- [23:10](https://youtu.be/XrxUy51NsvI?t=1390) **[[building-art-and-assets]]** Retexturing many marketplace assets for branded updates is a major artist time sink; generative retexturing can let a small team ship more games per update cycle.
- [27:17](https://youtu.be/XrxUy51NsvI?t=1637) **[[ai-and-tools]]** Start early, fail early, and experiment with open models; the fireside guest says teams must first fully embrace AI before it changes workflows.
- [33:37](https://youtu.be/XrxUy51NsvI?t=2017) **[[ai-and-tools]]** Use Studio autocomplete and code explanation for debugging; the speaker says code explanation is among the highest-rated features.
- [35:42](https://youtu.be/XrxUy51NsvI?t=2142) **[[common-mistakes]]** Assume generated code is not free of IP risk without checking; per the speaker, Roblox ingests only opted-in code and shreds it into tokens, so content with copyright headers is excluded.
