# Playbook: Blender 3D for Roblox Studio: using Claude with Blender (blender-mcp, bpy scripting) and the Blender-to-Roblox asset pipeline

Every step cites the source notes it rests on and carries a trust label (OFFICIAL, CORROBORATED, SINGLE-SOURCE, CONTRADICTED, OUTDATED/UNSURE; the weakest label of the points it cites). The quick, safe subset is in [[blender-cheat-sheet-claude-blender-roblox]]. Confidence is the synthesiser's judgement from agreement between sources, not a guarantee. See [[blender-README]], [[blender-open-questions]], [[blender-recall-check]].

Playbook for taking Blender assets into Roblox Studio, with notes on Claude-driven Blender automation. Official Roblox sources cover the export, import, rigging, avatar and limit rules. They contain no blender-mcp, bpy or Claude content (T1.14, T6.4). The Claude/MCP material comes from community sources and is mostly single-source or possibly outdated, so treat it as unconfirmed. Core flow: set up the Blender scene and units, model within the triangle, UV and texture limits, rig, export FBX or glTF, import with Studio's importer, then iterate with Reimport. The Open Cloud plugin is an optional upload route. Several figures disagree between sources, including scale ratios, texture caps and Blender 4.x plugin support. Those are flagged under contradictions.

## 1. Set up tools (plugin and optional Claude automation)
1. **[OFFICIAL]** **[OFFICIAL] If you want Open Cloud upload from Blender, install the Roblox Blender plugin. Click Install Dependencies once in the N-panel Roblox tab, restart Blender, log in via browser OAuth, then pick the creator in the 'Upload to' dropdown.** The plugin is the official reference implementation for uploading meshes and collections. *(high)* [[sources/off-gh-roblox-blender-plugin-README|off-gh-roblox-blender-plugin-README]] [[sources/off-art_modeling_roblox-blender-plugin|off-art_modeling_roblox-blender-plugin]] [[sources/web-1170ea0231|web-1170ea0231]]

It may not work on 4.x or earlier.** Compatibility is version-sensitive. Sources disagree about 4.x. *(high)* [[sources/off-gh-roblox-blender-plugin-rel-v1.0.5|off-gh-roblox-blender-plugin-rel-v1.0.5]] [[sources/gh-Roblox-roblox-blender-plugin-rel-v1.0.5|gh-Roblox-roblox-blender-plugin-rel-v1.0.5]] [[sources/gh-Roblox-roblox-blender-plugin-i8|gh-Roblox-roblox-blender-plugin-i8]] [[sources/off-gh-roblox-blender-plugin-README|off-gh-roblox-blender-plugin-README]] [[sources/gh-Roblox-roblox-blender-plugin-i32|gh-Roblox-roblox-blender-plugin-i32]] [[sources/gh-Roblox-roblox-blender-plugin-rel-v1.0.3|gh-Roblox-roblox-blender-plugin-rel-v1.0.3]]
3. **[OFFICIAL]** **[OFFICIAL] If login fails with a DNS error on Windows, delete the bundled aiodns folder. For ModuleNotFoundError, do a clean reinstall. Avoid rapid repeat logins (429). Read the system console for logs.** These are the documented fixes for common install and login failures. *(high)* [[sources/gh-Roblox-roblox-blender-plugin-i112|gh-Roblox-roblox-blender-plugin-i112]] [[sources/gh-Roblox-roblox-blender-plugin-i35|gh-Roblox-roblox-blender-plugin-i35]] [[sources/gh-Roblox-roblox-blender-plugin-i75|gh-Roblox-roblox-blender-plugin-i75]] [[sources/gh-Roblox-roblox-blender-plugin-i12|gh-Roblox-roblox-blender-plugin-i12]] [[sources/gh-Roblox-roblox-blender-plugin-i20|gh-Roblox-roblox-blender-plugin-i20]]

## 2. Scripting Blender with bpy (headless/batch)
1. **[OFFICIAL]** **[OFFICIAL] Run batch scripts with `blender --background --factory-startup --python-exit-code 1 --python script.py -- args`. Then check the exit code and that the output file exists.** Without --python-exit-code 1, Blender exits 0 even if the script raised (measured on 5.0.1, single source). *(high)* [[sources/gh-elithril-blender-kiln-f-plugin-references-animation.md|gh-elithril-blender-kiln-f-plugin-references-animation.md]] [[sources/gh-elithril-blender-kiln-f-plugin-references-export-targets.md|gh-elithril-blender-kiln-f-plugin-references-export-targets.md]]
2. **[OUTDATED/UNSURE]** **[OUTDATED/UNSURE] Do not rely on older or LLM-generated bpy snippets without testing. Reports say Principled input names changed in 4.x and 4.4+ slotted actions break action.fcurves.new. This is unconfirmed and possibly outdated.** API drift reportedly breaks old snippets. *(low)* [[sources/gh-elithril-blender-kiln-f-plugin-references-texturing-strategy.md|gh-elithril-blender-kiln-f-plugin-references-texturing-strategy.md]] [[sources/gh-elithril-blender-kiln-f-plugin-references-characters.md|gh-elithril-blender-kiln-f-plugin-references-characters.md]]
3. **[SINGLE-SOURCE]** **[SINGLE-SOURCE] When batch-clearing scenes through blender-mcp, reportedly delete objects and orphan datablocks instead of calling read_homefile(use_empty=True). This is unconfirmed.** A single source says read_homefile resets integration flags and later assets fail silently. *(low)* [[sources/gh-elithril-blender-kiln-f-plugin-references-batch-mode.md|gh-elithril-blender-kiln-f-plugin-references-batch-mode.md]]
4. **[OUTDATED/UNSURE]** **[OUTDATED/UNSURE] On Windows with a headless MCP server, reportedly use list-form subprocess args and stdin=DEVNULL (fixed in v0.11.0 of one server). This is unconfirmed and possibly outdated.** Reported hangs came from shell=True quoting and an inherited stdin pipe. *(low)* [[sources/gh-sandraschi-blender-mcp-i2|gh-sandraschi-blender-mcp-i2]] [[sources/gh-sandraschi-blender-mcp-i3|gh-sandraschi-blender-mcp-i3]]

## 3. Model within Roblox limits
1. **[OFFICIAL]** **[OFFICIAL] Keep each mesh at or under 20,000 triangles. Rigid accessories must be one mesh at or under 4,000 triangles. Body budgets: head 4000, torso 1750, each arm and leg 1248. Triangles are about 2x quads.** Import auto-simplifies meshes over 20k, and the avatar limits are enforced. *(high)* [[sources/web-7195087017|web-7195087017]] [[sources/off-dev_3958222|off-dev_3958222]] [[sources/off-avatar_layered-accessories_specifications|off-avatar_layered-accessories_specifications]] [[sources/web-04cef4e0ee|web-04cef4e0ee]] [[sources/off-avatar_character-bodies_specifications|off-avatar_character-bodies_specifications]] [[sources/web-2a50b96cb8|web-2a50b96cb8]]
2. **[OFFICIAL]** **[OFFICIAL] Make geometry watertight with quads, no N-gons, and non-zero thickness. Use one material per mesh and a single UV set with all UVs inside 0:1.** Validation requires these, and the UV check has no auto-fix. *(high)* [[sources/off-art_modeling_specifications|off-art_modeling_specifications]] [[sources/web-7195087017|web-7195087017]] [[sources/off-dev_4950522|off-dev_4950522]] [[sources/web-04cef4e0ee|web-04cef4e0ee]] [[sources/off-art_modeling_texture-specifications|off-art_modeling_texture-specifications]] [[sources/web-2cd06949f0|web-2cd06949f0]]
3. **[OFFICIAL]** **[OFFICIAL] Size textures to the item. Basic guidance: 5x5 studs 256, 10x10 512, 20x20 1024. Marketplace avatar textures are capped at 2048.** Right-sizing saves memory. Low-RAM devices stay at 1k. *(high)* [[sources/off-art_modeling_texture-specifications|off-art_modeling_texture-specifications]] [[sources/off-dev_4358444|off-dev_4358444]] [[sources/off-avatar_layered-accessories_specifications|off-avatar_layered-accessories_specifications]] [[sources/web-04cef4e0ee|web-04cef4e0ee]] [[sources/web-2cd06949f0|web-2cd06949f0]]
4. **[OFFICIAL]** **[OFFICIAL] For PBR use SurfaceAppearance maps: OpenGL tangent-space normals, metalness workflow only, albedo with no baked lighting. For accessories, cap Normal/Roughness/Metalness at 256 and Color at 1024.** These are the official PBR format rules. *(high)* [[sources/off-dev_3816937|off-dev_3816937]] [[sources/off-art_modeling_texture-specifications|off-art_modeling_texture-specifications]] [[sources/off-art_modeling_surface-appearance|off-art_modeling_surface-appearance]] [[sources/web-5464514816|web-5464514816]] [[sources/web-903b57f8b0|web-903b57f8b0]] [[sources/off-avatar_layered-accessories_import|off-avatar_layered-accessories_import]]
5. **[OUTDATED/UNSURE]** **[OUTDATED/UNSURE] Bake or convert shader features before glTF export, because glTF carries textures, not node trees. Packing images and baking AO, SSS or procedural shaders are reportedly needed. The details here are possibly outdated.** Reports say some maps are dropped and unpacked images render black. *(low)* [[sources/gh-elithril-blender-kiln-f-plugin-references-reference-fidelity.md|gh-elithril-blender-kiln-f-plugin-references-reference-fidelity.md]] [[sources/gh-elithril-blender-kiln-f-plugin-references-texturing-strategy.md|gh-elithril-blender-kiln-f-plugin-references-texturing-strategy.md]]

## 4. Rig and animate
1. **[CORROBORATED]** **[CORROBORATED] Before rigging, apply scale and rotation, weld duplicate vertices and remove loose parts. Disconnected islands make automatic weights fail.** Clean meshes skin reliably. *(high)* [[sources/gh-ahujasid-mcp-for-blender-f-src-blender_mcp-guides-rigging.md|gh-ahujasid-mcp-for-blender-f-src-blender_mcp-guides-rigging.md]] [[sources/gh-elithril-blender-kiln-f-plugin-references-characters.md|gh-elithril-blender-kiln-f-plugin-references-characters.md]]
2. **[OFFICIAL]** **[OFFICIAL] Use the standard R15 hierarchy and Roblox's Rig_and_Attachments_Template.blend. Put Root and LowerTorso at 0,0,0 and parent all 15 meshes to one armature.** The template guarantees correct names and structure. *(high)* [[sources/off-avatar_character-bodies_specifications|off-avatar_character-bodies_specifications]] [[sources/web-2a50b96cb8|web-2a50b96cb8]] [[sources/off-art_modeling_rig-a-humanoid-model|off-art_modeling_rig-a-humanoid-model]] [[sources/web-0edc91a2bc|web-0edc91a2bc]] [[sources/off-art_modeling_cage-meshes_index|off-art_modeling_cage-meshes_index]] [[sources/off-dev_4541689|off-dev_4541689]]
3. **[OFFICIAL]** **[OFFICIAL] Respect the skinning limits: at most 4 influences per vertex, none on Root or HumanoidRootNode, and bones frozen at scale 1 and rotation 0.** Roblox drops or removes violating data on import. *(high)* [[sources/off-art_modeling_skin-a-humanoid-model|off-art_modeling_skin-a-humanoid-model]] [[sources/off-art_modeling_specifications|off-art_modeling_specifications]] [[sources/off-studio_importer|off-studio_importer]] [[sources/off-avatar_character-bodies_specifications|off-avatar_character-bodies_specifications]]
4. **[OFFICIAL]** **[OFFICIAL] Paint weights with the armature shown as Sticks and Auto Normalize on. Use X-Axis Mirror, test in Pose mode and reset with Alt+R.** This is the documented weight-painting workflow. *(high)* [[sources/web-1cc5c97477|web-1cc5c97477]] [[sources/off-art_modeling_skin-a-humanoid-model|off-art_modeling_skin-a-humanoid-model]] [[sources/off-art_modeling_rig-a-humanoid-model|off-art_modeling_rig-a-humanoid-model]]
5. **[OFFICIAL]** **[OFFICIAL] Export FBX with Add Leaf Bones off. Enable Bake Animation only for keyframed content, and export one animation track per file.** Only one animation track per mesh export is supported. *(high)* [[sources/web-3a1e35acf3|web-3a1e35acf3]] [[sources/off-art_modeling_specifications|off-art_modeling_specifications]] [[sources/web-7195087017|web-7195087017]] [[sources/web-19fbb4beda|web-19fbb4beda]]
6. **[OFFICIAL]** **[OFFICIAL] Import animations through the Animation Clip Editor importer (Rig Type, Rig Scale, Rest Pose Source). Use Joint Upgrade constraints for multi-bone rigs. Expect AnimationConstraint rather than Motor6D under the Avatar Joint Upgrade.** The importer is the current official route. Motor6D import gives warnings and broken playback. *(high)* [[sources/off-dev_4775593|off-dev_4775593]] [[sources/off-dev_4260501|off-dev_4260501]] [[sources/web-af064b2633|web-af064b2633]] [[sources/off-art_modeling_cage-meshes_index|off-art_modeling_cage-meshes_index]] [[sources/off-dev_4541689|off-dev_4541689]] [[sources/off-art_accessories_creating_armature-setup|off-art_accessories_creating_armature-setup]]

## 5. Export from Blender
1. **[OFFICIAL]** **[OFFICIAL] Export FBX with Apply Scalings = FBX Unit Scale, Path Mode = Copy with Embed Textures, Add Leaf Bones off, selected objects only, and lights and cameras removed.** These are the documented recommended settings. *(high)* [[sources/off-art_accessories_creating_exporting|off-art_accessories_creating_exporting]] [[sources/off-art_blender|off-art_blender]] [[sources/off-art_modeling_export-requirements|off-art_modeling_export-requirements]] [[sources/off-art_characters_creating_blender-configurations|off-art_characters_creating_blender-configurations]]
2. **[CORROBORATED]** **[CORROBORATED] Apply modifiers before export, including Geometry Nodes results. Do not rename meshes or move pivots if you plan to Reimport.** Unapplied modifiers can export only the base mesh. Renames break Reimport matching. *(medium)* [[sources/gh-elithril-blender-kiln-f-plugin-references-batch-mode.md|gh-elithril-blender-kiln-f-plugin-references-batch-mode.md]] [[sources/off-art_accessories_creating_exporting|off-art_accessories_creating_exporting]] [[sources/off-dev_4068650|off-dev_4068650]] [[sources/off-dev_4112031|off-dev_4112031]]
3. **[OFFICIAL]** **[OFFICIAL] Connect the colour map to alpha in the Blender PBR material and export glTF/FBX, so the importer auto-sets DoubleSided and Transparency.** The importer handles this automatically from Blender exports. *(high)* [[sources/off-dev_4137281|off-dev_4137281]]
4. **[OFFICIAL]** **[OFFICIAL] For avatar items, include cages named <Mesh>_InnerCage and <Mesh>_OuterCage from Roblox's templates. Never delete cage vertices or alter cage UVs.** Violations cause import, equip or validation failures. *(high)* [[sources/off-art_modeling_specifications|off-art_modeling_specifications]] [[sources/off-avatar_layered-accessories_specifications|off-avatar_layered-accessories_specifications]] [[sources/web-04cef4e0ee|web-04cef4e0ee]] [[sources/web-96978ac98f|web-96978ac98f]] [[sources/web-565bb91116|web-565bb91116]] [[sources/web-21daf6242f|web-21daf6242f]]

## 6. Import into Studio and iterate
1. **[OFFICIAL]** **[OFFICIAL] Import via the Studio Importer. Pick the scale approach deliberately: Scale Unit Stud, or a real-world unit plus the Scale Factor field. Enable 'Uses Cages' when cages are present.** The unit conversion for non-Stud units changes on 2026-06-16 (20 studs/m to 25:7). Setting 5.6 with a non-Stud unit preserves the old behavior. *(high)* [[sources/off-art_blender|off-art_blender]] [[sources/off-dev_4644371|off-dev_4644371]] [[sources/off-art_modeling_cage-meshes_index|off-art_modeling_cage-meshes_index]] [[sources/off-dev_4541689|off-dev_4541689]] [[sources/off-art_accessories_creating_armature-setup|off-art_accessories_creating_armature-setup]]
2. **[OFFICIAL]** **[OFFICIAL] For bulk imports use the import queue presets and Apply settings to all. Use the Upload to Roblox toggle during test iteration.** These reduce manual steps. *(high)* [[sources/off-studio_importer|off-studio_importer]] [[sources/web-5d5513d689|web-5d5513d689]]
3. **[OFFICIAL]** **[OFFICIAL] Iterate with Reimport (right-click or Alt+Shift+R). It matches meshes by name. Use Quick Import (Alt+M) for single files.** Reimport updates models in place. Quick Import skips animations and doesn't add to inventory. *(high)* [[sources/off-dev_4068650|off-dev_4068650]] [[sources/off-dev_4112031|off-dev_4112031]] [[sources/off-dev_3958222|off-dev_3958222]]
4. **[OFFICIAL]** **[OFFICIAL] For layered accessories, import as a Model and then use the Accessory Fitting Tool (Generate MeshPart Accessory). Check Marketplace requirements: Material Plastic, Transparency 0, VertexColor 1,1,1, no extra Scripts or Parts.** This converts the model to a valid accessory. *(high)* [[sources/off-avatar_layered-accessories_import|off-avatar_layered-accessories_import]] [[sources/web-5d5513d689|web-5d5513d689]] [[sources/web-0d333c4d57|web-0d333c4d57]] [[sources/off-avatar_character-bodies_specifications|off-avatar_character-bodies_specifications]] [[sources/off-avatar_layered-accessories_specifications|off-avatar_layered-accessories_specifications]] [[sources/web-2a50b96cb8|web-2a50b96cb8]]
5. **[OFFICIAL]** **[OFFICIAL] Validate with the UGC Validation visualization plugin (red for errors, yellow for warnings).** It catches spec problems before upload. *(high)* [[sources/off-dev_4709282|off-dev_4709282]] [[sources/off-dev_4950522|off-dev_4950522]]

## 7. Upload and automate
1. **[OFFICIAL]** **[OFFICIAL] Upload from the Blender plugin and check Toolbox > Inventory > My Packages. Re-uploading updates the same package. Deleting the 'Roblox Package ID' custom property creates a new asset.** Packages carry versioning through that custom property. *(high)* [[sources/off-gh-roblox-blender-plugin-README|off-gh-roblox-blender-plugin-README]]
2. **[OFFICIAL]** **[OFFICIAL] For HTTP automation, use the Open Cloud Assets API: an x-api-key, up to 20 MB per call, then poll the returned operation for the assetId. It accepts .rbxm, animations and Roblox meshes since 2025-10-23. Docs still recommend the Studio Importer for custom 3D models.** This is the official API route, with its limits. *(high)* [[sources/off-cloud_guides_usage-assets|off-cloud_guides_usage-assets]] [[sources/web-57279f4b4c|web-57279f4b4c]] [[sources/off-dev_4022082|off-dev_4022082]] [[sources/off-dev_3642901|off-dev_3642901]]
3. **[SINGLE-SOURCE]** **[SINGLE-SOURCE] A manifest-driven batch with a YAML status file is reportedly used by some creators (failures skipped, no retry). This is unconfirmed single-source practice.** It is one reported way to run unattended batches. *(low)* [[sources/gh-elithril-blender-kiln-f-plugin-references-batch-mode.md|gh-elithril-blender-kiln-f-plugin-references-batch-mode.md]] [[sources/gh-elithril-blender-kiln-f-plugin-references-naming-conventions.md|gh-elithril-blender-kiln-f-plugin-references-naming-conventions.md]] [[sources/gh-elithril-blender-kiln-f-plugin-references-sourcing-strategy.md|gh-elithril-blender-kiln-f-plugin-references-sourcing-strategy.md]]

## Where sources disagree
- **[OFFICIAL]** **[OFFICIAL] Scale approach for FBX exports**: Older guidance: FBX Unit Scale, Scene Units None, Studio unit Stud. Newer importer docs: real-world units with 25:7 scaling and a Scale Factor field from 2026-06-16, because the old 20:1 ratio made meshes oversized. The Stud unit is unchanged, so both work. The newer docs are more recent and official. [[sources/off-art_blender|off-art_blender]] [[sources/off-dev_4644371|off-dev_4644371]]

- **[OFFICIAL]** **[OFFICIAL] Maximum texture size**: UV rules cite 1024. Newer guidance allows 2048 for Marketplace avatar assets, and the engine supports 4096. PBR accessory maps are capped at 256 (normal, roughness, metalness) and 1024 (color). Treat these as separate contexts. The 2048 and PBR-accessory caps are the best supported for avatar items.
