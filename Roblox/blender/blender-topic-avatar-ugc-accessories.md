# "Avatar, UGC and accessories"

Back to [[blender-README]] | [[blender-playbook]]

Roblox avatar items (rigid accessories, layered accessories, character bodies, dynamic/face heads) each have separate specs and export settings. Layered clothing relies on paired inner/outer cages (named <Mesh>_InnerCage/_OuterCage, matching UVs, no deleted vertices), a rigging armature and fixed-name attachments; bodies need 15 *_Geo meshes, 15 outer cages and 19 attachments. Roblox cage templates or Avatar Setup should be used, not custom cages. Import via Studio Importer, then convert with the Accessory Fitting Tool (Generate MeshPart Accessory). PBR is optional for accessories. Recent Studio updates added Auto-Setup for accessories, eyebrows/eyelashes, leader/follower skinning and a UGC Validation visualization plugin. Invisible heads were removed from the Marketplace in Dec 2025. Prices and fees are time-stamped and vary between sources.

## Key points
- **[OFFICIAL]** [OFFICIAL] Avatar items (rigid accessories, layered accessories, character bodies) each need their own specs and export settings, separate from generic export settings. *(multiple-sources, high)* [[sources/gh-Roblox-creator-docs-f-content-en-us-art-blender.md|gh-Roblox-creator-docs-f-content-en-us-art-blender.md]] [[sources/off-art_blender|off-art_blender]] [[sources/web-3a1e35acf3|web-3a1e35acf3]] [[sources/web-df8d902e57|web-df8d902e57]]
- **[OFFICIAL]** [OFFICIAL] Cage meshes are invisible surfaces on a MeshPart that let layered items deform and layer over each other. They pair by UV, not position, and work only with other paired cages. In Studio they appear as WrapTarget and WrapLayer, and MeshPart is the only valid parent. *(multiple-sources, high)* [[sources/off-art_modeling_cage-meshes_index|off-art_modeling_cage-meshes_index]] [[sources/off-avatar_layered-accessories_index|off-avatar_layered-accessories_index]]
- **[OFFICIAL]** [OFFICIAL] Layered accessories need an inner and outer cage named <Mesh>_InnerCage and <Mesh>_OuterCage. The outer cage starts identical to the inner and is the only one to adjust. Never delete cage vertices or alter cage UVs, or you risk import or equip errors and validation failure. *(multiple-sources, high)* [[sources/off-art_modeling_specifications|off-art_modeling_specifications]] [[sources/off-avatar_layered-accessories_specifications|off-avatar_layered-accessories_specifications]] [[sources/web-04cef4e0ee|web-04cef4e0ee]] [[sources/web-96978ac98f|web-96978ac98f]]
- **[OFFICIAL]** [OFFICIAL] Use Roblox cage templates (Clothing_Cage_Template.blend, appended via File > Append) or the Avatar Setup tool, not custom cages. Characters and layered clothing must share a common Roblox cage. A skinned model with no cage data (e.g. Lola) cannot equip accessories. *(multiple-sources, high)* [[sources/web-565bb91116|web-565bb91116]] [[sources/web-96978ac98f|web-96978ac98f]] [[sources/web-21daf6242f|web-21daf6242f]] [[sources/web-3cd0175a8a|web-3cd0175a8a]] [[sources/off-art_modeling_skin-a-humanoid-model|off-art_modeling_skin-a-humanoid-model]]
- **[OFFICIAL]** [OFFICIAL] Character body requirements: 15 *_Geo meshes that are watertight and capped, 15 outer cages parented to one empty object, and 19 attachments in an armature. Transforms must be frozen with pivots at 0,0,0, facing +Z with +Y up, in I/A/T pose. Bodies need only an outer cage. On upload the body is split into 6 assets. *(multiple-sources, high)* [[sources/off-avatar_character-bodies_export|off-avatar_character-bodies_export]] [[sources/off-avatar_character-bodies_specifications|off-avatar_character-bodies_specifications]] [[sources/web-2a50b96cb8|web-2a50b96cb8]] [[sources/web-6e2b07b559|web-6e2b07b559]]
- **[OFFICIAL]** [OFFICIAL] Body scale bounding box is min 1.0x4.0x0.5 studs and max 8.0x10.0x4.0 studs. Body parts must be opaque and fill at least 50% of their bounding box. Importer Rig Type mapping: Rthro = Normal, Rthro Narrow = Slender, Default = Classic. *(multiple-sources, medium)* [[sources/off-avatar_character-bodies_specifications|off-avatar_character-bodies_specifications]] [[sources/web-2a50b96cb8|web-2a50b96cb8]]
- **[OFFICIAL]** [OFFICIAL] Marketplace upload requires MeshPart Material Plastic, Transparency 0, VertexColor 1,1,1, and no extra Script or Part objects. Attachments import as Attachment objects only with the _Att suffix. Grip attachments must be perpendicular to the lower arm (90,0,0 in I-pose), and head attachments must sit on the visible head surface. Attachment names are fixed per accessory type and generated by the Accessory Fitting Tool. *(multiple-sources, high)* [[sources/off-avatar_character-bodies_specifications|off-avatar_character-bodies_specifications]] [[sources/off-avatar_layered-accessories_specifications|off-avatar_layered-accessories_specifications]] [[sources/web-2a50b96cb8|web-2a50b96cb8]] [[sources/web-04cef4e0ee|web-04cef4e0ee]]
- **[OFFICIAL]** [OFFICIAL] Layered accessory pipeline: import .fbx/.gltf via the Studio Importer as a Model, then in the Accessory Fitting Tool pick Clothing and the clothing type, test on sample characters, and Generate MeshPart Accessory. Minor cage tweaks are possible in the tool, but larger ones need re-export. Left and right shoes are converted separately. glTF cages create extra Models that can be deleted. *(multiple-sources, high)* [[sources/off-avatar_layered-accessories_import|off-avatar_layered-accessories_import]] [[sources/web-5d5513d689|web-5d5513d689]] [[sources/web-0d333c4d57|web-0d333c4d57]]
- **[OFFICIAL]** [OFFICIAL] The PBR accessory workflow uses the Import 3D tool, SurfaceAppearance maps, and Generate MeshPart Accessory for rigid items. PBR is optional and applies to all accessory categories. The same item can be uploaded with and without PBR. Non-albedo maps for rigid accessories are capped at 256x256. Emissive strength must stay between 0 and 40. *(multiple-sources, high)* [[sources/off-dev_3816937|off-dev_3816937]] [[sources/web-0a3000a567|web-0a3000a567]] [[sources/web-2cd06949f0|web-2cd06949f0]] [[sources/off-art_modeling_texture-specifications|off-art_modeling_texture-specifications]] [[sources/web-5464514816|web-5464514816]]
- **[OFFICIAL]** [OFFICIAL] Eyebrows and eyelashes cannot be standalone uploads. They must be bundled with a character body or makeup asset and named EyebrowAccessory, EyelashAccessory or HairAccessory. Face accessories need a rig and inner and outer cages, with multi-piece items combined into one mesh. Auto-Setup (May 2026) supports them as 'Eye Layered', and leader/follower skinning (Dec 2025) fixes stretching. *(multiple-sources, high)* [[sources/off-avatar_layered-accessories_specifications|off-avatar_layered-accessories_specifications]] [[sources/web-04cef4e0ee|web-04cef4e0ee]] [[sources/web-10c4f3f2a8|web-10c4f3f2a8]] [[sources/off-dev_4634673|off-dev_4634673]] [[sources/off-dev_4137281|off-dev_4137281]]
- **[OFFICIAL]** [OFFICIAL] Dynamic heads need a RootFaceJoint under the head joint, distinct eyes, teeth, tongue, mouth bag and eye bag, and an outer cage. They must map to FACS, and 17 of the 50 poses are required. Import fails on unmapped poses, empty mapping strings, or duplicate pose names. Failing heads are often fixed faster by refitting a Roblox cage template. *(multiple-sources, high)* [[sources/web-dab3337bfb|web-dab3337bfb]] [[sources/web-ce404af0d8|web-ce404af0d8]]
- **[OFFICIAL]** [OFFICIAL] Studio now offers a UGC Validation visualization plugin (Beta in June 2026, under the Avatar tab by Oct 2026). It validates bodies, heads, layered clothing and rigid accessories, showing errors in red and warnings in yellow, with a quality score. Quality measures technical soundness, not realism. *(multiple-sources, high)* [[sources/off-dev_4709282|off-dev_4709282]] [[sources/off-dev_4950522|off-dev_4950522]]
- **[OFFICIAL]** [OFFICIAL] Roblox removed partially or fully invisible heads from the Marketplace and inventories on 2025-12-11. Creators got no strike, buyers were refunded in Robux within 7 business days, and equipped heads revert to default. New circumvention attempts face moderation. *(single-source, high)* [[sources/off-dev_4144715|off-dev_4144715]]
- **[OFFICIAL]** [OFFICIAL] Auto-Setup (Feb 2026) extends to in-experience clothing and accessories. Rigid accessories must be submitted to AutoSetupAvatarAsync together with a body model, and outputs are EditableMesh and EditableImage. Auto-Setup output can be exported as glTF to finalize in Blender, but layered clothing may misposition and won't deform outside Roblox. *(multiple-sources, high)* [[sources/off-dev_4358192|off-dev_4358192]] [[sources/off-dev_3905928|off-dev_3905928]] [[sources/off-art_modeling_gltf-export|off-art_modeling_gltf-export]]

## Techniques
- **[OFFICIAL]** **[OFFICIAL] Cage setup from template in Blender**: Append InnerCage/OuterCage from Clothing_Cage_Template.blend, duplicate and clear the parent (keep transformation), and rename to <Mesh>_InnerCage/_OuterCage. Fit only the outer cage to the item, then export just the mesh, armature and cages. [[sources/web-96978ac98f|web-96978ac98f]] [[sources/web-21daf6242f|web-21daf6242f]] [[sources/web-10c4f3f2a8|web-10c4f3f2a8]]
- **[OFFICIAL]** **[OFFICIAL] PBR accessory publish**: Import via Import 3D, add SurfaceAppearance maps if missing, convert with the Accessory Fitting Tool (Generate MeshPart Accessory), then upload. [[sources/off-dev_3816937|off-dev_3816937]]
- **[OFFICIAL]** **[OFFICIAL] Data Transfer custom normals per body part**: Duplicate the model, separate the original into parts, and add a Data Transfer modifier to each part with the duplicate as source and Face Corner Data > Custom Normals enabled. Apply the modifiers and delete the duplicate. [[sources/web-e67479ac6e|web-e67479ac6e]]
- **[OFFICIAL]** **[OFFICIAL] Body cage morph and UV link**: Morph the Roblox cage to the character without deleting vertices or faces. Then select the morphed part followed by the original cage part and press Ctrl+L to link UV data. [[sources/web-e67479ac6e|web-e67479ac6e]]
- **[OFFICIAL]** **[OFFICIAL] Validate UGC Body / UGC Validation visualization**: Use Validate UGC Body to open the asset in the Avatar Setup tool. Alternatively, in the Avatar tab select the asset type, run validation, and click messages to see issues. [[sources/off-studio_importer|off-studio_importer]] [[sources/off-dev_4950522|off-dev_4950522]] [[sources/off-dev_4709282|off-dev_4709282]]
- **[CORROBORATED]** **[CORROBORATED] Rigid accessory import and attach**: Export .fbx, import it as a Model, and convert it with the Accessory Fitting Tool. In Blender, the video attaches with the Attach Accessories tool, parenting, or a Child Of constraint. [[sources/web-1dee9451ae|web-1dee9451ae]] [[sources/yt-qb4lUcRtMRk|yt-qb4lUcRtMRk]]
