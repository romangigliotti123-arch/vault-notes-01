## Summary

- c1: [4:40] Developer of I Just Wanted to Fish said the only tool used was Blender MCP with Claude, which created all game assets in Blender; no image or 3D AI used. *(experience, low; claude-blender-ai)*
- c2: [3:59] Same developer reportedly spent two weeks, used Opus 5.5 on a $100 plan, consumed two weekly limits, and spent over 30 billion tokens. Secondhand, unverified. *(experience, low; automation-and-creator-workflows)*

- c5: [17:44] ZERO-G was made by Opus alone; a model was generated in parts with Tripo P2 and Opus animated parts such as ears in code. *(experience, low; other)*
- c6: [7:47] Pixel-art game Luminati was described by code, with initial build about 3.5 MB, reportedly done in under one day with Opus 5.5. *(experience, low; other)*
