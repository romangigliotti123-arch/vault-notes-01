Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox official tutorial for converting an existing premade model (Sci Fi Mask reference FBX) into a rigid Accessory: Blender import, 1/100 scale fix, -Y forward orientation, PBR texture node setup (ALB, MTL, RGH, NOR via Normal Map node), apply all transforms, export FBX, import via Studio Importer, fit/convert in Accessory Fitting Tool, publish. No bpy, MCP, or Claude content.

## Claims
- c1: Premade FBX models may import into Blender at 1/100 scale due to FBX conversion; fix by setting object Transform X/Y/Z to 1.000. *(doc, high; roblox-import-pipeline)*
- c2: Accessory should face -Y forward and be placed at world origin (0,0,0) so it imports centred on the camera in Studio. *(doc, high; roblox-export-settings)*
- c3: Failing to apply transforms (Object > Apply > All Transforms) can cause unexpected orientation and behaviour when importing into Studio. *(doc, high; common-mistakes-fixes)*
- c4: PBR maps are linked in Blender Principled BSDF: ALB to Base Color, MTL to Metallic, RGH to Roughness; NOR must pass through a Normal Map node into Normal. *(doc, high; texturing-baking-uv)*
- c5: Tutorial covers only rigid accessories, not layered clothing or character body models. *(doc, high; avatar-ugc-accessories)*
- c6: PBR textures are optional for accessories; non-PBR basic texture is an acceptable alternative. *(doc, high; avatar-ugc-accessories)*
- c7: Studio Importer provides object previews and error checking for third-party 3D assets; conversion from Model to Accessory is done with Accessory Fitting Tool. *(doc, high; roblox-import-pipeline)*
- c8: Publishing to Marketplace is optional and only needed for creators who intend to sell the asset. *(doc, high; creator-workflows)*
- c9: Workflow is generic: same concepts apply to other third-party modelling apps and custom assets. *(doc, medium; creator-workflows)*
- c10: Source does not mention blender-mcp, Claude, or bpy scripting at all. *(doc, high; claude-blender-mcp)*

## Numbers
- n1: **FBX import scale error**: 1/100 scale; fix Transform to 1.000 
- n2: **Accessory type scope**: rigid accessories only 

## Techniques
- t1: **Fix 1/100 FBX import scale**: Open Blender, delete default cube/camera, File>Import>FBX, select object, Properties>Object>Transform set X,Y,Z to 1.000.
- t2: **PBR node linking in Blender**: Shading tab, New material, drag PNG maps into node editor; ALB->Base Color, MTL->Metallic, RGH->Roughness; NOR->Normal Map node->Normal; preview in Material Preview mode.
- t3: **Freeze transforms before export**: Object mode, select mesh, Object>Apply>All Transforms; remove lights, cameras, mannequin meshes and apply modifiers before FBX export.
