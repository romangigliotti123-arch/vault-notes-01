# web-182902a186

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox creator doc on building animation packs: seven locomotion states (eight or nine clips), R15 rig, CurveAnimation-only clips, 10s max, looping rules, Studio-only upload and assembly, validation limits. Only tangentially about Blender: it mentions importing .fbx into Studio, not Blender export settings or bpy workflows.

## Claims
- c1: Animation pack clips must reference a standard R15 rig and be Class.CurveAnimation; KeyframeSequence data is not accepted by upload. *(doc, high; rigging-animation)*
- c2: Each clip must be 10 seconds or shorter; all clips except Jump must loop. *(doc, high; rigging-animation)*
- c3: Validation fails if a body part translates more than 1.5 studs from its start in any frame, root joint moves too far, or frame-to-frame speed is exceeded. *(doc, high; rigging-animation)*
- c4: Converting a track to CurveAnimation via Curve Editor is irreversible and may break some third-party animation plugins; verify data first. *(doc, high; rigging-animation)*
- c5: Animation clips are imported into Studio from .fbx via Animation Editor, Import > From File, with root pose source set to Imported Rig. *(doc, high; rigging-animation)*
- c6: Pack needs 8 or 9 clips: Idle (1-2), Walk, Run, Jump, Fall, Climb, and Swim plus Swim Idle. *(doc, high; avatar-ugc-accessories)*
- c7: All clips in a pack must share the same Parent model name string or Studio creates separate models and validation fails. *(doc, high; avatar-ugc-accessories)*
- c8: Clips can be authored in Studio or an external tool, but upload and pack assembly must be done in Studio ('Save to Roblox'). *(doc, high; automation-and-creator-workflows)*
- c9: Uploads are limited to one pack per day per creator; upload fee is 80 Robux per pack; Marketplace price floor is 300 Robux. *(doc, high; automation-and-creator-workflows)*
- c10: Animation pack assembly requires Content Type Avatar Item and Asset Category Avatar Animations; submission goes to moderation queue. *(doc, high; automation-and-creator-workflows)*
- c11: Idle weight field takes a positive integer; blank defaults to 1; applies only to Idle clips. *(doc, medium; avatar-ugc-accessories)*
- c12: Packs apply in experiences with Animation Packs set to Player Choice (default); developers can force Standard R15 or Standard R6. *(doc, high; avatar-ugc-accessories)*
- c13: The doc says nothing about Blender, bpy, blender-mcp, FBX export settings, scale, or axes; the Blender-to-Roblox pipeline is not covered. *(doc, high; other)*

## Numbers
- n1: **max clip length**: 10 s clips must be 10 seconds or shorter
- n2: **max body-part translation per frame**: 1.5 studs validation spatial bound
- n3: **upload fee**: 80 Robux per pack one pack per day per creator
- n4: **Marketplace price floor**: 300 Robux animation packs minimum selling price
- n5: **clip count**: 8 or 9 Idle 1-2, Swim includes Swim and Swim Idle

## Techniques
- t1: **Block Avatar R15 base rig authoring**: Avatar tab > Character > Rig Builder, select R15, Block Avatar; open Clip Editor; author clips on it for broad avatar compatibility.
- t2: **Curve conversion and save**: Import FBX into Animation Editor, click Curve Editor, Confirm to convert to CurveAnimation, rename, save; enable Loop on the RBX_ANIMSAVES track in Properties.
- t3: **Shared parent model grouping**: Give every clip the same Parent model name, then right-click the Workspace parent model and Save to Roblox as Avatar Item / Avatar Animations.

## Quotes (brief, for attribution)
