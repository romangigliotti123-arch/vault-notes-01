# web-26c47b56f5

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox overview of rigid accessories: components (single MeshPart under Model, textures via SurfaceAppearance or TextureID, Attachment points), single .fbx/.gltf export from Blender/Maya, Avatar Setup tool, and resource links. Thin on Blender specifics; no blender-mcp, bpy, or Claude content.

## Claims
- c1: Rigid accessories are 3D objects attached to avatar attachment points; users can adjust position/rotation away from the attachment point per body type. *(doc, high; avatar-ugc-accessories)*
- c2: A rigid accessory has two layers: mesh and textures for appearance, and Attachments for how it attaches to the body. *(doc, high; avatar-ugc-accessories)*
- c3: Every rigid accessory needs a single mesh object, a MeshPart nested under a single Model in Studio. *(doc, high; avatar-ugc-accessories)*
- c4: Textures must be imported as image files and applied either via a child SurfaceAppearance object or the MeshPart.TextureID property. *(doc, high; mesh-texture-limits)*
- c5: Attachment points are Attachment objects; they can be auto-generated with the Accessory Fitting Tool. *(doc, high; avatar-ugc-accessories)*
- c6: In Blender or Maya, all avatar components must be exported together in a single .fbx or .gltf file for import into Studio. *(doc, high; blender-roblox-export-import)*
- c7: Layered accessories differ from rigid ones: they stretch and wrap over a target to fit the body and need additional components. *(doc, high; avatar-ugc-accessories)*
- c8: After import, the Avatar Setup tool in Studio processes the creation into an avatar asset ready for Marketplace sale. *(doc, high; avatar-ugc-accessories)*
- c9: Roblox provides Blender and Maya project files and reference files for accessory creation; FBX export settings are documented separately. *(doc, medium; blender-roblox-export-import)*
- c10: The source does not mention blender-mcp, Claude, or bpy scripting; it is not relevant to the Claude-Blender topic. *(doc, high; claude-blender-ai)*

## Numbers
- n1: **mesh objects per rigid accessory**: 1 (single MeshPart under single Model) 

## Techniques
- t1: **Single combined export**: Export all avatar components in one .fbx or .gltf from Blender/Maya, then import into Studio.
- t2: **Auto-generate attachments**: Use the Accessory Fitting Tool to generate attachment points for a rigid accessory.

## Quotes (brief, for attribution)
> When designing a rigid accessory in Blender or Maya, you must export all of the avatar components in a single .fbx or .gltf for import into Studio.  (create.roblox.com)
> In Studio, you must import textures as image files and set them to MeshPart objects by a child SurfaceAppearance object or the mesh's TextureID property.  (create.roblox.com)
