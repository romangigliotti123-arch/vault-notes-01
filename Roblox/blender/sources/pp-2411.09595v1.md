Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
arXiv abstract page for LLaMA-Mesh (Nov 2024): fine-tunes an LLM to emit 3D meshes as plain-text vertex/face lists (OBJ-like) without vocabulary expansion, enabling text-to-mesh, interleaved text/mesh output and mesh understanding. Only the abstract is available; no Blender, Roblox, MCP or bpy specifics.

## Claims
- c1: LLaMA-Mesh represents mesh vertex coordinates and face definitions as plain text, so an LLM can read and write meshes without expanding its vocabulary. *(doc, high; procedural-generation)*
- c2: An SFT dataset enables three abilities: text-to-mesh generation, interleaved text and mesh output, and mesh understanding/interpretation. *(doc, high; procedural-generation)*
- c3: The authors claim mesh quality on par with models trained from scratch while keeping text generation performance. The abstract gives no numbers. *(doc, medium; procedural-generation)*
- c4: The stated motivation is that LLMs already hold spatial knowledge from text sources such as 3D tutorials, which allows conversational 3D generation. *(doc, medium; procedural-generation)*

## Techniques
- t1: **Mesh as plain text for LLM fine-tuning**: Serialize the mesh as text (vertex coordinates plus face definitions), build an SFT dataset, and fine-tune a pretrained LLM. No new tokens are added to the vocabulary.
