## Summary
Roblox creator doc on pre-export cleanup for Blender avatar templates. Explains joining UpperTeeth, LowerTeeth, Tongue, lashes, eyes and Head_Geo into one Head_Geo object (Head_Geo must be active), noting validation fails otherwise. Points to the next step, removing extra head bones. No Claude, bpy, or blender-mcp content.

## Claims
- c1: Head geometry must be combined into a single Head_Geo object before export, or the character fails validation against the expected geometry standard. *(doc, high; blender-roblox-export-import)*
- c2: To combine head parts: in Outliner, Ctrl/⌘-click UpperTeeth_Geo, LowerTeeth_Geo, Tongue_Geo, RightLash_Geo, RightEye_Geo, LeftLash_Geo, LeftEye_Geo, then Head_Geo last so it is the active (yellow) object. *(doc, high; blender-roblox-export-import)*
- c3: Join is done in Object mode via right-click in viewport > Join; selecting Head_Geo last preserves custom properties stored in the head mesh. *(doc, high; blender-roblox-export-import)*
- c4: Pre-export cleanup checklist: combine extra head geometry, remove extra head bones, verify attachment points, run final technical checks. *(doc, high; avatar-ugc-accessories)*
- c5: Extra head bones must be removed as well; leaving them breaks the expected joint hierarchy and causes validation issues. *(doc, high; rigging-animation)*
- c6: Some character templates omit face objects such as lashes, so the join list may need adjusting per template. *(doc, medium; other)*
- c7: Source does not mention blender-mcp, bpy scripting, or Claude usage; it covers only manual Blender UI cleanup steps. *(doc, high; claude-blender-ai)*

## Techniques
- t1: **Join head parts into Head_Geo**: Object mode; Ctrl/⌘-click face parts in Outliner, select Head_Geo last so it is active; right-click viewport > Join.

## Quotes (brief, for attribution)
> When selecting multiple head objects, make sure that the Head_Geo is highlighted as yellow, indicating it as the main object that the others merge into.  (create.roblox.com)
