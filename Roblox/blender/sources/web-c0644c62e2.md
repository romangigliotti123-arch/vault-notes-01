## Claims
- c1: Blender Python scripts should follow PEP8: 4-space indent, no wildcard imports, CamelCase classes, lower_case module names. *(doc, high; bpy-scripting-headless)*
- c2: Blender convention: single quotes for enum values (e.g. file_format = 'PNG') and double quotes for ordinary strings. *(doc, high; bpy-scripting-headless)*
- c3: Line length limit of 79 characters is optional per script in Blender style. *(doc, high; bpy-scripting-headless)*
- c4: Remove list items by iterating backwards or building a new list via comprehension; rebuilding is faster than repeated pop/remove on large lists. *(doc, medium; bpy-scripting-headless)*
- c5: Use startswith()/endswith() over slicing for string prefix checks; slightly faster and avoids length mismatch errors. *(doc, medium; bpy-scripting-headless)*
- c6: try/except is significantly slower than if-checks when run in tight loops, since an exception must be raised each time. *(doc, medium; bpy-scripting-headless)*
- c7: Passing a sliced list (my_list[:]) copies the whole list in memory; avoid for large arrays. *(doc, medium; common-mistakes-fixes)*
- c8: Time scripts with time.time() before and after the work to track performance changes. *(doc, high; bpy-scripting-headless)*

## Numbers
- n1: **max line length (optional)**: 79 characters 
- n2: **startswith speedup**: around 5% 
- n3: **indent**: 4 spaces 

## Techniques
- t1: **Reverse-index pop**: Loop from len(list) down to 0, decrementing index, and pop matching items so indices stay valid and removal is cheaper.
- t2: **Swap-then-pop**: Swap the target item with the last element, then call pop() with no index; useful when list order can change.
