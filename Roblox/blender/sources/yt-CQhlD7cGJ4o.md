# yt-CQhlD7cGJ4o

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox Studio tutorial on collision groups, not Blender. Shows creating "players" and "player door" groups in the Window > 3D > Collision Groups UI, disabling players vs player door collision, assigning the door's CollisionGroup property, and two server scripts: one moves character parts into players, one spawns balls in Default. Nothing on Blender, Claude, bpy, mesh export, or the Roblox asset pipeline.

## Claims
- c1: [0:16] Collision groups let players pass through a door while balls still collide with it, by disabling one group pair in the Collision Groups window. *(demo, high; other)*
- c2: [1:24] Door collision is set via its Collision section by changing its collision group to player door; objects left in Default still collide with it. *(demo, medium; other)*
