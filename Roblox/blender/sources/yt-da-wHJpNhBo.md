## Summary
Vibe-coding video by SmartyRBX on building a Roblox simulator game with AI. Describes ChatGPT-refined prompts fed to Claude, screenshot-based narrow bug fixes, and human taste for polish. Nothing on Blender, blender-mcp, bpy, or the Roblox asset pipeline; relevance to the topic is very low.

## Claims
- c1: Creator's process: describe idea to ChatGPT first, let it refine, then ask it to write a detailed prompt for Claude Code/Claude to build the core loop. *(experience, high; creator-workflows)*
- c2: [2:08] Creator says prompts rewritten with 'maximum detail' yield better model output; vague requests cause incomplete, half-done work. Opinion-based. *(opinion, medium; creator-workflows)*
- c3: [3:33] Iteration loop: screenshot the game, identify issues, give narrow specific correction prompts (e.g., relocate purchase stands to left/right to reduce clutter). *(experience, high; creator-workflows)*
- c4: [7:11] Creator says human taste and game-feel judgment must come from the developer; AI makes systems but lacks taste. Opinion. *(opinion, medium; creator-workflows)*
- c5: [6:30] Creator uses simple direct or voice prompts for small edits and ChatGPT-refined prompts for complex features; project took multiple days to a week of sessions. *(experience, medium; creator-workflows)*
- c6: [5:01] Adding keywords like 'unique', 'detailed', 'fancy' to UI prompts produced more detailed UI, per creator. *(opinion, low; creator-workflows)*
- c7: [9:39] Creator says MCP allows AI to build basic UI and builds in Roblox Studio; this video itself does not show Blender usage. *(opinion, low; claude-blender-mcp)*

## Techniques
- t1: **Two-stage prompting**: Brainstorm and critique idea in ChatGPT, ask it to produce a detailed build prompt, paste that prompt into Claude. Refine the prompt once more for asset/effect detail.
- t2: **Screenshot-driven correction**: Screenshot the built game, describe the specific issue, request a narrow fix; add effects and sounds by describing them explicitly.
