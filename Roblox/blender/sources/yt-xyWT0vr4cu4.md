## Summary
Video listing communities and resources for getting help with Blender Python scripting (bpy): official Blender chat, BlenderArtists, TechArtists forum/Slack, Blender Discord scripting channel, CG Python Academy, Curtis TL's Discord and easy-bpy module, and AI chatbots with a warning about outdated bpy API examples. Not about Roblox or blender-mcp.

## Claims
- c1: [0:24] chat.blender.org is the official Blender chat with a Python help channel where Blender developers sometimes participate. *(opinion, medium; bpy-scripting-headless)*
- c2: [1:34] Blender community Discord has an active 'help with scripting' channel. *(opinion, medium; bpy-scripting-headless)*
- c3: [2:07] Curtis TL created the easy-bpy Python module, a collection of utilities for quickly iterating on Blender Python scripts. *(doc, medium; bpy-scripting-headless)*
