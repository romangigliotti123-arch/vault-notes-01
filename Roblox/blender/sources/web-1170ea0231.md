## Summary
Short Roblox docs page for the Roblox Blender plugin: a Blender add-on that links a Roblox account and transfers 3D objects directly from Blender into a Studio session, skipping manual FBX/OBJ export-import. Described as an open-source implementation of the Open Cloud API. Points to the GitHub repo for install and licensing. Contains no bpy, MCP, rigging, or mesh-limit details.
