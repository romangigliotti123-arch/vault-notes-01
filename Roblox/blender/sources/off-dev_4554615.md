# off-dev_4554615

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Staff announcement of the Universal Importer full release in Roblox Studio. It extends the 3D Import Queue to image, audio, and video, adds a refreshed UI and Find in Workspace / Copy AssetId context options, and will replace the legacy Bulk Importer. It does not cover Blender, blender-mcp, bpy, or export settings.

## Claims
- c1: Universal Importer full release (2026-04-02) adds image, audio, and video support to the Import Queue, which previously handled 3D models only. *(doc, high; blender-roblox-export-import)*
- c2: Universal Importer is accessed via Studio Ribbon Import button, File > Import, Cmd-M (Mac) / Ctrl-M (Windows), or the revamped Asset Manager's import button. *(doc, high; blender-roblox-export-import)*
- c3: Right Click > Find in Workspace focuses the inserted asset; only applies to models because image, audio, and video are not inserted into workspace on import. *(doc, high; blender-roblox-export-import)*
- c4: Right Click > Copy AssetId copies the uploaded asset id; for models it copies the uploaded model's asset id. *(doc, high; blender-roblox-export-import)*
- c5: Universal Importer is planned to fully replace the legacy Bulk Importer; legacy Bulk Importer remains in legacy Asset Manager until revamped Asset Manager reaches GA in coming months. *(doc, high; automation-and-creator-workflows)*
- c6: Source contains no Blender, blender-mcp, bpy, FBX/glTF settings, scale/axis guidance, or Claude-related content; relevance to Blender-to-Roblox pipeline is minimal. *(doc, high; other)*
