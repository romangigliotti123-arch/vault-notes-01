# web-6e2b07b559

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox creator doc for exporting character body models as FBX/glTF from Blender and Maya for Studio Importer. Gives concrete Blender FBX checklist (Path Mode Copy, FBX Unit Scale, no leaf bones, NLA/keyframe/simplify settings) and Maya settings (Y up, automatic units, bake animation). Specifies 15 body parts, 19 attachments, 15 outer cages. Does not cover blender-mcp, bpy, or Claude.

## Claims
- c1: Roblox character body export from Blender: File > Export > FBX; Path Mode Copy; Embed Textures on; Include Custom Properties on; Transform Apply Scalings = FBX Unit Scale; Armature: uncheck Add Leaf Bones. *(doc, high; blender-roblox-export-import)*
- c2: Blender FBX animation export: uncheck NLA Strips, All Actions, Force Start/End Keyframes; set Simplify to 0.0; timeline Start/End must cover all keyframes. *(doc, high; blender-roblox-export-import)*
- c3: Maya FBX character export: Smooth Mesh and Referenced Asset Content on; Animation and Bake Animation on; Units Automatic; Up Axis Y. *(doc, high; blender-roblox-export-import)*
- c4: Dynamic-head avatar characters require animation data in the export. *(doc, high; rigging-animation)*
- c5: Character body must contain 15 body-part mesh objects and 19 attachments parented in an armature, plus 15 outer cages parented to a single empty cage object. *(doc, high; avatar-ugc-accessories)*
- c6: Avatar template files require cleanup steps (combine head geometry) before assets validate. *(doc, high; avatar-ugc-accessories)*
- c7: Before export, apply or delete modifiers on mesh/project objects and export only Roblox-supported objects. *(doc, high; blender-roblox-export-import)*
- c8: Exported character FBX imports into Studio as a Class.Model; HumanoidDescription applied to the Model to use the character in games. *(doc, high; blender-roblox-export-import)*
- c9: Source does not mention blender-mcp, bpy scripting, or Claude; it covers manual GUI export only. *(doc, high; claude-blender-ai)*

## Numbers
- n1: **body parts**: 15 mesh objects 
- n2: **attachments**: 19 
- n3: **outer cages**: 15 
- n4: **Simplify**: 0.0 

## Techniques
- t1: **Blender FBX character export**: File>Export>FBX; Path Mode Copy; Embed Textures; Custom Properties on; Apply Scalings FBX Unit Scale; uncheck Add Leaf Bones; disable NLA Strips, All Actions, Force Start/End Keyframes; Simplify 0.0; click Export FBX.
- t2: **Maya FBX character export**: File>Export All; Files of type FBX export; enable Smooth Mesh, Referenced Asset Content, Animation, Bake Animation; Units Automatic; Up Axis Y.
- t3: **Pre-export cleanup**: Apply or delete modifiers; export only Roblox-supported objects; parent cages to one empty; parent 15 meshes and 19 attachments under armature.
