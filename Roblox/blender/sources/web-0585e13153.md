# web-0585e13153

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox doc for exporting avatar animations from Maya to .fbx. Covers required R15 joint hierarchy and naming, muting root translation so animation plays in place, FBX export settings (bake, step 1, binary, FBX 2020), and testing via Studio Animation Editor import. Nothing on Blender, Claude, or bpy.

## Claims
- c1: Roblox avatar animations cannot move the character; locomotion root translation must be muted (Translate Z muted in Maya Channel Box) so animation plays in place at origin. *(doc, high; rigging-animation)*
- c2: Studio requires exact joint hierarchy and names: Root, HumanoidRootPart, LowerTorso, UpperTorso, Head, Left/Right UpperArm, LowerArm, Hand, UpperLeg, LowerLeg, Foot (standard R15). *(doc, high; rigging-animation)*
- c3: Maya export: enable fbxmaya plugin (Loaded + Auto load), FBX export with Bake Animation on, Step=1, Format Binary, Version FBX 2020 if required. *(doc, high; rigging-animation)*
- c4: Test in Studio: Avatar tab > Character to pick rig, Clip Editor to create animation, then media controls ... > Import > From FBX Animation. *(doc, high; rigging-animation)*
- c5: Doc covers only Maya; no Blender-specific export settings, scale, or axis guidance is given. *(doc, high; blender-roblox-export-import)*
- c6: Source contains no content on blender-mcp, bpy scripting, or Claude-with-Blender workflows. *(doc, high; claude-blender-ai)*

## Numbers
- n1: **Bake animation step**: 1 Maya FBX export Bake Animation Step setting
- n2: **FBX version**: FBX 2020 Maya export, set only if required
- n3: **Joint count in required hierarchy**: 18 joints Root through RightFoot, standard R15 naming

## Techniques
- t1: **Mute root translation for in-place animation**: Open Graph Editor (Windows > Workspaces > Animation), set time to frame 0, select root in Outliner, right-click Translate Z in Channel Box, Mute Selected.
- t2: **Maya FBX animation export**: Load fbxmaya plugin, File > Export All, FBX export, enable Bake Animation with Step 1, binary FBX, export.

## Quotes (brief, for attribution)
