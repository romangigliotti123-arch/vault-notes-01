## Summary
Video on learning Blender Python with ChatGPT. Covers prompt patterns (persona, five beginner project ideas, break big add-ons into core functionality before UI, line-by-line comments, analogies, recall questions, error explanation). Warns against copy-pasting generated code and against lowering difficulty too early. No Roblox, Claude, blender-mcp, or export content.

- c2: [2:30] Ask the LLM to break a large add-on into core functionality first; build a working script without UI before adding panels. *(opinion, medium; claude-blender-ai)*

## Numbers
- n1: **beginner project ideas requested**: 5

- n3: **persona experience stated in prompt**: two decades of Python programming 

## Techniques
- t1: **Persona + structured prompt for bpy project ideas**: Set role (tech artist, 20 yrs Python), request 5 beginner ideas on a Blender topic, require steps and simple script per idea, specify output format.
- t2: **Line-by-line commented explanation**: Paste script, ask LLM to comment every line, highlight Python and bpy API concepts, explain in artist-friendly terms.
- t3: **Close-the-tab reproduction check**: Hide the chat, rewrite the understood code in the Blender scripting editor from memory, note the parts that fail and study those.
- t4: **Analogy prompt**: Ask the LLM to act as a Python tutor and give analogies plus how each maps to the concept.
