Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
arXiv abstract page for GPT4Motion (2023): GPT-4 generates Blender scripts that drive Blender's physics engine (rigid body, cloth, liquid) to produce scene components fed to Stable Diffusion for text-to-video. Only the abstract is available; no code, settings, or Roblox content. Tangentially shows LLM-to-bpy script generation works for physics simulations.

## Claims
- c1: GPT4Motion uses GPT-4 to generate a Blender script from a user text prompt; the script commands Blender's built-in physics engine to produce scene components with coherent physical motion across frames. *(doc, high; claude-blender-ai)*
- c2: The Blender-rendered components are fed into Stable Diffusion to generate the final video. The framework is training-free. *(doc, high; claude-blender-ai)*
- c3: Tested on three physical scenarios: rigid object drop and collision, cloth draping and swinging, and liquid flow. The authors report coherent motion and entity consistency. *(doc, medium; claude-blender-ai)*

## Techniques
- t1: **LLM-planned Blender physics script**: Prompt GPT-4 with a text description. It outputs a Blender (bpy) script that sets up rigid body, cloth or fluid physics. Run it in Blender to get per-frame scene components, then condition a diffusion model on them.
