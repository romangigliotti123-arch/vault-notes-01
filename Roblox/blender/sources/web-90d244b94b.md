# web-90d244b94b

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
DevForum bug report (Apr 2023): a team's lion-head FBX exported from Blender lost material references and imported inconsistently. Avatar Importer kept geometry but materials broke, and some models appeared upside down. Avatar/Home Import 3D showed invisible meshes with console error "invalid unordered_map<K, T> key". Same with hippo and Corinthian helmets. Staff reply (Dec 2023) says latest Studio works.

## Claims
- c1: Blender-exported FBX lost material references; import success and results varied by Studio tool (Avatar Importer vs Avatar/Home Import 3D). *(experience, high; roblox-import-pipeline)*
- c2: Models imported via Avatar Importer were reported upside down by other team members, in addition to broken materials. *(experience, medium; common-mistakes-fixes)*
- c3: Import 3D paths produced an invisible mesh in preview and after import, with console error 'exception while signaling: invalid unordered_map<K, T> key'. *(experience, high; common-mistakes-fixes)*
- c4: Problem also affected other headwear (hippo and Corinthian helmets), suggesting an issue with the accessory import path rather than one mesh. *(experience, medium; avatar-ugc-accessories)*
- c5: Roblox staff replied in Dec 2023 that the latest Studio version imported the file correctly after recent fixes; no root cause or export-side fix was stated. *(doc, medium; common-mistakes-fixes)*
