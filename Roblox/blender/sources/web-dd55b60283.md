Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox creator docs page defining layered accessories (layered clothing): three layers (mesh/textures, rigging armature, cage meshes plus attachments). Explains Studio classes (MeshPart, SurfaceAppearance, WrapLayer, Attachment), single FBX/glTF export of all avatar components, and links to specs, validation tools and Marketplace steps. Little Blender-specific or bpy content; no blender-mcp or Claude material.

## Claims
- c1: Layered accessories require a single MeshPart nested under one Model; cages are WrapLayer objects and attachments are Attachment objects in Studio. *(doc, high; avatar-ugc-accessories)*
- c2: All avatar components must be exported in a single .fbx or .gltf file for import into Studio. *(doc, high; avatar-ugc-accessories)*
- c3: Inner cage defines where the accessory wraps over the body; outer cage defines where other layered accessories wrap over it. *(doc, high; avatar-ugc-accessories)*
- c4: Textures apply via a child SurfaceAppearance object or the MeshPart.TextureID property. *(doc, high; mesh-texture-limits)*
- c5: Attachment points set which body part the accessory attaches to when the body ragdolls or dismembers; they can be auto-generated with the Accessory Fitting Tool. *(doc, high; avatar-ugc-accessories)*
- c6: Rigid accessories do not deform and attach at one point; layered ones stretch and wrap to fit. *(doc, high; avatar-ugc-accessories)*
- c7: Layered accessories must be weighted to the avatar rigging armature so they deform with joints; skinning data is saved to mesh geometry in Studio. *(doc, high; rigging-animation)*
- c8: Validation and testing use the Calisthenics tool and the Clothing validation tool before Marketplace upload; Avatar Setup tool processes imported creations. *(doc, high; automation-and-creator-workflows)*

## Techniques
- t1: **Layered accessory creation workflow**: Model accessory in Blender or Maya with rig, cages and attachments; export all components in one FBX/glTF; import to Studio; run Avatar Setup tool; validate; upload to Marketplace.
