## Summary
Roblox creator docs page on sculpting clothing detail in Blender. A t-shirt mesh (LongSleeve object) is shaped over a mannequin using Sculpt mode tools: Elastic Deform, Inflate, and Cloth. Covers symmetry and brush settings. Part of a sequence after trimming, before watertight. Not about bpy/MCP or the Roblox import pipeline.

## Claims
- c1: Roblox's clothing tutorial shapes a t-shirt mesh over a mannequin in Blender Sculpt mode using Elastic Deform, Inflate, and Cloth tools. *(doc, high; avatar-ugc-accessories)*
- c2: Elastic Deform brush is set to strength 0.5 to stretch vertex groups so the shirt fully covers the mannequin. *(doc, high; avatar-ugc-accessories)*
- c3: Cloth tool should be used with X-Axis symmetry disabled because it can produce unexpected results with symmetry on. *(doc, high; common-mistakes-fixes)*
- c4: Mannequin can be hidden to reach hard-to-access areas while sculpting; brush radius changed with F key. *(doc, medium; avatar-ugc-accessories)*
- c5: Sculpting is done after scaling/positioning the mesh and before the watertight step in the accessory creation sequence. *(doc, medium; avatar-ugc-accessories)*

## Numbers
- n1: **Elastic Deform strength**: 0.5 Used to stretch vertices to cover the mannequin

## Techniques
- t1: **Shape clothing over mannequin with sculpt brushes**: Enter Sculpt mode, disable wireframe, enable X symmetry, use Elastic Deform (0.5) to cover mannequin, then Cloth tool with symmetry off, then Inflate/Elastic/Cloth for final fit.
