# off-art_accessories_creating_index

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox Creator Docs intro tutorial for making a Studio-ready layered accessory (t-shirt) in Blender from a provided mannequin template with cages and armature templates, exported and converted to Class.Accessory in Studio. Covers the six-step process; no Claude, MCP, or bpy content. Marketplace listing requires Plus/Premium, upload fee, and publishing advance.

## Claims
- c1: Roblox's official tutorial builds a layered t-shirt in Blender using downloadable project templates containing all components required for layered accessories. *(doc, high; blender-roblox-export-import)*
- c2: Layered accessories stretch and fit to the avatar via rigging armature and cage meshes so they animate with the character and layer over other clothing. *(doc, high; avatar-ugc-accessories)*
- c3: Final step of listing on Marketplace requires Roblox Plus or Premium account, an upload fee, and a publishing advance; creating and building is free. *(doc, high; avatar-ugc-accessories)*
- c4: Tutorial workflow order: model using mannequin shape, texture, cage with Roblox template cages, rig with armature templates, export from Blender, import and convert to Class.Accessory in Studio. *(doc, high; automation-and-creator-workflows)*
- c5: Source does not mention Claude, blender-mcp, or bpy scripting; the workflow is manual Blender modeling. *(doc, high; claude-blender-ai)*

## Techniques
- t1: **Layered accessory creation sequence**: 1) Start from provided Blender mannequin template. 2) Model clothing over it. 3) Texture. 4) Cage with Roblox template cages. 5) Rig with Roblox armature templates. 6) Export. 7) Import to Studio and convert to Class.Accessory.
