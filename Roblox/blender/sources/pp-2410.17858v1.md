## Summary
arXiv abstract page for Blendify, a Python framework wrapping Blender's bpy API for scene creation and ray-traced rendering in computer vision research. Only the abstract is present. It has no Roblox, Claude, MCP, export or import content.

## Claims
- c1: Blendify is a lightweight Python framework on top of Blender giving a high-level API for scene creation and rendering, reducing the complexity of Blender's native API. *(doc, high; claude-blender-ai)*
- c2: Blendify automates object creation, color and material linking, and shadow-catcher objects, while keeping ray-traced high-quality rendering. Aimed at computer vision and graphics research visualization, not game asset export. *(doc, high; claude-blender-ai)*
