# web-628960347e

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox doc on assigning basic or PBR textures in Blender or Maya so they import into Studio. Blender: Principled BSDF with Image Texture nodes wired to Base Color, Metallic, Roughness, and normal via Normal Map node. Maya: Standard Surface with Bump 2d (Tangent Space). Then export and import via Studio importer. No bpy, MCP, or numeric limits.

## Claims
- c1: Roblox doc: to texture in Blender, use a Principled BSDF material, add Image Texture nodes (Add > Texture > Image Texture), and connect Color to Base Color for basic/albedo textures. *(doc, high; blender-roblox-export-import)*
- c2: Roblox doc: Metallic and Roughness image textures connect via their Color output to the Principled BSDF Metallic and Roughness sockets respectively. *(doc, high; blender-roblox-export-import)*
- c3: Roblox doc: normal map images must go through a Normal Map node (Add > Vector > Normal Map), with its Normal output connected to Principled BSDF Normal. *(doc, high; blender-roblox-export-import)*
- c4: Roblox doc: after replacing PBR textures in Blender, export the entire model using the export requirements page, then import into Studio via the Studio importer. *(doc, high; blender-roblox-export-import)*
- c5: Roblox doc: Maya path uses Standard Surface shader, Bump 2d node set to Tangent Space Normals for normal maps, and Assign Material to Selection. *(doc, high; blender-roblox-export-import)*
- c6: Page covers only manual node setup in Blender/Maya GUI; it does not mention blender-mcp, bpy scripting, or Claude. *(doc, high; other)*
- c7: Page says textures must meet Roblox texture specifications (linked separately); no numeric limits are given on this page. *(doc, medium; mesh-texture-limits)*
- c8: Page includes a warning that these steps are for makeup textures on generic meshes; makeup reassignment has a separate guide. *(doc, medium; avatar-ugc-accessories)*

## Techniques
- t1: **Principled BSDF texture wiring**: Verify material uses Principled BSDF; add Image Texture node; open or drag-drop file; connect Color to Base Color, Metallic, or Roughness; route normal via Normal Map node.
- t2: **Maya Standard Surface setup**: Create Standard Surface in Hypershade; add Bump 2d for normals set to Tangent Space; drag textures to graph; assign material to selection; export model.
