# yt-bvHINFe-ex0

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Researcher talk on generating synthetic LiDAR point clouds in Blender with geometry nodes (Raycast node, noise, dropout, attribute transfer) to train a log-detection model for forestry cranes. Does not cover Claude, blender-mcp, bpy, Roblox, or the Roblox export pipeline. Off-topic for this research goal.

## Claims
- c1: [9:15] Blender geometry nodes Raycast node can simulate a LiDAR scan by shooting rays from a sensor pose and recording hit positions, avoiding physical time-of-flight simulation. *(demo, high; other)*
- c2: [10:38] Real sensor modeled as 360° horizontal sweep with 105° vertical opening angle; ray directions generated by a geometry-nodes function from FOV and resolution. *(demo, medium; other)*
- c3: [12:42] Scan realism added by jittering point positions with noise and randomly dropping points to mimic absorption and non-return. *(demo, medium; other)*
- c4: [15:42] Generated 5,000 procedurally varied scenes; some contain almost no logs, others more than 30. *(data, medium; other)*
- c5: [16:24] Manually fitting three cylinders to a real point cloud in Blender took about 30 seconds, motivating synthetic labels. *(experience, low; other)*

## Numbers
- n1: **generated scenes**: 5000 
- n2: **vertical FOV of real sensor**: 105° 
- n3: **horizontal coverage**: 360° 
- n4: **manual cylinder fitting time**: ~30 s for 3 cylinders 
- n5: **detector training time**: a few days 

## Techniques
- t1: **Geometry-nodes LiDAR simulation**: Place scene collection in Raycast node; generate ray directions from FOV and resolution; set sensor position; output hit points. Add noise and random point dropout.
- t2: **Attribute transfer to point cloud**: Pass object IDs, semantic IDs, or reflectivity intensity through Raycast node onto hit points to get per-point labels.
- t3: **Point export from geometry nodes**: Update dependency graph, read evaluated geometry points into an array, export positions and attributes to a point cloud file format.
