# off-dev_4601232

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox staff post (2026-04-27) announcing opt-in Mesh Streaming and improved cloud LoD generation for published experiences via Workspace.MeshStreamingAndImprovedLoDs. Covers phased rollout (default ~July 2026), RenderFidelity deprecation, triangle reductions, and a known Mesh Detail Level debug issue. No Blender, bpy, MCP, or export-pipeline content.

## Claims
- c1: Not applicable: source covers mesh LoD and streaming only, no rigging content. *(doc, high; rigging-animation)*
- c2: Roblox generates 4 LoDs per mesh using a rudimentary simplification algorithm; old LoD quality was poor for some meshes. *(doc, high; mesh-texture-limits)*
- c3: Mesh Streaming is an engine-level system that streams specific LoDs per mesh by scene importance under a strict mesh memory budget. *(doc, high; mesh-texture-limits)*
- c4: Enable via Workspace.MeshStreamingAndImprovedLoDs = Enabled (Phase 1 opt-in); Default maps to Enabled in Phase 2 (~July 2026 target), Disabled is opt-out. *(doc, high; mesh-texture-limits)*
- c5: When enabled, MeshPart.RenderFidelity is ignored on all MeshParts in the place and meshes use the next-gen LoD transcoder. *(doc, high; mesh-texture-limits)*
- c6: Mesh Streaming works with or without Workspace.StreamingEnabled and alongside Instance Streaming and SLIM. *(doc, high; mesh-texture-limits)*
- c7: Lower LoDs are used only at initial load, when meshes are far away, occupy little screen space, or under memory pressure. *(doc, high; mesh-texture-limits)*
- c8: Studio requires a restart after changing MeshStreamingAndImprovedLoDs before the change takes effect; changes must be published to reach players. *(doc, high; mesh-texture-limits)*
- c9: Comparison method: set all MeshParts to RenderFidelity = Performance, then toggle the workspace property Enabled/Disabled, restarting Studio each time. *(doc, high; mesh-texture-limits)*
- c10: Test case: a car mesh of 4200 triangles simplified to two lower LoDs; new algorithm preserves silhouette, normals and UVs better than old. *(demo, medium; mesh-texture-limits)*
- c11: In a side-by-side scene, triangles dropped from ~1.08M to ~403k at first frame and ~681k to ~244k at last frame with streaming enabled. *(data, medium; mesh-texture-limits)*
- c12: Known issue: Settings > Rendering > Debug > Mesh Detail Level does not work as expected when the property is Enabled; fix pending. *(doc, high; automation-and-creator-workflows)*
- c13: Creators should report broken-looking meshes with a video repro and asset IDs; EAP is being shut down now that the feature is in published experiences. *(doc, high; automation-and-creator-workflows)*
- c14: Source is an official Roblox staff devforum post dated 2026-04-27; no Blender, bpy, blender-mcp, or FBX/glTF export content. *(doc, high; other)*

## Numbers

- n2: **Car test mesh triangle count**: 4200 Original UV-mapped car simplified to two lower LoDs for comparison

- n5: **Target default-on date**: ~July 2026 Phase 2 opt-out default expected around this time

## Techniques
- t1: **Enable mesh streaming and next-gen LoDs**: Explorer > Workspace > Behavior > MeshStreamingAndImprovedLoDs = Enabled; restart Studio; test in Studio; publish place.
- t2: **A/B compare LoD transcoder**: Set all MeshParts RenderFidelity=Performance; toggle workspace property Enabled/Disabled; restart Studio between toggles; compare visuals and triangle stats.
