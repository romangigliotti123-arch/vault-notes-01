## Summary
arXiv abstract page for FRELLED 5.0, a Python-script suite for visualising astronomical FITS volumetric data in Blender 2.79. It has nothing on Roblox, Claude, blender-mcp or game asset export. Only loosely relevant as an example of large-scale bpy scripting and modular Blender add-on code.

## Claims
- c1: FRELLED 5.0 is a suite of Python scripts for Blender that visualises astronomical volumetric data (FITS cubes) in real time. Its operating environment moved from Blender 2.49 to 2.79. *(doc, high; other)*
- c2: FRELLED 5.0 can export data to Blender 2.9+, which supports stereoscopic 3D display in VR headsets. It uses astropy and other standard Python modules, and its code is more modular to ease migration to newer Blender versions. *(doc, high; other)*
