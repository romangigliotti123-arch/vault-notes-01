# web-96978ac98f

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox doc for layered clothing in Blender 3.0: import FBX into mannequin rig template, parent with Automatic Weights, append and rename Inner/Outer cage meshes, shape outer cage tightly, export FBX, convert via Accessory Fitting Tool. Doesn't cover blender-mcp, bpy scripting, or Claude.

## Claims
- c1: Roblox doc: to make a layered clothing model, parent (Blender) or bind (Maya) the mesh to the mannequin armature, then add Inner and Outer Cage meshes around the accessory. *(doc, high; roblox-import-pipeline)*
- c2: Parenting uses Blender Automatic Weights: select mesh, shift-click armature, Ctrl+P, choose Automatic Weights. Doc warns complex moving parts may need Weight Painting. *(doc, high; rigging-animation)*
- c3: Inner and Outer Cage meshes come from Clothing_Cage_Template.blend, appended via File > Append (Object folder); must be renamed to match the imported mesh name exactly. *(doc, high; avatar-ugc-accessories)*
- c4: Do not delete vertices or alter UVs on Inner or Outer Cages; doc says this can cause import errors in Studio or when equipping. *(doc, high; avatar-ugc-accessories)*
- c5: Outer cage should sit on the accessory with minimal extra space; inner cage is where the accessory fits on top. Doc gives no numeric tolerance. *(doc, medium; avatar-ugc-accessories)*
- c6: Export the Blender model to FBX, then import and convert into Studio via Accessory Fitting Tool and the converting-clothing tutorial. *(doc, high; roblox-import-pipeline)*
- c7: Accessory model may need resizing to fit the mannequin after FBX import, depending on how it was modeled. *(doc, medium; common-mistakes-fixes)*
- c8: Guide written for Blender 3.0; other versions may differ slightly in UI and settings. *(doc, high; other)*
- c9: Keep faces consistently sized and keep symmetry when editing the outer cage; use Blender symmetry toggles. *(doc, medium; avatar-ugc-accessories)*

## Numbers
- n1: **Blender version used**: 3.0 

## Techniques
- t1: **Layered clothing cage setup**: Import FBX into Rig_and_Attachments template; parent mesh to mannequin armature with Automatic Weights; append inner/outer cage from template; rename cages to match mesh; shape outer cage over accessory; export FBX; convert with Accessory Fitting Tool.

## Quotes (brief, for attribution)
