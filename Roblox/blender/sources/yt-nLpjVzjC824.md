## Summary
Blender Today Live #277 (Mar 2026) is a weekly Blender release recap covering Blender 5.1 news, LTS point releases, sculpt, compositor, Cycles, Eevee and geometry nodes changes. It does not cover Roblox, blender-mcp, Claude, or the Roblox asset pipeline. Only minor items touch the pipeline: the legacy FBX add-on is hidden by default in 5.1, and GLTF gained point cloud import.
