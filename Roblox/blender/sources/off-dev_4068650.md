# off-dev_4068650

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox staff post on Studio Beta Reimport: one-click, in-place updates of imported FBX/glTF Models and SurfaceAppearances, remembering file paths per device. Covers naming/pivot pitfalls, mesh ID behavior, Known Asset Cache, and the Nov/Dec 2025 and May 2026 status updates. No blender-mcp, bpy, or Claude content.

## Claims
- c1: Reimport (Studio Beta, announced 2025-11-13) updates FBX/glTF-imported Models and SurfaceAppearances in place from the original file path, instead of creating new instances like a regular import. *(doc, high; blender-roblox-export-import)*
- c2: Reimport is triggered by right-click Reimport on a Model or SurfaceAppearance in Explorer, or hotkey Alt+Shift+R; first use prompts for a file, and the path is remembered in the Configure dialog. *(doc, high; blender-roblox-export-import)*
- c3: Reimport config (file paths) is stored device-local and never saved in the placefile; a Reimport ID on the instance indexes that store, so paths can differ per device. *(doc, high; blender-roblox-export-import)*
- c4: Reimport matches meshes by path/name; unmatched instances are left alone, so renaming a mesh in Blender creates a new MeshPart and keeps the old one. Pre-rename the MeshPart in Studio to avoid duplicates. *(doc, high; blender-roblox-export-import)*
- c5: Reimport relies on Model pivot points; models with modified pivots align badly. Workaround: Reimport relative to a MeshPart that has not moved in the 3D file. *(doc, high; blender-roblox-export-import)*
- c6: SurfaceAppearance Reimport detects the four maps from one selected image by shared name plus suffix. Color suffixes: diffuse, diff, albedo, base, col, color, alb. Metalness: metallic, metalness, metal, mtl, met. Roughness: roughness, rough, rgh. Normal: normal, nor, nrm, nrml, norm. *(doc, high; mesh-texture-limits)*
- c7: Mesh content that changed gets a new Mesh ID; the existing ID can only be reused when geometry is unchanged. Updating an existing ID with new geometry is not possible (as of Nov 17, 2025). *(doc, high; mesh-texture-limits)*
- c8: Known Asset Cache in the 3D importer (since Sept 2025) reuses existing asset IDs for identical content in the same session; over 25 million duplicate uploads prevented. Floating-point differences, e.g. moving a mesh in Blender, cause cache misses. *(doc, high; mesh-texture-limits)*
- c9: At launch Reimport did not update Bones, Attachments or Motor6Ds on rigs/avatars, and did not support animations because the 3D importer Model output omits them. Dec 3, 2025 update added rig/avatar/bone/joint/cage/dynamic head support. *(doc, high; rigging-animation)*
- c10: Reimport works on Model and SurfaceAppearance only; Accessory, Decal, Audio, Video are not supported yet (as of the original post). *(doc, high; automation-and-creator-workflows)*
- c11: Reimport always adds an undo checkpoint before changes; Ctrl/Cmd+Z restores state if a reimport goes wrong. *(doc, high; automation-and-creator-workflows)*
- c12: Reimport memory survives copy-paste, rbxl/rbxm save-load and Asset Manager; packages keep the reimport ID on every instance, so pushing a package update propagates to all instances. *(doc, high; automation-and-creator-workflows)*
- c13: Reimport was enabled for everyone on Dec 3, 2025 (no longer needs the Beta Features toggle); fully released May 20, 2026. *(doc, high; automation-and-creator-workflows)*
- c14: Reimport does not change Blender-side scripting or blender-mcp workflows; the source contains no Claude, bpy, or MCP content. *(doc, high; automation-and-creator-workflows)*

## Numbers
- n1: **duplicate assets prevented by Known Asset Cache**: 25 million+ since Sept rollout in 3D importer
- n2: **Reimport hotkey**: Alt+Shift+R while Model or SurfaceAppearance selected

## Techniques
- t1: **Reimport relative to a stable mesh**: If model pivot was moved, right-click an unmoved MeshPart under the Model and choose Reimport > Reimport relative to this; uses that part's pivot as anchor.
- t2: **Pre-rename MeshParts in Studio**: Rename the Studio MeshPart to the new Blender mesh name before reimporting so the match updates it instead of creating a duplicate.
- t3: **Four-map SurfaceAppearance reimport**: Select one texture in the file dialog; same-folder maps with matching base name and suffix are auto-detected and remembered for future updates.
