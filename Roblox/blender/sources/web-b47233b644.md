# web-b47233b644

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Forum announcement thread for NExport, a community Roblox Studio plus Blender plugin pair for exporting Roblox place content into Blender. Per the author, it exports meshes (including others' meshes), materials, lighting, and folder hierarchy as Blender empties, and reduces vertex counts. V1.1 added decals, union support and chunked HTTP transfer. V1.2 added packaged Blender and Roblox plugins and converted SpecialMeshes to MeshParts to fix scaling. Mostly self-promotion; no Claude or bpy content.

## Claims
- c1: NExport is a Roblox Studio plugin plus Blender addon pair. It moves meshes, materials, lighting and folder hierarchy from Roblox into Blender. Folders become Blender empties with assets parented under them. *(doc, medium; roblox-import-pipeline)*
- c2: Author says Roblox's native OBJ/glTF export is poor and that NExport bypasses native asset permission blocks for other creators' meshes. Author's claim, not verified. *(opinion, low; roblox-import-pipeline)*
- c3: NExport attempts to minimise vertex count during export for performance. No figures given. *(doc, low; roblox-mesh-limits)*
- c4: V1.2 converts SpecialMeshes to MeshParts, which the author says fixes previous scaling issues. *(doc, medium; common-mistakes-fixes)*
- c5: V1.1 added decal support and UnionOperation support. Earlier versions failed on unions, which the author attributed to missing union handling. *(doc, medium; roblox-import-pipeline)*
- c6: V1.1 HTTP sender/receiver transfers in chunks, removing the 1024 KB payload limit so files of any size can export. *(doc, medium; roblox-import-pipeline)*
- c7: V1.2 (2026-05-17) packaged NExport as a Roblox plugin and a Blender plugin, the latter distributed as a zip in the repo. *(doc, high; roblox-import-pipeline)*

## Numbers
- n1: **HTTP payload limit**: 1024 KB (removed in V1.1 via chunking) Previous transfer cap, lifted by chunked sender/receiver in V1.1 (2026-05-12)
- n2: **Release date V1.2**: 2026-05-17 Blender and Roblox plugin release, per author post

## Techniques
- t1: **Folder-to-empty hierarchy mapping**: Roblox folders are recreated as Blender empties; child assets are parented to the empty to keep structure on import.
- t2: **SpecialMesh to MeshPart conversion**: Convert SpecialMesh instances to MeshParts before export to avoid scale errors (per V1.2 notes).
- t3: **Chunked HTTP transfer**: Split plugin-to-Blender payloads into chunks so files are not limited by the 1024 KB single-request cap.
