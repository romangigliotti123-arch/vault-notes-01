# off-dev_3816937

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox staff announcement (2025-07-15, relaunched 2025-07-28) on PBR textures for avatar accessories and hair. Covers SurfaceAppearance setup, Accessory Fitting Tool with MeshPart accessory option, texture size caps (256x256 for Normal/Roughness/Metalness, 1024x1024 ColorMap), opaque-only validation, fees and price floor. Not about Blender, bpy, or blender-mcp.

## Claims
- c1: PBR accessory Normal, Roughness, and Metalness maps are capped at 256x256 px; ColorMap max is 1024x1024. *(doc, high; mesh-texture-limits)*
- c2: NormalMaps and ColorMaps are validated to be opaque on Marketplace upload. *(doc, high; mesh-texture-limits)*
- c3: Transparency not supported yet; SurfaceAppearance.AlphaMode defaults to Overlay for PBR accessories. *(doc, high; mesh-texture-limits)*
- c4: PBR workflow matches layered clothing: Import 3D tool, add SurfaceAppearance if textures don't auto-apply, then convert with Accessory Fitting Tool. *(doc, high; avatar-ugc-accessories)*
- c5: When converting rigid accessories with PBR, use Generate MeshPart Accessory, not Generate Legacy Accessory. *(doc, high; avatar-ugc-accessories)*
- c6: PBR textures apply to all accessory categories: Hats, Hair, Face, Shoulder, Front, Waist, Back accessories. *(doc, high; avatar-ugc-accessories)*
- c7: PBR upload fee is 750 Robux, same as non-PBR items; PBR items have a separate price floor. *(doc, high; avatar-ugc-accessories)*
- c8: Same item can be uploaded both with and without PBR as separate items; PBR is optional. *(doc, high; avatar-ugc-accessories)*
- c9: Creators earn higher revenue share by pricing PBR items above the price floor. *(doc, medium; other)*

## Numbers
- n1: **Normal/Roughness/Metalness map max size**: 256x256 px PBR accessories only
- n2: **ColorMap max size**: 1024x1024 px PBR accessories
- n3: **PBR upload fee**: 750 Robux same as regular items

## Techniques
- t1: **PBR accessory publish steps**: 1) Import 3D model with PBR textures via Import 3D tool. 2) If textures missing, add SurfaceAppearance and assign ColorMap, NormalMap, RoughnessMap, MetalnessMap. 3) Convert with Accessory Fitting Tool using Generate MeshPart Accessory. 4) Upload to Marketplace.
- t2: **Keep PBR maps small and opaque**: Size Normal/Roughness/Metalness maps to 256x256 max; ColorMap up to 1024x1024; ensure NormalMap and ColorMap are fully opaque to pass validation.

### Code: Default alpha mode for PBR accessories
```text
SurfaceAppearance.AlphaMode = Enum.AlphaMode.Overlay
```
