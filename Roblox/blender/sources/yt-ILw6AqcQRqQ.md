Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Off-topic for Blender-to-Roblox pipeline. Video lists five Roblox Studio building plugins: Brush Tool (paint/stamp assets with random rotation and scale), Redo (duplicate and transform along a path), Resize Line (align two faces), 3D Text (extruded fonts, neon material), and F3X/Build V4 (multi-part scaling and selection). No Blender, bpy, MCP, FBX/glTF export, or asset-import content.

## Claims
- c1: Source covers Roblox Studio in-engine building plugins only; it does not discuss Blender, Claude, blender-mcp, bpy, or external asset export. *(doc, high; other)*
- c2: [0:00] Brush Tool plugin paints assets onto the map; spacing, rotation and scale can be set to random (author's suggested scale range 0.8 to 1.2). *(demo, high; other)*
- c3: [3:15] Redo plugin duplicates and rotates/scales a selected piece to repeat it along a line or curve (stairs, fences, roads). *(demo, high; other)*
- c4: [4:45] Resize Line plugin aligns two selected faces so pieces meet cleanly, avoiding manual nudging. *(demo, medium; other)*
- c5: [5:44] 3D Text plugin creates extruded text in any font with adjustable thickness, color and material (e.g. neon) directly in the world. *(demo, high; other)*
- c6: [7:02] F3X and Build V4 plugins scale multiple parts individually and select nested models without holding Alt; author prefers Build V4. *(opinion, medium; other)*
