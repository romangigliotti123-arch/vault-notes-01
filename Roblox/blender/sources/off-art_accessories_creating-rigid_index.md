# off-art_accessories_creating-rigid_index

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox Creator Docs intro to rigid accessories: 3D objects attached to avatar attachment points, with position and rotation adjustable per body type. Tutorial path: model in Blender, import to Studio, convert to a Class.Accessory for Marketplace, toolbox, or in-game use. Says the same concepts apply to other modeling apps. No bpy, blender-mcp, Claude, or export-settings detail.

## Claims
- c1: Rigid accessories are 3D objects attached to attachment points on an avatar; buyers can adjust position and rotation away from the attachment point based on body type. *(doc, high; avatar-ugc-accessories)*
- c2: Documented workflow: create a simple model in Blender, import it into Studio, then convert it into a Marketplace-ready Class.Accessory. *(doc, high; blender-roblox-export-import)*
- c3: Listing a rigid accessory on the Marketplace requires a Roblox Plus or Premium account, an upload fee, and a publishing advance. *(doc, high; avatar-ugc-accessories)*
- c4: Source states the Blender steps are a reference example; the same concepts apply to other third-party modeling applications. *(doc, medium; avatar-ugc-accessories)*
- c5: Source does not mention Claude, blender-mcp, mcp-for-blender, or bpy scripting; it is a manual Blender-to-Studio tutorial only. *(doc, high; claude-blender-ai)*

## Techniques
- t1: **Blender to Class.Accessory conversion**: Model a simple mesh in Blender, import into Roblox Studio, then convert the mesh into a Class.Accessory so it can be equipped, sold, or saved to toolbox. Page gives no export settings.
