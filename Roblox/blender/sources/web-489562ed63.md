# web-489562ed63

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox creator-docs page listing downloadable character body reference files: advanced/standard R15 rigs, Blender/Maya/FBX rig and cage templates, and head/body templates. Relevant mainly to Blender rig and cage setup; does not cover blender-mcp or bpy scripting.

## Claims
- c1: Rig_and_Attachments_Template.blend is a starting Blender armature with a standard R15 rig, correct naming conventions and attachment points, for rigging bodies and layered accessories. *(doc, high; blender-roblox-export-import)*
- c2: Body_Cage_Template.blend has individual cages for each of the 15 humanoid body parts; edit the full-body std_cage_deformable mesh to propagate vertex changes, then remove it before importing FBX into Studio. *(doc, high; mesh-texture-limits)*
- c3: Combined-Template.blend bundles the rigging armature, body cages and attachment points in one file. *(doc, high; blender-roblox-export-import)*
- c4: Each template zip contains a .blend, .fbx and PBR .png textures; Blender users should use the .blend project. *(doc, high; blender-roblox-export-import)*
- c5: Roblox avatar template files need cleanup steps (combine head geometry) before assets validate for Marketplace publishing. *(doc, high; avatar-ugc-accessories)*
- c6: Lola.fbx standard R15 skinned model has no inner/outer cage mesh data, so it cannot equip layered accessories. *(doc, high; rigging-animation)*
- c7: For Roxie-HigherFidelity.zip (Rthro Normal body), set Rig Scale to Rthro Narrow on import. *(doc, high; blender-roblox-export-import)*
- c8: *_With-Cages mannequin FBX files may not import correctly into Studio until cage objects are configured. *(doc, high; avatar-ugc-accessories)*
- c9: Maya-exported general FBX templates are for non-Blender/Maya workflows; with Blender or Maya use the program-specific templates. *(doc, medium; blender-roblox-export-import)*

## Numbers
- n1: **humanoid body parts with individual cages**: 15 
- n2: **Rthro Narrow rig scale for Roxie import**: Rthro Narrow 

## Techniques
- t1: **Start from template armature**: Open Rig_and_Attachments_Template.blend, keep R15 bone naming and attachment points, rig the character body or layered accessory, then export FBX.
- t2: **Cage via deformable helper**: Edit std_cage_deformable in Body_Cage_Template.blend so vertex changes apply to the 15 part cages; delete the helper before importing the FBX into Studio.

## Quotes (brief, for attribution)
> To save time, edit the full-body std_cage_deformable mesh to automatically apply vertex changes to the individual body part meshes. When importing the .fbx into Studio, you can remove this helper mesh.  (create.roblox.com)
