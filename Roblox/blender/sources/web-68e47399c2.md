# web-68e47399c2

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Official Roblox doc on applying cage-mesh deformation in Studio: WrapTarget and WrapLayer MeshParts grouped in a Model with a WeldConstraint, triggered by WrapLayer.Order. Covers stacking multiple layers and UV-matching requirement. Relevant only to the Roblox-side layered accessory workflow; no Blender, bpy, or Claude content.

## Claims
- c1: Deformation (WrapLayer) requires target and layered meshes to share the same UV layout; Roblox pairs layers to the target by UV, so mismatched UVs won't deform. *(doc, high; mesh-texture-limits)*
- c2: All Roblox avatars share a standard body cage; accessories caged to that shared UV layout fit every avatar body. Example meshes in the guide use their own cages and are not compatible with the standard body cage. *(doc, high; avatar-ugc-accessories)*
- c3: Cage objects must exist for each of the 15 avatar body parts on R15 avatars. *(doc, high; avatar-ugc-accessories)*
- c4: Layered accessory pipeline composes the layered mesh automatically on Humanoid body cages; WrapLayer.AutoSkin transfers skinning data. *(doc, high; avatar-ugc-accessories)*
- c5: Deformation setup: parent target MeshPart (with WrapTarget) and layered MeshPart (with WrapLayer) in one Model, add WeldConstraint to layered mesh with Part0=layered, Part1=target, then change WrapLayer.Order (e.g. 2 or 5) to trigger deformation. *(doc, high; mesh-texture-limits)*
- c6: Deformation is retained after computing; the duplicate layered mesh and WeldConstraint can be deleted and WrapLayer.Order reset, leaving one deformed mesh. *(doc, high; mesh-texture-limits)*
- c7: Multiple layers can be added to one target; each added layer recalculates the target surface. For stacking, the second layer's WeldConstraint Part0 is the original layered mesh and Part1 is the new layer; WrapLayer.Order sets which renders on top. *(doc, high; mesh-texture-limits)*
- c8: Source is an official Roblox creator doc on cage-mesh deformation; it does not mention Blender, blender-mcp, bpy, Claude, or Blender export settings. *(doc, high; other)*

## Numbers
- n1: **body parts with cage objects**: 15 Cage objects required for each avatar body part
- n2: **example WrapLayer.Order values**: 2 or 5 Non-default order value suggested to trigger deformation

## Techniques
- t1: **WrapLayer deformation via WeldConstraint**: Group target (WrapTarget) and layered (WrapLayer) MeshParts in a Model. Add WeldConstraint on layered mesh: Part0=layered, Part1=target. Change WrapLayer.Order to trigger deform. Optionally delete weld/duplicate after compute.

## Quotes (brief, for attribution)
> Roblox pairs each layer to the target by UV, so mismatched UVs won't deform correctly.  (create.roblox.com)
