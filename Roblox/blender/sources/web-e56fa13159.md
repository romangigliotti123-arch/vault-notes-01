Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox doc for the Layered Accessory Validation Tool, a Blender (3.0) or Maya (2022) add-on that checks layered accessories before export: layers, transforms, unused data, keyframes, attachment points, cage intersection, texture format. Covers install steps and Maya Python setup. Does not cover blender-mcp, Claude, or bpy scripting.

## Claims
- c1: Roblox's Layered Accessory Validation Tool is a supplemental add-on for Blender (designed for Blender 3.0) or Maya (designed for Maya 2022) that checks common layered accessory issues before export. *(doc, high; avatar-ugc-accessories)*
- c2: The tool does not comprehensively verify layered accessories; the model must still meet general mesh specs and Roblox layered accessory specs before importing to Studio. *(doc, high; avatar-ugc-accessories)*
- c3: Blender install: Edit > Preferences > Add-Ons > Install..., select ValidationTool_Blender.zip, enable the Validation Tool add-on, then expand the viewport sidebar to access it. *(doc, high; common-mistakes-fixes)*
- c4: Maya install requires Python 3.0+ (with 'Add Python to PATH' enabled), then running install.bat on Windows or install.command on Mac, entering the Maya version number when prompted. *(doc, high; avatar-ugc-accessories)*
- c5: On Mac, install.command may need chmod 777 to run; this requires administrator access. *(doc, high; common-mistakes-fixes)*
- c6: In Maya, first launch uses 'import ValidationTool' in Script Editor; later launches use ValidationTool.validationTool(); a shelf shortcut can be created from the UI. *(doc, high; bpy-scripting-headless)*
- c7: Workflow: select the object, click Check Assets; failing checks turn red in Blender (yellow in Maya), passing ones grey (Blender) or green (Maya); some fixable via button. *(doc, high; creator-workflows)*
- c8: Layers check flags extra scene layers; auto-fix tries removal. Transforms check requires geometry location, rotation and scale frozen at 0,0,0; auto-fix may change the rig. *(doc, high; roblox-export-settings)*
- c9: Unused Material check covers orphan data (Blender), construction history (Maya), and unused materials; auto-fix removes extra data. *(doc, high; roblox-export-settings)*
- c10: Keyframes check flags unnecessary keyframes; Attachment Points check requires attachment points present with correct naming and auto-fix parents unexpected ones. *(doc, high; rigging-animation)*
- c11: Intersection check finds vertices where character geometry intersects the inner/outer cage meshes; in Blender the button enters Edit Mode and highlights them. Sleeve, neck and torso hole edges may be false positives. *(doc, high; avatar-ugc-accessories)*
- c12: Texture Format check verifies resolution and other texture requirements; users can pick an external image file; output messages guide manual fixes. *(doc, medium; texturing-baking-uv)*
- c13: The source does not cover blender-mcp, Claude integration, bpy headless scripting, or Blender-to-Roblox FBX/glTF import; it is only the Roblox validation add-on doc. *(doc, high; other)*

## Numbers
- n1: **Blender version tested**: 3.0 
- n2: **Maya version tested**: 2022 
- n3: **Python minimum for Maya tool**: 3.0+ 
- n4: **Transform target values**: 0,0,0 (location, rotation, scale) 

## Techniques
- t1: **Validation tool run**: Select object in scene, open Validation Tool, click Check Assets, review red/yellow results, click fix buttons where offered, then manually fix remaining issues.
- t2: **Intersection review**: Click Intersection check in Blender to enter Edit Mode and see highlighted intersecting vertices; ignore sleeve, neck and torso hole edges.

### Code: Maya first-launch and later-launch commands
```text
import ValidationTool
ValidationTool.validationTool()
```

### Code: Mac fix for install.command permissions
```bash
chmod 777 install.command
```
