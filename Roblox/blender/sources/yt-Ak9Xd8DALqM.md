# yt-Ak9Xd8DALqM

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox Studio tutorial: retexture existing builds with stud material variants instead of toolbox stud models. Import the texture folder into MaterialService to get five variants (inlet, studs, small studs, universal, weld), then set Properties > MaterialVariant per part. Not about Blender, bpy, Claude, or the FBX/glTF pipeline.

## Claims
- c1: [0:00] Toolbox stud search gives a stud texture but requires remodeling any existing model, the video's stated main drawback. *(demo, medium; other)*
- c2: [0:40] Dragging a downloaded folder into Studio's MaterialService creates five material variants: inlet, studs, small studs, universal, weld. *(demo, high; other)*
- c3: [0:40] Material variants are applied via Properties > MaterialVariant on any existing part, so existing models need no remodeling. *(demo, high; other)*
- c4: [1:22] Creator sells building packs of 10 buildings each; one building per pack was used in the demo. *(opinion, low; other)*
- c5: [2:03] Creator's workflow: multi-select parts, set MaterialVariant to studs, then switch some walls/windows/floors to weld for variety; small studs suit tiny parts. *(demo, medium; other)*

## Numbers
- n1: **buildings per pack**: 10 
- n2: **material variants included**: 5 

## Techniques
- t1: **MaterialService variant import**: Drag the downloaded texture folder into Roblox Studio and drop it into MaterialService. Then select a part, open Properties > MaterialVariant, and pick a variant.
- t2: **Multi-select retexture**: Hold Ctrl and click parts to select them, set MaterialVariant once for the group, then reselect subsets (walls, floors) to assign a different variant.
