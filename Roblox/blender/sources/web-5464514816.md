# web-5464514816

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox doc on PBR SurfaceAppearance for MeshParts: five supported maps (color, normal, roughness, metalness, emissive), alpha modes, tinting, normal map format, emissive validation limit. Relevant to texturing/baking in Blender for Roblox import; nothing on Claude, blender-mcp or bpy.

## Claims
- c1: Studio supports 5 PBR map types: color, normal, roughness, metalness, emissive. Maps change only appearance, not MeshPart geometry. *(doc, high; mesh-texture-limits)*
- c2: PBR is added by inserting a SurfaceAppearance under a MeshPart; each map property takes an uploaded image asset ID. SurfaceAppearance properties generally can't be modified by scripts at runtime because of engine pre-processing. *(doc, high; mesh-texture-limits)*
- c3: Roblox only supports OpenGL-format, tangent-space normal maps. A flat normal map is uniform [127,127,255]. Normal maps accentuate texture seams, so hide seams. *(doc, high; mesh-texture-limits)*
- c4: Roblox only supports OpenGL-format normals, so Blender normal maps (OpenGL convention) fit; DirectX-style maps from other tools would need the green channel flipped (inference, not stated). *(opinion, low; blender-roblox-export-import)*
- c5: Roughness and metalness maps are grayscale. Studio uses only the metalness workflow; metalness should mostly be 0% or 100%, partial values for satin or silk. *(doc, high; mesh-texture-limits)*
- c6: Fresnel may give unexpected specular on rough surfaces; compensate by raising roughness about 0.1. Brightness may differ between Substance Painter and Studio. *(doc, medium; mesh-texture-limits)*
- c7: Use albedo maps with no baked lighting, not diffuse maps. Diffuse maps with baked shading look wrong under mismatched lighting. *(doc, high; mesh-texture-limits)*
- c8: AlphaMode values: Opaque (beta, ignores alpha), Overlay (default, reveals MeshPart.Color where transparent), Transparency (cuts out mesh), TintMask (alpha controls Color tint strength). *(doc, high; mesh-texture-limits)*
- c9: For Transparency mode, MeshPart.Transparency 0 suits hard-edged cutouts (foliage, lace) with proper depth occlusion; at least 0.02 suits soft gradients, with blending trade-offs. 0.01 may trigger opaque behavior due to precision. *(doc, high; mesh-texture-limits)*
- c10: For TintMask color maps, preserve color in transparent regions and disable pre-multiplied alpha, which darkens those areas. *(doc, high; mesh-texture-limits)*
- c11: SurfaceAppearance.Color tint multiplies the texel color, so near-white grayscale color maps tint most strongly. Reusing one color map with different tints saves memory with no performance cost. *(doc, high; mesh-texture-limits)*
- c12: Emissive masks work on Marketplace 3D accessories, layered clothing and avatar bodies, but not 2D clothing, makeup or In-Experience Creation at launch. Marketplace items must keep EmissiveStrength between 0 and 40 to pass validation. *(doc, high; avatar-ugc-accessories)*
- c13: Emissive uses a grayscale EmissiveMaskContent plus EmissiveTint and EmissiveStrength, giving finer control than the Neon material. *(doc, high; mesh-texture-limits)*
- c14: The doc points to a separate page, 'Blender / Maya texture settings' (assign-textures.md), for connecting PBR textures in Blender for Studio import. It is not covered here. *(doc, high; blender-roblox-export-import)*

## Numbers
- n1: **supported PBR map types**: 5 
- n2: **flat normal map color**: [127,127,255] 
- n3: **EmissiveStrength range for Marketplace validation**: 0 to 40 
- n4: **MeshPart.Transparency threshold for blended alpha**: at least 0.02 
- n5: **roughness compensation for fresnel**: about +0.1 

## Techniques
- t1: **Enable PBR on a MeshPart**: In Explorer hover the MeshPart, click the plus button, insert SurfaceAppearance, then paste uploaded image asset IDs into ColorMap, NormalMap, RoughnessMap, MetalnessMap and EmissiveMaskContent.
- t2: **Cutout detail via alpha**: Use AlphaMode Transparency with a color-map alpha channel for lace, netting or foliage instead of modeling the geometry, and set MeshPart.Transparency to 0 for hard edges.
- t3: **Selective tinting**: Author a near-white color map, set AlphaMode to TintMask, and use the alpha channel as the tint strength mask, then set SurfaceAppearance.Color.
