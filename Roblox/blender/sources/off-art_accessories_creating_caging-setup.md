# off-art_accessories_creating_caging-setup

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox Creator Docs page on caging setup for a clothing accessory in Blender. Explains inner vs outer cage, says only the outer cage needs adjusting when built from cage templates, and gives the Outliner/Object Properties steps to isolate LongSleeve_OuterCage for sculpting. Little on bpy, MCP, or export.

## Claims
- c1: Caging = setting the clothing's inner and outer cage surfaces so clothing layers over bodies and other clothes; outer cage is the part that must be adjusted. *(doc, high; avatar-ugc-accessories)*
- c2: If the clothing was built using the cage templates as a mannequin, the inner cage needs no adjustment; only the outer cage must be reshaped to fit the new item. *(doc, high; avatar-ugc-accessories)*
- c3: Caging setup in Blender: switch to Object mode, hide the armature, unhide LongSleeve_OuterCage, set LongSleeve to unselectable to avoid accidental edits. *(doc, high; avatar-ugc-accessories)*
- c4: Enable Wireframe in Object Properties for the active outer cage mesh to make it easier to visualize and select. *(doc, high; avatar-ugc-accessories)*

## Techniques
- t1: **Isolate outer cage for editing**: Object mode; hide armature; unhide LongSleeve_OuterCage; lock LongSleeve as unselectable; enable Wireframe on cage in Object Properties; then sculpt outer cage to wrap clothing.

## Quotes (brief, for attribution)
> Only the outer cage needs to be adjusted to fit over the new clothing item.  (create.roblox.com)
