Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox staff early-access announcement for Mesh Streaming, an engine-level system that streams mesh LoDs by scene importance and memory budget, plus new cloud-generated LoDs. Only tangentially related to Blender-to-Roblox pipeline. Key constraints: only unskinned meshes are supported (custom/skinned characters excluded), collision is unaffected, and it works without StreamingEnabled. Not about blender-mcp, bpy, or FBX/glTF import settings.

## Claims
- c1: Mesh Streaming engine system streams specific mesh LoDs based on scene importance and a strict mesh memory budget, instead of loading high-poly meshes all-or-nothing. *(doc, high; mesh-texture-limits)*
- c2: Mesh Streaming and Next-gen Cloud LoDs only support un-skinned meshes; skinned meshes (e.g. custom characters) do not yet work with it. *(doc, high; rigging-animation)*
- c3: Collision geometry is stored as a separate data blob and is not swapped between LoD versions; Mesh Streaming only affects the rendered visual mesh. *(doc, high; mesh-texture-limits)*
- c4: Mesh Streaming is conceptually like MeshPart.RenderFidelity but with a cloud-transcoded LoD generator, automatic selection, and automatic load/unload based on available resources. *(doc, high; mesh-texture-limits)*
- c5: Mesh Streaming does not require Workspace.StreamingEnabled; asset streaming (LoD/texture mip quality) is decoupled from instance streaming. *(doc, high; mesh-texture-limits)*
- c6: New LoD generation algorithm runs on Roblox cloud transcoder infrastructure and aims to better preserve original silhouettes than previous LoDs. *(doc, medium; mesh-texture-limits)*
- c7: Early access is gated by waitlist sign-up and staged admission; enabling/disabling the early build is per-client (Studio and Roblox Player) via a private dev forum area. *(doc, high; automation-and-creator-workflows)*
- c8: Mesh Streaming was made available in published experiences as opt-in on 2026-06-17 per a staff update to the post. *(doc, high; mesh-texture-limits)*
- c9: Automatic LoD selection may not suit every asset; Roblox asks creators to report assets or scenarios where automatic selection fails, since granular LoD control is limited. *(doc, medium; mesh-texture-limits)*
