# web-6cc6a34706

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
A 2020 DevForum Q&A about getting Blender models into Roblox Studio. Covers why .blend uploads fail ("Unexpected File type"), choosing OBJ vs FBX, and why FBX vertex colours showed white. Suggested fix: export OBJ groups and recolour in Studio. No Claude, MCP, or bpy content.

## Claims
- c1: Roblox rejects .blend files with 'Unexpected File type'; the model must be exported as OBJ or FBX from Blender (File > Export) before upload. *(experience, high; roblox-import-pipeline)*
- c2: Per a forum reply, OBJ import carries mesh data but no colour; FBX carries vertex colour and mesh data but cannot be exported in groups. *(opinion, low; roblox-export-settings)*
- c3: To keep vertex colours in Blender, add a Vertex Color node (Shift+A) and connect it to the Color input of the Principled BSDF in the Shader editor. *(experience, medium; texturing-baking-uv)*
- c4: An FBX with painted colours imported into Roblox appeared white; the poster's guess was that the vertex colour setting was not enabled, with no confirmed fix. *(experience, low; common-mistakes-fixes)*
- c5: Recommended workflow: separate leaves and trunk into OBJ groups and recolour them in Roblox Studio; unwrap UVs only if logos or textures are needed. *(opinion, medium; creator-workflows)*
- c6: Logos or other textures on a model require UV unwrapping in Blender. *(opinion, medium; texturing-baking-uv)*

## Techniques
- t1: **Export OBJ groups for recolouring**: Separate parts (e.g. leaves vs trunk) into separate objects, export as OBJ with groups, import to Roblox, then colour each part in Studio.
- t2: **Vertex colour to Principled BSDF**: In Blender Shader editor, Shift+A, add Vertex Color node, connect its output to Principled BSDF Color input; export FBX.
