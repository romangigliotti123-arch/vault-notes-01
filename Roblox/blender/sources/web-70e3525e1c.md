Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox creator docs tutorial on preparing a clothing mesh for texturing in Blender: mark seams with Alt-click and Make Seam, unwrap all vertices via UV > Unwrap, then switch to Texture Paint mode. Explicitly excludes PBR textures (needs third-party tools like Substance Painter). Does not cover Blender scripting, blender-mcp, or the Roblox import/export pipeline.

## Claims
- c1: UV map requires seams: select complete edges (key 2 for edge mode, Alt-click), right-click > Make Seam, then select all and UV > Unwrap. *(doc, high; texturing-baking-uv)*
- c2: Seams should be placed along center vertical edges of a shirt so Blender separates front and back into distinct UV surfaces. *(doc, high; texturing-baking-uv)*
- c3: Texture Paint mode is used after unwrapping to paint a full colour and smaller design; UVs display in the left window. *(doc, medium; texturing-baking-uv)*
- c4: Tutorial excludes PBR textures; the doc says these often require third-party apps such as Substance Painter. *(doc, high; avatar-ugc-accessories)*

## Techniques
- t1: **Seam-then-unwrap UV workflow**: Edit mode, key 2 for edge select, Alt-click center edges of a complete loop, right-click Make Seam, select all (A), UV > Unwrap, switch to Texture Paint.

## Quotes (brief, for attribution)
