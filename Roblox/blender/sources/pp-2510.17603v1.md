## Claims
- c1: ShapeCraft represents 3D assets as shape programs, using a multi-agent LLM framework for text-to-3D. This is conceptually related to LLM-driven procedural modeling scripts. The abstract does not name Blender or bpy. *(doc, medium; claude-blender-ai)*
- c2: The Graph-based Procedural Shape (GPS) representation decomposes natural language into a structured graph of sub-tasks. Agents parse input hierarchically, then iteratively refine procedural modeling and painting. *(doc, high; claude-blender-ai)*
- c3: The authors say existing text-to-3D methods give unstructured meshes with poor interactivity, which makes them impractical for artistic workflows. ## Techniques
- t1: **Graph-based Procedural Shape (GPS) decomposition**: The LLM breaks a prompt into a graph of sub-tasks that capture spatial relationships and semantic shape details. Agents initialize the GPS hierarchically, then iteratively refine procedural modeling and painting.
