# web-2cd06949f0

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox creator doc listing technical texture requirements: file formats (png/jpg/tga/bmp), max 4096x4096 for basic textures with size guidance by stud size, single material per mesh, and PBR SurfaceAppearance map formats (albedo RGB 24-bit, normal OpenGL tangent space RGB, roughness/metalness/emissive grayscale 8-bit). Gives a 256px-per-2-unit-cube budget table and UV rules (single UV set, 0:1 space, overlaps allowed, max 1024).

## Claims
- c1: Texture files uploaded separately in Studio must be .png, .jpg, .tga, or .bmp. *(doc, high; mesh-texture-limits)*
- c2: Roblox supports texture resolutions up to 4096x4096 for basic textures; manual sizing can still improve memory use. *(doc, high; mesh-texture-limits)*
- c3: Guidance: 5x5 stud objects 256x256; 10x10 studs 512x512; 20x20 studs 1024x1024. *(doc, high; mesh-texture-limits)*
- c4: Mesh objects can only have one material assigned. *(doc, high; mesh-texture-limits)*
- c5: Roblox default parts display 1024x1024 on an 8x8 stud face; terrain displays 512x512 across 8x8 studs. *(doc, high; mesh-texture-limits)*
- c6: PBR albedo map: RGB 24-bit. Normal map: RGB 24-bit, only OpenGL format Tangent Space supported. *(doc, high; mesh-texture-limits)*
- c7: PBR roughness, metalness, and emissive mask maps: single channel grayscale 8-bit. *(doc, high; mesh-texture-limits)*
- c8: PBR budget rule: 256x256 per 2x2x2 unit space; larger assets use next highest resolution; 1024x1024 maximum (8x8x8 units). *(doc, high; mesh-texture-limits)*
- c9: 256x256 is the maximum budget for non-albedo maps on rigid accessories. *(doc, high; avatar-ugc-accessories)*
- c10: Small 1x1x1 items (jewelry, sunglasses, eyebrows) use 64x64 to 128x128 maps. *(doc, high; mesh-texture-limits)*
- c11: UV rules: use a single UV set per component because Studio does not allow multiple UV sets; all UVs within 0:1 space; overlapping UVs allowed; max 1024x1024. *(doc, high; mesh-texture-limits)*
- c12: Roblox may downsample textures when many render simultaneously. *(doc, medium; mesh-texture-limits)*
- c13: Source does not mention Claude, blender-mcp, or bpy scripting; it is not a Blender workflow source. *(doc, high; claude-blender-ai)*
- c14: Doc points to a separate page 'Blender / Maya texture settings' (assign-textures.md) for connecting textures in Blender/Maya; no import settings are in this page. *(doc, high; blender-roblox-export-import)*

## Numbers
- n1: **max basic texture resolution**: 4096x4096 
- n2: **texture res for 5x5 stud object**: 256x256 
- n3: **texture res for 10x10 stud object**: 512x512 
- n4: **texture res for 20x20 stud object**: 1024x1024 
- n5: **PBR map size per 2x2x2 units**: 256x256 
- n6: **PBR max map size (8x8x8 units)**: 1024x1024 
- n7: **default part texel density**: 1024x1024 on 8x8 studs 
- n8: **rigid accessory non-albedo max**: 256x256 

## Techniques
- t1: **Size textures by stud footprint**: Pick map size from object's stud size (5→256, 10→512, 20→1024) or from unit-cube volume (256 per 2x2x2, round up).
- t2: **Single UV set per component**: Build one UV set for each humanoid or accessory; keep all UVs in 0:1; overlaps permitted to save atlas space.
