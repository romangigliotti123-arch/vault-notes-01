Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox staff announcement (2026-09-17) of CollisionFidelity = Tunable with a per-MeshPart CollisionPrecision slider, auto-default precision based on mesh size, and improved collision visualizers. Does not cover Blender, blender-mcp, bpy, or FBX/glTF export. Only tangentially relevant to the Blender-to-Roblox pipeline via collision geometry settings.

## Claims
- c1: CollisionFidelity = Tunable adds a CollisionPrecision slider per MeshPart; higher is more precise and costlier, lower is coarser and cheaper. *(doc, high; mesh-texture-limits)*
- c2: Default CollisionPrecision is computed from mesh size, so the post recommends sizing MeshParts roughly correctly before switching to Tunable. *(doc, high; mesh-texture-limits)*
- c3: Existing MeshParts keep their collision geometry; Tunable must be set manually, so existing experiences are unaffected. *(doc, high; mesh-texture-limits)*
- c4: Resizing a mesh does not currently change its collision geometry; the team is asking whether auto-recalculation or leaving it as-is should be the default. *(doc, high; mesh-texture-limits)*
- c5: For complex meshes, the first Tunable computation may take up to 5 seconds; precision levels are then cached, and bulk switching can briefly pause Studio. *(doc, high; mesh-texture-limits)*
- c6: Collision visualizer can now render visual mesh and collision geometry together with adjustable transparency, and filter by CanCollide, CanQuery, CanTouch, and Collision Groups. *(doc, high; mesh-texture-limits)*
- c7: Known limits: erroneous convexes can appear on meshes with fine detail relative to size or many intersecting parts; Solid Modeling API does not accept custom CollisionPrecision and uses the default. *(doc, high; mesh-texture-limits)*
- c8: Collision visualization is reached via the gear icon in the top-right of the 3D Viewport (Visualization Modes). *(doc, high; other)*

## Numbers
- n1: **Tunable computation time**: up to 5 seconds first time for complex meshes 

## Techniques
- t1: **Tunable collision setup**: Size the MeshPart correctly first, set CollisionFidelity to Tunable in Properties, then adjust CollisionPrecision slider; use Visualization Modes to inspect.
