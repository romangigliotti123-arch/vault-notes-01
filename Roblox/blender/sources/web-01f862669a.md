# web-01f862669a

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
DevForum thread (2024-03). User imports FBX from Blender into Studio; objects appear grey and have invisible collision blocks that make the player float. Suggested fix: set CollisionFidelity to PreciseConvexDecomposition, which the user reported made it worse. Splitting the mesh into pieces in Blender fixed it. Grey colour needs a texture image. No Claude, MCP or bpy content.

## Claims
- c1: Imported Blender FBX objects show invisible collision blocks around edges, making characters float above floors and window frames. *(experience, medium; common-mistakes-fixes)*
- c2: Setting CollisionFidelity to PreciseConvexDecomposition made the floating bug worse for the poster, per their report. *(experience, medium; roblox-mesh-limits)*
- c3: Splitting the mesh into several pieces in Blender before export fixed the invisible collision problem, per the poster. *(experience, medium; common-mistakes-fixes)*
- c4: FBX colours from Blender did not carry over; Studio showed grey. Advice given: a texture image containing the colours is required. *(opinion, low; texturing-baking-uv)*
- c5: Thread gives no version numbers, no export settings (scale, axes, apply transforms) and no root cause for the collision issue. *(doc, high; roblox-import-pipeline)*

## Techniques
- t1: **Split mesh into pieces in Blender**: Cut the object into smaller parts in Blender, export as FBX, import into Studio. Reported to fix floating collision. Reply by poster said it worked after the CollisionFidelity change failed.
