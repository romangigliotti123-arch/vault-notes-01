## Summary

Shows /mcp connection check, an empty viewport, a single natural-language prompt plus reference image, a rigged lizard with fingers clipping a vine fixed by hand, and 1-2 hour renders. ## Techniques
- t1: **Blender MCP connection check**: In Claude session run /mcp, search Blender in the server list, confirm connected. Open an empty Blender scene before prompting.
- t2: **Reference-image plus natural-language prompt**: Copy a reference image (e.g. from blender.org), paste into Claude, describe the scene in plain language; no structured prompt template.
- t3: **Manual rig correction after Claude**: Open the rig in Blender, zoom to the interfering finger, select bone, move or rotate it out of the branch, re-check main camera view.
- t4: **Low-res preview before final render**: Render a 480p preview to check motion, then a 1080p final render of the approved shot.
