# web-218f911357

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
DevForum thread: user's FBX mesh from Blender shows altered colours in Roblox Studio. Replies say the load is fine and the problem is background/texture or multiple material slots. Suggests checking MeshPart Color is 255,255,255 (vertex paint or texture alpha behaviour changed), and falling back to OBJ export. Thin, anecdotal; no bpy/MCP content.

## Claims
- c1: Colour shift after FBX import can be caused by MeshPart Color property not being 255,255,255; checking it is the first suggested fix. *(opinion, medium; roblox-import-pipeline)*
- c2: Parts of a model showing different colours may come from separate texture slots or separate exported parts, per a replier's guess. *(opinion, low; common-mistakes-fixes)*
- c3: Replier says Roblox changed alpha colour behaviour for textured meshes, so changing MeshPart base colour alters how textures look. *(opinion, low; roblox-export-settings)*
- c4: If FBX colour problems persist, try exporting the mesh as .obj instead. *(opinion, low; roblox-export-settings)*

## Numbers
- n1: **MeshPart Color target value**: 255,255,255 

## Techniques
- t1: **Reset MeshPart Color**: Select MeshPart in Studio, open Properties, set Color to 255,255,255 to test whether tint is multiplying texture or vertex colours.
- t2: **Fallback OBJ export**: If FBX colours remain wrong, re-export the mesh from Blender as .obj and re-import.
