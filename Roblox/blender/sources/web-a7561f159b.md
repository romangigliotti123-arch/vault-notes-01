# web-a7561f159b

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox doc on 2D classic clothing (T-shirts, Shirts, Pants): template pixel regions, export as PNG/JPG, Studio testing via Block Avatar rig and ShirtGraphic/Shirt/Pants objects, and 80 Robux upload fee. No Blender, bpy, or FBX/glTF pipeline content; low relevance to the Blender-to-Roblox topic.

## Claims
- c1: Classic clothing are 2D decal-style images wrapped on a classic character; only need image editor and browser to create and sell. *(doc, high; avatar-ugc-accessories)*
- c2: Three classic clothing types: T-shirts, Shirts, Pants. T-shirts are square, e.g. 512x512, show on front torso of blocky character. *(doc, high; avatar-ugc-accessories)*
- c3: Shirt/pants template regions: Large square 128x128 (FRONT, BACK); Tall rectangle 64x128 (torso sides R/L, arm and leg sides); Wide rectangle 128x64 (UP, DOWN); Small square 64x64 (arm/leg top and bottom). *(doc, high; avatar-ugc-accessories)*
- c4: Export classic clothing as .png or .jpg before testing and uploading in Studio. *(doc, high; avatar-ugc-accessories)*
- c5: Shoe artwork extending too far up leg regions makes shoes look like part of pants; keep shoe designs near leg bottoms for separation. *(doc, medium; avatar-ugc-accessories)*
- c6: Testing in Studio: Avatar tab > Character > Block Avatar rig; insert ShirtGraphic, Shirt, or Pants under Rig; set Graphic or ShirtTemplate/PantsTemplate property to uploaded image. Testing is free. *(doc, high; avatar-ugc-accessories)*
- c7: Upload fee for classic clothing is 80 Robux per submission via Creator Dashboard > Avatar Items > Classics tab; set Asset Type to T-Shirt, Shirt, or Pants. *(doc, high; avatar-ugc-accessories)*
- c8: Doc warns many user-generated Marketplace avatars do not support 2D classic clothing; modern 3D cosmetics/rigid accessories are documented separately. *(doc, high; avatar-ugc-accessories)*
- c9: Source does not cover Blender, blender-mcp, bpy scripting, FBX/glTF export, or 3D mesh import to Roblox; off-topic for the Blender pipeline subject. *(doc, high; other)*

## Numbers
- n1: **T-shirt template size**: 512x512 (example square) 
- n2: **Shirt/pants template region sizes**: 128x128, 64x128, 128x64, 64x64 px 
- n3: **Upload fee**: 80 Robux per submission
