Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox DevForum staff post on the Avatar Joint Upgrade (Jan 26, 2026). R15 avatar joints move from Motor6D to AnimationConstraints plus BallSocketConstraints, enabled via StarterPlayer.AvatarJointUpgrade. Does not cover Blender, bpy, blender-mcp, or the Blender-to-Roblox asset pipeline. Only tangentially relevant to rigging.

## Claims
- c1: Upgrade replaces R15 character Motor6Ds with AnimationConstraints and BallSocketConstraints when StarterPlayer.AvatarJointUpgrade is Enabled. *(doc, high; rigging-animation)*
- c2: Upgraded joint AnimationConstraints default to IsKinematic=True to match Motor6D behavior; set False for force/torque-driven joints. *(doc, high; rigging-animation)*
- c3: Scripts using IsA('Motor6D') miss AnimationConstraints, and setting C0/C1/Part0/Part1 errors; use Attachments instead. *(doc, high; rigging-animation)*
- c4: Upgraded joints apply only to Player spawn and HumanoidDescription character flows, not existing NPC models; R6 is unaffected. *(doc, high; rigging-animation)*
- c5: Known issue: choppy physics replication on other characters when a mix of kinematic and physical joints plays torso-moving animations. *(doc, high; rigging-animation)*
- c6: Phase 2 (default enabled, breaking for Motor6D-dependent experiences) targeted for H2 2026; Phase 3 date TBD. *(doc, medium; other)*

## Numbers
- n1: **Phase 2 target**: H2 2026 
- n2: **Post date**: 2026-01-26 

## Techniques
- t1: **Opt-in avatar joint upgrade**: Set StarterPlayer.AvatarJointUpgrade to Enabled; ctrl+shift+F search codebase for Motor6D, C0, C1, Part0, Part1 references and migrate to Attachments.
