## Summary
Roblox creator docs landing page for assets. Covers creating assets in Studio, third-party DCC tools, in-game creation, packages, privacy and moderation, and selling on the Creator Store. No Blender, Claude, bpy, or MCP content; no export settings or pipeline steps.

## Claims
- c1: Roblox docs say third-party 3D modeling tools can be used and their industry-standard asset types imported directly into Studio; no Blender specifics given. *(doc, high; creator-workflows)*
- c2: Creator Store sellers receive 100% of net proceeds on transactions, per the page, with pricing in USD. *(doc, high; creator-workflows)*
- c3: Packages bundle models, scripts and multimedia so updates propagate automatically to every place that uses them. *(doc, high; creator-workflows)*
- c4: Assets can be kept private for exclusive use in a project or published to the community, with moderation applied. *(doc, medium; other)*
