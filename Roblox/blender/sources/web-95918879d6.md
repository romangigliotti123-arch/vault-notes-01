## Techniques
- t1: **Instancing**: Reuse one mesh via instances instead of duplicate geometry to cut render cost.
- t2: **Frustum culling**: Exclude objects outside camera view from render processing.
- t3: **Light clamping**: Clamp light/ray intensity to reduce fireflies and noise-related cost.
- t4: **Simplify window glass**: Reduce glass ray bounces in Simplify settings.
- t5: **Persistent data**: Keep scene data in memory between frames for animation renders.
- t6: **Noise threshold**: Set adaptive sampling noise threshold to stop sampling early.
- t7: **Fast GI approximation**: Use approximate global illumination in Simplify to cut bounces.
- t8: **Simplify geometry**: Reduce viewport/render subdivision and geometry detail via Simplify panel.
