# web-903b57f8b0

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox creator docs page on Meshes. Explains MeshPart as the Studio object for third-party-modeled meshes (Blender/Maya), import via the Importer (which converts _Att, _OuterCage, _InnerCage objects and facial data into Attachment, WrapTarget, WrapLayer, FaceControls), texture options (TextureID vs SurfaceAppearance/MaterialVariant PBR), RenderFidelity distance bands, CollisionFidelity options, and rigging/skinning basics. No Blender-specific or bpy workflow content.

## Claims
- c1: Meshes must be created in a third-party modeling app such as Blender or Maya, then imported into Studio as MeshPart objects; parts cannot be created directly in Studio. *(doc, high; blender-roblox-export-import)*
- c2: Importer converts objects with _Att suffix to Attachment, _OuterCage to WrapTarget, _InnerCage plus _OuterCage to WrapLayer, and avatar heads with facial animation data to FaceControls. *(doc, high; blender-roblox-export-import)*
- c3: Importer previews meshes and rejects meshes with errors; Asset Manager bulk import does not support rigging, skinning, animation, accessories, or facial-animated characters. *(doc, high; blender-roblox-export-import)*
- c4: A mesh can take a single texture via MeshPart.TextureID, or up to four PBR texture maps via a SurfaceAppearance child or a MaterialVariant set in MeshPart.MaterialVariant. *(doc, high; mesh-texture-limits)*
- c5: If both SurfaceAppearance child and MaterialVariant are set, only SurfaceAppearance texture maps apply; other MaterialVariant settings such as physical properties still apply. *(doc, high; mesh-texture-limits)*
- c6: Setting TextureID cannot override existing PBR textures on a mesh. *(doc, high; mesh-texture-limits)*
- c7: RenderFidelity Automatic uses Highest under 250 studs, Medium at 250-500 studs, Lowest at 500+ studs from camera. *(doc, high; mesh-texture-limits)*
- c8: CollisionFidelity options: Box (small/non-interactive), Hull (convex), Default (concave-capable approximate), PreciseConvexDecomposition (most precise, most expensive), Tunable (CollisionPrecision slider; default chosen by engine from mesh size). *(doc, high; mesh-texture-limits)*
- c9: Rigging connects a mesh to an internal skeleton; skinning lets the mesh deform and bend instead of rotating rigidly on one axis. *(doc, high; rigging-animation)*
- c10: Marketplace avatar bodies, accessories and clothing are MeshParts that require rigging and skinning per the Avatar requirements. *(doc, medium; avatar-ugc-accessories)*

## Numbers
- n1: **RenderFidelity distance thresholds**: <250 Highest; 250-500 Medium; >=500 Lowest studs 
- n2: **PBR texture maps supported**: 4 

## Techniques
- t1: **Naming suffixes for attachments and cages**: Name Blender objects with _Att, _OuterCage, or _InnerCage+_OuterCage suffixes so the Importer converts them to Attachment, WrapTarget, or WrapLayer instead of MeshPart.
- t2: **Single texture via TextureID**: Import texture file via Asset Manager, copy asset ID, paste into MeshPart TextureID property in Properties window.
