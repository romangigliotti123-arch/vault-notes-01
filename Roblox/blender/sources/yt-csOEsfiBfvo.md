## Summary
Off-topic for Blender/Roblox. Shows an agentic-coding workflow (Antigravity with a Spline skill) that builds a web landing page with Spline 3D embeds and deploys to Netlify. The only transferable idea is installing a skill (SKILL.md) into an agent workspace to give it tool context. Nothing on Blender, bpy, Roblox, or Claude-Blender MCP.

## Claims
- c1: [6:51] A skill is dropped into the workspace and the agent unzips it to the right folder (for Antigravity, the agent folder). SKILL.md gives the agent instructions and context for the tool, so it can work with Spline. *(demo, medium; automation-and-creator-workflows)*
- c2: [10:30] The agent is asked to ask clarifying questions before integrating an asset. It corrected an error by consulting the installed skill. If it doesn't use the skill, you can prompt it to. *(demo, medium; automation-and-creator-workflows)*

## Techniques
- t1: **Install an agent skill via the agent**: Drag the skill zip into the workspace and ask the agent to install it. It unzips to the IDE's skill folder, where SKILL.md holds the usage instructions. Works with Antigravity, Claude Code and Codex.
