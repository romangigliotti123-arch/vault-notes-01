# web-1cc5c97477

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox doc on skinning an R15 humanoid in Blender 3.0 (not Claude/blender-mcp/bpy). Covers armature Sticks display, Auto Normalize, weight painting head, hand, forearm, upper arm, shoulder, and Studio constraints: max 4 bones per vertex, no Root/HumanoidRootNode weights, extra bones import as Class.Bone. Exports FBX. Layered accessories need cage data.

## Claims
- c1: Studio supports at most 4 bones influencing any single vertex; exceeding this can happen in complex rigs or when Auto Normalize is disabled. *(doc, high; blender-roblox-export-import)*
- c2: Do not paint influences on the Root or HumanoidRootNode parent bones; added influences are dropped on import into Studio. *(doc, high; rigging-animation)*
- c3: Extra bones skinned to a mesh that don't match Humanoid bone names (e.g. LowerTorso, LeftFoot) import into Studio as Class.Bone with the same name. *(doc, high; rigging-animation)*
- c4: Workflow: set armature Display As to Sticks, enable Auto Normalize in Weight Paint Tool options, then paint per limb with brush strength 1 (0.25 for shoulder/upper torso). *(doc, high; rigging-animation)*
- c5: A skinned model without inner and outer cage mesh data cannot equip layered accessories. *(doc, high; avatar-ugc-accessories)*
- c6: Full-range arm rotation can cause a candy-wrapping volume-loss artifact at shoulder-torso; the doc says it may not be avoidable in many cases. *(doc, medium; rigging-animation)*
- c7: Export the skinned model as .fbx using Blender export settings for Studio; guide targets Blender 3.0 and says other versions may differ in UI. *(doc, high; blender-roblox-export-import)*
- c8: Source does not mention Claude, blender-mcp, or bpy scripting; it covers manual Blender GUI skinning only. *(doc, high; claude-blender-ai)*

## Numbers
- n1: **max bones per vertex**: 4 Studio limit on bones influencing a single vertex
- n2: **brush strength**: 1 (head, hand, arms); 0.25 (upper torso shoulder) weight paint tool settings in guide
- n3: **Blender version used**: 3.0 version the guide was written against

## Techniques
- t1: **Auto Normalize weight painting**: Select armature, Shift-select mesh, enter Weight Paint, Tool tab > Options > enable Auto Normalize. Painting a wrong bone removes influence from the original bone.
- t2: **Bone-by-bone test**: Shift-select a bone, press R to rotate it, check mesh deformation, then adjust paint with Brush tool.

## Quotes (brief, for attribution)
> Studio doesn't support more than 4 bones to influence any single vertex.  (create.roblox.com)
> Do not apply influences on the Root or HumanoidRootNode parent bones in a humanoid rig. Any added influences are dropped when importing into Studio.  (create.roblox.com)
