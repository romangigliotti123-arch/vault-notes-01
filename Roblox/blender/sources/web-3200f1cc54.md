Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox creator-docs checklist for testing character bodies, split into Blender tests and Studio tests. Blender side: check geometry and textures against specs, pose-test rigging and skinning, verify FACS face data, and manually check cage and attachment placement. Studio side: test movement, lighting and skin tone, facial expressions, clothing try-on, and accessory fit. Gives no numeric limits; it defers to linked spec pages.

## Claims
- c1: Character body components should be tested periodically in both the modeling tool and Studio, so rigging, skinning and caging rework is caught early. *(doc, high; avatar-ugc-accessories)*
- c2: In Blender, confirm body geometry follows Roblox geometry specifications and textures follow Roblox texture specifications (linked to specifications.md; no numbers given). *(doc, high; mesh-texture-limits)*
- c3: Check rigging and skinning quality in Blender using posing tools (test-blender.md#skinning-data). *(doc, high; rigging-animation)*
- c4: Confirm FACS facial animation data is present and correctly configured before Studio testing. *(doc, high; rigging-animation)*
- c5: Cage meshes must completely and tightly cover the character model and follow outer cage specs; verified manually, not by tool. *(doc, high; avatar-ugc-accessories)*
- c6: Attachment points must be manually verified for correct position and conformance to attachment specifications. *(doc, high; avatar-ugc-accessories)*
- c7: Studio testing covers equipping clothing for fit and cosmetic issues, and equipping accessories for rigid placement and orientation. *(doc, high; avatar-ugc-accessories)*
- c8: Studio testing: cycle through facial animations and movement/animation environments to verify rigging, skinning and movement quality. *(doc, high; rigging-animation)*
- c9: Roblox provides an uncopylocked testing place file in Studio with quick access to environments and testing features. *(doc, high; other)*

## Techniques
- t1: **Iterative test-in-both-tools checklist**: Test body parts, textures, rig, face, cage and attachments in Blender first, then repeat the core checks in Studio with try-on of clothing and accessories while iterating.
- t2: **Pose test in Blender**: Use Blender posing tools on the armature to check skinning quality before exporting to Studio.
