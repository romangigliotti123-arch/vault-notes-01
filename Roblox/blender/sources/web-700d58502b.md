# web-700d58502b

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox creator doc on replacing PBR textures on the template head used for makeup. Covers Blender (unlink image via X, browse new image, delete unused nodes, export FBX/glTF with Custom Properties and Only Deform Bones) and Maya (replace Image Name in Hypershade, export with Skins enabled). Purpose: keep eyebrow/eyelash skinning intact. No bpy, MCP, or Claude content.

## Claims
- c1: Roblox template head textures are reassigned in Blender by selecting the texture node, clicking X to unlink, then folder icon to browse for the new image; repeat for all PBR maps. *(doc, high; blender-roblox-export-import)*
- c2: Alternative to per-texture unlinking in Blender: File > External Data > Unpack Resources > Remove Pack clears all image links at once. *(doc, high; blender-roblox-export-import)*
- c3: After retexturing, export the entire template head as FBX or glTF, then import into Studio; standard modeling export requirements still apply. *(doc, high; blender-roblox-export-import)*
- c4: Blender makeup export: enable Include > Custom Properties (for makeup UV data transfer) and Armature > Only Deform Bones so eyebrows and eyelashes keep skinning data. *(doc, high; blender-roblox-export-import)*
- c5: Maya makeup export: under Deformed Models, enable Skins so eyebrows and eyelashes include skinning data. *(doc, high; blender-roblox-export-import)*
- c6: Delete unused texture nodes and verify the final node graph matches the reference template with nothing unintentionally missing. *(doc, medium; blender-roblox-export-import)*
- c7: Reassignment applies only to template heads that already have PBR texture nodes; assigning textures from scratch is covered by a separate doc. *(doc, high; mesh-texture-limits)*
- c8: Source does not mention Claude, blender-mcp, or bpy scripting; it covers manual GUI texture reassignment only. *(doc, high; claude-blender-ai)*

## Techniques
- t1: **Unlink and relink texture images on template head**: Shading tab, select face region in Outliner Makeup collection, click X on image node, folder icon to browse new image, repeat per PBR map, delete unused nodes.
- t2: **Bulk clear image links**: File > External Data > Unpack Resources > Remove Pack unlinks all images at once.
