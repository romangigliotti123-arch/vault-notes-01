## Summary
DevForum thread (2021) asking whether merging default Parts into Unions/MeshParts helps performance via RenderFidelity LoD on a 30,000x30,000 stud map. Reply says it depends on instancing count, complexity, editability, and memory usage; advises testing. Not about Blender, Claude, MCP, bpy, or the Blender-to-Roblox pipeline.

## Claims
- c1: Whether to merge Parts into Unions/Meshes depends on instancing count, complexity, edit needs, and memory usage; no blanket answer given. *(opinion, medium; creator-workflows)*
- c2: Advice: judge performance by memory usage rather than part or triangle counts, and test in-game before committing to Unions/Meshes. *(opinion, medium; creator-workflows)*
- c3: Unions/Meshes can use RenderFidelity LoD, whereas default Parts do not; claimed as the thread's premise, not verified. *(opinion, low; roblox-mesh-limits)*
