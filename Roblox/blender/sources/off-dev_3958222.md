Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox staff recap (May-Aug 2025) of Asset Workflows: glTF export from Studio, Alt+M Quick Import, session-local known-asset upload cache, new simplifier for >20k-triangle meshes, glTF skinning and cage fixes, planned non-destructive Reimport. Nothing on blender-mcp or bpy/Claude scripting.

## Claims
- c1: Roblox Studio now exports assets as glTF files (glTF Export feature added to the May-Aug 2025 Asset Workflows recap). *(doc, high; blender-roblox-export-import)*
- c2: Quick Import: Alt+M (Option+M on Mac) opens a file picker to import one 3D file using default settings ('Studio Default' preset), skipping the main import settings UI. *(doc, high; blender-roblox-export-import)*
- c3: Quick-imported models are not added to inventory automatically; use Explorer right-click Save / Export > Save to Roblox... to save them. *(doc, high; blender-roblox-export-import)*
- c4: Quick Import does not support animations due to how they upload. *(doc, high; blender-roblox-export-import)*
- c5: Known Asset Cache skips re-upload of unchanged content and reuses prior asset IDs; cache is keyed by content hash plus creator ID and is local to the current Studio session (lost on restart or different machine). *(doc, high; blender-roblox-export-import)*
- c6: Cache misses on tiny changes: untouched meshes re-exported through Blender reliably skip upload, but moving an object without changing geometry causes floating-point differences that usually miss the cache. *(doc, high; blender-roblox-export-import)*
- c7: Import 3D auto-simplifies meshes over the 20k triangle limit; a new simplification engine replaced the old one (staff claims drastically higher quality; example 350K-triangle mesh). *(doc, medium; mesh-texture-limits)*
- c8: Fixed bug: glTF skinned mesh parts imported at the origin instead of their scene position. *(doc, high; rigging-animation)*
- c9: Reimport (planned, announced at RDC) non-destructively updates an existing Model or SurfaceAppearance from the remembered source file via Explorer right-click or hotkey; public beta hoped for October 2025. *(doc, medium; automation-and-creator-workflows)*
- c10: glTF export fixes: infinite loading when only non-numeric content IDs were exported; cage export failure; natively built Rig Builder rigs failed to export; missing position bounds on accessors caused validation issues in external apps. *(doc, high; blender-roblox-export-import)*
- c11: Cage export failure was fixed in glTF Export (relevant to layered clothing cages). *(doc, medium; avatar-ugc-accessories)*
- c12: Asset Manager gained arrow-key navigation (list and grid, Shift multi-select) and saves UI state such as hidden columns and grid/list mode. *(doc, high; automation-and-creator-workflows)*
- c13: Import Queue could not auto-upload to a Group inventory when in a Group experience; fixed. *(doc, high; blender-roblox-export-import)*
- c14: Source does not mention blender-mcp, bpy scripting, or Claude integration; no Claude-with-Blender workflow content. *(doc, high; claude-blender-ai)*

## Numbers
- n1: **Triangle limit for automatic simplification**: 20k triangles 
- n2: **Example mesh for simplifier comparison**: 350K triangles 
- n3: **Quick Import hotkey**: Alt+M (Windows) / Option+M (Mac) 
- n4: **Reimport public beta target**: October (2025, per post) 

## Techniques
- t1: **Quick Import for single files**: Press Alt+M/Option+M in Studio, pick a supported 3D file; default settings apply; if it fails an info dialog appears. Save to inventory afterward via Explorer right-click Save / Export > Save to Roblox.
- t2: **Re-export unchanged meshes to hit cache**: Re-export untouched mesh from Blender and re-import in same Studio session under same creator; cache skips upload. Avoid moving objects if you want cache hits, since transforms alter the hash.
