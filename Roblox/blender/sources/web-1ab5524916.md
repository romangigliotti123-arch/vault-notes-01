## Summary
Roblox creator docs page on texture painting for accessories in Blender. Explains entering Texture Paint mode, selecting the t-shirt mesh, choosing colour/brush size/falloff, painting on the UV 2D map or 3D mesh, and saving the texture as PNG via Image > Save. Covers no Claude, blender-mcp, bpy, or Roblox import/export specifics beyond a pointer to PBR surface appearance docs.

## Claims
- c1: Blender Texture Paint mode can be used to brush colours directly onto a mesh; painting works on either the UV 2D map or the 3D mesh. *(doc, high; texturing-baking-uv)*
- c2: Texture is saved as a .png via Image > Save in Blender. *(doc, high; texturing-baking-uv)*
- c3: Doc is part of Roblox accessory tutorial sequence (texture-map, texture-painting, armature-setup), applied to a t-shirt/long-sleeve clothing item. *(doc, high; avatar-ugc-accessories)*
- c4: Roblox suggests PBR textures via surface appearance as an alternative to plain painted colour maps. *(doc, medium; texturing-baking-uv)*

## Techniques
- t1: **Blender Texture Paint for clothing**: Enter Texture Paint mode, select the mesh, open sidebar brush settings, set colour/size/falloff, paint on UV 2D map or 3D view, then Image > Save as PNG.
