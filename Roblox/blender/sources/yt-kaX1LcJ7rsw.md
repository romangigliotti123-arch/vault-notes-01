## Techniques
- t1: **Verify MCP connection**: Run /mcp in Claude session; if not listed, open new session or refresh; check Blender Preferences add-ons for MCP path.
- t2: **Low-res test then final render**: Generate each scene at 480p to check output cheaply, iterate, then produce final 1080p clip.
- t3: **Per-scene generation**: Split video into scenes so one scene can be regenerated without redoing the whole ad.
