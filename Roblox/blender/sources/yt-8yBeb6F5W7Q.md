# yt-8yBeb6F5W7Q

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Showcase of Roblox Rig Vault, a Blender add-on and rig pack of 50 unusual R15-style rigs (20 free, 50 paid). Covers asset-library setup via preferences, per-rig settings (costume switcher, IK, sharpen edges), and collaboration process. No Claude, MCP, bpy scripting, or export-settings content.

## Claims
- c1: [1:44] Add-on does not auto-create an asset library; user creates a file path, sets import method to Append, then clicks Update Library in add-on preferences, naming it RV. *(demo, high; other)*
- c2: [1:28] Rig Vault has 50 rigs in paid version and 20 in free version; rigs are described as uncommon or unusual, not standard Roblox R15 bodies. *(doc, high; avatar-ugc-accessories)*
- c3: [3:25] Perry Bez supplied a base rig; most rigs were made by importing it, mapping it to body parts of the target character, then finishing rigging. Some streamed rigs did not use it. *(experience, medium; rigging-animation)*
- c4: [4:34] Every rig includes IK settings toggled on/off to make posing easier; some rigs have fingers, some do not. *(demo, high; rigging-animation)*
- c5: [3:52] Bear suit rig packs two designs in one file with a costume-type switcher (bear suit vs polar bear), plus a toggle for polar bear head. *(demo, high; avatar-ugc-accessories)*
- c6: [8:35] Sharpen Edges option preserves hard edges on low-poly Roblox-style meshes; it is off by default in viewport because it lags the viewport. *(experience, medium; roblox-mesh-limits)*
- c7: [6:07] Author accidentally saved a dynamic head into the Kenneth rig when importing an OBJ into Roblox Studio; the author calls this an unintended mistake. *(experience, medium; common-mistakes-fixes)*
- c8: [2:44] Work was split 25 rigs each between the two authors; the project grew from a planned 40 rigs to 50. *(experience, medium; creator-workflows)*
- c9: [5:23] Bone shapes differ by author: one author uses WGTS-style bone shapes while the other uses basic custom bone shapes. *(opinion, low; rigging-animation)*
- c10: [10:06] Gingerbread rig's green buttons would not attach well to the torso; a modifier was added to fix attachment. *(experience, low; common-mistakes-fixes)*
- c11: [1:44] Setup Asset Browser panel in the add-on opens preferences and explains how to create the library; the panel was moved to preferences. *(demo, medium; other)*

## Numbers
- n1: **rig count**: 50 paid / 20 free 
- n2: **rig split**: 25 per author 
- n3: **planned rigs**: 40 originally, grew to 50 
- n4: **rig completion**: finished in December (video recorded after) 

## Techniques
- t1: **Blender asset library setup for rig pack**: Create a folder path for the library, set import method to Append, open add-on preferences, click Update Library, select the library named RV.
- t2: **Base-rig remapping**: Import a shared base rig, map its bones to target character body parts, then finish weights and controls per rig.
