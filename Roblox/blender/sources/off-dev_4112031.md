# off-dev_4112031

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox Studio Reimport beta update (Dec 2025): right-click a Model > Reimport, or Alt+Shift+R, to update an imported model in place while keeping setup. Beta added rigs, avatars, bones, cages, dynamic heads and Joints/Motor6D. Limits: missing bones are deleted, WrapTargets are swapped (not updated), ACE must be closed. Not Blender-specific.

## Claims
- c1: Reimport updates a previously imported Model in place, non-destructively, via right-click > Reimport > Reimport or Alt+Shift+R (default hotkey). *(doc, high; blender-roblox-export-import)*
- c2: Reimport beta (Dec 2025) added support for rigs, avatars, bones, cages, dynamic heads and Joints/Motor6D, letting skinned-mesh skeletons be updated without losing setup. *(doc, high; rigging-animation)*
- c3: Reimport treats the entire skeleton as one unit: bones missing from the external file are deleted, while other instances not in the file are generally kept. *(doc, high; rigging-animation)*
- c4: Reimport replaces WrapTarget instances rather than updating them, because WrapTarget data is fixed at import time; children, attributes and tags are copied over. *(doc, high; avatar-ugc-accessories)*
- c5: Instance references and UniqueId links to replaced WrapTargets break after Reimport; Ctrl+Z restores the old instance. *(doc, high; avatar-ugc-accessories)*
- c6: Avoid Reimport while the Animation Clip Editor (ACE) is open; bone/joint handles may not update and Reimport can get stuck. Close and reopen ACE, re-trigger if stuck. *(doc, high; rigging-animation)*
- c7: Reimport targets are currently limited to Model and SurfaceAppearance instances; Decals and Accessories are planned. *(doc, high; blender-roblox-export-import)*
- c8: A prototype for reimporting animations mid-loop exists; UI and testing not finished, and availability was hoped for early the following year. *(doc, medium; rigging-animation)*
- c9: Reimport was an opt-out beta enabled by default; it can be disabled under File > Beta Features. Update to Reimport v0.1.3 for the new rig support. *(doc, high; automation-and-creator-workflows)*
- c10: Reimport is a Studio feature for iterating on Roblox-side assets; it is not documented as tied to Blender or FBX export settings. *(doc, medium; blender-roblox-export-import)*

## Numbers
- n1: **Reimport plugin version**: v0.1.3 Version needed for rig/avatar/joint support
- n2: **Hotkey**: Alt+Shift+R Default Reimport hotkey
- n3: **Supported targets**: Model, SurfaceAppearance Only these instance types reimportable at time of update
- n4: **Full release date**: 2026-05-20 Update note says Reimport fully released

## Techniques
- t1: **In-place reimport iteration**: Edit source model externally, then right-click Model > Reimport (or Alt+Shift+R) to update in Studio, keeping configuration. Close ACE first. Use Ctrl+Z if a WrapTarget swap was unwanted.
- t2: **Bone handling before reimport**: Keep all skeleton bones in the external file; bones created in Studio and absent from the file will be deleted on reimport.
