# web-b7b43e1465

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
DevForum tutorial (2021, partly outdated) on Roblox MeshPart performance: avoid UnionOperations, recycle MeshIds, choose RenderFidelity and CollisionFidelity, disable CanCollide/CanTouch/CanQuery/CastShadow where possible, avoid SpecialMeshes. Nothing on Claude, MCP, bpy or export settings; only generic Blender-to-Roblox mesh optimisation guidance.

## Claims
- c1: Import MeshParts only when the object can't be built efficiently from Roblox primitives; aim for the lowest triangle count. Blender models avoid the excess hidden triangles that primitive assemblies produce. *(experience, medium; roblox-mesh-limits)*
- c2: UnionOperations produce bad topology, excess triangles and bad collision wedges. They have no Performance RenderFidelity. Scripted property changes (material/color) break part instancing and force recalculation. *(experience, medium; roblox-mesh-limits)*
- c3: To convert a Union to a MeshPart: select it, Export Selection, then import as .obj MeshPart. Do this if you need to copy the union several times. *(doc, medium; roblox-import-pipeline)*
- c4: Recycle MeshIds: the engine downloads each unique MeshId once and reuses it. Vary scale, rotation and color to make copies look different, which cuts loading time. Example forest used only two unique MeshIds. *(experience, medium; roblox-mesh-limits)*
- c5: Default RenderFidelity is Precise (full triangles at any distance). Automatic degrades triangles with distance. Performance degrades like Automatic and also reduces more when FPS drops. Precise should rarely be used, except for landmarks that must always be visible. *(doc, high; roblox-mesh-limits)*
- c6: CollisionFidelity options, cheapest to costliest: Box, Hull, Default, PreciseConvexDecomposition. Box uses the bounding box. Hull makes a convex shape. Default struggles with holes. PreciseConvexDecomposition handles holes but is the most expensive. *(experience, medium; roblox-mesh-limits)*
- c7: Test CollisionFidelity in-game starting from Box and moving up, rather than choosing by triangle count. Terrain-like meshes made in Blender may need Default or PreciseConvexDecomposition, otherwise characters can float. *(opinion, medium; roblox-mesh-limits)*
- c8: Disable CanCollide and CanTouch on decorative or walk-through meshes and set CollisionFidelity to Box. Also disable CanQuery. Staff reportedly confirmed a performance gain, which varies with part size, movement and count. An older DevHub page said otherwise and is likely outdated. *(experience, medium; roblox-mesh-limits)*
- c9: Disable CastShadow on tiny parts and on objects already in shadow. Avoid SpecialMeshes: they cost two instances and have no Render/CollisionFidelity. *(opinion, medium; roblox-mesh-limits)*
- c10: Basic Roblox parts are pre-downloaded, so use them instead of Blender-made cubes. MeshParts need downloading and only add load time. *(experience, medium; roblox-mesh-limits)*
- c11: A MeshPart with non-Box CollisionFidelity and CanCollide off produced an odd shadow under Future lighting when EnvironmentDiffuse/SpecularScale is above 0. Bulk-setting ~50 meshes to Box is instant; Default or PreciseConvexDecomposition can be slow. *(experience, low; common-mistakes-fixes)*

## Numbers
- n1: **Automatic RenderFidelity distance example**: 3,000 tris under 250 studs; halved at 250-500 studs Imported 3,000-triangle MeshPart per RenderFidelity docs chart
- n2: **Target framerate**: 60 FPS Developer goal
- n3: **Minimum part scale**: below 0.05 now allowed So SpecialMesh not needed for tiny parts

## Techniques
- t1: **Wireframe check of triangles**: Enable Wireframe Rendering in Studio to see triangles. Compare primitive or union builds against Blender-made meshes.
- t2: **Visualise collision**: Use CloneTrooper1019's Mesh Optimization Tools plugin to view collision decomposition per CollisionFidelity setting.
- t3: **MeshId reuse with variation**: Model a few modular meshes. Reuse them with randomised rotation, size and color so the scene stays varied but loads few unique assets.

## Contradictions flagged
- Disabling CanCollide/CanTouch gives a performance gain, per staff reply cited by the author (vs Older DevHub 'Improving Performance' page saying setting CanCollide on distant objects won't improve performance)
