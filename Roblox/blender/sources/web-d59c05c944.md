# web-d59c05c944

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox creator doc on importing an .fbx animation into Studio's Animation Editor, converting it to a CurveAnimation, getting an asset ID, wrapping it in an Animation object, and uploading as an Avatar Item emote. Covers R15 standard rig setup. Says nothing about Blender, bpy, or MCP.

## Claims
- c1: Emote import starts from a standard R15 rig: add a character body with Rig Type R15 and Body Shape Masculine or Feminine via the Avatar tab Character button. *(doc, high; rigging-animation)*
- c2: Animation is brought in via Animation Editor > ... > Import > From File, accepting a .fbx file with animation data. *(doc, high; blender-roblox-export-import)*
- c3: Emote animation data must be a CurveAnimation, not KeyframeSequence; existing keyframes are converted via the Curve Editor button and Confirm prompt. *(doc, high; rigging-animation)*
- c4: Publish to Roblox from the Animation Editor menu opens Asset Configuration; saving the CurveAnimation generates a cloud asset ID. *(doc, high; automation-and-creator-workflows)*
- c5: Marketplace emote submission requires an Animation object whose AnimationId is the CurveAnimation asset ID. *(doc, high; avatar-ugc-accessories)*
- c6: Uploading an emote costs an 80 Robux upload fee; in Asset Configuration set Content Type to Avatar Item and Asset Category to Emote, then Submit for moderation. *(doc, high; avatar-ugc-accessories)*
- c7: Emotes must meet the separate emote specifications page or errors appear at later workflow steps. *(doc, medium; avatar-ugc-accessories)*

## Numbers
- n1: **upload fee**: 80 Robux Marketplace emote upload fee per the doc
- n2: **required rig**: R15 standard rig Masculine or Feminine body shape

## Techniques
- t1: **FBX to emote pipeline in Studio**: Add R15 character via Avatar > Character. Open Clip Editor, select rig. Import .fbx via Animation Editor menu. Convert to CurveAnimation with Curve Editor, Confirm. Publish to Roblox for asset ID.

## Quotes (brief, for attribution)
> The animation data for emotes must be a Class.CurveAnimation object instead of a Class.KeyframeSequence object.  (create.roblox.com)
