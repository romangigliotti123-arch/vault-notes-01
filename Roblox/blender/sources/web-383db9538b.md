# web-383db9538b

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox docs page on texturing setup in Blender for custom avatar templates. Covers manual texture saving in Texture Paint (and Blender 5.2+ auto-save option), the 1024x1024 albedo limit in Studio, and a temporary higher-resolution painting workflow resized back to 1024 before baking. Says nothing on blender-mcp, bpy, Claude, or FBX export settings.

## Claims
- c1: Roblox Studio supports 1024 x 1024 resolution for albedo texture maps; finer detail may not paint as expected at that size. *(doc, high; blender-roblox-export-import)*
- c2: Temporarily raise texture resolution to 2048x2048 or 4096x4096 for fine detail work, then resize back to 1024x1024 to bake changes in. *(doc, high; mesh-texture-limits)*
- c3: Blender Texture Paint: Image > Resize in the 2D view window sets texture size; select Head_Geo in Layout tab first. *(doc, high; blender-roblox-export-import)*
- c4: Blender downloadable templates require manually saving textures in Texture Paint 2D view; saving the .blend alone does not save textures, risking lost work. *(doc, high; blender-roblox-export-import)*
- c5: Blender 5.2+ setting: Edit > Preferences > Save & Load > Blend Files > Save Modified Images = Always Save avoids manual image saving. *(doc, high; blender-roblox-export-import)*
- c6: Templates include a color texture map; skin tone previews in Blender are recommended to verify final look in-game. *(doc, medium; avatar-ugc-accessories)*
- c7: Texturing body parts requires a modesty layer over sensitive regions per Marketplace policy. *(doc, high; avatar-ugc-accessories)*

## Numbers
- n1: **Albedo texture resolution (Studio)**: 1024 x 1024 
- n2: **Temporary working resolution**: 2048 x 2048 or 4096 x 4096 
- n3: **Blender version for Always Save setting**: 5.2+ 

## Techniques
- t1: **Upscale-paint-downscale texturing**: Select Head_Geo in Layout tab; Texture Paint tab > 2D view > Image > Resize to 2048/4096 for detail; paint; resize back to 1024 to bake.
- t2: **Auto-save texture images**: Edit > Preferences > Save & Load > Blend Files > Save Modified Images = Always Save (Blender 5.2+).
