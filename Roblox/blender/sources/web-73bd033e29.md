Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox creator docs page on querying the Creator Store (Studio assets) and Marketplace (avatar items) externally. Covers the Marketplace catalog search URL, its query parameters (Category, Subcategory, Genres, SortType, Limit and others), paging via Cursor, and response fields. It does not cover Blender, bpy, blender-mcp, FBX/glTF export, or mesh/rig limits.

## Claims
- c1: Marketplace avatar items can be queried externally via https://catalog.roblox.com/v1/search/items/details?[params]; Creator Store assets are queried via the Open Cloud Toolbox Service SearchCreatorStoreAssets. *(doc, high; automation-and-creator-workflows)*
- c2: Marketplace Limit parameter accepts only 10, 28, or 30; Cursor paging uses nextPageCursor/previousPageCursor and is valid only if other params are unchanged. *(doc, high; avatar-ugc-accessories)*
- c3: Marketplace Category/Subcategory filters include Accessories (11), Clothing (3), Gear (5), and Subcategories such as Hats (9), Shirts (12), Pants (14), Heads (15), DynamicHeads (66). *(doc, high; avatar-ugc-accessories)*

## Numbers
- n1: **Limit values**: 10, 28, 30
