# yt-wugtjJEqfNA

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Video showing how to debug Blender Python scripts (generated by ChatGPT) in VS Code using the Blender Development extension. Covers installing a matching Python interpreter, the Python and Blender Development extensions, launching Blender from VS Code via the command palette, and line-by-line stepping with breakpoints. Nothing on Roblox, blender-mcp, or Claude.

## Claims
- c1: [0:57] Install a Python interpreter whose first two version numbers match the version shown in Blender's scripting console; the latest version is said to work too. *(demo, medium; bpy-scripting-headless)*
- c2: [2:21] VS Code needs two extensions: Microsoft's Python extension and the 'Blender Development' extension (shown with 64k+ installs). *(demo, medium; bpy-scripting-headless)*
- c3: [3:56] Run a script from VS Code: Ctrl+Shift+P (Cmd+Shift+P on Mac), 'Blender: Start', choose a local Blender install, then 'Blender: Run Script' to execute main.py inside Blender. *(demo, medium; bpy-scripting-headless)*
- c4: [5:16] Breakpoints are set by clicking the gutter next to line numbers; debugging is started with the debug shortcut, pausing before Blender state changes, with Step Over and Continue controls and variable inspection. *(demo, medium; bpy-scripting-headless)*
- c5: [5:59] Stepping through a for-loop that creates lights lets you watch list variables (light coordinates) change per iteration, useful for understanding generated code. *(demo, medium; bpy-scripting-headless)*
- c6: [3:28] Example ChatGPT prompt generated a Blender script for a 3-point light rig: lights parented to empties, tracking another empty, randomized colours, and not clearing the scene on each run. *(demo, low; procedural-generation)*

## Techniques
- t1: **VS Code Blender debugging loop**: Open main.py in VS Code; Ctrl+Shift+P, 'Blender: Start' to launch chosen Blender; clear scene; run 'Blender: Run Script'. Set gutter breakpoint; start debug run; use Step Over and Continue to inspect variables.
