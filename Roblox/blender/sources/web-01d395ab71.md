Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox creator doc on manually rigging a simple mesh in Blender 3.0: armature and bone setup, Automatic Weights parenting, rigid vertex-group assignment for a robot model, and pose-mode testing before FBX export. Covers no Claude, MCP, or bpy scripting; export specifics are deferred to another page.

## Claims
- c1: Roblox doc says to set up Blender to Studio's relative scene units before importing a model to rig. *(doc, high; blender-roblox-export-import)*
- c2: Rigging workflow: add armature, add bones in Edit Mode (Add > Single Bone), position with G, rename in Outliner, parent mesh to armature with Automatic Weights. *(doc, high; rigging-animation)*
- c3: Doc recommends Armature Object Properties > Viewport Display > Show > In Front for bone visibility. *(doc, medium; rigging-animation)*
- c4: Vertex weights for rigid robot limbs assigned via Object Properties > Vertex Group > Assign; each limb fully influenced by one bone (rigid, no blending). *(doc, high; rigging-animation)*
- c5: Test rig in Pose mode: Shift-click bone, R to rotate, Alt+R resets rotation to neutral. *(doc, high; rigging-animation)*
- c6: Doc says rig after modeling but before exporting; exports follow the Studio export requirements page. *(doc, medium; blender-roblox-export-import)*
- c7: Source does not mention Claude, blender-mcp, bpy scripting, or any AI tooling. *(doc, high; claude-blender-ai)*

## Numbers
- n1: **Blender version used in guide**: 3.0 

## Techniques
- t1: **Automatic Weights parenting**: Select mesh then armature (Shift), Ctrl/right-click in viewport, Parent > With Automatic Weights. Then refine vertex groups per limb in Edit Mode.
- t2: **Rigid limb assignment**: Edit Mode, X-Ray, box-select limb vertices, Object Properties > Vertex Group, pick bone, Assign. Repeat per bone.
