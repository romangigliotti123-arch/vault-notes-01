Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
GitHub issue on ifBars/blender-agent-studio. The repo's Blender agent skills were originally Codex-only. A user forked it and converted the skill set for Claude. The maintainer later merged PR #4, which adds a Claude Code plugin manifest and marketplace entry alongside the Codex ones, sharing the same skills and MCP server. Nothing on Roblox export or import.
