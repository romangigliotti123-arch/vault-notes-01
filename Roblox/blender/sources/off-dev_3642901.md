## Summary
Roblox staff recap (May 2025) of the Asset Manager beta, Import Queue redesign, and 3D Importer fixes. Little direct Blender/bpy/blender-mcp content; relevant mainly for the Roblox 3D Importer side of the Blender-to-Roblox pipeline (glTF/FBX import bug fixes, head bones, animation naming, CreateAssetAsync animations).

## Claims
- c1: Roblox 3D Importer fixed bones under the Head being lost on import (FBX/glTF rigs). *(doc, high; blender-roblox-export-import)*
- c2: glTF neutral FACS pose is now frame 0, stated as consistent with documentation. *(doc, high; blender-roblox-export-import)*
- c3: Fixed imported glTF tangents causing normal shading issues. *(doc, high; blender-roblox-export-import)*
- c4: Fixed crash from empty glTF animation names and renaming issue with duplicate glTF bone/node names. *(doc, high; blender-roblox-export-import)*
- c5: Fixed FBX dynamic head scale issue that caused exaggerated poses. *(doc, high; blender-roblox-export-import)*
- c6: Animation names no longer get an _animation suffix on import. *(doc, high; blender-roblox-export-import)*
- c7: Texture preview performance drastically improved in 3D Importer, expected to fix out-of-memory crashes. *(doc, medium; mesh-texture-limits)*
- c8: Error/warning icons in the 3D Importer now jump to the offending scene node when clicked. *(doc, high; blender-roblox-export-import)*
- c9: CreateAssetAsync now supports creating Animation assets (announced May 2025). *(doc, high; automation-and-creator-workflows)*
- c10: Asset Manager beta organizes assets by user and group inventories with search, filter/sort, bulk select, and copy asset ID. *(doc, high; automation-and-creator-workflows)*
- c11: Import Queue beta redesign with per-file state visibility and creator toggle targeted for late June launch; will expand to other asset types and replace Asset Manager bulk importer. *(doc, medium; automation-and-creator-workflows)*
- c12: Known open issues: bulk importer unavailable in published experiences; hard to find recently imported assets. *(doc, high; automation-and-creator-workflows)*
- c13: No Blender-side bpy, blender-mcp, or Claude-with-Blender content in this post. *(doc, high; other)*
