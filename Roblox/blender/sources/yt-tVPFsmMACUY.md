## Summary
Blender Today Live #260 (June 2025) is a community news recap of Blender 4.5 LTS and Blender 5.0 development: compositor, Eevee/GPU load speed, geometry nodes, Grease Pencil, outliner and UI changes. It does not cover Claude, blender-mcp, bpy scripting, Roblox export, or the Roblox asset pipeline. Only the OpenCOLLADA removal and glTF/FBX remarks touch export formats.

## Claims
- c1: Blender 5.0 removes the OpenCOLLADA (.dae) exporter/importer, which has been inactive for 6-7 years; Blender 4.5 LTS (supported to 2027) is the last with it. *(doc, high; blender-roblox-export-import)*
- c2: Speaker suggests glTF, USD or FBX as replacements for Collada; no Roblox-specific guidance given. *(opinion, medium; blender-roblox-export-import)*
- c3: Blender 5 allows longer ID names (limit raised from 63 bytes to 256); 4.5 truncates long names when opening 5.0 files. *(doc, medium; other)*

## Numbers
- n1: **OpenCOLLADA removal**: removed in Blender 5.0; 4.5 LTS last with it 
- n2: **ID name length limit**: 63 bytes -> 256 in Blender 5
