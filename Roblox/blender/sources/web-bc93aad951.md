Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox creator docs page listing official avatar body template files (Round, Square, Muzzle, SemiRealistic, Anime, Stylized, Caricature) for Blender. Each zip contains .blend, .fbx and PBR PNG textures; use the .blend when following Blender creation guides. Points to head-object structure and Blender configuration pages that must be adjusted before export. Does not cover blender-mcp, bpy scripting, or Roblox import settings.

## Claims
- c1: Roblox provides pre-baked avatar body template models (Round, Square, Muzzle, SemiRealistic, Anime, Stylized, Caricature) to start custom avatar characters in Blender. *(doc, high; avatar-ugc-accessories)*
- c2: Each template zip contains a .blend, an .fbx and PBR texture .png files; use the .blend when following Blender template guides. *(doc, high; avatar-ugc-accessories)*
- c3: Head-object structure and additional Blender settings must be reviewed and adjusted before export, as they can conflict with Roblox avatar requirements. *(doc, high; avatar-ugc-accessories)*
- c4: Some template files include eyebrow and eyelash mesh assets that may not be fully compatible with the template body. *(doc, medium; avatar-ugc-accessories)*

## Techniques
- t1: **Start from template body**: Download the zip matching head shape and gender, open the .blend in Blender, follow template creation guides; review head object structure and Blender configuration before export.
