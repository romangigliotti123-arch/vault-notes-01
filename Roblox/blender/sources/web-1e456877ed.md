Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox creator docs page on creating a 2D texture map in Blender for a clothing accessory (example: LongSleeve) after seams and UV unwrapping. Steps: add a new material, set Base Color to an Image Texture, create a new image named after the mesh with a _TXT suffix, fill black or a base colour, keep defaults. Manual UI only; no bpy code, no export settings.

## Claims
- c1: A texture map is the 2D image the clothing mesh's UVs project onto; you must create it before applying any texture appearance changes. *(doc, high; texturing-baking-uv)*
- c2: Texture map creation requires seams and unwrapping to be done first, since unwrapping defines how the 3D surface maps to 2D. *(doc, high; texturing-baking-uv)*
- c3: Texture image is named the same as the clothing mesh with a _TXT suffix. *(doc, high; texturing-baking-uv)*
- c4: Base colour is set via Material Properties > + New, then the Base Color yellow dot > Image Texture, then + New for the image; base colour set to black or preferred colour, other defaults kept. *(doc, high; texturing-baking-uv)*
- c5: Doc uses a LongSleeve clothing item as the worked example for the Roblox clothing texturing workflow in Blender. *(doc, medium; avatar-ugc-accessories)*
- c6: Page is one step in a sequence: unwrapping, then texture map creation, then texture painting (next page). *(doc, high; other)*

## Numbers
- n1: **texture image suffix**: _TXT 
- n2: **default image setting**: keep defaults in New Image dialog 

## Techniques
- t1: **Image Texture base colour setup**: Select mesh, Material Properties > +New; Base Color yellow dot > Image Texture; +New image named MeshName_TXT, set base colour (black default), keep defaults, OK.
