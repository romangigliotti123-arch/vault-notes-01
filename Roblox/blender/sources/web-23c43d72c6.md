# web-23c43d72c6

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Official Blender manual page for the built-in Wavefront OBJ importer/exporter. Covers import options (scale, axis conversion, split by object/group, validate meshes, material name collision) and export options (UVs, normals, vertex colours, triangulation, apply modifiers/transform, material groups, MTL/PBR, path modes, per-frame animation export). Says nothing about Roblox, Claude, or MCP; relevant only as a generic OBJ interchange step.

## Claims
- c1: OBJ format does not support armatures, lights, cameras, empty objects, parenting, or transformations, so rigs and hierarchy are lost on OBJ export. *(doc, high; roblox-export-settings)*
- c2: OBJ export has an Apply Transform option that bakes location, rotation and scale into vertices in world space; disabled, vertices stay in local object space. *(doc, high; roblox-export-settings)*
- c3: OBJ export has a Triangulated Mesh option that writes quads as two triangles, useful for programs with basic OBJ support. *(doc, high; roblox-export-settings)*
- c4: OBJ export can write active UV layer coordinates, normals and active vertex colours (xyzrgb extension) when the matching options are enabled. *(doc, high; texturing-baking-uv)*
- c5: Blender uses Y Forward, Z Up; apps using Y-up need -Z Forward, Y Up axis settings on import/export to avoid rotated models. *(doc, high; common-mistakes-fixes)*
- c6: Import/export Scale is a global multiplier relative to world origin; it is a manual setting, not a unit conversion to studs. *(doc, medium; roblox-export-settings)*
- c7: OBJ import loads materials from a matching .MTL file; Material Name Collision can make unique materials or reference existing ones. *(doc, high; texturing-baking-uv)*
- c8: Animation export writes one numbered OBJ per frame across start to end frame, and the manual warns this can take quite a long time. *(doc, high; creator-workflows)*
- c9: NURBS surfaces, text3D and metaballs are converted to meshes at OBJ export time. *(doc, high; procedural-generation)*
- c10: MTL export supports PBR extensions (roughness, metallic, sheen, clearcoat, anisotropy, transmission) and path modes including Copy and Strip Path. *(doc, high; texturing-baking-uv)*
- c11: Smooth normals must be written explicitly for Blender normal maps to match; most importers recompute normals otherwise. *(doc, medium; common-mistakes-fixes)*
