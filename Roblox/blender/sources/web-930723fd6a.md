# web-930723fd6a

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
DevForum troubleshooting thread (2024) about a 248k-polygon auto-rigged soldier mesh that deformed, had holes, and lost textures on Roblox import. Replies: a poster recalled a ~30k polygon per-mesh import limit (hedged), suggested fixing flipped normals, and suggested scaling to 0.01 and applying transforms. No Claude, MCP or bpy content. The OP later remade the model with less detail.

## Claims
- c1: Poster recalls a per-mesh polygon limit of about 30k on Roblox import; stated as 'if i remember correctly', unverified. *(opinion, low; roblox-mesh-limits)*
- c2: Reported mesh of about 248k polygons imported deformed with holes and missing textures; OP attributed the failure to the polygon count. *(experience, medium; roblox-mesh-limits)*
- c3: Translucent or see-through meshes may come from flipped face normals; fix is Edit mode, select all faces, Mesh > Normals > Recalculate Outside/Inside or Flip. *(experience, medium; common-mistakes-fixes)*
- c4: Oversized imports were suggested to be caused by missing scale-down in Blender; suggested scaling XYZ to 0.01 before export. *(opinion, low; common-mistakes-fixes)*
- c5: Suggested applying all transforms (Object > Apply > All Transforms) before export to avoid texture/transform problems on import. *(opinion, medium; roblox-export-settings)*
- c6: Textures sometimes appeared on import and sometimes did not; no working fix was found in the thread. Making the mesh double-sided did not help. *(experience, medium; texturing-baking-uv)*
- c7: Poster claims the polygon limit cannot be bypassed by alternate import paths because uploads are stored in Roblox's database; this is opinion, not documented. *(opinion, low; roblox-mesh-limits)*
- c8: Removing and re-adding bones, or importing only armature and mesh, was tried by the OP without solving the deformation. *(experience, medium; common-mistakes-fixes)*
- c9: OP abandoned the high-poly model and remade it with fewer details to fit Roblox limits. *(experience, medium; creator-workflows)*

## Numbers
- n1: **Per-mesh polygon limit (recalled)**: ~30k polygons 
- n2: **Failing mesh polycount**: 248k polygons 
- n3: **Suggested Blender scale**: 0.01 on X, Y, Z 

## Techniques
- t1: **Fix flipped normals**: Edit mode, select all faces, Mesh > Normals > Recalculate Outside (or Inside / Flip). Check flipped faces via the overlay face-orientation view.
- t2: **Apply transforms before export**: Select all meshes, Object > Apply > All Transformations, then export FBX and reimport into Roblox.
- t3: **Scale down in Blender**: Scale the object to 0.01 on XYZ in Blender before export, per the thread's suggestion.
- t4: **Reduce polycount**: Remake or decimate the model to fit under the per-mesh limit; OP chose to remake with less detail.
