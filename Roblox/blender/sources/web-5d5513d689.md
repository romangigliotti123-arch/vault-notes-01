Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox Studio Importer doc: imports .fbx, .gltf/.glb, .obj via File > Import. Covers import queue, presets, preview, per-file/object settings (scale unit, axes, rig type, cages, pivot, merge meshes), glTF vs FBX hierarchy differences, and warnings. Useful for the Blender-to-Roblox export/import step; nothing on Claude or blender-mcp.

## Claims
- c1: Studio Importer accepts .fbx, .gltf/.glb and .obj meshes; FBX and glTF support multiple meshes/hierarchies, PBR textures, cage meshes, rigs, avatar components, animation data and vertex colors. *(doc, high; blender-roblox-export-import)*
- c2: Import path: File > Import, pick file, configure settings, check warnings/errors, click Import. Right-click imported asset to copy asset ID (the Model's ID) or Find in Workspace. *(doc, high; blender-roblox-export-import)*
- c3: FBX imports as a Model with MeshPart directly inside; glTF imports as a Model containing a Model with one MeshPart per glTF primitive. Same-named node and mesh get a _Node suffix. *(doc, high; blender-roblox-export-import)*
- c4: With glTF, cage meshes produce a WrapLayer in the MeshPart plus extra Models for each original inner/outer cage node; these extra models can be deleted after import. *(doc, high; avatar-ugc-accessories)*
- c5: File Geometry Scale Unit defaults to Studs; set it to match the units the file was modeled in so size is correct. World Forward defaults to Front, World Up to Top. *(doc, high; blender-roblox-export-import)*
- c6: Uses Cage converts cage meshes into WrapLayer/WrapTarget; it is auto-enabled if cages are detected. If disabled, cages import as regular meshes. *(doc, high; avatar-ugc-accessories)*
- c7: Rig Type options are R15, Custom, No Rig; the Importer auto-picks from detected rig and skinning data. R15 adds Rig Scale: Default, Rthro, Rthro Narrow. *(doc, high; rigging-animation)*
- c8: Keep Zero Influence Bones is off by default, so bones that don't influence the mesh are removed on import. *(doc, high; rigging-animation)*
- c9: Upload to Roblox is on by default; disabling it lets you iterate on a model without creating multiple Toolbox/Asset Manager copies. Import Only As Model is on by default, Import as Package off. *(doc, high; automation-and-creator-workflows)*
- c10: Merge Meshes (default off) combines all MeshParts into one MeshPart instead of a Model. Set Pivot to Scene Origin is on by default; Use Imported Pivot per object is on by default. *(doc, high; blender-roblox-export-import)*
- c11: Make Double Sided is off by default and is more performance-intensive. Ignore Vertex Colors is off by default. Invert Negative Faces is off by default. *(doc, high; mesh-texture-limits)*
- c12: Import queue handles multiple files with per-item presets; 'Apply settings to all' copies one item's settings. Presets: Studio Default, Last Imported, plus saved custom presets. *(doc, high; automation-and-creator-workflows)*
- c13: For importing assets by HTTP requests rather than Studio, the doc points to the Open Cloud usage guide for assets. *(doc, high; automation-and-creator-workflows)*
- c14: Images import as .png, .jpg, .gif, .tga or .bmp; audio as .ogg, .mp3, .flac, .wav; video as .mp4, .mov. *(doc, high; mesh-texture-limits)*
- c15: Validate UGC Body opens imported assets in the Avatar Setup tool for testing and Marketplace upload. Meshes should meet the avatar character-bodies specifications to reduce errors. *(doc, high; avatar-ugc-accessories)*

## Techniques
- t1: **Import FBX/glTF/OBJ into Studio**: File > Import, select file, set preset and settings (Scale Unit, World Forward/Up, Rig Type, Uses Cage), fix warnings shown in the hierarchy or inspector, click Import.
- t2: **Iterate without cluttering inventory**: Disable Upload to Roblox during test imports so no Toolbox/Asset Manager copies are created. Enable it for the final import.
- t3: **Bulk import with presets**: Add multiple files to the queue, set a preset per row, or right-click an item and choose Apply settings to all, then press Import.
