## Summary
Blender manual page for the Triangulate modifier. Converts quads and n-gons to triangles non-destructively. Documents Quad Method (Beauty, Fixed, Fixed Alternate, Shortest Diagonal, Longest Diagonal), N-gon Method (Beauty, Clip), and Minimum Vertices. Says nothing about Roblox, bpy, or MCP.

## Claims
- c1: Triangulate modifier converts quads and n-gons to triangles; same function as Edit Mode Triangulate tool. Possibly useful for pre-export triangle counts, but source does not mention Roblox. *(doc, high; roblox-export-settings)*
- c2: Source does not state triangle budgets or Roblox limits; only describes triangulation options. *(doc, high; roblox-mesh-limits)*

## Numbers
- n1: **Minimum Vertices example**: 5 (prevents quad triangulation, n-gons only) 

## Techniques
- t1: **Quad method choice for cloth**: Use Longest Diagonal quad method; manual says it is preferred for cloth simulations. Beauty is slower but gives nicer triangles. Clip uses ear-clipping, same as viewport tessellation.

## Quotes (brief, for attribution)
> The Triangulate modifier converts all faces in a mesh (quads and n-gons) to triangular faces.  (docs.blender.org)
