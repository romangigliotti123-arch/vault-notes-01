## Summary
Roblox staff post (2026-05-13) on Studio Avatar Auto-Setup update: eyebrow/eyelash support as Eye Layered accessories, parallel clothing processing, decal-style face conversion, and optional extended R15 joints. Only tangentially relevant to Blender/bpy/MCP workflows; no Blender-specific content.

## Claims
- c1: Auto-Setup now supports eyebrows and eyelashes as 'Eye Layered' type, auto-scaling to different head sizes via leader/follower skinning transfer. *(doc, high; avatar-ugc-accessories)*
- c2: Decal-style 2D faces without separate eyeball or mouthbag meshes can be converted: Auto-Setup infers eye/mouth regions from texture, generates cages and FACS data, and maps onto a Dynamic Head template. *(doc, high; avatar-ugc-accessories)*
- c3: Decal face mode works best with near-neutral initial expression; open mouth keeps mouth interior visible. *(doc, medium; avatar-ugc-accessories)*
- c4: Default Auto-Setup output is R15; 'Create R15 with optional joints' setting adds spine, clavicle, head, finger and toe joints. *(doc, high; rigging-animation)*
- c5: Clothing layers are processed in parallel and recombined following preview layer order, claimed to yield significant performance gains. *(doc, medium; automation-and-creator-workflows)*

## Numbers
- n1: **Default rig type**: R15 (optional joints off by default) Extended joints need toggle ON in gear settings

## Techniques
- t1: **Eye Layered asset type**: Select 'Eye Layered' type for eyebrows/eyelashes so Auto-Setup builds them as layered accessories that scale to heads.
- t2: **Handle face as 2D decal**: Enable 'Handle face as a 2D decal' in Auto-Setup settings (gear, lower-left) when head lacks separate eyeball/mouthbag meshes.
- t3: **Create R15 with optional joints**: Enable setting via gear button lower-left to generate extended R15 rig with finger, spine, clavicle, head, toe joints.
