Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox docs on Packages: converting Studio instances into reusable, versioned assets with PackageLink, auto-update, permissions, and version compare. Covers Studio-side asset organization only; nothing on Blender, Claude, bpy, or mesh export/import pipelines. Marginally useful for organizing imported Blender-made models as packages.

## Claims
- c1: Wrap a single object in a Model before converting to a package so child objects can be added, removed or scaled later without breaking the package. *(doc, high; automation-and-creator-workflows)*
- c2: Deleting or moving the PackageLink object turns a package copy back into a normal object, losing update capability. *(doc, high; automation-and-creator-workflows)*
- c3: Placeholder packages (simple shapes) can be used to greybox; copies auto-update when detailed versions are published. *(doc, high; automation-and-creator-workflows)*
- c4: Auto-update occurs when a place is opened in Studio; it is disabled on modified copies. For nested packages, AutoUpdate only applies to the top-level parent. *(doc, high; automation-and-creator-workflows)*
- c5: Mass update (Update All) saves selected places but does not publish them, skips modified copies, and recommends closing other Studio instances to avoid overwrites. *(doc, high; automation-and-creator-workflows)*
- c6: Package ownership transfers are not supported; choose the owner (user or group) at creation. *(doc, high; automation-and-creator-workflows)*
- c7: Instance attributes on the package root act as default configs; per-copy overrides persist through updates, but only scripts in the package can act on them at runtime. *(doc, high; automation-and-creator-workflows)*
- c8: Use & View access cannot be revoked for copies already inserted; revoking only blocks reinsertion and updates. Edit permission allows publishing changes. *(doc, high; automation-and-creator-workflows)*
- c9: Version compare diff viewer offers Visual Overview (3D roots), Properties and Script tabs; some older versions are incompatible. *(doc, medium; automation-and-creator-workflows)*

## Techniques
- t1: **Create and auto-update a package**: Right-click object(s) in Explorer, Convert to Package, set Ownership (group if needed), Submit. Then select the PackageLink child and enable AutoUpdate. Share with collaborators via Package Details > Permissions.
