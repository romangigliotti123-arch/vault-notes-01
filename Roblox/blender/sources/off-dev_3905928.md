# off-dev_3905928

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Staff announcement of glTF Export beta in Roblox Studio (Aug 2025). Exports owned or explicitly shared assets to single embedded-texture .gltf with optional skinning, textures, cages. Preserves hierarchy, PBR, rigs, vertex colors. Lists permission restrictions, no-animation limit, layered clothing issues, and a non-numeric ID hang bug. Useful for Blender round-trips; no bpy or MCP content.

## Claims
- c1: glTF Export beta in Studio exports assets uploaded to your account or group to a single .gltf file with embedded textures (glTF 2.0 spec). *(doc, high; blender-roblox-export-import)*
- c2: Enable via File > Beta Features > glTF Export. Export selection via Explorer right-click > Save / Export > Export as glTF, or whole place via File > Export as glTF. *(doc, high; blender-roblox-export-import)*
- c3: Export dialog options: Skinning (bones, dynamic heads), Textures (decals, PBR textures), Cages. Export runs a permissions check and warns on blocked assets. *(doc, high; blender-roblox-export-import)*
- c4: Stated use case: run Avatar Auto-Setup and finalize meshes or cages in Blender via glTF export. *(doc, high; avatar-ugc-accessories)*
- c5: glTF export preserves scene hierarchy, PBR textures, skinning rigs, vertex colors, instances and dynamic heads; OBJ export supports none of these. *(doc, high; blender-roblox-export-import)*
- c6: Exportable: assets uploaded to your account or group, and Mesh/Image assets explicitly shared with you (via Asset Manager beta). *(doc, high; blender-roblox-export-import)*
- c7: Not exportable: Avatar Marketplace assets, acquired Creator Store assets, collaborator-shared assets without explicit mesh/image sharing, and public Open Use assets not explicitly shared. *(doc, high; blender-roblox-export-import)*
- c8: Permission restrictions apply only to glTF export, not the existing OBJ exporter. *(doc, high; blender-roblox-export-import)*
- c9: Limitation: animations are not exported. Some FACS rigs do not export correctly (known bug under investigation). *(doc, high; rigging-animation)*
- c10: Limitation: layered clothing may be mispositioned and does not deform to the avatar body outside Roblox. *(doc, high; avatar-ugc-accessories)*
- c11: Known bug: exports containing only non-numeric asset IDs (e.g., spawn location decal) hang indefinitely. Workaround: include a numeric asset or remove non-numeric ones. *(doc, high; blender-roblox-export-import)*
- c12: The source does not mention blender-mcp, bpy scripting, or Claude; it covers only the Studio-side export feature. *(doc, high; claude-blender-ai)*
- c13: Source gives no triangle limits, UV rules, texture sizes or SurfaceAppearance specifics; only states PBR textures are included in export. *(doc, medium; mesh-texture-limits)*
