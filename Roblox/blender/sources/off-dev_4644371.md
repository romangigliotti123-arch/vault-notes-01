# off-dev_4644371

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox staff post on Importer changes. Adds a custom Scale Factor field (File Geometry section, default 1.0, saved in presets). Non-Stud unit conversion (meter, cm, mm, foot, inch) changes from 20 Studs/meter to 25:7 Stud/meter on June 16, 2026, fixing ~5.6x oversized meshes. Scale factor 5.6 restores old behavior. Warning removed July 14, 2026. Animation Clip Editor importer to get same options later.

## Claims
- c1: Importer adds custom Scale Factor field under File Geometry; multiplies on top of unit conversion; defaults to 1.0; saved with importer presets. *(doc, high; blender-roblox-export-import)*
- c2: Non-Stud unit conversion changes from 20 Studs/meter to 25:7 Stud/meter on June 16, 2026 for meter, cm, mm, foot, inch. *(doc, high; blender-roblox-export-import)*
- c3: Old 20:1 ratio made meshes authored in meters import about 5.6x larger than intended. *(doc, high; blender-roblox-export-import)*
- c4: To preserve old behavior after June 16, 2026, set Scale Factor to 5.6 with a non-Stud unit. *(doc, high; blender-roblox-export-import)*
- c5: Stud unit with factor 1.0 is unchanged; Meter with factor 1.0 now uses 25:7; Meter with factor 5.6 gives old 20:1 result. *(doc, high; blender-roblox-export-import)*
- c6: Before June 16 the Meter/factor 5.6 combination applied 20:1 then x5.6, yielding 112:1 scaling; that is the prior combined behavior per the post's table. *(doc, medium; blender-roblox-export-import)*
- c7: Rollout: Scale Factor available now; warning shown on non-Stud units until July 14, 2026 when warning is removed. *(doc, high; blender-roblox-export-import)*
- c8: Example: a ~1.76 m character imported with Meter unit was too large under 20:1 and correct under 25:7. *(doc, high; blender-roblox-export-import)*
- c9: Planned next: same custom scale factor and unit option coming to the Animation Clip Editor importer. *(doc, medium; blender-roblox-export-import)*
- c10: Importer supports glTF, FBX, OBJ; default unit is Studs, so 5 file units become 5 Studs. *(doc, high; blender-roblox-export-import)*

## Numbers
- n1: **Old Stud/meter ratio**: 20 Studs per meter (20:1) 
- n2: **New Stud/meter ratio**: 25:7 (effective June 16, 2026) 
- n3: **Old-behavior scale factor**: 5.6 
- n4: **Default scale factor**: 1.0 
- n5: **Oversize before fix**: ~5.6x for meter-authored meshes 
- n6: **Warning removal date**: July 14, 2026 
- n7: **Example character height**: ~1.76 m 

## Techniques
- t1: **Author in real-world units and import with Meter**: Model in Blender in meters, pick Meter as the import unit in Importer; after June 16 2026 the 25:7 ratio scales it correctly with factor 1.0.
- t2: **Preserve legacy scale with factor 5.6**: For existing non-Stud workflows relying on 20:1, set custom Scale Factor to 5.6 in Importer (saved in presets) after the June 16 change.
