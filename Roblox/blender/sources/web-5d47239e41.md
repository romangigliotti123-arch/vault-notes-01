Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox official doc on exporting a character model from Blender as FBX with required settings: Copy path mode, embedded textures, custom properties, no leaf bones, baked animation with NLA/actions/keyframe options off and Simplify 0.0. Covers testing in Studio and post-import uses (Marketplace, HumanoidDescription, Toolbox). Does not cover blender-mcp or bpy scripting.

## Claims
- c1: Export character from Blender via File > Export > FBX; set Path Mode to Copy and enable Embed Textures. *(doc, high; blender-roblox-export-import)*
- c2: In FBX Include section, enable Custom Properties. *(doc, high; blender-roblox-export-import)*
- c3: Armature section: disable Add Leaf Bones. *(doc, high; blender-roblox-export-import)*
- c4: Bake Animation enabled; disable NLA Strips, All Actions, and Force Start/End Keyframes; set Simplify to 0.0. *(doc, high; blender-roblox-export-import)*
- c5: Doc says to test character bodies in a test place after export, verifying avatar and related components before Marketplace upload. *(doc, medium; rigging-animation)*
- c6: After import, the Class.Model character can be uploaded to Marketplace, applied to a game via HumanoidDescription, or saved to Toolbox. *(doc, medium; automation-and-creator-workflows)*

## Numbers
- n1: **Simplify**: 0.0 

## Techniques
- t1: **Roblox character FBX export preset**: File>Export>FBX; Path Mode Copy + Embed Textures; Include Custom Properties; Armature: disable Add Leaf Bones; Bake Animation on, with NLA Strips, All Actions, Force Start/End Keyframes off and Simplify 0.0; Export FBX.
