# web-7784aa52f9

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox Creator Docs page on animating live (animatable) heads in Studio's Animation Editor. Covers manual FACS tracks (values 0-1 mapped to FaceControls), the Face Animation Editor sliders with symmetry, focus and reset controls, webcam capture, saving to AnimSaves under the rig, and playing from scripts. Says face animations cannot be imported, so they must be authored in Studio. No Blender content.

## Claims
- c1: Face animations cannot be imported into Roblox Studio; they must be created with the Animation Editor's tracks, Face Animation Editor, or Animation Capture. *(doc, high; rigging-animation)*
- c2: FACS pose values in the Animation Editor are percentages from 0 to 1 that map directly to FaceControls values. *(doc, high; rigging-animation)*
- c3: Head animation only works on heads marked as animatable (dynamic heads); other heads cannot use these facial tracks. *(doc, medium; avatar-ugc-accessories)*
- c4: Saved face animations appear as children of an AnimSaves object under the rig in Explorer. *(doc, high; rigging-animation)*
- c5: Exported head animations become available in all of the creator's games and can be reused on any character with an animatable head. *(doc, high; rigging-animation)*
- c6: Face Animation Editor Symmetry toggle mirrors a slider change to the opposite side of the face, useful for full smiles. *(doc, high; rigging-animation)*
- c7: Animations can be played from scripts or used to replace a character's default animation. *(doc, high; rigging-animation)*

## Numbers
- n1: **FACS pose value range**: 0 to 1 Animation Editor percentage values mapped to FaceControls

## Techniques
- t1: **Face Animation Editor slider keyframing**: Open Animation Editor, click Face button, adjust sliders at a frame; move scrubber and set new expression; playback eases between expressions; Save via Media controls ... menu.
- t2: **Manual FACS track entry**: Click plus icon in track list, hover Brows/Eyes/Jaw/Mouth/Tongue, pick pose, enter 0-1 value.

## Quotes (brief, for attribution)
> Since you cannot import face animations, these methods are the only ways to create and utilize them.  (create.roblox.com)
