# off-art_modeling_material-reference

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox Creator Docs page giving PBR roughness/metalness reference values for common materials and clothing examples (Substance Painter vs Roblox Studio). Covers surface appearance values only. Does not mention Blender, bpy, blender-mcp, Claude, FBX/glTF export, or the Blender-to-Roblox pipeline, so it is largely off-topic for the requested subject.

## Claims
- c1: Roblox PBR material reference: Glossy Plastic roughness 0.1, metalness 0.0; Matte Plastic roughness 0.4, metalness 0.0; Latex roughness 0.0, metalness 0.0. *(doc, high; mesh-texture-limits)*
- c2: Pure metals (gold, silver, bronze) use roughness 0.2-0.3 with metalness 1.0; glass mirror uses roughness 0.0 and metalness 0.1. *(doc, high; mesh-texture-limits)*
- c3: Clothing reference values: leather fabric roughness 0.62 metalness 0.0; brass zipper roughness 0.25 metalness 1.0; denim roughness 0.9 metalness 0.0; silk roughness 0.52 metalness 0.3. *(doc, high; avatar-ugc-accessories)*
- c4: Layered clothing examples were compared between Substance Painter renders and Roblox Studio renders to show PBR values in real-time rendering. *(doc, medium; avatar-ugc-accessories)*

## Numbers
- n1: **Glossy Plastic roughness / metalness**: 0.1 / 0.0 
- n2: **Pure Metals roughness / metalness**: 0.2-0.3 / 1.0 
- n3: **Glass Mirror roughness / metalness**: 0.0 / 0.1 
- n4: **Leather jacket fabric roughness**: 0.62 
- n5: **Denim fabric roughness**: 0.9
