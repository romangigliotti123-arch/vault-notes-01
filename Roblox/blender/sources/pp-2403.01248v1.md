# pp-2403.01248v1

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Abstract-only page for SceneCraft (arXiv 2403.01248, Mar 2024): an LLM agent that turns text into Blender Python scripts for scenes with up to ~100 assets, using a scene graph, numerical layout constraints, a vision-language critique loop, and a learned function library. No Roblox, MCP, or export content. Only loosely relevant as prior art for LLM-written bpy.

## Claims
- c1: SceneCraft converts text descriptions into Blender-executable Python scripts that render scenes with up to a hundred 3D assets. *(doc, high; bpy-scripting-headless)*
- c2: It first builds a scene graph as a blueprint of spatial relationships, then writes scripts that translate those relationships into numerical layout constraints. *(doc, high; procedural-generation)*
- c3: A vision-language model (GPT-V) analyzes rendered images to iteratively refine the scene, giving a render-critique-fix loop. *(doc, high; creator-workflows)*
- c4: A library-learning mechanism compiles common script functions into a reusable library, so the agent improves without LLM parameter tuning. *(doc, high; bpy-scripting-headless)*
- c5: The paper reports it beats existing LLM agents on constraint adherence and human ratings. It also reconstructs scenes from the Sintel movie and uses generated scenes to guide a video generative model. The abstract gives no numbers. *(doc, medium; other)*

## Numbers
- n1: **max assets per scene**: up to ~100 scene complexity SceneCraft claims to handle

## Techniques
- t1: **Scene graph to constraint-based layout script**: Have the LLM produce a scene graph of asset relationships, then generate bpy code that turns the relations into numeric placement constraints.
- t2: **Render-and-critique refinement loop**: Render the scene, send the image to a vision-language model for critique, then revise the script. Repeat.
- t3: **Library learning**: Collect frequently used script functions into a reusable library the agent can call in later tasks.
