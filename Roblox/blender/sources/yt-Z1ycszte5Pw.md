Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox Studio tutorial on building a first-person weapon viewmodel: a hidden head part as camera reference, two arm parts, a gun from the Creator Store, anchored parts with collisions/queries/touch/shadows disabled, a Tool with Requires Handle and Can Be Dropped off, and a local controller script for mouse sway. No Blender, Claude, bpy, or Blender-to-Roblox export content.

## Claims
- c1: [3:10] Viewmodel parts should be anchored with CanCollide, CanQuery, CanTouch and CastShadow disabled so the model does not interfere with gameplay physics. *(doc, low; avatar-ugc-accessories)*
- c2: [3:10] The viewmodel Model's PrimaryPart is set to the head part, which the controller uses as the positioning reference. *(doc, low; other)*
- c3: [3:44] A Tool used only for equipping can disable Requires Handle and Can Be Dropped when the weapon visuals live in the viewmodel. *(doc, low; other)*
