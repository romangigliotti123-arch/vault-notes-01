## Summary
Roblox docs page on sculpting a head in Blender for avatar characters. Uses RoundMale template to make a goblin head with Grab, Smooth, Flatten, Elastic Deform, and Mask. Stresses non-destructive vertex preservation. No Claude, blender-mcp, bpy, or Roblox import/export specifics.

## Claims
- c1: Source is Roblox's sculpting tutorial for the RoundMale template (goblin head), using Blender sculpt mode; it does not cover blender-mcp, bpy, or the Roblox export pipeline. *(doc, high; other)*
- c2: Recommends sculpt tools that preserve vertices per Non-Destructive Modeling: Grab, Smooth, Flatten, Elastic Deform. *(doc, high; other)*
- c3: Setup: enable X-Axis symmetry and Wireframe in viewport; use Mask tool to paint over mouth and eyes before sculpting. *(doc, high; other)*
- c4: Head edits: flatten and enlarge top, elongate ears, extend nose bridge, widen brow, broaden chin; refinement pass for ear detail and cheeks. *(doc, medium; avatar-ugc-accessories)*

## Techniques
- t1: **Mask-protect then sculpt**: Select Head_Geo, enter Sculpting mode, enable X-symmetry, paint Mask over mouth and eyes, then Grab/Smooth edits.
