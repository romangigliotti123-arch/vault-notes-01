# off-dev_4022082

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox staff announcement (2025-10-23) that Open Cloud Assets API now accepts .rbxm models, animations, and Roblox-formatted meshes, mainly to re-upload native data downloaded via Roblox APIs/Studio. Warns externally edited .rbxm/mesh files may fail or misbehave due to Studio processing. Standard 3D formats should use Studio 3D Importer or FBX/glTF via Assets API. Legacy cookie-based upload endpoints to be deprecated after 3 months.

## Claims
- c1: Standard 3D formats should be imported via Studio 3D Importer, or uploaded through Open Cloud Assets API as FBX or glTF Models. *(doc, high; blender-roblox-export-import)*
- c2: Externally edited .rbxm or mesh files may not upload successfully or function correctly due to Studio's additional processing. *(doc, high; blender-roblox-export-import)*
- c3: Open Cloud Assets API now accepts .rbxm models, animations, and Roblox-formatted meshes as of 2025-10-23. *(doc, high; automation-and-creator-workflows)*
- c4: Legacy cookie-based upload endpoints (Upload.ashx, UploadNewMesh, UploadNewAnimation) planned for deprecation after 3 months. *(doc, high; automation-and-creator-workflows)*

## Numbers
- n1: **Legacy endpoint deprecation window**: 3 months 

## Techniques
- t1: **Blender export to Assets API**: Export model from Blender as FBX or glTF, then upload as Model via Open Cloud Assets API. Source does not mention Blender specifically.

## Quotes (brief, for attribution)
> If you are trying to import 3D assets in standard formats, use the 3D Importer in Studio or upload Models using the Assets API with either an FBX or glTF file.  (devforum.roblox.com)
> .rbxm or mesh files edited externally might not upload successfully or function correctly due to additional processing done by Studio.  (devforum.roblox.com)
