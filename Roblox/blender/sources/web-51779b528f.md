## Summary
Blender manual page for the Decimate modifier. Covers three modes: Collapse (ratio, symmetry, triangulate, vertex group), Un-Subdivide (iterations, meant for grid-based topology), and Planar (angle limit, delimit options, all boundaries). Not Roblox-specific; relevant only as a mesh-reduction tool before Roblox import.

## Claims
- c1: Blender Decimate modifier can reduce face count for performance; manual says it is not usually used on carefully modeled low-poly meshes. *(doc, high; roblox-mesh-limits)*
- c2: Decimate Collapse ratio: 1.0 leaves mesh unchanged, 0.5 keeps about half the faces, 0.0 removes all faces. *(doc, high; roblox-mesh-limits)*
- c3: Collapse ratio counts triangles, so quads stay unchanged if their edges are not collapsed, leaving more faces than expected unless Triangulate is enabled. *(doc, high; roblox-mesh-limits)*
- c4: Decimate modifier cannot be previewed in Edit Mode, unlike most modifiers. *(doc, high; common-mistakes-fixes)*
- c5: Planar mode Delimit options include UVs and Seam, preventing dissolving edges that are UV seams or part of a UV map. *(doc, medium; texturing-baking-uv)*
- c6: Un-Subdivide mode reverses a subdivide and is intended for mainly grid-based topology; two iterations equals one subdivide, so even numbers are usually used. *(doc, medium; procedural-generation)*

## Numbers
- n1: **Collapse ratio**: 1.0 unchanged; 0.5 half faces; 0.0 all removed Ratio is proportional to remaining triangles
- n2: **Un-Subdivide iterations**: 2 = one subdivide operation Use even numbers usually

## Techniques
- t1: **Decimate Collapse with Triangulate**: Set Ratio below 1.0 to reduce faces. Enable Triangulate so the ratio predicts face count accurately, since quads otherwise stay unchanged. Use Vertex Group plus Factor to limit where decimation applies.
- t2: **Un-Subdivide**: For grid-based meshes from subdivision, set Iterations (even numbers). Reverses subdivide by removing edges; unreliable after manual edits.
- t3: **Planar dissolve**: Set Angle Limit to dissolve edges between near-flat faces. Use Delimit (Normal, Material, Seam, Sharp, UVs) to protect edges; All Boundaries can help at high angle limits.
