Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox Studio Beta release note (2026-01-30) on the Universal Importer, which extends the 3D Import Queue to images, audio and video. Covers entry points, mixed-batch imports, per-file Creator inventory choice, and a Robux/limit confirmation for audio and video. Says nothing about Blender, bpy, blender-mcp, FBX/glTF settings, or mesh and texture limits, so it is only tangentially relevant.

## Claims
- c1: Universal Importer (Studio Beta) extends the 3D Import Queue to accept images, audio, video and 3D files in one batch; 3D files keep the existing importer path. *(doc, high; blender-roblox-export-import)*
- c2: Any file type previously supported by the legacy Bulk Importer can be selected, so Blender-exported FBX/OBJ-type 3D files go through the same queue. Source does not state specific format settings. *(doc, medium; blender-roblox-export-import)*
- c3: Creator (personal or group upload inventory) can be set per file before import starts. *(doc, high; automation-and-creator-workflows)*
- c4: Audio and video imports show a confirmation step with Robux cost and upload limits before upload. *(doc, high; automation-and-creator-workflows)*
- c5: Enable via Studio Beta Features tab; Asset Manager Import button now routes to Import Queue instead of legacy Bulk Importer when enabled. *(doc, high; automation-and-creator-workflows)*
- c6: Planned: design refresh, parallelized uploads for some asset types, and a 'Find In Workspace' action for inserted models. Full replacement of Bulk Importer is planned. *(doc, medium; automation-and-creator-workflows)*

## Techniques
- t1: **Mixed-batch import via Import Queue**: Open File > Import (Ctrl-M / Cmd-M) or Asset Manager Import. Select mixed image/audio/video/3D files. Set Creator per file. Confirm audio/video cost. Upload.
