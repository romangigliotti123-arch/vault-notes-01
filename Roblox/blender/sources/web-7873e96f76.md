## Summary
Roblox doc page on Studio's Importer for rigid accessories: import .fbx/.gltf via Home > Import, preview, then import as Model with textures on MeshPart.TextureID. Covers manual texture fix via Asset Manager (publish first if inaccessible, wait for moderation, set TextureID). Says nothing on Blender, bpy, or MCP.

## Claims
- c1: Studio's Importer accepts third-party .fbx or .gltf files, shows a preview, and error-checks against Studio's 3D requirements before import. *(doc, high; roblox-import-pipeline)*

## Techniques
- t1: **Manual texture reassignment**: Upload image in Asset Manager, wait for moderation, select MeshPart under imported Model, set TextureID to image asset ID.
