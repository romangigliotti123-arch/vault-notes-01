# off-dev_4709282

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox staff post announcing a Studio Beta UGC Validation visualization plugin for avatar assets (full avatar, head, clothing, rigid accessory, dynamic heads). Enable via Beta Features, add tool to toolbar, run validation, click messages to see visual overlays. Overhaul uses VaaS modular design and integrates Asset Quality scoring. No Blender, bpy, or FBX export content.

## Claims
- c1: Roblox released UGC Validation visualization as a Studio Beta plugin; enable via File > Beta Features > 'Visualizing UGC Validation', restart Studio, then add UGC Validation via the toolbar plus-tab. *(doc, high; avatar-ugc-accessories)*
- c2: Validation can be run on a selected full avatar, avatar head, one clothing item, or one rigid accessory in Explorer; user must pick the matching asset type before 'Run Validation'. *(doc, high; avatar-ugc-accessories)*
- c3: Validation errors are shown in red and warnings flag checks that passed but can improve quality score; clicking a message visualizes the issue. *(doc, high; avatar-ugc-accessories)*
- c4: Visual example: pants cage not tight enough and covering unrelated body parts, flagged in validation output. *(doc, medium; avatar-ugc-accessories)*
- c5: Dynamic head validation: select body model in Explorer and choose dynamic heads asset type; tool projects cage eyes/mouth landmarks onto the face; example low score 60 from misaligned landmarks. *(doc, high; avatar-ugc-accessories)*
- c6: Asset Quality system integrated with validation: non-compliant assets get errors; compliant assets get a quality assessment for optional improvement. *(doc, high; avatar-ugc-accessories)*
- c7: Validation overhauled into modular system to support Validation as a Service (VaaS), intended as step toward one unified validation system for Studio and in-game creation. *(doc, high; automation-and-creator-workflows)*
- c8: Validation runs as a background service and reports results as errors and/or warnings. *(doc, high; automation-and-creator-workflows)*
- c9: Source does not cover Blender, blender-mcp, bpy scripting, or FBX/glTF export settings; it is only about Studio's in-engine UGC validation tool. *(doc, high; other)*
- c10: Not all validation messages have a visual component; the docs list which checks are visualizable. *(doc, medium; other)*
