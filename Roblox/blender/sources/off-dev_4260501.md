Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox staff update on the Animation Clip Editor (ACE) importer. The importer now shares the Import 3D codepath, adding glTF support alongside FBX, auto-saves clips locally to ServerStorage/RBX_ANIMSAVES, supports multiple clips per file, adds a loading spinner and a rest-pose dialog. Upload still needs a separate step; reimport is in progress. Mentions Blender only as an example source. GA since March 31, 2026 after a 180-degree rotation bug fix.

## Claims
- c1: Animation Clip Editor importer now uses the same codepath as Import 3D, adding glTF support alongside FBX. *(doc, high; blender-roblox-export-import)*
- c2: Imported clips are auto-saved locally to ServerStorage/RBX_ANIMSAVES using the clip name; upload to Roblox still requires a separate step. *(doc, high; blender-roblox-export-import)*
- c3: Multiple animation clips in one glTF or FBX file are all saved on import and can be swapped in via the Load menu. *(doc, high; rigging-animation)*
- c4: Beta bug that rotated some animations 180 degrees was fixed before GA. *(doc, high; blender-roblox-export-import)*
- c5: Reimport support for animations is in development for faster iteration from external files. *(doc, medium; automation-and-creator-workflows)*
- c6: Rest pose dialog lets creators choose the imported file's rest pose or the existing rig in the Animation Editor. *(doc, high; rigging-animation)*

## Numbers
- n1: **GA date**: March 31, 2026 
- n2: **Local save path**: ServerStorage/RBX_ANIMSAVES 

## Techniques
- t1: **Import animation via ACE**: Open Animation Clip Editor, import FBX or glTF (e.g. exported from Blender), preview/edit, use Load menu to switch among clips, then upload as an animation asset separately.
