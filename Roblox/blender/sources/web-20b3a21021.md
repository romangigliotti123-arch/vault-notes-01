Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox official docs page for exporting an accessory from Blender as FBX for Studio import. Covers cleaning the scene (remove lights/cameras/mannequins, apply modifiers), FBX export settings: Path Mode Copy, Embed Textures on, Apply Scalings set to FBX Unit Scale. Says to check Export settings page for current specs. No Blender-MCP or bpy scripting content.

## Claims
- c1: Blender FBX export for Roblox accessories: File > Export > FBX, Path Mode set to Copy, Embed Textures enabled. *(doc, high; roblox-export-settings)*
- c2: Set Transform > Apply Scalings to FBX Unit Scale to avoid scale issues on import. *(doc, high; roblox-export-settings)*
- c3: Before export, delete extra objects (lights, cameras, mannequins) and apply modifiers so only the accessory mesh is exported. *(doc, high; common-mistakes-fixes)*
- c4: Docs also allow .gltf export; current settings are on the Export settings page, not this tutorial page. *(doc, medium; roblox-export-settings)*

## Techniques
- t1: **Manual FBX export for Studio**: Clean scene, apply modifiers, File > Export > FBX; Path Mode Copy; enable Embed Textures; Apply Scalings = FBX Unit Scale; Export FBX.
