Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
arXiv abstract page for DreamMesh (ECCV 2024), a text-to-3D method using triangle meshes with coarse-to-fine mesh deformation (text-guided Jacobians) and texturing via 2D diffusion. It has no content on Blender, Claude, blender-mcp, bpy, or Roblox pipelines.

## Claims
- c1: DreamMesh generates explicit textured triangle meshes from text via a coarse-to-fine scheme: coarse stage deforms mesh with text-guided Jacobians then textures from multiple views using interlaced 2D diffusion models, tuning-free. *(doc, high; other)*
- c2: Fine stage jointly manipulates the mesh and refines the texture map; authors claim it outperforms state-of-the-art text-to-3D methods (abstract claim, not verified here). *(doc, medium; other)*
