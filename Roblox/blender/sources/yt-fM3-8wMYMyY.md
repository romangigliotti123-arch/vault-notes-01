Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Darkfall video (2021-02-25) demoing Shader Library Blender add-on v1.7: install via Preferences > Add-ons (remove old version, install the .py), open N-panel shader library. New options: adjustable roughness for metallic materials, transparency slider for Ghost shader, wireframe size for Hologram shader. Not about Claude, blender-mcp, bpy pipelines, or Roblox export.

## Claims
- c1: [0:46] Shader Library v1.7 install: remove old version in Edit > Preferences > Add-ons, install downloaded .py, enable it, open N-panel. *(demo, high; other)*
- c2: [1:13] v1.7 Metallic materials gained a roughness setting in the operator (default 50) before adding the material. *(demo, high; other)*
- c3: [2:21] v1.7 Ghost shader operator gained a transparency slider; 1 is fully transparent, 0 is partially transparent. *(demo, high; other)*
- c4: [3:06] v1.7 Hologram shader operator gained a wireframe size option; slider max is 1 but values can be typed higher. *(demo, high; other)*
- c5: [1:39] Operator parameters can be changed after applying via the Redo panel. *(demo, medium; other)*
