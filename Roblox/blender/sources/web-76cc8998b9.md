## Summary
Blender manual page on UV layout workflow: split unwrapping into parts (head sphere project, ear project-from-view, neck cylinder project), then resolve overlapping islands via Ctrl-L/island select, pack islands, weld or stitch. Covers refining layout with scale and minimize stretch, multiple UV maps, and transferring UVs between meshes. Generic UV technique; no Roblox or Claude/bpy-specific content.

## Claims
- c1: Unwrapping a whole character mesh in one go yields messy UVs: ear and facial features squashed, neck overstretched. *(doc, high; texturing-baking-uv)*
- c2: Split unwrap: head via sphere_project, ear via project_from_view, neck via cylinder_project, each with the most suitable projection. *(doc, high; texturing-baking-uv)*
- c3: Overlapping islands fixed by selecting linked island (Ctrl-L or Island select mode), scaling/moving, or uv.pack_islands for automatic layout. *(doc, high; texturing-baking-uv)*
- c4: Join islands with uv.stitch (preferred) or uv.weld after aligning them. *(doc, high; texturing-baking-uv)*
- c5: Use minimize_stretch when UV map is too warped vs the 3D mesh; scale up areas needing more texture pixels. *(doc, high; texturing-baking-uv)*
- c6: A mesh can hold multiple UV maps; one for textures and another for prebaked lighting (lightmap). *(doc, high; texturing-baking-uv)*
- c7: Copy UVs between meshes with identical topology via object.join_uvs; for same surface with different topology use Data Transfer. *(doc, high; texturing-baking-uv)*

## Techniques
- t1: **Multi-step unwrap**: Select part, align view, apply suited projection (sphere/view/cylinder). Repeat per part. Then select all, pack islands or scale and place, and stitch seams.
- t2: **Seam-based single unwrap**: Mark seams around ear and neck, then one uv.unwrap call maps all parts.
