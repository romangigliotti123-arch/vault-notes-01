# web-84a5059308

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Blender Python API gotchas doc on armature data structures: edit_bones (Edit-Mode only, head/tail/roll/parenting), bones (Object-Mode data, editable in any mode, head/tail read-only), and pose bones (object.pose.bones, holds animation transforms, constraints, IK). Also warns that keeping edit-bone references after leaving Edit-Mode can crash Blender. Relevant only indirectly to Roblox pipeline.

## Claims
- c1: Edit bones exist only in Edit-Mode; accessed via object.data.edit_bones, used to set head/tail/roll and parenting. *(doc, high; bpy-scripting-headless)*
- c2: Bone head and tail properties are read-only on data.bones in Object/Pose mode; other Bone properties (e.g. use_deform) are editable in any mode. *(doc, high; bpy-scripting-headless)*
- c3: Animatable transforms, constraints and IK settings live on pose bones (object.pose.bones), not on armature data; this lets multiple objects share one armature in different poses. *(doc, high; rigging-animation)*
- c4: Keeping references to edit bones or their head/tail vectors after leaving Edit-Mode can crash Blender; scripts should separate mode-specific sections. *(doc, high; bpy-scripting-headless)*
- c5: bpy.context.active_bone returns an EditBone in Edit-Mode and a Bone outside it; active_pose_bone is pose-mode only. *(doc, medium; bpy-scripting-headless)*

## Techniques
- t1: **Choose the right bone data structure**: Use edit_bones in Edit-Mode to create/reparent bones; use data.bones for flags like use_deform in any mode; use pose.bones for transforms and constraints. Separate mode-switching sections so no edit-bone references survive mode changes.

### Code: Set edit bone head in Edit-Mode only
```python
bpy.context.object.data.edit_bones["Bone"].head = Vector((1.0, 2.0, 3.0))
```

### Code: Enable deform on a Bone; works in any mode
```python
bpy.context.object.data.bones["Bone"].use_deform = True
```

### Code: Read first constraint name on a pose bone
```python
bpy.context.object.pose.bones["Bone"].constraints[0].name
```
