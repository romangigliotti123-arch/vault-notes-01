# web-a99345c693

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox doc on cage meshes: invisible low-res surfaces on MeshPart (WrapTarget, WrapLayer) that let meshes deform over each other, paired by shared UV coordinates. Used for layered accessories. Cages authored in Blender/Maya; enable Uses Cages in 3D Importer. Does not cover blender-mcp, bpy, or Claude workflows.

## Claims
- c1: Cage meshes are invisible low-res surfaces of a MeshPart that let other paired meshes stretch and deform over each other; they power layered accessories like jackets and dresses. *(doc, high; avatar-ugc-accessories)*
- c2: Cage meshes can only work with other paired cage meshes, unlike the universal collision system. *(doc, high; avatar-ugc-accessories)*
- c3: Roblox pairs cage vertices by UV coordinates, not position, so cages sharing one UV layout can wrap over each other despite different shapes. *(doc, high; avatar-ugc-accessories)*
- c4: In Blender, a render mesh with a single _OuterCage mesh becomes a WrapTarget in Studio; a render mesh with _InnerCage and _OuterCage becomes a WrapLayer. *(doc, high; avatar-ugc-accessories)*
- c5: WrapTarget and WrapLayer are BaseWrap descendants, and a MeshPart is the only valid parent for them. *(doc, high; avatar-ugc-accessories)*
- c6: When importing a model with cages, Uses Cages must be enabled in the 3D Importer so Studio creates the cage objects. *(doc, high; blender-roblox-export-import)*
- c7: All targets and layers must share identical UVs for cage deformation to work. *(doc, high; avatar-ugc-accessories)*
- c8: Cages are typically authored in Blender or Maya and imported together with the render mesh; cages can also be created programmatically at runtime in specific experiences. *(doc, medium; automation-and-creator-workflows)*
- c9: The source does not cover blender-mcp, bpy scripting, or Claude usage; it only documents cage mesh concepts. *(doc, high; other)*

## Techniques
- t1: **Cage naming for layered accessories**: In Blender, name a render mesh's cages _OuterCage (target only) or _InnerCage plus _OuterCage (layer). Import with Uses Cages enabled so Studio creates WrapTarget/WrapLayer children. All cages must share identical UVs.

## Quotes (brief, for attribution)
> Roblox pairs cages by their UV coordinates rather than by position, so any two cages that share a UV layout can wrap over each other.  (create.roblox.com)
> Cage meshes can only work with other paired cage meshes.  (create.roblox.com)
