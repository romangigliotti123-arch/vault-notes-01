# pp-2401.07324v3

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
arXiv abstract on a multi-LLM agent framework (planner, caller, summarizer) for tool use with smaller LLMs, trained in two stages. It has no Blender, Roblox, blender-mcp or bpy content. Only loosely relevant as general background on LLM tool-use agent design.

## Claims
- c1: Tool-use capability is decomposed into three separate LLMs: planner, caller, summarizer. Each handles one sub-task, which allows individual updates and the use of smaller models. *(doc, high; other)*
- c2: Two-stage training: first fine-tune a backbone LLM on the whole dataset without separating sub-tasks. Then instantiate planner, caller and summarizer from it and fine-tune each on its own sub-task. *(doc, high; other)*
- c3: The authors report that the multi-LLM framework beats the single-LLM approach across various tool-use benchmarks. The abstract gives no numbers. *(doc, medium; other)*

## Techniques
- t1: **Planner/caller/summarizer decomposition**: Split an agent into three specialised LLMs for task planning, tool invocation and result summarization. Fine-tune a shared backbone on all data first, then fine-tune each copy on its own sub-task.
