Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox docs for the built-in Studio MCP server: setup for clients (Claude Code, Claude Desktop, Cursor etc.), JSON/CLI configs for Windows/macOS, and the tool list (Luau execution, script edit, generate_mesh, insert_asset, playtest, screen capture). Relevant to Claude-to-Studio automation; it has nothing on Blender, bpy, or FBX export.

## Claims
- c1: Roblox Studio has a built-in MCP server using stdio transport. AI clients can read the data model, edit scripts, run Luau, insert assets and control play mode in an open Studio session. *(doc, high; automation-and-creator-workflows)*
- c2: Quick connect supports Antigravity, Codex CLI, Claude Code, Claude Desktop, Cursor, Gemini CLI and VS Code. Enable it via Assistant > ... > Manage MCP Servers > Enable Studio as MCP server. *(doc, high; automation-and-creator-workflows)*
- c3: `generate_mesh` creates a textured 3D mesh from a text prompt using AI. This is a Studio-native alternative to Blender modeling for simple assets. *(doc, high; automation-and-creator-workflows)*
- c4: `insert_asset` inserts an already-uploaded asset by numeric ID (models, meshes, images, audio, animations, packages). The docs do not cover uploading Blender exports. `upload_image` only uploads images from HTTP URLs. *(doc, medium; automation-and-creator-workflows)*
- c5: `execute_luau` runs Luau in Studio and requires `datamodel_type` (Edit, Client or Server). It could be used after a Blender export to configure imported MeshParts, e.g. set SurfaceAppearance. *(doc, medium; automation-and-creator-workflows)*
- c6: Every tool call takes a `studio_id`. `list_roblox_studios` returns instance names, IDs and place IDs, so one client can drive several Studio windows. *(doc, high; automation-and-creator-workflows)*
- c7: `screen_capture` returns a viewport image, optionally from a custom camera position and look-at target. This lets an agent visually check imported meshes. *(doc, medium; automation-and-creator-workflows)*
- c8: The docs warn that MCP clients can read and modify content in open places, so only trusted clients should be connected. *(doc, high; automation-and-creator-workflows)*

## Techniques
- t1: **Connect Claude Code/Desktop to Studio MCP**: Update Studio. Enable Studio as MCP server in Assistant > Manage MCP Servers. Turn on the client under Assistant Settings > MCP Servers > Quick connect, or add the JSON/CLI config. Restart the client and check for the green connected indicator.
- t2: **Manual JSON config**: Add a Roblox_Studio entry to mcpServers. On Windows use command cmd.exe with args /c and %LOCALAPPDATA%\Roblox\mcp.bat. On macOS use /Applications/RobloxStudio.app/Contents/MacOS/StudioMCP. Separate entries with commas.
- t3: **Troubleshooting MCP connection**: Restart Studio and the client. Verify the binary path exists. Check the JSON for missing commas or brackets.

### Code: Windows MCP config for Roblox Studio
```json
{
  "mcpServers": {
    "Roblox_Studio": {
      "command": "cmd.exe",
      "args": [
        "/c",
        "%LOCALAPPDATA%\\Roblox\\mcp.bat"
      ]
    }
  }
}
```

### Code: macOS MCP config for Roblox Studio
```json
{
  "mcpServers": {
    "Roblox_Studio": {
      "command": "/Applications/RobloxStudio.app/Contents/MacOS/StudioMCP"
    }
  }
}
```
