## Summary
Blender manual introduction to modifiers: non-destructive stack, categories (Edit, Generate, Deform, Simulate), panel controls, Apply/Apply as Shape Key, stack ordering. General Blender modeling reference only; no Roblox, bpy scripting, MCP, or export content.

## Claims
- c1: Source is the Blender manual page on modifiers; it does not mention Roblox, Claude, blender-mcp, or bpy export pipelines. Off-topic for the target subject. *(doc, high; other)*
- c2: Modifiers are non-destructive; they change display/render but not base geometry, and can be applied to make permanent. Geometry Nodes node groups can be exposed as custom modifiers if flagged Modifier. *(doc, high; procedural-generation)*
- c3: New modifiers are added at bottom of stack and evaluated last; stack is evaluated top to bottom, so order changes result (e.g. Mirror before Subdivision Surface). *(doc, high; other)*
- c4: Applying a modifier that is not first in the stack ignores stack order and applies as if it were first, which may produce undesired results. *(doc, high; common-mistakes-fixes)*
- c5: Applying a modifier to an object sharing object data with other objects requires making it Single User first; modifiers cannot be applied to Empty objects. *(doc, high; common-mistakes-fixes)*
