# off-dev_4775593

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Roblox staff update (2026-08-04) on the Animation Clip Editor Importer: new settings for Rig Scale, Rest Pose Source, Rig Type (R15/Custom) and track selection. Imported 3D models now auto-save their animations to AnimSaves. Relevant only indirectly to Blender-to-Roblox work: it covers importing animations into Studio, not Blender export. Stud = 0.28 m.

## Claims
- c1: Animation Clip Editor Importer adds a Rig Scale setting to match animation scale to the Studio stud, plus a scale factor to directly scale the animation. *(doc, high; rigging-animation)*
- c2: Rest Pose Source lets the creator pick which track supplies the rest pose; previously it was always the first frame of the first track. *(doc, high; rigging-animation)*
- c3: Rig Type setting selects R15 or Custom when importing an animation. *(doc, high; rigging-animation)*
- c4: Imported Rig takes rest pose from the file's rig; Imported Rig (Zeroed Rotations) zeroes all bone rotations before taking the rest pose. *(doc, high; rigging-animation)*
- c5: Importing a 3D model via the Universal Importer now auto-saves its embedded animation data under AnimSaves, removing the separate select-model-then-import step. *(doc, high; automation-and-creator-workflows)*
- c6: Animation Clip Editor Importer lets the creator choose which animation track in the selected file to load. *(doc, high; rigging-animation)*
- c7: R15 suits emotes and humanoid functionality; Custom suits non-humanoid characters with custom rigs. *(doc, medium; rigging-animation)*
- c8: One stud equals 0.28 meters (11.02 inches), relevant when matching animation scale units. *(doc, high; mesh-texture-limits)*
- c9: Post does not mention Blender, bpy, blender-mcp, FBX/glTF export settings, or Claude; it covers only in-Studio animation import. *(doc, high; other)*

## Numbers
- n1: **stud length**: 0.28 m (11.02 in) Unit reference for Rig Scale matching
- n2: **default rest pose source**: first frame of first track Previous behavior before Rest Pose Source setting

## Techniques
- t1: **Rig Scale correction on import**: In Animation Clip Editor, click From File, pick file; in dialog set Rig Scale to match stud size, or set scale factor to scale the animation.
- t2: **Zeroed-rotation rest pose**: Choose Imported Rig (Zeroed Rotations) so all bone rotations are zeroed before the rest pose is read from the rig.
