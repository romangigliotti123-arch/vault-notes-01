# web-af064b2633

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
DevForum thread on Den_S's Roblox plugin + Blender addon that exports a Roblox rig as OBJ, rebuilds an armature in Blender, and exports Blender animation back as Roblox animation data. It covers install, workflow, FBX/Mixamo/BVH retargeting, headless bpy invocation, and common errors. Rigid Motor6D rigs only; skinned meshes unsupported. Dated (2017–2023, Blender 2.79–2.93+).

## Claims
- c1: Plugin exports any Roblox rig as OBJ; Blender addon 'Rebuild rig' generates an equivalent armature; animation is exported back as text to clipboard and loaded in Roblox via 'Load large animation'. *(doc, high; rigging-animation)*
- c2: Skinned meshes/bones are not supported; for skinned mesh animation use Roblox's built-in .fbx animation importer instead. *(doc, high; rigging-animation)*
- c3: Rig Motor6Ds must be direct children of the parent part (typically Part0), otherwise the plugin may not find the joint. *(doc, high; common-mistakes-fixes)*
- c4: Check the rig loads in the default Roblox Animation Editor first; the plugin does little error checking while the editor gives helpful errors. Outdated addon yields error 'object.name = partnames[-index]'. *(doc, high; common-mistakes-fixes)*
- c5: Animation parameters: scene frame start/end set length; fps sets frame duration; use step 1 at 30 fps for high quality, step 2–5 gives smoother (varies). *(doc, medium; rigging-animation)*
- c6: Mixamo/FBX animations can be imported via the 'Import FBX' button (FBX must contain one armature with animation) or 'map rig' button, which maps by bone name within the set frame range; set keying set to LocRot first. *(doc, high; rigging-animation)*
- c7: Armature object must be named __Rig / __Rig2 (the object, not armature data) for mapping; __Rig holds metadata so it cannot be replaced. *(experience, medium; rigging-animation)*
- c8: To copy your character for rigging: use Play Solo, copy the character from the workspace, paste out of play mode, and Anchor the HumanoidRootPart before running the plugin. *(experience, medium; creator-workflows)*
- c9: Humanoid appearances (clothing) no longer import automatically; workaround is exporting an OBJ of the character from Studio, importing into Blender and linking each mesh to the generated bones. *(doc, medium; common-mistakes-fixes)*
- c10: Addon operators can be scripted headless: run Blender with --python script.py --background -- args, calling rbxanims_importmodel, rbxanims_genrig, then export FBX or import FBX animation and rbxanims_bake (copies to clipboard). *(doc, high; bpy-scripting-headless)*
- c11: OBJ import errors occur if Blender's OBJ import addon is disabled; enabling it (and some community add-ons) fixed it. Rigs not at origin in Studio will import away from the Blender origin. *(experience, medium; common-mistakes-fixes)*
- c12: Addon saved from pastebin must have .py extension; Windows hiding file extensions leads to .py.txt files Blender won't list. *(experience, high; common-mistakes-fixes)*
- c13: R6 rigs export poorly: joints with non-identity rest rotation cause wrong transformations, and the face imports as a separate object; removing the face in Roblox helps. Unfixed as of 2017. *(experience, medium; rigging-animation)*
- c14: To save an animation without uploading, press Upload animation and cancel; KeyframeSequence is placed in Workspace and can be converted to an asset ID via KeyframeSequenceProvider. *(experience, medium; rigging-animation)*
- c15: BVH mocap can be retargeted onto R15 via the MakeHuman makewalk plugin (set frames to 500+), then used with the addon. *(experience, low; rigging-animation)*
- c16: Addon has 'Create IK constraints' tool: select end-of-chain bones in Pose mode, generate; tune parameters afterwards. Lock local bone axes in the IK panel to limit R15 lower limbs. *(doc, medium; rigging-animation)*

## Numbers
- n1: **recommended frame step at 30 fps for high quality**: 1 Steps 2–5 give smoother results
- n2: **supported Blender versions**: 2.80, 2.82, 2.91, 2.93+ (2.79 unmaintained) Addon versions
- n3: **mocap frame range suggested**: 500+ frames MakeHuman retarget

## Techniques
- t1: **Blender animation round trip**: Enable Roblox plugin, click rig, Export rig (.obj). Blender: File>Import OBJ, N panel>Rbx Animations>Rebuild rig. Pose mode, keyframe with LocRot keying set. Export animation (clipboard). Roblox: Load large animation, Upload animation.
- t2: **Mixamo retarget**: Export generated rig to FBX, upload to Mixamo, download animation, click Import FBX (or rename to __Rig2 and use map rig), set frame range and LocRot keying set first.
- t3: **Offset fix across frames**: Move bone (e.g. LowerTorso) in Pose mode, then run script looping frames to repeat_last and keyframe_insert across remaining frames, via Blender Text Editor.

### Code: Headless import of Roblox rig OBJ, generate armature, export FBX
```python
bpy.ops.object.rbxanims_importmodel(filepath=objpath)
bpy.ops.object.rbxanims_genrig()
bpy.ops.export_scene.fbx(filepath=fbxpath)
```

### Code: Convert FBX animation to Roblox string on clipboard
```python
bpy.ops.object.rbxanims_importmodel(filepath=objpath)
bpy.ops.object.rbxanims_genrig()
bpy.ops.object.rbxanims_importfbxanimation(filepath=fbxpath)
bpy.ops.object.rbxanims_bake()
```

### Code: Repeat last transform across all later frames and keyframe
```python
import bpy

for f_idx in range(bpy.context.scene.frame_current+1, bpy.context.scene.frame_end+1):
    bpy.context.scene.frame_set(f_idx)
    bpy.ops.screen.repeat_last()
    bpy.ops.anim.keyframe_insert()
```
