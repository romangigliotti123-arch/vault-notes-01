## Summary
Blender Today live #252 (Jan 2025) is a Blender 4.4 release-notes walkthrough. It has no Roblox, blender-mcp, Claude, or bpy-to-Roblox content. Only tangential items: glTF exporter gained an always-bake-animation option, USD import/export gained options, and Python API changes were noted for 4.4 with deprecations planned for 5.0.

## Claims
- c1: [54:24] Blender 4.4 glTF exporter adds an option to always bake scene animation so driven/animated properties can be exported; glTF import gained scene-extras and selection options. *(doc, medium; blender-roblox-export-import)*
- c2: [54:54] Blender 4.4 Python API has breaking changes (e.g., influence vertex group removed from texture mapping modifier in Grease Pencil API); larger sequencer API changes, with the old strip call style deprecated for 5.0. *(doc, medium; claude-blender-ai)*
- c3: [55:34] Blender 4.4 can be used as a Python module via pip (bpy-style module), optionally providing OpenColorIO/OpenImageIO-type VFX libraries. *(doc, low; claude-blender-ai)*
- c4: [1:39:27] Video sequencer Python API: strips are being renamed from the confusing 'sequence' naming; the old calls remain usable in 4.4 and are deprecated for 5.0. *(doc, low; claude-blender-ai)*
- c5: [17:30] Blender release schedule stated: 4.4 beta around Feb 4 2025, 4.4 release March 2025, 4.5 alpha Feb 2025 timing, Blender 5.0 targeted November 2025. *(doc, low; other)*
