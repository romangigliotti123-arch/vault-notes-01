# web-c35023e341

Personal-use research note. Brief quotes only, with attribution; see the original at the URL above.

## Summary
Blender Python API gotchas page on file paths and string encoding. Covers why Blender's // relative paths break standard os/sys modules, using bpy.path.abspath (with library= for linked data), and that blend-file strings must be UTF-8/ASCII-compatible while filesystem paths may not be. Gives os.fsencode workarounds and repr() advice for printing paths. Not Roblox-specific.

## Claims
- c1: Blender '//' relative paths are not understood by Python's os/sys; use bpy.path.abspath(image.filepath) before exporting material image paths. *(doc, high; bpy-scripting-headless)*
- c2: For data from linked libraries, pass library=image.library to bpy.path.abspath so the path resolves relative to the library blend-file, not the open file. *(doc, high; bpy-scripting-headless)*
- c3: All strings in blend-files must be UTF-8/ASCII-compatible; assigning non-UTF-8 strings (e.g. to object names) raises an error. Paths are the exception. *(doc, high; bpy-scripting-headless)*
- c4: Printing bpy.data.filepath can raise UnicodeEncodeError on non-ASCII file systems; assigning it to an object name raises TypeError. Fix: os.fsencode then decode utf-8 with 'replace'. *(doc, high; common-mistakes-fixes)*
- c5: Use os.fsencode/os.fsdecode rather than str decoding for paths, os.path functions rather than string manipulation, and repr(path) for printing or UI display. *(doc, high; bpy-scripting-headless)*

## Techniques
- t1: **Absolute path resolution for export**: Call bpy.path.abspath(image.filepath) and, for linked data, pass library=image.library. Use the result with native Python file APIs when exporting textures.
- t2: **Safe path-to-string conversion**: filepath_bytes = os.fsencode(bpy.data.filepath); decode('utf-8','replace') before assigning to a name. Print with repr() to avoid encoding errors.

### Code: Resolve Blender relative image path for export, linked-library aware
```python
bpy.path.abspath(image.filepath)
bpy.path.abspath(image.filepath, library=image.library)
```
