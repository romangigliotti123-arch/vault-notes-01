# "Blender to Roblox export, import and common mistakes"

Back to [[blender-README]] | [[blender-playbook]]

Sources establish a Blender→Roblox pipeline built on FBX or glTF export and Studio's 3D Importer. Documented FBX settings: Apply Scalings = FBX Unit Scale, Path Mode Copy with Embed Textures, Add Leaf Bones off, selected objects only, modifiers applied. Import scale is changing: on June 16, 2026 non-Stud units move from 20 studs/m to 25:7, and a Scale Factor field is added. Reimport (Beta, Nov 2025) updates models in place (Alt+Shift+R). Quick Import (Alt+M) and the Known Asset Cache speed iteration. Studio glTF export is beta and has permission limits. The official Roblox Blender plugin (v1.0.5) targets Blender 5.x; older versions had Blender 4.0 and dependency-install errors. Common mistakes: unapplied modifiers, linear textures, unpacked images, renamed meshes, and moved pivots.

## Key points
- **[OFFICIAL]** [OFFICIAL] Recommended Blender FBX export settings for Studio: Apply Scalings = FBX Unit Scale, Path Mode = Copy with Embed Textures, Add Leaf Bones disabled, limit to selected objects, extra objects (lights, cameras) removed, modifiers applied or removed. *(multiple-sources, high)* [[sources/off-art_accessories_creating_exporting|off-art_accessories_creating_exporting]] [[sources/off-art_blender|off-art_blender]] [[sources/off-art_modeling_export-requirements|off-art_modeling_export-requirements]] [[sources/off-art_characters_creating_blender-configurations|off-art_characters_creating_blender-configurations]]
- **[OFFICIAL]** [OFFICIAL] Axis and unit settings: Blender Scene Units = None with Rotation in Degrees; export Forward Z, Up Y; Studio import with World Forward Front, World Up Top, Scale Unit Stud, Insert Using Scene Position enabled. glTF avoids the FBX scaling workarounds. *(single-source, medium)* [[sources/off-art_blender|off-art_blender]]
- **[OFFICIAL]** [OFFICIAL] Importer unit conversion changes on June 16, 2026: non-Stud units (m, cm, mm, ft, in) move from 20 studs/m to 25:7 studs/m. Old ratio made meter-authored meshes ~5.6x too large. Stud unit is unchanged. A new Scale Factor field multiplies on top and is saved in presets. Setting 5.6 with a non-Stud unit preserves the old behavior. *(single-source, high)* [[sources/off-dev_4644371|off-dev_4644371]]
- **[OFFICIAL]** [OFFICIAL] The Scale Factor is available now. A warning shows on non-Stud units until July 14, 2026. Default unit is Studs. The importer supports glTF, FBX and OBJ. The same option is planned for the Animation Clip Editor importer. *(single-source, medium)* [[sources/off-dev_4644371|off-dev_4644371]]
- **[OFFICIAL]** [OFFICIAL] Reimport (Beta, announced 2025-11-13) updates FBX/glTF-imported Models and SurfaceAppearances in place via right-click or Alt+Shift+R. It matches meshes by name, so renaming a mesh in Blender creates a new MeshPart and leaves the old one. Pre-rename the MeshPart in Studio to avoid this. Modified pivots misalign; use 'Reimport relative to this' on an unmoved MeshPart. File paths are stored device-local, not in the place file. *(multiple-sources, high)* [[sources/off-dev_4068650|off-dev_4068650]] [[sources/off-dev_4112031|off-dev_4112031]]
- **[OFFICIAL]** [OFFICIAL] Quick Import (Alt+M / Option+M) imports one file with Studio Default settings. It does not support animations and does not add the model to inventory automatically. The Known Asset Cache skips re-upload of unchanged content (keyed by content hash plus creator ID, session-local). Moving an object causes floating-point differences that usually miss the cache. *(single-source, high)* [[sources/off-dev_3958222|off-dev_3958222]]
- **[OFFICIAL]** [OFFICIAL] Studio glTF export is a beta feature. It exports account or group assets with skinning, textures and cages, but not animation. It cannot export Avatar Marketplace assets, acquired Creator Store assets, or unshared collaborator assets. A known bug hangs exports that contain only non-numeric asset IDs. *(multiple-sources, high)* [[sources/off-dev_3905928|off-dev_3905928]] [[sources/off-art_modeling_gltf-export|off-art_modeling_gltf-export]]
- **[CORROBORATED]** [CORROBORATED] The Geometry Nodes result is a modifier. Exporting with export_apply=False writes only the base mesh, silently (2,688 triangles exported as 2). Apply modifiers before export. *(multiple-sources, medium)* [[sources/gh-elithril-blender-kiln-f-plugin-references-batch-mode.md|gh-elithril-blender-kiln-f-plugin-references-batch-mode.md]] [[sources/off-art_accessories_creating_exporting|off-art_accessories_creating_exporting]]
- **[OUTDATED/UNSURE]** [OUTDATED/UNSURE] glTF carries textures, not node trees. Procedural or box-projected shaders must be baked to the asset's UVs, and images must be packed or they render black. On Blender 5.2.2, linear float base-colour images are written without the sRGB transfer, so they ship near-black. Convert to an sRGB byte image first. *(single-source, medium)* [[sources/gh-elithril-blender-kiln-f-plugin-references-reference-fidelity.md|gh-elithril-blender-kiln-f-plugin-references-reference-fidelity.md]]
- **[OFFICIAL]** [OFFICIAL] The importer auto-sets DoubleSided and Transparency when the colour map is connected to alpha in the Blender PBR material and exported as glTF/FBX. Maya FBX does not get this. *(single-source, high)* [[sources/off-dev_4137281|off-dev_4137281]]
- **[OFFICIAL]** [OFFICIAL] The official Roblox Blender plugin v1.0.5 (2026-04-20) fixes install and startup errors on Blender 5.0 and 5.1, may not work on Blender 4.x or earlier, and sanitizes exported file names. The plugin needs Blender 3.2+ and a one-time 'Install Dependencies' click. *(multiple-sources, high)* [[sources/off-gh-roblox-blender-plugin-rel-v1.0.5|off-gh-roblox-blender-plugin-rel-v1.0.5]] [[sources/gh-Roblox-roblox-blender-plugin-rel-v1.0.5|gh-Roblox-roblox-blender-plugin-rel-v1.0.5]] [[sources/gh-Roblox-roblox-blender-plugin-i8|gh-Roblox-roblox-blender-plugin-i8]] [[sources/off-gh-roblox-blender-plugin-README|off-gh-roblox-blender-plugin-README]]
- **[OFFICIAL]** [OFFICIAL] Historical plugin errors: Blender 4.0 'selected_ids' AttributeError (fixed in v1.0.3); Windows pip exit code 3221225781. Use the system console to read tracebacks. *(multiple-sources, medium)* [[sources/gh-Roblox-roblox-blender-plugin-i32|gh-Roblox-roblox-blender-plugin-i32]] [[sources/gh-Roblox-roblox-blender-plugin-rel-v1.0.3|gh-Roblox-roblox-blender-plugin-rel-v1.0.3]] [[sources/gh-Roblox-roblox-blender-plugin-i14|gh-Roblox-roblox-blender-plugin-i14]] [[sources/gh-Roblox-roblox-blender-plugin-i20|gh-Roblox-roblox-blender-plugin-i20]] [[sources/gh-Roblox-roblox-blender-plugin-i8|gh-Roblox-roblox-blender-plugin-i8]] [[sources/gh-Roblox-roblox-blender-plugin-i57|gh-Roblox-roblox-blender-plugin-i57]]
- **[OFFICIAL]** [OFFICIAL] Cages and rigs: with cages in the file, enable 'Uses Cages' in the importer. A single _OuterCage makes a WrapTarget; _InnerCage plus _OuterCage makes a WrapLayer. The importer's Constraint Type defaults to Joint Upgrade; use it for multi-bone rigs, since Motor6D import gives a warning and broken playback. Roblox's Rig_and_Attachments_Template.blend is recommended, and transforms should be applied after aligning the armature. *(multiple-sources, high)* [[sources/off-art_modeling_cage-meshes_index|off-art_modeling_cage-meshes_index]] [[sources/off-dev_4541689|off-dev_4541689]] [[sources/off-art_accessories_creating_armature-setup|off-art_accessories_creating_armature-setup]]
- **[CORROBORATED]** [CORROBORATED] Third-party Blender MCP or export-preset tools surveyed have no Roblox preset (VRChat, Resonite, Unity only). Externally edited .rbxm or mesh files may fail to upload. *(multiple-sources, medium)* [[sources/gh-sandraschi-blender-mcp-f-docs-blender-TOOL_REFERENCE.md|gh-sandraschi-blender-mcp-f-docs-blender-TOOL_REFERENCE.md]] [[sources/gh-sandraschi-blender-mcp-f-mcpb-packaging-README.md|gh-sandraschi-blender-mcp-f-mcpb-packaging-README.md]] [[sources/gh-sandraschi-blender-mcp-f-mcpb-assets-prompts-user.md|gh-sandraschi-blender-mcp-f-mcpb-assets-prompts-user.md]] [[sources/off-dev_4022082|off-dev_4022082]]

## Techniques
- **[OFFICIAL]** **[OFFICIAL] FBX export for Studio**: Select objects, enable Selected Objects, set Path Mode Copy with Embed Textures, Apply Scalings = FBX Unit Scale, and turn off Add Leaf Bones. Apply modifiers first. [[sources/off-art_accessories_creating_exporting|off-art_accessories_creating_exporting]] [[sources/off-art_modeling_export-requirements|off-art_modeling_export-requirements]]
- **[OFFICIAL]** **[OFFICIAL] Author in meters, import with Meter**: After June 16, 2026, model in meters and choose Meter in the importer with factor 1.0. For legacy workflows, use factor 5.6. [[sources/off-dev_4644371|off-dev_4644371]]
- **[CORROBORATED]** **[CORROBORATED] In-place Reimport loop**: Export again from Blender, then in Studio use Reimport > Configure to set the path once, and press Alt+Shift+R after each export. [[sources/yt-uElRpN1ZQ-4|yt-uElRpN1ZQ-4]] [[sources/off-dev_4068650|off-dev_4068650]]
- **[OFFICIAL]** **[OFFICIAL] Pre-rename MeshParts / reimport relative**: Rename the Studio MeshPart to match the new Blender name. If the pivot moved, use 'Reimport relative to this' on an unmoved part. [[sources/off-dev_4068650|off-dev_4068650]]
- **[SINGLE-SOURCE]** **[SINGLE-SOURCE] Bake and pack before glTF export**: Bake procedural shaders to UV textures, convert linear data to an sRGB byte image, and run bpy.ops.file.pack_all(). [[sources/gh-elithril-blender-kiln-f-plugin-references-reference-fidelity.md|gh-elithril-blender-kiln-f-plugin-references-reference-fidelity.md]]
- **[OFFICIAL]** **[OFFICIAL] Plugin troubleshooting**: Open Window > Toggle System Console (Windows) or launch from a terminal (macOS). Click Install Dependencies and read the traceback. Rename objects containing '/'. [[sources/gh-Roblox-roblox-blender-plugin-i57|gh-Roblox-roblox-blender-plugin-i57]] [[sources/gh-Roblox-roblox-blender-plugin-i8|gh-Roblox-roblox-blender-plugin-i8]]
- **[OFFICIAL]** **[OFFICIAL] Isolation test**: Export the same model as FBX and OBJ, import via Studio's importer, and compare with the plugin upload. [[sources/gh-Roblox-roblox-blender-plugin-i74|gh-Roblox-roblox-blender-plugin-i74]]

## Disagreements
- **Which scale approach to use for Blender FBX exports**: FBX Unit Scale with Scene Units None and Studio import unit Stud [[sources/off-art_blender|off-art_blender]] | Newer importer docs add real-world units (Meter) with 25:7 scaling and a Scale Factor field from 2026-06-16, and the older 20:1 ratio is described as producing oversized meshes [[sources/off-dev_4644371|off-dev_4644371]] Note: S265 is newer (2026-05) than the 2026-10-31 crawl dates of the S2xx docs, but these are crawl dates. The settings are not strictly contradictory: both can work if the unit and export scale match.
- **Plugin compatibility with Blender 4.x**: v1.0.3 fixed uploading in Blender 4.0 [[sources/gh-Roblox-roblox-blender-plugin-rel-v1.0.3|gh-Roblox-roblox-blender-plugin-rel-v1.0.3]] | v1.0.5 targets Blender 5.x and may not work on 4.x or earlier [[sources/off-gh-roblox-blender-plugin-rel-v1.0.5|off-gh-roblox-blender-plugin-rel-v1.0.5]] [[sources/gh-Roblox-roblox-blender-plugin-rel-v1.0.5|gh-Roblox-roblox-blender-plugin-rel-v1.0.5]] Note: The newer 2026 release notes take precedence for current versions. Use v1.0.3 or an older release for Blender 4.x.

## Gaps
- No source gives the exact glTF export settings to use in Blender for Roblox. Most settings guidance is for FBX.
- The root cause of several plugin 'Unknown Error' and 'Add-on error' reports was never established.
- Whether the June 16, 2026 scale change shipped as planned is not verified. Sources are pre-announcements.
- There is no Blender-specific guidance on using blender-mcp or bpy scripts for export, and no Roblox export preset exists in the surveyed MCP tools.
- The Reimport YouTube demo comes from a source with insufficient credibility. Its claims are only corroborated by the official Reimport announcement.
