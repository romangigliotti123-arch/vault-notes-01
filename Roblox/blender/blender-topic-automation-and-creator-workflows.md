# "Open Cloud automation, plugins and what top creators do"

Back to [[blender-README]] | [[blender-playbook]]

Sources establish that Roblox's open-source Blender plugin (Roblox/roblox-blender-plugin) uploads meshes/collections to Roblox via Open Cloud OAuth as packages, with versioning through a 'Roblox Package ID' custom property. Common failures are dependency install, DNS/aiodns login errors, and duplicate installs. The Open Cloud Assets API (single HTTP request, 20 MB, operation polling, API key with x-api-key) now accepts .rbxm, animations and Roblox meshes (2025-10-23), but docs still recommend the Studio Importer for custom 3D models. Studio Reimport, import queue presets, and validation tooling reduce manual steps. Creator workflows shown involve naming conventions, manifest-driven batch runs, and Blender animation export via clipboard. The notes contain no direct blender-mcp or Claude content from official Roblox sources.

## Key points
- **[OFFICIAL]** [OFFICIAL] Roblox Blender plugin uploads selected meshes or collections via Open Cloud; each selected object becomes its own asset, a collection becomes one asset. It is an open-source reference implementation of Open Cloud that developers are encouraged to extend. *(multiple-sources, high)* [[sources/off-gh-roblox-blender-plugin-README|off-gh-roblox-blender-plugin-README]] [[sources/off-art_modeling_roblox-blender-plugin|off-art_modeling_roblox-blender-plugin]] [[sources/web-1170ea0231|web-1170ea0231]]
- **[OFFICIAL]** [OFFICIAL] Setup: click Install Dependencies once in the N-panel Roblox tab, restart Blender, then log in via browser OAuth, choose account/groups, and pick the creator from the 'Upload to' dropdown. *(single-source, high)* [[sources/off-gh-roblox-blender-plugin-README|off-gh-roblox-blender-plugin-README]]
- **[OFFICIAL]** [OFFICIAL] Uploads are packages (visible in Toolbox > Inventory > My Packages). Re-uploading updates the existing package; PackageLink AutoUpdate in Studio overwrites local modifications. Deleting the 'Roblox Package ID' custom property in Blender makes the next upload a new asset ID. *(single-source, high)* [[sources/off-gh-roblox-blender-plugin-README|off-gh-roblox-blender-plugin-README]]
- **[OFFICIAL]** [OFFICIAL] Roblox accepts only bug-fix PRs for the plugin, not new features. Releases are built by GitHub Actions on v#.#.# tags; CI requires black formatting; dev uses VS Code with the blender-development extension. Recent changes (2026-04-20): Blender 5.0 add-on UI README, clearer login errors (PR #106). *(multiple-sources, high)* [[sources/off-gh-roblox-blender-plugin-README|off-gh-roblox-blender-plugin-README]] [[sources/off-gh-roblox-blender-plugin-rel-v1.0.5|off-gh-roblox-blender-plugin-rel-v1.0.5]] [[sources/gh-Roblox-roblox-blender-plugin-rel-v1.0.5|gh-Roblox-roblox-blender-plugin-rel-v1.0.5]]
- **[OFFICIAL]** [OFFICIAL] Login/install troubleshooting: DNS error on Windows (Blender 5.1 and 4.5.8) fixed by deleting the bundled aiodns folder; clean reinstall for ModuleNotFoundError; install from repo if the release skips the dependency prompt; avoid rapid repeat logins (429); select a creator on the OAuth page. Use the system console to see logs. *(multiple-sources, high)* [[sources/gh-Roblox-roblox-blender-plugin-i112|gh-Roblox-roblox-blender-plugin-i112]] [[sources/gh-Roblox-roblox-blender-plugin-i35|gh-Roblox-roblox-blender-plugin-i35]] [[sources/gh-Roblox-roblox-blender-plugin-i75|gh-Roblox-roblox-blender-plugin-i75]] [[sources/gh-Roblox-roblox-blender-plugin-i12|gh-Roblox-roblox-blender-plugin-i12]] [[sources/gh-Roblox-roblox-blender-plugin-i20|gh-Roblox-roblox-blender-plugin-i20]]
- **[OFFICIAL]** [OFFICIAL] Open Cloud Assets API: one asset per call up to 20 MB, x-api-key with assets permission and Read/Write on the game, upload returns an operation to poll for assetId and moderation result. Use via rbxassetid:// or Content.fromAssetId(). *(multiple-sources, high)* [[sources/off-cloud_guides_usage-assets|off-cloud_guides_usage-assets]] [[sources/web-57279f4b4c|web-57279f4b4c]]
- **[OFFICIAL]** [OFFICIAL] As of 2025-10-23 the Assets API accepts .rbxm models, animations and Roblox-formatted meshes; legacy cookie-based upload endpoints (Upload.ashx etc.) were slated for deprecation after 3 months. Animation creation via CreateAssetAsync was announced May 2025. *(multiple-sources, high)* [[sources/off-dev_4022082|off-dev_4022082]] [[sources/off-dev_3642901|off-dev_3642901]]
- **[OFFICIAL]** [OFFICIAL] Update Asset currently supports only .fbx content, each update creating a new version; docs still recommend the Studio Importer for custom 3D models (3D preview, error checks, settings). OAuth 2.0 use needs asset:read/asset:write and is beta. *(multiple-sources, high)* [[sources/off-cloud_guides_usage-assets|off-cloud_guides_usage-assets]] [[sources/web-57279f4b4c|web-57279f4b4c]]
- **[OFFICIAL]** [OFFICIAL] Studio Reimport non-destructively updates Model and SurfaceAppearance from the remembered source file, adds an undo checkpoint, persists across copy/paste and packages. Enabled for everyone Dec 3, 2025; fully released May 20, 2026 (Accessory, Decal, Audio, Video unsupported at original post). *(multiple-sources, medium)* [[sources/off-dev_4068650|off-dev_4068650]] [[sources/off-dev_4112031|off-dev_4112031]] [[sources/off-dev_3958222|off-dev_3958222]]
- **[OFFICIAL]** [OFFICIAL] Studio import queue supports bulk import with per-item presets (Studio Default, Last Imported, custom), Apply settings to all, Upload to Roblox toggle for test iteration, and Import as Package (off by default). *(multiple-sources, high)* [[sources/off-studio_importer|off-studio_importer]] [[sources/web-5d5513d689|web-5d5513d689]]
- **[SINGLE-SOURCE]** [SINGLE-SOURCE] Creator batch practice: manifest-driven unattended runs with YAML status updated after each asset (failures skipped, no retry); PascalCase SM_ naming with matching _Mesh data-block names; batch rename through bpy; post-import normalization checks. *(multiple-sources, medium)* [[sources/gh-elithril-blender-kiln-f-plugin-references-batch-mode.md|gh-elithril-blender-kiln-f-plugin-references-batch-mode.md]] [[sources/gh-elithril-blender-kiln-f-plugin-references-naming-conventions.md|gh-elithril-blender-kiln-f-plugin-references-naming-conventions.md]] [[sources/gh-elithril-blender-kiln-f-plugin-references-sourcing-strategy.md|gh-elithril-blender-kiln-f-plugin-references-sourcing-strategy.md]]
- **[SINGLE-SOURCE]** [SINGLE-SOURCE] Blender animation workflow: export from the RBX Animations add-on to clipboard, import in Studio with the Blender Animations plugin; the rig PrimaryPart must be anchored or import errors (the cause of most failed imports). *(single-source, medium)* [[sources/yt-EM9u4gIHoRg|yt-EM9u4gIHoRg]]
- **[OFFICIAL]** [OFFICIAL] Roblox lists Blender tools: the open-source Blender Studio plugin, a Validation Tool, and a Calisthenics Tool. Studio's Accessory Fitting Tool auto-adds attachments and can generate skinning at runtime. *(multiple-sources, medium)* [[sources/web-3cd0175a8a|web-3cd0175a8a]] [[sources/off-avatar_layered-accessories_specifications|off-avatar_layered-accessories_specifications]] [[sources/off-avatar_layered-accessories_index|off-avatar_layered-accessories_index]]
- **[CORROBORATED]** [CORROBORATED] Official Roblox sources checked contain no blender-mcp, bpy or Claude content; Studio MCP server material comes only from low-credibility video sources. *(multiple-sources, medium)* [[sources/off-dev_4068650|off-dev_4068650]] [[sources/off-art_modeling_specifications|off-art_modeling_specifications]] [[sources/gh-Roblox-roblox-blender-plugin-rel-v1.0.1|gh-Roblox-roblox-blender-plugin-rel-v1.0.1]] [[sources/yt-v8r1d80DxOY|yt-v8r1d80DxOY]]

## Techniques
- **[OFFICIAL]** **[OFFICIAL] Re-version a package**: Upload again from Blender to update the existing package; enable PackageLink AutoUpdate in Studio; delete the Roblox Package ID custom property to publish a new asset ID. [[sources/off-gh-roblox-blender-plugin-README|off-gh-roblox-blender-plugin-README]]
- **[OFFICIAL]** **[OFFICIAL] Group into one asset**: Put objects in a Collection, select the Collection, Upload. [[sources/off-gh-roblox-blender-plugin-README|off-gh-roblox-blender-plugin-README]]
- **[OFFICIAL]** **[OFFICIAL] Fix login DNS error**: Delete the aiodns folder in the plugin's dependencies-public folder, restart Blender, log in again. [[sources/gh-Roblox-roblox-blender-plugin-i112|gh-Roblox-roblox-blender-plugin-i112]]
- **[OFFICIAL]** **[OFFICIAL] Versioned FBX update via API**: PATCH /assets/v1/assets/{assetId} with assetType, assetId, optional fileContent; updateMask for metadata; only .fbx. [[sources/off-cloud_guides_usage-assets|off-cloud_guides_usage-assets]]
- **[SINGLE-SOURCE]** **[SINGLE-SOURCE] Manifest-driven batch**: Wizard writes batch-manifest.yaml; runner loops over not-done assets, logs, takes viewport screenshots, writes batch-report.md, and rewrites the manifest after each asset. [[sources/gh-elithril-blender-kiln-f-plugin-references-batch-mode.md|gh-elithril-blender-kiln-f-plugin-references-batch-mode.md]]
- **[SINGLE-SOURCE]** **[SINGLE-SOURCE] Batch rename via bpy**: Set obj.name to Prefix_Name and obj.data.name to Prefix_Name_Mesh; prefix materials with M_. [[sources/gh-elithril-blender-kiln-f-plugin-references-naming-conventions.md|gh-elithril-blender-kiln-f-plugin-references-naming-conventions.md]]
- **[OFFICIAL]** **[OFFICIAL] Batch import queue with shared preset**: Add files to the queue, configure one item, Apply settings to all, save preset, Import. [[sources/off-studio_importer|off-studio_importer]]
- **[OFFICIAL]** **[OFFICIAL] Capture Blender console logs**: Windows: Window > Toggle System Console; macOS: launch Blender from Terminal. [[sources/gh-Roblox-roblox-blender-plugin-i12|gh-Roblox-roblox-blender-plugin-i12]] [[sources/gh-Roblox-roblox-blender-plugin-i20|gh-Roblox-roblox-blender-plugin-i20]]
