# "other"

Back to [[blender-README]] | [[blender-playbook]]

This "other" bucket is mostly peripheral material. Many sources (Roblox docs on cages, skinning, validation, audio, and Studio Assistant; Blender-MCP release notes and READMEs) explicitly lack Roblox export guidance, such as scale, axis, FBX/glTF settings, or triangle and texture limits. What the notes do establish: Roblox publishes an open-source Studio MCP server and a reference-implementation Blender plugin that takes bug-fix PRs only. Blender-mcp variants export GLB/GLTF/FBX/OBJ/USD headless. The kiln plugin shrank its install from 46 MB to about 9 MB. Benchmark hygiene guidance stresses isolated runs and repeated trials. Several Principled BSDF details apply to Cycles versus EEVEE. Roblox audio import limits are documented.

## Techniques
- **[SINGLE-SOURCE]** **[SINGLE-SOURCE] Reference camera matching**: Create a named camera in bpy, match projection and framing first, compare silhouettes or overlay, fix the largest mismatch, and keep the camera fixed while editing geometry. [[sources/gh-ifBars-blender-agent-studio-f-plugins-blender-agent-studio-skills-blender-modeling-workflo|gh-ifBars-blender-agent-studio-f-plugins-blender-agent-studio-skills-blender-modeling-workflo]]
- **[OFFICIAL]** **[OFFICIAL] Thin-walled material**: Enable Thin Wall for paper, leaves or window sheets; in EEVEE set Thickness 0 and Thickness Mode Slab. Subsurface inputs are ignored. [[sources/web-49f00d77aa|web-49f00d77aa]]
- **[OUTDATED/UNSURE]** **[OUTDATED/UNSURE] PBR texture auto-setup**: Enable Node Wrangler, extract the Poly Haven zip, select all texture files, and run Principled Texture Setup (Ctrl+Shift+T) with the Principled BSDF selected. [[sources/yt-rwUuX-Iwkus|yt-rwUuX-Iwkus]]
- **[OFFICIAL]** **[OFFICIAL] Re-login for revoked token**: Log out of the Roblox plugin and log in again to get a new refresh token (reported as not helping in one case). [[sources/gh-Roblox-roblox-blender-plugin-i57|gh-Roblox-roblox-blender-plugin-i57]]
- **[CORROBORATED]** **[CORROBORATED] Benchmark isolation**: Sandbox each session, audit transcripts, and record agent CLI, requested and observed model, and output hashes. [[sources/gh-ifBars-blender-agent-studio-f-plugins-blender-agent-studio-skills-blender-agent-benchmark-|gh-ifBars-blender-agent-studio-f-plugins-blender-agent-studio-skills-blender-agent-benchmark-]] [[sources/gh-elithril-blender-kiln-f-docs-benchmarks.md|gh-elithril-blender-kiln-f-docs-benchmarks.md]]
