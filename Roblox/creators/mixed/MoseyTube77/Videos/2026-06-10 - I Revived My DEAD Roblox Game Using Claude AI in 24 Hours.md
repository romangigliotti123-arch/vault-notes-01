## Tips
- [2:07](https://youtu.be/esZQX5COI_E?t=127) **[[core-loops-and-game-design]]** Give idle plot elements a purpose: replace a dead placeholder pad with a reward mechanic (wheel spin for cash every hour) that players return to.
- [2:47](https://youtu.be/esZQX5COI_E?t=167) **[[retention-d1-d7]]** Add a daily challenges board with three random tasks every 24 hours, each paying a reward, to give players a reason to return.
- [2:07](https://youtu.be/esZQX5COI_E?t=127) **[[common-mistakes]]** Don't leave non-functional UI like a 'join event' board with no event behind it; it makes the game feel dead.
- [1:24](https://youtu.be/esZQX5COI_E?t=84) **[[first-session-onboarding]]** Make the map feel inhabited: add a character at key counters, a vibrant skybox, and scattered decor around the edges so the space looks like a real place.
- [2:07](https://youtu.be/esZQX5COI_E?t=127) **[[scripting-and-performance]]** Put shared cooldowns on reward mechanics so players can't abuse them by hopping between instances (e.g. plots).
- [3:16](https://youtu.be/esZQX5COI_E?t=196) **[[ads-and-sponsored-experiences]]** When re-advertising an old game, the algorithm already has data from earlier runs, so a short $10/day test can show it an updated version without starting from zero.
- [4:27](https://youtu.be/esZQX5COI_E?t=267) **[[analytics-metrics]]** Track favorites as a retention signal; the creator treats 2,140 favorites as stronger evidence of retention than clicks.
