# roblox growth, for idiots like me

## Summary
Beginner-friendly Roblox growth primer: pick a one-sentence idea that copies a proven genre with a twist, build a tiny MVP, fix icon/thumbnail/title packaging for CTR, make a retention loop, deliver fun in 8 seconds, and build an audience before launch.

## Tips
- [0:11](https://youtu.be/q0lIbkUC2r8?t=11) **[[game-ideas-and-genres]]** Apply the one-sentence test: explain your game to a stranger in one sentence. If you can't, the concept is too unclear.
- [0:51](https://youtu.be/q0lIbkUC2r8?t=51) **[[game-ideas-and-genres]]** Don't invent a new genre. Take a proven working formula and add your own twist; combining existing ideas is fine, one-to-one copying is not.
- [0:51](https://youtu.be/q0lIbkUC2r8?t=51) **[[trend-research-and-validation]]** Find proven ideas by checking popular YouTube videos, App Store top charts, and hit shows/films (e.g. Squid Game, Invincible) that have been turned into Roblox games.
- [0:11](https://youtu.be/q0lIbkUC2r8?t=11) **[[game-ideas-and-genres]]** Ensure mass appeal: pick a simple, satisfying concept anyone can play (Grow a Garden was not made only for gardeners).
- [2:37](https://youtu.be/q0lIbkUC2r8?t=157) **[[development-process-and-speed]]** Build an MVP: one map, one core loop, no extras. Release it, then iterate based on real player feedback rather than building a large game first.
- [3:18](https://youtu.be/q0lIbkUC2r8?t=198) **[[development-process-and-speed]]** Prioritise speed over polish and bug-free code at the early stage; a finished simple game beats an unfinished complex one.
- [4:11](https://youtu.be/q0lIbkUC2r8?t=251) **[[thumbnails-icons]]** Check CTR in Creator Hub. If it is below 3%, fix packaging (icon, title, thumbnail) before anything else, since low CTR stops the algorithm testing your game.
- [4:30](https://youtu.be/q0lIbkUC2r8?t=270) **[[thumbnails-icons]]** Design icons with one clear high-contrast focal point, a popping colour, and a slightly intriguing or confusing element that makes people want to click.
- [4:30](https://youtu.be/q0lIbkUC2r8?t=270) **[[thumbnails-icons]]** Run the two-second test: show your icon for 2 seconds; if a viewer can't roughly say what the game is, redo it.
- [4:30](https://youtu.be/q0lIbkUC2r8?t=270) **[[thumbnails-icons]]** Avoid AI-generated icons and cluttered in-game screenshots as icons.
- [5:35](https://youtu.be/q0lIbkUC2r8?t=335) **[[core-loops-and-game-design]]** Build a core loop: action, reward, repeat. Keep progress visible so the game does not feel the same 10 minutes in as at the start.
- [5:35](https://youtu.be/q0lIbkUC2r8?t=335) **[[player-psychology-and-game-feel]]** Use variable rewards that differ each time a player completes something, which drives the same compulsion as slot machines.
- [6:16](https://youtu.be/q0lIbkUC2r8?t=376) **[[retention-d1-d7]]** Track day-7 retention as a signal of quality; if players don't return after a week, add at least one retention hook.
- [6:16](https://youtu.be/q0lIbkUC2r8?t=376) **[[retention-d1-d7]]** Add a retention hook such as a daily reward, progression system, trading, or a leaderboard to bring players back.
- [6:16](https://youtu.be/q0lIbkUC2r8?t=376) **[[social-features-and-virality]]** Prompt players inside the game to favourite it, so it appears in their Roblox favourites and they return.
- [7:05](https://youtu.be/q0lIbkUC2r8?t=425) **[[first-session-onboarding]]** Make the game fun within about 8 seconds; avoid gating fun behind long tutorials or grinding, since attention spans are short. Slap Battles spawns you straight into slapping people.
- [7:05](https://youtu.be/q0lIbkUC2r8?t=425) **[[first-session-onboarding]]** Apply the living-room test: if a friend watching a kid play thinks it is boring, rework the core fun. Games should be fun to watch as well as play.
- [7:45](https://youtu.be/q0lIbkUC2r8?t=465) **[[discovery-algorithm]]** Target high average session time, strong retention, and non-spammy monetisation; the algorithm pushes games that show these signals.
- [7:45](https://youtu.be/q0lIbkUC2r8?t=465) **[[ads-and-sponsored-experiences]]** Bring external traffic first (small Robux-funded ads, Discord shares, community posts, TikTok, YouTube) so the algorithm gets data to act on.
- [8:23](https://youtu.be/q0lIbkUC2r8?t=503) **[[community-and-discord]]** Build an audience before launch: pick one platform (TikTok, YouTube, Discord) and post dev logs consistently for about 2 months before release.
- [9:04](https://youtu.be/q0lIbkUC2r8?t=544) **[[trailers-and-video-marketing]]** Post gameplay clips and dev logs on TikTok or YouTube during development; even 1% of a large viewership can give thousands of players at launch.
- [9:04](https://youtu.be/q0lIbkUC2r8?t=544) **[[community-and-discord]]** Respond to bug reports quickly; ignoring players and slow bug fixes kill a game.
- [9:04](https://youtu.be/q0lIbkUC2r8?t=544) **[[common-mistakes]]** Avoid overcomplicating the game, adding tutorials early, copying other games one-to-one, and spam-selling purchases.
