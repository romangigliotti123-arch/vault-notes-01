## [[localization-and-international]]
- 2018-03-07 [0:41](https://youtu.be/wKjTYdVi4KE?t=41) Enable Text Capture in the Localization Tools plugin, play the game to collect GUI text, then toggle it off to generate a LocalizationTable. ([[2018-03-07 - Roblox Localization Tools Demo with NDS|Roblox Localization Tools Demo with NDS]])
- 2018-03-07 [2:43](https://youtu.be/wKjTYdVi4KE?t=163) Use machine translation only as a first pass. Pay for professional or bilingual-friend translation if the game earns money, since literal translations lose context. ([[2018-03-07 - Roblox Localization Tools Demo with NDS|Roblox Localization Tools Demo with NDS]])
- 2018-03-07 [1:21](https://youtu.be/wKjTYdVi4KE?t=81) Use the context column to disambiguate identical strings that need different translations in different UI locations. ([[2018-03-07 - Roblox Localization Tools Demo with NDS|Roblox Localization Tools Demo with NDS]])
- 2018-03-07 [3:25](https://youtu.be/wKjTYdVi4KE?t=205) Test translations by setting the play-mode language in the plugin and playing, to see what that locale's players will see. ([[2018-03-07 - Roblox Localization Tools Demo with NDS|Roblox Localization Tools Demo with NDS]])
- 2018-03-07 [4:06](https://youtu.be/wKjTYdVi4KE?t=246) Put text that must be translated on a GUI TextLabel over an image, not baked into image art, since image text cannot be translated automatically. ([[2018-03-07 - Roblox Localization Tools Demo with NDS|Roblox Localization Tools Demo with NDS]])
- 2018-03-07 [4:06](https://youtu.be/wKjTYdVi4KE?t=246) Handle rich text effects and text animations in scripts. The automatic text replacement system does not handle them well. ([[2018-03-07 - Roblox Localization Tools Demo with NDS|Roblox Localization Tools Demo with NDS]])
- 2018-03-07 [4:47](https://youtu.be/wKjTYdVi4KE?t=287) Localization means making the game feel native, not just translated. Put research and effort into it beyond quick translations. ([[2018-03-07 - Roblox Localization Tools Demo with NDS|Roblox Localization Tools Demo with NDS]])
