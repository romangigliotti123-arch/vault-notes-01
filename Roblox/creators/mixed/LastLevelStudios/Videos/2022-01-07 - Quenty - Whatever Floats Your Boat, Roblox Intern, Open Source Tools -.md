# Quenty - Whatever Floats Your Boat, Roblox Intern, Open Source Tools - Beyond The Blox S2E7

## Summary
Quenty (Roblox intern, open source plugin author, Nevermore engine creator) discusses his Roblox history, open-source philosophy, and the games Whatever Floats Your Boat, Windlight Bay, Ragdoll Sim and Would You Quiz. Covers reusable packages, memory/streaming for low-end mobile, and accelerator project lessons.

## Tips
- [10:06](https://youtu.be/v8S5puPQEw4?t=606) **[[community-and-discord]]** Open-source reusable code and link it to people asking how to solve problems; it builds reputation and helps others, which he says benefits the platform overall.
- [16:57](https://youtu.be/v8S5puPQEw4?t=1017) **[[development-process-and-speed]]** Extract systems (lighting, permissions, commands, pets) into modular, versioned packages so you can drop them into new games in about 30 seconds.
- [24:10](https://youtu.be/v8S5puPQEw4?t=1450) **[[common-mistakes]]** Don't build tech without designing the game. Windlight Bay had lots of tech (NPCs, building, dialogue) but weak game design, so it didn't find players.
- [25:33](https://youtu.be/v8S5puPQEw4?t=1533) **[[development-process-and-speed]]** Build small games that prove out individual tech pieces while drawing players, then reuse the pieces in bigger projects.
- [30:01](https://youtu.be/v8S5puPQEw4?t=1801) **[[optimization-and-streaming]]** Design for low-end mobile first: enable streaming and program with it on from the start, even if you later turn it off.
- [30:42](https://youtu.be/v8S5puPQEw4?t=1842) **[[optimization-and-streaming]]** Minimise textures and polygons; texture memory scales quadratically, and mobile crashes are almost always memory-related.
- [30:42](https://youtu.be/v8S5puPQEw4?t=1842) **[[optimization-and-streaming]]** When diagnosing mobile crashes, check memory usage first rather than other causes.
- [19:42](https://youtu.be/v8S5puPQEw4?t=1182) **[[game-ideas-and-genres]]** Sandbox/building survival games with physics let players grow into creators; Whatever Floats Your Boat drew many players who became developers.
- [27:06](https://youtu.be/v8S5puPQEw4?t=1626) **[[development-process-and-speed]]** Expect most accelerator-style projects not to release; the learning still has value, and pieces can be reused in future games.
- [26:25](https://youtu.be/v8S5puPQEw4?t=1585) **[[mindset-and-strategy]]** Consistently releasing games is a skill in itself; most people never get a project released and popular.
- [4:17](https://youtu.be/v8S5puPQEw4?t=257) **[[mindset-and-strategy]]** Keep creating things for fun, not just for payoff, to avoid burnout when Roblox becomes a job.
- [6:58](https://youtu.be/v8S5puPQEw4?t=418) **[[community-and-discord]]** Releasing a plugin as open source costs little and raises the platform for everyone; a rising tide lifts all boats.

## Games
- **Whatever Floats Your Boat** [19:00](https://youtu.be/v8S5puPQEw4?t=1140): Physics-based boat building survival sandbox; creative sandbox drew players who later became developers. Mobile port never fully done.
- **Windlight Bay** [23:29](https://youtu.be/v8S5puPQEw4?t=1409): Tech-heavy accelerator project with weak game design; lesson is to design the game first and pull reusable tech out of it.
- **Ragdoll Sim** [25:33](https://youtu.be/v8S5puPQEw4?t=1533): Built in ~8 hours at accelerator; succeeded by proving out ragdoll system from Windlight Bay; core code open-sourced.
- **Would You Quiz** [4:03](https://youtu.be/v8S5puPQEw4?t=243): Built in ~12 hours; popular test bed for the dialogue system reused from Windlight Bay.
