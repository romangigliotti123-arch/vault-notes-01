## Summary
Podcast interview with evaera (Roblox systems engineer on Adopt Me). Covers his path into the Adopt Me team, lessons from the Roblox Aquaman event (tight deadline, sponsor changes, crunch), the Rover verification bot and its scaling/support burden, open-source libraries (Commander, Rojo), Scripting Helpers Q&A site, and QA tooling.

## Tips
- [12:18](https://youtu.be/4fz4fpJLUSQ?t=738) **[[community-and-discord]]** Turn off @everyone/@here pings and auto-delete messages that ping staff in your server, so helpers aren't buried in notifications.
- [19:08](https://youtu.be/4fz4fpJLUSQ?t=1148) **[[community-and-discord]]** Add features players request directly from feedback; e.g. rank tags in nicknames for Rover came from user requests.
- [25:51](https://youtu.be/4fz4fpJLUSQ?t=1551) **[[version-control-and-tooling]]** Use Rojo to write code in a normal editor (VS Code) and sync to Studio, enabling Git and external tooling.
- [23:08](https://youtu.be/4fz4fpJLUSQ?t=1388) **[[code-architecture-and-frameworks]]** Write code for reuse across games from the start; game-specific code wastes time when you need it again.
- [30:39](https://youtu.be/4fz4fpJLUSQ?t=1839) **[[community-and-discord]]** Open-source reusable tools; contributors find bugs you miss and you gain value and visibility, even in a narrow market.
- [23:08](https://youtu.be/4fz4fpJLUSQ?t=1388) **[[scripting-and-performance]]** Use a command framework like Commander so argument parsing (e.g. converting names to Player objects) is handled before your command code runs.
- [15:46](https://youtu.be/4fz4fpJLUSQ?t=946) **[[common-mistakes]]** Plan infrastructure for scale early: Rover hit ~100k servers and needed 32+ GB RAM, forcing a rewrite and a separate hosted service.
- [17:48](https://youtu.be/4fz4fpJLUSQ?t=1068) **[[monetisation-other]]** Offer a paid upgraded tier of a free community tool via Patreon; Rover Plus had ~160 subscribers at $6/month, offsetting server costs.
- [9:21](https://youtu.be/4fz4fpJLUSQ?t=561) **[[common-mistakes]]** Lock down scope with sponsors; mid-project asset rejections forced deleted work and a 15-hour-day crunch at the end.
- [7:57](https://youtu.be/4fz4fpJLUSQ?t=477) **[[team-and-budget]]** Watch for red flags early on a team; mixed experience levels caused repeated mistakes and constant rework fixing them.
