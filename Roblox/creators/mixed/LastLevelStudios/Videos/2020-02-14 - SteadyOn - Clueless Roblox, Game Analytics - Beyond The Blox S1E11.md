# SteadyOn - Clueless Roblox, Game Analytics - Beyond The Blox S1E11

[Watch](https://youtu.be/_LdpUJ41cso) | LastLevelStudios | 1,976 views | 2020-02-14

## Summary
Podcast interview with developer SteadyOn (Clueless, Bakery Tycoon, OurTrack). Covers learning Roblox via roleplay groups and free models, early launch bugs at 20k CCU, starting small projects, paid access alpha, and building OurTrack, a stats/tracking service using Roblox APIs.

## Tips
- [9:43](https://youtu.be/_LdpUJ41cso?t=583) **[[mindset-and-strategy]]** Start with small experimental projects to learn scripting; don't jump straight into a big game, since big projects set you up to fail.
- [11:47](https://youtu.be/_LdpUJ41cso?t=707) **[[playtesting-and-feedback]]** Fix bugs before a big traffic spike; a front-page surge with broken saving or empty plots lost most new players.
- [27:52](https://youtu.be/_LdpUJ41cso?t=1672) **[[testing-debugging-and-qa]]** Test with many players; issues like DataStore loss and server overload often only appear at scale after release.
- [28:34](https://youtu.be/_LdpUJ41cso?t=1714) **[[playtesting-and-feedback]]** Build a tester community or request QA testing from a QA Discord before release.
- [28:34](https://youtu.be/_LdpUJ41cso?t=1714) **[[ab-testing-and-experiments]]** Release in paid access alpha: gradual player growth, exclusive alpha-tester rewards, and invested early community.
- [29:55](https://youtu.be/_LdpUJ41cso?t=1795) **[[community-and-discord]]** Create a Discord early and add it to social links so players can report bugs and discuss the game.
- [25:06](https://youtu.be/_LdpUJ41cso?t=1506) **[[mindset-and-strategy]]** Make games you genuinely care about; copying trending genres (clicker, lifting simulators) flopped and lost money.
- [36:19](https://youtu.be/_LdpUJ41cso?t=2179) **[[pricing]]** Track gamepass price changes day by day to see whether a price cut or rise increases total revenue, not just sales.
- [22:23](https://youtu.be/_LdpUJ41cso?t=1343) **[[game-ideas-and-genres]]** Test a quiz concept with minimal content first; adding minigames raised playtime and player counts for Clueless.
- [34:41](https://youtu.be/_LdpUJ41cso?t=2081) **[[development-process-and-speed]]** Spread development out as a marathon; rushing a release reduces polish.
- [31:17](https://youtu.be/_LdpUJ41cso?t=1877) **[[mindset-and-strategy]]** Roblox development transfers to real game dev skills: server/client, UX, and monetisation design.
- [46:18](https://youtu.be/_LdpUJ41cso?t=2778) **[[analytics-metrics]]** Judge ratings using recent data only; old dislikes from an early buggy version can permanently hurt a game that was later fixed.
