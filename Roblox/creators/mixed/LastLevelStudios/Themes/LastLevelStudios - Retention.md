## [[retention-d1-d7]]
- 2019-09-06 [21:52](https://youtu.be/hnCm955Du8w?t=1312) Publish a clear progression pathway (e.g. Trainee to Signaller) so players see a reachable goal and stay engaged. ([[2019-09-06 - Charlie_RBX - Building a Roblox Game Community - Beyond The Blox S1E3|Charlie_RBX - Building a Roblox Game Community - B]])
- 2019-09-13 [45:52](https://youtu.be/h4W8yHxmxns?t=2752) For free-to-play, design for players returning daily or several times a week, not one-time play; value comes from repeat sessions. ([[2019-09-13 - spotco - Former Roblox Employee, Robeats Creator - Beyond The Blox S1E|spotco - Former Roblox Employee, Robeats Creator -]])
- 2019-09-13 [46:34](https://youtu.be/h4W8yHxmxns?t=2794) Use daily rotating content (daily shop songs, daily missions), gacha-style rolls, and slow progression grinds so players never see all content in one session. ([[2019-09-13 - spotco - Former Roblox Employee, Robeats Creator - Beyond The Blox S1E|spotco - Former Roblox Employee, Robeats Creator -]])
- 2019-10-11 [20:47](https://youtu.be/vY0om5O-Oh8?t=1247) Add badges and clear progression (levels, XP, crates) so players have achievement and a reason to return. ([[2019-10-11 - iGottic - Common Roblox Developer Mistakes - Beyond The Blox S1E6|iGottic - Common Roblox Developer Mistakes - Beyon]])

## [[community-and-discord]]
- 2019-09-06 [1:26](https://youtu.be/hnCm955Du8w?t=86) Choose community depth to fit the genre: flat fan groups for simple games, deep ranked hierarchies for games where ranks unlock gameplay. ([[2019-09-06 - Charlie_RBX - Building a Roblox Game Community - Beyond The Blox S1E3|Charlie_RBX - Building a Roblox Game Community - B]])
- 2019-09-06 [4:10](https://youtu.be/hnCm955Du8w?t=250) Use community ranks to restrict technically risky modes to trained players so they can't ruin the game for others. ([[2019-09-06 - Charlie_RBX - Building a Roblox Game Community - Beyond The Blox S1E3|Charlie_RBX - Building a Roblox Game Community - B]])
- 2019-09-06 [5:35](https://youtu.be/hnCm955Du8w?t=335) Budget development time for community management; delegate, then train and check in on delegates regularly. ([[2019-09-06 - Charlie_RBX - Building a Roblox Game Community - Beyond The Blox S1E3|Charlie_RBX - Building a Roblox Game Community - B]])
- 2019-09-06 [7:01](https://youtu.be/hnCm955Du8w?t=421) Watch for community pressure making you build only what fans want; keep room for your own interests to avoid burnout. ([[2019-09-06 - Charlie_RBX - Building a Roblox Game Community - Beyond The Blox S1E3|Charlie_RBX - Building a Roblox Game Community - B]])
- 2019-09-06 [7:42](https://youtu.be/hnCm955Du8w?t=462) If you can't commit long term, let fans run an unofficial community so you aren't pressured or guilty when you move on. ([[2019-09-06 - Charlie_RBX - Building a Roblox Game Community - Beyond The Blox S1E3|Charlie_RBX - Building a Roblox Game Community - B]])
- 2019-09-06 [8:02](https://youtu.be/hnCm955Du8w?t=482) Base the community on Discord with separate voice/text channels per purpose, since Roblox groups lack push notifications, voice, and rich media. ([[2019-09-06 - Charlie_RBX - Building a Roblox Game Community - Beyond The Blox S1E3|Charlie_RBX - Building a Roblox Game Community - B]])
- 2019-09-06 [8:45](https://youtu.be/hnCm955Du8w?t=525) Use RoVer bot to assign Discord roles from Roblox group rank and link Roblox usernames to Discord accounts. ([[2019-09-06 - Charlie_RBX - Building a Roblox Game Community - Beyond The Blox S1E3|Charlie_RBX - Building a Roblox Game Community - B]])
- 2019-09-06 [8:45](https://youtu.be/hnCm955Du8w?t=525) Host a community wiki that members can contribute to, so new players can catch up from one central hub. ([[2019-09-06 - Charlie_RBX - Building a Roblox Game Community - Beyond The Blox S1E3|Charlie_RBX - Building a Roblox Game Community - B]])
- 2019-09-06 [9:28](https://youtu.be/hnCm955Du8w?t=568) Use Google Forms for applications, linked to a spreadsheet you can share with the team to assess applicants collaboratively. ([[2019-09-06 - Charlie_RBX - Building a Roblox Game Community - Beyond The Blox S1E3|Charlie_RBX - Building a Roblox Game Community - B]])
- 2019-09-06 [10:12](https://youtu.be/hnCm955Du8w?t=612) Replace open suggestion/bug Discord channels, which get flooded with duplicates, with a web tool that merges duplicates and supports voting and comments. ([[2019-09-06 - Charlie_RBX - Building a Roblox Game Community - Beyond The Blox S1E3|Charlie_RBX - Building a Roblox Game Community - B]])
- 2019-09-06 [10:12](https://youtu.be/hnCm955Du8w?t=612) Use a moderation bot for auto-removal of spam links and invites, plus a warning system so members learn rules before eviction. ([[2019-09-06 - Charlie_RBX - Building a Roblox Game Community - Beyond The Blox S1E3|Charlie_RBX - Building a Roblox Game Community - B]])
- 2019-09-06 [10:53](https://youtu.be/hnCm955Du8w?t=653) Build a custom customer-service bot with a shared queue so members post once and any staff member can claim the request. ([[2019-09-06 - Charlie_RBX - Building a Roblox Game Community - Beyond The Blox S1E3|Charlie_RBX - Building a Roblox Game Community - B]])
- 2019-09-06 [12:06](https://youtu.be/hnCm955Du8w?t=726) Delegate moderation with escalation paths; keep potentially damaging permissions close to the creator. ([[2019-09-06 - Charlie_RBX - Building a Roblox Game Community - Beyond The Blox S1E3|Charlie_RBX - Building a Roblox Game Community - B]])
- 2019-09-06 [14:18](https://youtu.be/hnCm955Du8w?t=858) Give small, frequent sneak peeks so members see progress; avoid the creator personally tracking the hype and reacting to it. ([[2019-09-06 - Charlie_RBX - Building a Roblox Game Community - Beyond The Blox S1E3|Charlie_RBX - Building a Roblox Game Community - B]])
- 2019-09-06 [15:38](https://youtu.be/hnCm955Du8w?t=938) Avoid overzealous moderation; keep moderators calm, since heavy-handed enforcement upsets the community. ([[2019-09-06 - Charlie_RBX - Building a Roblox Game Community - Beyond The Blox S1E3|Charlie_RBX - Building a Roblox Game Community - B]])
- 2019-09-06 [23:48](https://youtu.be/hnCm955Du8w?t=1428) Post non-pushed announcements or sneak peeks every few days, and pushed announcements for major updates. ([[2019-09-06 - Charlie_RBX - Building a Roblox Game Community - Beyond The Blox S1E3|Charlie_RBX - Building a Roblox Game Community - B]])
- 2020-02-07 [6:31](https://youtu.be/HU4JJOft4Pw?t=391) Open-source your modules on the DevForum; user feedback improves your code and builds recognition. ([[2020-02-07 - boatbomber - Lua Learning on Roblox - Beyond The Blox S1E10|boatbomber - Lua Learning on Roblox - Beyond The B]])
- 2020-02-07 [22:48](https://youtu.be/HU4JJOft4Pw?t=1368) Let the community create content, such as user-submitted tutorials with reviews, voting and a moderator team, to scale without overloading yourself. - 2020-02-14 [29:55](https://youtu.be/_LdpUJ41cso?t=1795) Create a Discord early and add it to social links so players can report bugs and discuss the game. ([[2020-02-14 - SteadyOn - Clueless Roblox, Game Analytics - Beyond The Blox S1E11|SteadyOn - Clueless Roblox, Game Analytics - Beyon]])
