## Summary
Tutorial on Roblox ParticleEmitter properties (color, light emission, size, transparency, texture, Z offset, acceleration, lifetime, rate, rotation, rotation speed, speed, velocity spread) in Studio and via Luau scripting using ColorSequence, NumberSequence and NumberRange. Mostly a properties walkthrough for visual effects.

## Tips
- [0:00](https://youtu.be/4hZo6m1N2-w?t=0) **[[vfx-and-particles]]** Use ParticleEmitters instead of legacy fire/smoke/sparkles for longer, less laggy effects that look better up close.
- [1:34](https://youtu.be/4hZo6m1N2-w?t=94) **[[vfx-and-particles]]** Set Start and End color to the same value for a solid color; the gradient is controlled only by these two fields.
- [4:33](https://youtu.be/4hZo6m1N2-w?t=273) **[[vfx-and-particles]]** Use the spline curve editor on Size, Transparency and similar properties to animate values over the particle's lifetime.
- [9:37](https://youtu.be/4hZo6m1N2-w?t=577) **[[vfx-and-particles]]** Fix flickering between overlapping particle emitters on one part by changing Z Offset; it changes render priority only, not position.
