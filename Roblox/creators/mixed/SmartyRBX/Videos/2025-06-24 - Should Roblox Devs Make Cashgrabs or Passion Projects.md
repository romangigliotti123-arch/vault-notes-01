# Should Roblox Devs Make Cashgrabs or Passion Projects?

[Watch](https://youtu.be/skcp4P68i84) | SmartyRBX | 6,219 views | 2025-06-24

## Summary
Speaker argues the "passion project vs cash grab" binary is false. Serious devs put strategy first: make simple games first, release fast as MVPs, learn from player data, raise complexity over time, use earnings to fund teams. Monetization should be added within fun core loops. 99% of devs should not chase passion projects yet. Promotes his Substack.

## Tips
- [9:31](https://youtu.be/skcp4P68i84?t=571) **[[development-process-and-speed]]** Make simple games first (e.g. hot potato, freeze tag), release them fast as MVPs, and increase complexity as skill and funds grow.
- [11:27](https://youtu.be/skcp4P68i84?t=687) **[[analytics-metrics]]** Read your analytics after release: watch where players drop off, which gamepasses sell, and when players stop returning (e.g. after 7 days).
- [11:27](https://youtu.be/skcp4P68i84?t=687) **[[retention-d1-d7]]** If players stop coming back around day 7, add incentives to return and make the game more engaging.
- [15:29](https://youtu.be/skcp4P68i84?t=929) **[[development-process-and-speed]]** Keep project scope small at the start; a dream game with too large a scope often never ships.
- [16:11](https://youtu.be/skcp4P68i84?t=971) **[[playtesting-and-feedback]]** Use live player counts from released games to decide what to build next, not developer taste.
- [18:34](https://youtu.be/skcp4P68i84?t=1114) **[[business-and-payouts]]** Reinvest game earnings into paying scripters, builders, modelers, and designers to build a team and make more games.
- [25:54](https://youtu.be/skcp4P68i84?t=1554) **[[mindset-and-strategy]]** Think like the CEO (strategy) guiding the artist (passion); let passion be fuel within a structured long-term plan.
- [29:54](https://youtu.be/skcp4P68i84?t=1794) **[[core-loops-and-game-design]]** Make the game fun first (core loop, mechanics) and add monetization as an extra layer, not the main feature.
- [36:17](https://youtu.be/skcp4P68i84?t=2177) **[[monetisation-gamepasses]]** Monetize through gamepasses and developer products to fund future projects, while giving players value in return.
- [37:19](https://youtu.be/skcp4P68i84?t=2239) **[[monetisation-gamepasses]]** Sell optional upgrades so spenders can pay more; avoid pay-to-win that lowers gameplay quality.
