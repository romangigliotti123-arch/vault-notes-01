# How To Plan A Roblox Game - And Actually Finish It.

[Watch](https://youtu.be/fxZ8Qv91LbY) | SmartyRBX | 65,943 views | 2022-09-10

## Summary
Introduces planning a Roblox game: write a game design document (concept, features, monetisation, team roles), agree team payment upfront, break work into Trello or Google Docs checklists, build map/UI first then scripting, take breaks, keep the project fun, and set task deadlines.

## Tips
- [0:00](https://youtu.be/fxZ8Qv91LbY?t=0) **[[development-process-and-speed]]** Write a game design document (Google Docs is fine) covering genre, concept, reference games, features, modes, monetisation, controls, UI, and required assets/roles.
- [0:40](https://youtu.be/fxZ8Qv91LbY?t=40) **[[game-ideas-and-genres]]** Describe how your game differs from similar existing games in the design document.
- [1:47](https://youtu.be/fxZ8Qv91LbY?t=107) **[[team-and-budget]]** Agree how teammates are paid before release (flat rate, Robux/USD, or hourly) and write it down so payouts don't cause disputes later.
- [2:30](https://youtu.be/fxZ8Qv91LbY?t=150) **[[development-process-and-speed]]** Turn the design document into a task board (Trello or checkbox list) with one list per discipline such as UI, scripting, building, modeling, animation.
- [4:11](https://youtu.be/fxZ8Qv91LbY?t=251) **[[development-process-and-speed]]** Build the map and UI first, then have scripters wire up systems, keeping Studio organised so updates stay manageable.
- [4:53](https://youtu.be/fxZ8Qv91LbY?t=293) **[[mindset-and-strategy]]** Take regular breaks and keep the project fun; burnout and taking it too seriously are the main reasons developers quit before finishing.
- [5:45](https://youtu.be/fxZ8Qv91LbY?t=345) **[[development-process-and-speed]]** Set deadlines on individual tasks (e.g. build the lobby within a week) rather than only a final release date, and get teammates to agree to them.
- [6:26](https://youtu.be/fxZ8Qv91LbY?t=386) **[[team-and-budget]]** Involve teammates in every step of the process, since motivating collaborators on a shared project is hard.
