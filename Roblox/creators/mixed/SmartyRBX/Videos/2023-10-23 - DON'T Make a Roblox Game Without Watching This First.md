# DON'T Make a Roblox Game Without Watching This First.

[Watch](https://youtu.be/vemqKJ-5yRE) | SmartyRBX | 867,924 views | 2023-10-23

## Summary
Framework for planning a Roblox game from idea to release: strong base idea, high concept with premise, USPs, target player empathy, competitor and cost/monetisation analysis, team roles (energy/edge/execute), building an MVP, then pivoting based on player feedback. Uses Sussy Imposter Land and Jailbreak as MVP-to-pivot examples.

## Tips
- [1:33](https://youtu.be/vemqKJ-5yRE?t=93) **[[game-ideas-and-genres]]** Write a 30-second elevator pitch and a premise; pick 1-3 core USPs and build the game around them rather than being average at everything.
- [6:28](https://youtu.be/vemqKJ-5yRE?t=388) **[[game-ideas-and-genres]]** Model your target player's perspective, not your own; check the audience is large enough for your niche before committing.
- [8:57](https://youtu.be/vemqKJ-5yRE?t=537) **[[trend-research-and-validation]]** Analyse competitors: check if the market is saturated, and innovate on what they do rather than copying it.
- [10:18](https://youtu.be/vemqKJ-5yRE?t=618) **[[pricing]]** Estimate build cost and realistic earnings upfront so you don't start a project that needs more money than it can return.
- [11:46](https://youtu.be/vemqKJ-5yRE?t=706) **[[team-and-budget]]** Hire for complementary skills and experience, define roles in writing, and use a project manager to coordinate.
- [13:17](https://youtu.be/vemqKJ-5yRE?t=797) **[[development-process-and-speed]]** Build a minimum viable product: strip to core systems, maps and fun, and make it playable before adding features.
- [15:22](https://youtu.be/vemqKJ-5yRE?t=922) **[[playtesting-and-feedback]]** Release the MVP so testers and players can give feedback, and use it to decide what to build next.
- [15:36](https://youtu.be/vemqKJ-5yRE?t=936) **[[development-process-and-speed]]** Pivot after testing: refine the edges and add what players want, staying within your scope, budget and Roblox limits.
- [17:39](https://youtu.be/vemqKJ-5yRE?t=1059) **[[development-process-and-speed]]** Keep updating the game as a living product; improving monetisation, gameplay and maps over time drove Sussy Imposter Land's growth.
- [21:02](https://youtu.be/vemqKJ-5yRE?t=1262) **[[development-process-and-speed]]** Keep the game design document light and flexible, since rigid GDDs block the iteration Roblox updates allow.
- [24:32](https://youtu.be/vemqKJ-5yRE?t=1472) **[[team-and-budget]]** Apply the four Es of project management: energy, edge (make tough calls), execute, and tell the truth to the team.
- [26:32](https://youtu.be/vemqKJ-5yRE?t=1592) **[[mindset-and-strategy]]** Plan to promote the game after release; a released game with no promotion will not get players.
