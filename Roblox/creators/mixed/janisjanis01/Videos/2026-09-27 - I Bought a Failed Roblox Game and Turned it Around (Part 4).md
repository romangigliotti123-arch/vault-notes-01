# I Bought a Failed Roblox Game and Turned it Around (Part 4)

[Watch](https://youtu.be/WJpNCB5J9bg) | janisjanis01 | 455,748 views | 2026-09-27

## Summary
Creator buys a failing Roblox game (Beehive RNG) for 115,000 Robux, then tries to revive it: fixes tutorial, UI, mobile clicks and next-button guidance, runs ads, adds a remote-unlock gamepass and a cash boost. Ends with a loss: 5,937 Robux earned vs 115k purchase plus 13k ad spend.

## Tips
- [0:00](https://youtu.be/WJpNCB5J9bg?t=0) **[[trend-research-and-validation]]** Buying a failing game is risky; prefer games with good quality and clear problems, since you can't know what's really wrong with a dead game.
- [1:17](https://youtu.be/WJpNCB5J9bg?t=77) **[[trend-research-and-validation]]** Finding a good game to buy can take weeks of scrolling the homepage and messaging owners; many owners never reply.
- [4:27](https://youtu.be/WJpNCB5J9bg?t=267) **[[first-session-onboarding]]** Make the tutorial and button highlighting extremely clear; the speaker felt the unclear tutorial was the biggest problem.
- [5:43](https://youtu.be/WJpNCB5J9bg?t=343) **[[first-session-onboarding]]** Add arrow guidance pointing players to the next objective so they don't get lost, and check sorting logic for the target.
- [5:02](https://youtu.be/WJpNCB5J9bg?t=302) **[[discovery-algorithm]]** Low home recommendations meant the game relied on ads; check whether the game is getting algorithm traffic before spending on ads.
- [6:27](https://youtu.be/WJpNCB5J9bg?t=387) **[[playtesting-and-feedback]]** Read player feedback and rebirth/progress behaviour to find what drives long-term play.
- [6:27](https://youtu.be/WJpNCB5J9bg?t=387) **[[ab-testing-and-experiments]]** Run A/B tests on thumbnails; the previous owner had none running, which was a missed opportunity.
- [7:10](https://youtu.be/WJpNCB5J9bg?t=430) **[[ui-ux-design]]** Test mobile input early; buttons that cannot be clicked on mobile cause immediate exits.
- [7:52](https://youtu.be/WJpNCB5J9bg?t=472) **[[scripting-and-performance]]** Changing signal behaviour from immediate to deferred fixed a sync issue between plot and character; check event ordering when objects fail to update.
- [7:52](https://youtu.be/WJpNCB5J9bg?t=472) **[[playtesting-and-feedback]]** Play-test after every change; a config error blocked progress after an upgrade, likely driving players away.
- [7:52](https://youtu.be/WJpNCB5J9bg?t=472) **[[thumbnails-icons]]** A high ad CTR (around 7%) does not help if the game has too few players; fix retention and the game before scaling ads.
- [8:45](https://youtu.be/WJpNCB5J9bg?t=525) **[[monetisation-gamepasses]]** Gamepass ownership must be checked against the real item; a gamepass that says owned but gives no item will cause refunds and complaints.
- [8:45](https://youtu.be/WJpNCB5J9bg?t=525) **[[monetisation-gamepasses]]** A remote-unlock gamepass can drive sales of convenience purchases; test whether players actually buy it.
- [10:02](https://youtu.be/WJpNCB5J9bg?t=602) **[[analytics-metrics]]** Judge a game by player count stability and retention over a week, not by one-off spikes from ads.
- [10:43](https://youtu.be/WJpNCB5J9bg?t=643) **[[common-mistakes]]** Do not assume stats or marketing fix a game; if the core game is weak, players will leave regardless of thumbnails or ads.
