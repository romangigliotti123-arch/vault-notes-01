# How Hard Is It To Make A Viral Roblox Game?

[Watch](https://youtu.be/NWyK_PbFdxE) | janisjanis01 | 47,575 views | 2024-06-16

## Summary
Generic overview of what makes Roblox games go viral: story-driven progression, daily login rewards, cosmetic-only monetisation, uncompletable replayability via trading, leaderboards, solving a real problem, and eye-catching icons. Mostly motivational; examples are Murder Mystery 2, Pet Simulator 99, Adopt Me, Please Donate and Catalog Avatar Creator. Advice is high-level, with few concrete numbers.

## Tips
- [0:40](https://youtu.be/NWyK_PbFdxE?t=40) **[[core-loops-and-game-design]]** Make the odds improve as the player plays, as Murder Mystery 2 does with murderer chance, so players keep playing to reach a better chance.
- [1:41](https://youtu.be/NWyK_PbFdxE?t=101) **[[retention-d1-d7]]** Add daily rewards for just logging in, regardless of genre. Login streaks make players afraid to lose progress, so they return daily.
- [2:34](https://youtu.be/NWyK_PbFdxE?t=154) **[[monetisation-gamepasses]]** Sell cosmetics or convenience, not power. Pay-to-win drives player loss and lower retention; MM2 sells Godly skins with no gameplay advantage.
- [2:48](https://youtu.be/NWyK_PbFdxE?t=168) **[[core-loops-and-game-design]]** Keep the game uncompletable. Trading in Pet Simulator 99 lets players keep chasing better items after maxing out.
- [3:28](https://youtu.be/NWyK_PbFdxE?t=208) **[[social-features-and-virality]]** Add leaderboards to create competition. Popular games use them; MM2 runs leaderboard seasons twice a year and players spend heavily to compete.
- [3:33](https://youtu.be/NWyK_PbFdxE?t=213) **[[game-ideas-and-genres]]** Take a popular game and make a clearly better version of it instead of copying it. Starting from a proven trend is easier than inventing a new genre.
- [4:14](https://youtu.be/NWyK_PbFdxE?t=254) **[[game-ideas-and-genres]]** Build a game that solves a real problem players have. Please Donate reached about 100 concurrent players with no ads by solving the problem of having no Robux.
- [4:14](https://youtu.be/NWyK_PbFdxE?t=254) **[[game-ideas-and-genres]]** Find a clear pain point in existing games and make a feature that removes it, such as letting players try on catalog items before buying.
- [4:58](https://youtu.be/NWyK_PbFdxE?t=298) **[[thumbnails-icons]]** Make the game icon fit the niche and stand out. Avoid oversaturated brights on horror games; use mystery that suits the genre.
- [4:58](https://youtu.be/NWyK_PbFdxE?t=298) **[[thumbnails-icons]]** If you are weak at design, hire an icon artist. The speaker cites game icons for about $5 on Fiverr.
- [5:47](https://youtu.be/NWyK_PbFdxE?t=347) **[[development-process-and-speed]]** Start with a small project and learn from mistakes. Avoid months-long projects for a first game.
- [5:47](https://youtu.be/NWyK_PbFdxE?t=347) **[[community-and-discord]]** Grow an audience on Twitter or YouTube before launch to build hype. Popular games had large hype before release.
- [5:47](https://youtu.be/NWyK_PbFdxE?t=347) **[[studio-business-funding-and-publishing]]** Look for developers to team up with once the game gets bigger, rather than trying to build everything alone from the start.
