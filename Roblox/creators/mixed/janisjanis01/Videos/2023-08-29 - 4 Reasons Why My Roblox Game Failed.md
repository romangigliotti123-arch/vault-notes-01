# 4 Reasons Why My Roblox Game Failed...

[Watch](https://youtu.be/fRBNHaMtvFs) | janisjanis01 | 13,148 views | 2023-08-29

## Summary
Creator reviews why his 5-day Roblox game failed: visuals looked like Minecraft 2009, the game was too easy to finish in about 10 minutes, the icon was weak, and monetisation was missing. Advises adding replayability (rebirths, rounds, leaderboards), polished lobby/UI, gamepasses, developer products and a unique twist.

## Tips
- [0:25](https://youtu.be/fRBNHaMtvFs?t=25) **[[building-art-and-assets]]** Polish the lobby and buildings first; new players judge quality immediately, so basic visuals make them leave within minutes.
- [0:25](https://youtu.be/fRBNHaMtvFs?t=25) **[[ui-ux-design]]** Add polished GUI animations and click sound effects to menus and buttons to make the game feel more finished.
- [1:20](https://youtu.be/fRBNHaMtvFs?t=80) **[[retention-d1-d7]]** Make the game take longer to complete; Roblox recommends games with good playtime, so a 10-minute completion hurts discovery.
- [2:02](https://youtu.be/fRBNHaMtvFs?t=122) **[[core-loops-and-game-design]]** Add replayability via rebirths, rounds or leaderboards so players return to earn more items after finishing.
- [2:17](https://youtu.be/fRBNHaMtvFs?t=137) **[[thumbnails-icons]]** Make the game icon and thumbnail eye-catching like a YouTube thumbnail, since a weak icon stops players clicking even if the game is polished.
- [2:17](https://youtu.be/fRBNHaMtvFs?t=137) **[[monetisation-gamepasses]]** Sell gamepasses that help progression, such as a skip-stage button in obbies.
- [2:59](https://youtu.be/fRBNHaMtvFs?t=179) **[[monetisation-devproducts]]** If the game has currency, add developer products so players can buy it with Robux.
- [3:08](https://youtu.be/fRBNHaMtvFs?t=188) **[[game-ideas-and-genres]]** Don't just copy inspiration; add a unique twist to an existing genre, e.g. an obby with falling anchors.
- [3:08](https://youtu.be/fRBNHaMtvFs?t=188) **[[team-and-budget]]** For a big game, hire builders or scripters so you don't have to do all the work alone.
- [3:08](https://youtu.be/fRBNHaMtvFs?t=188) **[[mindset-and-strategy]]** Stay consistent and keep learning Studio, Blender and coding; viral success takes patience and skill.
- [0:00](https://youtu.be/fRBNHaMtvFs?t=0) **[[common-mistakes]]** Don't expect a 5-day game to go viral; a rushed build with no experience rarely reaches the front page.
