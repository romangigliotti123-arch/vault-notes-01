# How I’d Make a Roblox Game Hit 10K CCU

## Summary
Boo Studios outlines a playbook for hitting 10K CCU on Roblox: pick proven concepts (existing, announced-on-Steam, or revived old games), add a core fantasy, hook in 5 min, build in 1-3 weeks, test with ads, and prioritize longevity over one-hit spikes. Heavy on mindset; few concrete metrics.

## Tips
- [1:31](https://youtu.be/d5YHwCqwgYM?t=91) **[[game-ideas-and-genres]]** Build on a proven concept: take an existing hit, add your own spin, or revive an old popular game rather than inventing something unproven.
- [3:33](https://youtu.be/d5YHwCqwgYM?t=213) **[[trend-research-and-validation]]** Copy concepts already announced on Steam/Kickstarter before release to get to Roblox first, since speed matters more than originality.
- [6:18](https://youtu.be/d5YHwCqwgYM?t=378) **[[game-ideas-and-genres]]** Give the game a core fantasy players want to inhabit (biker, cleaner, firefighter), not a bare mechanic like 'jump from the highest tower'.
- [8:21](https://youtu.be/d5YHwCqwgYM?t=501) **[[first-session-onboarding]]** Make the first 5 minutes intriguing as a hook, then keep the next ~15 minutes easy so players accumulate playtime before grinding starts.
- [8:21](https://youtu.be/d5YHwCqwgYM?t=501) **[[core-loops-and-game-design]]** Include social hangout elements (view others' pets/items), rarity-based grinding, and player-vs-player competition; he says single-player games fail on Roblox.
- [9:46](https://youtu.be/d5YHwCqwgYM?t=586) **[[development-process-and-speed]]** Keep builds to 1-3 weeks (a month max); if a game drags longer, cut scope. Use templates for models and UI to save time.
- [10:27](https://youtu.be/d5YHwCqwgYM?t=627) **[[development-process-and-speed]]** Learn scripting well enough to structure a game with a proper framework; AI-only code gets buggy, unreadable and crashes servers, he claims.
- [13:08](https://youtu.be/d5YHwCqwgYM?t=788) **[[ads-and-sponsored-experiences]]** Run ads for 1-2 weeks with a 30k-60k Robux (about $100-$200) budget; if the game gets no traction, cut it and start another idea.
- [13:08](https://youtu.be/d5YHwCqwgYM?t=788) **[[updates-live-ops]]** If the test shows traction, keep updating the game regularly to extend its life rather than abandoning it.
- [14:31](https://youtu.be/d5YHwCqwgYM?t=871) **[[mindset-and-strategy]]** Optimise for longevity: a game averaging 5-8K CCU for a year beats a 20K-peak game that dies in 15 days, in his view.
- [16:33](https://youtu.be/d5YHwCqwgYM?t=993) **[[mindset-and-strategy]]** Keep shipping games; markets shift, so good ideas can still fail. Expect that one of several releases will hit.
