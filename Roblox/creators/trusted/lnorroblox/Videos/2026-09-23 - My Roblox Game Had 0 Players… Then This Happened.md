# My Roblox Game Had 0 Players… Then This Happened

## Summary
Developer's Roblox game (dumpling/aura farming) failed to get players; a 45-day final update fixes progression, roll system, tutorial and retention via daily quests, events, and trading. Gets feedback-driven fixes, expert playtest, and a $2,000 investment offer that he declined for now.

## Tips
- [1:12](https://youtu.be/gSFxStWqmgM?t=72) **[[core-loops-and-game-design]]** Make progression visibly feel like growth: new islands and placeable decorations with bonuses so new players feel stronger.
- [2:16](https://youtu.be/gSFxStWqmgM?t=136) **[[playtesting-and-feedback]]** Have an experienced developer play the game as a brand-new player on a call; this exposed problems the creator was blind to.
- [2:56](https://youtu.be/gSFxStWqmgM?t=176) **[[player-psychology-and-game-feel]]** Show reward feedback on screen (money and currency gain animations) so players can see what they earned.
- [2:56](https://youtu.be/gSFxStWqmgM?t=176) **[[common-mistakes]]** Passive timer-based rewards (e.g., currency every 10 seconds) were hard to understand and easy to exploit with auto clickers; tie rewards to player actions instead.
- [3:39](https://youtu.be/gSFxStWqmgM?t=219) **[[monetisation-devproducts]]** Offer a starter pack and boost potions (double money, luck, aura) as early purchasable boosts.
- [4:12](https://youtu.be/gSFxStWqmgM?t=252) **[[core-loops-and-game-design]]** Hide rare outcomes until revealed; showing rarity before opening killed curiosity. Remove forced walking and cooldowns between actions.
- [5:00](https://youtu.be/gSFxStWqmgM?t=300) **[[first-session-onboarding]]** Tutorials should explain why the player is doing each step, not just say what to do; study top games' tutorials for comparison.
- [5:41](https://youtu.be/gSFxStWqmgM?t=341) **[[first-session-onboarding]]** Show UI teleport buttons early or animate them so tutorial doesn't force long walks to shops.
- [5:41](https://youtu.be/gSFxStWqmgM?t=341) **[[retention-d1-d7]]** Add daily quests on the main screen right after the tutorial so players have a goal instead of asking 'what now?'.
- [6:22](https://youtu.be/gSFxStWqmgM?t=382) **[[events-and-seasonal-content]]** Fill waiting time between harvests with short random events (e.g., every 90 seconds) to prevent boredom and quitting.
- [7:04](https://youtu.be/gSFxStWqmgM?t=424) **[[events-and-seasonal-content]]** Give live leaderboards in competitive events with better rewards for first place to drive participation.
- [7:47](https://youtu.be/gSFxStWqmgM?t=467) **[[social-features-and-virality]]** Add player-to-player trading (gated behind a progression milestone) so players interact with each other.
- [7:47](https://youtu.be/gSFxStWqmgM?t=467) **[[player-psychology-and-game-feel]]** Sell cosmetic trails for an in-game currency to create a status sink for progression currency.
- [2:56](https://youtu.be/gSFxStWqmgM?t=176) **[[community-and-discord]]** Organize the Discord into categories per game and add a management bot; a helpful community member did this for them.
