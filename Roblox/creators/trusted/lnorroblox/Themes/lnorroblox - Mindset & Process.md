## [[common-mistakes]]
- 2025-12-03 [1:31](https://youtu.be/Nywo2NwQPNo?t=91) Scanning all world objects every second to find players burned ~30% of server resources. Use event-driven detection or cached lists instead. ([[2025-12-03 - I Created an RPG on Roblox in 313 Days With Zero Experience|I Created an RPG on Roblox in 313 Days With Zero E]])
- 2026-09-23 [2:56](https://youtu.be/gSFxStWqmgM?t=176) Passive timer-based rewards (e.g., currency every 10 seconds) were hard to understand and easy to exploit with auto clickers; tie rewards to player actions instead. ([[2026-09-23 - My Roblox Game Had 0 Players… Then This Happened|My Roblox Game Had 0 Players… Then This Happened]])
