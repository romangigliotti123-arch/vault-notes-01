# No, "Get Good" doesn't excuse bad Roblox games.

[Watch](https://youtu.be/jXogdTgtlXE) | NotCumin | 345,515 views | 2025-07-31

## Summary
Critique of AOT Freedom War (Roblox), framed as a lesson on hard-game design. Argues that a hard game still needs a sensible gameplay loop, fair failure, fair respawn timers, a non-resetting progression system, scaling difficulty, a real tutorial, and map design that supports the core movement. Mostly entertainment with some design lessons.

## Tips
- [5:35](https://youtu.be/jXogdTgtlXE?t=335) **[[genre-mechanics]]** In a movement-based game, design maps around the core movement; tall, reachable structures matter more than realism.
- [4:57](https://youtu.be/jXogdTgtlXE?t=297) **[[player-psychology-and-game-feel]]** Keep respawn timers short (a few seconds in shooters, about a minute max in MOBAs); long waits make a game boring and cut learning time.
- [9:39](https://youtu.be/jXogdTgtlXE?t=579) **[[core-loops-and-game-design]]** Never reset all of a player's progress on death in a non-roguelike; it makes the progression loop feel pointless.
- [11:43](https://youtu.be/jXogdTgtlXE?t=703) **[[genre-mechanics]]** Make PvE difficulty scale up across campaign stages; a flat difficulty with player power growth makes the late game trivial.
- [13:17](https://youtu.be/jXogdTgtlXE?t=797) **[[core-loops-and-game-design]]** Check that the repeated tasks players do for the whole session lead to a satisfying experience before building around them.
- [13:59](https://youtu.be/jXogdTgtlXE?t=839) **[[matchmaking-and-teleport]]** Use per-mission queues or lobbies for group PvE content instead of drop-in servers, so players don't abandon a run when others leave.
- [7:04](https://youtu.be/jXogdTgtlXE?t=424) **[[first-session-onboarding]]** Build an interactive tutorial that makes players practise each control and mechanic, not just a text list of controls.
- [8:28](https://youtu.be/jXogdTgtlXE?t=508) **[[first-session-onboarding]]** Explain every in-game signal or UI color (e.g. flare colors) so players know what each means.
- [3:36](https://youtu.be/jXogdTgtlXE?t=216) **[[core-loops-and-game-design]]** Only use a campaign structure if it has real progression, story presentation and changing content; otherwise drop it.
- [15:21](https://youtu.be/jXogdTgtlXE?t=921) **[[genre-mechanics]]** Consider separating PvP from PvE modes so PvP players don't block campaign progress.
