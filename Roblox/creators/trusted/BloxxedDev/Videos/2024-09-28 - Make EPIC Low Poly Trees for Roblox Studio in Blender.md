# Make EPIC Low Poly Trees for Roblox Studio in Blender

[Watch](https://youtu.be/5cLUGex3nUY) | BloxxedDev | 246 views | 2024-09-28

## Summary
Tutorial on making low-poly trees in Blender 4.1 for Roblox Studio: cylinder-based trunk/canopy modeling, vertex morphing, UV-mapping a color palette via image texture, exporting FBX and importing via Asset Manager in Studio.

## Tips
- [0:00](https://youtu.be/5cLUGex3nUY?t=0) **[[building-art-and-assets]]** Use a low-vertex cylinder (8 vertices) as the base for low-poly tree trunks and canopies.
- [0:41](https://youtu.be/5cLUGex3nUY?t=41) **[[building-art-and-assets]]** Color low-poly models by UV-projecting from view and assigning a palette image as an Image Texture base color, rather than per-face colors.
- [1:21](https://youtu.be/5cLUGex3nUY?t=81) **[[building-art-and-assets]]** If palette colors don't show in Blender, switch viewport shading from Material Preview to Solid/Viewport shading.
- [2:01](https://youtu.be/5cLUGex3nUY?t=121) **[[building-art-and-assets]]** Shape organic silhouettes by moving individual vertices and extruding/scaling faces instead of building new primitives.
- [2:44](https://youtu.be/5cLUGex3nUY?t=164) **[[building-art-and-assets]]** Use Ctrl+R loop cuts and scale to add a mid-section bulge so the tree looks rounder and more natural.
- [3:25](https://youtu.be/5cLUGex3nUY?t=205) **[[building-art-and-assets]]** Export as FBX and import into Studio via View > Asset Manager; keep parts separate so you can edit them later.
- [3:25](https://youtu.be/5cLUGex3nUY?t=205) **[[building-art-and-assets]]** Import errors reported on FBX import can usually be ignored; the mesh still imports correctly.
