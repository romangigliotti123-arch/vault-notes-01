# How to fix your Roblox game (5 Simple Strategies)

## Summary
Generic troubleshooting advice for fixing a Roblox game: break problems into smaller questions, use multiple resources, use Studio's Script Analysis and Output windows to locate errors, ask the community for help, and strengthen fundamentals. Mostly motivational with a few debugging tips; promotes the creator's tutorial series.

## Tips
- [0:00](https://youtu.be/SdCmo91rsVc?t=0) **[[testing-debugging-and-qa]]** Break a broken feature into smaller sub-problems and search for each one separately, then combine the tutorials that solve each part.
- [1:07](https://youtu.be/SdCmo91rsVc?t=67) **[[testing-debugging-and-qa]]** Enable Script Analysis and Output windows via the View tab; Script Analysis flags script-breaking errors without joining the game.
- [1:47](https://youtu.be/SdCmo91rsVc?t=107) **[[testing-debugging-and-qa]]** Click an error in Script Analysis or Output to jump to the script and line; read the Stack Begin/End trace in Output to locate it.
- [2:13](https://youtu.be/SdCmo91rsVc?t=133) **[[community-and-discord]]** When stuck, post the question on the Roblox Developer Forum or community servers for help.
- [2:31](https://youtu.be/SdCmo91rsVc?t=151) **[[development-process-and-speed]]** Strengthen basics in scripting, building, and animation; continuously learn from each problem and mistake encountered.
