# Roblox Team Create & Collaborative Editing Guide - Tutorial Series [EP 7]

[Watch](https://youtu.be/vsHJH2bFn0Q) | Emancyphur | 14,467 views | 2021-07-24

## Summary
Tutorial on Roblox Team Create and Collaborative Editing: enabling Team Create per place, inviting collaborators via Permissions (group edit access limited to Owner since May 2021), chat, real-time building, script drafts, committing/merging conflicts, and playtest behaviour with drafts.

## Tips
- [0:00](https://youtu.be/vsHJH2bFn0Q?t=0) **[[development-process-and-speed]]** Enable Team Create separately for each place via View tab > Team Create; close and reopen the place if it doesn't activate.
- [0:28](https://youtu.be/vsHJH2bFn0Q?t=28) **[[community-and-discord]]** Invite collaborators in Game Settings > Permissions; only friends can be invited to edit, and group-based editing currently only works for the group Owner.
- [1:46](https://youtu.be/vsHJH2bFn0Q?t=106) **[[development-process-and-speed]]** Use Team Create for real-time building; each user gets a colour shown in Explorer and selection boxes, giving instant feedback.
- [2:28](https://youtu.be/vsHJH2bFn0Q?t=148) **[[common-mistakes]]** Avoid simultaneous edits to the same objects in Team Create, since they can break undo/redo.
- [2:32](https://youtu.be/vsHJH2bFn0Q?t=152) **[[development-process-and-speed]]** Keep Collaborative Editing enabled (default) so multiple devs can edit the same script via separate drafts instead of locking it.
- [4:03](https://youtu.be/vsHJH2bFn0Q?t=243) **[[development-process-and-speed]]** Commit script drafts promptly; if others committed first, resolve conflicts via Merge From Server (Draft, Server, or Other) before committing.
- [3:51](https://youtu.be/vsHJH2bFn0Q?t=231) **[[testing-debugging-and-qa]]** Check the publish reminder for uncommitted drafts before publishing so unfinished script changes are not missed.
- [5:34](https://youtu.be/vsHJH2bFn0Q?t=334) **[[playtesting-and-feedback]]** Keep uncommitted scripts out of team tests: solo playtests use drafts, Team Tests use only committed versions, so you can test without disrupting teammates.

## Numbers
- [1:09](https://youtu.be/vsHJH2bFn0Q?t=69) Group Team Create editing access: **Owner-only since at least May 2021 (per speaker)** (Despite docs saying group roles with Create and Edit Group Games can edit)

## Tools
Roblox Studio, Team Create widget, Chat widget, Drafts widget, Game Settings > Permissions
