# 2018-2021 ROBLOX Private/VIP Server Guide - What Private Servers are, How to make one, & Sell them

[Watch](https://youtu.be/RUqr6lj1UYI) | Emancyphur | 86,048 views | 2018-07-22

## Summary
Walkthrough of Roblox VIP (private) servers: what they are, buying one from the game's Servers tab, configuring access (friends list, manual invites, shareable link, regenerate link, enable/disable), and how creators set VIP server price and enablement in Configure this Place > Access. Notes 10 Robux minimum, monthly subscription renewal, and that changing price cancels existing subscriptions.

## Tips
- [1:29](https://youtu.be/RUqr6lj1UYI?t=89) **[[monetisation-other]]** VIP servers renew monthly; owners pay the creation price again each month to keep a server running, so price it with that recurring cost in mind.
- [7:15](https://youtu.be/RUqr6lj1UYI?t=435) **[[pricing]]** Do not change the VIP server price while servers exist; changing it cancels existing subscriptions and can upset buyers.
- [6:33](https://youtu.be/RUqr6lj1UYI?t=393) **[[monetisation-other]]** Enable VIP servers and set the price in Configure this Place > Access; the price field shows projected Robux earnings and current VIP server count.
- [3:50](https://youtu.be/RUqr6lj1UYI?t=230) **[[monetisation-other]]** Disabling a VIP server does not stop the subscription; disable auto-renewal instead to have it deleted at the end of the period.

## Numbers
- [0:45](https://youtu.be/RUqr6lj1UYI?t=45) VIP server minimum price: **10 Robux (free allowed since 2020 update)**
- [1:29](https://youtu.be/RUqr6lj1UYI?t=89) VIP server duration: **1 month, then renew at the same price**
- [6:33](https://youtu.be/RUqr6lj1UYI?t=393) Price field: **No maximum; shows Robux earnings per purchase**
