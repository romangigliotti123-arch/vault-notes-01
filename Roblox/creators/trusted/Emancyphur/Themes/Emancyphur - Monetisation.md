## [[monetisation-other]]
- 2018-07-22 [1:29](https://youtu.be/RUqr6lj1UYI?t=89) VIP servers renew monthly; owners pay the creation price again each month to keep a server running, so price it with that recurring cost in mind. ([[2018-07-22 - 2018-2021 ROBLOX PrivateVIP Server Guide - What Private Servers are, H|2018-2021 ROBLOX Private/VIP Server Guide - What P]])
- 2018-07-22 [6:33](https://youtu.be/RUqr6lj1UYI?t=393) Enable VIP servers and set the price in Configure this Place > Access; the price field shows projected Robux earnings and current VIP server count. ([[2018-07-22 - 2018-2021 ROBLOX PrivateVIP Server Guide - What Private Servers are, H|2018-2021 ROBLOX Private/VIP Server Guide - What P]])
- 2018-07-22 [3:50](https://youtu.be/RUqr6lj1UYI?t=230) Disabling a VIP server does not stop the subscription; disable auto-renewal instead to have it deleted at the end of the period. ([[2018-07-22 - 2018-2021 ROBLOX PrivateVIP Server Guide - What Private Servers are, H|2018-2021 ROBLOX Private/VIP Server Guide - What P]])
- 2020-09-17 [5:42](https://youtu.be/C0ybJ5ghSHk?t=342) Make all progression earnable through play, with Robux purchases being cosmetic only, so paying players don't gain unfair advantages. ([[2020-09-17 - The TRUTH of ROBLOX Piggy’s Success & MiniToon’s Rise to Fame|The TRUTH of ROBLOX Piggy’s Success & MiniToon’s R]])

## [[pricing]]
- 2018-07-22 [7:15](https://youtu.be/RUqr6lj1UYI?t=435) Do not change the VIP server price while servers exist; changing it cancels existing subscriptions and can upset buyers. ([[2018-07-22 - 2018-2021 ROBLOX PrivateVIP Server Guide - What Private Servers are, H|2018-2021 ROBLOX Private/VIP Server Guide - What P]])
