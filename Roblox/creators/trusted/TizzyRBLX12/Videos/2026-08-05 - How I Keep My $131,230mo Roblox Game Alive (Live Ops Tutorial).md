# How I Keep My $131,230/mo Roblox Game Alive (Live Ops Tutorial)

[Watch](https://youtu.be/TVdqb9O0RMw) | Tizzy | 47,865 views | 2026-08-05

## Summary
Live ops guide from a Build a Base and Steel producer: separate fast patches from weekly/biweekly updates, plan updates from qualitative data (Discord, forum, feedback tab), quantitative data (home-rec acquisition, play days, bounce rate, playtime), and competitor research; talk to core players; weekly Mon-Sun cadence with internal and core playtesting; dos and don'ts.

## Tips
- [1:39](https://youtu.be/TVdqb9O0RMw?t=99) **[[updates-live-ops]]** Ship patches (bug fixes, exploits, nerfs/buffs, monetisation tweaks) on the fly, daily if needed; don't wait for the weekly update.
- [2:22](https://youtu.be/TVdqb9O0RMw?t=142) **[[updates-live-ops]]** Ship planned updates weekly, moving to bi-weekly eventually, and make each one target specific home-recommendation metrics.
- [3:41](https://youtu.be/TVdqb9O0RMw?t=221) **[[playtesting-and-feedback]]** Collect bug reports in Discord, read the group community forum, and check the creator dashboard Feedback tab's AI summary for player sentiment.
- [5:17](https://youtu.be/TVdqb9O0RMw?t=317) **[[analytics-metrics]]** Check Acquisition > Home Recs over the last 7 days and pick one metric (e.g. play days per user, bounce rate, playtime) to target per update.
- [5:59](https://youtu.be/TVdqb9O0RMw?t=359) **[[core-loops-and-game-design]]** Build emotional investment (sunk cost) so players keep returning; example: a build mode letting players without a private server build their base in peace.
- [6:41](https://youtu.be/TVdqb9O0RMw?t=401) **[[first-session-onboarding]]** To reduce play bounce, confirm the title promise within the first 30 seconds; avoid long cutscenes.
- [6:41](https://youtu.be/TVdqb9O0RMw?t=401) **[[retention-d1-d7]]** Raise playtime with random events and a collection index tied to events; the speaker notes AFK behaviour also boosted playtime in his genre.
- [7:23](https://youtu.be/TVdqb9O0RMw?t=443) **[[trend-research-and-validation]]** Once compared against similar-player experiences, play those games and identify what they have that yours lacks to find update inspiration.
- [8:03](https://youtu.be/TVdqb9O0RMw?t=483) **[[community-and-discord]]** Build a core group of 8-10 playtesters in your Discord, plan updates with them, and have them test updates before launch.
- [9:25](https://youtu.be/TVdqb9O0RMw?t=565) **[[community-and-discord]]** Check server tags of your most active Discord members and ask them which games they used to play; this reveals competitor games to study (e.g. Base Raiders).
- [10:47](https://youtu.be/TVdqb9O0RMw?t=647) **[[development-process-and-speed]]** Run a weekly cycle: plan Saturday after the update, build Mon-Wed, ready Thursday, internal then core playtest Friday, launch Saturday.
- [12:32](https://youtu.be/TVdqb9O0RMw?t=752) **[[community-and-discord]]** Stay active in your game's Discord yourself or have the producer do it; players react very positively to visible developer activity.
- [12:32](https://youtu.be/TVdqb9O0RMw?t=752) **[[playtesting-and-feedback]]** Test every update before launch; never ship last-second updates.
- [13:54](https://youtu.be/TVdqb9O0RMw?t=834) **[[playtesting-and-feedback]]** Watch small, unpromoted player videos (10-15 views, recorded by kids) to see where new players get stuck or confused.
- [14:35](https://youtu.be/TVdqb9O0RMw?t=875) **[[team-and-budget]]** Hire a team incentivised to do great work; the speaker currently hires an internal live ops team rather than a big studio, citing studios treating games as numbers.
- [14:35](https://youtu.be/TVdqb9O0RMw?t=875) **[[discovery-algorithm]]** Prioritise updates that extend content life, given the speaker's view that Roblox's algorithm now weighs retention (D28).
- [14:35](https://youtu.be/TVdqb9O0RMw?t=875) **[[common-mistakes]]** Don't prioritise monetisation over gameplay; making a game super pay-to-win kills it. Add monetisation that doesn't hurt core gameplay.
- [15:16](https://youtu.be/TVdqb9O0RMw?t=916) **[[common-mistakes]]** Don't implement every community suggestion or give players everything they ask for; it can break your economy (e.g. giving away the rarest pet).
- [15:16](https://youtu.be/TVdqb9O0RMw?t=916) **[[community-and-discord]]** Run polls in your games Discord as an additional data source for decisions.
- [15:57](https://youtu.be/TVdqb9O0RMw?t=957) **[[common-mistakes]]** Don't stop improving a game once it makes money; neglecting updates is how games die.
- [16:38](https://youtu.be/TVdqb9O0RMw?t=998) **[[common-mistakes]]** Don't push cosmetic-only updates (e.g. one skin) that add no engagement or content.
