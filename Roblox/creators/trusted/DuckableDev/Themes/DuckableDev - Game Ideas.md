## [[core-loops-and-game-design]]
- 2025-02-07 [4:46](https://youtu.be/OS-k2iOEfhM?t=286) Build a simple core loop: action, sell for currency, buy upgrades, unlock expansion. Make the loop satisfying enough to keep players hooked. ([[2025-02-07 - Roblox Fisch's Genius Strategy For Success|Roblox Fisch's Genius Strategy For Success]])
- 2025-02-07 [5:28](https://youtu.be/OS-k2iOEfhM?t=328) Give players repeatable actions, rewards for completing set tasks, and unlockable expansion or new content to sustain play. ([[2025-02-07 - Roblox Fisch's Genius Strategy For Success|Roblox Fisch's Genius Strategy For Success]])
- 2025-02-14 [4:51](https://youtu.be/6g8ZYtDKPBw?t=291) Give XP for placing items and costs for items to create a basic progression loop. ([[2025-02-14 - I'm Creating A Sandbox Tycoon on Roblox|I'm Creating A Sandbox Tycoon on Roblox]])
- 2025-03-15 [1:38](https://youtu.be/I9eyeEG6dpc?t=98) For round-based games, use matchmaking that drops players straight into the next match with one click to avoid lobby waiting and keep retention high. ([[2025-03-15 - How This Roblox Game Keeps You ADDICTED|How This Roblox Game Keeps You ADDICTED]])
- 2025-03-15 [2:34](https://youtu.be/I9eyeEG6dpc?t=154) Add progression systems (per-weapon levels, unlockable cosmetics, paid upgrade currency) so players always have a next goal even after losses. ([[2025-03-15 - How This Roblox Game Keeps You ADDICTED|How This Roblox Game Keeps You ADDICTED]])
- 2025-03-15 [5:26](https://youtu.be/I9eyeEG6dpc?t=326) Require some player skill (learning curve, movement, aiming) rather than idle clicking or RNG rolling so achievements feel earned. ([[2025-03-15 - How This Roblox Game Keeps You ADDICTED|How This Roblox Game Keeps You ADDICTED]])
- 2026-07-04 [1:21](https://youtu.be/eRhFPgj8tc4?t=81) Copy proven loops from current top games (e.g. Slime RNG) and re-skin them; the creator switched from tycoon to RNG after seeing Slime RNG hit #1. ([[2026-07-04 - My Viral Roblox Game DIED… So I Made a Better One|My Viral Roblox Game DIED… So I Made a Better One]])
- 2026-08-04 [9:10](https://youtu.be/Cc7HT3uNjeQ?t=550) Add satisfying pickup feedback early, such as orbs flying to the player, since unsatisfying collection makes the core loop feel boring. ([[2026-08-04 - I Made a VIRAL Roblox Game Without AI|I Made a VIRAL Roblox Game Without AI]])
