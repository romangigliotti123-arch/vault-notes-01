# I Spent 2,000 DAYS to Make a VIRAL Roblox Game

[Watch](https://youtu.be/52srr65Mksc) | DuckableDev | 930,192 views | 2026-05-31

## Summary
Creator Duckable recounts six years of failed Roblox projects (Classic Tycoon, Card Wars attempts, commissions, tutorial copying) and how a 24-hour YouTube-driven game, Steal a Duck, with paid ads finally reached 1.6M Robux. Lessons: scope small, ship often, ads can lose money, passion vs. trend tradeoff.

## Tips
- [20:51](https://youtu.be/52srr65Mksc?t=1251) **[[trailers-and-video-marketing]]** Devlogs showing a single system build (e.g. placement system) can outperform; one video reached 100k views and built a dev channel audience.
- [21:31](https://youtu.be/52srr65Mksc?t=1291) **[[mindset-and-strategy]]** Release every game you start, even small ones, instead of abandoning them; the creator had five years of coding with no released game.
- [21:31](https://youtu.be/52srr65Mksc?t=1291) **[[development-process-and-speed]]** Use 24-hour build challenges to force scope limits and ship a complete game quickly.
- [13:33](https://youtu.be/52srr65Mksc?t=813) **[[development-process-and-speed]]** Abandon ambitious large projects in favour of smaller, simpler games; repeated big-project attempts burned out motivation.
- [22:54](https://youtu.be/52srr65Mksc?t=1374) **[[trend-research-and-validation]]** Follow current trends (e.g. steal-a-brainrot style games) with a themed twist; the creator's hit was a duck-themed trend ripoff.
- [5:51](https://youtu.be/52srr65Mksc?t=351) **[[common-mistakes]]** Don't rely on tutorial copy-paste; the creator learned nothing from blindly following tutorials and felt no progress.
- [3:38](https://youtu.be/52srr65Mksc?t=218) **[[common-mistakes]]** Avoid copy-pasting repeated code blocks for each mode; it made the early game hard to maintain.
- [2:57](https://youtu.be/52srr65Mksc?t=177) **[[common-mistakes]]** Don't use free models you don't understand as a substitute for writing code; it stalls learning.
- [10:09](https://youtu.be/52srr65Mksc?t=609) **[[common-mistakes]]** Don't spend Robux on ads before the game has basic bugs fixed; bugs wasted an ad spend of 32,000 Robux.
- [22:12](https://youtu.be/52srr65Mksc?t=1332) **[[ads-and-sponsored-experiences]]** Track ad return: 37,000 Robux on ads returned only about 10,000 Robux in the creator's first 24-hour game.
- [10:52](https://youtu.be/52srr65Mksc?t=652) **[[community-and-discord]]** Study other Roblox dev YouTubers' content to learn what the audience wants to see and how to present devlogs.
- [12:15](https://youtu.be/52srr65Mksc?t=735) **[[development-process-and-speed]]** Use official Roblox documentation when stuck rather than relying on AI code generation, which the creator found unreliable.
- [24:43](https://youtu.be/52srr65Mksc?t=1483) **[[mindset-and-strategy]]** Make games you enjoy; the creator says selling out means making games you hate, and passion projects can coexist with trend games.
- [5:10](https://youtu.be/52srr65Mksc?t=310) **[[mindset-and-strategy]]** Expect motivation to burn out on large plans; plan scope so you can finish within weeks.

## Games
- **Steal a Duck** [22:54](https://youtu.be/52srr65Mksc?t=1374): Trend-following 24-hour game with a themed twist (brainrot-style) became the breakout hit after ad spend.
- **100 Player Downhill Smash** [21:31](https://youtu.be/52srr65Mksc?t=1291): 24-hour build; ads spent 37k Robux but returned only ~10k, showing ads alone don't guarantee returns.
- **Memory Massacre** [22:22](https://youtu.be/52srr65Mksc?t=1342): Shipped with bugs after ad spend; the bugs broke the game and drained the balance.
- **Card Wars (Adventure Time)** [4:29](https://youtu.be/52srr65Mksc?t=269): Ambitious card game repeatedly abandoned; scope was too large for the skill level at the time.
- **Color Chaos** [3:38](https://youtu.be/52srr65Mksc?t=218): Copied Hive's color-matching mode; first game to earn Robux but code was repetitive.
- **Flip Cards** [13:33](https://youtu.be/52srr65Mksc?t=813): Revival of an abandoned game; complex systems took days and went unfinished.
- **Lumber Tower Tycoon** [12:15](https://youtu.be/52srr65Mksc?t=735): Tower tycoon with no drop limit caused performance issues; add limits to economy-driven mechanics.
