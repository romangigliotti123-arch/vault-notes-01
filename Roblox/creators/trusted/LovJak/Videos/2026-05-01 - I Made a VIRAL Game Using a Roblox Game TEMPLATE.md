# I Made a VIRAL Game Using a Roblox Game TEMPLATE

[Watch](https://youtu.be/FpbZRgRHYjQ) | LovJak | 128,864 views | 2026-05-01

## Summary
Creator turns a purchased Roblox game template (a fish-speed/escape-stages game) into a publishable game: reskins it as fruit, adds levels, timed events, lobby sign-up and daily chest, group and badge rewards, and then runs a 3-day Roblox ad campaign. Shows results: 3,254 visits, 884 Robux, 2,000 plays.

## Tips
- [0:41](https://youtu.be/FpbZRgRHYjQ?t=41) **[[development-process-and-speed]]** Start from a professional template to save build time; templates include instructions for changing things, so fixing animations and swapping assets is quick.
- [2:03](https://youtu.be/FpbZRgRHYjQ?t=123) **[[common-mistakes]]** Don't publish a template unchanged; the creator judged it 'not unique' and unlikely to go viral without changing levels, models, prices and gameplay.
- [2:44](https://youtu.be/FpbZRgRHYjQ?t=164) **[[building-and-level-design]]** Reorder and recolor levels and add stages to make the template's map distinct; visuals matter a lot for the first impression.
- [2:44](https://youtu.be/FpbZRgRHYjQ?t=164) **[[retention-d1-d7]]** Add a daily chest in the lobby and a sign-up for event/update notifications to bring players back.
- [3:25](https://youtu.be/FpbZRgRHYjQ?t=205) **[[3d-modeling-rigging-and-animation]]** If not a 3D modeler, use an AI model generator and then fix animation bugs in Studio; the creator reskinned the mounts this way.
- [4:05](https://youtu.be/FpbZRgRHYjQ?t=245) **[[monetisation-devproducts]]** Set developer product prices and update their UI; likewise replace gamepass icons and make the gamepasses work in-game.
- [4:05](https://youtu.be/FpbZRgRHYjQ?t=245) **[[social-features-and-virality]]** Add group-join rewards and badges like Welcome and Play With Friends to encourage joining the group and playing together.
- [4:47](https://youtu.be/FpbZRgRHYjQ?t=287) **[[updates-live-ops]]** Run timed in-game events (every 30 min, lasting 3 min) that change gameplay; start with the easiest ones like foggy map and low gravity.
- [4:47](https://youtu.be/FpbZRgRHYjQ?t=287) **[[updates-live-ops]]** Schedule a game update date on the Roblox calendar to give players a reason to return.
- [6:09](https://youtu.be/FpbZRgRHYjQ?t=369) **[[thumbnails-icons]]** Commission a professional icon and thumbnail before advertising; the creator's ad reached 1.95% CTR with 82k impressions.
- [6:50](https://youtu.be/FpbZRgRHYjQ?t=410) **[[ads-and-sponsored-experiences]]** Target ads to the days when players are most active (Friday to Sunday here) and set a daily budget to cap spend.
- [6:50](https://youtu.be/FpbZRgRHYjQ?t=410) **[[ads-and-sponsored-experiences]]** Ad spend was lower than expected: 21 credits bought for 5,500 Robux, with only about 16 credits used over 3 days; check spend against the budget.
- [8:14](https://youtu.be/FpbZRgRHYjQ?t=494) **[[analytics-metrics]]** Monitor CCU, session time, crash rate, FPS and server memory in the dashboard while the ad runs; day-7 retention is meaningless before a week has passed.
- [8:55](https://youtu.be/FpbZRgRHYjQ?t=535) **[[social-features-and-virality]]** Make short vertical gameplay videos for YouTube Shorts and TikTok to drive traffic to the game.
