# How pro Roblox developers learnt to script

[Watch](https://youtu.be/fivk8yp-VT4) | AlvinBlox | 953,973 views | 2021-01-23

## Summary
Three top Roblox developers (Bomber, Wesley of Deathrun, and Mister A) and a survey of 100 developers explain how they learned to script. Core method: study free models and open-source code, look up every unfamiliar API line, build small projects, and search for error messages and ask for help.

## Tips
- [0:31](https://youtu.be/fivk8yp-VT4?t=31) **[[scripting-and-performance]]** Learn by picking apart free models and open-source code to see why developers made their scripting decisions, not just copying them.
- [0:31](https://youtu.be/fivk8yp-VT4?t=31) **[[scripting-and-performance]]** When stuck, google the exact error message or API name instead of blindly following tutorials, so you learn how the code works.
- [2:24](https://youtu.be/fivk8yp-VT4?t=144) **[[scripting-and-performance]]** Read every line of a reference script and look up each unfamiliar call in the API reference until you understand what it does.
- [3:45](https://youtu.be/fivk8yp-VT4?t=225) **[[scripting-and-performance]]** Before using a new API or mechanic, find a practical example of someone else using it, then check the API docs with that context.
- [5:52](https://youtu.be/fivk8yp-VT4?t=352) **[[development-process-and-speed]]** Build small projects to apply what you learn; 58% of surveyed developers did this to build knowledge.
- [6:58](https://youtu.be/fivk8yp-VT4?t=418) **[[development-process-and-speed]]** Break an idea into the smallest pieces, look up each piece separately, and simplify the search until you find usable code.
- [8:19](https://youtu.be/fivk8yp-VT4?t=499) **[[development-process-and-speed]]** Use scripting challenges such as coder advent calendars to generate small project ideas when you run out of ideas.
- [9:17](https://youtu.be/fivk8yp-VT4?t=557) **[[development-process-and-speed]]** Start with small projects rather than huge games; big games cause loss of motivation and take months for even experienced devs.
- [9:00](https://youtu.be/fivk8yp-VT4?t=540) **[[mindset-and-strategy]]** Work on ideas you are passionate about; motivation comes from seeing your own work come to life.
- [5:22](https://youtu.be/fivk8yp-VT4?t=322) **[[mindset-and-strategy]]** Treat Roblox development as a hobby while learning so scripting stays enjoyable rather than a chore.
- [6:32](https://youtu.be/fivk8yp-VT4?t=392) **[[mindset-and-strategy]]** Expect your first game to be bad; every later game improves on the lessons from earlier ones.
- [1:14](https://youtu.be/fivk8yp-VT4?t=74) **[[scripting-and-performance]]** Learn what code elements do rather than only how to make one thing, so you can plan new scripts yourself.
- [1:14](https://youtu.be/fivk8yp-VT4?t=74) **[[community-and-discord]]** Ask for help on the DevForum or from a friend when stuck, and see a practical example of where the code is used.
