- 2021-06-14 [16:21](https://youtu.be/0rMO-VHSuGs?t=981) Add checkpoints using Team objects set to auto-assignable with unique team colors, and make spawn locations non-neutral with matching team color and Team Change On Touch. - 2021-06-14 [20:52](https://youtu.be/0rMO-VHSuGs?t=1252) Keep distances between points of interest to about 10 seconds of walking. Long empty walks feel boring and make players quit. ([[2021-06-14 - Are YOU making these Game Dev Mistakes|Are YOU making these Game Dev Mistakes?]])

- 2022-12-15 [7:38](https://youtu.be/R-xurNJtx7M?t=458) Lerp lets you change the target mid-movement, which TweenService cannot do; use it for dynamic, on-the-fly motion. ([[2022-12-15 - Lerping - How To Move Parts Without TweenService|Lerping - How To Move Parts Without TweenService]])
- 2024-09-20 [6:49](https://youtu.be/SUZPuQrKJuU?t=409) Add a dedicated voting stage between intermission and gameplay with its own countdown (example: 5 seconds). ([[2024-09-20 - How to make a Voting System|How to make a Voting System]])
- 2024-09-20 [19:07](https://youtu.be/SUZPuQrKJuU?t=1147) Reset player health to max when teleporting between rounds so damage does not carry over into the next map, especially for fighting games. ([[2024-09-20 - How to make a Voting System|How to make a Voting System]])
- 2024-10-12 [1:31](https://youtu.be/H9CbgCe47Mo?t=91) Don't over-worry about difficulty; keep players engaged with next milestones instead, as in Pet Simulator, since too-hard moments make players leave. - 2024-10-12 [11:01](https://youtu.be/H9CbgCe47Mo?t=661) Ensure real gameplay exists early and is fun; a basic obby with more gameplay beats a flashy game with little to do. ([[2024-10-12 - Are you making these Game Design Mistakes|Are you making these Game Design Mistakes?]])
- 2025-03-08 [7:00](https://youtu.be/u_8p65Bsm2Y?t=420) Smooth a sharp difficulty spike by adding an on-screen hint before the hard section so players are not instantly killed. ([[2025-03-08 - How to Boost your Game using Roblox Funnel Analytics|How to Boost your Game using Roblox Funnel Analyti]])
