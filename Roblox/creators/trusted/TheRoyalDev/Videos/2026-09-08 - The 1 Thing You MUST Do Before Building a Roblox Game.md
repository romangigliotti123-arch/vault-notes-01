# The 1 Thing You MUST Do Before Building a Roblox Game

[Watch](https://youtu.be/MZ-nsDEVXH4) | TheRoyalDev | 249 views | 2026-09-08

## Summary
Short video arguing every Roblox project, solo or team, should be planned before building. Speaker suggests writing the game name, core loop, progression, required script systems, builds, animations, UI and monetisation in a doc. Says his first game (Panic Button) failed partly because it was unplanned.

## Tips
- [0:02](https://youtu.be/MZ-nsDEVXH4?t=2) **[[development-process-and-speed]]** Write a game plan document before building: game name, core loop, progression, systems, builds, UI, animations and monetisation. Saves time and rework later.
- [0:43](https://youtu.be/MZ-nsDEVXH4?t=43) **[[core-loops-and-game-design]]** Define the core loop and how the game progresses (levels, updates) before building, so you don't lose the original idea mid-development.
- [0:43](https://youtu.be/MZ-nsDEVXH4?t=43) **[[scripting-and-performance]]** List required script systems upfront (e.g. level loader) so you know what to build before starting code.
- [2:05](https://youtu.be/MZ-nsDEVXH4?t=125) **[[development-process-and-speed]]** Split the planning doc into tabs or sections per area (systems, builds, animations, attributes) for easy reference in Google Drive or Word.
