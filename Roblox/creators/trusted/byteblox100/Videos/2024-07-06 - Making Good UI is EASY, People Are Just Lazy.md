# Making Good UI is EASY, People Are Just Lazy

[Watch](https://youtu.be/ZTzUHfMeYKA) | byteblox100 | 174,474 views | 2024-07-06

## Summary
Roblox UI design walkthrough: pick a colour palette tied to the game's vibe and assign each colour a role, use scaled sizing, make custom-drawn image buttons (Canva/remove.bg, uploaded as decals), and add simple TweenService slide-in and hover animations. Includes a paid course plug.

## Tips
- [1:25](https://youtu.be/ZTzUHfMeYKA?t=85) **[[ui-ux-design]]** Set UI sizes in Scale (0.1–1) rather than Offset so elements resize with the screen; Roblox doesn't stretch them by default.
- [4:12](https://youtu.be/ZTzUHfMeYKA?t=252) **[[ui-ux-design]]** Store a colour palette in a Configuration (Color3 values) with a fixed role per colour: base, outline, button outline, text. Keeps the GUI consistent.
- [6:13](https://youtu.be/ZTzUHfMeYKA?t=373) **[[ui-ux-design]]** Learn the UI modifiers (UIStroke, UICorner, UIGradient) and use gradients on key text like headers to add polish.
- [6:45](https://youtu.be/ZTzUHfMeYKA?t=405) **[[ui-ux-design]]** Make custom button and icon images in a design tool rather than basic frames; custom art makes a UI stand out from most games using defaults.
- [8:07](https://youtu.be/ZTzUHfMeYKA?t=487) **[[building-art-and-assets]]** For transparent PNGs without Canva Pro, remove the background with remove.bg, then upload as a Decal on create.roblox.com and use its asset ID.
- [10:05](https://youtu.be/ZTzUHfMeYKA?t=605) **[[ui-ux-design]]** Animate panels open and closed with TweenService (about 0.1–0.2s, Back easing) instead of making them blink in and out.
- [14:51](https://youtu.be/ZTzUHfMeYKA?t=891) **[[ui-ux-design]]** Add MouseEnter hover tweens on buttons to make the UI feel responsive.
- [16:06](https://youtu.be/ZTzUHfMeYKA?t=966) **[[ui-ux-design]]** Keep menus uncluttered and easy for a new player to understand; overly complex UI drives players away.
