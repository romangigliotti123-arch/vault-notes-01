# How to Make a Game Addictive in 15 Minutes

[Watch](https://youtu.be/ekM2z9FMhZc) | byteblox100 | 31,559 views | 2024-06-24

## Summary
Shows how to build a basic incremental/tycoon-style Roblox game in about 15 minutes using a scrolling frame of purchase buttons, attributes for cost and cash-per-second, a loop that awards cash each second, and a cash display. The creator also jokes about microtransactions and promotes a paid course.

## Tips
- [0:46](https://youtu.be/ekM2z9FMhZc?t=46) **[[game-ideas-and-genres]]** Incremental/tycoon games with a simple buy-button loop are very quick to build; the core mechanic can be done with basic UI and a few scripts.
- [2:16](https://youtu.be/ekM2z9FMhZc?t=136) **[[building-art-and-assets]]** Use a UIGridLayout with Scale cell size and vertical fill direction to lay out purchasable item rows; add UIPadding to stop items touching the edges.
- [4:19](https://youtu.be/ekM2z9FMhZc?t=259) **[[core-loops-and-game-design]]** Store per-item data (cost, cash per second, owned amount) as Attributes on a template frame and clone it, so each item shares structure but has different values.
- [4:19](https://youtu.be/ekM2z9FMhZc?t=259) **[[scripting-and-performance]]** Clone a template from ReplicatedStorage and scale values per tier (e.g. cost x5, cash x2) in a loop to generate many upgrade items quickly.
- [9:45](https://youtu.be/ekM2z9FMhZc?t=585) **[[ui-ux-design]]** Bind a text label to an Attribute with GetAttributeChangedSignal so the displayed cash updates automatically when the value changes.
- [10:29](https://youtu.be/ekM2z9FMhZc?t=629) **[[combat-and-gameplay-systems]]** Before a purchase, check that the player's cash is at least the item cost; if so, subtract cost and increment the item's owned amount attribute.
- [11:53](https://youtu.be/ekM2z9FMhZc?t=713) **[[core-loops-and-game-design]]** Run a task.wait(1) loop that iterates owned items and adds amount x cash-per-second to the player's total each tick to create passive income.
- [12:35](https://youtu.be/ekM2z9FMhZc?t=755) **[[ui-ux-design]]** Update the cost and owned-amount text labels whenever a new item is created or purchased, otherwise the UI shows stale values.
- [13:20](https://youtu.be/ekM2z9FMhZc?t=800) **[[common-mistakes]]** Parenting a cloned item to the wrong container or forgetting to connect the button's Activated event on every clone causes bugs; verify each step.
- [14:00](https://youtu.be/ekM2z9FMhZc?t=840) **[[ui-ux-design]]** Use LayoutOrder instead of renaming frames to control display order in a UIGridLayout or UIListLayout.
- [15:02](https://youtu.be/ekM2z9FMhZc?t=902) **[[ui-ux-design]]** Style buy buttons as bold, bright, clickable elements and make stat labels gray so players can tell buttons from readouts.
- [15:49](https://youtu.be/ekM2z9FMhZc?t=949) **[[monetisation-gamepasses]]** Incremental games are commonly monetised with microtransactions; the creator suggests adding gamepasses on top of the core loop.
