# How I Made $1,000 Making Roblox UGC With AI (Tutorial)

## Summary
Tutorial on making Roblox UGC accessories using AI image-to-3D generation (Tripo AI), then importing to Roblox Studio, fitting the accessory with the Avatar Editor, generating a thumbnail with ThumbMaker, and uploading. The creator claims ~$1,000 earned passively from UGC with no upfront spend.

## Tips
- [1:06](https://youtu.be/wkfCP_09CI8?t=66) **[[trend-research-and-validation]]** Sort Marketplace by Best Selling (weekly) and filter minimum 50 Robux to find which UGC items actually sell.
- [2:47](https://youtu.be/wkfCP_09CI8?t=167) **[[ai-and-tools]]** In Tripo AI, set texture 2K, PBR off (cheaper upload), triangle count under Roblox's 4,000 max (he used 3,990).
- [3:52](https://youtu.be/wkfCP_09CI8?t=232) **[[building-art-and-assets]]** Extract the Tripo zip before importing; import FBX via File > Import, then press 3 to scale and Ctrl+U to ungroup, renaming the part to Handle.
- [5:14](https://youtu.be/wkfCP_09CI8?t=314) **[[building-art-and-assets]]** Use Avatar Editor accessory fitting: place model in the Face bounds (box turns blue when within limits) before clicking Generate Mesh Part Accessory.
- [6:21](https://youtu.be/wkfCP_09CI8?t=381) **[[building-art-and-assets]]** Use the free ThumbMaker plugin to produce the marketplace thumbnail from the Handle, then right-click Handle > Save and Export to Roblox.
- [7:02](https://youtu.be/wkfCP_09CI8?t=422) **[[ugc-and-avatar-economy]]** When uploading, set type to avatar item and accessory category (face accessory), then add it to a bundle as required.
- [0:41](https://youtu.be/wkfCP_09CI8?t=41) **[[mindset-and-strategy]]** Keep adding new UGC items consistently; creator says earnings scaled slowly over months after posting more items.
- [0:00](https://youtu.be/wkfCP_09CI8?t=0) **[[common-mistakes]]** Creator says early old dynamic-face items were a waste; focus on items that match current demand and trends (e.g., seasonal makeup).
