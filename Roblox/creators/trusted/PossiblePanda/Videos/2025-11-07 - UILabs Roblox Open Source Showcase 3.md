## Summary
Walkthrough of UI Labs, a story-booking plugin for previewing Roblox UI outside gameplay. Covers story files, controls, storybooks, and using it with Fusion, with a real-game button component example.

## Tips
- [1:08](https://youtu.be/qo0x-Et5NPk?t=68) **[[development-process-and-speed]]** Install UI Labs from the Roblox marketplace to preview UI components without launching the game, speeding up UI iteration.
- [2:20](https://youtu.be/qo0x-Et5NPk?t=140) **[[ui-ux-design]]** Create a ModuleScript ending in .story per component; expose controls (color, text size) so you can tweak props live in the preview.
- [5:00](https://youtu.be/qo0x-Et5NPk?t=300) **[[ui-ux-design]]** Wrap controlled props in Fusion used-as so they accept either a raw value or a Fusion state, matching the story's control input.
- [7:03](https://youtu.be/qo0x-Et5NPk?t=423) **[[ui-ux-design]]** Use Mount in Widget to dock the preview in a separate window on a second monitor and see live changes like corner radius.
