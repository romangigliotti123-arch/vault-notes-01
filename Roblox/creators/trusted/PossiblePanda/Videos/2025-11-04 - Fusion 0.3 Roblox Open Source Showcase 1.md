# Fusion 0.3 | Roblox Open Source Showcase #1

[Watch](https://youtu.be/3e406QQHt7o) | PossiblePanda | 17,401 views | 2025-11-04

## Summary
Tutorial on Fusion 0.3, a code-based Roblox UI library. Covers installing it (Wally eltab/fusion or fusion.rbxm), creating scopes, ScreenGui/Frame/TextButton with scope:new, state via scope:value with peek(), onEvent handlers, and reusable component ModuleScripts that take props.

## Tips
- [1:36](https://youtu.be/3e406QQHt7o?t=96) **[[version-control-and-tooling]]** Install Fusion via Wally using eltab/fusion; other forks are clones that won't be updated. Without Rojo, drag fusion.rbxm into Studio.
- [2:36](https://youtu.be/3e406QQHt7o?t=156) **[[ui-ux-design]]** Build Fusion UI in a client-side script. Rendering on the client uses the player's CPU/GPU and keeps server load down.
- [3:17](https://youtu.be/3e406QQHt7o?t=197) **[[code-architecture-and-frameworks]]** Create a scope with fusion.scoped({...}) listing every Fusion function you use. Scopes are for memory cleanup of instances and state.
- [4:00](https://youtu.be/3e406QQHt7o?t=240) **[[code-architecture-and-frameworks]]** Alias frequently used Fusion functions (children, scope:new) to local variables to avoid repetitive typing.
- [8:16](https://youtu.be/3e406QQHt7o?t=496) **[[ui-ux-design]]** Use Scale UDim2 values and AnchorPoint (0.5,0.5) for position and size so layouts scale across screen sizes.
- [10:26](https://youtu.be/3e406QQHt7o?t=626) **[[code-architecture-and-frameworks]]** Store UI-driven data in scope:value() state objects. Bound properties like Text update automatically when the value changes.
- [11:51](https://youtu.be/3e406QQHt7o?t=711) **[[ui-ux-design]]** Set TextScaled = true so text fills its container instead of using a fixed text size.
- [13:50](https://youtu.be/3e406QQHt7o?t=830) **[[code-architecture-and-frameworks]]** In Fusion 0.3, read state with peek(value), not :get(). Use peek(counter) + 1 inside handlers to update state.
- [15:10](https://youtu.be/3e406QQHt7o?t=910) **[[code-architecture-and-frameworks]]** Put reusable UI components in ReplicatedStorage as ModuleScripts that take a props table with optional typed defaults.
- [15:53](https://youtu.be/3e406QQHt7o?t=953) **[[code-architecture-and-frameworks]]** Create state inside the component function, not outside it. Otherwise every instance shares one counter, as the speaker demonstrated.
- [17:57](https://youtu.be/3e406QQHt7o?t=1077) **[[common-mistakes]]** The most common Fusion error is a stray or extra comma, or forgetting to return the instance from the component function.
- [19:21](https://youtu.be/3e406QQHt7o?t=1161) **[[ui-ux-design]]** Wrap sibling components in a UIListLayout inside a parent frame so they stack instead of overlapping.
