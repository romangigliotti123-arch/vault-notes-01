## Tips
- [4:43](https://youtu.be/xVtvDYvUTqc?t=283) **[[social-features-and-virality]]** Broadcast other players' level-up fireworks to nearby players so they see and congratulate each other; a small social hook.
- [8:06](https://youtu.be/xVtvDYvUTqc?t=486) **[[first-session-onboarding]]** Keep the item and stat display simple: one big number anyone can read, hide names until selected, avoid making players do math.
- [10:42](https://youtu.be/xVtvDYvUTqc?t=642) **[[building-art-and-assets]]** Use the Photo Booth plugin (by Ego Moose) to make item icons with no background and a consistent stroke, instead of viewport frames or green screen.
- [14:14](https://youtu.be/xVtvDYvUTqc?t=854) **[[core-loops-and-game-design]]** Give every button the same upgrade-tree template plus one unique branch, so progression stays consistent while each zone feels different.
- [3:45](https://youtu.be/xVtvDYvUTqc?t=225) **[[core-loops-and-game-design]]** Design so pure auto-clicking in one spot is not the optimal meta; add mechanics like ordered button sequences that require player movement.
- [1:19](https://youtu.be/xVtvDYvUTqc?t=79) **[[core-loops-and-game-design]]** Make auto-collectors roam and pick up loot themselves rather than pulling loot toward them, which reads as more intentional.
- [0:41](https://youtu.be/xVtvDYvUTqc?t=41) **[[core-loops-and-game-design]]** Add a max capacity to collectors so players must return to collect, giving a reason to revisit earlier zones (Clash of Clans-style).
- [16:18](https://youtu.be/xVtvDYvUTqc?t=978) **[[core-loops-and-game-design]]** Stack multiple collector upgrades (e.g., two coin carts, up to four item carts) to scale collection feel, then balance numbers later.
- [12:45](https://youtu.be/xVtvDYvUTqc?t=765) **[[building-art-and-assets]]** Give each item a distinct click animation (wiggle, slam, kickflip, roll) to make rare or strong items feel different.
- [5:24](https://youtu.be/xVtvDYvUTqc?t=324) **[[building-art-and-assets]]** Learning Blender through a prior game (Slime RNG) paid off; simple primitives like a sphere plus rectangles can make cute stylized models.
- [9:59](https://youtu.be/xVtvDYvUTqc?t=599) **[[core-loops-and-game-design]]** Reuse one particle system for XP and coin pickups; pop-then-fly-to-player-then-to-inventory feels better than linear movement.
- [6:45](https://youtu.be/xVtvDYvUTqc?t=405) **[[building-art-and-assets]]** Tag buttons with CollectionService instead of building physical barriers to define zones, keeping map transitions open.
