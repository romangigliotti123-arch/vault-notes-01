## Summary
Creator uses Claude Max with Forge GUI to build a Roblox parkour movement system (sprint, double jump, wall run, wall jump, slide), then a lava-rising tower race game with rounds, lobby, round modifiers, HUD, and an ability shop. Shows AI prompt-by-prompt workflow and session-usage tracking. Mostly a devlog/experiment.

## Tips
- [1:21](https://youtu.be/5S_MYGBtmbM?t=81) **[[development-process-and-speed]]** Ask the AI for improvement suggestions on a prototype, then tell it to implement the good ones in one batch prompt.
- [3:23](https://youtu.be/5S_MYGBtmbM?t=203) **[[development-process-and-speed]]** Pick game ideas that build on a validated core mechanic; the creator chose a lava-rising tower race because the movement system was already fun and simple to build.
- [5:26](https://youtu.be/5S_MYGBtmbM?t=326) **[[development-process-and-speed]]** Build mechanic by mechanic (round loop, HUD, rewards) and playtest after each step rather than one giant prompt.
- [7:33](https://youtu.be/5S_MYGBtmbM?t=453) **[[thumbnails-icons]]** Provide a reference screenshot to the AI when asking for UI layout changes; it matches style far better than text descriptions.
