## Tips
- [0:43](https://youtu.be/i5sldtdF8m0?t=43) **[[ai-and-tools]]** Use Forge UI icon mode with a short prompt (e.g. 'X close button, cartoony style') to generate UI assets, then refine with follow-up edit prompts.
- [1:24](https://youtu.be/i5sldtdF8m0?t=84) **[[building-art-and-assets]]** Import generated PNGs via Studio Window > Asset Manager, copy the asset ID, and set image scaling to Crop to avoid stretching.
- [2:46](https://youtu.be/i5sldtdF8m0?t=166) **[[building-art-and-assets]]** Replace a UI icon across all frames after checking it in-game; the creator found the AI often did not fully apply requested changes, so verify visually.
- [4:03](https://youtu.be/i5sldtdF8m0?t=243) **[[ai-and-tools]]** Use Forge UI's Magic Edit by uploading a screenshot of an existing frame and prompting for a restyle; generate variants to pick the best match.
