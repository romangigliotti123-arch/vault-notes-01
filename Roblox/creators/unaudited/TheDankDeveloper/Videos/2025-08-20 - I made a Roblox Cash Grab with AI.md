## Summary
Creator builds a tower obby ("OP Slap Tower") in Studio, uses the Lemonade AI plugin to script group-gated access, rainbow UI, and device scaling, tests with fans, then runs a ~10-credit ad campaign and reports roughly break-even Robux recovery.

## Tips
- [2:46](https://youtu.be/OauiTUkK7og?t=166) **[[ai-and-tools]]** Use an AI Roblox coding plugin (Lemonade) to script features from a plain-English prompt, e.g. group-and-like gating, instead of writing Luau yourself.
- [6:05](https://youtu.be/OauiTUkK7og?t=365) **[[ai-and-tools]]** Check AI-generated scripts land in the correct folder/parent; the rainbow background only worked after moving it out of a folder.
- [7:02](https://youtu.be/OauiTUkK7og?t=422) **[[updates-live-ops]]** Set UI size units to Scale instead of Offset so UI fits all device sizes; verify on device previews.
- [8:21](https://youtu.be/OauiTUkK7og?t=501) **[[playtesting-and-feedback]]** Test with a fan group before publishing; the test exposed exploits (OP slaps) and an invisible wall bug.
- [10:12](https://youtu.be/OauiTUkK7og?t=612) **[[playtesting-and-feedback]]** Check group-gated access works for players already in the group; a bug left them unable to open the group door and get the tool.
- [10:54](https://youtu.be/OauiTUkK7og?t=654) **[[ads-and-sponsored-experiences]]** Run a small visits campaign: 10 ad credits, US and Canada only, console unchecked, max bid 0.01, to test ROI cheaply.
- [11:28](https://youtu.be/OauiTUkK7og?t=688) **[[ads-and-sponsored-experiences]]** Ad spend of ~2,800 Robux on ~2,654 visits recovered only ~1,200 Robux in sales, so ads alone did not pay back immediately.
- [12:09](https://youtu.be/OauiTUkK7og?t=729) **[[updates-live-ops]]** Plan to add content after launch; the creator expects updates to help the algorithm pick the game up.
