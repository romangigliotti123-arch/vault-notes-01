# How to make Floating Text in ROBLOX Studio!

## Summary
Tutorial on making floating text in Roblox Studio using a BillboardGui with a TextLabel. Covers setting text, TextScaled, font, transparent background, scale vs offset sizing so text doesn't grow with distance, UIStroke and UIGradient styling.

## Tips
- [0:20](https://youtu.be/K9cVA4EbbB0?t=20) **[[building-art-and-assets]]** Add a BillboardGui to a part, put a TextLabel inside, and set the part's transparency to 1 so the part doesn't obscure the label.
- [0:41](https://youtu.be/K9cVA4EbbB0?t=41) **[[building-art-and-assets]]** Enable TextScaled on the TextLabel so text fits its frame instead of staying tiny.
- [1:22](https://youtu.be/K9cVA4EbbB0?t=82) **[[building-art-and-assets]]** Use Scale, not Offset, for TextLabel and BillboardGui size (set offsets to 0) so floating text doesn't grow larger as the player moves away.
- [2:04](https://youtu.be/K9cVA4EbbB0?t=124) **[[building-art-and-assets]]** Set the BillboardGui size to a fixed scale-based value (e.g. Y 3, 15.5 in the example) so it stays readable at distance.
