## Summary
Shows how to replace Roblox Studio's toolbar icons with a free third-party icon pack ("Vanilla"): download and extract the pack, set File > Studio Settings > Custom Icon Directory to the chosen color folder, restart Studio. Reverting uses the Roblox Custom option. A studio-UI tweak, not game-development advice.

## Tools
Roblox Studio, Vanilla icon pack (free, third-party), 7-Zip or WinRAR (optional for extraction)

## On screen
Screens show the Vanilla icon pack webpage with color variants (Colourful, Mono, Mono Blue, Mono Red, Mono Purple, etc.), a Studio toolbar with the new icons, the Studio Settings dialog with Custom Icon Directory, and a Windows folder picker in the extracted Vanilla folder.
