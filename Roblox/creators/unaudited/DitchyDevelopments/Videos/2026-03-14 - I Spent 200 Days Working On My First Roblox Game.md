# I Spent 200 Days Working On My First Roblox Game

[Watch](https://youtu.be/O9fIqTik9ik) | DitchyDevelopments | 42,042 views | 2026-03-14

## Summary
Developer's 200-day journey building a Roblox hide-and-seek/parkour game. Covers movement system overhaul (nerfs, momentum chaining, speed cap), tracking reliability, a Discord community map competition, learning Blender for own assets, QoL updates (freeze tag, map fixes, coin progression, lobby music), and planned ability/leveling systems. Mostly a devlog.

## Tips
- [0:46](https://youtu.be/O9fIqTik9ik?t=46) **[[core-loops-and-game-design]]** Nerf overpowered mechanics and remove overlapping ones; a dash that carries further on second use and combo-able slide jumps made movement feel broken.
- [1:27](https://youtu.be/O9fIqTik9ik?t=87) **[[core-loops-and-game-design]]** Cap max speed (here 70 studs/sec) so tracking and collision systems can keep up with chained movement.
- [1:27](https://youtu.be/O9fIqTik9ik?t=87) **[[scripting-and-performance]]** Use sub-step position checks between frames so fast-moving players still register tags/hits reliably.
- [3:20](https://youtu.be/O9fIqTik9ik?t=200) **[[core-loops-and-game-design]]** Give hiders/seekers ongoing rewards (coins per tag, coins for surviving 30 seconds) on top of round win/loss rewards to sustain progression.
- [3:20](https://youtu.be/O9fIqTik9ik?t=200) **[[core-loops-and-game-design]]** Fix map exits where players fall off and get stuck; add climbable spots and timed off-path penalties instead of letting players soft-lock.
- [4:10](https://youtu.be/O9fIqTik9ik?t=250) **[[updates-live-ops]]** Add music to lobby, voting and countdown screens so the game feels alive between matches.
- [4:10](https://youtu.be/O9fIqTik9ik?t=250) **[[building-art-and-assets]]** Build a personal asset pack instead of relying on the toolbox to keep maps original and consistent in style.
- [2:05](https://youtu.be/O9fIqTik9ik?t=125) **[[community-and-discord]]** Run community map submission contests via Discord; adding all submitted maps to the game is a way to reward many creators at once.
- [4:51](https://youtu.be/O9fIqTik9ik?t=291) **[[common-mistakes]]** Starting with a simple scoped game is hard to keep to; the author's 'small' project grew into a 200-day build because of feature creep.
