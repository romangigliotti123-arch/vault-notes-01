# Designing Game Expansions with AbstractAlex, Usering & ImprobableAI

[Watch](https://youtu.be/Gv5OVVyWM10) | MustWatch | 14,868 views | 2021-07-16

## Summary
Red Manta team (Alex, Adam, Nate) on designing and shipping major updates for Roblox games (Robloxian High School, World Zero): why big updates matter, brainstorming, MVP cuts, community QA, staged marketing, analytics, grades battle pass, tower update lessons, and Q&A on bugs, shutdowns and cadence.

## Tips
- [2:10](https://youtu.be/Gv5OVVyWM10?t=130) **[[core-loops-and-game-design]]** Major updates should change the core loop or game dynamics, not just add content; weekly updates sustain metrics while major ones improve retention and reach new audiences.
- [4:35](https://youtu.be/Gv5OVVyWM10?t=275) **[[development-process-and-speed]]** Keep one master document for all brainstorm decisions so ideas don't get lost across Discord and calls; treat design docs as living documents.
- [5:15](https://youtu.be/Gv5OVVyWM10?t=315) **[[playtesting-and-feedback]]** Mine ideas from playtest sessions and from community suggestion boards where members upvote ideas; a high-vote threshold sends them to review.
- [11:42](https://youtu.be/Gv5OVVyWM10?t=702) **[[development-process-and-speed]]** Draw the feature's core loop on a whiteboard and cut anything not essential; ship a minimal version first to learn if it's fun before building more.
- [13:44](https://youtu.be/Gv5OVVyWM10?t=824) **[[playtesting-and-feedback]]** Test the minimal feature with dedicated community champions on a mirror test server before it reaches the live game.
- [16:28](https://youtu.be/Gv5OVVyWM10?t=988) **[[playtesting-and-feedback]]** Fix bugs first in playtests since testers fixate on them; then prioritize remaining feedback by whether the feature actually worked.
- [18:34](https://youtu.be/Gv5OVVyWM10?t=1114) **[[development-process-and-speed]]** Push the ship date when testers say a feature isn't ready; one extra week (about 20% more time) beats shipping a rushed update that wastes the prior weeks.
- [20:38](https://youtu.be/Gv5OVVyWM10?t=1238) **[[updates-live-ops]]** Aim for a content drop roughly every two weeks to stay visible on a noisy platform, even while a large feature is in progress.
- [24:05](https://youtu.be/Gv5OVVyWM10?t=1445) **[[development-process-and-speed]]** Get the game in front of players early via alpha/beta; Red Manta's World Zero launched with 70,000 users and zero ad spend due to pre-launch hype.
- [26:08](https://youtu.be/Gv5OVVyWM10?t=1568) **[[updates-live-ops]]** Advertise each update in Discord, Twitter and in-game news bulletins beforehand; returning players won't know what's new otherwise.
- [26:48](https://youtu.be/Gv5OVVyWM10?t=1608) **[[updates-live-ops]]** Run in-game countdown timers for big updates for one to two weeks; Red Manta reports player counts doubling or tripling during hyped updates.
- [34:15](https://youtu.be/Gv5OVVyWM10?t=2055) **[[analytics-metrics]]** Instrument each feature: track level progression, pet and dungeon usage, and use the data to decide future content and whether to remove features.
- [35:47](https://youtu.be/Gv5OVVyWM10?t=2147) **[[analytics-metrics]]** Prioritise retention as the key metric, with ARPU and ARPPU for monetisation health; Red Manta used GameAnalytics SDK for tracking.
- [37:10](https://youtu.be/Gv5OVVyWM10?t=2230) **[[core-loops-and-game-design]]** Fix unbalanced or unpopular features within the first week; players shouldn't have to warm up to a feature that is not fun.
- [37:51](https://youtu.be/Gv5OVVyWM10?t=2271) **[[common-mistakes]]** Pair unpopular changes with good news and explain the reason; hiding the why makes players angrier than hearing an answer they dislike.
- [42:43](https://youtu.be/Gv5OVVyWM10?t=2563) **[[monetisation-gamepasses]]** Improve the purchase funnel after launch: moving a button to where players see it can noticeably increase battle pass sales.
- [43:05](https://youtu.be/Gv5OVVyWM10?t=2585) **[[first-session-onboarding]]** Put key features like the shop directly on screen; deeply hidden features are often never found by most players.
- [53:45](https://youtu.be/Gv5OVVyWM10?t=3225) **[[development-process-and-speed]]** Make new features relevant throughout the game, not just at start or end, and avoid chasing perfection; ship the MVP early.
- [55:01](https://youtu.be/Gv5OVVyWM10?t=3301) **[[first-session-onboarding]]** Don't assume players know how to play; veterans forget newcomers can't unlock classes or find dungeons, so teach core mechanics explicitly.
- [57:59](https://youtu.be/Gv5OVVyWM10?t=3479) **[[common-mistakes]]** Prioritise bugs by whether they make players quit (purchase failures, data loss) rather than by severity alone; fix those before cosmetic issues.
- [1:00:03](https://youtu.be/Gv5OVVyWM10?t=3603) **[[updates-live-ops]]** Use migrate-style updates for minor fixes; use full server shutdowns when purchases or item states break, since players could carry items into servers lacking them.
- [1:00:29](https://youtu.be/Gv5OVVyWM10?t=3629) **[[analytics-metrics]]** Watch long-term retention (week-later returns) to judge an update's success; it is slower to read but shows whether the update kept players.
- [1:05:09](https://youtu.be/Gv5OVVyWM10?t=3909) **[[team-and-budget]]** Don't pull the team off a live game with an active player base for a new project; only shift when the live game shows clear long-term decline.
- [1:21:29](https://youtu.be/Gv5OVVyWM10?t=4889) **[[roblox-platform-changes]]** Avoid paid access: Red Manta's paid access made no money and kept players out; going free drew content creators who wouldn't cover paid-access games.

## Games
- **Robloxian High School** [0:20](https://youtu.be/Gv5OVVyWM10?t=20): Battle pass 'Grades' with exclusive rewards and daily star caps; drove heavy monetisation and more classroom social play.
- **World Zero** [0:50](https://youtu.be/Gv5OVVyWM10?t=50): Launched free with 70k users from pre-launch alpha/beta hype; tower update's random mazes proved less valuable than handcrafted dungeons.
- **Welcome to Bloxburg** [1:03:01](https://youtu.be/Gv5OVVyWM10?t=3781): Kept the same icon for four years, adding only seasonal hats; changing icons can confuse existing players.
- **Adopt Me** [1:19:06](https://youtu.be/Gv5OVVyWM10?t=4746): Hosted huge update launches with hundreds of thousands of players, stress testing Roblox servers.
