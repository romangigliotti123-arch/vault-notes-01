# Core Loop Essentials

[Watch](https://youtu.be/bROouMt1b3g) | MustWatch | 5,053 views | 2022-01-27

## Summary
Explains the core loop as the most-repeated minute-to-minute action that all game systems should tie back to. Illustrates with RPG, baseball, Jailbreak (cop/robber roles) and Robloxian High School, and how to enhance a live loop.

## Tips
- [0:18](https://youtu.be/bROouMt1b3g?t=18) **[[core-loops-and-game-design]]** Define your core loop first: the most-repeated minute-to-minute action players do, since every session relies on it. Without it, the game lacks cohesion.
- [5:33](https://youtu.be/bROouMt1b3g?t=333) **[[core-loops-and-game-design]]** For every new system you add, ask how it interacts with the core loop. If it doesn't feed or augment the loop, don't build it.
- [3:10](https://youtu.be/bROouMt1b3g?t=190) **[[core-loops-and-game-design]]** Give different player roles (e.g. cop vs robber) distinct but meaningful interactions with the same loop, rather than separate loops.
- [6:02](https://youtu.be/bROouMt1b3g?t=362) **[[updates-live-ops]]** Enhance a live core loop with new activities, goals, and map updates to refresh how players interact with it, as Robloxian High School did.
- [6:43](https://youtu.be/bROouMt1b3g?t=403) **[[core-loops-and-game-design]]** Use reward systems like season passes or attendance bonuses to reward players for engaging with the core loop.

## Games
- **Jailbreak** [2:44](https://youtu.be/bROouMt1b3g?t=164): Loop: explore, complete objective, earn money, power up. Cops detain criminals, robbers commit crimes, both earn currency.
- **Robloxian High School** [4:12](https://youtu.be/bROouMt1b3g?t=252): Explore and attend class to earn currency, customize and decorate; many systems all tie back to the core loop.
