# How to ACTUALLY Advertise Your Roblox Game

[Watch](https://youtu.be/7QfaQe4rsq8) | MustWatch | 89,258 views | 2026-03-06

## Summary
Explains how to advertise a Roblox game with Roblox's new ads manager: keep audience on all players, use daily (never lifetime) budgets, run for 7-10+ days, test thumbnail CTR with a small ~$25 test ad first. Argues game quality determines ad cost more than spend; typical spend $50-100 for a strong game.

## Tips
- [0:00](https://youtu.be/7QfaQe4rsq8?t=0) **[[ads-and-sponsored-experiences]]** Use Roblox's new ads system via Creator Hub > Ads; keep audience on 'all players' when advertising a new game.
- [6:08](https://youtu.be/7QfaQe4rsq8?t=368) **[[thumbnails-icons]]** Run a small test ad (lifetime budget at the ~$25 minimum) to measure thumbnail/icon CTR before spending heavily.
- [6:50](https://youtu.be/7QfaQe4rsq8?t=410) **[[ads-and-sponsored-experiences]]** Always use a daily budget, never lifetime; steady daily player flow signals consistency and retention to the algorithm.
- [7:32](https://youtu.be/7QfaQe4rsq8?t=452) **[[ads-and-sponsored-experiences]]** Set daily budget around $5-8 and run ads at least 7 days, ideally more than 10, for consistent exposure.
- [8:55](https://youtu.be/7QfaQe4rsq8?t=535) **[[thumbnails-icons]]** Load multiple thumbnails into one ad; the system pushes the best-performing one, then set that as the game's main thumbnail.
- [4:46](https://youtu.be/7QfaQe4rsq8?t=286) **[[ads-and-sponsored-experiences]]** Ad cost depends on game quality and audience size; a strong game with a big audience can be advertised for roughly $50-100.
- [5:27](https://youtu.be/7QfaQe4rsq8?t=327) **[[game-ideas-and-genres]]** Avoid niche high-complexity genres like realistic FPS; small audiences make ads very expensive and often fail.
