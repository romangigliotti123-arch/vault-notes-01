# How the “Recommended for You” algorithm works on Roblox

[Watch](https://youtu.be/K7jsk3bzmvE) | MustWatch | 5,666 views | 2026-06-15

## Summary
Explains Roblox's "Recommended for You" homepage algorithm as a two-step process. Step one, retrieval, narrows millions of games to thousands using engagement, retention and monetization signals, boosted by ads, editorial features and other channels. Step two, ranking, personalizes order per user using staying engaged, returning, spending Robux and co-playing with friends. Only organic-home signals count. Creator Analytics dashboard shows performance against these signals.
