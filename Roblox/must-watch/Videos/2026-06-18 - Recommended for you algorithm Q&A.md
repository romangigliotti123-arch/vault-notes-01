# Recommended for you algorithm Q&A

[Watch](https://youtu.be/B3R1ybI3yzs) | MustWatch | 3,626 views | 2026-06-18

## Summary
Roblox team (Sandeep, Ben, Patty) explains the two-stage Recommended for You algorithm (retrieval then ranking), the replacement of QPTR with play-through rate and first-play bounce rate, the signal time windows, and the expanded creator analytics dashboard. Q&A covers new games, old game revival, genre neutrality, and D1/D7/D28 definitions.

## Tips
- [8:28](https://youtu.be/B3R1ybI3yzs?t=508) **[[discovery-algorithm]]** Prioritise play-through rate, first-play bounce rate, play time and play days first; they are the most important recommendation signals, per the team.
- [10:25](https://youtu.be/B3R1ybI3yzs?t=625) **[[analytics-metrics]]** Check the Acquisition tab in Creator Analytics; bounce rate is a negative signal, so lower is better.
- [12:29](https://youtu.be/B3R1ybI3yzs?t=749) **[[discovery-algorithm]]** New games are not penalised for 28 days; day-1 signals and PTR/bounce feed distribution early, and deeper retention later earns more impressions.
- [18:06](https://youtu.be/B3R1ybI3yzs?t=1086) **[[discovery-algorithm]]** Old or dormant games can be revived by updating them; the algorithm re-tests with new users daily, so improvements get re-explored.
- [16:52](https://youtu.be/B3R1ybI3yzs?t=1012) **[[analytics-metrics]]** Use Creator Analytics experimentation to A/B test changes; it controls for competition and seasonality to measure causal impact.
- [29:42](https://youtu.be/B3R1ybI3yzs?t=1782) **[[titles-descriptions]]** Set an accurate genre and video/description; mismatched expectations cause bounces, which hurt recommendation signals.
- [23:33](https://youtu.be/B3R1ybI3yzs?t=1413) **[[game-ideas-and-genres]]** Genre is not an explicit ranking factor; casual and deep games both get distribution if users retain on them.
- [28:20](https://youtu.be/B3R1ybI3yzs?t=1700) **[[retention-d1-d7]]** Players coming back on day 1, days 2-7 and days 8-28 all matter; retention on each window feeds the score, so build repeat play.
- [37:56](https://youtu.be/B3R1ybI3yzs?t=2276) **[[discovery-algorithm]]** Pre-ranking is personalised per user, so you should not worry about a fixed list cutoff; the system narrows millions of games to about 100 per user.
- [26:16](https://youtu.be/B3R1ybI3yzs?t=1576) **[[discovery-algorithm]]** Only plays from the Recommended for You surface count for its signals; friend, search or paid traffic do not count as qualified RFY tests.
