## Summary
Tutorial on a professional Roblox dev workflow: VS Code with Luau language server, Rojo for live sync to Studio, Wally for packages, Rokit as toolchain manager, Selene linting, StyLua formatting, and Git/GitHub for version control. Covers setup steps and basic branching. Not about game success or monetisation.

## Tips
- [0:26](https://youtu.be/IJDg6tRJmHo?t=26) **[[development-process-and-speed]]** Use Git version control even when working solo; commits act as restore points and undo in Studio does not reliably recover changes.
- [1:09](https://youtu.be/IJDg6tRJmHo?t=69) **[[scripting-and-performance]]** Write code outside Studio in VS Code with the Luau language server, Selene linter and StyLua auto-format on save for richer IntelliSense and cleaner code.
- [7:11](https://youtu.be/IJDg6tRJmHo?t=431) **[[scripting-and-performance]]** Enable the Luau language server auto-import setting so services and module require paths are suggested and written automatically.
- [9:20](https://youtu.be/IJDg6tRJmHo?t=560) **[[development-process-and-speed]]** Manage shared libraries (e.g. ProfileService, Promise, React, Fusion) with Wally instead of copying them manually; put server-only packages in a server dependency section.
- [11:55](https://youtu.be/IJDg6tRJmHo?t=715) **[[development-process-and-speed]]** Add Wally package folders and autogenerated files (sourcemap.json, wally.lock) to .gitignore so Git tracks only your own code.
