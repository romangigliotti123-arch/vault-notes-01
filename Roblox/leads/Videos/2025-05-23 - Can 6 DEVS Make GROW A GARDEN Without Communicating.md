# Can 6 DEVS Make GROW A GARDEN Without Communicating?

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.

## Summary
A comedic game-swap video where six developers each add to one Roblox Grow a Garden-style ore-mining game in turn without communicating. Shows rapid prototyping, scripting pitfalls, AI-generated 3D assets, and a tongue-in-cheek lesson on how little a single hour of work can change a game.

## Tips
- [4:43](https://youtu.be/Gw2FwndwnOg?t=283) **[[development-process-and-speed]]** Dev 2 spent about 2 hours on core money and save scripts; scope each session to one system so progress is testable.
- [9:30](https://youtu.be/Gw2FwndwnOg?t=570) **[[core-loops-and-game-design]]** Dev 5 found emerald was reachable in about 5 minutes; tune ore value and time-to-unlock against the progression curve before adding content.
- [10:51](https://youtu.be/Gw2FwndwnOg?t=651) **[[core-loops-and-game-design]]** Add something to do while waiting for timers to finish, as Grow a Garden does with fast permanent fruit, so idle time isn't dead time.
- [10:51](https://youtu.be/Gw2FwndwnOg?t=651) **[[combat-and-gameplay-systems]]** Prevent soft-locks: a player who can lose all money must still be able to play; add a recovery path.
