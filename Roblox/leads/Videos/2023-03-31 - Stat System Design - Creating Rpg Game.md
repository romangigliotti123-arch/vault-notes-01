# Stat System Design - Creating Rpg Game

[Watch](https://youtu.be/bYyD6tyz6Dg) | leads | 48,041 views | 2023-03-31

## Summary
Developer explains the stat system in his Roblox RPG: four major stats (Strength, Agility, Intelligence, Vitality) feed secondary stats, with no manual stat allocation. Stats rise only via buffs and items to avoid build-choice FOMO. Magic splits into fire, ice and lightning with simple ailments. The same system drives both players and enemies.

## Tips
- [1:24](https://youtu.be/bYyD6tyz6Dg?t=84) **[[core-loops-and-game-design]]** Skip manual stat allocation if you want low-friction progression; grant stat boosts via items and buffs so players never feel they picked a wrong build.
- [2:22](https://youtu.be/bYyD6tyz6Dg?t=142) **[[core-loops-and-game-design]]** Use one shared stat system for both players and enemies so the same numbers balance both sides.
- [3:54](https://youtu.be/bYyD6tyz6Dg?t=234) **[[genre-mechanics]]** Keep elemental status effects simple (burn, slow, chill, shock) rather than multi-step ailment chains, so players don't get confused by extra calculations.
- [4:34](https://youtu.be/bYyD6tyz6Dg?t=274) **[[combat-and-gameplay-systems]]** Give each status effect a clear gameplay logic tied to its theme, e.g. shock causes missed attacks, chill reduces armor, making effects easy to understand.

## Games
- **Diablo 2** [0:40](https://youtu.be/bYyD6tyz6Dg?t=40): Major stats allocated on level-up affect secondary stats and equipment eligibility; gives build variety.
- **Divinity: Original Sin 2** [3:02](https://youtu.be/bYyD6tyz6Dg?t=182): Elemental interactions like wet plus lightning and poison cloud plus fire create emergent combos.
- **Path of Exile** [3:42](https://youtu.be/bYyD6tyz6Dg?t=222): Two-step ailment application is deep but too complex for a casual audience, per the speaker.
