## [[first-session-onboarding]]
- 2022-02-01 [9:28](https://youtu.be/WGRpglQ87XE?t=568) Playtest the first-time experience with recruited target-audience players before shipping. Watch for usability gaps; Design Home found players missed room requirements, which caused churn. ([[2022-02-01 - Research Methods to Improve Live Game Retention, D1 to D100|Research Methods to Improve Live Game Retention, D]])
- 2022-02-01 [40:36](https://youtu.be/WGRpglQ87XE?t=2436) Teach with memorable, high-value examples. Use a famous fan-favourite character as the reward and the main protagonist as the example for leveling, so players learn the right priorities. ([[2022-02-01 - Research Methods to Improve Live Game Retention, D1 to D100|Research Methods to Improve Live Game Retention, D]])
- 2026-09-18 [3:43](https://youtu.be/j3L0K1yZjms?t=223) Point new players to the in-game Book of Guidance quest; it shows the recommended progression path on the map. ([[2026-09-18 - In-Depth Beginners Leveling Guide Project Slayers 2|In-Depth Beginners Leveling Guide | Project Slayer]])
- 2026-09-18 [15:45](https://youtu.be/j3L0K1yZjms?t=945) Make the key early drop (cutlass, 20% drop chance) obtainable by grinding; players skipping it struggle with fist-only combat. ([[2026-09-18 - In-Depth Beginners Leveling Guide Project Slayers 2|In-Depth Beginners Leveling Guide | Project Slayer]])

## [[player-psychology-and-game-feel]]
- 2018-05-27 [12:53](https://youtu.be/8X4fx-YncqA?t=773) Add a scoring system that rewards combos, variety and quick kills while penalising damage taken, so casual players can mash while skilled players chase grades. ([[2018-05-27 - What Makes a Good Combat System|What Makes a Good Combat System?]])
- 2018-05-27 [13:53](https://youtu.be/8X4fx-YncqA?t=833) Sell impact with animation: a big wind-up, a fast strike, a brief hold on contact (around 3 frames), then a heavy recovery, plus motion lines, screen blur, sparks, enemy hurt reactions and crunchy sound. ([[2018-05-27 - What Makes a Good Combat System|What Makes a Good Combat System?]])
- 2022-04-25 [10:34](https://youtu.be/Zrf1cou_yVo?t=634) Use drains to add risk: losing carried currency on death (Elden Ring) makes exploring new areas feel dangerous as holdings grow. ([[2022-04-25 - How Video Game Economies are Designed|How Video Game Economies are Designed]])
- 2025-05-23 [11:32](https://youtu.be/Gw2FwndwnOg?t=692) Random size and rarity rolls create engagement, but too much variance can feel like pure gambling; tune the odds so good results still happen. ([[2025-05-23 - Can 6 DEVS Make GROW A GARDEN Without Communicating|Can 6 DEVS Make GROW A GARDEN Without Communicatin]])
- 2025-06-28 [1:08](https://youtu.be/-Z0C5YJtnqY?t=68) Free earn-once-every-30-minutes unit roll gives free-to-play players an outlet alongside paid gacha crates. ([[2025-06-28 - i spent WAY TOO MUCH for the NEW SPONGEBOB TD EXOTIC|i spent WAY TOO MUCH for the NEW SPONGEBOB TD EXOT]])
- 2026-09-18 [29:43](https://youtu.be/j3L0K1yZjms?t=1783) Stackable title bonuses let new slots progress faster, encouraging repeat investment in progression. ([[2026-09-18 - In-Depth Beginners Leveling Guide Project Slayers 2|In-Depth Beginners Leveling Guide | Project Slayer]])
