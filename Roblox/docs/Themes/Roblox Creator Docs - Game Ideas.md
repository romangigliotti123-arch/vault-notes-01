- 2026-10-28 [page](https://create.roblox.com/docs/ip-licensing) Build games around popular licensed IP from the Licenses catalog to reach audiences already familiar with the characters, settings, and storylines. ([[2026-10-28 - Docs ip-licensing|Docs: ip-licensing]])
- 2026-10-28 [page](https://create.roblox.com/docs/production/game-design/design-for-roblox) Match the design patterns and UX of the most popular games in your genre so seasoned users need less explanation upfront. ([[2026-10-28 - Docs production game-design design-for-roblox|Docs: production / game-design / design-for-roblox]])
- 2026-10-28 [page](https://create.roblox.com/docs/production/game-design/design-for-roblox) Strange and innovative games can succeed on Roblox more than elsewhere, though iterating on proven designs and themes remains relevant. ([[2026-10-28 - Docs production game-design design-for-roblox|Docs: production / game-design / design-for-roblox]])
- 2026-10-28 [page](https://create.roblox.com/docs/chat/preset-system-guidelines) Keep the preset list to 12 or fewer per universe, finite and creator-controlled. ([[2026-10-28 - Docs chat preset-system-guidelines|Docs: chat / preset-system-guidelines]])
- 2026-10-28 [page](https://create.roblox.com/docs/production/game-design/monetization-foundations) Before choosing items, know your players: whether they are competitive, collaborative, casual or experienced, and how easy the experience is to learn. - 2026-10-28 [page](https://create.roblox.com/docs/education/developer/planning-for-educational-settings) Start educational games from learning standards and objectives, then build gameplay that supports the learning rather than starting from a mechanic. ([[2026-10-28 - Docs education developer planning-for-educational-settings|Docs: education / developer / planning-for-educati]])
- 2026-10-28 [page](https://create.roblox.com/docs/education/developer/planning-for-educational-settings) Make objectives specific and measurable, and have each show how a student demonstrates the knowledge, e.g. describing concepts or analysing situations. ([[2026-10-28 - Docs education developer planning-for-educational-settings|Docs: education / developer / planning-for-educati]])
- 2026-10-28 [page](https://create.roblox.com/docs/creator-programs/standout-games) Target underrepresented genres: RPG, strategy, puzzle, shooter. - 2026-10-28 [page](https://create.roblox.com/docs/resources/battle-royale) Offer several modes (Last One Standing, Solo and Team Deathmatch, Free Play) in one experience to serve different play styles. ([[2026-10-28 - Docs resources battle-royale|Docs: resources / battle-royale]])
- 2026-10-28 [page](https://create.roblox.com/docs/production/publishing/experience-genres) Only pick a genre once you are confident what your game is; genre changes are limited to once every three months. - 2026-10-28 [page](https://create.roblox.com/docs/production/publishing/experience-genres) When multiple genres fit, pick the one matching the game's primary purpose or core gameplay loop. - 2026-10-28 [page](https://create.roblox.com/docs/production/publishing/experience-genres) Select a subgenre when one applies to describe core mechanics more precisely; a genre without subgenre is acceptable if none fits. ([[2026-10-28 - Docs production publishing experience-genres|Docs: production / publishing / experience-genres]])
- 2026-10-28 [page](https://create.roblox.com/docs/production/roblox-user-base) Design your game around three platform strengths: content variety, low friction (play in seconds on almost any device), and social connection (friends playing together). ([[2026-10-28 - Docs production roblox-user-base|Docs: production / roblox-user-base]])
- 2026-10-28 [page](https://create.roblox.com/docs/production/roblox-user-base) Study and emulate common platform conventions and mechanics so players learn your game quickly and are less likely to bounce in frustration. ([[2026-10-28 - Docs production roblox-user-base|Docs: production / roblox-user-base]])
- 2026-10-28 [page](https://create.roblox.com/docs/get-started/strategies) Choose a proven genre (RPGs, simulators, obbies, survival) to raise the likelihood of attracting and retaining players. ([[2026-10-28 - Docs get-started strategies|Docs: get-started / strategies]])
- 2026-10-28 [page](https://create.roblox.com/docs/education/build-it-play-it-story-games/writing-the-story) Keep the story idea simple: write 2-3 sentences for the opening paragraph before coding anything. ## [[core-loops-and-game-design]]
- 2026-10-28 [page](https://create.roblox.com/docs/production/configs) Use configs instead of hard-coded constants for boss health, XP gain, item prices so you can tune live without a new version. ([[2026-10-28 - Docs production configs|Docs: production / configs]])
- 2026-10-28 [page](https://create.roblox.com/docs/education/battle-royale-series/cleanup-and-reset) Structure the match as a game loop: intermission, prepare, match, end status, cleanup, reset, then repeat, so the game runs indefinitely. ([[2026-10-28 - Docs education battle-royale-series cleanup-and-reset|Docs: education / battle-royale-series / cleanup-a]])
- 2026-10-28 [page](https://create.roblox.com/docs/education/adventure-game-series/finishing-the-project) Tune sell price per item between 50 and 200, multiplied by item count, so the sell loop feels rewarding. ([[2026-10-28 - Docs education adventure-game-series finishing-the-project|Docs: education / adventure-game-series / finishin]])
- 2026-10-28 [page](https://create.roblox.com/docs/education/adventure-game-series/finishing-the-project) Set upgrade capacity increase to 10-15 and upgrade cost to 500-1000 to keep upgrades challenging but fair. ([[2026-10-28 - Docs education adventure-game-series finishing-the-project|Docs: education / adventure-game-series / finishin]])
- 2026-10-28 [page](https://create.roblox.com/docs/education/adventure-game-series/finishing-the-project) Vary item placement and add obstacles to collection so item gathering stays fun rather than trivial. ([[2026-10-28 - Docs education adventure-game-series finishing-the-project|Docs: education / adventure-game-series / finishin]])
- 2026-10-28 [page](https://create.roblox.com/docs/education/adventure-game-series/create-the-map) Define the game loop as a cycle of mechanics (e.g. explore, harvest, sell, upgrade) before building; each loop step should be a distinct player action. ([[2026-10-28 - Docs education adventure-game-series create-the-map|Docs: education / adventure-game-series / create-t]])
- 2026-10-28 [page](https://create.roblox.com/docs/production/game-design/prototyping) Prioritise prototyping the core loop, the central gameplay the whole game is built on. ([[2026-10-28 - Docs production game-design prototyping|Docs: production / game-design / prototyping]])
- 2026-10-28 [page](https://create.roblox.com/docs/production/game-design/prototyping) Work out game rules in detail, e.g. respawn timer length, respawn location, and factors that change how fast players rejoin the action. ([[2026-10-28 - Docs production game-design prototyping|Docs: production / game-design / prototyping]])
- 2026-10-28 [page](https://create.roblox.com/docs/education/adventure-game-series/collect-items) Make harvested items disappear for a few seconds so players explore for more instead of re-clicking one object. ([[2026-10-28 - Docs education adventure-game-series collect-items|Docs: education / adventure-game-series / collect-]])
- 2026-10-28 [page](https://create.roblox.com/docs/education/battle-royale-series/finishing-the-project) Make the lobby social with mini-games such as physics spheres or mini obstacle courses to keep players engaged during intermission. ([[2026-10-28 - Docs education battle-royale-series finishing-the-project|Docs: education / battle-royale-series / finishing]])
- 2026-10-28 [page](https://create.roblox.com/docs/education/battle-royale-series/landing) Build a round-based game loop that runs in the background and drives match states; separate concerns into modules (game loop, player management, timers). ([[2026-10-28 - Docs education battle-royale-series landing|Docs: education / battle-royale-series / landing]])
- 2026-10-28 [page](https://create.roblox.com/docs/education/battle-royale-series/landing) Track players in arrays and update them as players start, win, or leave matches. ([[2026-10-28 - Docs education battle-royale-series landing|Docs: education / battle-royale-series / landing]])
- 2026-10-28 [page](https://create.roblox.com/docs/tutorials/curriculums/gameplay-scripting/add-rounds) Track team points in a separate attribute store rather than only the Teams service, because a leaving player's contribution is deducted from team score on disconnect. ([[2026-10-28 - Docs tutorials curriculums gameplay-scripting add-rounds|Docs: tutorials / curriculums / gameplay-scripting]])
- 2026-10-28 [page](https://create.roblox.com/docs/tutorials/curriculums/gameplay-scripting/add-rounds) Set a clear round objective shown at the top of the screen so players know what the team must do to win. ([[2026-10-28 - Docs tutorials curriculums gameplay-scripting add-rounds|Docs: tutorials / curriculums / gameplay-scripting]])
- 2026-10-28 [page](https://create.roblox.com/docs/tutorials/curriculums/gameplay-scripting/add-rounds) Use rounds with clear start and finish points so players can measure progress and get periodic equal footing, especially in team games. ([[2026-10-28 - Docs tutorials curriculums gameplay-scripting add-rounds|Docs: tutorials / curriculums / gameplay-scripting]])
- 2026-10-28 [page](https://create.roblox.com/docs/tutorials/curriculums/gameplay-scripting/add-rounds) Keep the objective limit in a single shared config module so the UI and server both read the same value and can be tuned quickly. ([[2026-10-28 - Docs tutorials curriculums gameplay-scripting add-rounds|Docs: tutorials / curriculums / gameplay-scripting]])
- 2026-10-28 [page](https://create.roblox.com/docs/tutorials/curriculums/gameplay-scripting/add-rounds) Reset all leaderboard and team points to zero at the start of each round loop before sorting players into teams. ([[2026-10-28 - Docs tutorials curriculums gameplay-scripting add-rounds|Docs: tutorials / curriculums / gameplay-scripting]])
- 2026-10-28 [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/ui/proximity-prompts) Set HoldDuration above zero for actions that should feel deliberate (e.g. picking a lock); PromptTriggered fires only after the hold completes. ([[2026-10-28 - Docs tutorials use-case-tutorials ui proximity-prompts|Docs: tutorials / use-case-tutorials / ui / proxim]])
- 2026-10-28 [page](https://create.roblox.com/docs/resources/the-mystery-of-duvall-drive/develop-a-moving-world) Decide which movement tool fits by need: physics for interactables, TweenService for scripted motion, animations for shared motion, particles for ambient effects. - 2026-10-28 [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-2/parameters-practice-buttons) Give players feedback when they touch a button (color change, sound) so they know it is being interacted with. ([[2026-10-28 - Docs tutorials fundamentals coding-2 parameters-practice-buttons|Docs: tutorials / fundamentals / coding-2 / parame]])
- 2026-10-28 [page](https://create.roblox.com/docs/characters/character-controller-library) Do not disable Running; doing so prevents characters from moving along the ground. ([[2026-10-28 - Docs characters character-controller-library|Docs: characters / character-controller-library]])
- 2026-10-28 [page](https://create.roblox.com/docs/characters/character-controller-library) If FallingDown is enabled, always keep GettingUp enabled; otherwise characters can trip but never get back up. ([[2026-10-28 - Docs characters character-controller-library|Docs: characters / character-controller-library]])
- 2026-10-28 [page](https://create.roblox.com/docs/characters/character-controller-library) Use Input Mode Press for discrete actions (dash, attack, throw), Hold or Toggle for sustained actions (sprint, aim, block, crouch), Hold with Repeats for repeated jumping. ([[2026-10-28 - Docs characters character-controller-library|Docs: characters / character-controller-library]])
- 2026-10-28 [page](https://create.roblox.com/docs/characters/character-controller-library) Do not put Rule.Input into StartsWhen or RunsWhile; it throws an error. - 2026-10-28 [page](https://create.roblox.com/docs/characters/character-controller-library) Use OutlivesInputWhile on Hold/Toggle abilities to keep an action running past release under a world condition (e.g. crouch while a ceiling is overhead). - 2026-10-28 [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-6/coding-concept-algorithms) Break large game logic into smaller functions that call each other, e.g. a main function calling pickClothes() and putOnClothes(), to keep systems manageable. - 2026-10-28 [page](https://create.roblox.com/docs/production/game-design/introduction-to-quest-design) Tie quests to the core loop so players naturally earn and spend resources; scarce or effort-heavy sources hurt economy participation and retention. ([[2026-10-28 - Docs production game-design introduction-to-quest-design|Docs: production / game-design / introduction-to-q]])
- 2026-10-28 [page](https://create.roblox.com/docs/production/game-design/introduction-to-quest-design) Use quest-based season passes with reward tiers tied to core-loop activities, showing progress UI against the season deadline. ([[2026-10-28 - Docs production game-design introduction-to-quest-design|Docs: production / game-design / introduction-to-q]])
- 2026-10-28 [page](https://create.roblox.com/docs/production/game-design/introduction-to-quest-design) Use achievements/badges for challenging alternate goals (e.g., unusual gameplay combos) to re-engage experienced players between updates. ([[2026-10-28 - Docs production game-design introduction-to-quest-design|Docs: production / game-design / introduction-to-q]])
- 2026-10-28 [page](https://create.roblox.com/docs/production/game-design/introduction-to-quest-design) Use quests to surface under-discovered features in large worlds or complex games; a quest can be the first time players learn a location exists. ([[2026-10-28 - Docs production game-design introduction-to-quest-design|Docs: production / game-design / introduction-to-q]])
- 2026-10-28 [page](https://create.roblox.com/docs/production/game-design/introduction-to-quest-design) Add optional flavor text to quests to deliver narrative and tie rewards thematically to the story. ([[2026-10-28 - Docs production game-design introduction-to-quest-design|Docs: production / game-design / introduction-to-q]])
