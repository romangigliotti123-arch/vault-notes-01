- 2026-10-28 [page](https://create.roblox.com/docs/production/publishing/thumbnails) Upload 16:9 thumbnails at 1920×1080; other ratios get stretched. ([[2026-10-28 - Docs production publishing thumbnails|Docs: production / publishing / thumbnails]])
