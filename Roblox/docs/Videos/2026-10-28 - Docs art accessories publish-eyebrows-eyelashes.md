# Docs: art / accessories / publish-eyebrows-eyelashes

[Open](https://create.roblox.com/docs/art/accessories/publish-eyebrows-eyelashes.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs on publishing avatar bodies bundled with eyelash and eyebrow accessories. Covers Marketplace requirements (Automatic Skinning Transfer with RBX_Leader/RBX_Follower joints), the only allowed bundled cosmetics, and the Accessory Fitting Tool steps to generate and parent face accessories under the character Model.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/publish-eyebrows-eyelashes) **[[ugc-and-avatar-economy]]** Only eyelashes, eyebrows, and hair can be bundled with a body on Marketplace upload; horns, makeup, glitter and other facial cosmetics are not accepted.
- [page](https://create.roblox.com/docs/art/accessories/publish-eyebrows-eyelashes) **[[3d-modeling-rigging-and-animation]]** Face accessories must use Automatic Skinning Transfer with the RBX_Leader and RBX_Follower special joints to be publishable on the Marketplace.
- [page](https://create.roblox.com/docs/art/accessories/publish-eyebrows-eyelashes) **[[ugc-and-avatar-economy]]** Parent eyelash and eyebrow Accessory objects under the avatar character Model before uploading the body to the Marketplace.
- [page](https://create.roblox.com/docs/art/accessories/publish-eyebrows-eyelashes) **[[building-art-and-assets]]** Import the .fbx face accessory and body, set Rig Type to Rthro for the reference body, then run Accessory Fitting Tool with Accessory > Eyelash or Eyebrow asset type.
- [page](https://create.roblox.com/docs/art/accessories/publish-eyebrows-eyelashes) **[[building-art-and-assets]]** Rename face accessories to EyelashAccessory or EyebrowAccessory if required before upload.
