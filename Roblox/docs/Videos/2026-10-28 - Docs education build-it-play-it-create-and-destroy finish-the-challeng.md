## Summary
Roblox Creator Challenge follow-up tutorial: how to add custom building models to the map. Models must be placed in the HighPoints, MediumPoints, or LowPoints folders under Workspace > Arena > Map so the code recognizes them as destroyable and scores them by value. Any Studio-built model or trusted Marketplace object can be used.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/finish-the-challenge) **[[building-and-level-design]]** Place destructible buildings in the HighPoints, MediumPoints, or LowPoints folder according to how many points they should be worth when destroyed; the code only scores objects in these folders.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/finish-the-challenge) **[[building-art-and-assets]]** Clear any search filters in the Explorer before adding models so the folder tree is fully visible.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/finish-the-challenge) **[[building-art-and-assets]]** Sample trusted Marketplace objects as an alternative to building models from scratch.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/finish-the-challenge) **[[building-art-and-assets]]** Objects can be copied and pasted from other Studio files into the template, as long as they are placed in the correct scoring folder.
