# Docs: education / lesson-plans / galactic-speedway-lesson

[Open](https://create.roblox.com/docs/education/lesson-plans/galactic-speedway-lesson.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Education lesson plan for "Galactic Speedway": students build a driftspeeder spaceship from premade 3D parts in Roblox Studio, add a Body part with flight script, change a speed variable, test in a race, and publish with VIP/private servers for classmates. Covers timing, troubleshooting and classroom management.

## Tips
- [page](https://create.roblox.com/docs/education/lesson-plans/galactic-speedway-lesson) **[[first-session-onboarding]]** Set a time limit (e.g. 2 minutes) for the initial test drive so students stay focused before building.
- [page](https://create.roblox.com/docs/education/lesson-plans/galactic-speedway-lesson) **[[development-process-and-speed]]** Use placeholder titles and descriptions (e.g. 'My game') when publishing first; change them after finishing to save time.
- [page](https://create.roblox.com/docs/education/lesson-plans/galactic-speedway-lesson) **[[development-process-and-speed]]** Set time limits per build step (e.g. five minutes for wings) and reserve at least five minutes for testing.
- [page](https://create.roblox.com/docs/education/lesson-plans/galactic-speedway-lesson) **[[common-mistakes]]** If a vehicle won't fly, confirm it is inside the Garage folder in Explorer and includes at least one Body part with the flight script.
- [page](https://create.roblox.com/docs/education/lesson-plans/galactic-speedway-lesson) **[[building-and-level-design]]** Check builds from multiple angles with camera tools; parts may float or be misaligned.
- [page](https://create.roblox.com/docs/education/lesson-plans/galactic-speedway-lesson) **[[community-and-discord]]** Use private/VIP servers so only class members can join published games when students share them.
- [page](https://create.roblox.com/docs/education/lesson-plans/galactic-speedway-lesson) **[[playtesting-and-feedback]]** Set sportsmanship guidelines for playtesting: respect others, don't make excuses when losing, don't rub it in when winning.
- [page](https://create.roblox.com/docs/education/lesson-plans/galactic-speedway-lesson) **[[building-art-and-assets]]** Encourage experimenting with different part sizes and rotations; unexpected part uses often produce better designs.
- [page](https://create.roblox.com/docs/education/lesson-plans/galactic-speedway-lesson) **[[first-session-onboarding]]** Use 'Ask 3 Before Me': students ask three peers before asking the instructor for help.
- [page](https://create.roblox.com/docs/education/lesson-plans/galactic-speedway-lesson) **[[scripting-and-performance]]** Changing a single speed variable is a simple way to tune vehicle feel; introduce variables as placeholders for values.
