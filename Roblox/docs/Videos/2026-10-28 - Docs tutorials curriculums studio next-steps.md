## Summary
Roblox Studio docs "Next steps" page: points new developers to beginner lessons (building, coding, VFX, animation), then to Studio-specific guides (Projects, Assets, Data model, Client-server runtime), the Plant reference project, and intermediate tutorials (HUD meters, 3D audio, saving player data) before advanced paths.

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/studio/next-steps) **[[development-process-and-speed]]** If new to development, complete the building, coding, VFX and animation beginner lessons before making your first game, then learn Luau fundamentals.
- [page](https://create.roblox.com/docs/tutorials/curriculums/studio/next-steps) **[[development-process-and-speed]]** Pick one development specialization that interests you; if one area doesn't fit, try another, since game development spans many specializations.
- [page](https://create.roblox.com/docs/tutorials/curriculums/studio/next-steps) **[[data-persistence]]** Learn to save player data via the intermediate 'Save player data' tutorial as soon as your game needs progression that persists.
- [page](https://create.roblox.com/docs/tutorials/curriculums/studio/next-steps) **[[code-architecture-and-frameworks]]** Study the Plant reference project to see tradeoffs and rationale behind common implementation choices before designing your own systems.
