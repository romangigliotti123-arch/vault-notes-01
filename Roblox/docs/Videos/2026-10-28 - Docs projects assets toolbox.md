# Docs: projects / assets / toolbox

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/projects/assets/toolbox.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Creator Docs page on the Studio Toolbox: its four sections (Creator Store, Inventory, Recent, Creations), how to search and insert assets, disabling asset scripts, editing published assets via Asset Configuration, and WebView2/WebKit troubleshooting steps.

## Tips
- [page](https://create.roblox.com/docs/projects/assets/toolbox) **[[building-art-and-assets]]** Right-click an inserted asset in Explorer and choose Disable Scripts to use it without its bundled scripts running.
- [page](https://create.roblox.com/docs/projects/assets/toolbox) **[[building-art-and-assets]]** Use the Creations tab to find and configure assets you published or that groups you belong to published; Edit Asset lets you restore earlier versions.
- [page](https://create.roblox.com/docs/projects/assets/toolbox) **[[ai-and-tools]]** If the Toolbox fails to load, close all Studio instances, then delete the WebView2 data folder at %LOCALAPPDATA%\Roblox\RobloxStudio\WebView2 on Windows; Studio recreates it on launch.
- [page](https://create.roblox.com/docs/projects/assets/toolbox) **[[ai-and-tools]]** On Mac, delete ~/Library/WebKit/com.Roblox.RobloxStudio and ~/Library/Caches/com.Roblox.RobloxStudio/WebKit to reset the Toolbox web view.

## Tools
Roblox Studio Toolbox, Creator Store, Asset Configuration window, WebView2
