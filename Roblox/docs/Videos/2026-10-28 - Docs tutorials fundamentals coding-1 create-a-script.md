## Summary
Beginner Roblox docs page: creating a Script in ServerScriptService, print() and Output window testing, string and number data types, declaring local variables (camelCase naming), and string concatenation with the .. operator. Introduces Luau basics; no monetisation or growth advice.

## Tips
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-1/create-a-script) **[[development-process-and-speed]]** Create scripts in ServerScriptService to keep server code in one dedicated folder.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-1/create-a-script) **[[titles-descriptions]]** Name scripts descriptively so you and teammates remember what each does.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-1/create-a-script) **[[luau-language-and-types]]** Prefer local variables over globals; too many globals can make your game slow and unresponsive.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-1/create-a-script) **[[luau-language-and-types]]** Use camelCase for variable names and make names describe purpose; avoid generic names like myVariable.
