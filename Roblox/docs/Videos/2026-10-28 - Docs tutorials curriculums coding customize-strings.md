## Summary
Roblox docs tutorial on customizing a Luau story-maker string: adding punctuation via concatenation, line breaks with \n, and adding more placeholder questions with GetInput and combining answers into a story string. Beginner scripting walkthrough, no business advice.

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/coding/customize-strings) **[[luau-language-and-types]]** Use .. to concatenate strings; add a trailing space after punctuation so the next sentence doesn't run into it.
- [page](https://create.roblox.com/docs/tutorials/curriculums/coding/customize-strings) **[[luau-language-and-types]]** Use \n escape sequences inside strings for line breaks; repeat \n for multiple breaks.
- [page](https://create.roblox.com/docs/tutorials/curriculums/coding/customize-strings) **[[testing-debugging-and-qa]]** Playtest after each change to confirm the code works before adding more sentences.
