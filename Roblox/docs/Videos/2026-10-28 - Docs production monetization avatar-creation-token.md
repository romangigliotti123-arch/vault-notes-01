# Docs: production / monetization / avatar-creation-token

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/production/monetization/avatar-creation-token.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on avatar creation tokens: what they are, required for in-game avatar item creation APIs, and how to create one in the Creator Dashboard (item type, price floor, optional minimum price, creation advance and fee, token ID). Creator requirements must be maintained.

## Tips
- [page](https://create.roblox.com/docs/production/monetization/avatar-creation-token) **[[monetisation-other]]** Owner of a game using in-game avatar creation earns Marketplace commissions as both creator and game owner.
- [page](https://create.roblox.com/docs/production/monetization/avatar-creation-token) **[[monetisation-other]]** Choose the token item type carefully; it cannot be changed after creation. Body uses PromptCreateAvatarAsync; other types use PromptCreateAvatarAssetAsync.
- [page](https://create.roblox.com/docs/production/monetization/avatar-creation-token) **[[pricing]]** To offer different price points for same-type items in your game, purchase multiple tokens rather than one.
- [page](https://create.roblox.com/docs/production/monetization/avatar-creation-token) **[[pricing]]** Set the Amount Above Price Floor and optional Do not price below minimum; both can be modified after creation.

## Tools
Creator Dashboard, PromptCreateAvatarAsync, PromptCreateAvatarAssetAsync, PromptCreateMakeupAsync
