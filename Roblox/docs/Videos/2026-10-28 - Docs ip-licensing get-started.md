# Docs: ip-licensing / get-started

[Open](https://create.roblox.com/docs/ip-licensing/get-started.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs on becoming a rights holder: License Manager (license your IP to creators with set terms, revenue share, eligibility) and Rights Manager (report unauthorized use and request removals). Covers eligibility, account registration, IP family creation, keyword and image requirements, and documentation rules.

## Tips
- [page](https://create.roblox.com/docs/ip-licensing/get-started) **[[business-and-payouts]]** Register License Manager licensing on a Roblox account with no published earning games; license earnings are taxed as royalties, game earnings as services, and mixing them taxes all as royalties.
- [page](https://create.roblox.com/docs/ip-licensing/get-started) **[[brand-deals-and-ip-licensing]]** Make every IP keyword and image verifiable with a citation to your supporting document (page, section, or timestamp), or the submission may be rejected.
- [page](https://create.roblox.com/docs/ip-licensing/get-started) **[[brand-deals-and-ip-licensing]]** Use only distinct images: color, individual characters or logos on plain backgrounds; avoid geometric shapes, common objects, composites and text overlays.
- [page](https://create.roblox.com/docs/ip-licensing/get-started) **[[brand-deals-and-ip-licensing]]** Add at least 10 approved images to an IP family, otherwise Roblox generates no game matches even though creators can still request licenses.

## Numbers
- [page](https://create.roblox.com/docs/ip-licensing/get-started) Minimum approved images for game matches: **10** (Fewer than 10 approved images means no game matches generated)
- [page](https://create.roblox.com/docs/ip-licensing/get-started) Commercialized IP portfolio for License Manager: **5 or more works** (Alternative: existing license with established Roblox creator)
- [page](https://create.roblox.com/docs/ip-licensing/get-started) Max images per IP family: **50 approved or pending** (Archived images don't count toward limit)
- [page](https://create.roblox.com/docs/ip-licensing/get-started) Max image file size: **5 MB** (JPEG or PNG only)
- [page](https://create.roblox.com/docs/ip-licensing/get-started) Minimum image resolution: **224 x 224 px** (Preferred aspect ratio 1:1, up to 16:9 or 9:16)
- [page](https://create.roblox.com/docs/ip-licensing/get-started) Max supporting files per upload: **3** (Applies to account registration and IP ownership docs)
