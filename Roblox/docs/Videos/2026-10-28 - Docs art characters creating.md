# Docs: art / characters / creating

[Open](https://create.roblox.com/docs/art/characters/creating.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs tutorial on creating a custom avatar character body in Blender (3.4+) starting from Roblox's downloadable template model. Covers selecting a template with time-saving armature/rig/face setup, non-destructive sculpting, texture paint, editing cage meshes, cleaning for export, and exporting to Studio.

## Tips
- [page](https://create.roblox.com/docs/art/characters/creating) **[[3d-modeling-rigging-and-animation]]** Start from Roblox's downloadable character template instead of building armature, rigging, skinning and face setup from scratch; it saves significant time.
- [page](https://create.roblox.com/docs/art/characters/creating) **[[3d-modeling-rigging-and-animation]]** Use non-destructive sculpting workflows in Blender so modeling changes stay editable.
- [page](https://create.roblox.com/docs/art/characters/creating) **[[3d-modeling-rigging-and-animation]]** Create the character texture with Blender's texture paint tools on the template UVs.
- [page](https://create.roblox.com/docs/art/characters/creating) **[[3d-modeling-rigging-and-animation]]** Shape the avatar by editing the template's cage mesh objects, not the rigged body geometry directly.
- [page](https://create.roblox.com/docs/art/characters/creating) **[[3d-modeling-rigging-and-animation]]** Clean up and prep the Blender project before export to avoid problems when importing into Studio.
