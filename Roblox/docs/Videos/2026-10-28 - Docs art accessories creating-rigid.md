# Docs: art / accessories / creating-rigid

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/art/accessories/creating-rigid.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs tutorial on creating a rigid accessory: model a simple 3D mesh in Blender, import into Studio, and convert it into a Marketplace-ready Class.Accessory. Notes that listing requires Plus/Premium, an upload fee, and a publishing advance. Workflow is transferable to other modeling apps.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid) **[[building-art-and-assets]]** Rigid accessories attach to avatar attachment points; users can adjust position and rotation per body type, so design items to tolerate that offset.
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid) **[[ugc-and-avatar-economy]]** Listing a rigid accessory on the Marketplace requires a Roblox Plus or Premium account, an upload fee, and a publishing advance.
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid) **[[3d-modeling-rigging-and-animation]]** The same accessory workflow (model, import to Studio, convert to Class.Accessory) applies to other third-party modeling apps, not just Blender.

## Tools
Blender, Roblox Studio, Class.Accessory
