# Docs: education / collaboration / collaboration-best-practices

[Open](https://create.roblox.com/docs/education/collaboration/collaboration-best-practices.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox education docs on collaboration in classrooms: setting guidelines, conflict resolution using "I" messages and interest-based talk, and group strategies like "Ask Three Before Me", skill-shares, rotating roles, and shared to-do lists.

## Tips
- [page](https://create.roblox.com/docs/education/collaboration/collaboration-best-practices) **[[community-and-discord]]** Set classroom guidelines up-front: build your own (don't copy), respect others' work, solve problems together; invite students to add their own.
- [page](https://create.roblox.com/docs/education/collaboration/collaboration-best-practices) **[[common-mistakes]]** Ask permission before using someone else's work; never vandalise or put down others' builds.
- [page](https://create.roblox.com/docs/education/collaboration/collaboration-best-practices) **[[team-and-budget]]** Assign team roles (e.g. world builder, coder) and rotate them so members learn new skills.
- [page](https://create.roblox.com/docs/education/collaboration/collaboration-best-practices) **[[development-process-and-speed]]** Keep a group to-do list that anyone can add tasks to, so every member has something to work on.
- [page](https://create.roblox.com/docs/education/collaboration/collaboration-best-practices) **[[community-and-discord]]** Use 'Ask Three Before Me': students ask three peers before the instructor for help.
- [page](https://create.roblox.com/docs/education/collaboration/collaboration-best-practices) **[[community-and-discord]]** Give students 5-10 minutes during independent work to lead a skill-share tutorial to reward helping others.
- [page](https://create.roblox.com/docs/education/collaboration/collaboration-best-practices) **[[community-and-discord]]** Teach conflict resolution with 'I' messages ('I feel...') instead of 'you' messages, which helps both sides listen.
- [page](https://create.roblox.com/docs/education/collaboration/collaboration-best-practices) **[[community-and-discord]]** Enforce turn-taking without interruption; a private cue like tapping thumb helps a student signal they want to speak.
- [page](https://create.roblox.com/docs/education/collaboration/collaboration-best-practices) **[[community-and-discord]]** In conflicts, discuss interests and goals rather than positions to give students concrete common ground for resolution.

## Numbers
- [page](https://create.roblox.com/docs/education/collaboration/collaboration-best-practices) Skill-share duration: **5-10 minutes** (Independent work time given to a student to lead a tutorial)
