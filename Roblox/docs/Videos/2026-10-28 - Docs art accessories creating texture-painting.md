# Docs: art / accessories / creating / texture-painting

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/art/accessories/creating/texture-painting.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Docs page on texture painting in Blender for Roblox clothing (t-shirt) meshes: enter Texture Paint mode, pick color/brush size/falloff, paint on UV map or 3D mesh, save the PNG texture map via Image > Save. Alternatives suggested: alpha transparencies, seams, PBR textures.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/creating/texture-painting) **[[3d-modeling-rigging-and-animation]]** Paint clothing textures in Blender's Texture Paint mode, drawing on the UV 2D map or 3D mesh, then save the result as a .png via Image > Save.
- [page](https://create.roblox.com/docs/art/accessories/creating/texture-painting) **[[building-art-and-assets]]** Adjust brush color, size and falloff per modification; settings vary with the change you intend to make.
- [page](https://create.roblox.com/docs/art/accessories/creating/texture-painting) **[[building-art-and-assets]]** For more unique looks on meshes, consider alpha transparencies, unique seams, PBR textures, or other Blender texturing techniques.
