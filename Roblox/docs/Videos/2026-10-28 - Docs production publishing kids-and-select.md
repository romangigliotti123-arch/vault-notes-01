# Docs: production / publishing / kids-and-select

[Open](https://create.roblox.com/docs/production/publishing/kids-and-select.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs on Roblox Kids (ages 5-8) and Roblox Select (9-15) account tiers and the publishing requirements to reach those audiences: verification, 2FA, a one-time refundable fee or Plus/Premium subscription, and an evaluation requiring 250 unique plays from highly engaged 16+ players within 60 days. Also covers the expedited review fee and FAQs.

## Tips
- [page](https://create.roblox.com/docs/production/publishing/kids-and-select) **[[discovery-algorithm]]** To reach Kids/Select audiences, grow engagement with age-checked 16+ users; this speeds up the evaluation. Track progress in the Audience Reach dashboard.
- [page](https://create.roblox.com/docs/production/publishing/kids-and-select) **[[common-mistakes]]** Reaching Kids/Select requires 2FA, age/ID verification, and the full Maturity & Compliance Questionnaire; answering only the first question limits you to 16+.
- [page](https://create.roblox.com/docs/production/publishing/kids-and-select) **[[monetisation-other]]** Skip the publishing fee by keeping an active Roblox Plus or Premium subscription for 2 consecutive months before publishing for all ages.
- [page](https://create.roblox.com/docs/production/publishing/kids-and-select) **[[business-and-payouts]]** Publishing fee is refundable: automatic refund 90 days after eligibility, so budget for the temporary cash outlay.
- [page](https://create.roblox.com/docs/production/publishing/kids-and-select) **[[pricing]]** Use the expedited review fee (50,000 Robux, refundable) only for timed launches or off-platform campaigns that need a guaranteed all-ages date.

## Numbers
- [page](https://create.roblox.com/docs/production/publishing/kids-and-select) Expedited review fee (one-time, refundable, per game): **50,000 Robux** (Only for Kids/Select, skips waiting for engagement threshold)
- [page](https://create.roblox.com/docs/production/publishing/kids-and-select) Evaluation threshold for Kids/Select eligibility: **250 unique plays** (From highly engaged age-checked users within 60-day window)
- [page](https://create.roblox.com/docs/production/publishing/kids-and-select) Publishing fee refund timing: **90 days after eligibility** (Also applies if never eligible, counted from payment date)
- [page](https://create.roblox.com/docs/production/publishing/kids-and-select) Minimum creator account age for 16+ publishing: **2 days** (Account must also be in good standing)
