# Docs: art / modeling / roblox-blender-plugin

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.

## Summary
Documentation page for the official Roblox Blender plugin, a Blender add-on that links a Roblox account and transfers 3D objects directly into a Studio session via Open Cloud API. Open-source; points to GitHub for install, licensing, and contribution details.

## Tips
- [page](https://create.roblox.com/docs/art/modeling/roblox-blender-plugin) **[[building-art-and-assets]]** Use the official Roblox Blender plugin to send models straight from Blender to Studio, skipping manual export/import of third-party files to reduce errors.
- [page](https://create.roblox.com/docs/art/modeling/roblox-blender-plugin) **[[3d-modeling-rigging-and-animation]]** Link your Roblox account in the Blender add-on before transferring objects, since transfers run through Open Cloud API authentication.
- [page](https://create.roblox.com/docs/art/modeling/roblox-blender-plugin) **[[version-control-and-tooling]]** The plugin is open-source and built on Open Cloud API; fork or extend it for your own pipeline tooling.
