# Docs: creator-programs / brand-developer-directory

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.

## Summary
Roblox docs page on the Brand Developer Directory and Roblox Partner Program. Lists eligibility criteria for being featured as a Brand Creator Partner (badge), including MAU/like thresholds, custom brand game experience, Talent Hub profile, community standards, and age 18+ submitter. Status: open.

## Tips
- [page](https://create.roblox.com/docs/creator-programs/brand-developer-directory) **[[influencer-and-creator-marketing]]** Build and keep a complete, detailed, up-to-date Talent Hub profile; it is a stated eligibility requirement for the Brand Developer Directory.
- [page](https://create.roblox.com/docs/creator-programs/brand-developer-directory) **[[brand-deals-and-ip-licensing]]** Build a custom game for a brand, IP, or artist on Roblox to qualify for the Brand Developer Directory; interest can be expressed even without one for future featuring.
- [page](https://create.roblox.com/docs/creator-programs/brand-developer-directory) **[[age-ratings-moderation-and-tos]]** Keep account moderation history in good standing and meet Community Standards; these are required for directory eligibility.
- [page](https://create.roblox.com/docs/creator-programs/brand-developer-directory) **[[team-and-budget]]** If working in a group or studio, have the group owner submit the application on behalf of the team; the submitter must be over 18.

## Numbers
- [page](https://create.roblox.com/docs/creator-programs/brand-developer-directory) Eligibility: published games MAU: **at least 1 game with 4M+ MAU**
- [page](https://create.roblox.com/docs/creator-programs/brand-developer-directory) Eligibility: like score: **65% like score on that game**
- [page](https://create.roblox.com/docs/creator-programs/brand-developer-directory) Submitter minimum age: **over 18**
