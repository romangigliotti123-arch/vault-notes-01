# Docs: production / analytics / demographics

[Open](https://create.roblox.com/docs/production/analytics/demographics.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Creator Dashboard docs for the Demographics analytics page. It shows age, gender, country, server frame rate and top languages for monthly active users (MAUs), with per-country data downloadable. It explains how to access the page, including for group-owned games, and suggests using the data to prioritize content, localize metadata and pitch sponsors.

## Tips
- [page](https://create.roblox.com/docs/production/analytics/demographics) **[[analytics-metrics]]** Use Demographics (Creator Dashboard > Analytics) to prioritize future content updates based on your MAU's age, country and language mix.
- [page](https://create.roblox.com/docs/production/analytics/demographics) **[[titles-descriptions]]** Localize game metadata such as titles for your top audience countries and languages.
- [page](https://create.roblox.com/docs/production/analytics/demographics) **[[analytics-metrics]]** Look for audience segments you aren't yet serving and use them to attract new audiences.
- [page](https://create.roblox.com/docs/production/analytics/demographics) **[[business-and-payouts]]** Share demographic data with potential brand sponsors to support sponsorship deals.
- [page](https://create.roblox.com/docs/production/analytics/demographics) **[[analytics-metrics]]** Group-owned games require group analytics permissions to view demographics.

## Numbers
- [page](https://create.roblox.com/docs/production/analytics/demographics) Age/gender group visibility threshold: **Groups with fewer than 3 users are hidden** (Privacy rule for age and gender charts on Demographics page)
- [page](https://create.roblox.com/docs/production/analytics/demographics) Top languages shown: **10** (Top languages list shows top 10 with percentages of MAUs)
- [page](https://create.roblox.com/docs/production/analytics/demographics) Demographic base: **Monthly active users (MAU)** (All demographic breakdowns are percentages of MAUs)
