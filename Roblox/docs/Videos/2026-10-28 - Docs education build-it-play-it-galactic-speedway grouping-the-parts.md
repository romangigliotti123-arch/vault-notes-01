## Summary
Roblox Education docs page (Build It, Play It: Galactic Speedway) on grouping the driftspeeder's parts into one model so attached code applies to the whole vehicle. Covers selecting only the speeder parts, grouping with Ctrl/Cmd+G, and verifying by moving it.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-galactic-speedway/grouping-the-parts) **[[building-and-level-design]]** Group all vehicle parts into a single model before attaching scripts, so code on the body controls the whole vehicle.
- [page](https://create.roblox.com/docs/education/build-it-play-it-galactic-speedway/grouping-the-parts) **[[building-art-and-assets]]** Position the camera above the build and drag-select only the intended parts to avoid grouping stray objects.
- [page](https://create.roblox.com/docs/education/build-it-play-it-galactic-speedway/grouping-the-parts) **[[building-art-and-assets]]** Verify grouping by moving the model; if pieces stay behind or extra objects move, undo (Ctrl/Cmd+Z) and regroup.
