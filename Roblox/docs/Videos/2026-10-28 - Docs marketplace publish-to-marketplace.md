# Docs: marketplace / publish-to-marketplace

[Open](https://create.roblox.com/docs/marketplace/publish-to-marketplace.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on publishing 3D accessories, bodies/heads and Limited/Non-Limited avatar items to the Marketplace: upload via Studio validation and moderation, then configure metadata, availability, pricing, sale location and scheduling, then publish with a fee.

## Tips
- [page](https://create.roblox.com/docs/marketplace/publish-to-marketplace) **[[common-mistakes]]** Test all assets thoroughly before uploading; they must meet Marketplace policy. Fixing after upload requires an update via Update an existing item.
- [page](https://create.roblox.com/docs/marketplace/publish-to-marketplace) **[[thumbnails-icons]]** Add a custom thumbnail before uploading so the item displays well on the Marketplace.
- [page](https://create.roblox.com/docs/marketplace/publish-to-marketplace) **[[building-art-and-assets]]** Upload accessories as Accessory objects (use Accessory Fitting Tool to convert Models); shoes need LeftShoeAccessory and RightShoeAccessory grouped as a Model.
- [page](https://create.roblox.com/docs/marketplace/publish-to-marketplace) **[[titles-descriptions]]** Follow metadata best practices for title and description to avoid moderation and improve discoverability.
- [page](https://create.roblox.com/docs/marketplace/publish-to-marketplace) **[[ugc-and-avatar-economy]]** Only Limited items can be resold and sold free; Non-Limited items cannot be resold or sold free. Choose availability before publishing.
- [page](https://create.roblox.com/docs/marketplace/publish-to-marketplace) **[[pricing]]** Set price as Amount Above Price Floor (can be 0) plus optional Do Not Price Below floor to guarantee a minimum sale price.
- [page](https://create.roblox.com/docs/marketplace/publish-to-marketplace) **[[updates-live-ops]]** Post-publish updates should only be fixes (fit, cages, small mesh/texture, thumbnail); substantial design changes are not allowed.
- [page](https://create.roblox.com/docs/marketplace/publish-to-marketplace) **[[ugc-and-avatar-economy]]** Copy limits per user can only be increased after publishing, never decreased; set them carefully before publishing.
- [page](https://create.roblox.com/docs/marketplace/publish-to-marketplace) **[[ugc-and-avatar-economy]]** Use Sale Location = Experience By Place ID to restrict an item to a specific game's stock; the game owner must manually enable it after saving the Place ID.
- [page](https://create.roblox.com/docs/marketplace/publish-to-marketplace) **[[events-and-seasonal-content]]** Schedule Limited or Non-Limited sales up to 30 days in advance using Schedule Sale.
- [page](https://create.roblox.com/docs/marketplace/publish-to-marketplace) **[[common-mistakes]]** Avoid using AssetIDs or TextureIDs that belong to others, existing Marketplace assets, or assets pending moderation; these cause validation failures.
- [page](https://create.roblox.com/docs/marketplace/publish-to-marketplace) **[[titles-descriptions]]** Studio's text filter rejects inappropriate strings in name or description; check metadata before submitting.

## Numbers
- [page](https://create.roblox.com/docs/marketplace/publish-to-marketplace) Free Limited publish limit: **50 per day** (Enabling free Limiteds on sale; paid Limiteds have no limit)
- [page](https://create.roblox.com/docs/marketplace/publish-to-marketplace) Max quantity paid Limited: **3000** (Free Limiteds have no quantity maximum)
- [page](https://create.roblox.com/docs/marketplace/publish-to-marketplace) Schedule sale window: **up to 30 days in advance** (Scheduling for Limited and Non-Limited assets)
- [page](https://create.roblox.com/docs/marketplace/publish-to-marketplace) Amount Above Price Floor: **default 0 Robux (required)** (Legacy listings default; example floor 50 + 5 = 55 Robux)
- [page](https://create.roblox.com/docs/marketplace/publish-to-marketplace) Recents view size: **50 most recent items** (Avatar Items Recents view under All tab)
