# Docs: ai / build-with-assistant

[Open](https://create.roblox.com/docs/ai/build-with-assistant.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox official guide to building a first game with Assistant: plan in Plan mode, build a greybox prototype, playtest and iterate with prompts, then refine and polish using generation commands and Studio tools (Lighting, Move/Scale/Rotate, Properties, UI tools). Uses a simple obby as the example.

## Tips
- [page](https://create.roblox.com/docs/ai/build-with-assistant) **[[ai-and-tools]]** Switch Assistant to Plan mode and review the step-by-step plan before building; start with world and core gameplay, add scripts and secondary systems later.
- [page](https://create.roblox.com/docs/ai/build-with-assistant) **[[development-process-and-speed]]** Ask Assistant to simplify scope if the plan is too ambitious; it is much easier to add features later than remove them.
- [page](https://create.roblox.com/docs/ai/build-with-assistant) **[[development-process-and-speed]]** Break work into small steps that each produce something playable, and playtest after each step.
- [page](https://create.roblox.com/docs/ai/build-with-assistant) **[[ai-and-tools]]** If Assistant hits max output length, click Continue so it resumes building where it left off.
- [page](https://create.roblox.com/docs/ai/build-with-assistant) **[[testing-debugging-and-qa]]** Report bugs by stating expected vs actual behaviour, or paste Output window errors to Assistant for diagnosis.
- [page](https://create.roblox.com/docs/ai/build-with-assistant) **[[testing-debugging-and-qa]]** Playtest the game start to finish after every round of changes, since small changes can have unexpected effects.
- [page](https://create.roblox.com/docs/ai/build-with-assistant) **[[development-process-and-speed]]** Tackle one area at a time (gameplay, environment, assets, UI, audio) to make changes easier to evaluate.
- [page](https://create.roblox.com/docs/ai/build-with-assistant) **[[ai-and-tools]]** Mix workflows: generate or modify content with Assistant, then fine-tune positioning, materials, lighting and UI with Studio's built-in tools.
- [page](https://create.roblox.com/docs/ai/build-with-assistant) **[[building-art-and-assets]]** Use /generate_procedural_model for objects you may want to resize later; use /generate_mesh for single fixed textured models.
- [page](https://create.roblox.com/docs/ai/build-with-assistant) **[[building-art-and-assets]]** Tweak Lighting properties in Studio for skybox, atmosphere and lighting; changes apply instantly without re-prompting.
- [page](https://create.roblox.com/docs/ai/build-with-assistant) **[[ui-ux-design]]** Adjust UI layout with drag-and-drop in Studio rather than describing pixel adjustments in prompts.
- [page](https://create.roblox.com/docs/ai/build-with-assistant) **[[core-loops-and-game-design]]** Verify in playtest: spawn room, fair jump gaps, checkpoint respawn updates, kill bricks respawn correctly, win zone triggers.

## Numbers
- [page](https://create.roblox.com/docs/ai/build-with-assistant) Example obby plan size: **6 stages, checkpoints, kill bricks, moving platforms, victory area**
- [page](https://create.roblox.com/docs/ai/build-with-assistant) Example shooter prompt: **Rounds 60 seconds; first to 3 rounds wins match**
