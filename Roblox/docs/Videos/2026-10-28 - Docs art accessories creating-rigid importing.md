# Docs: art / accessories / creating-rigid / importing

[Open](https://create.roblox.com/docs/art/accessories/creating-rigid/importing.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on using Studio's Importer to bring third-party .fbx or .gltf rigid accessories into a project. Covers the import steps, previews and error checks, and fixing textures manually via Asset Manager by uploading an image and setting the MeshPart TextureID.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/importing) **[[building-art-and-assets]]** Use Studio's Importer (Home tab > Import) for .fbx or .gltf files; it previews the asset and error-checks it against Studio's 3D requirements before import.
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/importing) **[[building-art-and-assets]]** Imported assets populate as a Model with MeshParts whose TextureID carries the textures automatically applied during import.
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/importing) **[[building-art-and-assets]]** If textures fail to load, upload the image via Asset Manager, wait for moderation to clear, then paste its asset ID into the MeshPart's TextureID property.
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/importing) **[[development-process-and-speed]]** If the Asset Manager is inaccessible, save and publish the game first, then retry the manual texture upload.

## Tools
Roblox Studio Importer, Asset Manager
