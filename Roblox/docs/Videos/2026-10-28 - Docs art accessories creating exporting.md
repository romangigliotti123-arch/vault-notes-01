# Docs: art / accessories / creating / exporting

[Open](https://create.roblox.com/docs/art/accessories/creating/exporting.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Studio docs page on exporting a Blender model to a Studio-compatible FBX file. Covers outliner cleanup, export settings (Path Mode Copy, Embed Textures, FBX Unit Scale, disable Add Leaf Bones and Bake Animation) and a success checkpoint before importing.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/creating/exporting) **[[3d-modeling-rigging-and-animation]]** Before export, remove extra objects like lights, cameras and mannequins, and apply or remove all active modifiers.
- [page](https://create.roblox.com/docs/art/accessories/creating/exporting) **[[3d-modeling-rigging-and-animation]]** In Blender FBX export, set Path Mode to Copy and enable Embed Textures so the FBX carries its textures.
- [page](https://create.roblox.com/docs/art/accessories/creating/exporting) **[[3d-modeling-rigging-and-animation]]** Set Apply Scalings to FBX Unit Scale in the Transform section to avoid import scaling problems.
- [page](https://create.roblox.com/docs/art/accessories/creating/exporting) **[[3d-modeling-rigging-and-animation]]** Disable Add Leaf Bones in the Armature section when exporting rigged meshes for Studio.
- [page](https://create.roblox.com/docs/art/accessories/creating/exporting) **[[3d-modeling-rigging-and-animation]]** Disable Bake Animation when exporting a static model; enable only Selected Objects in the Include section.
- [page](https://create.roblox.com/docs/art/accessories/creating/exporting) **[[building-art-and-assets]]** Unhide all objects and make them selectable in the Outliner, then select everything, before exporting so nothing is skipped.
