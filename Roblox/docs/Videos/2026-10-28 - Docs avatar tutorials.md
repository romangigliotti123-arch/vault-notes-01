# Docs: avatar / tutorials

[Open](https://create.roblox.com/docs/avatar/tutorials.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs index for avatar asset tutorials using Blender and Studio. Covers three creation paths: rigid accessories, clothing (mannequin-based, caged), and full bodies (template-based). Lists the steps for each, from modeling and texturing through import, fitting, caging, export and publishing to the Marketplace.

## Tips
- [page](https://create.roblox.com/docs/avatar/tutorials) **[[building-art-and-assets]]** Use Blender 3.0+ for Roblox avatar asset tutorials; the official tutorial content targets that version.
- [page](https://create.roblox.com/docs/avatar/tutorials) **[[ugc-and-avatar-economy]]** Start avatar asset creation with a Roblox-provided project template or mannequin so meshes fit the avatar correctly.
- [page](https://create.roblox.com/docs/avatar/tutorials) **[[3d-modeling-rigging-and-animation]]** For clothing, rig and cage the mesh so it layers and deforms with the avatar body instead of being a static mesh.
- [page](https://create.roblox.com/docs/avatar/tutorials) **[[ugc-and-avatar-economy]]** Follow the publish path: model, texture, import to Studio, fit and convert, then publish to sell on the Marketplace.
- [page](https://create.roblox.com/docs/avatar/tutorials) **[[3d-modeling-rigging-and-animation]]** For bodies, pick a provided avatar template with pre-baked components, then model, texture, cage, clean up and export.
