## Summary
Roblox Creator Docs lesson defining algorithms and the three methods used to express them in code: selection (if/then), sequencing (ordered steps), and iteration (loops). Shows how to break an algorithm into smaller called algorithms, using a getDressed example. Includes an offline stick-figure classroom exercise.

## Tips
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-6/coding-concept-algorithms) **[[core-loops-and-game-design]]** Break large game logic into smaller functions that call each other, e.g. a main function calling pickClothes() and putOnClothes(), to keep systems manageable.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-6/coding-concept-algorithms) **[[scripting-and-performance]]** Use selection (if/then) for conditional outcomes, such as checking skill level before allowing item use.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-6/coding-concept-algorithms) **[[scripting-and-performance]]** Use iteration (loops with task.wait) for timed effects, such as lava dealing 5 health per second until respawn at 0.

## Numbers
