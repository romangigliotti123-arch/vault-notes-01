# Docs: education / edu-templates / edu-lesson-plan-template

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/education/edu-templates/edu-lesson-plan-template.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Education lesson plan template: a structure for teaching students to build an obstacle course and code color-changing blocks in Roblox Studio. Defines lesson title, objectives (max four, verb-first), concepts (max four, bolded terms with periods), materials/prep, timed plan (intro, guided tutorial, wrap-up), and appendix sections.

## Tips
- [page](https://create.roblox.com/docs/education/edu-templates/edu-lesson-plan-template) **[[development-process-and-speed]]** Limit lesson objectives to a maximum of four, each starting with a verb.
- [page](https://create.roblox.com/docs/education/edu-templates/edu-lesson-plan-template) **[[development-process-and-speed]]** Limit skills and concepts to a maximum of four, each as a bolded term with a brief description ending in a period.
- [page](https://create.roblox.com/docs/education/edu-templates/edu-lesson-plan-template) **[[development-process-and-speed]]** Avoid Roblox-unique concepts (e.g. starter packs) in concept lists; use general game design terms instead.
- [page](https://create.roblox.com/docs/education/edu-templates/edu-lesson-plan-template) **[[development-process-and-speed]]** Include links to all handouts, slides, and videos in the materials list.
