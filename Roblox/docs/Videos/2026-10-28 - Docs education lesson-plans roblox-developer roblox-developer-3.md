# Docs: education / lesson-plans / roblox-developer / roblox-developer-3

[Open](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-3.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Education lesson plan (part 1 of an adventure game unit). Covers pre-production with a paper vision document, building a starting area with terrain tools (6-minute limit), and scripting a leaderstats leaderboard to track player items. Also lists troubleshooting and classroom management notes.

## Tips
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-3) **[[development-process-and-speed]]** Keep the first area scoped to what can be built in about a week, such as a house with a lawn or a simple forest, then expand later.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-3) **[[development-process-and-speed]]** Sketch the map with simple shapes like circles and squares before opening Studio; detailed drawings aren't needed for pre-production.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-3) **[[building-and-level-design]]** Show each terrain tool once, then give a strict time box (at most six minutes) for the starting area to avoid over-building early.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-3) **[[building-art-and-assets]]** Build with parts rather than Toolbox models, since Toolbox assets may introduce unexpected issues into the game.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-3) **[[scripting-and-performance]]** The leaderstats folder name must be exactly "leaderstats", otherwise the script won't create the leaderboard.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-3) **[[development-process-and-speed]]** Keep a reference sheet of variable names (e.g. Gold or Rubies) so renamed stats stay consistent across scripts.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-3) **[[combat-and-gameplay-systems]]** Mark each collectible with a BoolValue named CanHarvest set to true, and keep every item in the same Explorer structure.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-3) **[[mindset-and-strategy]]** When goals grow too big, write extra ideas in the design document and focus on the current session's goal.

## Numbers
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-3) Session length: **5 min intro, 10 min planning, 10 min world, 30 min setup, 5 min wrap-up** (Lesson overview timing for the first session)
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-3) Terrain build time limit: **6 minutes** (Maximum time to create the starting area per terrain tool demo)
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-3) Project timeline: **Three sessions** (Time to build the full adventure game project)
