# Docs: education / resources / classroom-best-practices

[Open](https://create.roblox.com/docs/education/resources/classroom-best-practices.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on classroom best practices for educators: preparing lessons by playing learning games, setting student guidelines, managing transitions with I Do/We Do/You Do, peer-help systems, and keeping students focused on Studio tasks.

## Tips
- [page](https://create.roblox.com/docs/education/resources/classroom-best-practices) **[[first-session-onboarding]]** Before class, play a learning game or go through the project steps yourself so you know the flow students will hit.
- [page](https://create.roblox.com/docs/education/resources/classroom-best-practices) **[[community-and-discord]]** Create classroom guidelines with students up-front and invite their additions; state consequences for breaking them.
- [page](https://create.roblox.com/docs/education/resources/classroom-best-practices) **[[common-mistakes]]** Address off-topic questions (favourite game, free Robux) at the start of class by stating that only project-related questions will be answered.
- [page](https://create.roblox.com/docs/education/resources/classroom-best-practices) **[[development-process-and-speed]]** Use an I Do / We Do / You Do structure with visual cues (e.g. coloured flags) to signal when devices should be used.
- [page](https://create.roblox.com/docs/education/resources/classroom-best-practices) **[[community-and-discord]]** Use an 'Ask Three Before Me' rule so students check with three peers before asking the instructor.
- [page](https://create.roblox.com/docs/education/resources/classroom-best-practices) **[[community-and-discord]]** Nominate 3-5 student helpers at the start of class and rotate them so others get leadership chances.
- [page](https://create.roblox.com/docs/education/resources/classroom-best-practices) **[[development-process-and-speed]]** Add short relaxed warm-up tasks (e.g. a few minutes of Terrain Tools) near the end of long coding sessions to keep motivation up.

## Numbers
- [page](https://create.roblox.com/docs/education/resources/classroom-best-practices) Helper students nominated at class start: **3-5**
- [page](https://create.roblox.com/docs/education/resources/classroom-best-practices) Peers students ask before an adult: **3**
