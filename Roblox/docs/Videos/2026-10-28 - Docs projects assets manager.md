# Docs: projects / assets / manager

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/projects/assets/manager.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Creator Docs page on the Asset Manager: inventory sorting, folder limits and operations, display and filter options, asset import, quick actions, and the search query language. Reference material, not a how-to for building a game.

## Tips
- [page](https://create.roblox.com/docs/projects/assets/manager) **[[development-process-and-speed]]** Organize assets into folders early; folders hold up to 20,000 assets each and nest up to 20 levels deep.
- [page](https://create.roblox.com/docs/projects/assets/manager) **[[common-mistakes]]** Folders must be empty before deletion; move or delete contents first or the delete action fails.
- [page](https://create.roblox.com/docs/projects/assets/manager) **[[development-process-and-speed]]** Use Copy Asset ID to paste IDs directly into AudioPlayer.AssetId or MeshPart.MeshId properties instead of retyping them.
- [page](https://create.roblox.com/docs/projects/assets/manager) **[[development-process-and-speed]]** Use the search query language: quotes for exact phrases, -term to exclude, term? to boost, and asset_id to pin specific assets.

## Numbers
- [page](https://create.roblox.com/docs/projects/assets/manager) Max folders per account or root inventory: **50,000**
- [page](https://create.roblox.com/docs/projects/assets/manager) Max child folders per folder or root inventory: **100**
- [page](https://create.roblox.com/docs/projects/assets/manager) Max assets per folder: **20,000**
- [page](https://create.roblox.com/docs/projects/assets/manager) Max folder nesting levels: **20**
