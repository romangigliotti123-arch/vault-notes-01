# Docs: education / support / private-servers-for-classroom-use

[Open](https://create.roblox.com/docs/education/support/private-servers-for-classroom-use.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox education docs on using private servers for classroom use. Explains how to check whether a game offers private servers, set one up, invite students via link or username, name servers per group, and use Learn & Explore and Play Together sorts to find classroom-friendly games. Covers reporting tools and safety guidance before online play.

## Tips
- [page](https://create.roblox.com/docs/education/support/private-servers-for-classroom-use) **[[matchmaking-and-teleport]]** Check for a Private Servers section beneath the game description; a 'Create Private Server' button means the game offers them.
- [page](https://create.roblox.com/docs/education/support/private-servers-for-classroom-use) **[[matchmaking-and-teleport]]** Invite students by sharing the generated link (PC/Mac) or adding their Roblox usernames via Configure. Mobile players must be invited directly, not by link.
- [page](https://create.roblox.com/docs/education/support/private-servers-for-classroom-use) **[[matchmaking-and-teleport]]** Rename private servers (e.g. school-period names) to organize separate student groups.
- [page](https://create.roblox.com/docs/education/support/private-servers-for-classroom-use) **[[matchmaking-and-teleport]]** Student creators can enable private servers so only class members can play their game.
- [page](https://create.roblox.com/docs/education/support/private-servers-for-classroom-use) **[[age-ratings-moderation-and-tos]]** Teach students to use in-game reporting tools before starting online play, and how to react to bullies and angry players.
