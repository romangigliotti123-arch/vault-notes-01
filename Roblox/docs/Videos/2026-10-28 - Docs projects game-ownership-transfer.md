# Docs: projects / game-ownership-transfer

[Open](https://create.roblox.com/docs/projects/game-ownership-transfer.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox docs on game ownership transfer: how to transfer a game to a group you publish to, how to receive one, prerequisites (verified email, moving private ModuleScripts/InsertService assets, package ownership), API key implications, and FAQ on IDs, expiry, cooldowns, credit cards, private server revenue, and discovery impact.

## Tips
- [page](https://create.roblox.com/docs/projects/game-ownership-transfer) **[[team-and-budget]]** Before transferring, verify your email and move private ModuleScripts and InsertService assets to the target group; user-owned packages may need recreating or replacing with group-owned ones.
- [page](https://create.roblox.com/docs/projects/game-ownership-transfer) **[[anti-exploit-and-security]]** Check Open Cloud API keys before transferring. Keys use the access of the user who last generated them; if the transfer changes that user's access, create new keys under an account with the right access.
- [page](https://create.roblox.com/docs/projects/game-ownership-transfer) **[[business-and-payouts]]** Transferring to a group unlocks group permissions and revenue management, which helps manage content as the team scales.
- [page](https://create.roblox.com/docs/projects/game-ownership-transfer) **[[updates-live-ops]]** After the new group accepts, set up any needed permissions and release the game to the public again, or it stays hidden.
- [page](https://create.roblox.com/docs/projects/game-ownership-transfer) **[[titles-descriptions]]** Keep the game title unchanged during transfer to avoid search impact.
- [page](https://create.roblox.com/docs/projects/game-ownership-transfer) **[[discovery-algorithm]]** Transfers can affect discovery for up to 24 hours after the new owner releases the game; keep the title the same and avoid moderated receiving accounts.
- [page](https://create.roblox.com/docs/projects/game-ownership-transfer) **[[business-and-payouts]]** Private server subscription revenue from before the transfer goes to the receiving group without revenue splits; new subscriptions respect splits.
- [page](https://create.roblox.com/docs/projects/game-ownership-transfer) **[[common-mistakes]]** Changes made during an active transfer are not carried over; finish or cancel before editing, and note transfer requests expire after 7 days.
- [page](https://create.roblox.com/docs/projects/game-ownership-transfer) **[[common-mistakes]]** Credit card information is removed on transfer, so the new owner must set up payment details.
- [page](https://create.roblox.com/docs/projects/game-ownership-transfer) **[[business-and-payouts]]** After receiving a game, wait 30 days before transferring it again.

## Numbers
- [page](https://create.roblox.com/docs/projects/game-ownership-transfer) Transfer request expiry: **7 days** (Pending transfer requests expire after this period)
- [page](https://create.roblox.com/docs/projects/game-ownership-transfer) Re-transfer cooldown: **30 days** (Wait after receiving a transferred game before transferring again)
- [page](https://create.roblox.com/docs/projects/game-ownership-transfer) Discovery impact window: **up to 24 hours** (After new owner re-releases the game, if title changed or owner moderated)

Roblox Creator Dashboard (Creations, Publish Settings), Open Cloud API keys
