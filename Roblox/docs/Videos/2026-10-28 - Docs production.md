# Docs: production

[Open](https://create.roblox.com/docs/production.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox docs overview of the production phase: publishing (private by default vs public), monetization via Developer Products and Passes priced in Robux, Developer Exchange cash-out, localization via the Localization page, promotion via Ads Manager, experience events and notifications, and analytics for growth and retention.

## Tips
- [page](https://create.roblox.com/docs/production) **[[development-process-and-speed]]** Keep a game private while testing; it saves to the cloud but is not discoverable until you publish publicly.
- [page](https://create.roblox.com/docs/production) **[[monetisation-devproducts]]** Use Developer Products for repeatable purchases such as in-game currency, since users can buy them multiple times.
- [page](https://create.roblox.com/docs/production) **[[monetisation-gamepasses]]** Use Passes for one-time purchases such as VIP access or permanent power-ups, since users can only buy them once.
- [page](https://create.roblox.com/docs/production) **[[business-and-payouts]]** Convert earned Robux to real-world currency through the Developer Exchange (DevEx).
- [page](https://create.roblox.com/docs/production) **[[ads-and-sponsored-experiences]]** Use Ads Manager image, video, or portal ads to promote a game inside existing experiences.
- [page](https://create.roblox.com/docs/production) **[[updates-live-ops]]** Use time-based experience events and update announcements to re-engage your existing player base.
- [page](https://create.roblox.com/docs/production) **[[development-process-and-speed]]** Localize early: Roblox auto-captures game text into a table on the Localization page for translation.

## Tools
Ads Manager, Localization page, Developer Exchange, Analytics
