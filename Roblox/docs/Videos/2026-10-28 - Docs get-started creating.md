# Docs: get-started / creating

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/get-started/creating.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox getting-started docs page for creators. Outlines steps to start: learn overview, create account, play games and customize avatar, install Studio and take tour. Points to tutorials: "Create your first game" 3D platformer, world building and physics livestreams, and avatar item guides for t-shirts and backpack accessories.

## Tips
- [page](https://create.roblox.com/docs/get-started/creating) **[[development-process-and-speed]]** Start creating in under an hour: sign up, play a few games, install Studio, take the onboarding tour, then build the 'Create your first game' 3D platformer tutorial.
- [page](https://create.roblox.com/docs/get-started/creating) **[[building-art-and-assets]]** For avatar items, a simple 2D t-shirt can be made in an image editor without opening Studio; use Blender plus Studio for basic 3D accessories.
- [page](https://create.roblox.com/docs/get-started/creating) **[[building-art-and-assets]]** 3D accessories should be simple, non-animated items that attach to a single point on the avatar's body.
- [page](https://create.roblox.com/docs/get-started/creating) **[[common-mistakes]]** Don't assume game-making is too hard; the docs frame it as approachable, with tutorials walking through building and scripting basics.

## Numbers
