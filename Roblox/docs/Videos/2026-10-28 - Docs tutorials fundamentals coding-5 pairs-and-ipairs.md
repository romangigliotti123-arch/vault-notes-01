## Summary
Roblox Creator Docs tutorial on Luau pairs() and ipairs() loops. Covers iterating dictionaries with pairs(), arrays with ipairs(), and a restaurant soup practice script that builds an ingredient array from a dictionary of true/false flags, with optional challenges.

## Tips
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-5/pairs-and-ipairs) **[[luau-language-and-types]]** Use pairs() to iterate dictionaries (string keys, unknown size) and ipairs() to iterate arrays in ordered index sequence.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-5/pairs-and-ipairs) **[[common-mistakes]]** Dictionary iteration order with pairs() is not guaranteed; use an array with ipairs() when order matters, such as leaderboards.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-5/pairs-and-ipairs) **[[scripting-and-performance]]** Guard for empty results before using collected data, e.g. check #array > 0 and handle the else case to avoid runtime errors.
