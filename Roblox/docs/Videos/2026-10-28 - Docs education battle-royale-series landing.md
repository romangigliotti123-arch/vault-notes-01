## Summary
Official Roblox Education docs series outlining how to build a round-based battle royale game in Luau. Covers project setup, module-script game loop, managing player arrays, teleporting, events for match states, GUI, ending matches, cleanup/reset, and finishing with assets and challenges.

## Tips
- [page](https://create.roblox.com/docs/education/battle-royale-series/landing) **[[core-loops-and-game-design]]** Build a round-based game loop that runs in the background and drives match states; separate concerns into modules (game loop, player management, timers).
- [page](https://create.roblox.com/docs/education/battle-royale-series/landing) **[[code-architecture-and-frameworks]]** Use modular programming: separate scripts handle distinct functions such as teleporting players or running match timers.
- [page](https://create.roblox.com/docs/education/battle-royale-series/landing) **[[code-architecture-and-frameworks]]** Use events to signal state changes (match start, match end, timer end) so separate scripts react to cause and effect without tight coupling.
- [page](https://create.roblox.com/docs/education/battle-royale-series/landing) **[[core-loops-and-game-design]]** Track players in arrays and update them as players start, win, or leave matches.
