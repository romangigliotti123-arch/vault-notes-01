# Docs: studio / terrain-editor

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/studio/terrain-editor.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox Studio documentation for the Terrain Editor. Covers the Create tab (Import, Generate, Clear) and Edit tab (Select, Transform, Fill, Sea Level, Draw, Sculpt, Smooth, Paint, Flatten), with their settings and keyboard/mouse shortcuts for brush-based tools.

## Tips
- [page](https://create.roblox.com/docs/studio/terrain-editor) **[[building-art-and-assets]]** Use Generate to create a large base terrain map quickly, then fine-tune details with Edit tab tools.
- [page](https://create.roblox.com/docs/studio/terrain-editor) **[[building-art-and-assets]]** Use Select with Snap to Voxels enabled to keep terrain selection bounds aligned to the voxel grid.
- [page](https://create.roblox.com/docs/studio/terrain-editor) **[[building-art-and-assets]]** Disable Live Edit in Transform and press Enter/Return or Apply to preview a wireframe before committing a large terrain transform.
- [page](https://create.roblox.com/docs/studio/terrain-editor) **[[building-art-and-assets]]** Check the rotation snapping setting in the toolbar before rotating terrain with rotate rings; disable it for free-form rotation.

## Numbers
- [page](https://create.roblox.com/docs/studio/terrain-editor) Brush size range: **1 to 64 (Draw, Sculpt, Smooth, Paint, Flatten)**
- [page](https://create.roblox.com/docs/studio/terrain-editor) Brush strength range: **0.1 to 1 (Sculpt, Smooth, Flatten)**
- [page](https://create.roblox.com/docs/studio/terrain-editor) Custom terrain materials: **up to 62 custom materials can be painted onto terrain**
