# Docs: production / localization

[Open](https://create.roblox.com/docs/production/localization.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox official docs on localization: automatic translation (on by default for any game, players can toggle Automatic Translations), source and supported language setup via Creator Dashboard, manual translation tables, translator collaborators, and monthly translation analytics.

## Tips
- [page](https://create.roblox.com/docs/production/localization) **[[monetisation-other]]** Enable automatic translations on any game immediately; it expands audience with no setup beyond choosing languages, and shows progress before manual work.
- [page](https://create.roblox.com/docs/production/localization) **[[development-process-and-speed]]** Set the source language first (defaults to account language, one at a time) and then add supported languages before starting localization.
- [page](https://create.roblox.com/docs/production/localization) **[[building-art-and-assets]]** Set AutoLocalize to false on GuiBase2d objects that should never be translated, such as NPC names or street signs.
- [page](https://create.roblox.com/docs/production/localization) **[[common-mistakes]]** Manual translations always display to players, while automatic translations only fill in strings that are missing, so review manual entries carefully.
- [page](https://create.roblox.com/docs/production/localization) **[[community-and-discord]]** Add Roblox users as translators to review and polish automatic translations or supply manual ones.
- [page](https://create.roblox.com/docs/production/localization) **[[analytics-metrics]]** Download monthly translation analytics to track translation coverage and translator contributions.
- [page](https://create.roblox.com/docs/production/localization) **[[building-art-and-assets]]** Use the translation table programmatically to show language-specific images or assets, or contextual translations.

## Tools
Creator Dashboard localization settings, Automatic Translations user setting, Translation table (manual translations), Translator collaborators, Monthly translation analytics download
