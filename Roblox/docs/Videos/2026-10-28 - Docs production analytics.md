# Docs: production / analytics

[Open](https://create.roblox.com/docs/production/analytics.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox official docs on Analytics: a 3-step growth plan (optimize D1/session time, D7/D30 retention, payer conversion/ARPPU before acquisition; then acquisition via Acquisition page; then monitor metrics after each update). Covers Analytics Home watchlists, avatar sales tracking, share-link visits, and in-game GetPlayerSegmentsAsync for segment-based onboarding and offers.

## Tips
- [page](https://create.roblox.com/docs/production/analytics) **[[analytics-metrics]]** Before driving many new users, get D1 retention and average session time to benchmark level or above similar games.
- [page](https://create.roblox.com/docs/production/analytics) **[[retention-d1-d7]]** Grow D7 and D30 retention to benchmark levels to confirm users make progress and return long-term.
- [page](https://create.roblox.com/docs/production/analytics) **[[monetisation-other]]** Be thoughtful about monetization from the start; track payer conversion rate and ARPPU against benchmarks.
- [page](https://create.roblox.com/docs/production/analytics) **[[thumbnails-icons]]** Test different game icons, titles and descriptions and watch play-through rate from home recommendations.
- [page](https://create.roblox.com/docs/production/analytics) **[[social-features-and-virality]]** Use experience events and player invite prompts to get users to bring friends into the game.
- [page](https://create.roblox.com/docs/production/analytics) **[[updates-live-ops]]** After each update, check D1/D7 retention, average session time, payer conversion, ARPPU, revenue, new users and play-through rate.
- [page](https://create.roblox.com/docs/production/analytics) **[[analytics-metrics]]** Use benchmark scorecards (available at 100+ DAU) to find the weakest metric versus similar games, then use funnel analytics on onboarding.
- [page](https://create.roblox.com/docs/production/analytics) **[[discovery-algorithm]]** Benchmarks are not a direct discovery-algorithm signal; use them only as a comparison point for improving engagement, monetization and acquisition.
- [page](https://create.roblox.com/docs/production/analytics) **[[first-session-onboarding]]** Use GetPlayerSegmentsAsync to give players in their first 30 days extra tutorials, tooltips and simplified content.
- [page](https://create.roblox.com/docs/production/analytics) **[[monetisation-devproducts]]** Use GetPlayerSegmentsAsync to show low-cost items to non-spenders and bundles or upgrades to players with purchase history.

## Numbers
- [page](https://create.roblox.com/docs/production/analytics) Watchlist size: **up to 9 games** (Analytics Home watchlist limit per account)
- [page](https://create.roblox.com/docs/production/analytics) Benchmark scorecard threshold: **100+ DAU** (Minimum DAU to use similar-game benchmark scorecards)
- [page](https://create.roblox.com/docs/production/analytics) Top items on time-series graph: **up to 8** (Avatar Items sales/revenue showcase limit)
- [page](https://create.roblox.com/docs/production/analytics) Avatar catalog table: **up to 200 items** (Filterable, sortable avatar item table)
- [page](https://create.roblox.com/docs/production/analytics) New player window: **first 30 days** (Account-age segment for extra tutorials and simplified content)
