# Docs: studio / overview

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/studio/overview.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Studio interface docs: toolbar/mezzanine tabs (Home, Model, Avatar, UI, Script, Plugins), appearance options, custom tabs via Studio or local JSON files, 3D viewport camera and selection controls, frequently used windows (Explorer, Properties, Asset Manager, Toolbox, Output, Command Bar), and window layout customization.

## Tips
- [page](https://create.roblox.com/docs/studio/overview) **[[ai-and-tools]]** Duplicate a default tab before editing it; default tabs can't be modified directly, but duplicated tabs can be freely changed.
- [page](https://create.roblox.com/docs/studio/overview) **[[version-control-and-tooling]]** Share custom tab layouts with your team by sharing their .json files from the local CustomRibbonTabs folder, then use Reload custom tabs.
- [page](https://create.roblox.com/docs/studio/overview) **[[building-and-level-design]]** Hold Alt (or ⌥) and click to cycle selection to the next object behind the current one instead of moving the camera.
- [page](https://create.roblox.com/docs/studio/overview) **[[building-and-level-design]]** Press F to focus the camera on a selected part; use , and . to orbit around the focused object.

## Numbers
- [page](https://create.roblox.com/docs/studio/overview) Command Bar history: **last 10 executed commands** (Recent tab in Command Bar history popup)
- [page](https://create.roblox.com/docs/studio/overview) Command Bar size: **starts at 2 lines, grows to 10 lines** (Multiline editing, when Multi-line Command Bar beta enabled)
- [page](https://create.roblox.com/docs/studio/overview) Camera controls: **WASD/QE move; Shift changes speed** (3D viewport navigation keys)

## Tools
Roblox Studio, Command Bar, Explorer, Properties window
