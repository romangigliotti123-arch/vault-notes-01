## Summary
Official Roblox docs page on setting up Roblox Studio: system requirements, installation steps, customization options, update behaviour, and enabling beta features.

## Tips
- [page](https://create.roblox.com/docs/studio/setup) **[[development-process-and-speed]]** Keep Studio up to date: every game runs on the latest engine version, so outdated Studio lacks the newest APIs and features.
- [page](https://create.roblox.com/docs/studio/setup) **[[development-process-and-speed]]** Use Studio Settings search (Alt+S on Windows, ⌥+S on Mac) to find settings by keyword, e.g. 'theme'.
- [page](https://create.roblox.com/docs/studio/setup) **[[development-process-and-speed]]** Customize toolbar tabs and shortcuts via File > Customize Shortcuts to streamline your workflow.

## Numbers
- [page](https://create.roblox.com/docs/studio/setup) Minimum RAM: **3 GB** (Studio minimum memory requirement)
- [page](https://create.roblox.com/docs/studio/setup) Recommended RAM: **8 GB** (Studio recommended memory requirement)
- [page](https://create.roblox.com/docs/studio/setup) Recommended resolution: **1600×900 or higher** (Studio recommended display resolution)
- [page](https://create.roblox.com/docs/studio/setup) Minimum OS: **Windows 10 / macOS 10.14** (Studio minimum operating system versions)
