## Summary
Roblox Education docs page on playtesting a city-building map in Studio: Play from lobby, wait out the 5-second intermission, check for floating buildings, test destruction with E, and stop the playtest to keep changes.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/playtest-the-map) **[[building-and-level-design]]** Playtest maps via Studio's Play button so you see them as players will; check for floating buildings that need fixing.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/playtest-the-map) **[[playtesting-and-feedback]]** Run through the full in-game flow (lobby, intermission, map) before calling a build done, to catch bugs and unfun moments.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/playtest-the-map) **[[common-mistakes]]** Always click Stop to end a playtest; if you don't, any changes made during the playtest are lost.

## Numbers
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/playtest-the-map) Intermission before map load: **5 seconds**
