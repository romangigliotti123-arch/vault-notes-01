# Docs: education / lesson-plans / intro-to-game-and-coding

[Open](https://create.roblox.com/docs/education/lesson-plans/intro-to-game-and-coding.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Classroom lesson plan teaching students (ages ~middle school) to build an obstacle course in Roblox Studio and code color-changing parts using variables, strings and loops. Includes timed agenda, learning goals, troubleshooting tips and expansion via student playtesting.

## Tips
- [page](https://create.roblox.com/docs/education/lesson-plans/intro-to-game-and-coding) **[[first-session-onboarding]]** Allot about 5 minutes for first-time Roblox login so students with account issues don't stall the class.
- [page](https://create.roblox.com/docs/education/lesson-plans/intro-to-game-and-coding) **[[playtesting-and-feedback]]** Have students playtest each other's games and give feedback as 2 Stars (what they liked) and a Wish (what they'd want to see).
- [page](https://create.roblox.com/docs/education/lesson-plans/intro-to-game-and-coding) **[[playtesting-and-feedback]]** Set strict time limits for tasks, e.g. 1 minute to pick a part color, 2 minutes to playtest, to keep sessions on track.
- [page](https://create.roblox.com/docs/education/lesson-plans/intro-to-game-and-coding) **[[development-process-and-speed]]** Separate phases: build first, then code, then polish/playtest, so students don't switch tasks mid-coding.
- [page](https://create.roblox.com/docs/education/lesson-plans/intro-to-game-and-coding) **[[core-loops-and-game-design]]** Design goals for a playable level: reachable end at reasonable difficulty, balance of easy and hard jumps, free of visual or code bugs.
- [page](https://create.roblox.com/docs/education/lesson-plans/intro-to-game-and-coding) **[[common-mistakes]]** Most common beginner Luau errors are improper capitalization and typos; check these first when debugging.
- [page](https://create.roblox.com/docs/education/lesson-plans/intro-to-game-and-coding) **[[testing-debugging-and-qa]]** Ask guiding questions instead of giving answers so learners build troubleshooting skills, e.g. 'What symbols go around a string?'
- [page](https://create.roblox.com/docs/education/lesson-plans/intro-to-game-and-coding) **[[testing-debugging-and-qa]]** Use an 'Ask 3 Before Me' rule: ask three peers before asking the instructor for help.
- [page](https://create.roblox.com/docs/education/lesson-plans/intro-to-game-and-coding) **[[building-and-level-design]]** Remind builders to rotate the camera and use the Explorer to get an accurate view of the project.
- [page](https://create.roblox.com/docs/education/lesson-plans/intro-to-game-and-coding) **[[building-and-level-design]]** Emphasize the game is for other players, not just the creator, to shape build decisions.

## Numbers
- [page](https://create.roblox.com/docs/education/lesson-plans/intro-to-game-and-coding) Login setup time: **5 minutes allotted** (Recommended for first-time students logging into Roblox Studio)
- [page](https://create.roblox.com/docs/education/lesson-plans/intro-to-game-and-coding) Lesson agenda total: **120 minutes** (5 intro, 30 Studio tutorial, 60 coding, 20 independent work, 5 wrap-up)
- [page](https://create.roblox.com/docs/education/lesson-plans/intro-to-game-and-coding) Peer playtest time: **2 minutes** (Suggested strict time for student playtesting)
- [page](https://create.roblox.com/docs/education/lesson-plans/intro-to-game-and-coding) Roblox monthly users: **over 60 million** (Cited in example course description for workshop promotion)
