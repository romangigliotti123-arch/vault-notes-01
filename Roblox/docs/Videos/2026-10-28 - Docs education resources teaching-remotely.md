## Summary
Roblox docs page on teaching remotely with Roblox Studio. Covers remote-learning tools (training, interaction, Collaboration, private servers), lesson plans, educational games, and tips on setting expectations and login prep, plus recommended external resources and Roblox Education support.

## Tips
- [page](https://create.roblox.com/docs/education/resources/teaching-remotely) **[[community-and-discord]]** Set collaboration expectations with students before a build session, e.g. 'Don't change someone's work without permission'; co-creating rules increases buy-in.
- [page](https://create.roblox.com/docs/education/resources/teaching-remotely) **[[first-session-onboarding]]** Allow 3-5 minutes for students to log in when planning remote class start times.
- [page](https://create.roblox.com/docs/education/resources/teaching-remotely) **[[community-and-discord]]** Have students track their own Roblox usernames and passwords using a system you set up.
- [page](https://create.roblox.com/docs/education/resources/teaching-remotely) **[[matchmaking-and-teleport]]** Use private servers to set up servers for classes or individual students.

## Numbers
- [page](https://create.roblox.com/docs/education/resources/teaching-remotely) Student login time: **3-5 minutes** (Recommended allowance for students to log in in a remote classroom)
