# Docs: production / game-design / prototyping

[Open](https://create.roblox.com/docs/production/game-design/prototyping.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox official docs on prototyping: compares paper prototyping (fast iteration, broad system exploration, UI/UX design; not reusable, simulation limits, false positives) with Studio prototyping (rapid playtesting, reusable work, early technical issue detection; smaller test scope, slower iteration). Gives scope and focus guidance.

## Tips
- [page](https://create.roblox.com/docs/production/game-design/prototyping) **[[development-process-and-speed]]** Keep prototypes fast and narrow: hit the key aspects of a feature being tested, not the entire feature. Scope is what separates prototyping from building.
- [page](https://create.roblox.com/docs/production/game-design/prototyping) **[[playtesting-and-feedback]]** Run several playtest sessions with your team to confirm findings, then share the prototype with friends, family and social media for fresh feedback.
- [page](https://create.roblox.com/docs/production/game-design/prototyping) **[[development-process-and-speed]]** Use paper prototyping for early exploration; it takes minutes to start versus days or weeks for a virtual environment.
- [page](https://create.roblox.com/docs/production/game-design/prototyping) **[[development-process-and-speed]]** Prototype in Studio once ideas are settled to catch technical infeasibility early, since paper ideas can be impossible to implement.
- [page](https://create.roblox.com/docs/production/game-design/prototyping) **[[building-art-and-assets]]** Prototype UI/UX early, especially menu interaction and input controls, since paper is well suited to exploring UI layouts.
- [page](https://create.roblox.com/docs/production/game-design/prototyping) **[[core-loops-and-game-design]]** Prioritise prototyping the core loop, the central gameplay the whole game is built on.
- [page](https://create.roblox.com/docs/production/game-design/prototyping) **[[core-loops-and-game-design]]** Work out game rules in detail, e.g. respawn timer length, respawn location, and factors that change how fast players rejoin the action.
- [page](https://create.roblox.com/docs/production/game-design/prototyping) **[[common-mistakes]]** Test edge cases where players push the limits of the game, and design prevention or stop-gap solutions, or deliberately encourage the behaviour.
- [page](https://create.roblox.com/docs/production/game-design/prototyping) **[[common-mistakes]]** Do not trust paper prototypes for fun alone: some activities feel more engaging with physical assets than on screen (false positives).
