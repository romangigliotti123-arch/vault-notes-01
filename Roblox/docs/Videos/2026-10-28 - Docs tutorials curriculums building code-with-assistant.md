# Docs: tutorials / curriculums / building / code-with-assistant

[Open](https://create.roblox.com/docs/tutorials/curriculums/building/code-with-assistant.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on Assistant, Roblox's in-Studio AI helper. Shows how to open it, write specific prompts to add scripts that change part behavior (example: sparkles on touch), vary results by wording, undo accepted changes, and playtest and rate the output.

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/building/code-with-assistant) **[[ai-and-tools]]** Open Assistant inside Studio rather than the web version so it can reference your game's objects and scripts.
- [page](https://create.roblox.com/docs/tutorials/curriculums/building/code-with-assistant) **[[ai-and-tools]]** Rename parts (e.g. GlitterPart) before prompting so Assistant knows which part to script.
- [page](https://create.roblox.com/docs/tutorials/curriculums/building/code-with-assistant) **[[ai-and-tools]]** Include specific details in prompts (color, trigger, timing); fewer details produce more unpredictable results.
- [page](https://create.roblox.com/docs/tutorials/curriculums/building/code-with-assistant) **[[ai-and-tools]]** Word choice matters: small rephrasings can yield a new script, code in an existing script, or just a ParticleEmitter.
- [page](https://create.roblox.com/docs/tutorials/curriculums/building/code-with-assistant) **[[ai-and-tools]]** If results are wrong, rephrase the request and try again rather than editing blindly.
- [page](https://create.roblox.com/docs/tutorials/curriculums/building/code-with-assistant) **[[ai-and-tools]]** Undo unwanted changes with Ctrl+Z for non-script changes, or delete the generated script in Explorer.
- [page](https://create.roblox.com/docs/tutorials/curriculums/building/code-with-assistant) **[[testing-debugging-and-qa]]** Always playtest Assistant-generated code in Studio before keeping it, since its output may not work as intended.
- [page](https://create.roblox.com/docs/tutorials/curriculums/building/code-with-assistant) **[[ai-and-tools]]** Learn basic Luau before accepting code, so you can review Assistant's samples for your use case.

## Numbers
- [page](https://create.roblox.com/docs/tutorials/curriculums/building/code-with-assistant) Example prompt delay: **3 seconds** (Example behavior: platform moves up, waits 3 seconds, returns)
