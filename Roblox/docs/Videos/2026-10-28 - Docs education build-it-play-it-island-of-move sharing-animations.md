# Docs: education / build-it-play-it-island-of-move / sharing-animations

## Summary
Roblox Creator Docs page on exporting and importing animations via .RBXM files. Covers saving animations to AnimSaves folder, Save to File, Insert From File, loading in Animation Editor, and troubleshooting KeyframeSequence vs Keyframe imports. Notes animation sharing without re-uploading under updated asset privacy.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/sharing-animations) **[[3d-modeling-rigging-and-animation]]** Save an animation before exporting it so it appears under the rig's AnimSaves folder.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/sharing-animations) **[[3d-modeling-rigging-and-animation]]** Export the named Class.KeyframeSequence, not a single Keyframe object, or the animation will fail to load on import.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/sharing-animations) **[[3d-modeling-rigging-and-animation]]** If the target rig has no AnimSaves folder, create and save any animation on it first; saving auto-creates the folder.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/sharing-animations) **[[building-art-and-assets]]** Animations saved to .RBXM can be shared with friends and groups without re-uploading, per Roblox asset privacy changes.

## Tools
Roblox Studio Explorer, Animation Editor plugin, RBXM files
