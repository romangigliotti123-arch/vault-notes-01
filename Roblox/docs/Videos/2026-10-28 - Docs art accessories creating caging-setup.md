# Docs: art / accessories / creating / caging-setup

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/art/accessories/creating/caging-setup.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox creator docs on caging setup for clothing in Blender: explains inner/outer cages, and how to isolate the outer cage and clothing mesh in Object mode (hide armature, unhide LongSleeve_OuterCage, lock LongSleeve, enable wireframe) before sculpting the outer cage to fit.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/creating/caging-setup) **[[3d-modeling-rigging-and-animation]]** Build clothing from the cage templates as a mannequin so the inner cage already fits; only adjust the outer cage.
- [page](https://create.roblox.com/docs/art/accessories/creating/caging-setup) **[[3d-modeling-rigging-and-animation]]** Lock the clothing mesh as unselectable in the Outliner while editing the outer cage to prevent accidental edits.
- [page](https://create.roblox.com/docs/art/accessories/creating/caging-setup) **[[3d-modeling-rigging-and-animation]]** Enable Wireframe in Object Properties on the outer cage to make it easier to see and select while sculpting.
