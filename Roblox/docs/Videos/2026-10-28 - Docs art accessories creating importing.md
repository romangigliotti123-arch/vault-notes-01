# Docs: art / accessories / creating / importing

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/art/accessories/creating/importing.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs on importing a layered t-shirt .fbx made in Blender using Studio's Importer, which creates a Model with MeshParts, plus manual texture fallback through the Asset Manager.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/creating/importing) **[[building-art-and-assets]]** Import layered accessory .fbx files via Home > Import in Studio; the Importer previews the layers before you select Import.
- [page](https://create.roblox.com/docs/art/accessories/creating/importing) **[[building-art-and-assets]]** If textures fail to load, upload the image in Asset Manager and set the MeshPart's TextureID to the image asset ID.
- [page](https://create.roblox.com/docs/art/accessories/creating/importing) **[[ugc-and-avatar-economy]]** Wait for moderation to clear an uploaded texture before assigning its asset ID; if Asset Manager is inaccessible, save and publish the game first.

## Tools
Studio Importer, Asset Manager, Blender
