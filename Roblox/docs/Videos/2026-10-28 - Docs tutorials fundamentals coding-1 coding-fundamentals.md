## Summary
Roblox Docs series index for learning Luau fundamentals: variables/objects, functions/events, conditionals, loops, dictionaries/arrays, and organizing code with module scripts. Assumes basic Studio knowledge from the Studio and Building lesson. Teaches coding basics via step-by-step tutorials.

## Tips
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-1/coding-fundamentals) **[[first-session-onboarding]]** Before starting Luau courses, complete the Studio and Building lesson; the series assumes basic Roblox Studio familiarity.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-1/coding-fundamentals) **[[luau-language-and-types]]** Learn Luau in this order: variables/data types/properties, functions/events, conditionals, loops, tables/arrays, then module scripts.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-1/coding-fundamentals) **[[code-architecture-and-frameworks]]** Use module scripts to organize code once scripts start sharing logic; they let scripts interact in a reusable way.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-1/coding-fundamentals) **[[core-loops-and-game-design]]** Apply conditionals to gate gameplay, e.g. checking if the time is right to unlock power-ups for players.
