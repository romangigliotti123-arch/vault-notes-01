# Docs: ai / build

[Open](https://create.roblox.com/docs/ai/build.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox docs for Build, a mobile-first AI tool in the Roblox app that generates playable 2D/2.5D games from natural-language prompts. Covers prompts/credits, playtesting (coming soon), one-tap publishing, limits, and FAQ on age, Studio editing, and content rules.

## Tips
- [page](https://create.roblox.com/docs/ai/build) **[[development-process-and-speed]]** Give specific detail on how the game plays, what the player does, and how it looks for better first-generation results.
- [page](https://create.roblox.com/docs/ai/build) **[[development-process-and-speed]]** Refine with small follow-up prompts (e.g. 'make the coins bigger', 'add a timer') rather than one large request.
- [page](https://create.roblox.com/docs/ai/build) **[[testing-debugging-and-qa]]** Playtest after every few changes; catching issues early is easier than untangling multiple changes at once.
- [page](https://create.roblox.com/docs/ai/build) **[[testing-debugging-and-qa]]** When something misbehaves, describe the expected vs actual behaviour in chat so Build can adjust.
- [page](https://create.roblox.com/docs/ai/build) **[[common-mistakes]]** Do not edit a Build game in Roblox Studio: it permanently becomes a standard Studio game and loses Build status. Make all changes in the Build chat.
- [page](https://create.roblox.com/docs/ai/build) **[[common-mistakes]]** Build games default to 16+ age rating; apply via Roblox Select with content review to allow younger players.
- [page](https://create.roblox.com/docs/ai/build) **[[common-mistakes]]** If a request is refused, rephrase the idea to be more original; content rules, age setting, or IP restrictions may apply.
- [page](https://create.roblox.com/docs/ai/build) **[[first-session-onboarding]]** Keep the first game simple: clicker, arcade, collect-and-score, side-scroller or puzzle work best in Build right now.
- [page](https://create.roblox.com/docs/ai/build) **[[development-process-and-speed]]** If generation stops, type 'please continue'; if that fails, close and reopen the app and retry.
- [page](https://create.roblox.com/docs/ai/build) **[[community-and-discord]]** Share the game privately via playtest link with up to 10 friends for feedback before publishing (playtesters need a Roblox account, age 9+).
- [page](https://create.roblox.com/docs/ai/build) **[[updates-live-ops]]** Keep improving after launch by making changes in the Build chat; the game stays live while you iterate.
- [page](https://create.roblox.com/docs/ai/build) **[[pricing]]** Purchased Build credits (bought with Robux) do not expire; free prompts reset daily.

## Numbers

- [page](https://create.roblox.com/docs/ai/build) Playtester minimum age: **9 or older, with a Roblox account**
- [page](https://create.roblox.com/docs/ai/build) Default Build game age rating: **Players aged 16 and older by default**
- [page](https://create.roblox.com/docs/ai/build) Prompt limit: **Set number of free prompts per day, resets daily; each message counts as one prompt**
