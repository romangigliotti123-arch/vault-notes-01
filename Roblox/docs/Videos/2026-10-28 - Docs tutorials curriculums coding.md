## Summary
Roblox docs tutorial introducing coding in Studio with Luau, using the Story Games sample template. Learners replace placeholder words with player answers via variables. Chapters cover workspace setup, variables, testing/publishing, string customization, and next steps. Aimed at complete beginners.

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/coding) **[[first-session-onboarding]]** Start from the Story Games sample template so beginners see working code before writing their own.
- [page](https://create.roblox.com/docs/tutorials/curriculums/coding) **[[development-process-and-speed]]** Follow the Studio lesson first if unfamiliar with Studio UI or account setup; skip ahead if already comfortable with both coding and Studio.
- [page](https://create.roblox.com/docs/tutorials/curriculums/coding) **[[luau-language-and-types]]** Learn variables first: use them to ask players questions and reuse their answers in later text.
- [page](https://create.roblox.com/docs/tutorials/curriculums/coding) **[[testing-debugging-and-qa]]** Playtest the story in Studio after each change to confirm answers are inserted correctly before publishing.
