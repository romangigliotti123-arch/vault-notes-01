## Summary
Roblox docs intro to scripting: Luau basics (gradual typing, local scoping, nil, tables, generalized iteration), creating scripts in ServerScriptService, Studio scripting settings and Output tools, external editors via Script Sync, and script types and locations.

## Tips
- [page](https://create.roblox.com/docs/scripting) **[[luau-language-and-types]]** Declare variables and functions with the local keyword; the docs say this is almost always better than globals.
- [page](https://create.roblox.com/docs/scripting) **[[luau-language-and-types]]** Use generalized iteration (for k, v in table do) for cleaner loops; ipairs/pairs are optional in Luau.
- [page](https://create.roblox.com/docs/scripting) **[[luau-language-and-types]]** Check nil before use in conditionals; nil evaluates as false.
- [page](https://create.roblox.com/docs/scripting) **[[development-process-and-speed]]** Configure Script Editor settings (font, indentation, autocomplete, tooltips) and enable dark mode early to speed up coding.
