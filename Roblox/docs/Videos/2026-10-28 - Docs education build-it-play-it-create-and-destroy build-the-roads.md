## Summary
Roblox Education docs page on building roads in the "Build It, Play It, Create and Destroy" tutorial. Covers duplicating road tiles from the palette, rotating them with the Rotate tool's green handle, and leaving room for other buildings and decorations.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/build-the-roads) **[[building-and-level-design]]** Duplicate an existing road tile already placed in your map rather than duplicating from the palette each time to save time.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/build-the-roads) **[[building-and-level-design]]** Use the Rotate tool and drag the green handle to orient tiles correctly before placing them.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/build-the-roads) **[[building-and-level-design]]** Leave plenty of room between roads and buildings for other buildings and decorations.
