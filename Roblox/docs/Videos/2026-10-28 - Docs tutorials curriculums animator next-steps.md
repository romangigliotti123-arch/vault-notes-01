## Summary
Docs next-steps page for Roblox Studio Animation Editor. Points to share/testing features (invite early testers, release games), lists advanced animation features (event markers, Inverse Kinematics, Curve Editor), and links further use-case tutorials for character animation, rigging and skinning in Blender.

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/animator/next-steps) **[[ai-and-tools]]** Use Studio's Curve Editor to view and modify rig position/orientation changes between keyframes via color-coded curve graphs, for smoother animations.
- [page](https://create.roblox.com/docs/tutorials/curriculums/animator/next-steps) **[[3d-modeling-rigging-and-animation]]** Use event markers to trigger custom behavior at specific keyframes in an animation.
- [page](https://create.roblox.com/docs/tutorials/curriculums/animator/next-steps) **[[3d-modeling-rigging-and-animation]]** Use Inverse Kinematics to pose and animate multiple character parts by adjusting a single object.
- [page](https://create.roblox.com/docs/tutorials/curriculums/animator/next-steps) **[[playtesting-and-feedback]]** Invite early testers to preview your game before releasing it to players.
