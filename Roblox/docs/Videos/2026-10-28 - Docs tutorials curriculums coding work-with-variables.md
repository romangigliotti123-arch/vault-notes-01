## Summary
Roblox docs chapter on working with variables in the Story Game template's StoryManager script: opening the script, creating string variables via storyMaker:GetInput() with questions, and concatenating player answers into a story shown with storyMaker:Write().

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/coding/work-with-variables) **[[code-architecture-and-frameworks]]** Name variables after the information they store (e.g. teamScore, teamColor), and use lowercase starting names for locals.
- [page](https://create.roblox.com/docs/tutorials/curriculums/coding/work-with-variables) **[[luau-language-and-types]]** Strings must be in quotation marks; concatenate with .. and leave a space before the closing quote when joining text.
- [page](https://create.roblox.com/docs/tutorials/curriculums/coding/work-with-variables) **[[testing-debugging-and-qa]]** Playtest after wiring the first story segment to confirm the input and output work before adding more content.
