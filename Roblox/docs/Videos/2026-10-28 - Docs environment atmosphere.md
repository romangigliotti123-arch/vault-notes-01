# Docs: environment / atmosphere

[Open](https://create.roblox.com/docs/environment/atmosphere.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on Atmosphere properties in Lighting: Density, Offset, Haze, Color, Glare, Decay, with suggested values and how they interact.

## Tips
- [page](https://create.roblox.com/docs/environment/atmosphere) **[[building-art-and-assets]]** Balance Offset with Density: low Offset can show skybox through terrain, high Offset can show too much distant detail.
- [page](https://create.roblox.com/docs/environment/atmosphere) **[[building-art-and-assets]]** Use high Offset to create a horizon silhouette; use low Offset to blend distant objects into sky for open worlds.
- [page](https://create.roblox.com/docs/environment/atmosphere) **[[building-art-and-assets]]** Combine Color with a high Haze value to make the Color effect visible, e.g. smoky or foggy moods.
- [page](https://create.roblox.com/docs/environment/atmosphere) **[[building-art-and-assets]]** Glare only shows when Haze is above 0; Decay only shows when Glare and Haze are both above 0.
