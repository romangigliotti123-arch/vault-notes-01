# Docs: production / game-design / core-loops

[Open](https://create.roblox.com/docs/production/game-design/core-loops.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page defining the core loop as three parts: minute-to-minute interaction, the most repeated set of actions, and a progression engine. Uses an action RPG (exploration, fighting, upgrade tree) as the example.

## Tips
- [page](https://create.roblox.com/docs/production/game-design/core-loops) **[[core-loops-and-game-design]]** Structure every game's core loop in three steps: minute-to-minute interaction, most repeated set of actions, and a progression engine.
- [page](https://create.roblox.com/docs/production/game-design/core-loops) **[[core-loops-and-game-design]]** Identify the most frequently repeated actions; these are often the defining mechanic and become the core of the loop.
- [page](https://create.roblox.com/docs/production/game-design/core-loops) **[[core-loops-and-game-design]]** Always include a progression system; without one the game becomes repetitive, boring and shallow.
- [page](https://create.roblox.com/docs/production/game-design/core-loops) **[[core-loops-and-game-design]]** Make progression feed back into the earlier steps, so upgrades boost future exploration and combat capabilities.
