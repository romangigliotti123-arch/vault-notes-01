## Summary
Roblox docs tutorial on object properties: what properties are, viewing them in the Properties window, and changing a part's Color via a server Script in ServerScriptService using workspace.PracticePart.Color = Color3.fromRGB(...). Covers comments and dot-operator referencing.

## Tips
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-1/object-properties) **[[scripting-and-performance]]** Use the Explorer to find an object's exact path before scripting; PracticePart under Workspace is referenced as workspace.PracticePart.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-1/object-properties) **[[scripting-and-performance]]** Use comments (--) to note what each script does for yourself and other programmers; comments are not executed.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-1/object-properties) **[[luau-language-and-types]]** Color3.fromRGB takes three integers 0-255 separated by commas; values outside this range are invalid.

## Numbers
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-1/object-properties) RGB channel range: **0 to 255 per channel (black 0,0,0; white 255,255,255)**

Roblox Studio, Properties window, Explorer, Script editor
