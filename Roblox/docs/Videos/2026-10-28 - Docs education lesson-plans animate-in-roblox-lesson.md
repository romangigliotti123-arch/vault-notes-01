# Docs: education / lesson-plans / animate-in-roblox-lesson

[Open](https://create.roblox.com/docs/education/lesson-plans/animate-in-roblox-lesson.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox education lesson plan teaching animation basics: students pose a Roblox character (e.g., swimming, skipping) using keyposes in Roblox Studio's Animation Editor, then playtest it as the default walk animation in a multiplayer game. Includes timing, troubleshooting, and curriculum-integration tips.

## Tips
- [page](https://create.roblox.com/docs/education/lesson-plans/animate-in-roblox-lesson) **[[development-process-and-speed]]** Give students time limits per pose, such as 2-4 minutes, so projects finish; poses can always be improved later.
- [page](https://create.roblox.com/docs/education/lesson-plans/animate-in-roblox-lesson) **[[building-art-and-assets]]** Use body movement or reference images when posing; a visual reference helps identify which body part to rotate.
- [page](https://create.roblox.com/docs/education/lesson-plans/animate-in-roblox-lesson) **[[testing-debugging-and-qa]]** View the animation in Roblox Studio from multiple angles; a pose can look correct from one angle and wrong from another.
- [page](https://create.roblox.com/docs/education/lesson-plans/animate-in-roblox-lesson) **[[testing-debugging-and-qa]]** Use 'Ask 3 Before Me': ask three peers for help before asking the instructor.
- [page](https://create.roblox.com/docs/education/lesson-plans/animate-in-roblox-lesson) **[[playtesting-and-feedback]]** Pair students to review each other's animation using the feedback handout, after setting a goal for the animation beforehand.
- [page](https://create.roblox.com/docs/education/lesson-plans/animate-in-roblox-lesson) **[[playtesting-and-feedback]]** Limit play-testing to about 2 minutes per check so the lesson stays on schedule.
- [page](https://create.roblox.com/docs/education/lesson-plans/animate-in-roblox-lesson) **[[age-ratings-moderation-and-tos]]** If using motion-based mobile play or physical reference poses, set strict safety guidelines and a safe space for movement.
