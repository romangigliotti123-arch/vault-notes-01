# Docs: studio / plugins

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/studio/plugins.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox docs on Studio plugins: creating a toolbar plugin (AddEmptyScript sample), saving/reloading via Plugin Debugging, undo/redo with ChangeHistoryService, publishing to inventory, and selling on the Creator Store.

## Tips
- [page](https://create.roblox.com/docs/studio/plugins) **[[ui-ux-design]]** Set ClickableWhenViewportHidden = true on toolbar buttons so the plugin can be used when the 3D viewport is hidden.
- [page](https://create.roblox.com/docs/studio/plugins) **[[version-control-and-tooling]]** Enable Plugin Debugging Enabled in Studio settings to get PluginDebugService for live debugging and reloading plugin code.
- [page](https://create.roblox.com/docs/studio/plugins) **[[version-control-and-tooling]]** Delete the original script after 'Save as Local Plugin' and edit only the copy in PluginDebugService to avoid applying changes to the wrong script.
- [page](https://create.roblox.com/docs/studio/plugins) **[[testing-debugging-and-qa]]** Use Reload Plugin (not Save) when stepping through code with breakpoints; use Save and Reload to persist changes.

## Numbers
- [page](https://create.roblox.com/docs/studio/plugins) Plugin sale revenue share: **100% of net proceeds (only taxes and payment processing fees deducted)** (Creator Store plugin sales in USD)
- [page](https://create.roblox.com/docs/studio/plugins) Plugin thumbnail size: **512×512 px** (Optional image for published plugin)

## Tools
Roblox Studio, Plugin Debugging / PluginDebugService, ChangeHistoryService, Selection service
