# Docs: tutorials / curriculums / animator / test-and-save

[Open](https://create.roblox.com/docs/tutorials/curriculums/animator/test-and-save.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Creator Docs tutorial page on testing an animation in Studio and publishing the game to save progress. Covers the Test, Test Here and Run playtest options, a short troubleshooting list for glitchy or wrong animations, and the publish workflow with its recommended save cadence.

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/animator/test-and-save) **[[testing-debugging-and-qa]]** Playtest with Test or Test Here, not Run, so your avatar is inserted and you can actually see the animation play.
- [page](https://create.roblox.com/docs/tutorials/curriculums/animator/test-and-save) **[[building-art-and-assets]]** Make the first and last animation poses identical to avoid a skip or glitch when the animation loops; copy the first pose and paste it at the end.
- [page](https://create.roblox.com/docs/tutorials/curriculums/animator/test-and-save) **[[building-art-and-assets]]** Keep the rig inside the white grid in the Animation Editor so it does not pass through walls or the ground during playback.
- [page](https://create.roblox.com/docs/tutorials/curriculums/animator/test-and-save) **[[building-art-and-assets]]** Save animations in the Animation Editor after every edit; unsaved changes will not show in playtests.
- [page](https://create.roblox.com/docs/tutorials/curriculums/animator/test-and-save) **[[common-mistakes]]** If the wrong animation plays, confirm the animation was published via the Animation Editor and that WalkAnimationID's Value property is only a number.
- [page](https://create.roblox.com/docs/tutorials/curriculums/animator/test-and-save) **[[development-process-and-speed]]** Publish to Roblox every ten minutes or after a big change, since closing Studio without publishing loses all edits.
- [page](https://create.roblox.com/docs/tutorials/curriculums/animator/test-and-save) **[[development-process-and-speed]]** Save again later with File > Publish or Alt+P (Option+P on Mac) once the game is already connected to your account.

## Numbers
- [page](https://create.roblox.com/docs/tutorials/curriculums/animator/test-and-save) publish interval: **every 10 minutes** (Recommended Roblox publish cadence, or after a big change)
