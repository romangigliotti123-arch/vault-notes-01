# Docs: ui / labels

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/ui/labels.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox documentation page on Labels (TextLabel and ImageLabel). Explains the two label types, how to create them in a ScreenGui or on a SurfaceGui attached to a part face, and how to style ImageLabels with ImageColor3, ImageTransparency and BackgroundTransparency.

## Tips
- [page](https://create.roblox.com/docs/ui/labels) **[[building-art-and-assets]]** Use a ScreenGui in StarterGui for on-screen labels, such as character portraits with dialog.
- [page](https://create.roblox.com/docs/ui/labels) **[[building-art-and-assets]]** Use a SurfaceGui on a part face for billboards, posters and wallpaper. If the insert button is missing, change the SurfaceGui's Face property.
- [page](https://create.roblox.com/docs/ui/labels) **[[building-art-and-assets]]** ImageLabel images must be imported into Studio assets. Display them at native resolution, since they look best there.
- [page](https://create.roblox.com/docs/ui/labels) **[[ui-ux-design]]** Set BackgroundTransparency to 1 on an ImageLabel to show only the image and hide its rectangle.

## Numbers
- [page](https://create.roblox.com/docs/ui/labels) BackgroundTransparency: **1** (Hides the label rectangle so only the image shows)
