# Docs: ip-licensing / license-manager

[Open](https://create.roblox.com/docs/ip-licensing/license-manager.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox docs for the License Manager: how rights holders register IP families, create license listings and licenses (full game, in-game sales, Marketplace), review matches, offers, requests and conditional approvals, track disputes, and view analytics.

## Tips
- [page](https://create.roblox.com/docs/ip-licensing/license-manager) **[[brand-deals-and-ip-licensing]]** Only use License Manager with exclusive, worldwide rights to IP backed by copyright or trademark registrations; false ownership claims can terminate access or account.
- [page](https://create.roblox.com/docs/ip-licensing/license-manager) **[[brand-deals-and-ip-licensing]]** Upload at least 10 approved images when creating an IP family, otherwise Roblox won't generate game matches.
- [page](https://create.roblox.com/docs/ip-licensing/license-manager) **[[brand-deals-and-ip-licensing]]** Use perpetual duration if you want automatic matches and offers; time-limited licenses only receive creator requests.
- [page](https://create.roblox.com/docs/ip-licensing/license-manager) **[[brand-deals-and-ip-licensing]]** Duration type cannot be changed after creation; choose perpetual vs time-limited carefully.
- [page](https://create.roblox.com/docs/ip-licensing/license-manager) **[[brand-deals-and-ip-licensing]]** Revenue share rate can be set 0% to 95%; it cannot be changed once a license is used in any agreement.
- [page](https://create.roblox.com/docs/ip-licensing/license-manager) **[[brand-deals-and-ip-licensing]]** Use eligibility filters (min DAU, max maturity rating, min Marketplace earnings) to limit which creators can request your license.
- [page](https://create.roblox.com/docs/ip-licensing/license-manager) **[[brand-deals-and-ip-licensing]]** Use Private licenses to restrict requests to creators you contact directly; Public lets all eligible creators request.
- [page](https://create.roblox.com/docs/ip-licensing/license-manager) **[[brand-deals-and-ip-licensing]]** Use conditional offers when a game nearly fits your content standards; they do not auto-activate and require your approval after creator changes.
- [page](https://create.roblox.com/docs/ip-licensing/license-manager) **[[brand-deals-and-ip-licensing]]** Review match gameplay screenshots and play the game before sending a standard offer, since standard offers auto-activate after 14 days.
- [page](https://create.roblox.com/docs/ip-licensing/license-manager) **[[brand-deals-and-ip-licensing]]** Review creator game or materials before accepting, conditionally approving, or rejecting license requests.
- [page](https://create.roblox.com/docs/ip-licensing/license-manager) **[[brand-deals-and-ip-licensing]]** Give specific feedback naming the violated content standard when rejecting or conditionally approving; it helps creators re-request successfully.
- [page](https://create.roblox.com/docs/ip-licensing/license-manager) **[[brand-deals-and-ip-licensing]]** Showcase up to 10 live-agreement games on the license page to show creators examples of your IP in use.
- [page](https://create.roblox.com/docs/ip-licensing/license-manager) **[[brand-deals-and-ip-licensing]]** Write clear scope and content standards in the license; once used in an agreement, license requirements cannot be changed.
- [page](https://create.roblox.com/docs/ip-licensing/license-manager) **[[brand-deals-and-ip-licensing]]** Time-limited license start and end dates are based on midnight UTC.
- [page](https://create.roblox.com/docs/ip-licensing/license-manager) **[[brand-deals-and-ip-licensing]]** Submit up to 3 match requests per day for games using your IP that do not appear in Matches.

- [page](https://create.roblox.com/docs/ip-licensing/license-manager) Conditional offer / request change window: **14 days**
- [page](https://create.roblox.com/docs/ip-licensing/license-manager) Match requests per day: **3**
- [page](https://create.roblox.com/docs/ip-licensing/license-manager) Showcased games per license: **10**
