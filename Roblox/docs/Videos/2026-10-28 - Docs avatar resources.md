# Docs: avatar / resources

[Open](https://create.roblox.com/docs/avatar/resources.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox official docs page listing avatar creation resources: finished R15 reference rigs, auto-setup references, project files (rig/cage templates for Blender, Maya, FBX), mannequin sizing models, templates, and third-party add-ons/validation tools for avatar item creation.

## Tips
- [page](https://create.roblox.com/docs/avatar/resources) **[[building-art-and-assets]]** Clean up Roblox avatar template files (per warnings) before publishing to the Marketplace or they will fail validation.
- [page](https://create.roblox.com/docs/avatar/resources) **[[building-art-and-assets]]** Remove clothing and accessory items from Nature Girl and Stylish Male references before uploading; they can cause validation errors.
- [page](https://create.roblox.com/docs/avatar/resources) **[[3d-modeling-rigging-and-animation]]** Use the Standard R15 Rig and Attachments or Combined Project Files template when rigging bodies and clothing in Blender, Maya, or FBX.
- [page](https://create.roblox.com/docs/avatar/resources) **[[3d-modeling-rigging-and-animation]]** Use Cages for Clothing (inner and outer full-body cage) when creating clothing; use Cages for Bodies (15 body part cages) for bodies.
- [page](https://create.roblox.com/docs/avatar/resources) **[[3d-modeling-rigging-and-animation]]** Set Rig Scale to Rthro Narrow when importing the Roxie advanced R15 rig.
- [page](https://create.roblox.com/docs/avatar/resources) **[[building-art-and-assets]]** Check Blender armature bone orientation: references exported from Maya may look misoriented, but this does not affect rig performance.
- [page](https://create.roblox.com/docs/avatar/resources) **[[building-art-and-assets]]** Use mannequin models (Classic, Rthro, Rthro Slender) as scale, body shape and caging reference when designing accessories.
- [page](https://create.roblox.com/docs/avatar/resources) **[[ai-and-tools]]** Run the Blender Validation Tool before importing avatar items into Studio; use Blender Calisthenics Tool to check skinning data.
- [page](https://create.roblox.com/docs/avatar/resources) **[[building-art-and-assets]]** Lola reference lacks inner and outer cage mesh data, so it cannot equip rigid or layered accessories; use a caged reference instead.
- [page](https://create.roblox.com/docs/avatar/resources) **[[3d-modeling-rigging-and-animation]]** Mannequin and Auto-Setup references fail normal validation if uploaded as-is; Auto-Setup templates are incompatible with the traditional avatar workflow.

## Numbers
- [page](https://create.roblox.com/docs/avatar/resources) Texture resolution: **2K PBR textures in AA, Robuta, and Mannequin references** (Advanced R15 reference body downloads)
- [page](https://create.roblox.com/docs/avatar/resources) Body part cages: **15** (Individual body part cages in Cages for Bodies project file)

## Tools
Blender, Maya, FBX, Blender Studio Plugin, Blender Validation Tool, Blender Calisthenics Tool
