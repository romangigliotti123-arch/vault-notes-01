# Docs: avatar / layered-accessories / project-files

[Open](https://create.roblox.com/docs/avatar/layered-accessories/project-files.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Docs page listing official downloadable template and reference files for making layered accessories and bodies on Roblox: FBX mannequins with and without body cages, and Blender/Maya/general rigging and caging templates with R15 armature and attachment points.

## Tips
- [page](https://create.roblox.com/docs/avatar/layered-accessories/project-files) **[[building-art-and-assets]]** Start layered accessory work from Roblox's Clothing_Cage_Template and Rig_and_Attachments_Template files rather than from scratch, for correct naming and attachment points.
- [page](https://create.roblox.com/docs/avatar/layered-accessories/project-files) **[[3d-modeling-rigging-and-animation]]** Use the Blender or Maya template files for those programs; the general .fbx templates were exported from Maya and are meant only for other modeling software.
- [page](https://create.roblox.com/docs/avatar/layered-accessories/project-files) **[[3d-modeling-rigging-and-animation]]** Use the Combined-Template when you need to rig and cage a character body and its accessories together in one file.
- [page](https://create.roblox.com/docs/avatar/layered-accessories/project-files) **[[3d-modeling-rigging-and-animation]]** Cage-enabled mannequin FBX files may fail to import into Studio until their unconfigured cage objects are fixed.
- [page](https://create.roblox.com/docs/avatar/layered-accessories/project-files) **[[building-art-and-assets]]** Pick the mannequin matching the target body type (Classic, Rthro Normal, or Rthro Slender) so caging fits the intended avatar body.

## Tools
Blender, Maya, Roblox Studio, Clothing_Cage_Template, Rig_and_Attachments_Template, Combined-Template
