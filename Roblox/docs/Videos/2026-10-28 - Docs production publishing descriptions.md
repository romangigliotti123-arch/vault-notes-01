# Docs: production / publishing / descriptions

[Open](https://create.roblox.com/docs/production/publishing/descriptions.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs (experimental guidance) on writing game descriptions to improve external SEO (Google/Bing/DuckDuckGo). Covers a four-part structure: hook (~160 chars), optional recent updates, main content, and additional info (devices, codes, FAQ, changelog link). Advises against tags/hashtags and listing controls; keep content all-ages.

## Tips
- [page](https://create.roblox.com/docs/production/publishing/descriptions) **[[titles-descriptions]]** Write the first ~160 characters as a hook with title, core genre, unique feature and primary search keywords; this is what search snippets and mobile show first.
- [page](https://create.roblox.com/docs/production/publishing/descriptions) **[[titles-descriptions]]** Immediately communicate the main objective in the hook, e.g. 'Can you build the ultimate base and survive all 500 levels?'
- [page](https://create.roblox.com/docs/production/publishing/descriptions) **[[titles-descriptions]]** Keep the optional recent-updates blurb short; long update sections push the main content down for new players.
- [page](https://create.roblox.com/docs/production/publishing/descriptions) **[[titles-descriptions]]** Describe core gameplay loop and key selling points in main content, as bullets or paragraphs, so search engines can index and categorize the game.
- [page](https://create.roblox.com/docs/production/publishing/descriptions) **[[titles-descriptions]]** Keep FAQs concise and limited to basic questions (How do I X? What is X?); FAQs consume much of the 1000-character limit.
- [page](https://create.roblox.com/docs/production/publishing/descriptions) **[[titles-descriptions]]** Do not use tags or hashtags in descriptions; they are unused in ranking and only waste character count.
- [page](https://create.roblox.com/docs/production/publishing/descriptions) **[[titles-descriptions]]** Do not enumerate controls in the description; teach controls via an in-game tutorial to save characters.
- [page](https://create.roblox.com/docs/production/publishing/descriptions) **[[titles-descriptions]]** Put changelog/credits behind a DevForum link rather than inline text.
- [page](https://create.roblox.com/docs/production/publishing/descriptions) **[[titles-descriptions]]** Keep the whole description appropriate for all ages.
- [page](https://create.roblox.com/docs/production/publishing/descriptions) **[[titles-descriptions]]** Premium benefits section is optional; cut it first when character count is tight.

## Numbers
- [page](https://create.roblox.com/docs/production/publishing/descriptions) Hook length: **~160 characters** (Portion most likely shown in search snippets and mobile app before expansion)
- [page](https://create.roblox.com/docs/production/publishing/descriptions) Description character limit: **1000 characters** (Docs cite 1000-character count; FAQs can consume much of it)
- [page](https://create.roblox.com/docs/production/publishing/descriptions) Top game Google impressions: **millions per month** (Top games get millions of monthly Google impressions, per docs)
