# Docs: education / build-it-play-it-island-of-move / looping-animations

[Open](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/looping-animations.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Studio docs page on making animations loop smoothly in the Animation Editor: copy the first pose (at 0:00) and paste it at the end of the timeline (1:00) before creating the second pose.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/looping-animations) **[[3d-modeling-rigging-and-animation]]** To loop smoothly, copy the 0:00 start pose and paste it at the animation end (1:00) before posing the second frame.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/looping-animations) **[[3d-modeling-rigging-and-animation]]** In Animation Editor, select the white start-pose diamond (blue border) before pressing Ctrl+C / Cmd+C to copy the whole pose.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/looping-animations) **[[3d-modeling-rigging-and-animation]]** Set the current-time box to the end time (1:00), then press Ctrl+V / Cmd+V to paste; the pasted diamonds appear at the end.

## Numbers
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/looping-animations) Loop animation length: **1:00 timeline end used in example** (Example end-of-animation time for pasting the start pose)
