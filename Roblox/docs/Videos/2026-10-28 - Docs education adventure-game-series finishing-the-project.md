# Docs: education / adventure-game-series / finishing-the-project

[Open](https://create.roblox.com/docs/education/adventure-game-series/finishing-the-project.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Education docs page on finishing an adventure-game project: tune player variables (bag Spaces, sell price, upgrade cost), add more item placements, playtest with friends, and expand with more items and upgrade types.

## Tips
- [page](https://create.roblox.com/docs/education/adventure-game-series/finishing-the-project) **[[pricing]]** Set player bag Spaces to 6-10 as a starting point, then playtest to find the right number.
- [page](https://create.roblox.com/docs/education/adventure-game-series/finishing-the-project) **[[core-loops-and-game-design]]** Tune sell price per item between 50 and 200, multiplied by item count, so the sell loop feels rewarding.
- [page](https://create.roblox.com/docs/education/adventure-game-series/finishing-the-project) **[[core-loops-and-game-design]]** Set upgrade capacity increase to 10-15 and upgrade cost to 500-1000 to keep upgrades challenging but fair.
- [page](https://create.roblox.com/docs/education/adventure-game-series/finishing-the-project) **[[core-loops-and-game-design]]** Vary item placement and add obstacles to collection so item gathering stays fun rather than trivial.
- [page](https://create.roblox.com/docs/education/adventure-game-series/finishing-the-project) **[[playtesting-and-feedback]]** Test every number yourself and have friends playtest; initial values are educated guesses, not final balance.
- [page](https://create.roblox.com/docs/education/adventure-game-series/finishing-the-project) **[[playtesting-and-feedback]]** During playtests, check whether items are too easy or too far to find, whether upgrade cost feels too easy or hard, and look for unnoticed bugs.
- [page](https://create.roblox.com/docs/education/adventure-game-series/finishing-the-project) **[[development-process-and-speed]]** Once the core project works, expand with more collectible item types and different upgrade types.

## Numbers
- [page](https://create.roblox.com/docs/education/adventure-game-series/finishing-the-project) Spaces (bag capacity) starting value: **6-10** (Recommended starting range for player item capacity before selling)
- [page](https://create.roblox.com/docs/education/adventure-game-series/finishing-the-project) Sell value per item multiplier: **50-200** (Multiplier applied to playerItems.Value in SellScript)
- [page](https://create.roblox.com/docs/education/adventure-game-series/finishing-the-project) Upgrade newMaxItems: **10-15** (Recommended value for BuyScript newMaxItems)
- [page](https://create.roblox.com/docs/education/adventure-game-series/finishing-the-project) Upgrade cost: **500-1000** (Recommended value for BuyScript upgradeCost)
