# Docs: education / lesson-plans / roblox-developer / roblox-developer-1

[Open](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-1.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Educational lesson plan for a first Roblox Studio session: introduce the course, build a simple obstacle course with parts, and write a script using variables and strings to display text. Includes classroom management and troubleshooting tips for teachers.

## Tips
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-1) **[[first-session-onboarding]]** Start by playing a finished example of the project so students see the end goal before learning tools.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-1) **[[development-process-and-speed]]** Keep the obstacle course as practice, but let students reuse its parts in their final adventure game.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-1) **[[building-and-level-design]]** Remind students to rotate the camera to check builds from multiple angles for accurate placement.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-1) **[[building-and-level-design]]** Encourage students to use the Explorer window, a foundational Studio skill, to find and manage objects.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-1) **[[common-mistakes]]** If parts fall or disappear during playtesting, turn on Anchored for those parts.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-1) **[[common-mistakes]]** Most common beginner script errors are capitalization mistakes and typos; have students check their own code first.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-1) **[[development-process-and-speed]]** Set strict time limits for small tasks, such as one minute to add a part or pick a color, to keep lessons on schedule.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-1) **[[testing-debugging-and-qa]]** Use leading questions instead of direct fixes, e.g. ask what symbols surround a string, to build troubleshooting skill.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-1) **[[community-and-discord]]** Adopt an Ask 3 Before Me rule: students ask three peers before asking the instructor for help.

## Numbers
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-1) Lesson duration: **5 min intro, 5 min Studio basics, 15 min scripting, 5 min wrap-up (30 min total)**
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-1) Peer help rule: **Ask 3 peers before asking instructor**
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-1) Task time limit example: **1 minute to add a single part or pick a color**
