# Docs: avatar / emotes / import

[Open](https://create.roblox.com/docs/avatar/emotes/import.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs on importing a .fbx emote into Studio's Animation Editor, converting keyframes to a CurveAnimation, publishing it for an asset ID, wrapping it in an Animation object, and uploading it to the Marketplace as an Avatar Item (Emote) for 80 Robux.

## Tips
- [page](https://create.roblox.com/docs/avatar/emotes/import) **[[3d-modeling-rigging-and-animation]]** Emotes must use a standard R15 rig; add an R15 avatar body in the Avatar tab before importing the .fbx animation.
- [page](https://create.roblox.com/docs/avatar/emotes/import) **[[3d-modeling-rigging-and-animation]]** Convert keyframes to a CurveAnimation via the Curve Editor. Emotes require CurveAnimation, not KeyframeSequence, or errors occur.
- [page](https://create.roblox.com/docs/avatar/emotes/import) **[[building-art-and-assets]]** Publish the CurveAnimation to Roblox via Publish to Roblox to get a cloud asset ID, then set it as the AnimationId of an Animation object.
- [page](https://create.roblox.com/docs/avatar/emotes/import) **[[ugc-and-avatar-economy]]** Set Content Type to Avatar Item and Asset Category to Emote when saving the Animation object to Roblox for Marketplace submission.
- [page](https://create.roblox.com/docs/avatar/emotes/import) **[[business-and-payouts]]** Budget for the 80 Robux upload fee required to submit an emote to the Marketplace.

## Numbers
- [page](https://create.roblox.com/docs/avatar/emotes/import) Emote upload fee: **80 Robux** (Required to upload an emote to the Marketplace)

## Tools
Roblox Studio, Animation Editor, Curve Editor, Explorer, Properties window
