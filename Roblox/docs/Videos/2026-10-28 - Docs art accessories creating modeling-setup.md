# Docs: art / accessories / creating / modeling-setup

[Open](https://create.roblox.com/docs/art/accessories/creating/modeling-setup.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs tutorial on setting up a Blender project for clothing modeling: duplicating Roblox's Clothing_Cage.blend inner cage as the base mesh, renaming objects, and removing helper color attributes that would clash with textures in Studio. Covers the first two of seven modeling steps.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/creating/modeling-setup) **[[building-art-and-assets]]** Start clothing from Roblox's Clothing_Cage.blend template and use File > Save As so the template stays untouched.
- [page](https://create.roblox.com/docs/art/accessories/creating/modeling-setup) **[[building-art-and-assets]]** Duplicate the InnerCage, then Parent > Clear and Keep Transformation so the copy keeps its position and scale without a parent.
- [page](https://create.roblox.com/docs/art/accessories/creating/modeling-setup) **[[building-art-and-assets]]** Remove the helper colorSet1 vertex color attribute before importing, since it can clash with the texture in Studio.
- [page](https://create.roblox.com/docs/art/accessories/creating/modeling-setup) **[[3d-modeling-rigging-and-animation]]** Hide the original cage objects after duplicating so they don't get selected or exported by mistake.
