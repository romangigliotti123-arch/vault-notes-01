# Docs: art / accessories / creating / armature-setup

[Open](https://create.roblox.com/docs/art/accessories/creating/armature-setup.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on rigging a clothing mesh for R15 avatars. Covers appending Roblox's Rig_and_Attachments_Template.blend armature, reorienting and applying transforms, and parenting the mesh with Blender's Parent With Automatic Weights for skinning, then testing poses.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/creating/armature-setup) **[[3d-modeling-rigging-and-animation]]** Import Roblox's premade R15 rig template instead of building your own; a properly configured rig saves time and reduces configuration errors.
- [page](https://create.roblox.com/docs/art/accessories/creating/armature-setup) **[[3d-modeling-rigging-and-animation]]** Apply All Transforms (Object > Apply > All Transforms) after aligning the armature so its rotation values are frozen before parenting.
- [page](https://create.roblox.com/docs/art/accessories/creating/armature-setup) **[[3d-modeling-rigging-and-animation]]** Parent the mesh with Automatic Weights, selecting the armature last, to auto-skin clothing instead of weighting it manually.
- [page](https://create.roblox.com/docs/art/accessories/creating/armature-setup) **[[3d-modeling-rigging-and-animation]]** Test several basic poses after rigging to confirm the clothing moves and stretches correctly across character body shapes.
