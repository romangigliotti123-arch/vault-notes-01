# Docs: tutorials / curriculums / artist / work-with-particle-emitters

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.

## Summary
Roblox Creator Docs tutorial on customizing ParticleEmitter VFX in Studio. Covers finding sample emitters, setting Color and Texture (asset IDs), Size and Speed ranges, and additional properties like LightEmission, RotSpeed, Lifetime, and randomized Min/Max values.

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/artist/work-with-particle-emitters) **[[building-art-and-assets]]** Set ParticleEmitter Size to between 1 and 10 for best results; different textures look better at different sizes, so tune per texture.
- [page](https://create.roblox.com/docs/tutorials/curriculums/artist/work-with-particle-emitters) **[[building-art-and-assets]]** Set ParticleEmitter Speed between 10 (slow) and 100 (fast) to control whether particles burst out quickly or drift out slowly.
- [page](https://create.roblox.com/docs/tutorials/curriculums/artist/work-with-particle-emitters) **[[vfx-and-particles]]** Use the Texture property with an rbxassetid to change particle appearance entirely; texture choice drives how the effect reads.
- [page](https://create.roblox.com/docs/tutorials/curriculums/artist/work-with-particle-emitters) **[[vfx-and-particles]]** Raise LightEmission (0 to 1) so particles glow, even in low-light environments.

## Numbers
- [page](https://create.roblox.com/docs/tutorials/curriculums/artist/work-with-particle-emitters) Size: **1 to 10 (best results)** (Recommended ParticleEmitter Size range for explosion particles)
- [page](https://create.roblox.com/docs/tutorials/curriculums/artist/work-with-particle-emitters) Speed: **10 (slow) to 100 (fast)** (Recommended ParticleEmitter Speed range)
- [page](https://create.roblox.com/docs/tutorials/curriculums/artist/work-with-particle-emitters) Lifetime example: **0.5 s to 2 s** (Brief flash vs lingering particles)
- [page](https://create.roblox.com/docs/tutorials/curriculums/artist/work-with-particle-emitters) LightEmission example values: **0, 0.5, 1** (Glow amount demonstrated in docs)
