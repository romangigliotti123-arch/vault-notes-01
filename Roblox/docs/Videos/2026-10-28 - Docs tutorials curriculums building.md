# Docs: tutorials / curriculums / building

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.

## Summary
Roblox docs tutorial introducing building in Studio via a Classic Obby template: opening the template workspace, creating platforms with basic parts, modifying part behavior with AI Assistant code, playtesting and publishing, and next-step resources. Aimed at complete beginners.

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/building) **[[first-session-onboarding]]** Start from the Classic Obby template as a guide so beginners can focus on building rather than setup.
- [page](https://create.roblox.com/docs/tutorials/curriculums/building) **[[building-and-level-design]]** Build obstacle courses from basic part shapes; design platforms that players jump between to reach a final platform.
- [page](https://create.roblox.com/docs/tutorials/curriculums/building) **[[ai-and-tools]]** Use AI Assistant to generate code that modifies part behavior, rather than writing scripts from scratch as a beginner.
- [page](https://create.roblox.com/docs/tutorials/curriculums/building) **[[testing-debugging-and-qa]]** Playtest the experience in Studio before publishing to Roblox.

## Tools
Roblox Studio, AI Assistant, Classic Obby template
