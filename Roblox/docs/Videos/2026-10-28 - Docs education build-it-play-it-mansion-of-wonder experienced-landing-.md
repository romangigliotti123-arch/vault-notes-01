## Summary
Roblox Education docs page on designing a first-time user experience through an interactive tutorial. Covers guiding new players to goals, signalling task completion, and leading to the next goal, using beams for trails, particle effects on completion, and scripts that track goals and progress.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/experienced-landing-page) **[[first-session-onboarding]]** Make the first impression strong: if players don't know what to do, they're likely to leave and never return.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/experienced-landing-page) **[[first-session-onboarding]]** Teach new players how to play with an interactive tutorial that guides them to a first goal.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/experienced-landing-page) **[[first-session-onboarding]]** Confirm when each task is complete, then lead players directly to their next goal to keep them progressing.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/experienced-landing-page) **[[first-session-onboarding]]** Use beams to draw a trail guiding players to each goal in the tutorial.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/experienced-landing-page) **[[player-psychology-and-game-feel]]** Play a particle effect when a player completes a task to reward the action and mark progress.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/experienced-landing-page) **[[core-loops-and-game-design]]** Use scripts to track each player's current goal and progress so the tutorial advances correctly.
