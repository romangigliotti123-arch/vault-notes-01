## Summary
Roblox Studio docs page on saving and publishing a place. Covers saving an animation via the Animation Editor's three-dots menu, publishing the whole place with File → Publish, publishing regularly, and notes on mobile accelerometer controls and re-publishing with Alt+P / ⌥P.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/save-and-publish) **[[development-process-and-speed]]** Publish the place every ten minutes while working or after a big change so progress is saved to your Roblox account.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/save-and-publish) **[[cross-platform-and-console]]** Mobile players can move characters with device accelerometers; desktop players click a button to move. Plan controls for both.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/save-and-publish) **[[development-process-and-speed]]** Re-publish with File → Publish or Alt+P (⌥+P on Mac) to save the whole project after the first save.

## Numbers
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/save-and-publish) Recommended publish interval: **every 10 minutes** (Docs advice for publishing while working or after big changes)

## Tools
Roblox Studio, Animation Editor, File → Publish
