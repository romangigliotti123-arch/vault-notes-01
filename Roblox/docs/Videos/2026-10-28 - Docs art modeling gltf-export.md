# Docs: art / modeling / gltf-export

[Open](https://create.roblox.com/docs/art/modeling/gltf-export.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on glTF export (beta). Covers use cases, supported components (meshes, textures, rigging/skinning, vertex colors, cages, FACS data), limitations (no animation data, inconsistent layered accessory support), permission rules for which assets can be exported, and steps to export from Explorer or the whole place.

## Tips
- [page](https://create.roblox.com/docs/art/modeling/gltf-export) **[[building-art-and-assets]]** Enable glTF export via File > Beta Features > glTF Export before use; the feature is still in beta and specs may change.
- [page](https://create.roblox.com/docs/art/modeling/gltf-export) **[[3d-modeling-rigging-and-animation]]** Use glTF export to run Avatar auto setup, then finalize meshes, cages or rigging in a third-party tool like Blender or Maya.
- [page](https://create.roblox.com/docs/art/modeling/gltf-export) **[[3d-modeling-rigging-and-animation]]** Do not expect animation data in glTF exports; animations must be recreated outside Studio.
- [page](https://create.roblox.com/docs/art/modeling/gltf-export) **[[3d-modeling-rigging-and-animation]]** Layered clothing accessories may misposition and will not deform to avatar bodies outside Roblox; verify them after export.
- [page](https://create.roblox.com/docs/art/modeling/gltf-export) **[[common-mistakes]]** Check asset permissions before exporting: Avatar Marketplace, acquired Creator Store, and unshared collaborator or public Open Use assets cannot be exported.
- [page](https://create.roblox.com/docs/art/modeling/gltf-export) **[[building-art-and-assets]]** Export only assets uploaded to your own or your group's account, or mesh/image assets explicitly shared with you, to avoid permission conflicts.
- [page](https://create.roblox.com/docs/art/modeling/gltf-export) **[[building-and-level-design]]** Export the entire place via File > Export as glTF to render the scene in another 3D application at high fidelity.
