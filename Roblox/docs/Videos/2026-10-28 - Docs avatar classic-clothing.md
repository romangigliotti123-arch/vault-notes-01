# Docs: avatar / classic-clothing

[Open](https://create.roblox.com/docs/avatar/classic-clothing.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox docs on creating, testing, uploading and managing 2D classic clothing (T-shirts, Shirts, Pants). Covers template sizes, Studio testing steps, upload via Creator Dashboard, and the 80 Robux upload fee.

## Tips
- [page](https://create.roblox.com/docs/avatar/classic-clothing) **[[ugc-and-avatar-economy]]** Classic clothing is the simplest avatar item: only an image editor and browser are needed, so it is a low-cost entry point to selling on the Marketplace.
- [page](https://create.roblox.com/docs/avatar/classic-clothing) **[[building-art-and-assets]]** For shirts and pants, download and modify the official template files rather than starting from a blank canvas, since they have fixed size requirements.
- [page](https://create.roblox.com/docs/avatar/classic-clothing) **[[building-art-and-assets]]** Keep shoe designs near the bottom of leg regions; designs extending too far up look like part of the pants.
- [page](https://create.roblox.com/docs/avatar/classic-clothing) **[[building-art-and-assets]]** Export classic clothing as .png or .jpg before testing and uploading.
- [page](https://create.roblox.com/docs/avatar/classic-clothing) **[[playtesting-and-feedback]]** Test classic clothing in Studio on a Block Avatar Rig before uploading, to confirm it looks as intended; testing is free.
- [page](https://create.roblox.com/docs/avatar/classic-clothing) **[[common-mistakes]]** Many user-generated avatars on the Marketplace do not support 2D classic clothing; check for modern 3D cosmetic options instead for rigid accessories.
- [page](https://create.roblox.com/docs/avatar/classic-clothing) **[[titles-descriptions]]** Write a clear Name and Description at upload; these fields help users find your assets.

## Numbers
- [page](https://create.roblox.com/docs/avatar/classic-clothing) Upload fee: **80 Robux per submission** (Fee to upload and sell a classic clothing item on the Marketplace)
- [page](https://create.roblox.com/docs/avatar/classic-clothing) T-shirt size: **512x512 px square** (Classic T-shirt image dimensions)
- [page](https://create.roblox.com/docs/avatar/classic-clothing) Shirt/pants template sizes: **128x128, 64x128, 128x64, 64x64 px** (Large square, tall rect, wide rect, small square template regions)

Roblox Studio, Creator Dashboard, Image editor (any)
