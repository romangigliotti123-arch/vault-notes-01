# Docs: matchmaking / analytics

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.

## Summary
Roblox docs page on the Custom matchmaking Analytics dashboard: how to access it, filter by place and date range (1 day to 90 days), switch between average and P10/P50/P90, and what each signal chart measures.

## Tips
- [page](https://create.roblox.com/docs/matchmaking/analytics) **[[analytics-metrics]]** Use the Analytics tab date range (previous day to last 90 days) to compare matchmaking performance across periods.
- [page](https://create.roblox.com/docs/matchmaking/analytics) **[[analytics-metrics]]** For metrics where lower is better (e.g. Estimate Ping, Age Difference), read P10 as best case and P90 as worst case.
- [page](https://create.roblox.com/docs/matchmaking/analytics) **[[analytics-metrics]]** Switch the Filter By menu between average, P10, P50 and P90 to avoid being misled by averages skewed by outliers.
- [page](https://create.roblox.com/docs/matchmaking/analytics) **[[matchmaking-and-teleport]]** Check the Current Configuration shown after selecting a place to confirm which custom matchmaking config applies; places without one show default Roblox matchmaking.

## Numbers
- [page](https://create.roblox.com/docs/matchmaking/analytics) Date range options: **previous day to last 90 days** (Matchmaking analytics dashboard date range selector)
- [page](https://create.roblox.com/docs/matchmaking/analytics) Percentiles offered: **P10, P50, P90 plus average** (Filter By menu on Analytics tab)
