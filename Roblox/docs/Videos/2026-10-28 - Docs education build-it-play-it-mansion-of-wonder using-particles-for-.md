# Docs: education / build-it-play-it-mansion-of-wonder / using-particles-for-actions

[Open](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/using-particles-for-actions.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Creator Docs tutorial on using ParticleEmitters as action feedback in the Mansion of Wonder lesson. Covers creating a named Burst emitter, setting texture, color and size, configuring SpreadAngle and burst properties (LightEmission, Drag, Lifetime, Rate, Speed), and disabling Enabled so a script can trigger it.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/using-particles-for-actions) **[[player-psychology-and-game-feel]]** Give feedback through multiple forms (visual, sound) since players with sound off or hearing impairment rely on visual cues, and low-vision players rely on audio.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/using-particles-for-actions) **[[vfx-and-particles]]** Name particle emitters exactly as the script expects, since scripts look them up by name.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/using-particles-for-actions) **[[vfx-and-particles]]** For a quick burst, set SpreadAngle X and Y to 360 so particles fly in all directions.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/using-particles-for-actions) **[[vfx-and-particles]]** Burst settings: LightEmission 0.4, Drag 8, Lifetime 0.6-1, Rate 50, Speed 40 for a firework-like explosion that fades quickly.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/using-particles-for-actions) **[[vfx-and-particles]]** Use min/max ranges for Lifetime and Rotation to add randomness so repeated effects feel less repetitive.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/using-particles-for-actions) **[[vfx-and-particles]]** Disable the emitter's Enabled property so it only plays when a script activates it.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/using-particles-for-actions) **[[first-session-onboarding]]** Pair arrows with a celebratory particle burst on task completion so first-time players know they succeeded and stay on track.
