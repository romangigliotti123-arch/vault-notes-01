# Docs: ai / accelerated-workflows

[Open](https://create.roblox.com/docs/ai/accelerated-workflows.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on AI tools in Studio: enabling AI/MCP beta features, connecting MCP-aware coding clients to Studio, starter project with LLM-friendly markdown, Rojo/Git workflows, and the feature catalogue (3D generation, speech/text APIs, Code Assist, Assistant, policies on moderation and training data).

## Tips
- [page](https://create.roblox.com/docs/ai/accelerated-workflows) **[[ai-and-tools]]** Enable Studio as MCP server via Assistant → … → Manage MCP Servers, and turn on needed features under File → Beta Features; GA features are on by default.
- [page](https://create.roblox.com/docs/ai/accelerated-workflows) **[[ai-and-tools]]** Point an MCP-aware client at the Studio MCP server so it can read the data model, create and run scripts, edit instances, and playtest.
- [page](https://create.roblox.com/docs/ai/accelerated-workflows) **[[ai-and-tools]]** Start from the starter project with LLM-friendly markdown context files so a coding harness can plan and build the first game quickly.
- [page](https://create.roblox.com/docs/ai/accelerated-workflows) **[[version-control-and-tooling]]** Use Rojo and Git to build and version control Roblox projects via the file system.
- [page](https://create.roblox.com/docs/ai/accelerated-workflows) **[[ai-and-tools]]** Bring your own API keys via Assistant → … → Manage API Keys to use Anthropic, OpenAI, or Google models.
- [page](https://create.roblox.com/docs/ai/accelerated-workflows) **[[ai-and-tools]]** Run all generated text through TextService:FilterStringAsync() before showing it to players, as required for LLM NPC dialogue.
- [page](https://create.roblox.com/docs/ai/accelerated-workflows) **[[age-ratings-moderation-and-tos]]** You are responsible for content generated in your games; follow Community Standards, since all generations pass moderation.
- [page](https://create.roblox.com/docs/ai/accelerated-workflows) **[[age-ratings-moderation-and-tos]]** Manage your data sharing preferences for AI training on Creator Hub.
- [page](https://create.roblox.com/docs/ai/accelerated-workflows) **[[building-art-and-assets]]** Use the mesh generator or MCP command to get a textured MeshPart from a text description.
- [page](https://create.roblox.com/docs/ai/accelerated-workflows) **[[building-art-and-assets]]** Use the material generator for seamless tiling MaterialVariants on large surfaces like terrain, floors and walls.
- [page](https://create.roblox.com/docs/ai/accelerated-workflows) **[[building-art-and-assets]]** Use Avatar Auto-Setup to automatically rig, cage and segment 3D models into animatable avatars.
- [page](https://create.roblox.com/docs/ai/accelerated-workflows) **[[scripting-and-performance]]** Use Code Assist for real-time completions based on script context and comments; the Assistant can run and write Luau and playtest.
