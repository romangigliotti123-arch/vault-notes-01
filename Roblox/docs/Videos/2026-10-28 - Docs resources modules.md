## Summary
Roblox docs page listing Developer modules: prebuilt social features (Selfie Mode, Merch Booth, Friends Locator, Spawn With Friends, Emote Bar, Profile Card, Photo Booth, Surface Art, Scavenger Hunt, Social Interactions). Each works out of the box on play and can be configured for different behavior.

## Tips
- [page](https://create.roblox.com/docs/resources/modules) **[[social-features-and-virality]]** Use built-in Developer modules to add social features quickly; they work as soon as you press play without extra code.
- [page](https://create.roblox.com/docs/resources/modules) **[[social-features-and-virality]]** Configure individual modules to change how they behave rather than accepting defaults if the default doesn't fit your game.
