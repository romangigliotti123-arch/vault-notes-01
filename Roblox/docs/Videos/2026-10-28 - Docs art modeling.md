# Docs: art / modeling

[Open](https://create.roblox.com/docs/art/modeling.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox official docs overview of custom 3D assets (meshes). Covers mesh types (environment, body parts, accessories), MeshPart vs parts, rigging/skinning, PBR textures, and Studio objects auto-created by the 3D Importer via naming suffixes (_Att, _OuterCage, _InnerCage). Points to resources for specs and Marketplace monetization.

## Tips
- [page](https://create.roblox.com/docs/art/modeling) **[[building-art-and-assets]]** Build meshes in a third-party tool like Blender or Maya and import into Studio; parts can't be created directly as custom shapes.
- [page](https://create.roblox.com/docs/art/modeling) **[[building-art-and-assets]]** Every mesh must meet general mesh specs; character and accessory meshes must also meet avatar/accessory specs for rigging and skinning data.
- [page](https://create.roblox.com/docs/art/modeling) **[[3d-modeling-rigging-and-animation]]** A basic custom asset needs at least one MeshPart and one texture image map.
- [page](https://create.roblox.com/docs/art/modeling) **[[3d-modeling-rigging-and-animation]]** Name meshes with _Att suffix to auto-create Attachments, _OuterCage/_InnerCage for WrapTarget/WrapLayer, so set these up in your modeling software.
- [page](https://create.roblox.com/docs/art/modeling) **[[3d-modeling-rigging-and-animation]]** Use rigging and skinning so meshes bend at joints instead of rotating as a single rigid piece (e.g. head bends at neck).
- [page](https://create.roblox.com/docs/art/modeling) **[[building-art-and-assets]]** Use PBR textures with multiple maps (color, roughness, reflectivity) for realistic shading across lighting environments.
- [page](https://create.roblox.com/docs/art/modeling) **[[ugc-and-avatar-economy]]** Meeting account requirements lets you sell mesh collections on Marketplace (avatar-ready models) or Creator Store (earn 100% of net proceeds).
- [page](https://create.roblox.com/docs/art/modeling) **[[3d-modeling-rigging-and-animation]]** Use the Calisthenics Tool and Clothing Validation Tool to test and validate assets before publishing.
