# Docs: education / resources / roblox-for-the-ap-csp-create-performance-task

[Open](https://create.roblox.com/docs/education/resources/roblox-for-the-ap-csp-create-performance-task.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox docs guide for teachers using Roblox Studio and Luau for the AP Computer Science Principles Create Performance Task. Covers why Luau suits CSP, a 12-hour milestone schedule, the project example with algorithms and abstraction, video/written requirements, and classroom tips to keep scope small and avoid Toolbox scripts.

## Tips
- [page](https://create.roblox.com/docs/education/resources/roblox-for-the-ap-csp-create-performance-task) **[[development-process-and-speed]]** Keep visuals simple: use basic block shapes and colors so students spend limited time on core logic rather than decoration.
- [page](https://create.roblox.com/docs/education/resources/roblox-for-the-ap-csp-create-performance-task) **[[development-process-and-speed]]** Plan needed scripts before coding: list each script, its location, and its function; ensure at least one function simplifies the code.
- [page](https://create.roblox.com/docs/education/resources/roblox-for-the-ap-csp-create-performance-task) **[[development-process-and-speed]]** Identify cuttable features upfront so scope can be reduced if time runs short.
- [page](https://create.roblox.com/docs/education/resources/roblox-for-the-ap-csp-create-performance-task) **[[building-art-and-assets]]** Avoid Toolbox assets unless every bundled script is removed; prepackaged scripts can conflict with your code and waste debugging time.
- [page](https://create.roblox.com/docs/education/resources/roblox-for-the-ap-csp-create-performance-task) **[[development-process-and-speed]]** Have a working prototype by hour 2 and document issues and their solutions as you go; change goals if a task proves too difficult.
- [page](https://create.roblox.com/docs/education/resources/roblox-for-the-ap-csp-create-performance-task) **[[scripting-and-performance]]** Write logical, reusable functions with parameters rather than trial-and-error code; reuse functions called from multiple places.
- [page](https://create.roblox.com/docs/education/resources/roblox-for-the-ap-csp-create-performance-task) **[[common-mistakes]]** Don't let students copy-paste or hack code together; the rubric expects a clearly structured algorithm with abstraction.
- [page](https://create.roblox.com/docs/education/resources/roblox-for-the-ap-csp-create-performance-task) **[[testing-debugging-and-qa]]** Keep the submission video under one minute and under 30 MB, showing the program's purpose and at least one significant feature.
- [page](https://create.roblox.com/docs/education/resources/roblox-for-the-ap-csp-create-performance-task) **[[development-process-and-speed]]** Students should have prior Roblox Studio or Luau experience, since the build window is only about 6-8 hours.
- [page](https://create.roblox.com/docs/education/resources/roblox-for-the-ap-csp-create-performance-task) **[[community-and-discord]]** Use Studio's collaboration features so students can edit the same script or own separate scripts, making individual contributions traceable.

## Numbers
- [page](https://create.roblox.com/docs/education/resources/roblox-for-the-ap-csp-create-performance-task) Prep time: **At least 2 hours preparing students, plus 12 hours minimum class time** (Recommended total for AP CSP Create PT in class)
- [page](https://create.roblox.com/docs/education/resources/roblox-for-the-ap-csp-create-performance-task) Coding time: **About 6-7 hours** (Approximate time students have to complete the code)
- [page](https://create.roblox.com/docs/education/resources/roblox-for-the-ap-csp-create-performance-task) Video length: **Under 1 minute, max 30 MB** (Required length and size limit for submission video)
- [page](https://create.roblox.com/docs/education/resources/roblox-for-the-ap-csp-create-performance-task) Student project scope: **6-8 hour timeframe** (Time window for abstractions and algorithms in a student project)
