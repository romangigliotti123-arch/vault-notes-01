# Docs: avatar / rigid-accessories / export

[Open](https://create.roblox.com/docs/avatar/rigid-accessories/export.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on exporting rigid accessory models from Blender (.fbx/.gltf) and Maya (.fbx) for import into Studio as Class.Model, then converting with the Accessory Fitting Tool. Covers export settings for scale, texture embedding, smoothing, units and axis.

## Tips
- [page](https://create.roblox.com/docs/avatar/rigid-accessories/export) **[[building-art-and-assets]]** Apply or delete all modifiers and project object modifiers before exporting a rigid accessory model, so mesh and attachment data export correctly.
- [page](https://create.roblox.com/docs/avatar/rigid-accessories/export) **[[3d-modeling-rigging-and-animation]]** In Blender FBX export, set Path Mode to Copy, enable Embed Textures, and set Apply Scalings to FBX Unit Scale to import at correct scale.
- [page](https://create.roblox.com/docs/avatar/rigid-accessories/export) **[[3d-modeling-rigging-and-animation]]** In Maya FBX export, enable Smooth Mesh and Referenced Asset Content, disable Animation, and set Units to Automatic and Up Axis to Y.
- [page](https://create.roblox.com/docs/avatar/rigid-accessories/export) **[[3d-modeling-rigging-and-animation]]** Import the exported .fbx into Studio as a Class.Model, then use the Accessory Fitting Tool to convert it into an accessory.
- [page](https://create.roblox.com/docs/avatar/rigid-accessories/export) **[[building-art-and-assets]]** Enable Embed Media in Maya export only if you need textures imported as .png.

## Tools
Blender, Maya, Roblox Studio, Accessory Fitting Tool
