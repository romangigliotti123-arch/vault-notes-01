## Summary
Roblox Creator Docs tutorial introducing Luau if statements. Covers the if/then syntax, comparison and math operators, checking a false condition, and using conditionals to test whether a variable is assigned and whether a property (Transparency) has a given value. Includes a hands-on part-color exercise in ServerScriptService.

## Tips
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-3/intro-to-if-statements) **[[luau-language-and-types]]** Indent the lines inside an if block so it is easy to see where the code chunk starts and stops.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-3/intro-to-if-statements) **[[scripting-and-performance]]** Check that a variable was assigned (e.g. if mysteryPart then) before using it, since a failed lookup like workspace.MysteryPart yields nil and throws an error.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-3/intro-to-if-statements) **[[luau-language-and-types]]** Use == for equality checks and ~= for inequality; a single = assigns rather than compares.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-3/intro-to-if-statements) **[[luau-language-and-types]]** Add a comment above each conditional describing what it evaluates, e.g. 'Evaluates as true if MysteryPart is fully opaque'.
