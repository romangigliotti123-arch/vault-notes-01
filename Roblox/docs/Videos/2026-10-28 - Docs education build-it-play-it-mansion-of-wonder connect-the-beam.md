## Summary
Roblox docs tutorial on connecting a beam between a player attachment and a goal attachment, enabling FaceCamera, and styling the beam with a repeating arrow texture (TextureMode Static), color, LightEmission and TextureSpeed for tutorial guidance.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/connect-the-beam) **[[first-session-onboarding]]** Use a beam between the player and goal as a visual tutorial cue so new players know where to go.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/connect-the-beam) **[[ui-ux-design]]** Enable FaceCamera on beams so they stay visible from any camera angle.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/connect-the-beam) **[[vfx-and-particles]]** Set TextureMode to Static so a beam's arrow texture repeats at its original size instead of stretching.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/connect-the-beam) **[[ui-ux-design]]** Use contrasting or saturated colors for guide beams so they draw attention and show players where to look.
