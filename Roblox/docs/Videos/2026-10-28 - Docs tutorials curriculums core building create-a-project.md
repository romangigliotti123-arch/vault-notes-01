# Docs: tutorials / curriculums / core / building / create-a-project

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/tutorials/curriculums/core/building/create-a-project.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox curriculum step for the Island Jump 3D platformer: create a project from the Baseplate template, delete the Baseplate part so only the SpawnLocation remains, then move on to Terrain Editor island building. Notes the Assistant-based and manual build tabs.

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/core/building/create-a-project) **[[development-process-and-speed]]** Start from a Studio template (e.g. Baseplate) to get a working project faster than building from scratch.
- [page](https://create.roblox.com/docs/tutorials/curriculums/core/building/create-a-project) **[[ai-and-tools]]** Studio's built-in Assistant can handle routine tasks like creating instances, setting properties and generating scripts, freeing time for creative work.
- [page](https://create.roblox.com/docs/tutorials/curriculums/core/building/create-a-project) **[[building-and-level-design]]** Delete the default Baseplate in Explorer and keep only the SpawnLocation before shaping your own terrain.

## Games
- **Island Jump**: 3D platformer used as the tutorial project; built from Baseplate template in the official curriculum.

## Tools
Roblox Studio, Studio Assistant, Explorer, Terrain Editor
