# Docs: art / accessories / creating-rigid / exporting

[Open](https://create.roblox.com/docs/art/accessories/creating-rigid/exporting.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on exporting a custom accessory mesh from Blender as FBX. Covers cleaning the scene, embedding textures, and setting FBX unit scale before export.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/exporting) **[[building-art-and-assets]]** Before exporting an accessory, delete extra objects like lights, cameras, and mannequins so only the accessory mesh is exported.
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/exporting) **[[building-art-and-assets]]** Apply all modifiers to the mesh object before exporting from Blender.
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/exporting) **[[3d-modeling-rigging-and-animation]]** In Blender FBX export, set Path Mode to Copy and enable Embed Textures so textures travel with the file.
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/exporting) **[[3d-modeling-rigging-and-animation]]** Set Apply Scalings to FBX Unit Scale in the Blender FBX export Transform section to avoid import scaling issues.
