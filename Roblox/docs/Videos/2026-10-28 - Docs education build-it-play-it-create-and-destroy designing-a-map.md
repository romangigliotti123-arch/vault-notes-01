## Summary
Roblox education page on level design for the Create and Destroy template. Teaches symmetrical map design: build one half, duplicate and rotate it for a fair multiplayer map. Covers opening the template in Studio (File > Open from File) and the template's contents: a starter island plus a prop palette.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/designing-a-map) **[[building-and-level-design]]** Build half the map, then duplicate and rotate it to create the other half; this symmetry keeps competitive multiplayer maps fair.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/designing-a-map) **[[building-and-level-design]]** Use the template's starter island and prop palette rather than a blank map when prototyping a city-style level.
