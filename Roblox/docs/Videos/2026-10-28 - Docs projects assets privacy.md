# Docs: projects / assets / privacy

[Open](https://create.roblox.com/docs/projects/assets/privacy.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs on Asset Privacy: Restricted vs Open Use access types for Images, Decals, and Meshes. Covers enabling the setting per creator or group, granting permissions to collaborators and games, revoking, and irreversible Open Use. Other asset types are unaffected.

## Tips
- [page](https://create.roblox.com/docs/projects/assets/privacy) **[[common-mistakes]]** Open Use is irreversible: once an asset is set to Open Use it cannot go back to Restricted. Confirm before switching.
- [page](https://create.roblox.com/docs/projects/assets/privacy) **[[common-mistakes]]** Game grants are permanent. Once a game is granted a restricted asset, that access cannot be revoked.
- [page](https://create.roblox.com/docs/projects/assets/privacy) **[[common-mistakes]]** Removing a creator as a friend does not revoke their permission on restricted assets. Revoke explicitly on the asset's Permissions page.
- [page](https://create.roblox.com/docs/projects/assets/privacy) **[[common-mistakes]]** Asset Privacy does not affect Audio, Video, Models, MeshParts, Animations, or Packages. If those fail to load, look elsewhere for the cause.
- [page](https://create.roblox.com/docs/projects/assets/privacy) **[[common-mistakes]]** A Decal can only be set to Open Use if its Image dependency is Open Use. Set the Image first.
- [page](https://create.roblox.com/docs/projects/assets/privacy) **[[common-mistakes]]** Avatar items need all dependent textures and meshes set to Open Use before Marketplace upload. Convert restricted primitives first.
- [page](https://create.roblox.com/docs/projects/assets/privacy) **[[common-mistakes]]** If a game uses a restricted asset in a script or saves a template place with it, the game itself must have permission. Otherwise the asset is invisible or silent at runtime.
- [page](https://create.roblox.com/docs/projects/assets/privacy) **[[ugc-and-avatar-economy]]** Restricted assets can still be listed as dependencies on the Creator Store, letting others use your models and packages without accessing your restricted dependencies.
- [page](https://create.roblox.com/docs/projects/assets/privacy) **[[ugc-and-avatar-economy]]** Use the Revamped Asset Manager to bulk-grant or bulk-open permissions across many assets instead of editing each one.
- [page](https://create.roblox.com/docs/projects/assets/privacy) **[[business-and-payouts]]** Enabling Asset Privacy does not change Creator Store or Marketplace distribution eligibility, use in published games, or sharing with collaborators.
- [page](https://create.roblox.com/docs/projects/assets/privacy) **[[team-and-budget]]** To grant a collaborator access, they must be your friend (individual) or you must hold the permission in the group. Groups: only group owners can enable group-level Asset Privacy.

## Numbers
- [page](https://create.roblox.com/docs/projects/assets/privacy) Default access for Images, Decals, Meshes: **Open Use unless Asset Privacy is enabled**
- [page](https://create.roblox.com/docs/projects/assets/privacy) Scope of Asset Privacy: **Only Images, Decals, Meshes created after enabling**
