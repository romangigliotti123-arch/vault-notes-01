# Docs: tutorials / use-case-tutorials / audio / play-background-music

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.

## Summary
Official Roblox docs tutorial on adding background music: create a Sound object in SoundService, set SoundId, play it via a LocalScript, then set Looped on and Volume around 0.25.

## Tips
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/audio/play-background-music) **[[building-art-and-assets]]** Parent background music Sound objects to SoundService so they play at the same volume everywhere, unlike sounds parented to parts which are positional.
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/audio/play-background-music) **[[sound-and-music]]** Lower background music Volume to around 0.25; uploaded tracks are often too loud for background use.
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/audio/play-background-music) **[[sound-and-music]]** Enable Looped on background music so it doesn't stop after one play-through.
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/audio/play-background-music) **[[scripting-and-performance]]** Play background music from a LocalScript in StarterPlayerScripts, since the sound plays per client.

## Numbers
