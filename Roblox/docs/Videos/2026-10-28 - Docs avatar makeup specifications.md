# Docs: avatar / makeup / specifications

[Open](https://create.roblox.com/docs/avatar/makeup/specifications.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on makeup export specifications: required objects (head mesh and cage named with TransferTarget_ prefix, TransferTexture_Eyes/Face/Lips meshes with incrementing numbers, optional eyebrows/eyelashes), texture limits, and eyebrow/eyelash cage and triangle requirements.

## Tips
- [page](https://create.roblox.com/docs/avatar/makeup/specifications) **[[ai-and-tools]]** Start from the provided Roblox makeup template head; it already has correct objects and naming. Do not rename or delete its data model, or import may fail.
- [page](https://create.roblox.com/docs/avatar/makeup/specifications) **[[building-art-and-assets]]** Name head mesh and cage with the TransferTarget_ prefix, and TransferTexture_Eyes_01, TransferTexture_Face_01, TransferTexture_Lips_01 (increment the number for extra regions).
- [page](https://create.roblox.com/docs/avatar/makeup/specifications) **[[thumbnails-icons]]** Keep makeup textures within the limits: up to 4K for in-game makeup creation, and 1K for makeup uploaded to the Marketplace.
- [page](https://create.roblox.com/docs/avatar/makeup/specifications) **[[3d-modeling-rigging-and-animation]]** Eyebrows and eyelashes need their own inner and outer cage, and each can't exceed 4k triangles and the maximum dimensions for its asset type.
- [page](https://create.roblox.com/docs/avatar/makeup/specifications) **[[building-art-and-assets]]** Check all accessory texture specs against Roblox's texture requirements, and read the PBR textures guidance before exporting.

## Numbers
- [page](https://create.roblox.com/docs/avatar/makeup/specifications) Makeup texture limit (in-game creation): **4K** (Max texture size for makeup created in-game)
- [page](https://create.roblox.com/docs/avatar/makeup/specifications) Makeup texture limit (Marketplace upload): **1K** (Max texture size for makeup uploaded to Marketplace)
- [page](https://create.roblox.com/docs/avatar/makeup/specifications) Eye accessory triangle budget: **4k triangles each** (Eyebrows and eyelashes, each individually)
