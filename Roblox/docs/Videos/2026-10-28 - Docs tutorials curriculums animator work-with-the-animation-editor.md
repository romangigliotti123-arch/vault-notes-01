## Summary
Roblox Creator Docs lesson on the Animation Editor: opening Clip Editor, preparing a rig, posing with the Rotate tool, duplicating keyframes for seamless looping, and creating a second pose to build a swimming animation.

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/animator/work-with-the-animation-editor) **[[building-art-and-assets]]** Open the Animation Editor via Avatar tab > Clip Editor; rig must be selected so part names display in the editor.
- [page](https://create.roblox.com/docs/tutorials/curriculums/animator/work-with-the-animation-editor) **[[building-art-and-assets]]** Turn off Rotate and Move snapping before posing so rig parts rotate freely.
- [page](https://create.roblox.com/docs/tutorials/curriculums/animator/work-with-the-animation-editor) **[[building-art-and-assets]]** Select the Rotate tool; if you see arrows instead of circular handles, switch to Rotate. Rotate from the torso outward: upper arms and thighs first, then hands and feet.
- [page](https://create.roblox.com/docs/tutorials/curriculums/animator/work-with-the-animation-editor) **[[building-art-and-assets]]** Copy the first pose's keyframe at 0:00 and paste it at the end of the timeline, then enable Loop so the animation repeats seamlessly.

## Numbers
- [page](https://create.roblox.com/docs/tutorials/curriculums/animator/work-with-the-animation-editor) Animation length in lesson: **1:00 (end keyframe for loop)** (Swimming example loops from 0:00 to 1:00)
- [page](https://create.roblox.com/docs/tutorials/curriculums/animator/work-with-the-animation-editor) Second pose position: **0.5** (Set in position indicator to place mid-animation keyframe)

## Tools
Roblox Studio Animation Editor, Clip Editor, Rig Generator
