## Summary
Roblox Education docs page for Galactic Speedway tutorial: how to add a vehicle model to the Garage folder via Cut/Paste Into, rename it, and ungroup/regroup it to edit later.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-galactic-speedway/add-to-the-garage) **[[building-and-level-design]]** Place vehicle models into the designated Garage folder using Cut then Paste Into (not Paste) so the game recognises them as garage vehicles.
- [page](https://create.roblox.com/docs/education/build-it-play-it-galactic-speedway/add-to-the-garage) **[[common-mistakes]]** If the speeder disappears after Cut and Paste Into, use undo (Ctrl+Z / Cmd+Z) and repeat Cut and Paste Into rather than recreating it.
- [page](https://create.roblox.com/docs/education/build-it-play-it-galactic-speedway/add-to-the-garage) **[[building-and-level-design]]** Give vehicle models descriptive names (e.g. 'The Lightning') via right-click Model > Rename so they are identifiable in Explorer.
- [page](https://create.roblox.com/docs/education/build-it-play-it-galactic-speedway/add-to-the-garage) **[[building-and-level-design]]** To edit a grouped model, ungroup it, make changes, then regroup all parts (Ctrl+G / Cmd+G) before placing it back in the Garage folder.

## Games
- **Galactic Speedway**: Education tutorial game; vehicles are stored as grouped models inside a Garage folder in Workspace.
