# Docs: tutorials / fundamentals / coding-2 / functions-and-events

[Open](https://create.roblox.com/docs/tutorials/fundamentals/coding-2/functions-and-events.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Beginner Roblox Studio tutorial series on Luau functions and events. Covers placing code in reusable functions, understanding scope, parameters and arguments, returning values, and using events (e.g. button clicks) to trigger functions. Practice builds an in-world button that raises a bridge.

## Tips
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-2/functions-and-events) **[[code-architecture-and-frameworks]]** Put repeated code into functions so it runs only when called, rather than duplicating it across scripts.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-2/functions-and-events) **[[code-architecture-and-frameworks]]** Use events to tell functions when to run (e.g. button clicks, touches) instead of running code unconditionally.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-2/functions-and-events) **[[luau-language-and-types]]** Understand variable scope: know where a local is visible so functions don't read or overwrite values they shouldn't.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-2/functions-and-events) **[[luau-language-and-types]]** Pass information in through parameters and return results with return values so functions stay reusable.
