# Docs: education / lesson-plans / digital-citizenship / lights-and-polish

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.

## Summary
Teacher lesson plan (Roblox Education digital citizenship series) on "Lights and polish": students implement feedback from peers, then a brief lesson on Post Processing Effects (e.g., lighting effects) to change a game's look and feel, followed by independent project work on the obstacle course and a wrap-up showcase.

## Tips
- [page](https://create.roblox.com/docs/education/lesson-plans/digital-citizenship/lights-and-polish) **[[playtesting-and-feedback]]** Give peer feedback using a structured handout, then have each builder pick one goal from it and implement a change in the next session.
- [page](https://create.roblox.com/docs/education/lesson-plans/digital-citizenship/lights-and-polish) **[[building-art-and-assets]]** Use Post Processing Effects (lighting-based) to dramatically change a game's look and feel without rebuilding assets.
- [page](https://create.roblox.com/docs/education/lesson-plans/digital-citizenship/lights-and-polish) **[[development-process-and-speed]]** Ask three peers for help before asking the instructor; this builds collaboration and reduces blocking time.

## Numbers
- [page](https://create.roblox.com/docs/education/lesson-plans/digital-citizenship/lights-and-polish) Lesson timing: **5 min intro, 15 min feedback, 5 min lesson, 30 min project work, 5 min wrap-up** (Education lesson plan duration breakdown)
- [page](https://create.roblox.com/docs/education/lesson-plans/digital-citizenship/lights-and-polish) Peer help rule: **Ask 3 peers before the teacher** (Ask 3 Before Me classroom practice)

## Tools
Post Processing Effects (Roblox Studio lighting)
