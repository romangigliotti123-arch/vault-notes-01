# Docs: resources / beyond-the-dark

[Open](https://create.roblox.com/docs/resources/beyond-the-dark.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on how the official Beyond the Dark demo (Kerr-Newman DSR-14 space station, non-copylocked) was built in Studio. Covers modular building architecture, custom skinned creature avatars, layered clothing with cage deformers, SoundService sound placement, and UI with parallax maps and holo-screens. Notes may be outdated.

## Tips
- [page](https://create.roblox.com/docs/resources/beyond-the-dark) **[[building-and-level-design]]** Build environments modularly so you can move from early layouts to a polished game as fast as possible.
- [page](https://create.roblox.com/docs/resources/beyond-the-dark) **[[3d-modeling-rigging-and-animation]]** Follow the documented best practices for building skinned custom avatars before importing them into Studio.
- [page](https://create.roblox.com/docs/resources/beyond-the-dark) **[[vfx-and-particles]]** Add visual effects, sound effects and lights directly to custom characters to enhance creature presence.
- [page](https://create.roblox.com/docs/resources/beyond-the-dark) **[[3d-modeling-rigging-and-animation]]** Use the layered clothing system with the cage deformer feature to fit suits and clothing onto characters.
- [page](https://create.roblox.com/docs/resources/beyond-the-dark) **[[sound-and-music]]** Configure SoundService and place sounds deliberately to maximise immersion.
- [page](https://create.roblox.com/docs/resources/beyond-the-dark) **[[ui-ux-design]]** Use a literal in-world UI layer, such as parallax map effects and in-world holo-screens, to add atmosphere.

## Games
- **Beyond the Dark**: Official Roblox Studio showcase demo; demonstrates modular building, custom characters, layered clothing, SoundService and UI techniques for high-fidelity environments.

## Tools
Roblox Studio, Layered clothing system, Cage deformer, SoundService
