## Summary
Official Roblox Studio docs page on Terrain Editor basics: creating an island shape with Add, refining with Smooth and Subtract, and painting sand/mud for beaches. Beginner-level tutorial for terrain building.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/terrain-tools) **[[building-and-level-design]]** Use Add with a blue cursor drag to block out the island, then undo with Ctrl+Z (⌘+Z on Mac) if the result is not right.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/terrain-tools) **[[building-and-level-design]]** Break up hard straight edges from the initial building area so the terrain looks natural rather than square.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/terrain-tools) **[[building-and-level-design]]** Use the Smooth tool to average out highs and lows and make jagged terrain look more natural.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/terrain-tools) **[[building-and-level-design]]** Rotate the camera to inspect terrain from multiple angles, not only from the top, to catch problems.

## Tools
Terrain Editor, Add tool, Smooth tool, Subtract tool
