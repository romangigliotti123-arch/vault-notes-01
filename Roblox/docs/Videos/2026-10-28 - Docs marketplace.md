# Docs: marketplace

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/marketplace.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox docs overview of the Marketplace, where users buy avatar items (bodies, heads, clothing, accessories, animations) and where creators can sell 3D accessories, clothing and character bodies. Covers the Avatar Editor Service for in-game access, creator commission, and the policy pages to review before publishing. Explicitly distinguishes the Marketplace from the Creator Store.

## Tips
- [page](https://create.roblox.com/docs/marketplace) **[[ugc-and-avatar-economy]]** Before uploading, review Marketplace policy, Intellectual property and Moderation docs so assets meet Roblox technical and community standards.
- [page](https://create.roblox.com/docs/marketplace) **[[ugc-and-avatar-economy]]** Only 3D accessories, clothing and character bodies can be sold on the Marketplace; check the fees and commissions page since fees vary by item type.
- [page](https://create.roblox.com/docs/marketplace) **[[common-mistakes]]** Do not confuse the Marketplace (avatar items for sale) with the Creator Store (models, images, plugins for building games).
- [page](https://create.roblox.com/docs/marketplace) **[[monetisation-other]]** Developers can embed Marketplace access in their experience via the Avatar Editor Service and earn a commission on Marketplace item sales made within their game.
