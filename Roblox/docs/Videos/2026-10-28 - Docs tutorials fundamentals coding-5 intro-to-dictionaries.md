## Summary
Roblox official tutorial on Lua dictionaries (tables with key-value pairs). Covers syntax, bracket vs dot access, using instances as keys, using a player-name variable as a key in PlayerAdded, and iterating with pairs(). Includes optional challenges (trap part, points comparison, cipher).

## Tips
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-5/intro-to-dictionaries) **[[luau-language-and-types]]** Use consistent data types for dictionary keys; mixing strings and variables as keys yields inconsistent results and confuses other coders.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-5/intro-to-dictionaries) **[[luau-language-and-types]]** Use tableName.keyName for dictionaries describing an object; use tableName["keyName"] for collections like a list of players.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-5/intro-to-dictionaries) **[[luau-language-and-types]]** When a key is a variable, access it without quotes (playerPoints[name]); quoting it makes it a literal string key instead.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-5/intro-to-dictionaries) **[[luau-language-and-types]]** Use pairs() to iterate dictionaries with unknown size; ipairs() for arrays; generic 'in' loops also work without either.
