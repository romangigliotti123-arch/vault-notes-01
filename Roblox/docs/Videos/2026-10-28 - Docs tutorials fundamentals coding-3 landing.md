## Summary
Roblox official docs series intro to conditionals: teaches if/then logic, with elseif and else for multiple scenarios. Covers trap parts, power-up parts, and awarding points, with prerequisites of Studio navigation plus variables and functions.

## Tips
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-3/landing) **[[first-session-onboarding]]** Use conditionals to gate actions (rooms, purchases) behind requirements, e.g. team checks or ownership checks before letting players act.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-3/landing) **[[core-loops-and-game-design]]** Build traps and power-ups as conditional parts that only affect Humanoids/avatars, not arbitrary parts.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-3/landing) **[[luau-language-and-types]]** Use if/then for single conditions, and elseif/else to cover multiple scenarios instead of stacking separate if blocks.
