## Summary
Roblox Education docs page (Build It, Play It: Galactic Speedway). Shows how to playtest a driftspeeder by flying it via the robot NPC's Race menu, and troubleshoot missing speeders: the model must sit in the Garage folder and contain a Body part, with no extra models.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-galactic-speedway/test-the-speeder) **[[testing-debugging-and-qa]]** Playtest the vehicle in-game after building; stop playtest with Shift+F5 and fix issues before moving on.
- [page](https://create.roblox.com/docs/education/build-it-play-it-galactic-speedway/test-the-speeder) **[[testing-debugging-and-qa]]** If a vehicle is missing from the selection screen, confirm it sits inside the Garage folder in Explorer; move with Cut and Paste Into.
- [page](https://create.roblox.com/docs/education/build-it-play-it-galactic-speedway/test-the-speeder) **[[testing-debugging-and-qa]]** Ensure each speeder model has a Body part grouped within it; the game code only loads speeders containing a Body.
- [page](https://create.roblox.com/docs/education/build-it-play-it-galactic-speedway/test-the-speeder) **[[testing-debugging-and-qa]]** Remove extra models nested in the speeder model; they can cause loading issues.

## Tools
Roblox Studio Playtest (Play), Explorer window, Cut / Paste Into
