# Docs: education / support / designing-studio-templates

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/education/support/designing-studio-templates.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox Education docs on creating and distributing Roblox Studio templates for students: build a curated template (modified existing or new), publish it under a user or group, enable public playability and Allow Copying, and share the game URL so students open a copy in Studio.

## Tips
- [page](https://create.roblox.com/docs/education/support/designing-studio-templates) **[[team-and-budget]]** Publish templates under a group only when multiple developers must edit; groups cost a one-time 100 Robux (about $1.25 USD).
- [page](https://create.roblox.com/docs/education/support/designing-studio-templates) **[[common-mistakes]]** Do not let students join the template's group; a student may accidentally make unintended modifications to the template.
- [page](https://create.roblox.com/docs/education/support/designing-studio-templates) **[[development-process-and-speed]]** Position the camera where students should start before publishing; the first view students see is the view saved at publish time.
- [page](https://create.roblox.com/docs/education/support/designing-studio-templates) **[[ugc-and-avatar-economy]]** Add screenshots and an icon on the game page; they are optional but boost presentation and give an extra branding opportunity.

## Numbers
- [page](https://create.roblox.com/docs/education/support/designing-studio-templates) Group publishing cost: **100 Robux one-time (about $1.25 USD)** (Required to create a group for publishing templates)

## Tools
Roblox Studio, Experience Settings (Permissions, Playability, Configure Place, Allow Copying), Download a Copy (.rbxl)
