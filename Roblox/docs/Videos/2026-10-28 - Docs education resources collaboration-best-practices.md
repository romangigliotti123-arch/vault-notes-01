# Docs: education / resources / collaboration-best-practices

[Open](https://create.roblox.com/docs/education/resources/collaboration-best-practices.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox education docs on classroom collaboration: setting guidelines, conflict resolution via "I" messages and interests-over-positions, peer help ("Ask Three Before Me"), skill-shares, and group role rotation and shared to-do lists. Mostly classroom pedagogy, not game-business advice.

## Tips
- [page](https://create.roblox.com/docs/education/resources/collaboration-best-practices) **[[team-and-budget]]** Assign group roles (e.g. world builder, coder) and rotate them so members learn new skills and discover unexpected interests.
- [page](https://create.roblox.com/docs/education/resources/collaboration-best-practices) **[[development-process-and-speed]]** Have group members manage a shared collective to-do list so anyone can pick up a task when idle.
- [page](https://create.roblox.com/docs/education/resources/collaboration-best-practices) **[[community-and-discord]]** Set clear team norms: build your own work, ask permission before using others' assets, never vandalize or disparage others' work.
- [page](https://create.roblox.com/docs/education/resources/collaboration-best-practices) **[[team-and-budget]]** Resolve team conflicts by discussing interests and goals rather than positions; use 'I feel' messages instead of 'You did' messages.
- [page](https://create.roblox.com/docs/education/resources/collaboration-best-practices) **[[mindset-and-strategy]]** Encourage peers to help each other first (ask three peers before the lead) to build independence and reduce bottlenecks.

## Numbers
- [page](https://create.roblox.com/docs/education/resources/collaboration-best-practices) Skill-share length: **5-10 minutes** (Student-led tutorial during independent work time in classroom)
- [page](https://create.roblox.com/docs/education/resources/collaboration-best-practices) Peers asked before instructor: **3** ('Ask Three Before Me' rule for student questions)
