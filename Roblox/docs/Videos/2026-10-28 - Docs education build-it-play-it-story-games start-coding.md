## Summary
Roblox Creator Docs page on starting to code in the "Build It, Play It" story games lesson. Explains that code lives in Luau scripts, shows how to locate the StoryManager script in Explorer under StarterGUI/GameGUI, describes comment syntax (--), and shows the template loop (Reset, story code between dashes, Write, PlayAgain) where the player writes the story.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-story-games/start-coding) **[[scripting-and-performance]]** Put game logic in separate scripts, one per responsibility; Roblox games often use a distinct script for each thing the game must do.
- [page](https://create.roblox.com/docs/education/build-it-play-it-story-games/start-coding) **[[code-architecture-and-frameworks]]** Use comments (--) to leave notes for future coders; comments do not change program behaviour.
