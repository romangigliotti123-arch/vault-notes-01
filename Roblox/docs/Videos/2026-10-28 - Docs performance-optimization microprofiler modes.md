# Docs: performance-optimization / microprofiler / modes

[Open](https://create.roblox.com/docs/performance-optimization/microprofiler/modes.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on MicroProfiler modes: Timers (labels with times and call counts, bar graphs), Counters (memory and instance stats, use Developer Console for memory), Groups and Threads (web UI only, per-group and per-thread task times), and Hidden (desktop only, hides bar graph while keeping menu open).

## Tips
- [page](https://create.roblox.com/docs/performance-optimization/microprofiler/modes) **[[scripting-and-performance]]** Use MicroProfiler Timers mode to list tasks with processing times and call counts; horizontal bars highlight the busiest tasks.
- [page](https://create.roblox.com/docs/performance-optimization/microprofiler/modes) **[[optimization-and-streaming]]** Use MicroProfiler Groups or Threads mode (web UI) to see average, max and total task times by group or thread to find frame-time bottlenecks.
- [page](https://create.roblox.com/docs/performance-optimization/microprofiler/modes) **[[analytics-metrics]]** Pin Counters mode graphs to watch min and max values of instance count and memory usage over time.
- [page](https://create.roblox.com/docs/performance-optimization/microprofiler/modes) **[[optimization-and-streaming]]** Use the Developer Console rather than MicroProfiler Counters mode to identify memory issues; use X-ray view to find when problematic allocations occur.
- [page](https://create.roblox.com/docs/performance-optimization/microprofiler/modes) **[[testing-debugging-and-qa]]** Use Hidden mode (desktop UI) to keep the MicroProfiler menu open while pausing and unpausing the line graph, and to save frame data.

## Tools
MicroProfiler, Developer Console, X-ray view
