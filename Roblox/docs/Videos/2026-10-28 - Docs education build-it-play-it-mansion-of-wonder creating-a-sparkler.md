## Summary
Roblox Education tutorial showing how to build a particle-effect sparkler tool: add the pre-made Sparkler Set from the Toolbox Inventory, customize the SparklerParticle emitter's texture and color gradient, then move the tool into StarterPack. Part of the Mansion of Wonder "Build It, Play It" challenge.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/creating-a-sparkler) **[[vfx-and-particles]]** Build tool effects by attaching a ParticleEmitter to an Attachment inside the tool, then customize Texture, Color and Size/Speed.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/creating-a-sparkler) **[[vfx-and-particles]]** Use a ColorSequence with multiple arrows to make particles shift color over their lifetime, e.g. blue to yellow.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/creating-a-sparkler) **[[vfx-and-particles]]** Tune Size and Speed after setting the gradient to get the intended effect.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/creating-a-sparkler) **[[building-art-and-assets]]** Start from a pre-made tool set from the Toolbox Inventory (My Models) to skip building from scratch.
