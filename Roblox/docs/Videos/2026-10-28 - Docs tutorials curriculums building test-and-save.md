# Docs: tutorials / curriculums / building / test-and-save

[Open](https://create.roblox.com/docs/tutorials/curriculums/building/test-and-save.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox docs page on playtesting an obby (Test, Test Here, Run modes) and publishing to Roblox (File > Publish, Game details fields, saving cadence every ten minutes).

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/building/test-and-save) **[[playtesting-and-feedback]]** Playtest often to confirm the obby is completable; use Test or Test Here, not Run, so your avatar is inserted and you can check jump distances between platforms.
- [page](https://create.roblox.com/docs/tutorials/curriculums/building/test-and-save) **[[development-process-and-speed]]** Publish to Roblox every ten minutes or after a big change, since closing Studio without publishing loses all unsaved edits.
- [page](https://create.roblox.com/docs/tutorials/curriculums/building/test-and-save) **[[development-process-and-speed]]** If File > Publish is greyed out, stop the playtest first.
- [page](https://create.roblox.com/docs/tutorials/curriculums/building/test-and-save) **[[titles-descriptions]]** Fill in Name, Genre, optional Subgenre, and a summary Description in the Game details window before the first publish.
- [page](https://create.roblox.com/docs/tutorials/curriculums/building/test-and-save) **[[thumbnails-icons]]** Upload an icon and thumbnail in the Game details window; they display on the game's main details page.

## Numbers
- [page](https://create.roblox.com/docs/tutorials/curriculums/building/test-and-save) Recommended publish interval: **every 10 minutes or after big changes** (Official docs guidance for saving Studio work to Roblox)
