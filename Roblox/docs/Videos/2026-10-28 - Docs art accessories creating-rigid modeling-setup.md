# Docs: art / accessories / creating-rigid / modeling-setup

[Open](https://create.roblox.com/docs/art/accessories/creating-rigid/modeling-setup.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox docs tutorial on box-modeling a treasure chest accessory in Blender: basic block shape, bevelled rounded lid, side and front insets via loop cuts, extrusions, and completing the metal border. Modeling steps only; no game-business advice.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/modeling-setup) **[[building-art-and-assets]]** 
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/modeling-setup) **[[building-art-and-assets]]** Keep accessory geometry within the polycount budget and avoid IP that infringes other creators' work, inside or outside Roblox.
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/modeling-setup) **[[building-art-and-assets]]** After bevelling, run Merge Vertices by Distance at 0.01 so the mesh shares vertices instead of leaving near-duplicate verts.
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/modeling-setup) **[[building-art-and-assets]]** Use Clamp Overlap when bevelling to avoid self-intersecting geometry on rounded edges.

## Numbers
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/modeling-setup) Bevel segments: **6** (Segment count for the rounded chest lid bevel)
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/modeling-setup) Merge distance: **0.01** (Merge Vertices by Distance threshold)
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/modeling-setup) Lid height: **about half the body height** (Extrusion length for the chest lid)
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/modeling-setup) Loop cuts per direction: **2** (Vertical and horizontal loop cuts for front and side insets)
