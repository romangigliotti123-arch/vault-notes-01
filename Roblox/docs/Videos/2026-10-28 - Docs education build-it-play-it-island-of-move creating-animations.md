# Docs: education / build-it-play-it-island-of-move / creating-animations

[Open](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/creating-animations.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Studio docs tutorial on creating animations in the Animation Editor: opening it from the Avatar tab, selecting a rig part, turning off snapping, and moving/focusing the camera to pose figures. Poses are later connected by Studio into an animation.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/creating-animations) **[[building-art-and-assets]]** Open the Animation Editor via Avatar tab > Animation; it appears at the bottom of the screen.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/creating-animations) **[[3d-modeling-rigging-and-animation]]** Turn off the Rotate and Move snapping tools before posing so rig parts move freely.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/creating-animations) **[[3d-modeling-rigging-and-animation]]** Hold Shift while moving the camera to slow camera movement for finer posing control.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/creating-animations) **[[3d-modeling-rigging-and-animation]]** Select a part then press F to focus the camera on it before posing.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/creating-animations) **[[3d-modeling-rigging-and-animation]]** Create animations as two or more key poses; Studio interpolates between them during playback.
