# Docs: creator-programs / standout-games

[Open](https://create.roblox.com/docs/creator-programs/standout-games.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page for the Standout Games Home sort, which curates novel games. Explains qualifying traits (genre, gameplay depth, visual style), recommended optimizations, and what to prepare before nominating via survey.

## Tips
- [page](https://create.roblox.com/docs/creator-programs/standout-games) **[[discovery-algorithm]]** Standout Games is a curated Home sort; nominate via the survey. Curation team reviews on an ongoing basis and emails the result.
- [page](https://create.roblox.com/docs/creator-programs/standout-games) **[[game-ideas-and-genres]]** Target underrepresented genres: RPG, strategy, puzzle, shooter. Genre mash-ups and Roblox-native avatar/social/cross-platform blends are sought.
- [page](https://create.roblox.com/docs/creator-programs/standout-games) **[[common-mistakes]]** Copies or reskins of popular Roblox games are a hard sell for Standout Games. Make something with distinct mechanics.
- [page](https://create.roblox.com/docs/creator-programs/standout-games) **[[core-loops-and-game-design]]** Build deep gameplay, metagame systems and skillful challenges with high replayability; these keep players returning.
- [page](https://create.roblox.com/docs/creator-programs/standout-games) **[[ui-ux-design]]** Push visual boundaries (hyper-realistic 3D, stylized 2.5D sprites, high-fidelity avatars) so players think 'Wait, that's Roblox?'
- [page](https://create.roblox.com/docs/creator-programs/standout-games) **[[cross-platform-and-console]]** Recommended: optimize for both console and mobile devices. Not required but improves consideration.
- [page](https://create.roblox.com/docs/creator-programs/standout-games) **[[3d-modeling-rigging-and-animation]]** Recommended: support custom or R15 rigs, layered accessories and dynamic heads.
- [page](https://create.roblox.com/docs/creator-programs/standout-games) **[[events-and-seasonal-content]]** Recommended: use experience events for regular updates and future events.
- [page](https://create.roblox.com/docs/creator-programs/standout-games) **[[trailers-and-video-marketing]]** Before applying, upload a gameplay trailer and record footage of core mechanics for the nomination survey.
- [page](https://create.roblox.com/docs/creator-programs/standout-games) **[[localization-and-international]]** Before applying, localize the game to reach a global audience and improve accessibility for international players.
- [page](https://create.roblox.com/docs/creator-programs/standout-games) **[[thumbnails-icons]]** Before applying, review existing thumbnails to ensure they comply with Roblox best practices.
