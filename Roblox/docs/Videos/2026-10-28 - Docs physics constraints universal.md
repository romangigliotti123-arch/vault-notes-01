## Summary
Roblox engine docs for UniversalConstraint: keeps two attachments' SecondaryAxis perpendicular (used for drive shafts, robotics). Covers orientation requirements and LimitsEnabled/MaxAngle/Restitution cone limits.

## Tips
- [page](https://create.roblox.com/docs/physics/constraints/universal) **[[physics-pathfinding-and-npc-ai]]** Make both attachments' SecondaryAxis perpendicular to each other; the green L indicator confirms correct orientation. Misoriented axes make the universal move incorrectly.
- [page](https://create.roblox.com/docs/physics/constraints/universal) **[[physics-pathfinding-and-npc-ai]]** Enable LimitsEnabled to restrict tilt to a cone using MaxAngle; set Restitution to control elasticity when the limit is reached.
