## Summary
Roblox Creator Docs tutorial page on testing a project with Play mode and saving it by publishing to Roblox. Covers camera/movement controls for testing, verifying behavior before submitting code, and publishing regularly (every ten minutes) to keep work safe and editable from any computer.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-story-games/test-and-save) **[[development-process-and-speed]]** Test code frequently by clicking Play; testing often makes it easier to find where a mistake was made.
- [page](https://create.roblox.com/docs/education/build-it-play-it-story-games/test-and-save) **[[development-process-and-speed]]** Publish the whole project to Roblox every ten minutes while working, or after any big change, to save progress.
- [page](https://create.roblox.com/docs/education/build-it-play-it-story-games/test-and-save) **[[testing-debugging-and-qa]]** Stop the playtest after each check so changes are verified in isolation before building further features.

## Numbers
- [page](https://create.roblox.com/docs/education/build-it-play-it-story-games/test-and-save) Publish interval: **every 10 minutes** (Recommended frequency for publishing while working, per docs)

## Tools
Roblox Studio, Play button, File > Publish
