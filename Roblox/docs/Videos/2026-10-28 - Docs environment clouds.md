# Docs: environment / clouds

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/environment/clouds.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on dynamic clouds: enabling Clouds under Terrain, and the Cover, Density and Color properties with example values. Clouds only render when parented under Terrain; Color is also affected by Lighting and Atmosphere properties.

## Tips
- [page](https://create.roblox.com/docs/environment/clouds) **[[building-art-and-assets]]** Clouds only render if the Clouds object is parented under Terrain; it can live elsewhere for organization or replication.
- [page](https://create.roblox.com/docs/environment/clouds) **[[building-art-and-assets]]** Set cloud motion through global wind (Workspace wind), since wind controls drift direction and speed.
- [page](https://create.roblox.com/docs/environment/clouds) **[[building-art-and-assets]]** Tune cloud Color together with Lighting and Atmosphere properties, which also affect cloud color; experiment to get the atmosphere you want.
- [page](https://create.roblox.com/docs/environment/clouds) **[[building-art-and-assets]]** Use low Density (around 0.1) for light, semi-translucent clouds; higher Density (around 0.3+) for heavy, dark stormy clouds.

## Numbers
- [page](https://create.roblox.com/docs/environment/clouds) Cover range: **0 (sparse) to 1 (full cover); examples 0.65, 0.8**
- [page](https://create.roblox.com/docs/environment/clouds) Density example values: **0.1 (light) and 0.3 (heavier)**
- [page](https://create.roblox.com/docs/environment/clouds) Color example values: **[255,255,255] white; [75,50,255] blue-violet**

## Tools
Roblox Studio Explorer, Clouds object, Lighting, Atmosphere
