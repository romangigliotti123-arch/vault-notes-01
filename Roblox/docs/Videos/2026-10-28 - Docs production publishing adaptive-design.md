# Docs: production / publishing / adaptive-design

[Open](https://create.roblox.com/docs/production/publishing/adaptive-design.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox official docs on adaptive design: making games look and work across screen sizes, orientations, and input types (mouse/keyboard, touch, gamepad, VR). Covers four core principles: input fluidity, responsive layout, dynamic sizing, and legibility/contrast.

## Tips
- [page](https://create.roblox.com/docs/production/publishing/adaptive-design) **[[first-session-onboarding]]** Make every action triggerable via gamepad buttons/D-pad, keyboard shortcuts, and touch; test each input mode so core gameplay and menus are natural on any device.
- [page](https://create.roblox.com/docs/production/publishing/adaptive-design) **[[first-session-onboarding]]** Update prompts and tooltips to the active input type (e.g. 'Press A' on gamepad, 'Pinch' on touch, 'Shift+A' on keyboard) using platform-familiar icons and language.
- [page](https://create.roblox.com/docs/production/publishing/adaptive-design) **[[building-art-and-assets]]** Use responsive layout patterns: collapse less-important buttons into a menu button on small screens, show them in full on desktop; adapt to landscape and portrait if supported.
- [page](https://create.roblox.com/docs/production/publishing/adaptive-design) **[[building-art-and-assets]]** Build UI panels that react to parent size, e.g. split-view side panels that collapse on narrow screens and expand on wide ones.
- [page](https://create.roblox.com/docs/production/publishing/adaptive-design) **[[building-art-and-assets]]** Use content-driven sizing and automatic text wrapping so labels don't overflow or become unreadable as screen size changes.
- [page](https://create.roblox.com/docs/production/publishing/adaptive-design) **[[building-art-and-assets]]** Tie UI sizing to user text/UI scaling accessibility settings so larger preferences produce larger, more readable UI.
- [page](https://create.roblox.com/docs/production/publishing/adaptive-design) **[[building-art-and-assets]]** Choose font sizes readable at the smallest expected mobile size; test on real devices; avoid decorative or thin fonts.
- [page](https://create.roblox.com/docs/production/publishing/adaptive-design) **[[building-art-and-assets]]** Use high contrast between text/buttons and backgrounds, and strong hierarchy via size, color, or placement, for varied in-game lighting and TV viewing distances.
