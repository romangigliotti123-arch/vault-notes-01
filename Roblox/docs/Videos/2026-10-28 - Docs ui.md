# Docs: ui

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.

## Summary
Roblox official docs overview of the UI system: on-screen vs in-game containers (SurfaceGui, BillboardGui), core GuiObject types (Frame, Label, Button, TextBox), positioning/layout tools (UIListLayout, UIStroke, UIGradient), universal styling, and interactive frameworks (ProximityPrompt, UI and 3D drag detectors).

## Tips
- [page](https://create.roblox.com/docs/ui) **[[ui-ux-design]]** Use Position, Size, AnchorPoint and ZIndex to control placement and layering of GuiObjects rather than hardcoding screen coordinates.
- [page](https://create.roblox.com/docs/ui) **[[ui-ux-design]]** Use UIListLayout or grid layouts for repeated item sequences instead of manually positioning each element.
- [page](https://create.roblox.com/docs/ui) **[[ui-ux-design]]** Use tweening to transition GuiObjects between states for smooth animation and dynamic visual feedback.
- [page](https://create.roblox.com/docs/ui) **[[ui-ux-design]]** Apply universal styling (CSS-like overrides) to share property overrides across many UI instances instead of setting each one manually.

## Tools
Roblox Studio UI objects, Style Editor, UIListLayout, UIStroke
