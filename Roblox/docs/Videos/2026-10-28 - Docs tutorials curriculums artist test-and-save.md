# Docs: tutorials / curriculums / artist / test-and-save

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/tutorials/curriculums/artist/test-and-save.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Docs page on the final VFX tutorial step: playtesting with Test or Test Here (avatar inserted) versus Run, and publishing to Roblox via File > Publish to save progress and create a UniverseID.

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/artist/test-and-save) **[[ab-testing-and-experiments]]** Playtest often using Test or Test Here so your avatar spawns; Run skips avatar insertion, which blocks testing in-game VFX interactions.
- [page](https://create.roblox.com/docs/tutorials/curriculums/artist/test-and-save) **[[playtesting-and-feedback]]** Playtest VFX in the real game flow, not just in the Studio viewport, to confirm emitters fire and look correct.
- [page](https://create.roblox.com/docs/tutorials/curriculums/artist/test-and-save) **[[development-process-and-speed]]** Publish to Roblox every ten minutes or after a big change to avoid losing edits if Studio closes.
- [page](https://create.roblox.com/docs/tutorials/curriculums/artist/test-and-save) **[[testing-debugging-and-qa]]** Mouse input is disabled during a playtest; press 1 on the keyboard to regain mouse access to Studio.

## Numbers
- [page](https://create.roblox.com/docs/tutorials/curriculums/artist/test-and-save) Publish interval: **every 10 minutes or after a big change** (Roblox docs recommendation for saving work via Publish)
