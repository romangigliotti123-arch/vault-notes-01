# Docs: education / lesson-plans / digital-citizenship / animating-characters

[Open](https://create.roblox.com/docs/education/lesson-plans/digital-citizenship/animating-characters.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox education lesson plan for students to design a custom walk animation (exported 3D animation, keyposes) and swap it into an obstacle course game using an Animation Swap Script, followed by peer feedback and redesign.

## Tips
- [page](https://create.roblox.com/docs/education/lesson-plans/digital-citizenship/animating-characters) **[[core-loops-and-game-design]]** Plan the animation goal and reference material before building; collect reference images or act out motions first.
- [page](https://create.roblox.com/docs/education/lesson-plans/digital-citizenship/animating-characters) **[[development-process-and-speed]]** Use keyposes (key moments of motion, e.g. crouch before jump) to build animations pose by pose.
- [page](https://create.roblox.com/docs/education/lesson-plans/digital-citizenship/animating-characters) **[[testing-debugging-and-qa]]** After swapping an animation ID in the script, test in-game to confirm the new animation replaced the default walk; repeat the process if it fails.
- [page](https://create.roblox.com/docs/education/lesson-plans/digital-citizenship/animating-characters) **[[playtesting-and-feedback]]** Get peer feedback using a structured handout that asks for observations and one recommendation; treat feedback as a growth opportunity even if you disagree.
- [page](https://create.roblox.com/docs/education/lesson-plans/digital-citizenship/animating-characters) **[[community-and-discord]]** Practice civil, constructive feedback online and in person when reviewing others' work.

## Numbers
- [page](https://create.roblox.com/docs/education/lesson-plans/digital-citizenship/animating-characters) Lesson timing: **Total 60 min: intro 5, plan 5, design tutorial 25, add animations 10, feedback 10, wrap-up 5** (Classroom lesson plan duration breakdown)
- [page](https://create.roblox.com/docs/education/lesson-plans/digital-citizenship/animating-characters) Planning time: **2-4 minutes to decide animation and collect references** (Students' animation planning phase in class)
- [page](https://create.roblox.com/docs/education/lesson-plans/digital-citizenship/animating-characters) Recap sharing: **2-3 students share planned animations** (Class recap after planning phase)
