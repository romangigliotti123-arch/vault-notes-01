# Docs: studio / explorer

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/studio/explorer.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Studio Explorer window docs: navigating the instance hierarchy, reparenting, inserting objects, duplicate/paste actions, folder organization, and search syntax (name, property, bespoke, ancestry, combined queries).

## Tips
- [page](https://create.roblox.com/docs/studio/explorer) **[[building-and-level-design]]** Use Folders to group related objects (e.g. all environmental AudioPlayers) so the Explorer hierarchy stays logical and easy to navigate.
- [page](https://create.roblox.com/docs/studio/explorer) **[[building-and-level-design]]** Use Paste Into to paste one shared item (e.g. a Texture) into multiple selected parents at once instead of pasting individually.
- [page](https://create.roblox.com/docs/studio/explorer) **[[building-and-level-design]]** Use Paste Into At Original Location to keep 3D objects at their original CFrame position when pasting into a new parent.
- [page](https://create.roblox.com/docs/studio/explorer) **[[common-mistakes]]** When searching for names with spaces, wrap the full name in double quotes (e.g. tag:"Light Source") or the search logic treats spaces as a combined query.

## Tools
Roblox Studio Explorer window, Studio search input (Ctrl+Shift+X / Cmd+Shift+X)
