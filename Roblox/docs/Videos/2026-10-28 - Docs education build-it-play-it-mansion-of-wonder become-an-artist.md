## Summary
Official Roblox docs lesson for the Mansion of Wonder education template: opening the template in Studio, closing extra windows, and keeping Explorer and Properties open. Sets up the FX artist role where players design blaster effects.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/become-an-artist) **[[development-process-and-speed]]** Open the provided template first; it includes starter world and code so you can skip initial setup and focus on customizing.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/become-an-artist) **[[ui-ux-design]]** Keep only the Explorer and Properties windows open in Studio for a clearer workspace; reopen others later from the Window menu.

## Games
- **Mansion of Wonder**: Educational carnival ride template where players defend a cart with magic blasters; learners build the FX for those blasts.
