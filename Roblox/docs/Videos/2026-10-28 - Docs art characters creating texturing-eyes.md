# Docs: art / characters / creating / texturing-eyes

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/art/characters/creating/texturing-eyes.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Creator Docs page on texturing eye meshes in Studio's Texture Paint mode for a non-human character look. Covers joining eye objects, painting outer shadow, outer eye color, inner eye and pupils with specific brush radii, then separating the meshes by loose parts and renaming them.

## Tips
- [page](https://create.roblox.com/docs/art/characters/creating/texturing-eyes) **[[building-art-and-assets]]** Increase texture image resolution before painting eyes so fine details like pupils render sharply.
- [page](https://create.roblox.com/docs/art/characters/creating/texturing-eyes) **[[building-art-and-assets]]** Join both eye meshes before texture painting so both eyes receive identical texture work at the same time.
- [page](https://create.roblox.com/docs/art/characters/creating/texturing-eyes) **[[building-art-and-assets]]** Paint in order: fully black base, then outer eye color, then inner eye, then pupils, so layers stack correctly.
- [page](https://create.roblox.com/docs/art/characters/creating/texturing-eyes) **[[building-art-and-assets]]** Hide head, teeth and tongue meshes in the viewport while painting eyes, keeping only eye meshes visible.

## Numbers
- [page](https://create.roblox.com/docs/art/characters/creating/texturing-eyes) Brush radius, base black shadow: **50px, strength 1.0** (Outer eye shadow step in Texture Paint)
- [page](https://create.roblox.com/docs/art/characters/creating/texturing-eyes) Brush radius, outer eye color: **75px, strength 1.0** (Deep yellow outer eye, 4-6 clicks per eye)
- [page](https://create.roblox.com/docs/art/characters/creating/texturing-eyes) Brush radius, inner eye and pupils: **5px** (Red inner eye; bright red pupils; hold F to resize)

## Tools
Roblox Studio Texture Paint, Blender-style Object/Edit mode workflow
