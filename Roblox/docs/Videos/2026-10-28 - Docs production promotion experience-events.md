# Docs: production / promotion / experience-events

[Open](https://create.roblox.com/docs/production/promotion/experience-events.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs on experience events and update announcements: creating events (limits, thumbnails, privacy, place selection), event discovery surfaces (detail page, group page, Trending Events charts with 1,000 RSVP threshold), notifications, event attribution via GameJoinContext, update announcements (60-char limit, once every 3 days), and the Off-Platform Featuring program eligibility.

## Tips
- [page](https://create.roblox.com/docs/production/promotion/experience-events) **[[development-process-and-speed]]** Create events as private first; switch to public when ready to promote. Private events don't appear on the experience detail page.
- [page](https://create.roblox.com/docs/production/promotion/experience-events) **[[thumbnails-icons]]** Use a unique event thumbnail different from your experience thumbnails to increase player engagement with the event.
- [page](https://create.roblox.com/docs/production/promotion/experience-events) **[[first-session-onboarding]]** Set event place to a non-start place only if intended; event-surface joiners spawn in the event place rather than the start place.
- [page](https://create.roblox.com/docs/production/promotion/experience-events) **[[updates-live-ops]]** Announce updates with new, exciting, accessible info (new areas, skills, achievements); avoid vague entries like 'bug fixes'.
- [page](https://create.roblox.com/docs/production/promotion/experience-events) **[[updates-live-ops]]** Avoid overwhelming players: announcements are limited to once every three days; keep them spaced out.
- [page](https://create.roblox.com/docs/production/promotion/experience-events) **[[updates-live-ops]]** Write event descriptions summarizing key updates and incentives such as event-exclusive badges or merch.
- [page](https://create.roblox.com/docs/production/promotion/experience-events) **[[analytics-metrics]]** Read update stats: Views, Visit rate (visits from notification), Unfollow rate. Watch unfollow rate as a negative signal.
- [page](https://create.roblox.com/docs/production/promotion/experience-events) **[[analytics-metrics]]** Read event attribution: check GameJoinContext EventId in PlayerAdded to identify event participants and personalize their experience.
- [page](https://create.roblox.com/docs/production/promotion/experience-events) **[[social-features-and-virality]]** Share the event details page URL on and off platform via the share button or 'Copy Event Details URL' in the Creator Dashboard.
- [page](https://create.roblox.com/docs/production/promotion/experience-events) **[[trend-research-and-validation]]** Events must be public, active within last 7 days and have 1,000+ RSVPs to appear in Trending Events in Experiences.
- [page](https://create.roblox.com/docs/production/promotion/experience-events) **[[updates-live-ops]]** For Off-Platform Featuring, submit at least 7 days before event start; best events run 7-30 days; avoid editing after submission.
- [page](https://create.roblox.com/docs/production/promotion/experience-events) **[[thumbnails-icons]]** High-quality visuals and complete, accurate metadata (title, description, schedule, thumbnails) improve Off-Platform Featuring selection odds.

## Numbers
- [page](https://create.roblox.com/docs/production/promotion/experience-events) Max ongoing or upcoming events: **10** (Maximum published events per experience at once)
- [page](https://create.roblox.com/docs/production/promotion/experience-events) Update character limit: **60 characters** (Announcement update text limit)
- [page](https://create.roblox.com/docs/production/promotion/experience-events) Update announcement frequency: **once every 3 days** (Minimum interval between update announcements)
- [page](https://create.roblox.com/docs/production/promotion/experience-events) RSVPs needed for Trending Events: **1,000** (Minimum RSVPs to appear in Trending Events in Experiences sort)
- [page](https://create.roblox.com/docs/production/promotion/experience-events) Trending event recency: **started within last 7 days** (Event must be active and started within 7 days for trending)
- [page](https://create.roblox.com/docs/production/promotion/experience-events) Off-Platform submission lead time: **at least 7 days before event start** (Required submission lead for Off-Platform Featuring)
- [page](https://create.roblox.com/docs/production/promotion/experience-events) Best event run length: **7-30 days** (Stated duration of events that perform best for featuring)
- [page](https://create.roblox.com/docs/production/promotion/experience-events) Minimum creator age for Off-Platform Featuring: **13 years** (Plus linked email address required)
