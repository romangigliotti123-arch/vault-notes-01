# Docs: education / build-it-play-it-island-of-move / opening-the-template

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.

## Summary
Official Roblox education tutorial step: open the "Move It Simulator" template in Studio, close extra left-side windows, keep Explorer and Properties open. Explains the simulator premise: players move on a track to earn stars, level up after three stars, and move faster.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/opening-the-template) **[[development-process-and-speed]]** Start from the built-in Move It Simulator template, which includes simulator code and a starter world, then customize it rather than building from scratch.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/opening-the-template) **[[studio-business-funding-and-publishing]]** If Studio shows extra windows on first launch, close the left-side ones and keep Explorer and Properties open on the right for a cleaner workspace.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/opening-the-template) **[[version-control-and-tooling]]** If Explorer or Properties are missing, toggle them on from the Window menu.

## Numbers
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/opening-the-template) Stars to level up: **3 stars per level-up**

## Tools
Roblox Studio, Move It Simulator template, Explorer, Properties
