## Summary
Roblox Limited Use License for downloadable Roblox-provided software (SDKs, models, docs). Covers a revocable, non-transferable permission to use the software only to incorporate it into apps deployed on Roblox; bans use with competing services, removing notices, and harmful code. Also covers feedback licensing, an as-is disclaimer, and termination with required destruction of copies.
