## Summary
Roblox Studio docs page on saving a project by publishing it to Roblox. Publishing saves to your account without making the game public. Covers the File > Publish steps, naming and describing the project, and the shortcut for later saves.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/save-by-publishing) **[[development-process-and-speed]]** Publish to Roblox every ten minutes while working, or after a big change, to save progress. Publishing does not make the game public.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/save-by-publishing) **[[development-process-and-speed]]** Use File > Publish or Alt+P (Mac: Option+P) to re-save later. Name and description can be changed afterwards.

## Numbers
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/save-by-publishing) publish interval: **every 10 minutes** (Recommended frequency for publishing while working on a project)
