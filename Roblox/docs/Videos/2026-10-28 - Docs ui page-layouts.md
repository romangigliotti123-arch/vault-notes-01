## Summary
Roblox API docs page on UIPageLayout: parenting it to a UI container makes each sibling GuiObject a page, navigable via scripting (Next/Previous/JumpToIndex). Includes a sample transition script and Command Bar commands for previewing pages in Studio.

## Tips
- [page](https://create.roblox.com/docs/ui/page-layouts) **[[ui-ux-design]]** Use UIPageLayout for tabbed modals, tutorials, and character customization screens; each sibling GuiObject becomes a page.
- [page](https://create.roblox.com/docs/ui/page-layouts) **[[ui-ux-design]]** Drive page changes with UIPageLayout:Next() and Previous() from a client-side script in the layout's container.
- [page](https://create.roblox.com/docs/ui/page-layouts) **[[building-and-level-design]]** Preview individual pages in Studio without playing by selecting the UIPageLayout and running Command Bar commands like JumpToIndex(0) for the first page.
