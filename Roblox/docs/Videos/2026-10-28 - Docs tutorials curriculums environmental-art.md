# Docs: tutorials / curriculums / environmental-art

[Open](https://create.roblox.com/docs/tutorials/curriculums/environmental-art.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox official docs curriculum on environmental art: a five-chapter course building a laser tag FPS environment, covering greybox level design, polished third-party assets, an asset library, world construction, and memory/performance optimization across devices.

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/environmental-art) **[[building-and-level-design]]** Greybox the environment with simple shapes first to test how players will experience gameplay before investing in polished assets.
- [page](https://create.roblox.com/docs/tutorials/curriculums/environmental-art) **[[building-art-and-assets]]** Replace greybox with polished assets made in third-party modeling tools once layout and gameplay are validated.
- [page](https://create.roblox.com/docs/tutorials/curriculums/environmental-art) **[[building-art-and-assets]]** Import and configure assets in a central asset library inside the game for easy access and reuse across the world.
- [page](https://create.roblox.com/docs/tutorials/curriculums/environmental-art) **[[optimization-and-streaming]]** Keep frame rate and performance high across devices, especially low-memory ones, using memory and performance strategies from the optimization chapter.

## Tools
