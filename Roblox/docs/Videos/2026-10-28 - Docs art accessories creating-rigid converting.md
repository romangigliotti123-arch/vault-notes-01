# Docs: art / accessories / creating-rigid / converting

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/art/accessories/creating-rigid/converting.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on fitting a rigid MeshPart to a mannequin with the Accessory Fitting Tool (AFT) and converting it into a Class.Accessory. Covers panel steps, asset type/attachment selection, previewing and adjusting, generating the accessory, and testing it with Avatar Setup.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/converting) **[[building-art-and-assets]]** Judge rigid accessory fit using the AFT preview window and default character; the clothing mannequin in the viewport does not accurately show how rigid accessories attach.
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/converting) **[[building-art-and-assets]]** Set the asset type to Accessory and choose the attachment location (e.g. Back) before fitting, since this determines where the accessory attaches to the body.
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/converting) **[[building-art-and-assets]]** If you accidentally select another object while adjusting, click back into the AFT panel to reselect the accessory and resume with Move, Scale, and Rotate.
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/converting) **[[building-art-and-assets]]** Test the generated accessory by equipping it to a character with the Avatar Setup tool before publishing or saving it.

## Tools
Accessory Fitting Tool (AFT), Avatar Setup tool, Roblox Studio Avatar tab
