## Summary
Roblox Studio beginner animation tutorial: opening the Island of Move template, arranging the workspace (close left-side windows, keep Explorer and Properties), and playtesting the track-based star-collecting game with Test mode and the Play/Stop buttons.

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/animator/get-started) **[[building-art-and-assets]]** Start animation learning from a Roblox-provided template (e.g. Island of Move) that already contains working gameplay code and environment.
- [page](https://create.roblox.com/docs/tutorials/curriculums/animator/get-started) **[[development-process-and-speed]]** Close unused Studio windows and keep only Explorer and Properties open to reduce clutter while working on a task.
- [page](https://create.roblox.com/docs/tutorials/curriculums/animator/get-started) **[[playtesting-and-feedback]]** Playtest the template before editing so you understand the gameplay loop before changing anything.

## Games
- **Island of Move**: Roblox-provided template: players move along a track to earn stars; a starting point for animation lessons.
