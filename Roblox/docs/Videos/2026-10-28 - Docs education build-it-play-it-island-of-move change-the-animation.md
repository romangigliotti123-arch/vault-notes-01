# Docs: education / build-it-play-it-island-of-move / change-the-animation

[Open](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/change-the-animation.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on replacing the template's default walk animation. Covers finding WalkAnimationID in Explorer, pasting an animation asset ID from the Creator Dashboard, testing with WASD, and troubleshooting glitchy or wrong animations.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/change-the-animation) **[[building-art-and-assets]]** To swap the walk animation, search Explorer for 'walk', select WalkAnimationID, and paste your animation asset ID into its Value field.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/change-the-animation) **[[building-art-and-assets]]** Save the animation in the Animation Editor after every change, or updates will not appear in-game.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/change-the-animation) **[[3d-modeling-rigging-and-animation]]** Make the first and last poses identical (copy the first keyframe and paste at the end of the timeline) to prevent a skipping loop.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/change-the-animation) **[[3d-modeling-rigging-and-animation]]** Keep the rig inside the white grid in the Animation Editor so it does not clip through walls or the ground.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/change-the-animation) **[[3d-modeling-rigging-and-animation]]** Ensure the WalkAnimationID Value contains only a number. Extra text means the wrong or no animation plays.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/change-the-animation) **[[common-mistakes]]** If the animation you edited does not play, confirm you published it through the Animation Editor; unpublished changes won't load.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/change-the-animation) **[[building-art-and-assets]]** Re-copy the asset ID from Creator Dashboard > Development Items > Animations > Configure > Copy Asset ID if paste fails.
