## Summary
Roblox Studio docs page on Snap to Grid settings for map building. Covers setting the move snap to 4 studs to align 4x4 and 8x8 tiles, then placing SpawnLocation objects (starting points) on the map, first on the main island and second balanced at equal distance from center.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/snap-to-grid) **[[building-and-level-design]]** Set Snap to Grid move value to 4 studs so 4x4 small and 8x8 large tiles line up with each other.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/snap-to-grid) **[[building-and-level-design]]** Place the most important elements first, such as starting locations and largest map features, before smaller details.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/snap-to-grid) **[[building-and-level-design]]** Drag objects by their red and blue arrows with the Move tool; grabbing the piece body can make it move oddly.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/snap-to-grid) **[[building-and-level-design]]** Keep both SpawnLocations an equal distance from the map center to keep the game balanced.

## Numbers
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/snap-to-grid) Default move snap: **1 stud** (Default Move tool increment in Studio)
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/snap-to-grid) Recommended move snap: **4 studs** (Aligns with 4x4 small tiles)
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/snap-to-grid) Large tile size: **8x8 studs** (Palette tile piece size)
