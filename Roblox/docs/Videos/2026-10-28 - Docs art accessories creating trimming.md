# Docs: art / accessories / creating / trimming

[Open](https://create.roblox.com/docs/art/accessories/creating/trimming.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Creator Docs tutorial on trimming a clothing mesh in Blender for a long-sleeve shirt: delete unwanted vertices in Wireframe mode, apply Subdivision Surface, Shade Smooth, then scale and position the shirt over the mannequin body mesh.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/creating/trimming) **[[building-art-and-assets]]** Start clothing from a clean mesh: duplicate the mannequin body mesh and trim it down to the garment shape rather than modelling from scratch.
- [page](https://create.roblox.com/docs/art/accessories/creating/trimming) **[[building-art-and-assets]]** Enable Wireframe mode in Blender's viewport when trimming, so you can see and select the vertices you want to delete.
- [page](https://create.roblox.com/docs/art/accessories/creating/trimming) **[[3d-modeling-rigging-and-animation]]** Apply a Subdivision Surface modifier with default settings, then Shade Smooth, to remove the grid-like surface before sculpting detail.
- [page](https://create.roblox.com/docs/art/accessories/creating/trimming) **[[3d-modeling-rigging-and-animation]]** Scale clothing only slightly and let it rest loosely over the mannequin; it does not need a perfect fit at this stage.
- [page](https://create.roblox.com/docs/art/accessories/creating/trimming) **[[building-art-and-assets]]** Set the body mesh to unselectable in Blender while editing the clothing to prevent accidental edits to the mannequin.

## Tools
