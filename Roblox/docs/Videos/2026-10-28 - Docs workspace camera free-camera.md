# Docs: workspace / camera / free-camera

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/workspace/camera/free-camera.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs for the debug free camera (freecam). Toggle with Left Shift+P in Studio playtests or the live client (owner/editors only). Covers movement, FOV, roll, a config menu (speed/stiffness, UI visibility, Player Lock, post-processing) and Ctrl+Left Shift+G/C/B/N shortcuts to hide UI for clean shots. Freecam also suits spectating and debugging.

## Tips
- [page](https://create.roblox.com/docs/workspace/camera/free-camera) **[[trailers-and-video-marketing]]** Use freecam with hidden UI (Ctrl+Left Shift+C/G/B/N) to capture clean cinematic screenshots and trailer footage without HUD clutter.
- [page](https://create.roblox.com/docs/workspace/camera/free-camera) **[[trailers-and-video-marketing]]** Narrow the field of view with the mouse wheel or X/Y for tighter telephoto framing on distant subjects in shots.
- [page](https://create.roblox.com/docs/workspace/camera/free-camera) **[[trailers-and-video-marketing]]** Use Dutch-angle roll (Z/C or L1/R1) for dynamic shots; double-tap roll to snap back to level.
- [page](https://create.roblox.com/docs/workspace/camera/free-camera) **[[trailers-and-video-marketing]]** Lower the config-menu Stiffness for smoother, eased camera moves; raise it for snappy, tightly-following motion.

## Tools
Roblox Studio, Free camera mode (freecam), Input Action System (IAS)
