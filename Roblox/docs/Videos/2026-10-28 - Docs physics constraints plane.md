# Docs: physics / constraints / plane

## Summary
Roblox engine docs for PlaneConstraint. The constraint moves both attachments onto a plane whose normal is Attachment0's primary axis; both assemblies stay free to translate and rotate unless otherwise constrained. Attachment1 orientation is irrelevant.

## Tips
- [page](https://create.roblox.com/docs/physics/constraints/plane) **[[physics-pathfinding-and-npc-ai]]** Set Attachment0's orientation to define the plane: its primary axis is the plane normal. Attachment1's orientation has no effect on the plane.
- [page](https://create.roblox.com/docs/physics/constraints/plane) **[[physics-pathfinding-and-npc-ai]]** Remember both parent assemblies stay free to translate and rotate unless other constraints limit them; PlaneConstraint alone does not pin either part.
