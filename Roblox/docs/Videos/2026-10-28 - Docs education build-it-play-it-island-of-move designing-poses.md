# Docs: education / build-it-play-it-island-of-move / designing-poses

[Open](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/designing-poses.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Studio docs on creating animation poses in the Animation Editor: setting a neutral start pose, crouch anticipation pose, peak-of-jump pose, copying the first pose to the end for a seamless loop, testing with Looping, refining with extra poses and keyframe timing, and exporting.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/designing-poses) **[[3d-modeling-rigging-and-animation]]** Break an animation into key poses (neutral, anticipation, extreme, return) first; Studio interpolates between keyframes into smooth motion.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/designing-poses) **[[3d-modeling-rigging-and-animation]]** Pose from torso-connected parts outward (shoulder before hand) to keep the rig's pose logical.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/designing-poses) **[[3d-modeling-rigging-and-animation]]** Only move the LowerTorso when repositioning the rig; moving other parts disconnects body parts from the rig.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/designing-poses) **[[3d-modeling-rigging-and-animation]]** Select parts in the Animation Editor hierarchy rather than clicking the model, especially for small parts like hands.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/designing-poses) **[[3d-modeling-rigging-and-animation]]** Exaggerate poses (wider arms, head twist) so the motion reads clearly and feels exciting.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/designing-poses) **[[3d-modeling-rigging-and-animation]]** Copy the first pose and paste it at the final frame so the animation loops seamlessly back to its start.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/designing-poses) **[[3d-modeling-rigging-and-animation]]** Add extra poses to show anticipation, exaggerate motion, or convey personality; this moves animations from okay to polished.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/designing-poses) **[[3d-modeling-rigging-and-animation]]** Drag keyframes left or right in time to make motion feel snappier or more realistic.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/designing-poses) **[[3d-modeling-rigging-and-animation]]** Re-export the animation after every change; the in-game version only updates on export.

## Numbers
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/designing-poses) Anticipation pose timing: **one third of animation length (e.g. 0:09 in a 1:00 clip)**
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/designing-poses) Example animation length: **1:00 (keyframes at start, ~0:09, middle, and 1:00)**

## Tools
Roblox Studio Animation Editor, Rotate tool, Move tool
