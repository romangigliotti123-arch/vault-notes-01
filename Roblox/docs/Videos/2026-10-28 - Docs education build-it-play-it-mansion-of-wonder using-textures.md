## Summary
Roblox Education docs page on textures for particle emitters. Explains that particle visuals are textures (2D images) identified by asset ID, and shows how to swap the Texture property of a BlastParticles emitter in Studio to change its look.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/using-textures) **[[vfx-and-particles]]** Set a particle emitter's look by pasting a texture asset ID into its Texture property in Properties; the emitter then emits that image as particles.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/using-textures) **[[vfx-and-particles]]** Reuse one texture across several effects (e.g. blast and explosion) and vary its appearance by changing the emitter settings instead of creating new art.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/using-textures) **[[building-art-and-assets]]** Textures can be any 2D image, including custom drawings, not just the provided starter pack.

## Tools
Roblox Studio, Properties window, Explorer
