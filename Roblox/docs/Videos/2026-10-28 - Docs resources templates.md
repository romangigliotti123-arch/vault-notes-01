# Docs: resources / templates

## Summary
Roblox Creator Docs overview of Studio starter templates (Platformer, UGC Homestore, Laser Tag, FPS System, Racing, Baseplate, Modern City, Village, Castle, Suburban, Pirate Island, Classic Obby, Starting Place, Line Runner, Capture the Flag, Team/FFA Arena, Combat, Concert, Move It Simulator, Mansion of Wonder, Flat Terrain, Classic Racing, Classic Baseplate). Describes what each uncopylocked template includes for starting projects.

## Tips
- [page](https://create.roblox.com/docs/resources/templates) **[[development-process-and-speed]]** Start from a matching template (e.g. Obby, Racing, FPS, Combat) to get working mechanics and objects instead of building core systems from scratch.
- [page](https://create.roblox.com/docs/resources/templates) **[[building-and-level-design]]** Use modular template objects (Modern City walls/windows/doors, Castle, Suburban) and snap them together to create varied buildings quickly.
- [page](https://create.roblox.com/docs/resources/templates) **[[monetisation-other]]** If selling UGC, use the UGC Homestore template; items you already published to the Marketplace auto-populate its store when you publish the template as your own game.
- [page](https://create.roblox.com/docs/resources/templates) **[[combat-and-gameplay-systems]]** Customize Laser Tag blaster attributes (damage, ammo capacity, recoil, spread) rather than rewriting FPS weapon logic.

## Numbers
- [page](https://create.roblox.com/docs/resources/templates) Capture the Flag round timer: **5 minutes per round** (Capture the Flag template timer; teams split blue vs red)
- [page](https://create.roblox.com/docs/resources/templates) Baseplate grid: **4x4 studs** (Baseplate template floor texture aligns with stud measurements)
