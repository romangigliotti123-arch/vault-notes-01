## Summary
Roblox Creator Docs page on Activity History, a shared log in Studio (Window menu) and the Creator Hub showing key game changes with who made them and when. Lists which events (place config, game config, monetization, notifications, collaboration permissions) appear in Studio, Creator Hub, or both. Covers filtering and the ⋯ menu links to settings.

## Tips
- [page](https://create.roblox.com/docs/projects/activity-history) **[[team-and-budget]]** Use Activity History (Window menu in Studio, or Creator Hub) to audit who changed what and when across a shared game.
- [page](https://create.roblox.com/docs/projects/activity-history) **[[team-and-budget]]** Filter Activity History by event type or collaborator when the log is large to find specific changes quickly.
- [page](https://create.roblox.com/docs/projects/activity-history) **[[common-mistakes]]** Check Activity History after unexpected changes to paid access, price, or private server settings to trace who made them.
- [page](https://create.roblox.com/docs/projects/activity-history) **[[ai-and-tools]]** Use the ⋯ menu on an event to jump straight to the related setting in Studio or Creator Hub.

## Tools
