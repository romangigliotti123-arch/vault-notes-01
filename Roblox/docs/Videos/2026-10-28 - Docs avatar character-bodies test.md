# Docs: avatar / character-bodies / test

[Open](https://create.roblox.com/docs/avatar/character-bodies/test.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on testing avatar character bodies. Gives a checklist of tests to run in Blender (geometry, textures, rigging/skinning via posing, FACS face data, cage mesh coverage, attachment points) and in Studio (movement, lighting and skin tones, animations, facial expressions, clothing fit, accessory placement).

## Tips
- [page](https://create.roblox.com/docs/avatar/character-bodies/test) **[[testing-debugging-and-qa]]** Test character body components often while iterating in your modeling tool and Studio; early testing avoids reworking time-intensive rigging, skinning, and caging.
- [page](https://create.roblox.com/docs/avatar/character-bodies/test) **[[3d-modeling-rigging-and-animation]]** In Blender, confirm body part geometry follows Roblox geometry specifications before moving on.
- [page](https://create.roblox.com/docs/avatar/character-bodies/test) **[[3d-modeling-rigging-and-animation]]** Use Blender's posing tools to check rigging and skinning quality of the character body.
- [page](https://create.roblox.com/docs/avatar/character-bodies/test) **[[3d-modeling-rigging-and-animation]]** Confirm FACS face animation data is present and correctly configured in your character model.
- [page](https://create.roblox.com/docs/avatar/character-bodies/test) **[[3d-modeling-rigging-and-animation]]** Manually verify cage meshes completely and tightly cover the character model and follow Roblox outer cage specifications.
- [page](https://create.roblox.com/docs/avatar/character-bodies/test) **[[3d-modeling-rigging-and-animation]]** Manually verify attachment points are correctly positioned and oriented per Roblox attachment specifications.
- [page](https://create.roblox.com/docs/avatar/character-bodies/test) **[[building-art-and-assets]]** Check textures against Roblox texture specifications when texturing the character.
- [page](https://create.roblox.com/docs/avatar/character-bodies/test) **[[ugc-and-avatar-economy]]** Test how the character looks under various lighting environments and skin tone colors in Studio.
- [page](https://create.roblox.com/docs/avatar/character-bodies/test) **[[ugc-and-avatar-economy]]** Equip various clothing items in Studio to check fit and catch unexpected cosmetic issues.
- [page](https://create.roblox.com/docs/avatar/character-bodies/test) **[[ugc-and-avatar-economy]]** Equip various accessory items in Studio to verify rigid accessory placement and orientation.
- [page](https://create.roblox.com/docs/avatar/character-bodies/test) **[[3d-modeling-rigging-and-animation]]** Cycle through common facial animations in Studio to ensure the character can perform standard expressions.
- [page](https://create.roblox.com/docs/avatar/character-bodies/test) **[[3d-modeling-rigging-and-animation]]** Use animations and test environments in Studio to verify rigging, skinning, and movement quality.
- [page](https://create.roblox.com/docs/avatar/character-bodies/test) **[[testing-debugging-and-qa]]** Use Roblox's uncopylocked testing place file in Studio for quick access to test environments and testing features.
