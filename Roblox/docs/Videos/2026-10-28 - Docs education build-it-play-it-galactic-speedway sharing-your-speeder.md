## Summary
Roblox Education docs page for Galactic Speedway: how to save a driftspeeder model to Roblox as an asset, enable Creator Store distribution so friends can copy it, and load a friend's shared model from Inventory via the Toolbox in Studio.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-galactic-speedway/sharing-your-speeders) **[[ugc-and-avatar-economy]]** To share a model, right-click it in Explorer, choose Save to Roblox, then add a title and description so others can search for and understand it.
- [page](https://create.roblox.com/docs/education/build-it-play-it-galactic-speedway/sharing-your-speeders) **[[ugc-and-avatar-economy]]** Enable 'Distribute on Creator Store' under Distribution on the Configure page so others can copy the model into their inventory.
- [page](https://create.roblox.com/docs/education/build-it-play-it-galactic-speedway/sharing-your-speeders) **[[building-art-and-assets]]** Newly uploaded models may show a placeholder thumbnail until Roblox moderators review them; this can take some time.

## Games
- **Galactic Speedway**: Educational Roblox course project; players build driftspeeder models that can be saved and shared as assets.

## Tools
Roblox Studio, Explorer, Asset Configuration window, Creator Dashboard
