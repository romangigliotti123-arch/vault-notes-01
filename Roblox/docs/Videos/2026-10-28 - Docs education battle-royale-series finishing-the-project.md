# Docs: education / battle-royale-series / finishing-the-project

[Open](https://create.roblox.com/docs/education/battle-royale-series/finishing-the-project.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Education docs page closing the Battle Royale series. Covers polishing the finished project: map visuals with premade Synty asset packs, changing SpawnLocation forcefield duration, playtesting match length and map size, lobby mini-games, and optional challenges (traps, leaderboard, powerups, randomized MapManager for multiple arenas).

## Tips
- [page](https://create.roblox.com/docs/education/battle-royale-series/finishing-the-project) **[[building-art-and-assets]]** Turn the graybox into a real map with a clear setting; use premade textured packs like Synty Nature, City, or Dungeon if not building from scratch.
- [page](https://create.roblox.com/docs/education/battle-royale-series/finishing-the-project) **[[playtesting-and-feedback]]** Playtest frequently with peers and check whether match duration feels right and whether the map is too empty to find other players quickly.
- [page](https://create.roblox.com/docs/education/battle-royale-series/finishing-the-project) **[[development-process-and-speed]]** Tune variables like GameSettings.matchDuration and intermission length based on playtest feedback rather than guessing.
- [page](https://create.roblox.com/docs/education/battle-royale-series/finishing-the-project) **[[core-loops-and-game-design]]** Make the lobby social with mini-games such as physics spheres or mini obstacle courses to keep players engaged during intermission.
- [page](https://create.roblox.com/docs/education/battle-royale-series/finishing-the-project) **[[updates-live-ops]]** Many successful Roblox games keep receiving updates after release; add features like traps, leaderboards, powerups, or more arenas.
- [page](https://create.roblox.com/docs/education/battle-royale-series/finishing-the-project) **[[building-and-level-design]]** Add randomized map selection with a MapManager module so each match picks a random arena and assigns players to its SpawnLocations.
