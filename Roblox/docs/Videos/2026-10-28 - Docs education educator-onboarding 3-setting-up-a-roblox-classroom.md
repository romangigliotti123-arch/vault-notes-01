# Docs: education / educator-onboarding / 3-setting-up-a-roblox-classroom

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/education/educator-onboarding/3-setting-up-a-roblox-classroom.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Education docs on setting up a classroom: free accounts and software, one account per student (no batch creation), password management, client vs Studio installs (individual or batch installers), sharing games via hyperlinks and private servers, and parent/IT communication resources.

## Tips
- [page](https://create.roblox.com/docs/education/educator-onboarding/3-setting-up-a-roblox-classroom) **[[first-session-onboarding]]** Have students create accounts outside class; accounts cannot be created in a batch, so plan registration ahead of the lesson.
- [page](https://create.roblox.com/docs/education/educator-onboarding/3-setting-up-a-roblox-classroom) **[[first-session-onboarding]]** Recommend adding an email at signup, since forgotten passwords can only be recovered through email.
- [page](https://create.roblox.com/docs/education/educator-onboarding/3-setting-up-a-roblox-classroom) **[[first-session-onboarding]]** Use a password manager or a central login database for younger students, so logins can be recovered if forgotten.
- [page](https://create.roblox.com/docs/education/educator-onboarding/3-setting-up-a-roblox-classroom) **[[cross-platform-and-console]]** For larger schools, create a batch installer deployable via USB drive or image; for small classes, install per computer from a browser.

## Numbers
- [page](https://create.roblox.com/docs/education/educator-onboarding/3-setting-up-a-roblox-classroom) Private server monthly fee: **~100 Robux (~$1 USD) per month, set by developer** (Typical fee for some private servers; most educational games include one free)
- [page](https://create.roblox.com/docs/education/educator-onboarding/3-setting-up-a-roblox-classroom) Online Studio project limits: **None on number or file size** (Projects saved to student accounts, accessible from any computer)
- [page](https://create.roblox.com/docs/education/educator-onboarding/3-setting-up-a-roblox-classroom) Age threshold for restrictions: **Under 13** (Under-13 accounts see only curated games)

## Tools
Roblox client, Roblox Studio, LastPass, Google Classroom
