# Docs: tutorials / curriculums / building / get-started

## Summary
Roblox docs lesson: opening the Classic Obby template in Studio, arranging the workspace (close left-side windows, keep Explorer and Properties open), and playtesting the obby with Play/Stop and standard controls. Beginner onboarding only; no monetisation or growth advice.

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/building/get-started) **[[first-session-onboarding]]** Playtest a finished template before building so you understand how the gameplay works. Start by playing Classic Obby before adding your own parts.
- [page](https://create.roblox.com/docs/tutorials/curriculums/building/get-started) **[[ui-ux-design]]** Close Studio windows you don't need and keep Explorer and Properties open on the right to free space for coding or building.

## Games
- **Classic Obby**: Roblox-provided template; obstacle course with moving platforms, upward launch pads and kill bricks, getting harder toward the final platform.

## Tools
Roblox Studio, Explorer window, Properties window, Playtest (Play/Stop)
