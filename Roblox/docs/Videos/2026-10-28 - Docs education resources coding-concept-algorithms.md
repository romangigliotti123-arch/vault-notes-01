## Summary
Roblox education docs page explaining algorithms: definition with real-life and coding examples, the three construction methods (selection, sequencing, iteration) with Luau snippets, and how to combine smaller algorithms into larger ones. Includes classroom activities and discussion prompts.

## Tips
- [page](https://create.roblox.com/docs/education/resources/coding-concept-algorithms) **[[core-loops-and-game-design]]** Build game mechanics from small algorithms: e.g. a lava hazard that deducts 5 health per second and respawns the player at 0 health.
- [page](https://create.roblox.com/docs/education/resources/coding-concept-algorithms) **[[scripting-and-performance]]** Structure a main function that calls smaller helper functions (e.g. pickClothes, putOnClothes) so each piece is testable and reusable.
- [page](https://create.roblox.com/docs/education/resources/coding-concept-algorithms) **[[scripting-and-performance]]** Use task.wait inside loops for timed logic, such as a countdown that decrements every second.
- [page](https://create.roblox.com/docs/education/resources/coding-concept-algorithms) **[[development-process-and-speed]]** Break a mechanic into sub-algorithms before coding it; e.g. a timed bridge or shop each needs its own helper steps.
