# Docs: studio / material-generator

[Open](https://create.roblox.com/docs/studio/material-generator.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox Studio docs for the Material Generator: generate material variants from text keywords, preview with Studs Per Tile and Organic toggle, choose a Base Material, and save as a custom material via Save & Apply Variant. Includes keyword best practices.

## Tips
- [page](https://create.roblox.com/docs/studio/material-generator) **[[building-art-and-assets]]** Use 'close up', 'top down' or 'texture' in prompts for close-up patterns.
- [page](https://create.roblox.com/docs/studio/material-generator) **[[building-art-and-assets]]** Use 'simple', 'pattern', 'symmetrical' or 'flat' for simpler repeating patterns.
- [page](https://create.roblox.com/docs/studio/material-generator) **[[building-art-and-assets]]** Add 'photorealistic', 'cartoon' or 'hand-drawn' to add stylistic control over output.
- [page](https://create.roblox.com/docs/studio/material-generator) **[[building-art-and-assets]]** Include 'grayscale' in prompts so the generated material can be tinted afterwards.
- [page](https://create.roblox.com/docs/studio/material-generator) **[[building-art-and-assets]]** Expect iteration: every Generate click yields different results, so refine with longer keyword lists.
- [page](https://create.roblox.com/docs/studio/material-generator) **[[building-art-and-assets]]** Use the Studs Per Tile slider to preview texture scale on selected parts before saving.
- [page](https://create.roblox.com/docs/studio/material-generator) **[[building-art-and-assets]]** Enable the Organic toggle to reduce visible repetition by randomizing the output.
- [page](https://create.roblox.com/docs/studio/material-generator) **[[building-art-and-assets]]** Pick a Base Material before saving to inherit its default physical properties.

## Numbers
- [page](https://create.roblox.com/docs/studio/material-generator) Generation time: **Results within a few seconds** (Per Generate click, as stated in docs)

Roblox Studio Material Generator (Window > 3D menu), Material Manager, Material widget picker
