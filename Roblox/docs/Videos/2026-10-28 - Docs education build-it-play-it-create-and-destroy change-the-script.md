# Docs: education / build-it-play-it-create-and-destroy / change-the-script

[Open](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/change-the-script.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox Education tutorial for the Create and Destroy project. Shows how to open the GameSettings script, change building point values (HighPoints 15 to 150), playtest and undo mistakes, and make the experience public via Experience Settings > Permissions so friends can join by link.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/change-the-script) **[[scripting-and-performance]]** Keep tunable values such as point rewards in one settings table (GameSettings.pointValues) so balance changes need no logic edits.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/change-the-script) **[[scripting-and-performance]]** Value type keys in pointValues must match folder names exactly, or points will not be awarded correctly.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/change-the-script) **[[playtesting-and-feedback]]** Playtest after each balance change to judge how it feels before changing more values.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/change-the-script) **[[development-process-and-speed]]** Make small, single changes and undo the last one if the project breaks.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/change-the-script) **[[ui-ux-design]]** Set the experience to Public in Experience Settings > Permissions so friends can join via link; new publishes default to private.

## Numbers
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/change-the-script) HighPoints value: **changed from 15 to 150** (Large building point reward in Create and Destroy tutorial)
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/change-the-script) intermissionDuration: **10** (Default intermission length in seconds in GameSettings)
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/change-the-script) roundDuration: **30** (Default round length in seconds in GameSettings)
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/change-the-script) minimumPlayers: **1** (Default minimum players to start a round)
