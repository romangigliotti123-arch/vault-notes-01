# Docs: tutorials / use-case-tutorials / modeling / create-neon-signs

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.

## Summary
Roblox Creator Docs tutorial on making a neon sign in Studio: build a black backboard and lime-green border from Block parts, sculpt the border with Negate and Union, import an OPEN 3D text .obj set to Neon material, group into a model, and save to Roblox.

## Tips
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/modeling/create-neon-signs) **[[building-art-and-assets]]** Build signs from basic Block parts, then use Negate and Union to sculpt complex shapes such as a border, all within Studio.
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/modeling/create-neon-signs) **[[building-art-and-assets]]** Set Material to Neon on parts that should glow; this is the core technique for neon signage.
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/modeling/create-neon-signs) **[[building-art-and-assets]]** Name parts and group them into a Model (Ctrl+G) so the asset is organized and can be saved to Roblox as one object.
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/modeling/create-neon-signs) **[[building-art-and-assets]]** Save reusable assets to your Toolbox via Save to Roblox; you can later publish them to the Creator Store.

## Numbers
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/modeling/create-neon-signs) Backboard size: **8,4,1 studs** (Black block base for the neon sign)
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/modeling/create-neon-signs) Border size: **7.75,3.75,0.25 studs** (Lime Green border before sculpting)
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/modeling/create-neon-signs) Negative cut size: **7.5,3.5,1.0 studs** (Used to hollow out the border via Negate and Union)
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/modeling/create-neon-signs) Text color: **170,0,0** (Red neon color for the OPEN 3D text)

## Tools
Roblox Studio, Part tool (Block), Negate, Union
