# Docs: cloud / guides / error-reporting

[Open](https://create.roblox.com/docs/cloud/guides/error-reporting.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Cloud Error Reporting API docs. Explains API key setup (universe.analytics:read/write scopes), fetching error details by message hash, and creating/listing/reordering/dismissing/deleting regex rules that group or ignore error messages. Covers pattern restrictions, rule limits, and error codes.

## Tips
- [page](https://create.roblox.com/docs/cloud/guides/error-reporting) **[[analytics-metrics]]** Get error message hashes by querying the ErrorCount metric broken down by the MessageHash dimension before calling log-details.
- [page](https://create.roblox.com/docs/cloud/guides/error-reporting) **[[scripting-and-performance]]** Use Group rules to merge errors that differ only in variable details like player names or IDs so counts aggregate under one label.
- [page](https://create.roblox.com/docs/cloud/guides/error-reporting) **[[scripting-and-performance]]** Use Ignore rules to move known noisy errors into the Other bucket; totals are unchanged.
- [page](https://create.roblox.com/docs/cloud/guides/error-reporting) **[[scripting-and-performance]]** Order rules carefully: the first matching rule wins, so put specific rules before broad ones.
- [page](https://create.roblox.com/docs/cloud/guides/error-reporting) **[[scripting-and-performance]]** Rules only apply to new errors as they are processed; existing recorded errors are not changed. Allow a few minutes for changes to take effect.
- [page](https://create.roblox.com/docs/cloud/guides/error-reporting) **[[anti-exploit-and-security]]** Send all three fields (pattern, output, regexOperation) on rule updates; an omitted output is cleared.
- [page](https://create.roblox.com/docs/cloud/guides/error-reporting) **[[ai-and-tools]]** Use an API key with only the needed Access Permissions scopes; the key owner must also have analytics access or requests return 403.
- [page](https://create.roblox.com/docs/cloud/guides/error-reporting) **[[scripting-and-performance]]** Avoid patterns starting with unanchored wildcards like .* or nested quantifiers like (\w+)+; these are rejected with 400.
- [page](https://create.roblox.com/docs/cloud/guides/error-reporting) **[[scripting-and-performance]]** Ignore rule alternatives must start with at least 3 literal characters, e.g. ^AdService: is valid but ^\w+ is not.
- [page](https://create.roblox.com/docs/cloud/guides/error-reporting) **[[scripting-and-performance]]** Review AutoGenerated rules suggested by Roblox (with matchedCount and sampleMessage) and dismiss unwanted ones via the ignore endpoint, which only works on AutoGenerated rules.

## Numbers
- [page](https://create.roblox.com/docs/cloud/guides/error-reporting) API rate limit: **60 requests per minute per API key per endpoint** (Applies to each endpoint)
- [page](https://create.roblox.com/docs/cloud/guides/error-reporting) Max CreatorCreated rules: **100 per experience** (Exceeding returns 409)
- [page](https://create.roblox.com/docs/cloud/guides/error-reporting) Max pattern length: **1,000 characters** (Applies to pattern and output fields)
- [page](https://create.roblox.com/docs/cloud/guides/error-reporting) Default log-details time range: **7 days before endTime** (endTime defaults to now)
- [page](https://create.roblox.com/docs/cloud/guides/error-reporting) Ignore pattern minimum literal prefix: **3 literal characters** (For top-level alternatives in Ignore rules)
