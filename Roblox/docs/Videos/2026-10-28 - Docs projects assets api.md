## Summary
Roblox developer docs on querying catalog assets outside Studio. Covers the Creator Store API (via Toolbox Service in Open Cloud) for Studio assets, and the Marketplace catalog search endpoint for avatar items, with its query parameters (category, genre, sort, price filters, pagination) and response fields.

## Numbers
- [page](https://create.roblox.com/docs/projects/assets/api) Marketplace search result limit: **Limit values currently 10, 28, or 30**
- [page](https://create.roblox.com/docs/projects/assets/api) Marketplace SortAggregation options: **1=PastDay, 3=PastWeek, 4=PastMonth, 5=AllTime**

## Tools
Creator Store API (Toolbox Service, Open Cloud), Marketplace catalog search API (catalog.roblox.com/v1/search/items/details)
