# Docs: production / monetization / shop

[Open](https://create.roblox.com/docs/production/monetization/shop.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page for Shop: a personalized in-game storefront listing passes and developer products. Covers managing the Item catalog (listing/unlisting, categories), access via in-game menu or global Shop button, and that Shop doesn't change pass or product economics. Recommends implementing ProcessReceipt for external surfacing.

## Tips
- [page](https://create.roblox.com/docs/production/monetization/shop) **[[monetisation-devproducts]]** Implement ProcessReceipt so players receive purchases immediately; required for eligibility for external surfacing of listed developer products, including Shop and other Roblox surfaces.
- [page](https://create.roblox.com/docs/production/monetization/shop) **[[monetisation-devproducts]]** List developer products in Shop to let Roblox surface them outside your game, creating more purchase opportunities. Unlisted products remain purchasable via your own in-game flows.
- [page](https://create.roblox.com/docs/production/monetization/shop) **[[monetisation-other]]** Enable the global Shop button (disabled by default) so players always have a visible way to open Shop; toggle it in Monetization > Shop > Overview.
- [page](https://create.roblox.com/docs/production/monetization/shop) **[[titles-descriptions]]** Organize items into custom Shop categories (create, rename, move items) rather than relying only on Roblox's automatic suggestions, to match your game.
- [page](https://create.roblox.com/docs/production/monetization/shop) **[[common-mistakes]]** Remember to click Save in the Item catalog tab; changes to Shop aren't visible to players until saved.
