# Docs: resources / battle-royale

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/resources/battle-royale.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox docs page for Roblox Battle Royale, a free game kit built by internal Roblox developers. Covers features (3rd-person camera, 9 preconfigured ranged weapons, building and destruction systems, cross-platform support) and four play modes: Last One Standing, Solo Deathmatch, Team Deathmatch, and Free Play.

## Tips
- [page](https://create.roblox.com/docs/resources/battle-royale) **[[development-process-and-speed]]** Start from an existing kit like Roblox Battle Royale rather than building a battle royale from scratch; it ships with cameras, weapons, building and destruction already coded.
- [page](https://create.roblox.com/docs/resources/battle-royale) **[[cross-platform-and-console]]** Support mobile, Xbox and high-end PC from the start; the kit's systems are built to work across phones, consoles, controllers and screen sizes.
- [page](https://create.roblox.com/docs/resources/battle-royale) **[[scripting-and-performance]]** Keep code performant and easy to read so it can be reused and learned from; the kit is designed this way as a reference.
- [page](https://create.roblox.com/docs/resources/battle-royale) **[[game-ideas-and-genres]]** Offer several modes (Last One Standing, Solo and Team Deathmatch, Free Play) in one experience to serve different play styles.

## Numbers

- [page](https://create.roblox.com/docs/resources/battle-royale) Included play modes: **4** (Last One Standing, Solo Deathmatch, Team Deathmatch, Free Play)
