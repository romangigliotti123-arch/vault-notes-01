# Docs: studio / rig-builder

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/studio/rig-builder.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Docs page for the Studio Rig Generator tool. Explains inserting pre-built R6 or R15 character rigs (or a rig of your avatar with customizations and accessories) via the Character option in the Avatar or Home tab, choosing Masculine or Feminine body shape, and where the rig appears in Explorer.

## Tips
- [page](https://create.roblox.com/docs/studio/rig-builder) **[[3d-modeling-rigging-and-animation]]** Use R15 rigs if you need layered clothing or accessories; only R15 models can equip layerable accessories, while R6 is limited to basic motion.

## Numbers
- [page](https://create.roblox.com/docs/studio/rig-builder) R6 rig mesh object count: **6 mesh objects**
- [page](https://create.roblox.com/docs/studio/rig-builder) R15 rig mesh object count: **15 mesh objects**

## Tools
Rig Generator (Studio Avatar/Home tab > Character)
