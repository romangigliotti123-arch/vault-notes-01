## Summary
Roblox docs intro for educators: Roblox is a platform hosting user-made games; playing is free, Roblox Studio is free to create and publish, optional Robux fees (private server ~$1/month). Covers client vs Studio hardware, weekly updates, age suitability, and safety features.

## Numbers
- [page](https://create.roblox.com/docs/education/educator-onboarding/1-intro-to-roblox) Private server cost for educators: **about $1 (USD) per month**
- [page](https://create.roblox.com/docs/education/educator-onboarding/1-intro-to-roblox) Software update cadence: **weekly**
- [page](https://create.roblox.com/docs/education/educator-onboarding/1-intro-to-roblox) Cost to play, create, publish games: **free; no licensing fees**
