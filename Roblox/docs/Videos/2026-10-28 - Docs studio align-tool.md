# Docs: studio / align-tool

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/studio/align-tool.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox Studio docs for the Align tool (Model tab or Window > 3D). Covers aligning objects or models along X, Y, Z axes using Min, Center, or Max modes, with World or Local coordinate options, and relative to either Selection Bounds or the Active Object (last selected, outlined orange).

## Tips
- [page](https://create.roblox.com/docs/studio/align-tool) **[[building-and-level-design]]** Use Local alignment instead of World when aligning parts that don't share the same orientation or rotation.
- [page](https://create.roblox.com/docs/studio/align-tool) **[[building-and-level-design]]** Use Active Object relative alignment to align to the last selected object; it stays in place during the operation.
- [page](https://create.roblox.com/docs/studio/align-tool) **[[building-and-level-design]]** Align whole Models with Align to keep the model intact while aligning its parts relative to other parts.
- [page](https://create.roblox.com/docs/studio/align-tool) **[[building-and-level-design]]** Select multiple X, Y, and Z axes in one operation to align on several axes at once.
