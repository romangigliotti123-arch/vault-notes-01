# Docs: workspace

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/workspace.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Creator Docs page on the 3D workspace: what Workspace holds (BaseParts, Attachments, Models, Scripts), parts vs. meshes vs. terrain, models as physics assemblies, and the three ways to access Workspace from scripts.

## Tips
- [page](https://create.roblox.com/docs/workspace) **[[building-and-level-design]]** Use Models to group related geometry; set a PrimaryPart so the model acts as one physics assembly rigid body.
- [page](https://create.roblox.com/docs/workspace) **[[building-art-and-assets]]** Create complex meshes in Blender or Maya and import as MeshParts for far more detail than Studio solid modeling allows.
- [page](https://create.roblox.com/docs/workspace) **[[scripting-and-performance]]** Access Workspace via game:GetService("Workspace") or the workspace global; all three forms are valid.
- [page](https://create.roblox.com/docs/workspace) **[[building-and-level-design]]** Use solid modeling operations like union or negate to combine basic parts into shapes such as bowls or hollow pipes.

## Tools
Roblox Studio, Blender, Maya, Terrain Editor
