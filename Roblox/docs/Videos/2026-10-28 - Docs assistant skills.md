# Docs: assistant / skills

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/assistant/skills.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page for Assistant Skills: a skill is a Markdown file with frontmatter (name, description, enabled) plus instructions. Covers Roblox-authored rbx- skills, creating/duplicating/editing skills, and invoking them manually or automatically via description matching.

## Tips
- [page](https://create.roblox.com/docs/assistant/skills) **[[ai-and-tools]]** Write the skill description as specific as possible about what it does and when to use it; Assistant decides whether to load a skill from the description alone.
- [page](https://create.roblox.com/docs/assistant/skills) **[[ai-and-tools]]** Keep skill name and description each on a single line when creating manually in the Skills tab.
- [page](https://create.roblox.com/docs/assistant/skills) **[[ai-and-tools]]** Don't use the reserved rbx- prefix for your own skill names; it is reserved for Roblox-authored skills.
- [page](https://create.roblox.com/docs/assistant/skills) **[[ai-and-tools]]** To customize a Roblox-authored skill, duplicate it rather than editing it; Roblox skills are read-only and the original gets auto-disabled.

## Tools
Roblox Assistant, Skills tab, rbx-create-skill, rbx-debug
