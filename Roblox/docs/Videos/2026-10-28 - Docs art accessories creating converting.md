# Docs: art / accessories / creating / converting

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/art/accessories/creating/converting.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox docs page on the final step of layered clothing creation: converting a layered accessory MeshPart into a Class.Accessory using the Accessory Fitting Tool (AFT) in Studio. Covers selecting the part, setting asset type to Clothing (Shirt), previewing on sample characters, and generating the accessory, which can then be used in-game, published, or saved to Toolbox.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/creating/converting) **[[3d-modeling-rigging-and-animation]]** Preview the layered accessory on several sample characters, clothing and animations in AFT before generating; fix minor cage issues there, larger ones in your modeling software.
- [page](https://create.roblox.com/docs/art/accessories/creating/converting) **[[building-art-and-assets]]** Select the layered accessory MeshPart in Explorer as the AFT Part field before clicking Next; AFT needs the MeshPart, not the Model, to convert.
- [page](https://create.roblox.com/docs/art/accessories/creating/converting) **[[ugc-and-avatar-economy]]** Generated accessories can be uploaded to the Marketplace, used in-game via HumanoidDescription, or saved to Toolbox for reuse across your games.

## Tools
Roblox Studio, Accessory Fitting Tool (AFT), Toolbox
