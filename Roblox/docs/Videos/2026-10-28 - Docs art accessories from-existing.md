# Docs: art / accessories / from-existing

[Open](https://create.roblox.com/docs/art/accessories/from-existing.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs walkthrough for converting an existing 3D model (Blender, .fbx) into a rigid Accessory in Studio: model setup and scale, PBR texture linking, freezing transforms, export, import, fitting with the Accessory Fitting Tool, and Marketplace publishing.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/from-existing) **[[building-art-and-assets]]** Apply all transforms (Object > Apply > All Transforms) before export; unapplied scale/rotation causes unexpected orientation when importing into Studio.
- [page](https://create.roblox.com/docs/art/accessories/from-existing) **[[building-art-and-assets]]** Face the accessory -Y forward and center it at 0,0,0 in Blender so it imports at the center of the Studio camera.
- [page](https://create.roblox.com/docs/art/accessories/from-existing) **[[building-art-and-assets]]** Remove lights, cameras, and mannequin meshes and apply modifiers so only the accessory mesh is exported.
- [page](https://create.roblox.com/docs/art/accessories/from-existing) **[[3d-modeling-rigging-and-animation]]** If an FBX imports at 1/100 scale, set Blender object transform X/Y/Z to 1.000 before working on it.
- [page](https://create.roblox.com/docs/art/accessories/from-existing) **[[3d-modeling-rigging-and-animation]]** Link PBR maps in Blender: ALB to Base Color, MTL to Metallic, RGH to Roughness, and NOR through a Normal Map node into the Normal input.
- [page](https://create.roblox.com/docs/art/accessories/from-existing) **[[building-art-and-assets]]** PBR textures are optional for accessories but add realism; verify them in Material Preview mode.
- [page](https://create.roblox.com/docs/art/accessories/from-existing) **[[ugc-and-avatar-economy]]** Check the modeled asset for IP infringement and polycount budget before uploading, since Marketplace policy applies.
- [page](https://create.roblox.com/docs/art/accessories/from-existing) **[[ugc-and-avatar-economy]]** Use the Accessory Fitting Tool when converting a Model into an Accessory to preview placement correctly on a mannequin.

## Numbers
- [page](https://create.roblox.com/docs/art/accessories/from-existing) Import scale issue: **1/100 scale on Roblox .fbx conversion; fix by setting transform to 1.000** (Roblox-related FBX files import at 1/100 scale in Blender)

Blender, Roblox Studio, Accessory Fitting Tool (AFT), Studio Importer
