## Summary
Roblox Education docs page on creating a victory animation in Studio's Animation Editor: why feedback matters, enabling a character rig, creating a named animation, adding all rig parts, and the default 1-second animation length.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/animations-and-feedback) **[[3d-modeling-rigging-and-animation]]** Turn off Move and Rotate snapping before posing rig parts so you can freely manipulate them for animation.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/animations-and-feedback) **[[3d-modeling-rigging-and-animation]]** Add a character rig via Avatar > Character before creating player animations, then use the Animation Editor's (+) > Add All to include all rig parts.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/animations-and-feedback) **[[player-psychology-and-game-feel]]** Give a visible reaction to every player action (e.g. hit, checkpoint, level-up) so players don't think the game is broken.

## Numbers
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/animations-and-feedback) default new animation length: **1 second (shown as 1:00)** (Animation Editor default; change via second box in position indicator)

## Tools
Roblox Studio, Animation Editor, Avatar tab
