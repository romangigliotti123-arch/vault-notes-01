# Docs: art / accessories / validation-tool

[Open](https://create.roblox.com/docs/art/accessories/validation-tool.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox docs page for the Layered Accessory Validation Tool, a Blender (3.0) and Maya (2022) add-on/plugin that flags and sometimes auto-fixes common layered accessory export issues (extra layers, unfrozen transforms, unused data, keyframes, attachment points, cage intersections, texture format). It does not replace checking general mesh and layered accessory specs.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/validation-tool) **[[building-art-and-assets]]** Don't rely solely on the validation tool; verify general mesh requirements and Roblox layered accessory specs manually before importing into Studio.
- [page](https://create.roblox.com/docs/art/accessories/validation-tool) **[[building-art-and-assets]]** Select the accessory object and click Check Assets; red (Blender) or yellow (Maya) results mark issues, grey/green mean passed.
- [page](https://create.roblox.com/docs/art/accessories/validation-tool) **[[building-art-and-assets]]** Freezing transforms via the Transforms auto-fix may change your rig; check the rig after applying it.
- [page](https://create.roblox.com/docs/art/accessories/validation-tool) **[[building-art-and-assets]]** Intersection warnings on sleeve holes, neck and torso edges are default behavior and can be ignored.
- [page](https://create.roblox.com/docs/art/accessories/validation-tool) **[[building-art-and-assets]]** Remove extra layers, unused materials, orphan data (Blender) or construction history (Maya), and unnecessary keyframes before export.
- [page](https://create.roblox.com/docs/art/accessories/validation-tool) **[[building-art-and-assets]]** Name attachment points using the correct convention; the auto-fix parents unexpected attachment points.
- [page](https://create.roblox.com/docs/art/accessories/validation-tool) **[[building-art-and-assets]]** Check texture resolution against Roblox texture requirements; use the output messages to resolve texture issues.
- [page](https://create.roblox.com/docs/art/accessories/validation-tool) **[[3d-modeling-rigging-and-animation]]** On Maya, install Python 3.0+ with Add to PATH enabled before installing the tool; on Mac, chmod 777 install.command if it fails to run.
