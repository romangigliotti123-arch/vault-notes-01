# Docs: avatar / makeup / import

[Open](https://create.roblox.com/docs/avatar/makeup/import.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on importing makeup assets (.fbx/.gltf) into Studio via the Importer, verifying Decal/WrapTextureTransfer children, applying them to a character's Makeup folder in the Makeup test place, and previewing with Avatar Setup.

## Tips
- [page](https://create.roblox.com/docs/avatar/makeup/import) **[[3d-modeling-rigging-and-animation]]** Before importing makeup, verify template has target head mesh, target head cage mesh, and any modified Lips, Face, or Eyes meshes and textures; otherwise errors occur later.
- [page](https://create.roblox.com/docs/avatar/makeup/import) **[[3d-modeling-rigging-and-animation]]** After import, confirm Decal children exist under the new Model, each with a WrapTextureTransfer child; makeup decals without it will not work.
- [page](https://create.roblox.com/docs/avatar/makeup/import) **[[3d-modeling-rigging-and-animation]]** Use the Roblox-provided avatars in the test place for best makeup fit; other avatars may look misaligned due to differing head cage alignment.
- [page](https://create.roblox.com/docs/avatar/makeup/import) **[[testing-debugging-and-qa]]** Preview makeup in Avatar Setup (Avatar > Setup) before playtesting to check decals and mesh assets without running the game.

## Tools
Roblox Studio Importer, Avatar Setup tool, Explorer window
