# Docs: production / game-design / liveops-planning

[Open](https://create.roblox.com/docs/production/game-design/liveops-planning.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox official docs page on LiveOps planning. Covers two content types (events vs. permanent content updates), and a plan/communicate/monitor framework: pick KPIs, design player actions and economy impact, announce events externally and in-game (advance notice maximizes participation), and track data hourly and compare against weeks before and after the event.

## Tips
- [page](https://create.roblox.com/docs/production/game-design/liveops-planning) **[[updates-live-ops]]** Mix two content types: short events (contests, promotions) between larger permanent content updates that expand the core loop.
- [page](https://create.roblox.com/docs/production/game-design/liveops-planning) **[[updates-live-ops]]** Define the target KPI before designing an event (e.g. daily active users); events usually move several KPIs at once.
- [page](https://create.roblox.com/docs/production/game-design/liveops-planning) **[[core-loops-and-game-design]]** Design event rewards so they don't distort the economy; e.g. a fishing tournament boosts currency earning, so reward types must be intentional.
- [page](https://create.roblox.com/docs/production/game-design/liveops-planning) **[[updates-live-ops]]** Announce events in advance so players can schedule their return; late announcements risk being overlooked, though they can feel spontaneous.
- [page](https://create.roblox.com/docs/production/game-design/liveops-planning) **[[updates-live-ops]]** Use multiple channels: external (social media, community tools) plus internal (login pop-ups, UI alerts, lobby prominence).
- [page](https://create.roblox.com/docs/production/game-design/liveops-planning) **[[first-session-onboarding]]** Design an impactful, memorable event start that makes players excited and likely to return after the event ends.
- [page](https://create.roblox.com/docs/production/game-design/liveops-planning) **[[analytics-metrics]]** Track currency and resource sources and sinks and instrument features so you can see how players interact with them.
- [page](https://create.roblox.com/docs/production/game-design/liveops-planning) **[[analytics-metrics]]** Monitor event data hourly and same-day to catch too many prizes or events players can't complete.
- [page](https://create.roblox.com/docs/production/game-design/liveops-planning) **[[analytics-metrics]]** Compare event-period data with the week before and the week after to see whether the event had a lasting effect.
- [page](https://create.roblox.com/docs/production/game-design/liveops-planning) **[[analytics-metrics]]** Judge event success by retention during and after the event and by item and currency sales during and after.

## Numbers
- [page](https://create.roblox.com/docs/production/game-design/liveops-planning) Comparison window for event impact: **Week before vs. week after the event** (Docs' recommended baseline for judging lasting impact)
