## Summary
Roblox Education docs page (Build It, Play It story games). Finishes a text-adventure style project: concatenating the final sentence string, adding a second GetInput question with a placeholder variable, and optional tips: reusing variables in strings and using \n line breaks.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-story-games/finish-and-add) **[[luau-language-and-types]]** Use the .. operator to concatenate strings; remember a trailing space inside each string so sentences don't run together.
- [page](https://create.roblox.com/docs/education/build-it-play-it-story-games/finish-and-add) **[[playtesting-and-feedback]]** Playtest the game every time you add a new set of variables and strings.
- [page](https://create.roblox.com/docs/education/build-it-play-it-story-games/finish-and-add) **[[playtesting-and-feedback]]** Ask a peer or friend which other words they would like to customize.
- [page](https://create.roblox.com/docs/education/build-it-play-it-story-games/finish-and-add) **[[luau-language-and-types]]** Reuse a variable multiple times by concatenating it between strings wherever the word is needed.
