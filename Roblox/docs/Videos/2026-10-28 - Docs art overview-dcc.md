# Docs: art / overview-dcc

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/art/overview-dcc.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox staff docs overview on using third-party creation software (Blender, Maya, Photoshop, Audacity, etc.) to make assets and importing them into Studio. Covers supported file formats for models, images, sounds, and video, plus the Roblox Blender plugin and a moderation warning on uploads.

## Tips
- [page](https://create.roblox.com/docs/art/overview-dcc) **[[3d-modeling-rigging-and-animation]]** Uploaded models must follow Studio's modeling specifications; Studio's Importer accepts .gltf, .fbx, and .obj files.
- [page](https://create.roblox.com/docs/art/overview-dcc) **[[ai-and-tools]]** Use the Roblox Blender plugin to connect your modeling software to Studio and upload model assets directly between applications.
- [page](https://create.roblox.com/docs/art/overview-dcc) **[[building-art-and-assets]]** Uploaded textures must follow Studio's texture specifications; Asset Manager accepts .png, .jpg, .gif, .tga, .bmp and supports bulk import.
- [page](https://create.roblox.com/docs/art/overview-dcc) **[[building-art-and-assets]]** Uploaded sounds must meet Roblox's audio asset requirements; Asset Manager accepts .ogg, .mp3, .flac, .wav with bulk import.

## Tools
Blender, Maya, Cinema 4D, Photoshop
