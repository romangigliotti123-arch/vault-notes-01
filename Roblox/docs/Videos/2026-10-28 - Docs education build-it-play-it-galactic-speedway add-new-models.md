## Summary
Roblox Education docs page (Galactic Speedway kit): how to add a free kit asset to inventory via the web, import it into Studio via Toolbox > Inventory > My Models, and duplicate parts to customize a driftspeeder. Ends with a challenge game that awards an avatar hat and badge.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-galactic-speedway/add-new-models) **[[building-art-and-assets]]** Import kit assets via Toolbox > Inventory > My Models, after moving the camera to the target area; kits import at camera position.
- [page](https://create.roblox.com/docs/education/build-it-play-it-galactic-speedway/add-new-models) **[[building-art-and-assets]]** Duplicate kit parts with Ctrl+D (Cmd+D on Mac) to build variants rather than modelling from scratch.
