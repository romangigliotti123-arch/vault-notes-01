# Docs: production / monetization / private-servers

[Open](https://create.roblox.com/docs/production/monetization/private-servers.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox docs on private servers as a monetization feature: enabling them (game must be public), setting a monthly Robux fee via Requires Robux, Roblox Plus subscriber rules (up to 100 Robux per subscriber monthly), and the warning that changing the price cancels all active subscriptions.

## Tips
- [page](https://create.roblox.com/docs/production/monetization/private-servers) **[[monetisation-other]]** Your game must be public before you can enable private servers.
- [page](https://create.roblox.com/docs/production/monetization/private-servers) **[[pricing]]** The Robux price you set for paid private servers directly determines how much you earn per sale.
- [page](https://create.roblox.com/docs/production/monetization/private-servers) **[[monetisation-other]]** Paid access in Robux or local currency and private servers cannot be enabled at the same time.
- [page](https://create.roblox.com/docs/production/monetization/private-servers) **[[common-mistakes]]** Changing the private server price cancels all active subscriptions; players get an inbox message. Avoid price changes unless necessary.
- [page](https://create.roblox.com/docs/production/monetization/private-servers) **[[monetisation-other]]** Roblox Plus subscribers get paid private servers free, but you still earn up to 100 Robux per subscriber monthly based on their time in paid private servers.
- [page](https://create.roblox.com/docs/production/monetization/private-servers) **[[ads-and-sponsored-experiences]]** Private servers are useful for friends, classes, meetings, streaming without others, and gathering resources; design for these use cases.

## Numbers
- [page](https://create.roblox.com/docs/production/monetization/private-servers) Private server fee: **Monthly Robux fee set by creator**
- [page](https://create.roblox.com/docs/production/monetization/private-servers) Roblox Plus earnings cap: **Up to 100 Robux per subscriber per month**
- [page](https://create.roblox.com/docs/production/monetization/private-servers) Price change effect: **Cancels all active subscriptions**
