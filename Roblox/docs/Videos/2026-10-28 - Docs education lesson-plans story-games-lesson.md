# Docs: education / lesson-plans / story-games-lesson

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/education/lesson-plans/story-games-lesson.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Education lesson plan for a 60-minute "Code a story game" class. Students brainstorm a story, create Luau variables for user input, concatenate strings with a pre-written story, and test/troubleshoot in Roblox Studio. Covers variables, strings, and concatenation for beginners.

## Tips
- [page](https://create.roblox.com/docs/education/lesson-plans/story-games-lesson) **[[first-session-onboarding]]** Keep beginner coding sessions focused: one question, one sentence, one variable is a valid simplified scope for new learners.
- [page](https://create.roblox.com/docs/education/lesson-plans/story-games-lesson) **[[testing-debugging-and-qa]]** Have students swap projects and test each other's work; watch for missing spaces in concatenation as a common error.
- [page](https://create.roblox.com/docs/education/lesson-plans/story-games-lesson) **[[testing-debugging-and-qa]]** Enforce strict capitalization and spelling for identifiers like storyMaker and GetInput; one wrong letter causes an error.
- [page](https://create.roblox.com/docs/education/lesson-plans/story-games-lesson) **[[common-mistakes]]** String variables show everything literally between quotes, so stray spaces or missing spaces between joined words appear in output.

## Numbers
- [page](https://create.roblox.com/docs/education/lesson-plans/story-games-lesson) Lesson duration: **60 min total: 5 intro, 5 brainstorm, 25 tutorial, 10 independent, 5 wrap-up** (Suggested lesson structure for Hour of Code classroom)
- [page](https://create.roblox.com/docs/education/lesson-plans/story-games-lesson) Peers to ask before instructor: **3** (Ask 3 Before Me troubleshooting rule)
