# Docs: art / characters / facial-animation / animate-heads

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/art/characters/facial-animation/animate-heads.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs on animating character heads (facial animation). Covers three methods: manual FACS value tracks in the Animation Editor, the Face Animation Editor slider UI, and Animation Capture for Faces via webcam. Explains saving to AnimSaves, exporting to Studio, and scripting playback.

## Tips
- [page](https://create.roblox.com/docs/art/characters/facial-animation/animate-heads) **[[3d-modeling-rigging-and-animation]]** Use the Avatar Setup tool with presets to quickly preview head animations and accessories before building custom facial animations.
- [page](https://create.roblox.com/docs/art/characters/facial-animation/animate-heads) **[[3d-modeling-rigging-and-animation]]** Face animations cannot be imported; create them in the Animation Editor via tracks, the Face Animation Editor, or Animation Capture.
- [page](https://create.roblox.com/docs/art/characters/facial-animation/animate-heads) **[[3d-modeling-rigging-and-animation]]** Use Symmetry Toggle in the Face Animation Editor to drive both sides of the face together for symmetric expressions like a full smile.
- [page](https://create.roblox.com/docs/art/characters/facial-animation/animate-heads) **[[3d-modeling-rigging-and-animation]]** Set expressions at different timeline frames; playback eases between them, so combine sliders across frames for complex animation such as blinks.

## Numbers
- [page](https://create.roblox.com/docs/art/characters/facial-animation/animate-heads) FACS value range: **0 to 1 per pose** (Animation Editor values map directly to FaceControls values)

## Tools
Animation Editor, Face Animation Editor, Animation Capture for Faces extension, Avatar Setup tool
