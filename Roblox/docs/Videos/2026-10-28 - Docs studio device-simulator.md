# Docs: studio / device-simulator

[Open](https://create.roblox.com/docs/studio/device-simulator.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Studio docs for Device Simulator (beta): a toolbar above the viewport that simulates device category, screen size, pixel density, keyboard, touch and controller input, and display scaling. Covers the Device Manager, custom devices, and example test workflows.

## Tips
- [page](https://create.roblox.com/docs/studio/device-simulator) **[[testing-debugging-and-qa]]** Test on the Entry level phone, not only the Flagship, to confirm UI reads at that pixel density and the experience fits the memory budget.
- [page](https://create.roblox.com/docs/studio/device-simulator) **[[ui-ux-design]]** Check layouts across phone, tablet and console to surface safe area, overflow and anchoring problems immediately.
- [page](https://create.roblox.com/docs/studio/device-simulator) **[[ui-ux-design]]** Verify tap targets and text in Physical size mode after calibrating, comparing a phone against a tablet.
- [page](https://create.roblox.com/docs/studio/device-simulator) **[[ui-ux-design]]** Focus a text field on a simulated phone and confirm the on-screen keyboard does not cover controls the player needs.
- [page](https://create.roblox.com/docs/studio/device-simulator) **[[cross-platform-and-console]]** Use Controller Emulator alongside Device Simulator to test gamepad, VR and TV remote input without owning the hardware.
- [page](https://create.roblox.com/docs/studio/device-simulator) **[[testing-debugging-and-qa]]** Use Network Simulator in the same toolbar to test high latency, jitter and packet loss during playtests.
- [page](https://create.roblox.com/docs/studio/device-simulator) **[[cross-platform-and-console]]** Use the touch shortcuts (Alt+drag for pinch/rotate, Alt+Shift+drag for two-finger pan) to validate touch inputs land correctly.
- [page](https://create.roblox.com/docs/studio/device-simulator) **[[testing-debugging-and-qa]]** Hide unused standard devices in Device Manager to keep the device menu short; hidden devices can be re-added anytime.
- [page](https://create.roblox.com/docs/studio/device-simulator) **[[ui-ux-design]]** Calibrate physical scaling once by matching the on-screen width to a student ID or library card; the value persists across sessions.

## Numbers
- [page](https://create.roblox.com/docs/studio/device-simulator) Custom device screen width: **1 to 7680 px** (Device Simulator custom device dimensions limit)
- [page](https://create.roblox.com/docs/studio/device-simulator) Custom device screen height: **1 to 4320 px** (Device Simulator custom device dimensions limit)
- [page](https://create.roblox.com/docs/studio/device-simulator) Custom device pixel density: **72 to 10,000 PPI** (Drives physical-size scaling)
- [page](https://create.roblox.com/docs/studio/device-simulator) Keyboard height: **0 to 4320 px per orientation** (Portrait and landscape on-screen keyboard coverage)
- [page](https://create.roblox.com/docs/studio/device-simulator) Custom device name length: **200 characters max, unique** (Device name in device menu)
