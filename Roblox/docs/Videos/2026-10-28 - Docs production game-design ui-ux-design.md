# Docs: production / game-design / ui-ux-design

[Open](https://create.roblox.com/docs/production/game-design/ui-ux-design.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox official docs on UI and UX design: UI principles (prioritization, attention, visual language, conventions, consistency) and UX principles (understanding players, interaction design via conventions/metaphors/feedback, low-friction flows, flow charts). Illustrated with examples from named Roblox games.

## Tips
- [page](https://create.roblox.com/docs/production/game-design/ui-ux-design) **[[first-session-onboarding]]** Use conventions players already know (X to close, gray for unusable, lock icon for locked) to reduce need for game-specific instructions.
- [page](https://create.roblox.com/docs/production/game-design/ui-ux-design) **[[first-session-onboarding]]** Design for your target player group: consider demographics, experience level, genre familiarity and gameplay style before designing interactions.
- [page](https://create.roblox.com/docs/production/game-design/ui-ux-design) **[[core-loops-and-game-design]]** Show only contextually relevant buttons and HUD elements (e.g. Sprint/Tackle without ball, Deke/Pass with ball) to avoid clutter.
- [page](https://create.roblox.com/docs/production/game-design/ui-ux-design) **[[core-loops-and-game-design]]** Minimize steps in key flows (e.g. avatar equip) to keep friction low; map each flow as a flow chart to find pain points.
- [page](https://create.roblox.com/docs/production/game-design/ui-ux-design) **[[monetisation-gamepasses]]** Make the highest-value purchase option visually dominant by increasing its size and padding, as Dragon Adventures did with its coin bundles.
- [page](https://create.roblox.com/docs/production/game-design/ui-ux-design) **[[monetisation-other]]** Separate premium rewards visually (e.g. gold stripe under season pass-exclusive items) so they stand out from free rewards.
- [page](https://create.roblox.com/docs/production/game-design/ui-ux-design) **[[thumbnails-icons]]** Use bright, vibrant colors for crucial text and buttons and muted shades for less important elements; moderate bright or moving elements to avoid overwhelming players.
- [page](https://create.roblox.com/docs/production/game-design/ui-ux-design) **[[thumbnails-icons]]** Give buttons a container (colored background behind text/icon) and highlights or shadows so they read as interactive.
- [page](https://create.roblox.com/docs/production/game-design/ui-ux-design) **[[common-mistakes]]** Avoid cluttering mobile UIs with excessive buttons, screens and text; small screens get overwhelmed quickly.
- [page](https://create.roblox.com/docs/production/game-design/ui-ux-design) **[[common-mistakes]]** Apply UI decisions consistently everywhere (e.g. same green for Health in text, icons and bar; red price when unaffordable). Inconsistency causes confusion.
- [page](https://create.roblox.com/docs/production/game-design/ui-ux-design) **[[playtesting-and-feedback]]** Meet and play with your target players and learn their goals and preferences to inform design choices.
- [page](https://create.roblox.com/docs/production/game-design/ui-ux-design) **[[core-loops-and-game-design]]** Give feedback for every action: hit reactions, button hover/pressed states, purchase sound effects, progress bars for objectives.
- [page](https://create.roblox.com/docs/production/game-design/ui-ux-design) **[[building-art-and-assets]]** Document the visual language in a Style Guide so the whole team applies it consistently.
- [page](https://create.roblox.com/docs/production/game-design/ui-ux-design) **[[analytics-metrics]]** Use Experiments to test button placements and HUD layouts against player engagement; use Configs to toggle platform-specific UI or seasonal themes across servers.

## Games
- **Spellbound RPG**: Clean minimalist UI is crucial on mobile; spellcasting modeled as drawing cards from a deck grounds an abstract mechanic.
- **Super Striker League**: Swap contextual buttons by possession (Sprint/Tackle without ball, Deke/Pass with ball) to keep UI useful.
- **The Survival Game**: Keep health, hunger, map, inventory and tools easy to find; hard-to-find HUD makes survival needlessly frustrating.
- **Jailbreak**: Golden stripe under season pass-exclusive icons makes premium rewards visually distinct from free ones.
- **Dragon Adventures**: Enlarge and pad the highest-value coin bundle to prioritize it over smaller bundles.
- **Tower Defense Simulator**: Use size and proximity to group and distinguish Daily Tower Skins from Daily Crates in the shop.
- **Winds of Fortune**: Icons for related stats share palette and shapes; close-button convention used across games.
- **BotClash Simulator**: Button containers and shadows make buttons identifiable as interactive.
- **Arcane Odyssey**: Green Health stat applied consistently across text, icons and bar.
- **Mermaid Life**: Uses the standard E proximity prompt convention to signal interactable objects.
- **Berry Avenue RP**: Avatar equip flow uses few steps with a prominent HUD button, tabs, search and instant preview to keep friction low.
- **DOORS**: Uses the standard X close button convention.
