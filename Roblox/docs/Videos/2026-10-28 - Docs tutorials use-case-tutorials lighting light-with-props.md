# Docs: tutorials / use-case-tutorials / lighting / light-with-props

[Open](https://create.roblox.com/docs/tutorials/use-case-tutorials/lighting/light-with-props.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs tutorial on adding light-emitting props to a world. Covers PointLight (spherical, Range in studs), SpotLight (cone, Face, Angle up to 180), and SurfaceLight (emits from whole face, Angle 0 vs 180), using the Misty Harbor starter project.

## Tips
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/lighting/light-with-props) **[[building-art-and-assets]]** Set a part's Material to Neon to make it look glowing; Neon alone emits no light, so add a light object to it.
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/lighting/light-with-props) **[[building-art-and-assets]]** Use PointLight for bulbs, torches and fireballs (spherical emission from a single point).
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/lighting/light-with-props) **[[building-art-and-assets]]** Use SpotLight for street lamps, flashlights and headlights (cone emission); adjust Face to choose the emitting axis.
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/lighting/light-with-props) **[[building-art-and-assets]]** Use SurfaceLight for TV/computer screens, lit billboards and fluorescent panels, since it emits from the whole face.
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/lighting/light-with-props) **[[building-art-and-assets]]** Keep SpotLight Angle moderate (e.g. 30-75) for focused cones; max 180 lights a full half sphere.
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/lighting/light-with-props) **[[building-art-and-assets]]** For SurfaceLight, Angle 0 emits straight outward from the surface; Angle 180 emits perpendicular-spread across the surface.
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/lighting/light-with-props) **[[building-art-and-assets]]** Tune PointLight Range (e.g. 8 to 12 studs) to control illumination radius, alongside Brightness and Color.

- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/lighting/light-with-props) PointLight Range example: **8 to 12 studs** (Radial illumination distance)

- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/lighting/light-with-props) SpotLight Angle examples: **30 and 75** (Tutorial example values)
