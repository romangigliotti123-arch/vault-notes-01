# Docs: education / build-it-play-it-create-and-destroy / build-one-half

[Open](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/build-one-half.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Education docs page (Build it, Play it, Create and Destroy tutorial, "Build one half"). Covers duplicating large buildings from the palette, positioning them on one half of the map, checking placement from side/top views, and troubleshooting snapping with a 4-stud grid.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/build-one-half) **[[building-and-level-design]]** Duplicate objects with Ctrl+D (Cmd+D on Mac), not copy and paste. Duplicate keeps the new object in the same folder; copy and paste moves it outside the folder.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/build-one-half) **[[building-and-level-design]]** Build one half of a symmetric map and duplicate it to make the other half, so each player has equal access to the same number of buildings.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/build-one-half) **[[building-and-level-design]]** Set Snap to Grid for Move to 4 studs in the Model tab so buildings snap correctly.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/build-one-half) **[[building-and-level-design]]** Move objects with the arrow handles rather than dragging, and work from top view, for the most accurate snapping.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/build-one-half) **[[building-and-level-design]]** If an object won't snap correctly, delete it and duplicate a fresh one from the palette rather than fixing it in place.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/build-one-half) **[[building-and-level-design]]** Check placed buildings from side view (press F to focus, then use View Selector) to make sure they haven't moved up off the ground.

## Numbers
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/build-one-half) Large buildings to place per half: **3-5 additional** (Duplicate and place on the same half of the map as the tutorial's base building)
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/build-one-half) Snap to Grid for Move: **4 studs** (Recommended setting in the Model tab for accurate building placement)
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/build-one-half) Reachable buildings per player: **3 of 4** (Example layout where every player has an equal chance of reaching three of four buildings)

## Tools
Roblox Studio, Move tool, View Selector, Model tab Snap to Grid
