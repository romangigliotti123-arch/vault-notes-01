## Summary
Roblox docs page on inviting friends to play a published experience. Explains that new games default to private and shows how to switch Experience Settings > Permissions to Public, then save after publishing.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/invite-friends-to-play) **[[client-server-and-remotes]]** Publish the game before inviting friends so they receive your latest changes; unpublished edits are not visible to others.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/invite-friends-to-play) **[[first-session-onboarding]]** Set the experience to Public via File > Experience Settings > Permissions; new games are private by default and invisible to other players until changed.
