# Docs: tutorials / use-case-tutorials / use-case-tutorial-overview

## Summary
Roblox docs index for use-case tutorials, grouped by feature area: modeling (Studio solid modeling and Blender), UI, audio, lighting, VFX, physics, animation, scripting, camera/input, and data storage. Each section gives a short definition, the tutorials offered, and related docs.

## Tips
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/use-case-tutorial-overview) **[[building-art-and-assets]]** Use Studio solid modeling (union and negate basic parts) for complex shapes; use Blender for meshes and import them via the Importer.
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/use-case-tutorial-overview) **[[building-art-and-assets]]** Export meshes from Blender following the mesh and texture specifications and export requirements before importing into Studio.
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/use-case-tutorial-overview) **[[ui-ux-design]]** Place UI in key on-screen and in-world locations to communicate objectives and location, since players need this to succeed.
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/use-case-tutorial-overview) **[[sound-and-music]]** Use audio for both enjoyment and feedback: it immerses players and signals actions, status, and events.
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/use-case-tutorial-overview) **[[building-and-level-design]]** Set lighting deliberately, since lighting establishes mood, highlights important objects, and differs for indoor and outdoor environments.
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/use-case-tutorial-overview) **[[vfx-and-particles]]** Add VFX to give visual feedback on gameplay actions and to add movement to otherwise static scenes.
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/use-case-tutorial-overview) **[[physics-pathfinding-and-npc-ai]]** Understand assemblies and network ownership before building moving objects, since they determine how physics behaves in real time.
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/use-case-tutorial-overview) **[[3d-modeling-rigging-and-animation]]** Rig and skin meshes (rigging and skinning data) so they bend and flex naturally when animated.
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/use-case-tutorial-overview) **[[scripting-and-performance]]** Organize scripts by type and location, and use services, properties, attributes and events to keep logic clean and performant.
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/use-case-tutorial-overview) **[[cross-platform-and-console]]** Design the camera configuration and supported input types (mouse, mobile, gamepad) early, since they affect accessibility and engagement.
- [page](https://create.roblox.com/docs/tutorials/use-case-tutorials/use-case-tutorial-overview) **[[data-persistence]]** Use DataStores to save player progress and inventory across sessions; without them players lose all progress on leaving.
