# Docs: art / modeling / project-files

[Open](https://create.roblox.com/docs/art/modeling/project-files.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page listing modeling project files and references (.fbx, .blend, .ma) for art creation: tree, creature, robot NPC, avatar mannequins, caged clothing examples, R15 rig/cage templates, and Blender add-ons for upload and validation.

## Tips
- [page](https://create.roblox.com/docs/art/modeling/project-files) **[[building-art-and-assets]]** Start avatar and clothing work from the R15 rig template and cage templates rather than building rigs from scratch.
- [page](https://create.roblox.com/docs/art/modeling/project-files) **[[ugc-and-avatar-economy]]** Run the Blender validation tool before importing avatar items; avatar template assets must pass cleanup steps to validate before Marketplace publishing.
- [page](https://create.roblox.com/docs/art/modeling/project-files) **[[building-art-and-assets]]** Use the Blender Calisthenics tool to check skinning data on characters and clothing before upload.
- [page](https://create.roblox.com/docs/art/modeling/project-files) **[[ugc-and-avatar-economy]]** Models meant for Marketplace upload must keep accessories separate: e.g. a bulb antenna must be a separate head accessory, not part of head geometry.
- [page](https://create.roblox.com/docs/art/modeling/project-files) **[[ugc-and-avatar-economy]]** Layered accessories need inner and outer cage mesh data; models without cages (like the Lola reference) cannot equip layered clothing.
- [page](https://create.roblox.com/docs/art/modeling/project-files) **[[3d-modeling-rigging-and-animation]]** Use the Blender Studio plugin to upload assets directly from Blender to Studio.
- [page](https://create.roblox.com/docs/art/modeling/project-files) **[[building-art-and-assets]]** Apply UV textures to the skinned tree model with Class.SurfaceAppearance; the maple tree packs soil, branches and leaves as separate meshes on one armature.
- [page](https://create.roblox.com/docs/art/modeling/project-files) **[[3d-modeling-rigging-and-animation]]** Use Roblox mannequins (Classic, Rthro Normal, Rthro Slender) as proportion references when creating accessories and characters in third-party tools.

## Numbers
- [page](https://create.roblox.com/docs/art/modeling/project-files) Creature model mesh count: **11 meshes, over 50 bones (Beyond The Dark showcase)**
- [page](https://create.roblox.com/docs/art/modeling/project-files) Body cage parts: **15 individual body part cages required for avatar bodies**

## Tools
Blender, Autodesk Maya (.ma), FBX, Class.SurfaceAppearance, Blender Studio plugin, Blender validation tool, Blender Calisthenics tool
