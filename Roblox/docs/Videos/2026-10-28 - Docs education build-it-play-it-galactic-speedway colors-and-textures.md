## Summary
Roblox education docs page for Galactic Speedway: how to download driftspeeder texture files, import them via TextureID in Properties (requires published game), and multi-select parts to apply textures. Ends with a quiz challenge promoting rewards.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-galactic-speedway/colors-and-textures) **[[building-art-and-assets]]** Import textures via a part's TextureID property in Properties; click Add Image, then Choose File and Create. Game must be published first or Add Image won't appear.
- [page](https://create.roblox.com/docs/education/build-it-play-it-galactic-speedway/colors-and-textures) **[[building-art-and-assets]]** Select multiple parts in Explorer with Ctrl/Cmd-click, or click one part then Shift-click another to select the range, to apply a texture to many parts at once.
- [page](https://create.roblox.com/docs/education/build-it-play-it-galactic-speedway/colors-and-textures) **[[ai-and-tools]]** Create custom textures by editing provided texture files in Photoshop (paid) or Krita (open-source), varying colors or adding designs.

## Games
- **Galactic Speedway**: Educational tutorial game; driftspeeder texture customization is a lesson step.
