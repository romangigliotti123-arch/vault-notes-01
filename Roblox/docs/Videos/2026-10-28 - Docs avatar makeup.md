# Docs: avatar / makeup

[Open](https://create.roblox.com/docs/avatar/makeup.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox official docs on makeup assets for avatars/NPCs: makeup is baked into Decal objects per region (eyes, lips, face), with optional eyebrow/eyelash meshes. Covers template textures and heads, Blender/Maya export settings, and the Studio import workflow. Max 6 Decals per Marketplace makeup.

## Tips
- [page](https://create.roblox.com/docs/avatar/makeup) **[[building-art-and-assets]]** Pick either the mesh template or the cage template before starting; you cannot switch templates after you begin makeup work.
- [page](https://create.roblox.com/docs/avatar/makeup) **[[building-art-and-assets]]** Prefer the mesh template for most creators: it mimics real-world makeup application, with higher-fidelity mesh and UVs and minimal distortion.
- [page](https://create.roblox.com/docs/avatar/makeup) **[[building-art-and-assets]]** Use the cage template if you want fewer texture transfers (one vs two), which can reduce artifacts in makeup projection.
- [page](https://create.roblox.com/docs/avatar/makeup) **[[3d-modeling-rigging-and-animation]]** In Blender export, enable Custom Properties under Include and Only Deform Bones under Armature so eyebrows and eyelashes keep skinning data.
- [page](https://create.roblox.com/docs/avatar/makeup) **[[3d-modeling-rigging-and-animation]]** In Maya export, enable the Skins toggle under Deformed Models so eyebrows and eyelashes include skinning data.
- [page](https://create.roblox.com/docs/avatar/makeup) **[[building-art-and-assets]]** Export layers as separate PNGs and keep PBR texture names specific per component (e.g. Lips-Color, Lips-Metallic, Lips-Roughness) for easy reassignment.
- [page](https://create.roblox.com/docs/avatar/makeup) **[[building-art-and-assets]]** In Procreate, export the color texture with transparency by disabling the background layer before sharing the PNG.
- [page](https://create.roblox.com/docs/avatar/makeup) **[[building-art-and-assets]]** Test makeup by dropping Decal assets into a character's Makeup or Accessories folder in the reference place, then press Play to preview.
- [page](https://create.roblox.com/docs/avatar/makeup) **[[common-mistakes]]** Do not start makeup in one template and transfer it to the other; decide on the template before creating any textures.

## Numbers
- [page](https://create.roblox.com/docs/avatar/makeup) Max Decal objects per Marketplace makeup asset: **6** (Any combination of regions (eyes, lips, face))
- [page](https://create.roblox.com/docs/avatar/makeup) Texture transfers, cage template vs mesh template: **1 vs 2** (Cage needs one projection transfer; mesh needs two before projecting)
