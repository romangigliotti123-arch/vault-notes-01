## Summary
Roblox Studio beginner lesson: open the Story Game template, close unneeded left-side windows, keep Explorer and Properties open, and brainstorm a placeholder-word story (name1, food1, etc.) to be turned into code later.

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/coding/get-started) **[[first-session-onboarding]]** Start beginners from a pre-made template (e.g. Story Game) that already has everything except the code, so they can focus on scripting.
- [page](https://create.roblox.com/docs/tutorials/curriculums/coding/get-started) **[[ui-ux-design]]** Close unneeded Studio windows and keep only Explorer and Properties open to reduce clutter while coding.
- [page](https://create.roblox.com/docs/tutorials/curriculums/coding/get-started) **[[development-process-and-speed]]** Plan the game content first: write the story or core idea on paper before building, then number placeholders (name1, food1) for each player input.

## Tools
Roblox Studio, Story Game template, Explorer, Properties
