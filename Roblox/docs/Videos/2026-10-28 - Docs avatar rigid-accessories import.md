# Docs: avatar / rigid-accessories / import

[Open](https://create.roblox.com/docs/avatar/rigid-accessories/import.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on importing rigid accessories: importing .fbx/.gltf via Studio Importer as a Model, manually assigning textures via Asset Manager and SurfaceAppearance, and converting the MeshPart to an Accessory using the Accessory Fitting Tool (AFT) against a humanoid mannequin.

## Tips
- [page](https://create.roblox.com/docs/avatar/rigid-accessories/import) **[[building-art-and-assets]]** Import rigid accessories as .fbx or .gltf via the Home tab Import button; the Importer previews the asset and checks it against general 3D requirements.
- [page](https://create.roblox.com/docs/avatar/rigid-accessories/import) **[[building-art-and-assets]]** If textures fail to load on import, upload them via Asset Manager, wait for moderation to clear, then add a SurfaceAppearance to the MeshPart.
- [page](https://create.roblox.com/docs/avatar/rigid-accessories/import) **[[building-art-and-assets]]** Assign SurfaceAppearance maps from the _ALB, _MTL, _NOR and _RGH images to ColorMap, MetalnessMap, NormalMap and RoughnessMap respectively.
- [page](https://create.roblox.com/docs/avatar/rigid-accessories/import) **[[3d-modeling-rigging-and-animation]]** Use the Accessory Fitting Tool (Avatar tab > Accessory) to fit the asset; the clothing mannequin in the viewport does not show true rigid accessory attachment, so rely on the AFT preview.
- [page](https://create.roblox.com/docs/avatar/rigid-accessories/import) **[[3d-modeling-rigging-and-animation]]** Set the body type to the scale determined during sculpting and sizing, and choose the correct attachment location before fitting.
- [page](https://create.roblox.com/docs/avatar/rigid-accessories/import) **[[3d-modeling-rigging-and-animation]]** Click Generate MeshPart Accessory to convert the fitted MeshPart into an Accessory object, which can be published, equipped via HumanoidDescription, or saved to Toolbox.
- [page](https://create.roblox.com/docs/avatar/rigid-accessories/import) **[[common-mistakes]]** Ensure the model meets Roblox rigid accessory specifications before selling or using it; otherwise errors appear at different workflow points.

## Tools
Studio Importer, Asset Manager, Accessory Fitting Tool (AFT), SurfaceAppearance
