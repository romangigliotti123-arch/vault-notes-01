# Docs: studio / properties

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/studio/properties.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Studio documentation for the Properties window: browsing and editing sections, the property filter, instance tags, instance attributes (supported types and creation steps), and configurable instance defaults with their save/reset rules and local storage.

## Tips
- [page](https://create.roblox.com/docs/studio/properties) **[[building-art-and-assets]]** Use Edit > Save as Default [Instance] to make a configured instance (e.g. anchored MeshPart) the default for new inserts of that type.
- [page](https://create.roblox.com/docs/studio/properties) **[[building-art-and-assets]]** Defaults are stored locally in DefaultInstances.rbxm, not on your account; change the folder via Settings > Studio > Instance Defaults Dir.
- [page](https://create.roblox.com/docs/studio/properties) **[[building-art-and-assets]]** Reset defaults via Edit > Reset Default [Instance]; existing instances keep their properties, only new inserts change.
- [page](https://create.roblox.com/docs/studio/properties) **[[building-art-and-assets]]** Group as Model and Group as Folder ignore instance defaults; Position/CFrame/Origin/WorldPivot are not governed by defaults.

## Tools
Roblox Studio Properties window, CollectionService, Roblox Studio Explorer
