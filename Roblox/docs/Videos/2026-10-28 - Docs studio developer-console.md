# Docs: studio / developer-console

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/studio/developer-console.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page for the Developer Console: how to open it (F9, /console, in-game menu), and its tools: Log (client/server views, output filters, server command bar), Memory (real-time memory and Luau heap snapshots), Network (web call summary and details), and Script Profiler (CPU time per script).

## Tips
- [page](https://create.roblox.com/docs/studio/developer-console) **[[analytics-metrics]]** Use the Developer Console's Network tab to inspect web calls, including DataStore and HttpService requests, with status codes, timing and failures.
- [page](https://create.roblox.com/docs/studio/developer-console) **[[optimization-and-streaming]]** Use the Script Profiler to record CPU time per script and find the scripts consuming the most CPU before optimizing.
- [page](https://create.roblox.com/docs/studio/developer-console) **[[optimization-and-streaming]]** Use the Luau heap snapshot comparison to find memory growth over time by taking multiple snapshots and diffing them.
- [page](https://create.roblox.com/docs/studio/developer-console) **[[testing-debugging-and-qa]]** Open the Developer Console in live or test sessions with F9 or /console to see script output, warnings and errors like the Output window.

## Tools
Developer Console, Script Profiler, Luau heap memory snapshots
