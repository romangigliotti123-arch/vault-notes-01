# Docs: education / edu-templates / edu-styles

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/education/edu-templates/edu-styles.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Education template style guide. Defines four alert types (error, info, success, warning) with intended use, and a learning objective table format for the start of each module: max 4 objectives, sentences end with periods, key concept in bold, example included. Not about growing a game.

## Tips
- [page](https://create.roblox.com/docs/education/edu-templates/edu-styles) **[[ui-ux-design]]** Use error alerts very sparingly; reserve them for critical warnings only.
- [page](https://create.roblox.com/docs/education/edu-templates/edu-styles) **[[ui-ux-design]]** Use warning alerts as a heads-up, info for teacher-related comments, and success for non-crucial extra information.
- [page](https://create.roblox.com/docs/education/edu-templates/edu-styles) **[[ui-ux-design]]** Limit learning objectives to a maximum of 4 per module, ending each with a period and bolding the key concept.

## Numbers
- [page](https://create.roblox.com/docs/education/edu-templates/edu-styles) Max learning objectives per module: **4** (Learning objective table at the start of an individual module)
