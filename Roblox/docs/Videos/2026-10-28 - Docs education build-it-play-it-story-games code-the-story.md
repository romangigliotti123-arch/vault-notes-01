## Summary
Roblox Education docs tutorial step: create a `story` variable holding the first story string, concatenate the player's answer (name1) with `..`, and display it via storyMaker:Write(). Includes troubleshooting checks for missing questions, combined text, or absent output.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-story-games/code-the-story) **[[scripting-and-performance]]** Keep variable names case-exact; Luau treats name1 and Name1 as different variables, so mismatched capitalization breaks the output.
- [page](https://create.roblox.com/docs/education/build-it-play-it-story-games/code-the-story) **[[scripting-and-performance]]** Use the .. operator to concatenate strings; put variable names outside quotation marks so their values are inserted, not literal text.
- [page](https://create.roblox.com/docs/education/build-it-play-it-story-games/code-the-story) **[[testing-debugging-and-qa]]** Stop the playtest before editing scripts, then re-run and verify the combined sentence appears; check quotes, variable names, and the Write() argument if output is missing.
- [page](https://create.roblox.com/docs/education/build-it-play-it-story-games/code-the-story) **[[scripting-and-performance]]** Add a trailing space inside the string before the closing quote so the player's answer does not run into the next word.
