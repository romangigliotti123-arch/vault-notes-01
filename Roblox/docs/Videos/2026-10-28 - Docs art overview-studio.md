# Docs: art / overview-studio

[Open](https://create.roblox.com/docs/art/overview-studio.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs overview of Studio 3D art tools: interface panels, assets vs packages (packages recommended), Creator Store and Marketplace, basic parts vs mesh parts, materials and textures (PBR performance warning), and terrain and lighting for environments.

## Tips
- [page](https://create.roblox.com/docs/art/overview-studio) **[[building-art-and-assets]]** Use packages rather than loose assets where possible; packages propagate changes to all copies across games and offer versioning.
- [page](https://create.roblox.com/docs/art/overview-studio) **[[building-and-level-design]]** Use terrain for outdoor environments whenever possible to ensure performance and expected lighting and environmental behavior.
- [page](https://create.roblox.com/docs/art/overview-studio) **[[building-art-and-assets]]** Use basic parts for greyboxing or prototyping; they are performant and work well with native physics.
- [page](https://create.roblox.com/docs/art/overview-studio) **[[optimization-and-streaming]]** Avoid loading many unique PBR textures at once; reuse a single PBR texture set and vary alpha channels with mesh base colors for similar meshes.
- [page](https://create.roblox.com/docs/art/overview-studio) **[[3d-modeling-rigging-and-animation]]** Create custom meshes in Blender or Maya and import them into Studio; mixing basic parts with custom meshes works well for performant environments.
- [page](https://create.roblox.com/docs/art/overview-studio) **[[building-art-and-assets]]** Use the Material Generator and Texture Generator in Studio to create materials and textures from natural-language prompts.
- [page](https://create.roblox.com/docs/art/overview-studio) **[[building-and-level-design]]** Use local light sources (pointlights, spotlights, surface lights) and separate lighting scenarios per interior room or section.
- [page](https://create.roblox.com/docs/art/overview-studio) **[[building-art-and-assets]]** Use PBR textures when you need realistic surfaces, for assets destined for the Creator Store, Marketplace or your game.
