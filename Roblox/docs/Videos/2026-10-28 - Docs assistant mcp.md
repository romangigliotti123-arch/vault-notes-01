## Summary
Roblox docs page on MCP servers: Studio's open-source MCP server lets external AI coding tools access and edit a game. Explains connecting external LLMs (Anthropic, OpenAI, Google Gemini) via API keys in Studio's Assistant.

## Tips
- [page](https://create.roblox.com/docs/assistant/mcp) **[[ai-and-tools]]** Use Roblox's open-source Studio MCP server to let external AI coding tools read, write, test and modify your game code and data directly.
- [page](https://create.roblox.com/docs/assistant/mcp) **[[ai-and-tools]]** To use an external LLM in Studio Assistant: get an API key from the provider, open Assistant, click ⋯ > Manage API Keys, select provider, enter key, then pick model in Model drop-down.

## Tools
Roblox Studio MCP server, Roblox Studio Assistant, Anthropic, OpenAI
