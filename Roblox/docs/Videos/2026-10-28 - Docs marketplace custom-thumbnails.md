# Docs: marketplace / custom-thumbnails

[Open](https://create.roblox.com/docs/marketplace/custom-thumbnails.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on creating custom thumbnails for Marketplace accessories using the Custom Thumbnail Tool plugin. Covers the workflow (select Accessory, open UGC Thumbnail Tool, adjust camera, Accept, preview via Save To Roblox), the ThumbnailConfiguration structure, and troubleshooting zoom and orientation issues.

## Tips
- [page](https://create.roblox.com/docs/marketplace/custom-thumbnails) **[[thumbnails-icons]]** Create custom thumbnails before publishing; you must create them before uploading the asset to the Marketplace since they cannot be changed afterward.
- [page](https://create.roblox.com/docs/marketplace/custom-thumbnails) **[[thumbnails-icons]]** Use the Custom Thumbnail Tool plugin to generate ThumbnailConfiguration (CameraTarget, CameraValue) instead of relying on the default thumbnail, which may misrepresent the item.
- [page](https://create.roblox.com/docs/marketplace/custom-thumbnails) **[[thumbnails-icons]]** Make the accessory Handle cover the entire item; thumbnail zoom scales with Handle size.
- [page](https://create.roblox.com/docs/marketplace/custom-thumbnails) **[[building-art-and-assets]]** When resizing a Handle, change its Size property rather than using the resize tool, which can cause unintended changes to the item.
- [page](https://create.roblox.com/docs/marketplace/custom-thumbnails) **[[3d-modeling-rigging-and-animation]]** If imported meshes appear backward, rotate the mesh 180° in Blender or Maya and re-import; Studio may flip imports by 180°.
- [page](https://create.roblox.com/docs/marketplace/custom-thumbnails) **[[thumbnails-icons]]** Preview a thumbnail via right-click accessory > Save To Roblox… to see it in the Asset Configuration window before uploading.
- [page](https://create.roblox.com/docs/marketplace/custom-thumbnails) **[[thumbnails-icons]]** To redo a thumbnail, repeat the tool steps; Accept overwrites the existing thumbnail data.

## Tools
Custom Thumbnail Tool (UGC Thumbnail Tool) Studio plugin, Roblox Studio Explorer and Asset Configuration window, Blender, Maya
