# Docs: ip-licensing

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.

## Summary
Roblox docs page on licensed IP. Explains how creators request licenses for rights-holder IP via the Licenses catalog (Request for License flow: pick IP, choose game, review terms, pitch, submit) and how rights holders register IP through License Manager (proof of ownership plus letter of authorization). Lists founding partners and recent licensing announcements (Lionsgate, Kodansha).

## Tips
- [page](https://create.roblox.com/docs/ip-licensing) **[[game-ideas-and-genres]]** Build games around popular licensed IP from the Licenses catalog to reach audiences already familiar with the characters, settings, and storylines.
- [page](https://create.roblox.com/docs/ip-licensing) **[[team-and-budget]]** To use licensed IP, find it in the Licenses catalog, click Request for License, pick your game, review terms and content standards, include a pitch, and submit.
