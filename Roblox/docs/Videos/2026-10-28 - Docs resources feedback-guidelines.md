# Docs: resources / feedback-guidelines

## Summary
Roblox documentation page on giving feedback about the docs. Explains what to include in a bug or content report (steps to reproduce, browser extensions, frequency, problematic text or section header, suggested wording) and asks reporters not to include personal information.

## Tips
- [page](https://create.roblox.com/docs/resources/feedback-guidelines) **[[community-and-discord]]** When reporting a site issue, list the exact steps that trigger it and any relevant browser extensions so it can be reproduced.
- [page](https://create.roblox.com/docs/resources/feedback-guidelines) **[[community-and-discord]]** For intermittent bugs, note how often the behavior occurs and the situations where it seems most frequent.
- [page](https://create.roblox.com/docs/resources/feedback-guidelines) **[[community-and-discord]]** When flagging inaccurate docs, quote the problematic text or section header and suggest improved wording.
- [page](https://create.roblox.com/docs/resources/feedback-guidelines) **[[community-and-discord]]** Do not include personal information in feedback; include only what is needed to reproduce and troubleshoot.
