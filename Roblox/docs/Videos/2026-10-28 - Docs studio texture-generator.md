# Docs: studio / texture-generator

[Open](https://create.roblox.com/docs/studio/texture-generator.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Studio docs for the Texture Generator tool: generating custom textures for meshes via text or image prompts, Fast (1K diffuse, under 30s) vs Quality (4K PBR, a couple of minutes) modes, workflow steps, and prompting guidance.

## Tips
- [page](https://create.roblox.com/docs/studio/texture-generator) **[[building-art-and-assets]]** Select a single mesh or a unified Model of MeshParts; avoid scattered meshes or more than one identical mesh in one operation.
- [page](https://create.roblox.com/docs/studio/texture-generator) **[[building-art-and-assets]]** Use Texture Generator for contextual custom 3D assets; use Material Generator for repeating or tiled surfaces like wood floors or cobblestone.
- [page](https://create.roblox.com/docs/studio/texture-generator) **[[building-art-and-assets]]** Don't modify the asset while generation runs; editing before completion can cause the process to fail.
- [page](https://create.roblox.com/docs/studio/texture-generator) **[[building-art-and-assets]]** Back up assets before texturing, since Ctrl/Cmd+Z undo gets complicated when other scene work happens concurrently.
- [page](https://create.roblox.com/docs/studio/texture-generator) **[[development-process-and-speed]]** Prototype with Fast mode for rapid iteration, background assets, and simple assets without sharp details.
- [page](https://create.roblox.com/docs/studio/texture-generator) **[[building-art-and-assets]]** Use Quality mode (4K PBR) when fidelity matters; small generation artifacts are more visible at this sharpness.
- [page](https://create.roblox.com/docs/studio/texture-generator) **[[ai-and-tools]]** Write detailed prompts naming material, color, pattern and distinctive features; simple prompts like 'make it out of wood' give inconsistent results.
- [page](https://create.roblox.com/docs/studio/texture-generator) **[[ai-and-tools]]** Refine the prompt rather than regenerating previews with the same prompt, which yields only slightly different results.
- [page](https://create.roblox.com/docs/studio/texture-generator) **[[ai-and-tools]]** Set Preview orientation to Manual and orbit the mesh to choose the view, if Automatic picks a poor angle.
- [page](https://create.roblox.com/docs/studio/texture-generator) **[[ai-and-tools]]** Avoid prompts that change mesh geometry, reference the current texture, other scene objects, or previous textures, or describe reflectivity/transparency.
- [page](https://create.roblox.com/docs/studio/texture-generator) **[[ai-and-tools]]** With image prompts, expect a style guide rather than an exact template; details may not be preserved.

## Numbers
- [page](https://create.roblox.com/docs/studio/texture-generator) Preview generation time: **about 10 seconds for three preview images** (Texture Generator Preview step)
- [page](https://create.roblox.com/docs/studio/texture-generator) Fast mode output: **1K diffuse texture in under 30 seconds** (Fast generation mode)
- [page](https://create.roblox.com/docs/studio/texture-generator) Quality mode output: **4K PBR texture, generation takes a couple of minutes** (Quality generation mode)

## Tools
Texture Generator (Studio tool), Assistant /generate_texture command, Roblox Studio MCP, Material Generator
