## Summary
Roblox Creator Docs "Next steps" page for the first-obby tutorial. Points beginners to inviting early testers and releasing games, then lists further Studio building features: materials, Terrain Editor, textures/decals, and solid modeling (unions/intersections).

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/building/next-steps) **[[playtesting-and-feedback]]** Invite early testers to preview your game before releasing it publicly, per the docs' 'Invite early testers' guide.
- [page](https://create.roblox.com/docs/tutorials/curriculums/building/next-steps) **[[building-art-and-assets]]** Use Materials to change a part's visual appearance and physical properties instead of relying on plain parts.
- [page](https://create.roblox.com/docs/tutorials/curriculums/building/next-steps) **[[building-art-and-assets]]** Use the Terrain Editor to generate realistic environments such as mountains, grass hills, or flat deserts.
- [page](https://create.roblox.com/docs/tutorials/curriculums/building/next-steps) **[[building-art-and-assets]]** Use textures to scale and decals to stretch 2D images onto parts to decorate them.

## Tools
