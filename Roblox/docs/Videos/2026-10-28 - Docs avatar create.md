# Docs: avatar / create

[Open](https://create.roblox.com/docs/avatar/create.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs overview of avatar asset creation: asset types (bodies, makeup, accessories, animations), third-party tools (Blender, Maya, GIMP), and Studio tooling (Importer, Avatar Setup, Automatic Skinning Transfer, Accessory Fitting Tool, Animation Editor, Adaptive Animation), plus runtime avatar creation and Photo-to-Avatar generation.

## Tips
- [page](https://create.roblox.com/docs/avatar/create) **[[building-art-and-assets]]** Create avatar meshes in Blender, Maya, or GIMP, then import into Studio; almost every custom avatar asset needs both third-party work and Studio tooling.
- [page](https://create.roblox.com/docs/avatar/create) **[[building-art-and-assets]]** Use Avatar Setup to auto-generate missing essentials (geometry partitions, rig armatures, skinning weights, cages, facial animations, attachments) before Marketplace publishing.
- [page](https://create.roblox.com/docs/avatar/create) **[[3d-modeling-rigging-and-animation]]** Use Automatic Skinning Transfer for layered and facial rigid accessories so you don't have to skin each accessory manually.
- [page](https://create.roblox.com/docs/avatar/create) **[[3d-modeling-rigging-and-animation]]** Test accessories with the Accessory Fitting Tool across multiple bodies, animations, and accessory combinations before generating the final Accessory object.
- [page](https://create.roblox.com/docs/avatar/create) **[[3d-modeling-rigging-and-animation]]** Use Adaptive Animation to map internal joints so custom bodies with unusual proportions or rigs support universal animations.
- [page](https://create.roblox.com/docs/avatar/create) **[[3d-modeling-rigging-and-animation]]** Use the Animation Editor to import, design, and publish custom emotes for your rig armatures.
- [page](https://create.roblox.com/docs/avatar/create) **[[ugc-and-avatar-economy]]** Avatar in-experience creation lets players buy custom bodies that save to their Roblox inventory and work in other experiences, a route to selling avatar items.
