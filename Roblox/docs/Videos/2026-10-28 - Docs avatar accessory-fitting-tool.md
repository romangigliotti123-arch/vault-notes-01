# Docs: avatar / accessory-fitting-tool

[Open](https://create.roblox.com/docs/avatar/accessory-fitting-tool.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on the Accessory Fitting Tool (AFT), a built-in Studio tool to test custom models as Clothing (layered, cage-based) or Accessory (rigid, attachment-based) across bodies, layered items and animations before generating a Class.Accessory.

## Tips
- [page](https://create.roblox.com/docs/avatar/accessory-fitting-tool) **[[building-art-and-assets]]** Pick Clothing for layered accessories (inner/outer cage wraps body and clothing) and Accessory for rigid items attached to a fixed attachment point.
- [page](https://create.roblox.com/docs/avatar/accessory-fitting-tool) **[[building-art-and-assets]]** Set body type to the scale used while sculpting; it only affects rigid accessories unless the body part has a different AvatarPartScaleType StringValue.
- [page](https://create.roblox.com/docs/avatar/accessory-fitting-tool) **[[building-art-and-assets]]** Test accessories on multiple default bodies, layered items, and animations before generating, since fit issues show up across combinations.
- [page](https://create.roblox.com/docs/avatar/accessory-fitting-tool) **[[building-art-and-assets]]** For minor cage tweaks use the AFT cage editor; for major fit or sculpting changes, edit cage meshes in third-party modeling software and reimport.
- [page](https://create.roblox.com/docs/avatar/accessory-fitting-tool) **[[building-art-and-assets]]** Disable Move snapping when editing individual cage vertices for detailed positional changes; use Falloff Distance to control how many nearby vertices follow.
- [page](https://create.roblox.com/docs/avatar/accessory-fitting-tool) **[[building-art-and-assets]]** Keep rigid accessories inside the bounding box; the box turns red when the accessory is outside the valid placement space.
- [page](https://create.roblox.com/docs/avatar/accessory-fitting-tool) **[[building-art-and-assets]]** Toggle auto-skinning between EnabledPreserved and EnabledOverride; override can give better results depending on asset and skinning quality.
- [page](https://create.roblox.com/docs/avatar/accessory-fitting-tool) **[[ugc-and-avatar-economy]]** Make sure accessory designs adhere to Marketplace policies before selling on the Marketplace.
- [page](https://create.roblox.com/docs/avatar/accessory-fitting-tool) **[[matchmaking-and-teleport]]** Use playtest from the AFT to check your avatar with the selected body and accessories in-game at any stage of testing.
