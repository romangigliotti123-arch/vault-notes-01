# Docs: production / promotion / share-links

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/production/promotion/share-links.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs for Share Links: trackable off-platform links for a game, created in Creator Dashboard under Creations > Share Links. Covers tracking metrics by channel, using custom LaunchData via GetJoinData/LaunchData to give perks to link users, and the steps to create a link. Ownership rules apply for group games.

## Tips
- [page](https://create.roblox.com/docs/production/promotion/share-links) **[[ads-and-sponsored-experiences]]** Create a separate share link for each off-platform channel so acquisition metrics can be compared per channel.
- [page](https://create.roblox.com/docs/production/promotion/share-links) **[[analytics-metrics]]** Use the Acquisition page to see new users arriving at the game details page via share links and which channel brings the most engaged users.
- [page](https://create.roblox.com/docs/production/promotion/share-links) **[[social-features-and-virality]]** Enable custom LaunchData on a share link and read it with Player:GetJoinData().LaunchData to grant in-game perks to users who join through that link.
- [page](https://create.roblox.com/docs/production/promotion/share-links) **[[ads-and-sponsored-experiences]]** For group-owned games, create share links from the group account and ensure you have the required group permission; you must own the game to create links.

## Numbers
- [page](https://create.roblox.com/docs/production/promotion/share-links) Share links per game: **No limit** (Create as many links as needed, e.g. one per channel)

## Tools
Creator Dashboard (Creations > Share Links), Player:GetJoinData() / LaunchData
