# Docs: education / lesson-plans / roblox-developer-lesson

[Open](https://create.roblox.com/docs/education/lesson-plans/roblox-developer-lesson.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Education lesson plan for a 5-session "Roblox developer 101" course. Covers Studio basics, scripting fundamentals (properties, functions, if/then traps), and building a multi-session adventure game with leaderboard, harvestable items, tools, selling, and upgrades, ending with playtesting for fun, challenge, and bug-free play.

## Tips
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer-lesson) **[[development-process-and-speed]]** Limit world-building scope to what can be done in about a week, such as a house with a lawn or a simple forest, and expand later.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer-lesson) **[[building-art-and-assets]]** Build with parts and terrain tools rather than the Toolbox; Toolbox assets may introduce unexpected issues into the game.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer-lesson) **[[development-process-and-speed]]** Give each terrain tool a short, fixed time slot (about six minutes) to keep starting-area building from stalling.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer-lesson) **[[scripting-and-performance]]** Indent code and write accurate comments (e.g. 'Changes color of PracticePart' not 'Runs code') to keep scripts readable as they grow.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer-lesson) **[[scripting-and-performance]]** Match exact capitalization of service and property names; a single wrong letter in names like FindFirstChildWhichIsA causes errors.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer-lesson) **[[scripting-and-performance]]** Define functions above the event connection that calls them (e.g. giveUpgrade() above clickDetector.MouseClick), since order matters.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer-lesson) **[[scripting-and-performance]]** Name the leaderstats folder exactly "leaderstats" or the leaderboard script will not create the leaderboard.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer-lesson) **[[development-process-and-speed]]** Set strict time limits for playtesting (e.g. one minute) and give testers a specific goal, such as checking a tool harvests an item as intended.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer-lesson) **[[playtesting-and-feedback]]** Have a peer playtest the game and give feedback before finishing; evaluate against fun, challenging-but-fair, and error/glitch-free goals.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer-lesson) **[[core-loops-and-game-design]]** Design the core loop as collect, sell, upgrade: a tool harvests items, items sell for gold, gold buys upgrades that increase collection.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer-lesson) **[[core-loops-and-game-design]]** Tune starting gold and space variables to keep the game challenging but not frustrating or punishing.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer-lesson) **[[core-loops-and-game-design]]** Plan the game on paper first (game design document with simple shapes) before building in Studio.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer-lesson) **[[first-session-onboarding]]** Show a finished example of the game at the start so players and learners see the target experience.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer-lesson) **[[scripting-and-performance]]** Set Anchored on for parts that fall or disappear during playtesting.

## Numbers
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer-lesson) Course length: **5 sessions** (Covers Studio basics through final playtest in a classroom course)
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer-lesson) Starting-area build time: **At most 6 minutes per terrain tool demo** (Session 3 guided world creation before students expand later)
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer-lesson) Playtest time limit: **About 1 minute** (Suggested strict limit during session 4 playtesting)
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer-lesson) Guided tutorial time (Coding Fundamentals): **20 min properties, 35 min trap** (Session 2 timing breakdown)
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer-lesson) Ask 3 Before Me rule: **Ask three peers before the instructor** (Classroom help-seeking rule for troubleshooting)
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer-lesson) Harvest flag: **BoolValue named CanHarvest set to true** (Required on each harvestable item in the adventure game)

## Games
