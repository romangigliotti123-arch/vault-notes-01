# Docs: production / publishing / rights-manager

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/production/publishing/rights-manager.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox docs page on Rights Manager, the IP tool for rights holders to request removal of unauthorized games, avatar items, and assets. Covers registration prerequisite, filing a removal request (up to 250 links), review statuses, and re-filing rejected requests.

## Tips
- [page](https://create.roblox.com/docs/production/publishing/rights-manager) **[[business-and-payouts]]** Register as a rights holder and verify IP ownership before using Rights Manager; filing requires an accepted registration.
- [page](https://create.roblox.com/docs/production/publishing/rights-manager) **[[common-mistakes]]** After submitting a removal request, you cannot edit it while Roblox reviews it; double-check links and details first.
- [page](https://create.roblox.com/docs/production/publishing/rights-manager) **[[common-mistakes]]** For assets inside a game, include a screenshot and location details so Roblox can find the reported asset.
- [page](https://create.roblox.com/docs/production/publishing/rights-manager) **[[business-and-payouts]]** If a removal request is rejected, you can file a new request with additional information if infringement persists.

## Numbers
- [page](https://create.roblox.com/docs/production/publishing/rights-manager) Max creation links per removal request: **250** (Provide up to 250 links to creations reported in one request)

## Tools
Rights Manager (Intellectual Property > Removal Requests)
