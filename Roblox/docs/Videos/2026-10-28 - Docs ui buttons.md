# Docs: ui / buttons

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/ui/buttons.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on GuiButtons: TextButton vs ImageButton, placing buttons on screen (ScreenGui) or on part faces (SurfaceGui), appearance properties, hover/pressed image states, and scripting Activated/SecondaryActivated events with a random-color example.

## Tips
- [page](https://create.roblox.com/docs/ui/buttons) **[[ui-ux-design]]** Use SecondaryActivated for right-click on desktop and long press on mobile so secondary actions work cross-platform.
- [page](https://create.roblox.com/docs/ui/buttons) **[[ui-ux-design]]** Connect button logic to Activated, which fires on click or tap, rather than raw input events for cross-platform support.
- [page](https://create.roblox.com/docs/ui/buttons) **[[building-and-level-design]]** If a SurfaceGui button is not visible, try a different SurfaceGui.Face value (Top, Bottom, Front, Back, Left, Right).
- [page](https://create.roblox.com/docs/ui/buttons) **[[ui-ux-design]]** Use ImageButton HoverImage and PressedImage variants to give visual feedback on hover and press.
