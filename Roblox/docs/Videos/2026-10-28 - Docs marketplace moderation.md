# Docs: marketplace / moderation

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/marketplace/moderation.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Creator Docs page on Marketplace moderation: review timing, policy/metadata compliance, post-sale removal refunds, appeals and IP notices, and how to archive avatar items (only if 180+ days old; Limited items unsupported).

## Tips
- [page](https://create.roblox.com/docs/marketplace/moderation) **[[titles-descriptions]]** Follow general metadata best practices (title, description) when uploading to improve chances of clearing Marketplace moderation.
- [page](https://create.roblox.com/docs/marketplace/moderation) **[[common-mistakes]]** Ensure assets adhere to the Marketplace Policy before upload; non-compliant items can be rejected or removed.
- [page](https://create.roblox.com/docs/marketplace/moderation) **[[business-and-payouts]]** Know that if Roblox removes a sold item, purchasers are refunded and pending payments for it are cancelled.
- [page](https://create.roblox.com/docs/marketplace/moderation) **[[age-ratings-moderation-and-tos]]** Appeal incorrect moderation decisions with the moderation staff; use the IP infringement notice form for IP-related removals.

## Numbers
- [page](https://create.roblox.com/docs/marketplace/moderation) Marketplace moderation review time: **up to 24 hours** (Before an uploaded item can be sold)
- [page](https://create.roblox.com/docs/marketplace/moderation) Minimum age to archive avatar item: **180 days** (Since upload date)
