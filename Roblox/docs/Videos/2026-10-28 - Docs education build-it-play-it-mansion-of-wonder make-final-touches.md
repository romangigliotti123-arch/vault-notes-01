[Open](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/make-final-touches.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Creator Docs page for the Mansion of Wonder education project's final touches step: tuning explosion particle Size, Speed, LightEmission, RotSpeed, Lifetime, and randomized min/max values in the particle emitter properties.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/make-final-touches) **[[vfx-and-particles]]** Set particle Size between 1 and 10 for best results; different particle textures may suit different sizes.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/make-final-touches) **[[vfx-and-particles]]** Set particle Speed between 10 (slow) and 100 (fast) to control whether particles burst or creep out.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/make-final-touches) **[[vfx-and-particles]]** Use a short Lifetime (e.g. 0.5s) for a quick snappy blast, or a longer one (e.g. 2s) for lingering effects.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/make-final-touches) **[[vfx-and-particles]]** Randomize properties like Lifetime and Rotation with min and max values so particles feel less repetitive.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/make-final-touches) **[[vfx-and-particles]]** Run the project after each property change to test the particle and keep adjusting until it looks right.

## Numbers
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/make-final-touches) Particle Size: **1 to 10 recommended** (Best-results range for explosion particle Size property)
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/make-final-touches) Particle Speed (Emission): **10 (slow) to 100 (fast)** (Suggested range for Speed in Emission section)
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/make-final-touches) LightEmission: **0 (opaque) to 1 (glowing)** (Range; docs show 0, 0.5, 1.0 examples)
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/make-final-touches) Lifetime example: **0.5s snappy, 2s lingering** (Example values in seconds for explosion lifetime)
