# Docs: discovery-faq

[Open](https://create.roblox.com/docs/discovery-faq.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox official FAQ on Discovery and the Recommended for You (RFY) algorithm: key ranking signals, impression drivers, how new and old games are evaluated, how ads and quality enforcement affect reach, and thumbnail/title reuse rules.

## Tips
- [page](https://create.roblox.com/docs/discovery-faq) **[[core-loops-and-game-design]]** If retention is low, fix core gameplay first; once retention is strong, improve monetization to increase Home impressions.
- [page](https://create.roblox.com/docs/discovery-faq) **[[analytics-metrics]]** Check Creator Analytics > Overview and Acquisition > Home Recommendations to see where your game is strong and where to focus.
- [page](https://create.roblox.com/docs/discovery-faq) **[[discovery-algorithm]]** Focus on play through rate, first play bounce rate, play days per user and playtime per user; these are the most important RFY signals.
- [page](https://create.roblox.com/docs/discovery-faq) **[[titles-descriptions]]** Use accurate genre and category tags and an accurate gameplay video; inaccurate descriptions cause bounces that hurt signals.
- [page](https://create.roblox.com/docs/discovery-faq) **[[discovery-algorithm]]** Expect a temporary PTR drop when impressions rise to new users; PTR should stabilize as traffic patterns normalize.
- [page](https://create.roblox.com/docs/discovery-faq) **[[discovery-algorithm]]** Don't expect a penalty for weak early performance: fix onboarding or mechanics and the algorithm keeps testing with new users.
- [page](https://create.roblox.com/docs/discovery-faq) **[[common-mistakes]]** Don't assume ads hurt RFY; a drop in RFY impressions after ads is not a penalty, because ad-acquired users are excluded from RFY signals.
- [page](https://create.roblox.com/docs/discovery-faq) **[[common-mistakes]]** Avoid leading with giveaways, misleading or mismatched metadata, and non-unique games; these can reduce reach.
- [page](https://create.roblox.com/docs/discovery-faq) **[[thumbnails-icons]]** Make thumbnails, titles and gameplay distinct; indistinguishable games face reduced discoverability. Reusing your own old thumbnail alone shouldn't hurt discoverability.
- [page](https://create.roblox.com/docs/discovery-faq) **[[development-process-and-speed]]** Check the Creator Dashboard banner (updated daily) for reduced-exposure status; file a Bug Report with Universe ID if you think it's wrong.
- [page](https://create.roblox.com/docs/discovery-faq) **[[discovery-algorithm]]** Old games can regrow: a very low minimum of plays from any source lets the ranking stage test the game daily and raise impressions if retention improves.
- [page](https://create.roblox.com/docs/discovery-faq) **[[roblox-platform-changes]]** Impression changes can come from seasonality (weekly peak Saturday, summer, holidays), competitor improvements, or algorithm changes, not only your game.

## Numbers
- [page](https://create.roblox.com/docs/discovery-faq) RFY candidate list per user: **Narrows to roughly 100 games on a user's Home page** (From all eligible games, personalized per user)
- [page](https://create.roblox.com/docs/discovery-faq) Day 2-7 play days window: **6 days** (Play days averaged across RFY-acquired users, out of 6)
- [page](https://create.roblox.com/docs/discovery-faq) Signal staging for new games: **PTR and bounce, then Day 1, Day 2-7, Day 8-28** (New games don't wait 28 days for Home signals)
- [page](https://create.roblox.com/docs/discovery-faq) Signal aggregation: **Per-user averages, not totals** (Designed so small games with engaged users aren't disadvantaged)
