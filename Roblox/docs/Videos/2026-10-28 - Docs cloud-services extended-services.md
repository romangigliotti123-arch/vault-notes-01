# Docs: cloud-services / extended-services

[Open](https://create.roblox.com/docs/cloud-services/extended-services.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox docs for Extended Services: a paid add-on letting creators exceed default limits for data stores, memory stores, text-to-speech, speech-to-text and compute. Covers eligibility, unlocking via payment info, monthly budgets (min $0.50), account statuses, Compute diagnostics, billing dashboard, pricing and supported countries.

## Tips
- [page](https://create.roblox.com/docs/cloud-services/extended-services) **[[scripting-and-performance]]** Before paying for more CPU, reduce the work your servers do; Extended Services for Compute is rarely needed.
- [page](https://create.roblox.com/docs/cloud-services/extended-services) **[[optimization-and-streaming]]** Diagnose Compute need first: check server heartbeat for persistent drops below 60 FPS and CPU core utilization on the Performance dashboard.
- [page](https://create.roblox.com/docs/cloud-services/extended-services) **[[pricing]]** Set a monthly budget per resource; billing occurs at month end or when usage reaches $10 USD, whichever comes first. Minimum budget is $0.50 USD.
- [page](https://create.roblox.com/docs/cloud-services/extended-services) **[[analytics-metrics]]** Watch for email alerts at 80% and 100% of budget; decreasing budget below month-to-date usage throttles the service.
- [page](https://create.roblox.com/docs/cloud-services/extended-services) **[[data-persistence]]** Default data store limits scale with CCU (e.g. Get = 250 + CCU×40 requests/min); extended pricing applies only when you need more.
- [page](https://create.roblox.com/docs/cloud-services/extended-services) **[[business-and-payouts]]** Only the group owner must meet eligibility and unlock Extended Services for group-owned games; Overdue gives a 7-day grace period before suspension.

## Numbers
- [page](https://create.roblox.com/docs/cloud-services/extended-services) Minimum monthly budget: **$0.50 USD** (Minimum per-resource monthly budget for Extended Services)
- [page](https://create.roblox.com/docs/cloud-services/extended-services) Auto-billing threshold: **$10 USD** (Charged at month end or when usage reaches this, whichever first)
- [page](https://create.roblox.com/docs/cloud-services/extended-services) Overdue grace period: **7 days** (Before suspension after automatic payment failure)
- [page](https://create.roblox.com/docs/cloud-services/extended-services) Compute free allowance: **100K playtime hours/month** (Then $0.001 per playtime hour, when enrolled in Compute)
- [page](https://create.roblox.com/docs/cloud-services/extended-services) Standard data store Get (extended): **$0.08 / 1M requests** (Default: 250 + CCU×40 requests per minute)
- [page](https://create.roblox.com/docs/cloud-services/extended-services) Memory store requests (extended): **$0.003 / 1M requests** (Default: 1000 + CCU×120 requests per minute)
- [page](https://create.roblox.com/docs/cloud-services/extended-services) Text-to-speech (extended): **$5.00 / 1M requests** (Default: 1 + CCU×6 requests per minute)
- [page](https://create.roblox.com/docs/cloud-services/extended-services) Speech-to-text (extended): **$1 / 1M requests** (Default: 1 + CCU×5 requests per minute)
- [page](https://create.roblox.com/docs/cloud-services/extended-services) Data store storage (extended): **$0.12 / GB per month** (Default: 100 MB + 1 MB × lifetime players)
