# Docs: avatar / rigid-accessories

[Open](https://create.roblox.com/docs/avatar/rigid-accessories.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox documentation overview of rigid accessories: 3D objects that attach to avatar attachment points and can be repositioned by users per body type. Covers the two layers (mesh/textures and attachments), required components, the Blender/Maya export workflow, Avatar Setup tool, and resource list. Distinguishes rigid from layered accessories.

## Tips
- [page](https://create.roblox.com/docs/avatar/rigid-accessories) **[[building-art-and-assets]]** Export all avatar components in a single .fbx or .gltf file for import into Studio when creating a rigid accessory in Blender or Maya.
- [page](https://create.roblox.com/docs/avatar/rigid-accessories) **[[building-art-and-assets]]** A rigid accessory requires a single MeshPart nested under a single Model; textures are applied via a child SurfaceAppearance or the MeshPart TextureID property.
- [page](https://create.roblox.com/docs/avatar/rigid-accessories) **[[building-art-and-assets]]** Use the Accessory Fitting Tool to automatically generate attachment points for rigid accessories instead of placing them manually.
- [page](https://create.roblox.com/docs/avatar/rigid-accessories) **[[3d-modeling-rigging-and-animation]]** Follow the Roblox rigid accessory specifications and Marketplace requirements so accessories behave consistently across games.
- [page](https://create.roblox.com/docs/avatar/rigid-accessories) **[[3d-modeling-rigging-and-animation]]** Use the Avatar Setup tool in Studio to process an imported custom rigid accessory into an avatar asset ready for Marketplace sale.
- [page](https://create.roblox.com/docs/avatar/rigid-accessories) **[[ugc-and-avatar-economy]]** Before building a first accessory, review Roblox's reference Blender/Maya project files, Studio tooling, and the basic rigid accessory tutorial.
