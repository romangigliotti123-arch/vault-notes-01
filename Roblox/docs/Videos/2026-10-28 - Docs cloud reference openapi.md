## Summary
Roblox docs page describing the OpenAPI 3.0.4 document covering all Roblox Cloud APIs (openapi.json in the creator-docs repo), how to use it with Swagger Editor, Postman and OpenAPI Generator, a warning that it is under active development, and a table of x-roblox vendor extensions, most of which are experimental.

## Tips
- [page](https://create.roblox.com/docs/cloud/reference/openapi) **[[version-control-and-tooling]]** Import Roblox's openapi.json into Swagger Editor or Postman to test Cloud API calls and speed up development.
- [page](https://create.roblox.com/docs/cloud/reference/openapi) **[[version-control-and-tooling]]** Use OpenAPI Generator with openapi.json to generate client libraries in your preferred programming language.
- [page](https://create.roblox.com/docs/cloud/reference/openapi) **[[testing-debugging-and-qa]]** The OpenAPI document is still under active development and may be inaccurate; verify endpoint behaviour and report bugs when found.
- [page](https://create.roblox.com/docs/cloud/reference/openapi) **[[version-control-and-tooling]]** Don't rely on x-roblox-* vendor extensions long-term; they are experimental and may change without notice in favour of official OpenAPI fields.

## Numbers
