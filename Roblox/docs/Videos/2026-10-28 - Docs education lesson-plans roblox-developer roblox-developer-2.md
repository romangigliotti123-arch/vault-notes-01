# Docs: education / lesson-plans / roblox-developer / roblox-developer-2

## Summary
Teacher lesson plan for a 65-minute Roblox coding fundamentals class covering properties, loops, functions and if/then statements through a color-changing platform and a trap mini-project, with troubleshooting and commenting habits.

## Tips
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-2) **[[first-session-onboarding]]** Run a 5-minute intro framing mini-projects as reusable pieces that will later be added to a larger game.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-2) **[[common-mistakes]]** Check capitalization carefully; one wrong letter in long API names like FindFirstChildWhichIsA causes errors.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-2) **[[development-process-and-speed]]** When stuck, redo the last few steps first, then ask a peer, before asking the teacher (Ask 3 Before Me).
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-2) **[[scripting-and-performance]]** Write comments that describe specific actions, e.g. 'Changes color of PracticePart', not vague 'Runs code'.

## Numbers
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-2) Lesson duration: **65 minutes total (5 intro, 20 properties, 35 trap, 5 wrap-up)**
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-2) Peers to ask before teacher: **3 (Ask 3 Before Me)**
