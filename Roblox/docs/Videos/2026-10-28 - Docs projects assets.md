# Docs: projects / assets

## Summary
Roblox docs page on assets: cloud asset IDs (rbxassetid), asset types for games, places and avatars, packages, URI schemes (rbxassetid, rbxasset, rbxthumb, rbxgameasset, rbxhttp, rbxtemp, https), privacy defaults, moderation timing, Asset Manager/Toolbox/Importer tools, and archiving.

## Tips
- [page](https://create.roblox.com/docs/projects/assets) **[[building-art-and-assets]]** Use rbxassetid instead of rbxgameasset if an asset must work across multiple games; rbxgameasset only resolves in the game where it was uploaded.
- [page](https://create.roblox.com/docs/projects/assets) **[[building-art-and-assets]]** Assets are private by default on import; distribute to the Creator Store to let everyone use the asset ID.
- [page](https://create.roblox.com/docs/projects/assets) **[[building-art-and-assets]]** Use Packages for reusable asset hierarchies so a package update can be applied to all copies or set to auto-update.
- [page](https://create.roblox.com/docs/projects/assets) **[[building-art-and-assets]]** Import assets before publishing; unapproved assets in the moderation queue are invisible to users until Roblox approves them.
- [page](https://create.roblox.com/docs/projects/assets) **[[common-mistakes]]** Do not expect rbxgameasset names to load when pasting objects into another game; they will fail or load a different same-named asset.
- [page](https://create.roblox.com/docs/projects/assets) **[[ugc-and-avatar-economy]]** Archive unused development items in Creations > Development Items; archived assets disappear from games, including your own.
- [page](https://create.roblox.com/docs/projects/assets) **[[building-art-and-assets]]** Use the Toolbox to reuse any asset you or your groups have imported, across all games, rather than keeping local copies.

## Numbers
