# Docs: resources / the-mystery-of-duvall-drive

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.

## Summary
Official Roblox docs showcase for The Mystery of Duvall Drive, an uncopylocked, editable demo house. It walks through building the environment from sketches, materials via MaterialService and SurfaceAppearance, UI-driven lore, Streaming Enabled, movement, and volumetric audio with SoundService. It explains how and why each Studio feature was used.

## Tips
- [page](https://create.roblox.com/docs/resources/the-mystery-of-duvall-drive) **[[building-and-level-design]]** Build from simple sketches or a blueprint first, then iterate toward the final environment while checking that it stays fun at every stage.
- [page](https://create.roblox.com/docs/resources/the-mystery-of-duvall-drive) **[[building-art-and-assets]]** Use MaterialService with custom materials and SurfaceAppearance to make each room's normal and corrupted states look distinct.
- [page](https://create.roblox.com/docs/resources/the-mystery-of-duvall-drive) **[[optimization-and-streaming]]** Enable Streaming Enabled for large, complex games and structure the world and code to work with streaming.
- [page](https://create.roblox.com/docs/resources/the-mystery-of-duvall-drive) **[[sound-and-music]]** Use SoundService with volumetric audio to craft distinct soundscapes per area or state, such as normal versus corrupted worlds.

## Games
- **The Mystery of Duvall Drive**: Official uncopylocked, editable demo showing MaterialService, Packages, volumetric audio and Streaming Enabled in a dark house environment.
- **Beyond the Dark**: Earlier official Roblox environment showcase that this document follows in format, from sketches to a rich 3D environment.

## Tools
Roblox Studio, MaterialService, SurfaceAppearance, SoundService
