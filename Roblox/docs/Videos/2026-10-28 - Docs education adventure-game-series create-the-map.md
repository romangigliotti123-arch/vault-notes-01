# Docs: education / adventure-game-series / create-the-map

[Open](https://create.roblox.com/docs/education/adventure-game-series/create-the-map.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Creator Docs tutorial on planning and building an adventure game map. Covers the game loop (explore, harvest, sell, buy bag upgrades), writing a game design document with prompts for setting/items/tools/upgrades, sketching a map layout, and building terrain with the Terrain Editor's Paint and Draw tools.

## Tips
- [page](https://create.roblox.com/docs/education/adventure-game-series/create-the-map) **[[core-loops-and-game-design]]** Define the game loop as a cycle of mechanics (e.g. explore, harvest, sell, upgrade) before building; each loop step should be a distinct player action.
- [page](https://create.roblox.com/docs/education/adventure-game-series/create-the-map) **[[development-process-and-speed]]** Write a short game design document first, covering vision and world sketches, to speed up development and make feedback easier to gather.
- [page](https://create.roblox.com/docs/education/adventure-game-series/create-the-map) **[[building-and-level-design]]** Annotate the map layout with start point, harvestable item placement, sell locations, upgrade locations and environment details before building.
- [page](https://create.roblox.com/docs/education/adventure-game-series/create-the-map) **[[building-art-and-assets]]** Use the Terrain Editor Draw tool with Brush Mode to add terrain for hills and grasslands and subtract it for cliffs and rivers.
- [page](https://create.roblox.com/docs/education/adventure-game-series/create-the-map) **[[building-and-level-design]]** Rotate the camera while sculpting terrain, since terrain can look different from different angles.

## Tools
Roblox Studio, Terrain Editor, Paint tool, Draw tool, Brush Mode toggle
