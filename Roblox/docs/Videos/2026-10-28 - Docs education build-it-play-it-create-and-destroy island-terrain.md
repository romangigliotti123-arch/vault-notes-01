## Summary
Roblox Creator Docs tutorial page on finishing a map with island-shaped terrain. Covers opening the Terrain Editor, publishing before editing as a safety net, and switching to top-down view to make terrain edits easier.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/island-terrain) **[[version-control-and-tooling]]** Publish the game before major terrain edits so you can revert to the saved version if the changes turn out badly.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/island-terrain) **[[building-and-level-design]]** Use top-down view when editing terrain; it makes shaping map edges easier than perspective view.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/island-terrain) **[[building-art-and-assets]]** Customise map edges with Terrain Editor tools so the map reads as a natural island rather than a square.
