# Docs: projects

[Open](https://create.roblox.com/docs/projects.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs overview of projects: places (data model per place), cloud-stored assets referenced by asset ID, reusable packages, game settings categories (Basic Info, Communication, Permissions, Monetization, Localization, Avatar), built-in collaboration, and Studio testing modes.

## Tips
- [page](https://create.roblox.com/docs/projects) **[[building-art-and-assets]]** Use Packages for repeated objects (e.g. a tree duplicated many times); edit once in the package and the change propagates to every instance.
- [page](https://create.roblox.com/docs/projects) **[[building-art-and-assets]]** Start environments with graybox assets in packages, then swap in final art later; replaced assets keep original positions and orientations.
- [page](https://create.roblox.com/docs/projects) **[[building-and-level-design]]** Organize objects intentionally in the data model; it is essential for functionality and long-term maintenance of the project.
- [page](https://create.roblox.com/docs/projects) **[[playtesting-and-feedback]]** Use Rapid playtesting, multi-client simulation, device emulation and collaborative playtesting in Studio before releasing to the public.
- [page](https://create.roblox.com/docs/projects) **[[ui-ux-design]]** Use device emulation to check mobile control behaviour and how on-screen UI displays across different screen sizes and aspect ratios.
- [page](https://create.roblox.com/docs/projects) **[[team-and-budget]]** Use group roles to control which members can collaborate; collaborators can edit the same scripts, test locally, then commit to the cloud project.
- [page](https://create.roblox.com/docs/projects) **[[development-process-and-speed]]** Test on PC, mobile, VR via the Roblox app instead of compiling builds or waiting for app store approval.
- [page](https://create.roblox.com/docs/projects) **[[cross-platform-and-console]]** Newly published games are only visible to the creator, Edit/Playtest users and qualifying group members until you release them to a wider audience.
