# Docs: creator-programs / developer-awards

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/creator-programs/developer-awards.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox docs for the Developer Awards creator program (status: open). Lists award categories tied to MAU milestones (avatar crowns), 40M+ lifetime Robux earned over a rolling 12 months (swag bags), and lifetime play-hour milestones (trophies). Eligibility: age 13+, game owner. No application; Roblox contacts winners.

## Tips
- [page](https://create.roblox.com/docs/creator-programs/developer-awards) **[[mindset-and-strategy]]** Track milestones that trigger awards (MAU, rolling 12-month Robux, lifetime play hours) as long-term growth targets; awards are granted automatically with no application.
- [page](https://create.roblox.com/docs/creator-programs/developer-awards) **[[analytics-metrics]]** Monitor MAU, 12-month rolling Robux earned, and lifetime play hours; these are the metrics Roblox uses to recognise developer milestones.

## Numbers
- [page](https://create.roblox.com/docs/creator-programs/developer-awards) Virtual Items award: MAU milestones: **100, 1K, 10K, 100K, 1M, 10M, 100M, 1B+ MAU (crown per milestone)**
- [page](https://create.roblox.com/docs/creator-programs/developer-awards) Swag Bags award threshold: **40M+ lifetime Robux earned, rolling 12-month**
- [page](https://create.roblox.com/docs/creator-programs/developer-awards) Trophy award: lifetime play-hour milestones: **10M, 20M, 50M, 100M, 250M, 1B, 5B, 10B+ hours**
