# Docs: art / accessories / creating / unwrapping

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/art/accessories/creating/unwrapping.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox docs tutorial on UV unwrapping clothing meshes in Blender: marking seams with Alt-click and Make Seam, unwrapping selected faces, then entering Texture Paint mode to view UVs before painting a texture. Notes PBR textures are out of scope.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/creating/unwrapping) **[[building-art-and-assets]]** Create seams along natural separations (e.g. shirt center front/back edges) before unwrapping so Blender's UV layout splits the mesh into sensible front and back surfaces.
- [page](https://create.roblox.com/docs/art/accessories/creating/unwrapping) **[[3d-modeling-rigging-and-animation]]** In Blender Edit mode, press 2 for edge select, Alt-click edges, then right-click > Make Seam; repeat until seams form a continuous loop.
- [page](https://create.roblox.com/docs/art/accessories/creating/unwrapping) **[[3d-modeling-rigging-and-animation]]** Select all vertices (A) and use UV > Unwrap in Edit mode to generate the UV map from your seams, then verify layout in Texture Paint mode.
- [page](https://create.roblox.com/docs/art/accessories/creating/unwrapping) **[[building-art-and-assets]]** Use Blender Texture Paint mode to apply a base colour and smaller design directly to the UV-mapped clothing; PBR textures need third-party tools like Substance Painter.

## Tools
Blender, Blender Texture Paint mode, Substance Painter (for PBR, not covered)
