# Docs: production / promotion / social-media-links

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/production/promotion/social-media-links.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs on social media links: who can add them (age 16+ verified, up to three links), who can see them (age-gated visibility rules for user profiles), Community Standards limits on referencing links inside games, and step-by-step setup for game details pages, Creator Store assets, and user profiles.

## Tips
- [page](https://create.roblox.com/docs/production/promotion/social-media-links) **[[community-and-discord]]** Add up to three social media links on your game details page; each link type (Facebook, Twitter, YouTube, Twitch, Discord, Guilded, Roblox community) can be used only once.
- [page](https://create.roblox.com/docs/production/promotion/social-media-links) **[[community-and-discord]]** Verify your age as 16+ (facial age estimation or government ID) before you can add social links; otherwise the add UI is hidden.
- [page](https://create.roblox.com/docs/production/promotion/social-media-links) **[[common-mistakes]]** Do not put social URLs or invite codes inside the game itself; Community Standards only allow links on the main details page. Say 'Links on our game's page' instead.
- [page](https://create.roblox.com/docs/production/promotion/social-media-links) **[[community-and-discord]]** For group or community-owned games, keep at least one collaborator aged 16+ verified; otherwise links are auto-deleted after 90 days once all such collaborators leave.

## Numbers
- [page](https://create.roblox.com/docs/production/promotion/social-media-links) Max social links per game details page: **3**
- [page](https://create.roblox.com/docs/production/promotion/social-media-links) Days until links auto-delete after all 16+ verified collaborators leave: **90**
- [page](https://create.roblox.com/docs/production/promotion/social-media-links) Minimum verified age to add/see social links: **16**
- [page](https://create.roblox.com/docs/production/promotion/social-media-links) Social link types available: **7**
