# Docs: production / publishing / experience-icons

[Open](https://create.roblox.com/docs/production/publishing/experience-icons.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Creator Docs page on experience icons: the icon's role in brand recognition, the 512×512 square upload spec, the step-by-step upload path in the Creator Dashboard, and best practices for quality, relevant content, and color/contrast.

## Tips
- [page](https://create.roblox.com/docs/production/publishing/experience-icons) **[[thumbnails-icons]]** Upload a square icon at least 512×512 px so it stays sharp across the Roblox site and app.
- [page](https://create.roblox.com/docs/production/publishing/experience-icons) **[[thumbnails-icons]]** Preview the icon at ~150×150 px, since it scales down in some places, and confirm details stay clear.
- [page](https://create.roblox.com/docs/production/publishing/experience-icons) **[[thumbnails-icons]]** Make the icon express the game's theme, tone, and/or genre, since it gets prominent Home page placement.
- [page](https://create.roblox.com/docs/production/publishing/experience-icons) **[[thumbnails-icons]]** Avoid the default auto-generated icon; it may not match your game's theme and reduces recognition.
- [page](https://create.roblox.com/docs/production/publishing/experience-icons) **[[thumbnails-icons]]** Avoid ambiguous graphics; they cause confusion about what players should expect when joining.
- [page](https://create.roblox.com/docs/production/publishing/experience-icons) **[[thumbnails-icons]]** Use color and contrast to signal mood: bright saturated for fantasy/dreamy, muted for somber, high contrast for horror.
- [page](https://create.roblox.com/docs/production/publishing/experience-icons) **[[thumbnails-icons]]** Expect icon moderation to pass before it shows to others; plan upload timing accordingly.
- [page](https://create.roblox.com/docs/production/publishing/experience-icons) **[[thumbnails-icons]]** Use supplementary image and video thumbnails to further promote the game, alongside the single icon per locale.

## Numbers
- [page](https://create.roblox.com/docs/production/publishing/experience-icons) Icon template size: **512×512 px** (Recommended square template for game icon uploads)
- [page](https://create.roblox.com/docs/production/publishing/experience-icons) Small display size: **150×150 px** (Icons scale down to this size in some Roblox site/app locations)
- [page](https://create.roblox.com/docs/production/publishing/experience-icons) Icons per locale: **1** (Only one game icon displayed per locale)
