# Docs: cloud / reference / risk-levels

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/cloud/reference/risk-levels.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Open Cloud docs page defining the four "Try it out" risk levels (Low, Medium, High, Critical), what each allows (dialogs, banners, cookie attachment), and which endpoints fall into each category. Reference material, not a game-making guide.

## Tips
- [page](https://create.roblox.com/docs/cloud/reference/risk-levels) **[[ai-and-tools]]** Review an endpoint's functionality and potential impact before testing, especially medium and high risk endpoints that can modify your data.

## Numbers
- [page](https://create.roblox.com/docs/cloud/reference/risk-levels) Try-it-out risk levels: **4 (Low, Medium, High, Critical)** (Critical endpoints have Try it out disabled)
- [page](https://create.roblox.com/docs/cloud/reference/risk-levels) Medium risk confirmation dialog frequency: **once per endpoint per browser session** (Medium risk endpoints show a confirmation dialog before sending)
- [page](https://create.roblox.com/docs/cloud/reference/risk-levels) High risk confirmation dialogs: **2 (second dialog enforced per session, not per endpoint)** (High risk endpoints, typically DELETE and destructive actions)

## Tools
Roblox Open Cloud API documentation try-it-out feature
