## Summary
Roblox official docs index for tutorials: three creation areas (games, avatars, avatar items), plus short "use case" tutorials by category (modeling, environments, effects, UI, physics, animation, scripting, input/camera) and long-form "curriculum paths" (environmental art, gameplay scripting, UI design).

## Tips
- [page](https://create.roblox.com/docs/tutorials) **[[development-process-and-speed]]** Start with the 'Create your first game' tutorial (3D platformer where coins trade for jump power) to learn core Studio concepts before advanced work.
- [page](https://create.roblox.com/docs/tutorials) **[[building-art-and-assets]]** Learn solid modeling in Studio before rigging; use Blender with Roblox's template models for custom avatar characters.
- [page](https://create.roblox.com/docs/tutorials) **[[building-and-level-design]]** Use modular assets that snap together to build environments faster and in many configurations.
- [page](https://create.roblox.com/docs/tutorials) **[[building-art-and-assets]]** Use the built-in Animation Editor for basic animations, then swap default avatar animations with your own.
