# Docs: animation / capture

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/animation/capture.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on Animation Editor capture tools. Face capture uses webcam to puppeteer animation-compatible heads (up to 60s, beta feature). Body capture imports short single-shot video to generate R15 full-body keyframes. Lists setup steps and import requirements.

## Tips
- [page](https://create.roblox.com/docs/animation/capture) **[[building-art-and-assets]]** Enable File > Beta Features > Face Capture before using webcam face capture; it is off by default.
- [page](https://create.roblox.com/docs/animation/capture) **[[building-art-and-assets]]** For face capture, sit in a well-lit room, close to camera, with face centred in frame to improve tracking accuracy.
- [page](https://create.roblox.com/docs/animation/capture) **[[building-art-and-assets]]** Face capture records up to 60 seconds; use Re-Record to discard and retry a take before saving.
- [page](https://create.roblox.com/docs/animation/capture) **[[building-art-and-assets]]** Enable File > Beta Features > Live Animation Creator before importing video for body animation.

## Numbers
- [page](https://create.roblox.com/docs/animation/capture) Face capture max length: **60 seconds** (Webcam recording limit in Animation Editor)
- [page](https://create.roblox.com/docs/animation/capture) Body video max length: **<15 seconds** (Single continuous shot required for body import)
- [page](https://create.roblox.com/docs/animation/capture) Body import processing time: **about 1 minute** (Time until keyframes appear after selecting video)

## Tools
Animation Editor (Clip Editor), Face Capture (beta), Live Animation Creator (beta)
