# Docs: marketplace / sponsor-items

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/marketplace/sponsor-items.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on Sponsored Items: paid ads that promote 3D Marketplace items (not experiences). Covers bidding-based display, creating an ad cycle (24 hours to 28 days, min 10 Robux/day), reading statistics, and cancellation refunds.

## Tips
- [page](https://create.roblox.com/docs/marketplace/sponsor-items) **[[ads-and-sponsored-experiences]]** Sponsored items promote Marketplace items only; to advertise an experience use Ads Manager or the Advertising API.
- [page](https://create.roblox.com/docs/marketplace/sponsor-items) **[[ads-and-sponsored-experiences]]** Display share is proportional to Daily Budget relative to other bidders; doubling your bid roughly doubles impressions versus a rival's.
- [page](https://create.roblox.com/docs/marketplace/sponsor-items) **[[ads-and-sponsored-experiences]]** Set a target audience (gender, age, platform) and a descriptive ad name when creating a sponsored item; the name is only visible to you.
- [page](https://create.roblox.com/docs/marketplace/sponsor-items) **[[ads-and-sponsored-experiences]]** Roblox holds the full ad-cycle amount on Run. Cancelling refunds each full day left, so cancel early to recover unused days.

## Numbers
- [page](https://create.roblox.com/docs/marketplace/sponsor-items) Ad cycle duration: **24 hours to 28 days** (Sponsored item ad cycle length range)
- [page](https://create.roblox.com/docs/marketplace/sponsor-items) Minimum daily bid: **10 Robux per day** (Required to create a sponsored item)
- [page](https://create.roblox.com/docs/marketplace/sponsor-items) Bid display example: **50 / 100 / 300 Robux bids give 1x / 2x / 6x display frequency** (Three-bidder example; A=50, B=100, C=300)
- [page](https://create.roblox.com/docs/marketplace/sponsor-items) Refund rule: **Refund per full day remaining** (Example: 3-day cycle cancelled on day 1 refunds 2 days)

## Tools
Sponsored Items page (Roblox creator dashboard), Ads Manager, Advertising API
