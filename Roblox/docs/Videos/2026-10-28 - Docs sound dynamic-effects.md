# Docs: sound / dynamic-effects

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/sound/dynamic-effects.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on Dynamic effects: how to add Equalizer, Compressor, Reverb, Chorus, Distortion, Echo, Flange, PitchShift and Tremolo effects to Sound or SoundGroup objects via Explorer. Notes that a newer Audio effects system exists and is recommended for more control.

## Tips
- [page](https://create.roblox.com/docs/sound/dynamic-effects) **[[sound-and-music]]** Dynamic effects are legacy; Roblox warns a newer Audio effects set offers more control and robust use cases. Check that system first for new projects.
- [page](https://create.roblox.com/docs/sound/dynamic-effects) **[[sound-and-music]]** Add effects by hovering the Sound or SoundGroup in Explorer, clicking the ⊕ button, then choosing the dynamic effect. Adjust its properties in the Properties window.
- [page](https://create.roblox.com/docs/sound/dynamic-effects) **[[sound-and-music]]** Use EqualizerSoundEffect to muffle all audio when the player is underwater by reducing high frequencies.
- [page](https://create.roblox.com/docs/sound/dynamic-effects) **[[sound-and-music]]** Use ReverbSoundEffect in large interior rooms to simulate reflections, e.g. gymnasium or stadium spaces.

## Tools
Roblox Studio Explorer, EqualizerSoundEffect, CompressorSoundEffect, ReverbSoundEffect
