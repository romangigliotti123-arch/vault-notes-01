# Docs: avatar / character-bodies

[Open](https://create.roblox.com/docs/avatar/character-bodies.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs overview of avatar character bodies: four layers (body parts and textures, rigging armature, facial animation data, cage meshes and attachments), required counts and naming, creation workflows, and the resources provided for building custom avatar bodies for Marketplace sale.

## Tips
- [page](https://create.roblox.com/docs/avatar/character-bodies) **[[development-process-and-speed]]** Follow the basic character creation tutorial with Roblox templates before attempting a custom character from scratch.
- [page](https://create.roblox.com/docs/avatar/character-bodies) **[[3d-modeling-rigging-and-animation]]** Export all avatar components in a single .fbx or .gltf for import into Studio.
- [page](https://create.roblox.com/docs/avatar/character-bodies) **[[3d-modeling-rigging-and-animation]]** Use Roblox's body cage project file; adding or removing vertices from the standard cage mesh can break clothing fit and import.
- [page](https://create.roblox.com/docs/avatar/character-bodies) **[[3d-modeling-rigging-and-animation]]** Use the R15 Rig and Attachments project file so the 19 attachment points are created with standard names on import.
- [page](https://create.roblox.com/docs/avatar/character-bodies) **[[3d-modeling-rigging-and-animation]]** Name meshes and bones to the standard convention and keep the required bone hierarchy, or the avatar will not function in Studio or on the Marketplace.
- [page](https://create.roblox.com/docs/avatar/character-bodies) **[[common-mistakes]]** Do not skip the modesty layer over sensitive body regions when texturing; it is required by Community Standards.
- [page](https://create.roblox.com/docs/avatar/character-bodies) **[[age-ratings-moderation-and-tos]]** Ensure all avatar assets follow Roblox Community Standards and applicable Marketplace policies.
- [page](https://create.roblox.com/docs/avatar/character-bodies) **[[ugc-and-avatar-economy]]** Process the finished custom body with the Avatar Setup tool in Studio to make it ready to sell on the Marketplace.
- [page](https://create.roblox.com/docs/avatar/character-bodies) **[[testing-debugging-and-qa]]** Validate assets with the Calisthenics Tool and Clothing Validation Tool before publishing.
- [page](https://create.roblox.com/docs/avatar/character-bodies) **[[building-art-and-assets]]** Use facial bones and face pose keyframes mapped by pose name in the Head object so expressions work in chat and socializing.

## Numbers
- [page](https://create.roblox.com/docs/avatar/character-bodies) Body part meshes: **15 (head, upper/lower torso, arms and legs with hands and feet)**
- [page](https://create.roblox.com/docs/avatar/character-bodies) Minimum bones in rigging armature: **16 (one per body part plus a root bone)**
- [page](https://create.roblox.com/docs/avatar/character-bodies) Optional additional advanced R15 bones: **Up to 37 (hands, shoulders, spine)**
- [page](https://create.roblox.com/docs/avatar/character-bodies) Attachment points required: **19**
- [page](https://create.roblox.com/docs/avatar/character-bodies) Cage objects required: **One per each of the 15 body parts**

## Tools
Blender, Maya, Roblox Studio Avatar Setup tool, Accessory Fitting Tool, Calisthenics Tool, Clothing Validation Tool, Roblox Blender and Maya project files
