# Docs: art / characters / creating / sculpting

[Open](https://create.roblox.com/docs/art/characters/creating/sculpting.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs tutorial on sculpting an avatar head in Blender from the RoundMale template into a goblin-like character. Covers sculpting tools (Grab, Smooth, Flatten, Elastic Deform), symmetry/mask setup, and a refinement pass, while keeping non-destructive modeling in mind.

## Tips
- [page](https://create.roblox.com/docs/art/characters/creating/sculpting) **[[building-art-and-assets]]** Use only sculpting tools that preserve vertices (Non-Destructive Modeling); other Blender sculpt tools may destroy the mesh topology needed for Roblox avatars.
- [page](https://create.roblox.com/docs/art/characters/creating/sculpting) **[[3d-modeling-rigging-and-animation]]** Enable X-Axis symmetry and Wireframe in Blender's sculpt mode at the viewport top right to keep edits even and see vertex density.
- [page](https://create.roblox.com/docs/art/characters/creating/sculpting) **[[3d-modeling-rigging-and-animation]]** Paint the Mask tool over the mouth and eyes before sculpting so strokes don't distort those features accidentally.
- [page](https://create.roblox.com/docs/art/characters/creating/sculpting) **[[3d-modeling-rigging-and-animation]]** Isolate the mesh you're editing by hiding other Geo objects before sculpting, so you only touch the intended part.
- [page](https://create.roblox.com/docs/art/characters/creating/sculpting) **[[3d-modeling-rigging-and-animation]]** Use Grab and Smooth for broad reshaping, Flatten to straighten regions, and Elastic Deform to stretch multiple vertices with organic falloff.
- [page](https://create.roblox.com/docs/art/characters/creating/sculpting) **[[3d-modeling-rigging-and-animation]]** Keep vertices proportionally spaced when extending features like ears so the shape connects smoothly to the base.
- [page](https://create.roblox.com/docs/art/characters/creating/sculpting) **[[3d-modeling-rigging-and-animation]]** Finish with a refinement pass: add detail to inner/outer ears and chin/cheeks, and fix crowded vertices and edge lines.
