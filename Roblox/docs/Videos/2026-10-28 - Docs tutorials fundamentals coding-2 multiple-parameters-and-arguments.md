## Summary
Roblox Creator Docs lesson on functions with multiple parameters. Explains comma-separated parameters, passing arguments, and that arguments bind to parameters by position. Practice: a sortGarbage(trash, recyclable) function that destroys the first argument and adds a ParticleEmitter to the second.

## Tips
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-2/multiple-parameters-and-arguments) **[[scripting-and-performance]]** Separate multiple parameter names with commas in a function definition, e.g. local function assignTeam(playerName, whichTeam).
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-2/multiple-parameters-and-arguments) **[[scripting-and-performance]]** Arguments bind to parameters by position: the first argument fills the first parameter. Swapping argument order swaps behaviour.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-2/multiple-parameters-and-arguments) **[[common-mistakes]]** Passing fewer arguments than parameters leaves the missing ones nil; extra arguments are silently ignored.
