# Docs: production / analytics / feedback

[Open](https://create.roblox.com/docs/production/analytics/feedback.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on the Feedback dashboard (Audience > Feedback). Covers the chart view (upvote/downvote trends, date range 7/30/60/90 days or custom, relative change vs prior period), the detailed comment table (rating, device, platform, filtered comments), hiding/reporting feedback, and CSV export. Data is limited: upvotes/downvotes from Feb 1 2025, comments from Mar 17 2025.

## Tips
- [page](https://create.roblox.com/docs/production/analytics/feedback) **[[analytics-metrics]]** Use the Feedback chart view to spot sudden downvote spikes after an update, then compare sentiment before and after changes to judge their effect.
- [page](https://create.roblox.com/docs/production/analytics/feedback) **[[analytics-metrics]]** Use the Date Range selector (7/30/60/90 days or custom) and check the relative percentage, which compares the range against the prior equal-length period.
- [page](https://create.roblox.com/docs/production/analytics/feedback) **[[playtesting-and-feedback]]** Read every comment, including on downvotes; players who downvote often leave useful suggestions.
- [page](https://create.roblox.com/docs/production/analytics/feedback) **[[analytics-metrics]]** Export feedback to CSV from the export button for processing in external tools.
- [page](https://create.roblox.com/docs/production/analytics/feedback) **[[common-mistakes]]** Don't treat the dashboard as current: players can change ratings anytime and ratings update only at the end of each day.

## Numbers
- [page](https://create.roblox.com/docs/production/analytics/feedback) Date range options: **7, 30, 60, 90 days or custom** (Feedback chart date range selector)
