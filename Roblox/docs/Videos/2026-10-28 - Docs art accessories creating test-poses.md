# Docs: art / accessories / creating / test-poses

[Open](https://create.roblox.com/docs/art/accessories/creating/test-poses.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on testing clothing deformation (t-shirt) after rigging: parent mesh to armature, enable In Front bone display, pose bones with R in Pose mode, and keep the armature in place for correct layering in Studio.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/creating/test-poses) **[[3d-modeling-rigging-and-animation]]** Test clothing by posing bones in Pose mode across several natural poses to confirm the mesh stretches and fits correctly.
- [page](https://create.roblox.com/docs/art/accessories/creating/test-poses) **[[3d-modeling-rigging-and-animation]]** Enable Armature Properties > Viewport Display > Show > In Front so bones stay visible and selectable while posing.
- [page](https://create.roblox.com/docs/art/accessories/creating/test-poses) **[[3d-modeling-rigging-and-animation]]** Press R to rotate a bone and click to save; right-click cancels an unsaved rotation.
- [page](https://create.roblox.com/docs/art/accessories/creating/test-poses) **[[3d-modeling-rigging-and-animation]]** Reset saved test poses with right-click > Clear User Transforms before testing the next pose.
- [page](https://create.roblox.com/docs/art/accessories/creating/test-poses) **[[3d-modeling-rigging-and-animation]]** If clothing deforms badly, fix it with weight painting or by updating skinning data, not by changing the mesh alone.
- [page](https://create.roblox.com/docs/art/accessories/creating/test-poses) **[[3d-modeling-rigging-and-animation]]** Do not delete the armature after testing; it is required for the clothing to layer correctly in Studio.
