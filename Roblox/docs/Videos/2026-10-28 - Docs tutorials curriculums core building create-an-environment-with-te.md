# Docs: tutorials / curriculums / core / building / create-an-environment-with-terrain

[Open](https://create.roblox.com/docs/tutorials/curriculums/core/building/create-an-environment-with-terrain.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox docs chapter on building an environment with Terrain Editor: create a sand island with Draw, shape it with Flatten and Sculpt, fill water with the Fill tool, paint grass, reposition the SpawnLocation, and playtest the scale.

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/core/building/create-an-environment-with-terrain) **[[building-and-level-design]]** Use Draw to add or subtract material for new shapes; use Sculpt only to grow or erode existing terrain to refine them.
- [page](https://create.roblox.com/docs/tutorials/curriculums/core/building/create-an-environment-with-terrain) **[[building-and-level-design]]** Flatten with Flatten Plane set to Fixed at Y=0 to get a level island top; a spherical island makes players fall off.
- [page](https://create.roblox.com/docs/tutorials/curriculums/core/building/create-an-environment-with-terrain) **[[building-and-level-design]]** Use Fill with Size 1800,5,1800 and Position 0,-15,0 to create water reaching the horizon, positioned below the island top.
- [page](https://create.roblox.com/docs/tutorials/curriculums/core/building/create-an-environment-with-terrain) **[[building-and-level-design]]** Leave open space in the island centre for the spawn and first platforms; keep spawn near an edge if you need room for a launch platform.
- [page](https://create.roblox.com/docs/tutorials/curriculums/core/building/create-an-environment-with-terrain) **[[building-and-level-design]]** Playtest after terrain changes to check island scale and spawn facing; rotate SpawnLocation if the character faces the ocean.
- [page](https://create.roblox.com/docs/tutorials/curriculums/core/building/create-an-environment-with-terrain) **[[building-art-and-assets]]** Use Material Overrides to replace default terrain textures with custom texture assets for a more distinctive look.
- [page](https://create.roblox.com/docs/tutorials/curriculums/core/building/create-an-environment-with-terrain) **[[ai-and-tools]]** Build terrain directly in Studio rather than relying on Assistant; brush strokes and material edits are hard to reproduce with AI.
