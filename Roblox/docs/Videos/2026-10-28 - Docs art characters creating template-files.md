# Docs: art / characters / creating / template-files

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/art/characters/creating/template-files.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox official docs page on avatar body template files. Lists available head-shape templates (Round, Square, Muzzle, Semi-Realistic, Anime, Stylized, Caricature), notes each .zip contains .blend, .fbx and PBR textures, and warns that bundled eyebrow/eyelash meshes may not be fully compatible with the template body.

## Tips
- [page](https://create.roblox.com/docs/art/characters/creating/template-files) **[[building-art-and-assets]]** Start from a pre-built template body to skip the technical avatar components; building character bodies from scratch takes substantial time and modeling expertise.
- [page](https://create.roblox.com/docs/art/characters/creating/template-files) **[[building-art-and-assets]]** Use the .blend project file when working in Blender or following template creation guides; each zip also includes .fbx and PBR texture PNGs.
- [page](https://create.roblox.com/docs/art/characters/creating/template-files) **[[3d-modeling-rigging-and-animation]]** Review the unique head object structure and Blender export settings before altering the model, since changes can conflict with Roblox avatar requirements.
- [page](https://create.roblox.com/docs/art/characters/creating/template-files) **[[3d-modeling-rigging-and-animation]]** Treat bundled eyebrow and eyelash mesh versions with caution; they may not be fully compatible with the template body. Check Layered accessory specifications for current guidance.

## Tools
Blender, Roblox avatar body templates (.blend/.fbx/PBR .png)
