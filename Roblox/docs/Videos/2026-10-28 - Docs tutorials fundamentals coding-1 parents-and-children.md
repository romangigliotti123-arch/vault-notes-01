## Summary
Beginner Roblox docs lesson: parents and children in the Explorer hierarchy. Shows attaching a script to a part, using script.Parent to reference the object the script lives in, and duplicating the script so one script colors many parts.

## Tips
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-1/parents-and-children) **[[scripting-and-performance]]** Use script.Parent instead of hardcoded part names when one script should work on any part it is attached to; makes the code reusable across copies.
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-1/parents-and-children) **[[code-architecture-and-frameworks]]** Note the drawback: duplicated scripts each need separate edits when the logic changes, so keep behaviour in one place where possible.

## Numbers
- [page](https://create.roblox.com/docs/tutorials/fundamentals/coding-1/parents-and-children) Minimum parts to duplicate for test: **3**
