## Summary
Education lesson plan (Roblox Developer lesson 4, "Adventure game part 2"). A guided 50-minute session where students script a tool that collects items, a selling function, and an upgrade purchase for their spaces. Covers classroom troubleshooting and scripting pitfalls.

## Tips
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-4) **[[luau-language-and-types]]** Separate multiple function parameters with commas, e.g. sellItems(playerItems, playerGold); a missing comma is a common scripting error.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-4) **[[code-architecture-and-frameworks]]** Define giveUpgrade() above clickDetector.MouseClick in the Upgrade script; function order matters because the connection needs the function defined first.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-4) **[[luau-language-and-types]]** Indent code to match the sample code; consistent indentation makes scripts more readable and reduces errors.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-4) **[[playtesting-and-feedback]]** Set a strict playtest time limit, such as one minute, to keep students on track.

## Numbers
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-4) Guided tutorial length: **50 min** (Core scripting session within a 60-minute lesson)
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-4) Recommended playtest time limit: **1 min** (Strict limit to keep students on track during testing)
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-4) Introduction length: **5 min** (Session introduction)
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-4) Wrap-up length: **5 min** (Recap and reflection on the project)
