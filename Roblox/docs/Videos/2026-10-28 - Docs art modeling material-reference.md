# Docs: art / modeling / material-reference

[Open](https://create.roblox.com/docs/art/modeling/material-reference.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs reference table of PBR roughness and metalness values for common materials (plastic, wood, fabrics, leather, metals, glass) plus layered clothing examples comparing Substance Painter and Roblox Studio renders.

## Tips
- [page](https://create.roblox.com/docs/art/modeling/material-reference) **[[building-art-and-assets]]** Start PBR surfaces from baseline values: glossy plastic R 0.1/M 0.0, matte plastic R 0.4/M 0.0, pure metals R 0.2-0.3/M 1.0.
- [page](https://create.roblox.com/docs/art/modeling/material-reference) **[[building-art-and-assets]]** Use Metalness 0.0 for non-metal materials; only set Metalness near 1.0 for true metals, since fabrics like silk and velvet use 0.4-0.6.
- [page](https://create.roblox.com/docs/art/modeling/material-reference) **[[3d-modeling-rigging-and-animation]]** For clothing, layer materials: leather R 0.62/M 0.0, brass zipper R 0.25/M 1.0, fur hood R 0.75/M 0.0, cotton band R 0.8/M 0.0.
- [page](https://create.roblox.com/docs/art/modeling/material-reference) **[[building-art-and-assets]]** Combine roughness and metalness values with PBR textures to render most real-world surfaces; compare results against Substance Painter renders to calibrate.
