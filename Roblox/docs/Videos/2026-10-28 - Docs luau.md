## Summary

## Tips
- [page](https://create.roblox.com/docs/luau) **[[luau-language-and-types]]** Luau is dynamically typed by default; add explicit type annotations and enable strict type checking to surface type issues early.
- [page](https://create.roblox.com/docs/luau) **[[luau-language-and-types]]** Use the Script Editor's static linting, type checking and script analysis; it also shows Roblox Engine API signatures and docs while coding.
- [page](https://create.roblox.com/docs/luau) **[[luau-language-and-types]]** Implement stacks and queues with plain tables; use metatables for key-value pairs and custom arithmetic behaviour.
