# Docs: tutorials / curriculums / core

[Open](https://create.roblox.com/docs/tutorials/curriculums/core.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs overview of the Core curriculum: a three-chapter tutorial that builds a 3D platformer (greybox, coin collection and leaderboard scripting, hazards, jump-power upgrade button, then particles, lighting and imported models). Notes that Studio Assistant can handle routine instance creation and boilerplate scripting, while terrain, art style and gameplay design remain manual.

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/core) **[[first-session-onboarding]]** Start with a small, playable greybox before polishing; the curriculum builds a simple platformer in three chapters, each with a checkpoint place file.
- [page](https://create.roblox.com/docs/tutorials/curriculums/core) **[[core-loops-and-game-design]]** Build a simple core loop: collect coins, trade them for jump power, and use that power to reach higher platforms toward a goal.
- [page](https://create.roblox.com/docs/tutorials/curriculums/core) **[[scripting-and-performance]]** Track and store player data (such as coins) on the server and display it on a leaderboard, rather than trusting client values.
- [page](https://create.roblox.com/docs/tutorials/curriculums/core) **[[client-server-and-remotes]]** Handle GUI upgrade purchases by communicating with the server through a RemoteFunction, so the server validates and applies the upgrade.
- [page](https://create.roblox.com/docs/tutorials/curriculums/core) **[[building-art-and-assets]]** Use solid modeling to plan platform shapes first, then replace simple parts with polished imported models at the end.
- [page](https://create.roblox.com/docs/tutorials/curriculums/core) **[[vfx-and-particles]]** Add polish with particle emitters and global lighting settings after gameplay works, not before.
- [page](https://create.roblox.com/docs/tutorials/curriculums/core) **[[ai-and-tools]]** Use Studio Assistant for routine tasks (creating folders, models, parts, boilerplate event handlers, leaderboards, RemoteFunctions) and do terrain, colors, lighting and gameplay design yourself.
- [page](https://create.roblox.com/docs/tutorials/curriculums/core) **[[development-process-and-speed]]** Learn the manual steps at least once to understand how Studio works, then use Assistant to speed up repetitive work.
