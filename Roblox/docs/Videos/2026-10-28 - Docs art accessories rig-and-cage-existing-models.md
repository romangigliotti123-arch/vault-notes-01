# Docs: art / accessories / rig-and-cage-existing-models

[Open](https://create.roblox.com/docs/art/accessories/rig-and-cage-existing-models.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs guide on rigging and caging clothing/accessory models in Blender 3.0: import an FBX into the rig template, parent to the mannequin armature with Automatic Weights, then fit Inner and Outer Cage meshes around the model surfaces before export.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/rig-and-cage-existing-models) **[[building-art-and-assets]]** Use the rig template project so the accessory parents to the default mannequin armature required for layered accessories.
- [page](https://create.roblox.com/docs/art/accessories/rig-and-cage-existing-models) **[[3d-modeling-rigging-and-animation]]** Parent the mesh to the armature with Automatic Weights; for moving parts or complex clothing, use manual Weight Painting instead.
- [page](https://create.roblox.com/docs/art/accessories/rig-and-cage-existing-models) **[[3d-modeling-rigging-and-animation]]** Name the Inner and Outer Cage meshes exactly to match the imported mesh name, or import/conversion will fail.
- [page](https://create.roblox.com/docs/art/accessories/rig-and-cage-existing-models) **[[3d-modeling-rigging-and-animation]]** Never delete vertices or alter UVs on Inner or Outer Cages; this causes errors on import in Studio or when equipping.
- [page](https://create.roblox.com/docs/art/accessories/rig-and-cage-existing-models) **[[3d-modeling-rigging-and-animation]]** Fit the Inner Cage under the accessory first, then adjust the Outer Cage to cover the model tightly with minimal extra space.
- [page](https://create.roblox.com/docs/art/accessories/rig-and-cage-existing-models) **[[3d-modeling-rigging-and-animation]]** Keep faces consistently sized and keep symmetry on cage edits; use the viewport symmetry toggles when applicable.
- [page](https://create.roblox.com/docs/art/accessories/rig-and-cage-existing-models) **[[3d-modeling-rigging-and-animation]]** Use Hide (H) and Unhide (Alt+H) to isolate vertices while editing cages; scale or move multiple selected vertices together.
