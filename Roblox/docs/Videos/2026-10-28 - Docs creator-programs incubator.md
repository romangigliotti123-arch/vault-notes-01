# Docs: creator-programs / incubator

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/creator-programs/incubator.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official docs page for Roblox Incubator, a six-month, milestone-driven program that helps experienced teams refine concepts into polished, commercially successful games. Each cohort takes up to 40 teams, and milestones unlock resources and support. Applications are currently closed.

## Tips
- [page](https://create.roblox.com/docs/creator-programs/incubator) **[[team-and-budget]]** Incubator targets small, experienced teams; solo beginners are not the stated audience. Plan for a significant development commitment during the program.
- [page](https://create.roblox.com/docs/creator-programs/incubator) **[[development-process-and-speed]]** Apply with a strong prototype, or at least a concrete plan to build one. Program support is tied to milestones, so structure work around milestone deliverables.

## Numbers
- [page](https://create.roblox.com/docs/creator-programs/incubator) Cohort size: **Up to 40 teams per cohort** (Roblox Incubator cohort maximum)
- [page](https://create.roblox.com/docs/creator-programs/incubator) Program length: **Six months** (Milestone-driven program duration)
