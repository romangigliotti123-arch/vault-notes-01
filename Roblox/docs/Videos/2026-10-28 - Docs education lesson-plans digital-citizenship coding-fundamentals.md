## Summary
Teacher lesson plan (Roblox Education docs) teaching coding fundamentals: properties, loops, functions, and if/then statements through two mini-projects (color-changing parts and a trap). Covers troubleshooting strategies and classroom tips such as commenting accurately and indenting code.

## Tips
- [page](https://create.roblox.com/docs/education/lesson-plans/digital-citizenship/coding-fundamentals) **[[code-architecture-and-frameworks]]** Indent if-statement code to match samples; readability matters more as scripts grow larger.
- [page](https://create.roblox.com/docs/education/lesson-plans/digital-citizenship/coding-fundamentals) **[[testing-debugging-and-qa]]** When stuck, redo the last few steps first, then ask a peer. Use 'Ask 3 Before Me' before asking the teacher.
- [page](https://create.roblox.com/docs/education/lesson-plans/digital-citizenship/coding-fundamentals) **[[testing-debugging-and-qa]]** Check capitalization carefully; one wrong letter breaks long names like FindFirstChildWhichIsA.
- [page](https://create.roblox.com/docs/education/lesson-plans/digital-citizenship/coding-fundamentals) **[[code-architecture-and-frameworks]]** Write comments that describe specifically what the code does, e.g. 'Changes color of PracticePart', not 'Runs code'.

## Numbers
- [page](https://create.roblox.com/docs/education/lesson-plans/digital-citizenship/coding-fundamentals) Lesson duration: **65 min total: 5 intro, 20 properties tutorial, 35 trap tutorial, 5 wrap-up**
