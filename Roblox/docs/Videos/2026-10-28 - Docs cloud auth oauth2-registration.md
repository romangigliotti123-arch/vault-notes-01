# Docs: cloud / auth / oauth2-registration

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.

## Summary
Roblox Creator Docs on registering OAuth 2.0 apps: creating the app, client ID/secret handling, general info, permission scopes by app category, redirect URL rules, private vs public mode with review requirements, and editing/deleting apps.

## Tips
- [page](https://create.roblox.com/docs/cloud/auth/oauth2-registration) **[[client-server-and-remotes]]** Copy and store the OAuth client ID and secret immediately; the secret cannot be viewed after closing the page, only regenerated.
- [page](https://create.roblox.com/docs/cloud/auth/oauth2-registration) **[[anti-exploit-and-security]]** Request only the minimum permission scopes your app needs; Roblox does not approve scopes for planned or future functionality.
- [page](https://create.roblox.com/docs/cloud/auth/oauth2-registration) **[[anti-exploit-and-security]]** If you select the profile scope, you must also select openid.
- [page](https://create.roblox.com/docs/cloud/auth/oauth2-registration) **[[testing-debugging-and-qa]]** New apps stay in private mode (limit 10 unique users) for team testing; add redirect URLs once you have a testable version.

## Numbers
- [page](https://create.roblox.com/docs/cloud/auth/oauth2-registration) Private mode user limit: **10 unique users** (Unpublished OAuth app limit before public review approval)
- [page](https://create.roblox.com/docs/cloud/auth/oauth2-registration) Redirect URLs maximum: **10 URLs, 256 characters each** (OAuth app redirect URL limits)
- [page](https://create.roblox.com/docs/cloud/auth/oauth2-registration) Thumbnail minimum size: **150x150 pixels** (Recommended minimum for OAuth app thumbnail)
- [page](https://create.roblox.com/docs/cloud/auth/oauth2-registration) Demo video length: **at most 1 minute** (Required public demo video for public-mode review)
