# Docs: avatar / character-bodies / project-files

[Open](https://create.roblox.com/docs/avatar/character-bodies/project-files.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs index of avatar character-body project files and templates: advanced and standard R15 rig files (FBX/ZIP), Blender and Maya armature, body cage and combined templates, and head-shape and body-style starter templates for custom avatar bodies.

## Tips
- [page](https://create.roblox.com/docs/avatar/character-bodies/project-files) **[[3d-modeling-rigging-and-animation]]** Start custom character bodies from the Rig_and_Attachments_Template or Combined-Template so R15 bone naming and attachment points are already correct.
- [page](https://create.roblox.com/docs/avatar/character-bodies/project-files) **[[building-art-and-assets]]** Edit the full-body std_cage_deformable helper mesh to propagate vertex changes to all 15 body-part cages; remove the helper mesh after importing the FBX into Studio.
- [page](https://create.roblox.com/docs/avatar/character-bodies/project-files) **[[ugc-and-avatar-economy]]** Run the template cleanup steps before publishing avatar template-based assets to the Marketplace, or they will fail validation.
- [page](https://create.roblox.com/docs/avatar/character-bodies/project-files) **[[3d-modeling-rigging-and-animation]]** Use Blender or Maya template files for those programs; the General FBX templates were exported from Maya and are warned against for Blender/Maya workflows.
- [page](https://create.roblox.com/docs/avatar/character-bodies/project-files) **[[3d-modeling-rigging-and-animation]]** Set Rig Scale to Rthro Narrow when importing the Roxie HigherFidelity Rthro Normal body model.
- [page](https://create.roblox.com/docs/avatar/character-bodies/project-files) **[[building-art-and-assets]]** Lola.fbx has no inner/outer cage mesh data, so it cannot equip layered accessories; use a caged model if layered clothing is needed.
- [page](https://create.roblox.com/docs/avatar/character-bodies/project-files) **[[building-art-and-assets]]** Caged mannequin files may not import into Studio correctly until unconfigured cage objects are modified.

## Numbers
- [page](https://create.roblox.com/docs/avatar/character-bodies/project-files) Body parts caged in Body_Cage_Template: **15 humanoid body parts**
- [page](https://create.roblox.com/docs/avatar/character-bodies/project-files) Advanced rig texture resolution: **2K PBR textures (Mannequin, Robuta)**
