# Docs: tutorials / curriculums / user-interface-design / choose-an-art-style

[Open](https://create.roblox.com/docs/tutorials/curriculums/user-interface-design/choose-an-art-style.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox UI curriculum section on choosing an art style: identify UI elements by player questions and category, pick a color theme that reinforces genre conventions, outline simple icons, set interaction order by likelihood (primary/secondary/tertiary), and define a legible text system.

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/user-interface-design/choose-an-art-style) **[[ui-ux-design]]** Before designing, list the questions a player has on join (goal, team, blaster, cooldown, etc.) and group UI elements by functional category.
- [page](https://create.roblox.com/docs/tutorials/curriculums/user-interface-design/choose-an-art-style) **[[ui-ux-design]]** Limit your color theme to only the key information colors should signal; players then associate colors with function quickly.
- [page](https://create.roblox.com/docs/tutorials/curriculums/user-interface-design/choose-an-art-style) **[[ui-ux-design]]** Don't rely on color alone; pair colors with icons, shapes, or animations so colorblind players can still understand the UI.
- [page](https://create.roblox.com/docs/tutorials/curriculums/user-interface-design/choose-an-art-style) **[[ui-ux-design]]** Prioritize legibility over aesthetics; use simple UI with colors readable over both light and dark 3D backgrounds.
- [page](https://create.roblox.com/docs/tutorials/curriculums/user-interface-design/choose-an-art-style) **[[ui-ux-design]]** Keep icons simple with limited detail so they stay recognizable on small mobile screens.
- [page](https://create.roblox.com/docs/tutorials/curriculums/user-interface-design/choose-an-art-style) **[[localization-and-international]]** Replace unnecessary text with icons where comprehension is unaffected, which also eases localization.
- [page](https://create.roblox.com/docs/tutorials/curriculums/user-interface-design/choose-an-art-style) **[[genre-mechanics]]** Embrace genre iconography symbolism (e.g. sword for strength, beaker for magic) so players understand icons without guidance.
- [page](https://create.roblox.com/docs/tutorials/curriculums/user-interface-design/choose-an-art-style) **[[ui-ux-design]]** Make the primary action the largest element, the secondary smaller, and tertiary subtle, matching how likely each action is.
- [page](https://create.roblox.com/docs/tutorials/curriculums/user-interface-design/choose-an-art-style) **[[ui-ux-design]]** Give interactable UI elements at least one form of visual feedback, such as outline, size, color, or animation when in focus.
- [page](https://create.roblox.com/docs/tutorials/curriculums/user-interface-design/choose-an-art-style) **[[ui-ux-design]]** Use clear, concise, distinct labels for interactive elements so players don't misread which action does what.
- [page](https://create.roblox.com/docs/tutorials/curriculums/user-interface-design/choose-an-art-style) **[[ui-ux-design]]** Test interactive element sizes across screen sizes; use UIAspectRatioConstraint to keep proportions on any device.
- [page](https://create.roblox.com/docs/tutorials/curriculums/user-interface-design/choose-an-art-style) **[[ui-ux-design]]** Aim for mobile touch zones of at least 9x9 mm, per WCAG touch target size and spacing guidance.
- [page](https://create.roblox.com/docs/tutorials/curriculums/user-interface-design/choose-an-art-style) **[[ui-ux-design]]** Display UI text on a contrasting color or with a stroke so it isn't lost against the background.
- [page](https://create.roblox.com/docs/tutorials/curriculums/user-interface-design/choose-an-art-style) **[[ui-ux-design]]** Scale text per device and test on multiple devices, since text can become too large or unreadable.
- [page](https://create.roblox.com/docs/tutorials/curriculums/user-interface-design/choose-an-art-style) **[[localization-and-international]]** Reserve room for longer translations by planning for the maximum text space on screen, not the English length.
- [page](https://create.roblox.com/docs/tutorials/curriculums/user-interface-design/choose-an-art-style) **[[ui-ux-design]]** Use stylized fonts sparingly, such as for titles or alert text, since they are hard to read in large amounts.
