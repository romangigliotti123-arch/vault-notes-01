# Docs: education / adventure-game-series / landing

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.

## Summary
Roblox Education docs series for building a beginner adventure game: explore a map, harvest items via tools, sell items with Touch events, buy upgrades with click detectors, and track collected items with a leaderboard script. Prerequisites: basic Luau (variables, if/else, functions) and Studio world-building.

## Tips
- [page](https://create.roblox.com/docs/education/adventure-game-series/landing) **[[development-process-and-speed]]** Pre-plan with a game design document before building the map, then design, test, and iterate.
- [page](https://create.roblox.com/docs/education/adventure-game-series/landing) **[[building-and-level-design]]** Build the map with Roblox terrain tools after the design doc defines what players explore and harvest.
- [page](https://create.roblox.com/docs/education/adventure-game-series/landing) **[[combat-and-gameplay-systems]]** Create a script to manage collected items per player so inventory state stays consistent.
- [page](https://create.roblox.com/docs/education/adventure-game-series/landing) **[[scripting-and-performance]]** Use Touch events on a sell part to convert player items into currency.
