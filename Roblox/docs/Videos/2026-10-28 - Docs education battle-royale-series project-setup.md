# Docs: education / battle-royale-series / project-setup

[Open](https://create.roblox.com/docs/education/battle-royale-series/project-setup.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox Education docs page on setting up a Battle Royale project: explains the round-based game loop (Intermission, Match, Cleanup and Reset), a four-stage workflow (preproduction, test map, code and test, polish), and how to graybox a symmetrical arena with 8 spawns in a Lobby and Arena folder structure.

## Tips
- [page](https://create.roblox.com/docs/education/battle-royale-series/project-setup) **[[core-loops-and-game-design]]** Structure battle royales as a round loop: Intermission, Match (timer starts, players teleported to arena), then Cleanup and Reset back to lobby.
- [page](https://create.roblox.com/docs/education/battle-royale-series/project-setup) **[[development-process-and-speed]]** Finish each phase before starting the next (layout, test map, code, polish). Polishing art on an untested map risks wasted time if it must be redesigned.
- [page](https://create.roblox.com/docs/education/battle-royale-series/project-setup) **[[building-and-level-design]]** Draft the layout on paper first, using 1-3 basic shapes (square, rectangle, octagon); prefer symmetrical maps for easier balancing.
- [page](https://create.roblox.com/docs/education/battle-royale-series/project-setup) **[[building-and-level-design]]** Place 2-4 obstacles that force directional choices, plus secondary obstacles that prevent fighting right at the start.
- [page](https://create.roblox.com/docs/education/battle-royale-series/project-setup) **[[building-and-level-design]]** Balance choice: enough routes to make each round feel different, but not so many players can't remember the map or feel overwhelmed.
- [page](https://create.roblox.com/docs/education/battle-royale-series/project-setup) **[[building-and-level-design]]** Gray-box with basic parts first; skip textures and props until the map works in code and playtests fun.
- [page](https://create.roblox.com/docs/education/battle-royale-series/project-setup) **[[building-and-level-design]]** Vary height with hills, stairs and ramps to avoid a repetitive flat map. Build half the map and duplicate it for symmetry.
- [page](https://create.roblox.com/docs/education/battle-royale-series/project-setup) **[[building-and-level-design]]** Check scale against the average avatar height of 6.5 studs when sizing doorways, areas and spacing.
- [page](https://create.roblox.com/docs/education/battle-royale-series/project-setup) **[[building-and-level-design]]** Enable Snap to Grid and rotate parts at 90 or 45 degrees for cleaner, easier-aligned layouts.
- [page](https://create.roblox.com/docs/education/battle-royale-series/project-setup) **[[first-session-onboarding]]** Use eight spawn locations, placed randomly since all players spawn at random on join; more can be added later.
- [page](https://create.roblox.com/docs/education/battle-royale-series/project-setup) **[[playtesting-and-feedback]]** Playtest the graybox and check: can players move without getting stuck, does the size feel right, any floating or misaligned parts.
- [page](https://create.roblox.com/docs/education/battle-royale-series/project-setup) **[[version-control-and-tooling]]** Organise parts into folders (Lobby, Arena, SpawnLocations) to keep the project manageable.
