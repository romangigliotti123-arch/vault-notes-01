# Docs: get-started / tools

[Open](https://create.roblox.com/docs/get-started/tools.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Creator Hub docs overview of platform tools: Studio (Team Create, test and publish), Creator Dashboard KPIs, Documentation, Developer Forum, Marketplace, Talent Hub, AI Assistant, Roblox Cube, matchmaking signal control, discovery ranking, and Sponsored Ads. Mostly feature descriptions with few concrete numbers.

## Tips
- [page](https://create.roblox.com/docs/get-started/tools) **[[team-and-budget]]** Use Team Create so multiple users can edit the same project simultaneously, making collaboration with teammates easier.
- [page](https://create.roblox.com/docs/get-started/tools) **[[development-process-and-speed]]** Test changes directly in Studio and iterate quickly, then publish to Roblox with one click when ready.
- [page](https://create.roblox.com/docs/get-started/tools) **[[analytics-metrics]]** Track engagement, retention, and monetization KPIs in the Creator Dashboard, which is free of charge.
- [page](https://create.roblox.com/docs/get-started/tools) **[[discovery-algorithm]]** Use the matchmaking preview and test feature to see the impact of signal changes before they go live, and monitor them in the analytics dashboard.
- [page](https://create.roblox.com/docs/get-started/tools) **[[discovery-algorithm]]** Games are ranked by playtime and Robux spent; check the Home Recommendations dashboard to see these metrics for decisions.
- [page](https://create.roblox.com/docs/get-started/tools) **[[ads-and-sponsored-experiences]]** Use Sponsored Ads audience selection (demographics, interests) and flexible daily budgets to target players and manage ad spend.
- [page](https://create.roblox.com/docs/get-started/tools) **[[community-and-discord]]** Use the Developer Forum to get advice, file bug reports, and learn about the latest Roblox updates.
- [page](https://create.roblox.com/docs/get-started/tools) **[[building-art-and-assets]]** Source royalty-free music, community-made models, and plugins from the Marketplace instead of building everything from scratch.
- [page](https://create.roblox.com/docs/get-started/tools) **[[team-and-budget]]** Find and review artists, programmers, and designers on Talent Hub before hiring.
- [page](https://create.roblox.com/docs/get-started/tools) **[[ai-and-tools]]** Use the AI Assistant in Studio for code snippets, answers, asset insertion, and bulk property modifications to save time on chores.

## Numbers
- [page](https://create.roblox.com/docs/get-started/tools) Matchmaking custom signals: **up to 2** (Custom signals based on player attributes like skill level or game mode preference)
- [page](https://create.roblox.com/docs/get-started/tools) Creator Dashboard cost: **free** (Engagement, retention, and monetization KPIs)
- [page](https://create.roblox.com/docs/get-started/tools) Ranking KPIs: **playtime and Robux spent** (Key performance indicators used to rank games)
