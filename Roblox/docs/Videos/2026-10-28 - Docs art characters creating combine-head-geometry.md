# Docs: art / characters / creating / combine-head-geometry

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/art/characters/creating/combine-head-geometry.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on preparing a custom avatar head for export: join the separate face/eye/lash/teeth/tongue meshes into one Head_Geo object, with Head_Geo selected last so it stays the active merge target and keeps its custom properties.

## Tips
- [page](https://create.roblox.com/docs/art/characters/creating/combine-head-geometry) **[[3d-modeling-rigging-and-animation]]** Select Head_Geo last in the Outliner before joining so it is the active (yellow) object; this preserves custom properties stored in the head mesh.
- [page](https://create.roblox.com/docs/art/characters/creating/combine-head-geometry) **[[3d-modeling-rigging-and-animation]]** Combine UpperTeeth, LowerTeeth, Tongue, lashes and eyes into Head_Geo in Object mode via right-click > Join. Some templates lack some face objects.
- [page](https://create.roblox.com/docs/art/characters/creating/combine-head-geometry) **[[3d-modeling-rigging-and-animation]]** Clean up before export: combine head geometry, remove extra head bones, verify attachment points, run final technical checks. Skipping head combine/bone removal fails validation.
