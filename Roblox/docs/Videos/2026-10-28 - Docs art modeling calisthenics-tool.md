# Docs: art / modeling / calisthenics-tool

[Open](https://create.roblox.com/docs/art/modeling/calisthenics-tool.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page for the Calisthenics Tool, a deprecated Blender add-on (Blender 3.0+) that runs R15 walk/run/move/idle cycles to check skinning, attaches test accessories (normal and slender), and exports character bodies to FBX.

## Tips
- [page](https://create.roblox.com/docs/art/modeling/calisthenics-tool) **[[3d-modeling-rigging-and-animation]]** Test skinning by playing walk, run, move and idle cycles and checking movement from several angles; pause on frames to fix weights in Weight Paint mode.
- [page](https://create.roblox.com/docs/art/modeling/calisthenics-tool) **[[3d-modeling-rigging-and-animation]]** Verify bone hierarchy and naming against Roblox's custom mesh requirements if the tool reports armature errors or warnings.
- [page](https://create.roblox.com/docs/art/modeling/calisthenics-tool) **[[3d-modeling-rigging-and-animation]]** Tool testing is not complete verification; also check Studio's character body specs and layered accessory specs.
- [page](https://create.roblox.com/docs/art/modeling/calisthenics-tool) **[[building-art-and-assets]]** Test accessory attachment with Normal Size and Slender Size reference accessories; if one attaches wrong, reposition its Attachment object in the rig.
- [page](https://create.roblox.com/docs/art/modeling/calisthenics-tool) **[[3d-modeling-rigging-and-animation]]** Export with the tool's Export Model button, or manually: detach test accessories, Stop Animation, return to default pose, and use Roblox's Blender FBX export settings.
- [page](https://create.roblox.com/docs/art/modeling/calisthenics-tool) **[[3d-modeling-rigging-and-animation]]** Models with facial animation (FACS data) may behave unexpectedly in the tool because FACS conflicts with its reference animations.

## Numbers
- [page](https://create.roblox.com/docs/art/modeling/calisthenics-tool) Minimum Blender version: **3.0+**
- [page](https://create.roblox.com/docs/art/modeling/calisthenics-tool) Tool status: **No longer in active development**
