# Docs: animation

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/animation.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs overview of animation. Covers animatable object types: simple parts (single position/rotation), rigs joined by AnimationConstraints or Bones, and R15 rigs that can use Roblox's animation library. Introduces the Animation Editor for pose-to-pose animation, inverse kinematics APIs for procedural motion, and animation event markers detected via GetMarkerReachedSignal.

## Tips
- [page](https://create.roblox.com/docs/animation) **[[building-art-and-assets]]** Use the Animation Editor to pose rig joints; the editor interpolates smoothly between poses, so you only author keyframe poses.
- [page](https://create.roblox.com/docs/animation) **[[3d-modeling-rigging-and-animation]]** Standard and advanced R15 rigs can use Roblox's character animation library, whether the model is a player or an NPC.
- [page](https://create.roblox.com/docs/animation) **[[physics-pathfinding-and-npc-ai]]** Use inverse kinematics APIs to procedurally drive motion from events, e.g. head tracking a flying bird or an arm reaching for a door knob.
- [page](https://create.roblox.com/docs/animation) **[[vfx-and-particles]]** Add animation event markers in the Animation Editor timeline and listen with AnimationTrack:GetMarkerReachedSignal() to sync effects, such as a footstep sound.

## Tools
Animation Editor, Inverse kinematics APIs, AnimationConstraint, Bone
