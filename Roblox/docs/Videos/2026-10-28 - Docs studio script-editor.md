## Summary
Official Roblox Studio docs for the Script Editor: autocomplete, documentation tooltips, code navigation, find/replace, Script Analysis, Output, Code Assist AI suggestions (with limitations and privacy notes), multi-cursor editing, editor settings, and keyboard shortcuts.

## Tips
- [page](https://create.roblox.com/docs/studio/script-editor) **[[ai-and-tools]]** Use descriptive script, part and function names plus comments stating inputs/outputs; this produces more accurate Code Assist suggestions.
- [page](https://create.roblox.com/docs/studio/script-editor) **[[ai-and-tools]]** Always review, test and verify Code Assist suggestions; the tool can generate incorrect code and may suggest older APIs or Lua instead of Luau.
- [page](https://create.roblox.com/docs/studio/script-editor) **[[ai-and-tools]]** Break code into smaller named functions; named functions produce better Code Assist hints than anonymous functions.
- [page](https://create.roblox.com/docs/studio/script-editor) **[[luau-language-and-types]]** Place a block comment immediately before a declaration to create a hover tooltip; works inside typeof() in type expressions too.
- [page](https://create.roblox.com/docs/studio/script-editor) **[[testing-debugging-and-qa]]** Check Studio's Script Analysis window (Script tab > Analysis) for active errors and warnings before running; use Output for print/warn and runtime errors.
- [page](https://create.roblox.com/docs/studio/script-editor) **[[building-art-and-assets]]** Use Find All / Replace All (Ctrl+Shift+F) to refactor names across all scripts in the game.

## Numbers
- [page](https://create.roblox.com/docs/studio/script-editor) Code Assist auto-trigger delay: **after pausing a few seconds on a line** (Automatic suggestion trigger; manual trigger is Alt+\ (Option+\ on Mac))
- [page](https://create.roblox.com/docs/studio/script-editor) Code Assist daily suggestion cap: **capped per day; none until next day once reached** (Stated limitation; exact number not given)
