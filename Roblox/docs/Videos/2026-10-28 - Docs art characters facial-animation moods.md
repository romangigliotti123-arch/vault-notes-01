# Docs: art / characters / facial-animation / moods

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/art/characters/facial-animation/moods.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on moods: looping persistent facial animations for dynamic heads that play alongside default character animations. Covers creating moods in the Face Animation Editor, saving/publishing to Toolbox, setting moods via the Animate script's mood StringValue or HumanoidDescription, and disabling moods.

## Tips
- [page](https://create.roblox.com/docs/art/characters/facial-animation/moods) **[[ai-and-tools]]** Use the Face Animation Editor (Avatar tab > Clip Editor > Face) to create mood animations; undo/redo with Ctrl+Z/Ctrl+Y, right-click slider > Reset Selected.
- [page](https://create.roblox.com/docs/art/characters/facial-animation/moods) **[[3d-modeling-rigging-and-animation]]** To use a custom head, create an animatable head in Blender or Maya if not using the Blocky or Goblin reference models.
- [page](https://create.roblox.com/docs/art/characters/facial-animation/moods) **[[client-server-and-remotes]]** Change moods by editing the mood StringValue's Animation1 AnimationId under the character's Animate LocalScript after CharacterAppearanceLoaded fires.
- [page](https://create.roblox.com/docs/art/characters/facial-animation/moods) **[[combat-and-gameplay-systems]]** Use HumanoidDescription (GetAppliedDescription, set IdleAnimation, ApplyDescription) to change default animations like idle on a character.

## Tools
Face Animation Editor, Blender, Maya, Roblox Studio Clip Editor
