# Docs: production / analytics / engagement

[Open](https://create.roblox.com/docs/production/analytics/engagement.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox official docs on the Engagement analytics page (Creator Dashboard > Analytics > Engagement). Covers average session time drivers (fun within first five minutes, contextual tutorials instead of long ones, social design), repeat-visit design (clear goals, progression without gating fun), performance testing, and reading the New User First Session Retention chart to diagnose onboarding friction.

## Tips
- [page](https://create.roblox.com/docs/production/analytics/engagement) **[[first-session-onboarding]]** Make sure users have fun within the first five minutes; be able to communicate what makes your game fun and standout in that window.
- [page](https://create.roblox.com/docs/production/analytics/engagement) **[[first-session-onboarding]]** Avoid long tutorials; use short, unobtrusive contextual pop-ups when users meet a new feature, and tooltips on shop items.
- [page](https://create.roblox.com/docs/production/analytics/engagement) **[[first-session-onboarding]]** Give starter items and currency so new users can enjoy the core loop as soon as possible.
- [page](https://create.roblox.com/docs/production/analytics/engagement) **[[social-features-and-virality]]** Remove unnecessary barriers to social interaction and design for group play, since socializing is a core part of many successful Roblox games.
- [page](https://create.roblox.com/docs/production/analytics/engagement) **[[retention-d1-d7]]** Design for repeat visits by giving users clear short, mid, and long-term goals such as pet collections, top ranks, or rare items.
- [page](https://create.roblox.com/docs/production/analytics/engagement) **[[core-loops-and-game-design]]** Add a progression system to give users a clear path to goals and make content last longer.
- [page](https://create.roblox.com/docs/production/analytics/engagement) **[[core-loops-and-game-design]]** Keep enough content available upfront so progression does not gate off the fun for new users' first session.
- [page](https://create.roblox.com/docs/production/analytics/engagement) **[[scripting-and-performance]]** Test on various devices and platforms to find and fix performance issues; limit excessive textures, meshes and other variables that slow the game.
- [page](https://create.roblox.com/docs/production/analytics/engagement) **[[community-and-discord]]** Set up a user community that can help identify bugs and crashes.
- [page](https://create.roblox.com/docs/production/analytics/engagement) **[[analytics-metrics]]** Use the New User First Session Retention chart (percent still playing after X minutes, week-on-week) to catch onboarding issues.
- [page](https://create.roblox.com/docs/production/analytics/engagement) **[[analytics-metrics]]** After a drop in new-user retention, check recent updates for new onboarding steps or changed intro messaging, and check error/performance reports.
- [page](https://create.roblox.com/docs/production/analytics/engagement) **[[retention-d1-d7]]** Average session time = total time in game divided by number of sessions; it is closely tied to retention, so focus on meaningful sessions.

## Numbers
- [page](https://create.roblox.com/docs/production/analytics/engagement) Time to deliver fun: **within first five minutes** (Docs' stated target for communicating what makes the game fun)
- [page](https://create.roblox.com/docs/production/analytics/engagement) New User First Session Retention: **percent still playing at X minutes, compared to previous period** (Chart in Engagement analytics; example checkpoint is 5 minutes)
