# Docs: education / build-it-play-it-create-and-destroy / complete-the-city

[Open](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/complete-the-city.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Studio docs page on finishing a city build: turn the first half into a 4-player map by duplicating, rotating, and moving the city, then adjusting tiles so the halves fit.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/complete-the-city) **[[building-and-level-design]]** Turn collisions off in the Model tab before duplicating and moving large builds; collisions make the map hard to move and rotate.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/complete-the-city) **[[building-and-level-design]]** Click and drag to select all buildings, roads and props, then duplicate the selection to build out the full map.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/complete-the-city) **[[building-and-level-design]]** Use Move and Rotate on the duplicate to reposition it; if the layout looks wrong, undo (Ctrl+Z / Cmd+Z) and retry.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/complete-the-city) **[[building-and-level-design]]** After duplicating and rotating, add or adjust tiles so the two halves join cleanly.
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/complete-the-city) **[[building-and-level-design]]** Keep editing the city after duplicating the first half; duplication does not lock the original build.

## Numbers
- [page](https://create.roblox.com/docs/education/build-it-play-it-create-and-destroy/complete-the-city) map size: **4-player map from duplicating one half** (Docs: duplicate first half to make a complete 4-player city map)

## Tools
Roblox Studio Model tab (collisions toggle), Duplicate, Move tool, Rotate tool
