# Docs: resources / npc-kit

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/resources/npc-kit.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox official docs page for the NPC kit resource. Explains how to add the free NPC kits (Drooling Zombie, Soldiers, RO-01 Robots, NP-C 9000 Robots) via Toolbox, their rig/character structure, Animate and BodyParts objects, Configuration values, and CollectionService tags controlling soldier and zombie aggression.

## Tips
- [page](https://create.roblox.com/docs/resources/npc-kit) **[[ai-and-tools]]** Customize NPC animations by swapping AnimationId values in the Animate script poses or Animations folder; for finer changes, copy existing animations and edit Animate or NPC scripts.
- [page](https://create.roblox.com/docs/resources/npc-kit) **[[combat-and-gameplay-systems]]** Use CollectionService tags (SoldierEnemy, SoldierFriend, ZombieFriend) to control which characters NPCs attack; add tags to NPC models or player characters via StarterCharacterScripts.
- [page](https://create.roblox.com/docs/resources/npc-kit) **[[genre-mechanics]]** Set soldier AttackMode to 1 (only SoldierEnemy-tagged targets), 2 (everything without SoldierFriend), or 3 (attack all characters).
- [page](https://create.roblox.com/docs/resources/npc-kit) **[[building-art-and-assets]]** Customize NPC looks by modifying BodyParts and adding Accessory objects rather than changing the base rig.

## Tools
Roblox Toolbox, Roblox Studio, Animate script, NPC script
