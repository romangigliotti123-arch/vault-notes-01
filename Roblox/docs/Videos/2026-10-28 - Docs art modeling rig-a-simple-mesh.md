# Docs: art / modeling / rig-a-simple-mesh

[Open](https://create.roblox.com/docs/art/modeling/rig-a-simple-mesh.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox docs guide to rigging a simple mesh (robot) in Blender 3.0 before FBX export: set Studio-relative scene units, add armature and bones, parent with automatic weights, assign vertex groups per limb, and test poses in Pose mode.

## Tips
- [page](https://create.roblox.com/docs/art/modeling/rig-a-simple-mesh) **[[building-art-and-assets]]** Set Blender to Studio's relative scene units before importing a model to rig, so the exported rig scales correctly in Studio.
- [page](https://create.roblox.com/docs/art/modeling/rig-a-simple-mesh) **[[3d-modeling-rigging-and-animation]]** Rig the model after designing it but before exporting; rigging is done in the modelling tool, not in Studio.
- [page](https://create.roblox.com/docs/art/modeling/rig-a-simple-mesh) **[[3d-modeling-rigging-and-animation]]** Parent the mesh to the armature using 'With Automatic Weights' for a quick first-pass weight assignment; select the mesh first, then the armature.
- [page](https://create.roblox.com/docs/art/modeling/rig-a-simple-mesh) **[[3d-modeling-rigging-and-animation]]** For rigid non-organic models like robots, assign each limb's vertices fully (100%) to its bone so limbs bend without deformation blending.
- [page](https://create.roblox.com/docs/art/modeling/rig-a-simple-mesh) **[[3d-modeling-rigging-and-animation]]** Name bones in the Outliner (double-click to rename) so they are easy to reference later in code.
- [page](https://create.roblox.com/docs/art/modeling/rig-a-simple-mesh) **[[3d-modeling-rigging-and-animation]]** Test the rig in Pose mode across several poses after applying or changing influences, and before exporting.
