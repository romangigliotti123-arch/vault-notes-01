# Docs: art / characters / creating / modeling-tips

[Open](https://create.roblox.com/docs/art/characters/creating/modeling-tips.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox official docs page on Blender modeling tips for Roblox avatar/character meshes: hiding inactive objects in the Outliner (including bulk Shift-click hide of parent/child objects) and enabling wireframe display in Object Properties to inspect vertices while modeling.

## Tips
- [page](https://create.roblox.com/docs/art/characters/creating/modeling-tips) **[[building-art-and-assets]]** In the Blender Outliner, hide objects you aren't editing using the Hide In Viewport icon to avoid unintentional changes to other objects or collections.
- [page](https://create.roblox.com/docs/art/characters/creating/modeling-tips) **[[building-art-and-assets]]** Shift-click the Hide In Viewport icon on a parent object (e.g. Cage or Joints) to bulk hide or unhide its child objects that are not disabled.
- [page](https://create.roblox.com/docs/art/characters/creating/modeling-tips) **[[building-art-and-assets]]** Switch between X-Ray and Wireframe viewport options while modeling to better see vertices and shapes.
- [page](https://create.roblox.com/docs/art/characters/creating/modeling-tips) **[[3d-modeling-rigging-and-animation]]** Enable Wireframe on a mesh (Object Properties > Viewport Display) to view vertices over the material view when editing head or body geometry.
