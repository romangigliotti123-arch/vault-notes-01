# Docs: art / characters / creating / texturing-setup

[Open](https://create.roblox.com/docs/art/characters/creating/texturing-setup.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on texturing custom meshes in Blender. Covers manually saving textures in Texture Paint (or Blender 5.2+ auto-save setting), the 1024x1024 albedo resolution Studio supports, and temporarily painting at 2048/4096 then resizing back to 1024 to bake details in.

## Tips
- [page](https://create.roblox.com/docs/art/characters/creating/texturing-setup) **[[building-art-and-assets]]** In Blender, textures must be saved manually in the Texture Paint 2D view; saving only the .blend file does not save them. Save often to avoid losing hours of work.
- [page](https://create.roblox.com/docs/art/characters/creating/texturing-setup) **[[building-art-and-assets]]** On Blender 5.2+, set Edit > Preferences > Save & Load > Blend Files > Save Modified Images to Always Save to avoid losing texture work.
- [page](https://create.roblox.com/docs/art/characters/creating/texturing-setup) **[[building-art-and-assets]]** Final albedo texture resolution should be 1024x1024, the resolution Roblox Studio supports for albedo maps.
- [page](https://create.roblox.com/docs/art/characters/creating/texturing-setup) **[[building-art-and-assets]]** For fine details, temporarily resize the texture to 2048x2048 or 4096x4096 while painting, then resize back to 1024x1024 to bake the changes in.
- [page](https://create.roblox.com/docs/art/characters/creating/texturing-setup) **[[ugc-and-avatar-economy]]** Ensure character models include a modesty layer over sensitive body regions when texturing body parts, per Marketplace policy.
- [page](https://create.roblox.com/docs/art/characters/creating/texturing-setup) **[[ugc-and-avatar-economy]]** Preview custom skin tones in Blender to verify how the final avatar asset will look in a Roblox game.

## Numbers
- [page](https://create.roblox.com/docs/art/characters/creating/texturing-setup) Albedo texture resolution supported in Studio: **1024 x 1024**
- [page](https://create.roblox.com/docs/art/characters/creating/texturing-setup) Temporary high-res painting sizes: **2048 x 2048 or 4096 x 4096**
- [page](https://create.roblox.com/docs/art/characters/creating/texturing-setup) Blender version with auto-save texture setting: **5.2 and later**
