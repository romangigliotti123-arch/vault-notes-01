# Docs: production / game-design / onboarding

[Open](https://create.roblox.com/docs/production/game-design/onboarding.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox official docs on onboarding/FTUE: defines the first-time user experience, measures success via D1 retention and onboarding goals, and recommends teaching essentials, reaching fun fast, and leaving players wanting more. Recommends Experiments and Configs for tuning.

## Tips
- [page](https://create.roblox.com/docs/production/game-design/onboarding) **[[first-session-onboarding]]** Measure FTUE success by Day 1 retention and whether players hit onboarding goals; track a player funnel of FTUE steps to find drop-off leaks.
- [page](https://create.roblox.com/docs/production/game-design/onboarding) **[[first-session-onboarding]]** A/B test individual tutorial steps with Experiments (e.g., short dialogue vs guided arrow) to measure causal impact on step completion.
- [page](https://create.roblox.com/docs/production/game-design/onboarding) **[[first-session-onboarding]]** Teach controls for navigation and interaction; show complex unfamiliar controls on-screen or in a tutorial.
- [page](https://create.roblox.com/docs/production/game-design/onboarding) **[[first-session-onboarding]]** Teach the core loop: players must understand what to do and why they should do it.
- [page](https://create.roblox.com/docs/production/game-design/onboarding) **[[core-loops-and-game-design]]** Keep XP thresholds low for early levels so players level up quickly and feel progression immediately.
- [page](https://create.roblox.com/docs/production/game-design/onboarding) **[[core-loops-and-game-design]]** Use Configs to tune XP thresholds and rewards live without restarting servers or pushing a full update.
- [page](https://create.roblox.com/docs/production/game-design/onboarding) **[[social-features-and-virality]]** If the game is social, test matchmaking parameters during the FTUE with Experiments to see which groupings improve long-term engagement.
- [page](https://create.roblox.com/docs/production/game-design/onboarding) **[[monetisation-other]]** Give free starter items or soft currency so players use your systems early, balancing enough to enjoy them without removing reason to play on.
- [page](https://create.roblox.com/docs/production/game-design/onboarding) **[[analytics-metrics]]** Test different starting currency amounts across new-player groups with Experiments to find the value that maximises retention, then set it globally with Configs.
- [page](https://create.roblox.com/docs/production/game-design/onboarding) **[[retention-d1-d7]]** Surface short, mid, and long-term goals (skill trees, season passes, quests, collections) in visible game-world or UI locations as a reminder.
- [page](https://create.roblox.com/docs/production/game-design/onboarding) **[[retention-d1-d7]]** End onboarding with a deliberately designed moment of joy (rewards, animations, celebratory effects) so players return for the next session.
- [page](https://create.roblox.com/docs/production/game-design/onboarding) **[[first-session-onboarding]]** New players typically decide interest in a game within minutes; quickly demonstrate value via progression, social motivators, and starter items.
