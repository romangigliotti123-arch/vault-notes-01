# Docs: education / build-it-play-it-island-of-move / personalize-the-game

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.

## Summary
Roblox Education tutorial showing how to personalize the Move It Simulator template: change the game name and other text via the GameSettings script, and tune numbers like starting move speed and level-up growth. Ends with a promo code challenge and links to further customization (terrain, particles, atmosphere).

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/personalize-the-game) **[[building-and-level-design]]** Start from a template and personalize it by editing a central GameSettings script rather than hunting through code; text and numbers are exposed as variables.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/personalize-the-game) **[[thumbnails-icons]]** Change the game name in GameSettings so the in-game billboard at game start reflects your unique title.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/personalize-the-game) **[[core-loops-and-game-design]]** Tune growthModifier (1 = small movement needed per level, 3 = much more) to control how fast players level up.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/personalize-the-game) **[[core-loops-and-game-design]]** Raise startMoveSpeed (e.g. 7 to 30) to let players begin fast, changing the early-game feel.

## Numbers
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/personalize-the-game) growthModifier: **1 = small movement per level; 3 = much more movement; template uses 1.2** (Movement needed before each level in GameSettings)
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/personalize-the-game) startMoveSpeed: **template 7; example 30** (Starting WalkSpeed-related value before any levels)

## Games
- **Move It Simulator**: Official Roblox education template used as the base for personalization; change its name, speed, and leveling values.

## Tools
Roblox Studio, Explorer, GameSettings script
