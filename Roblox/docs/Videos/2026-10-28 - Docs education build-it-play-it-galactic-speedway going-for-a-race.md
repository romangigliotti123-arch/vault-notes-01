## Summary
Official Roblox education docs page for the Galactic Speedway lesson: test the customized driftspeeder in a race by walking up to the robot and starting a race, then make the experience public so friends can race it. Covers publish-then-set-Permissions steps.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-galactic-speedway/going-for-a-race) **[[development-process-and-speed]]** Publish after each change so players and friends get your latest version; publishing is required before updates reach others.
- [page](https://create.roblox.com/docs/education/build-it-play-it-galactic-speedway/going-for-a-race) **[[ugc-and-avatar-economy]]** New published experiences default to private; switch Permissions to Public in Experience Settings so others can play.
