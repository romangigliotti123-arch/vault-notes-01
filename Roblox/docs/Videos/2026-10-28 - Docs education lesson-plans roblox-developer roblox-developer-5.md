# Docs: education / lesson-plans / roblox-developer / roblox-developer-5

[Open](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-5.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Education lesson plan (Adventure game part 3): teaches students to evaluate and improve their adventure game against three goals: fun, challenging but fair, and error/glitch free. Covers guided finishing steps, independent work, and class wrap-up.

## Tips
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-5) **[[core-loops-and-game-design]]** Evaluate every game against three goals: fun (players want to keep playing), challenging but not punishing, and free of script errors and visual glitches.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-5) **[[core-loops-and-game-design]]** Tune difficulty by changing variables such as starting gold or number of spaces so the game is challenging but still fun.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-5) **[[player-psychology-and-game-feel]]** Challenge should not frustrate or punish players; aim for challenging but fair design.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-5) **[[testing-debugging-and-qa]]** Playtest with a peer before release and check for script errors and unusual-looking parts or visuals.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-5) **[[playtesting-and-feedback]]** Have a friend play the game and collect feedback once the core build is finished.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-5) **[[building-and-level-design]]** Use terrain tools to expand and improve the environment, and add decorative parts that fit the environment's theme.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-5) **[[development-process-and-speed]]** Use spare class time to catch up on unfinished lessons or further develop the project rather than rushing a release.

## Numbers
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/roblox-developer-5) Lesson duration: **60 min total: 5 intro, 15 guided, 30 independent, 10 wrap-up** (Classroom lesson plan timing)
