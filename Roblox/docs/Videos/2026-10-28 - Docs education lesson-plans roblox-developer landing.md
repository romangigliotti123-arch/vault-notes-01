## Summary
Roblox Education lesson-plan landing page for a multi-session "Roblox developer 101" high-school course. Covers Studio basics (parts, scripting via an obstacle course), coding fundamentals (functions, loops, if/then via traps and color-changing platforms), and a three-part adventure game (planning, world building, item tracking, tools, selling, upgrades, playtesting for fun/challenge/bug-free).

## Tips
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/landing) **[[first-session-onboarding]]** Start with a simple obstacle course to teach part manipulation and scripting before moving to a larger adventure game.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/landing) **[[development-process-and-speed]]** Plan the game first, then build the world, then add gameplay systems in stages rather than all at once.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/landing) **[[playtesting-and-feedback]]** Evaluate the finished game against three goals: fun, challenging, and bug-free; redesign or improve as needed before sharing with others.
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/landing) **[[core-loops-and-game-design]]** Build a basic loop of gather resources, purchase items, upgrade spaces, and sell items for an adventure game.

## Numbers
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/landing) Lesson length: **45 minutes per lesson plan (one full class day, high school)** (Course estimate given for each lesson plan)
- [page](https://create.roblox.com/docs/education/lesson-plans/roblox-developer/landing) Course length: **5 sessions** (Studio Basics, Coding Fundamentals, Adventure Game Pt. 1-3)
