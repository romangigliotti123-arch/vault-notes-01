# Docs: ip-licensing / creators

[Open](https://create.roblox.com/docs/ip-licensing/creators.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox official docs on IP licensing for creators: how to browse the Licenses catalog, request full game, in-game sales, and Marketplace licenses, pitch requirements, handle standard and conditional offers, cancel requests, and how revenue share is split.

## Tips
- [page](https://create.roblox.com/docs/ip-licensing/creators) **[[brand-deals-and-ip-licensing]]** Make sure your game is public before requesting an IP license; the docs require this.
- [page](https://create.roblox.com/docs/ip-licensing/creators) **[[brand-deals-and-ip-licensing]]** Write a pitch covering overall vision, creative elements, gameplay fit, and timeline; a well-written pitch makes approval more likely.
- [page](https://create.roblox.com/docs/ip-licensing/creators) **[[brand-deals-and-ip-licensing]]** Attach images to pitches for in-game sales and Marketplace requests (required there; optional for full game licenses).
- [page](https://create.roblox.com/docs/ip-licensing/creators) **[[brand-deals-and-ip-licensing]]** Do not use IP early. Early use can trigger early activation of a license request or accepted agreement.
- [page](https://create.roblox.com/docs/ip-licensing/creators) **[[brand-deals-and-ip-licensing]]** Standard offers auto-activate after 14 days; to reject one you must dispute it, not ignore it.
- [page](https://create.roblox.com/docs/ip-licensing/creators) **[[brand-deals-and-ip-licensing]]** Conditional offers have a 14-day window to make changes, dispute, or cancel; otherwise they expire and the rights holder may file an infringement claim.
- [page](https://create.roblox.com/docs/ip-licensing/creators) **[[brand-deals-and-ip-licensing]]** After marking conditional changes done, the agreement activates only if the rights holder approves; Roblox does not auto-verify.
- [page](https://create.roblox.com/docs/ip-licensing/creators) **[[brand-deals-and-ip-licensing]]** Cancel a pending request at least three days before the proposed start date for time-limited licenses, and only if no early IP use is detected.
- [page](https://create.roblox.com/docs/ip-licensing/creators) **[[brand-deals-and-ip-licensing]]** If you cancel but still want the IP, you must submit a new license request.
- [page](https://create.roblox.com/docs/ip-licensing/creators) **[[monetisation-other]]** Marketplace licensed items: each item can link to only one IP license, and each license allows up to 100 items. Only supported categories qualify: body items, clothing, accessories, animations, makeup.
- [page](https://create.roblox.com/docs/ip-licensing/creators) **[[monetisation-other]]** Removing IP from a game and disputing the offer with 'I modified my creation to remove the IP' is an available dispute path if you fully removed it.
- [page](https://create.roblox.com/docs/ip-licensing/creators) **[[common-mistakes]]** Publishing content using someone else's IP without permission violates the Terms of Use and can lead to content removal and account termination.
- [page](https://create.roblox.com/docs/ip-licensing/creators) **[[common-mistakes]]** Do not ignore a standard license offer expecting it to lapse; it auto-activates after 14 days.

## Numbers
- [page](https://create.roblox.com/docs/ip-licensing/creators) Standard offer auto-activation: **14 days** (Standard license offer activates automatically if not disputed)
- [page](https://create.roblox.com/docs/ip-licensing/creators) Conditional offer response window: **14 days** (To make changes, dispute, or cancel before expiry)
- [page](https://create.roblox.com/docs/ip-licensing/creators) Time-limited cancellation cutoff: **3 days** (Cancel at least 3 days before proposed start date)
- [page](https://create.roblox.com/docs/ip-licensing/creators) Marketplace items per license: **100** (Maximum separate items per Marketplace license)
- [page](https://create.roblox.com/docs/ip-licensing/creators) Item-to-license links: **1** (Each item can be associated with only one IP license at a time)
- [page](https://create.roblox.com/docs/ip-licensing/creators) Example: game pass 100 Robux, license 10%: **License owner 6 Robux, item owner 54, Roblox 30 (of 100 sale)** (Game pass split: 60 to item owner before license share)
- [page](https://create.roblox.com/docs/ip-licensing/creators) Example: developer product/subscription 100 Robux: **License owner 7 Robux, item owner 63, Roblox fees 30** (Developer products and subscriptions at 10% license rate)
- [page](https://create.roblox.com/docs/ip-licensing/creators) Example: avatar item 100 Robux: **License owner 3 Robux, creator 27, seller 40, Roblox fees 30** (Avatar items, bundles, resale items at 10% license rate)
