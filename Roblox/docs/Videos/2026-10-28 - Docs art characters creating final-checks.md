# Docs: art / characters / creating / final-checks

[Open](https://create.roblox.com/docs/art/characters/creating/final-checks.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox documentation checklist for final cleanup of a character model before upload: remove stray meshes, strip extra animation data unrelated to facial animation, and verify geometry, rig, and textures meet avatar technical specs.

## Tips
- [page](https://create.roblox.com/docs/art/characters/creating/final-checks) **[[3d-modeling-rigging-and-animation]]** Remove any mesh objects in the project that are not part of the character model geometry before upload.
- [page](https://create.roblox.com/docs/art/characters/creating/final-checks) **[[3d-modeling-rigging-and-animation]]** Delete extra keyframes, saved poses, and orientations not related to the original facial animation data.
- [page](https://create.roblox.com/docs/art/characters/creating/final-checks) **[[3d-modeling-rigging-and-animation]]** Verify geometry, rig, and textures adhere to the avatar technical specifications before publishing.
