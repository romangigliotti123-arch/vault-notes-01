# Docs: marketplace / categories

[Open](https://create.roblox.com/docs/marketplace/categories.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page defining marketplace avatar asset categories (rigid accessories, layered accessories, bodies/heads, animations, classic clothing). Notes Roblox is experimenting with automated categorization and that intentional miscategorization violates Marketplace policy.

## Tips
- [page](https://create.roblox.com/docs/marketplace/categories) **[[ugc-and-avatar-economy]]** Categorize avatar uploads accurately per the official definitions; intentional miscategorization violates Marketplace policy.
- [page](https://create.roblox.com/docs/marketplace/categories) **[[ugc-and-avatar-economy]]** If automated categorization misidentifies your Marketplace asset, report it as a bug, since Roblox is experimenting with auto-categorization.
- [page](https://create.roblox.com/docs/marketplace/categories) **[[ugc-and-avatar-economy]]** Choose rigid accessory slots by where the item sits: Hat (top of head), Face, Neck, Shoulder, Front (chest only), Back, Waist, Hair.
- [page](https://create.roblox.com/docs/marketplace/categories) **[[ugc-and-avatar-economy]]** Use Body suits or Full masks only when the item covers both upper and lower body or fully replaces head and face; these are auto-detected.
- [page](https://create.roblox.com/docs/marketplace/categories) **[[ugc-and-avatar-economy]]** Use Shorts for items ending above the knee and Dress/Skirt for waist-to-leg coverage without separate leg compartments; Pants for waist to ankle.
