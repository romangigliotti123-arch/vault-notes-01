# Docs: avatar

[Open](https://create.roblox.com/docs/avatar.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox official docs overview of the avatar system: the "who you are" layers (geometry, rigging armature, animations, attachment points/cage meshes) and the "what you wear" layers (makeup, rigid accessories, layered accessories, classic clothing), plus the Studio tooling and object types for each.

## Tips
- [page](https://create.roblox.com/docs/avatar) **[[ugc-and-avatar-economy]]** Use Avatar Setup to auto-process custom 3D assets into Marketplace-ready avatar components (rig, attachment points, cage meshes, FACS facial data).
- [page](https://create.roblox.com/docs/avatar) **[[3d-modeling-rigging-and-animation]]** Standard avatar rigs need 15 poseable joints for the 15 body parts; advanced R15 adds up to 37 optional joints for hands, shoulders and spine.
- [page](https://create.roblox.com/docs/avatar) **[[3d-modeling-rigging-and-animation]]** Follow the required joint hierarchy and naming convention, or the avatar will not function in Studio or on the Marketplace.
- [page](https://create.roblox.com/docs/avatar) **[[3d-modeling-rigging-and-animation]]** Use Adaptive Animation to map joints so animations play across characters with different body types, rigs and proportions.
- [page](https://create.roblox.com/docs/avatar) **[[3d-modeling-rigging-and-animation]]** Use the Animation Capture tool to record or upload video and convert movement and expressions into keyframes.
- [page](https://create.roblox.com/docs/avatar) **[[building-art-and-assets]]** Start from Roblox's downloadable Blender, Maya and .fbx project files for base rigs, attachment points and cage meshes to match standard humanoid specs.
- [page](https://create.roblox.com/docs/avatar) **[[building-art-and-assets]]** Use the Accessory Fitting Tool in Studio to test custom accessories and layered clothing across body types, animations and other accessories.
- [page](https://create.roblox.com/docs/avatar) **[[ugc-and-avatar-economy]]** Classic clothing (t-shirts, pants) is the simplest avatar item to sell: it needs only an image editor and browser, e.g. free GIMP.
- [page](https://create.roblox.com/docs/avatar) **[[ugc-and-avatar-economy]]** Use Roblox's makeup template textures and template heads to author and test face makeup before export.

## Numbers
- [page](https://create.roblox.com/docs/avatar) Body parts: **15 separate mesh body parts** (Avatar geometry: head, torso, and left/right arm and leg segments)
- [page](https://create.roblox.com/docs/avatar) Standard rig joints: **15 poseable joints** (Standard avatar rig articulating the 15 body parts)
- [page](https://create.roblox.com/docs/avatar) Advanced R15 joints: **up to 37 additional optional joints** (Advanced R15 rig for hands, shoulders and spine)

## Tools
Avatar Setup, Adaptive Animation, Animation Editor, Animation Capture, Face Animation Editor, Accessory Fitting Tool, GIMP, Blender
