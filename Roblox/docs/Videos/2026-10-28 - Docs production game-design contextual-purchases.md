# Docs: production / game-design / contextual-purchases

[Open](https://create.roblox.com/docs/production/game-design/contextual-purchases.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox official docs page on contextual purchases: purchase prompts placed outside the shop, categorised as in-play, pre-play, lobby, complementary, and UI, with examples from Dress to Impress, Doors, Super Striker League, Bee Swarm Simulator, BotClash Simulator and Adopt Me.

## Tips
- [page](https://create.roblox.com/docs/production/game-design/contextual-purchases) **[[monetisation-other]]** Use the 'right item, right time' framework: anticipate player wants at key stages and offer a purchasable solution there.
- [page](https://create.roblox.com/docs/production/game-design/contextual-purchases) **[[monetisation-other]]** For in-play purchase prompts, leave time for the full 'Buy Robux' flow (several seconds); if gameplay can't pause, skip in-play prompts.
- [page](https://create.roblox.com/docs/production/game-design/contextual-purchases) **[[monetisation-other]]** Place pre-play offers in natural waiting moments, such as an elevator or pre-round shop, and state each item's benefit clearly.
- [page](https://create.roblox.com/docs/production/game-design/contextual-purchases) **[[monetisation-other]]** If lobby 3D displays show only some items, have them open the full main shop so players know more items exist.
- [page](https://create.roblox.com/docs/production/game-design/contextual-purchases) **[[monetisation-gamepasses]]** Prompt players to buy complementary passes they didn't pick, and bundle items to avoid overusing sales prompts.
- [page](https://create.roblox.com/docs/production/game-design/contextual-purchases) **[[monetisation-other]]** Show loading-screen offers only after the first session, with enough context for players to judge value.
- [page](https://create.roblox.com/docs/production/game-design/contextual-purchases) **[[monetisation-other]]** Stop modal offers from stacking on each other so the UI stays clear.

## Numbers
- [page](https://create.roblox.com/docs/production/game-design/contextual-purchases) Buy Robux purchase flow duration: **several seconds** (time needed for in-play purchase flow to complete)

## Games
- **Dress to Impress**: Sells Theme Props during intermission between rounds to choose next round's theme.
- **Doors**: Pre-Run Shop in elevator sells consumables for next run, using in-game Knobs currency with clear item benefits.
- **Super Striker League**: Lobby 3D objects advertise sales; interaction can open the full main shop.
- **Bee Swarm Simulator**: Bee Pollen Pass and Honey Speed Pass sold side by side as complementary items.
- **BotClash Simulator**: Shop badge in UI signals purchase opportunities.
- **Adopt Me**: Uses loading-screen offers and modal offers (Modern Mansion) shown after play starts.
