## Summary
Roblox documentation tutorial on playtesting code in Studio (Test, Test Here, Run options, troubleshooting string/quote errors) and publishing a game to Roblox (File > Publish, game details, saving cadence of every ten minutes).

## Tips
- [page](https://create.roblox.com/docs/tutorials/curriculums/coding/test-and-save) **[[development-process-and-speed]]** Publish to Roblox every ten minutes or after making a big change to avoid losing edits if Studio closes.
- [page](https://create.roblox.com/docs/tutorials/curriculums/coding/test-and-save) **[[testing-debugging-and-qa]]** Playtest often using Test or Test Here, not Run, so your avatar is inserted and you can interact with scripted content.
- [page](https://create.roblox.com/docs/tutorials/curriculums/coding/test-and-save) **[[testing-debugging-and-qa]]** If the first question doesn't display, check that the question text is inside quotation marks.
- [page](https://create.roblox.com/docs/tutorials/curriculums/coding/test-and-save) **[[testing-debugging-and-qa]]** When concatenating strings with a variable, keep the variable name outside quotes, separate parts with .., and match capitalization exactly.

## Numbers
- [page](https://create.roblox.com/docs/tutorials/curriculums/coding/test-and-save) Recommended publish interval: **Every 10 minutes or after a big change**
