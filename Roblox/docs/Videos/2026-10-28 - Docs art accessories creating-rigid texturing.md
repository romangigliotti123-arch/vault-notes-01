# Docs: art / accessories / creating-rigid / texturing

[Open](https://create.roblox.com/docs/art/accessories/creating-rigid/texturing.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Blender tutorial for texture painting a Roblox accessory (treasure chest example): Smart UV Project unwrap, creating a material with an Image Texture base color, marking 3D areas in Texture Paint mode, then painting the 2D atlas with hard-edged brushes and saving the image.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/texturing) **[[building-art-and-assets]]** Unwrap with Smart UV Project and set Island Margin to .02 to keep UV islands from bleeding into each other.
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/texturing) **[[building-art-and-assets]]** Name texture image files with an affix like _TXT to keep texture files organized.
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/texturing) **[[building-art-and-assets]]** Mark the target areas on the 3D object in Texture Paint mode before painting the 2D atlas, since Smart UV layouts make it hard to see which island maps where.
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/texturing) **[[building-art-and-assets]]** Set the brush Falloff to the flattest icon so painted edges stay sharp.
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/texturing) **[[building-art-and-assets]]** Use Ctrl/Cmd+Z to undo accidental brushstrokes and hold F while dragging to resize the brush.
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/texturing) **[[3d-modeling-rigging-and-animation]]** Use a metallic color for metal borders to save time when texturing accessories, per the tutorial's recommendation.
- [page](https://create.roblox.com/docs/art/accessories/creating-rigid/texturing) **[[building-art-and-assets]]** PBR textures are optional for accessories; adding them adds visual flair but requires additional third-party software.

## Numbers
