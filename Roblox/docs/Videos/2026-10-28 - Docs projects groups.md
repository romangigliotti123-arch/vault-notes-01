# Docs: projects / groups

[Open](https://create.roblox.com/docs/projects/groups.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs on group (team) ownership: creating a group for 100 Robux, role and permission configuration, member management, recurring and one-time payouts with percentage splits, audit logs, and IP protection via Place Copying.

## Tips
- [page](https://create.roblox.com/docs/projects/groups) **[[business-and-payouts]]** Create a group to let multiple creators share a game, assets, and profits, with credit to all contributors. Group creation costs 100 Robux.
- [page](https://create.roblox.com/docs/projects/groups) **[[team-and-budget]]** Assign roles with least-privilege permissions; check each role's permissions before adding members, since permission changes apply only when you click the apply button.
- [page](https://create.roblox.com/docs/projects/groups) **[[business-and-payouts]]** Enable two-step verification before granting sensitive permissions such as payouts/revenue management, which require it.
- [page](https://create.roblox.com/docs/projects/groups) **[[team-and-budget]]** Use recurring payouts with per-game and group-wide percentage splits; the remainder goes to the group balance, so model the split math before launch.
- [page](https://create.roblox.com/docs/projects/groups) **[[business-and-payouts]]** Note that private server subscription split percentages are locked at purchase time and won't change if you adjust splits later.
- [page](https://create.roblox.com/docs/projects/groups) **[[anti-exploit-and-security]]** Keep Place Copying disabled before adding private assets to a group game, and confirm each member's role to protect intellectual property.
- [page](https://create.roblox.com/docs/projects/groups) **[[community-and-discord]]** Use audit logs (Activity History or Community Audit Log) to monitor collaborator activity that might violate group guidelines.
- [page](https://create.roblox.com/docs/projects/groups) **[[common-mistakes]]** Don't rely on Roblox to resolve group disputes; Roblox cannot arbitrate conflicts within a group, so agree on roles and splits in writing up front.

## Numbers
- [page](https://create.roblox.com/docs/projects/groups) Group creation cost: **100 Robux**
- [page](https://create.roblox.com/docs/projects/groups) Social links allowed on group profile: **up to 3**
- [page](https://create.roblox.com/docs/projects/groups) Example recurring split: 1000 Robux game, per-game split 40/30/10 with 20% remainder: **400/300/100 then group split 20/20/10 yields 40/40/20; 100 Robux (50% of group split) to group balance**
