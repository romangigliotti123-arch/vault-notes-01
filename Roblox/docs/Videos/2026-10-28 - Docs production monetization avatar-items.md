# Docs: production / monetization / avatar-items

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/production/monetization/avatar-items.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs on selling avatar items (accessories/clothing) exclusively inside your game via item creators. Covers adding the game's start Place ID to the item's sale location, enabling the Asset ID in the Monetization > Avatar Items menu, and the Avatar Items analytics tab (top items, revenue graph, catalog table, buyer demographics).

## Tips
- [page](https://create.roblox.com/docs/production/monetization/avatar-items) **[[monetisation-other]]** Sell game-specific avatar items by partnering with item creators; you keep Roblox's commission payouts for avatar assets sold within your game.
- [page](https://create.roblox.com/docs/production/monetization/avatar-items) **[[monetisation-other]]** Creator must add your game's starting Place ID to the item's Sale Location field before you can enable the item in your game.
- [page](https://create.roblox.com/docs/production/monetization/avatar-items) **[[monetisation-other]]** If the item doesn't appear when searching by Asset ID, verify the Asset ID and confirm the creator added the correct Place ID.
- [page](https://create.roblox.com/docs/production/monetization/avatar-items) **[[analytics-metrics]]** Use Monetization > Avatar Items > Analytics to compare top selling and top grossing items, net revenue, and buyer age, gender, location and platform.

## Numbers
- [page](https://create.roblox.com/docs/production/monetization/avatar-items) Analytics time-series graph: **up to 8 top items** (Showcase up to eight top items on the sales/net revenue graph)
- [page](https://create.roblox.com/docs/production/monetization/avatar-items) Catalog table size: **up to 400 items** (Sortable by sales and net revenue)

## Tools
Creator Dashboard, Monetization > Avatar Items, Avatar Items Analytics tab
