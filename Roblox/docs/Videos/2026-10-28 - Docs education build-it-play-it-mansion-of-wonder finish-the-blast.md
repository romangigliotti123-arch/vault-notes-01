## Summary
Docs page on finishing a particle "blast" effect in the Mansion of Wonder education project: adjusting particle Size (1–10) and choosing between trailing blasts (default) and single blasts via the LockToPart property.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/finish-the-blast) **[[vfx-and-particles]]** Set particle Size to a number from 1 to 10 in the particle properties, press Enter, then Play to check how it looks.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/finish-the-blast) **[[vfx-and-particles]]** Test particle changes in Play mode and adjust color and size until they fit the intended look before moving on.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/finish-the-blast) **[[vfx-and-particles]]** Leave LockToPart off for a trailing particle effect; turn it on (checkbox) for a single blast that moves as one part.
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/finish-the-blast) **[[vfx-and-particles]]** Compare trailing and single-blast versions and pick the one that fits the vision before continuing.

## Numbers
- [page](https://create.roblox.com/docs/education/build-it-play-it-mansion-of-wonder/finish-the-blast) Particle Size input range: **1 to 10** (Size property in particle properties accepts whole numbers from 1 to 10)
