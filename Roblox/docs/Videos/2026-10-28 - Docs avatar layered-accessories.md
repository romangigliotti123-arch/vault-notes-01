# Docs: avatar / layered-accessories

[Open](https://create.roblox.com/docs/avatar/layered-accessories.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs overview of layered accessories (layered clothing): three layers (mesh and textures, rigging armature, cage meshes and attachments), Studio representation of each, and the creation workflow from Blender/Maya export through Avatar Setup tool to Marketplace. Lists tooling and reference resources.

## Tips
- [page](https://create.roblox.com/docs/avatar/layered-accessories) **[[building-art-and-assets]]** Export all avatar components (mesh, rig, cages) in a single .fbx or .gltf file before importing into Studio.
- [page](https://create.roblox.com/docs/avatar/layered-accessories) **[[3d-modeling-rigging-and-animation]]** Weight the accessory mesh to the rig armature so sleeves and jackets bend with elbows and shoulders during animations.
- [page](https://create.roblox.com/docs/avatar/layered-accessories) **[[3d-modeling-rigging-and-animation]]** Use the inner cage to control how the item wraps the body and the outer cage to control how other layered items fit over it.
- [page](https://create.roblox.com/docs/avatar/layered-accessories) **[[building-art-and-assets]]** Use the Accessory Fitting Tool to auto-generate attachment points for layered accessories instead of placing them manually.
- [page](https://create.roblox.com/docs/avatar/layered-accessories) **[[development-process-and-speed]]** Start with Roblox's reference Blender/Maya project files and the basic sweater tutorial before building a custom layered accessory.
- [page](https://create.roblox.com/docs/avatar/layered-accessories) **[[testing-debugging-and-qa]]** Run the Calisthenics tool and Clothing validation tool to check layered accessories before publishing.
- [page](https://create.roblox.com/docs/avatar/layered-accessories) **[[3d-modeling-rigging-and-animation]]** Use rigid accessories instead of layered ones when the item should not deform and only attach to one avatar point.
- [page](https://create.roblox.com/docs/avatar/layered-accessories) **[[ugc-and-avatar-economy]]** Process the finished accessory with the Avatar Setup tool in Studio before uploading it to the Marketplace for sale.
