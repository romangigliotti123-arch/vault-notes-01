# Docs: avatar / emotes

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/avatar/emotes.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on emotes: an emote is a full-body Animation object whose AnimationId points to an uploaded animation asset. Lists creation workflows: Animation Capture from video, the Animation Editor for manual rigging, and third-party plugins like Moon Animator. Emotes must meet technical specs, Community Standards and Marketplace policies.

## Tips
- [page](https://create.roblox.com/docs/avatar/emotes) **[[ugc-and-avatar-economy]]** Emotes must meet Roblox's technical emote specifications, Community Standards, and Marketplace policies before they can be sold or used.
- [page](https://create.roblox.com/docs/avatar/emotes) **[[building-art-and-assets]]** Use Studio's Animation Capture tool to convert a full-body video into a keyframe sequence for an emote.
- [page](https://create.roblox.com/docs/avatar/emotes) **[[3d-modeling-rigging-and-animation]]** Create emotes manually in Studio's Animation Editor on a character rig, or with a third-party plugin such as Moon Animator.
- [page](https://create.roblox.com/docs/avatar/emotes) **[[ugc-and-avatar-economy]]** Convert the keyframe sequence into an uploadable animation asset via Import emotes - Generate asset ID before publishing to the Marketplace.

## Tools
Animation Capture, Animation Editor, Moon Animator
