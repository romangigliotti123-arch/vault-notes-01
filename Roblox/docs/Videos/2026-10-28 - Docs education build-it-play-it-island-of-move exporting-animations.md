## Summary
Roblox Education docs page on exporting animations from the Animation Editor. Covers publishing via Publish to Roblox (title, description, Submit), copying the exported animation ID, and troubleshooting a blank Animation Editor after restarting Studio.

## Tips
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/exporting-animations) **[[building-art-and-assets]]** Publish animations via Animation Editor > ... > Publish to Roblox, give a title and description, then Submit before using them in-game.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/exporting-animations) **[[building-art-and-assets]]** Copy the exported animation ID (green 'ID Copied!' confirmation) and use it in game scripts so the game knows which animation to play.
- [page](https://create.roblox.com/docs/education/build-it-play-it-island-of-move/exporting-animations) **[[building-art-and-assets]]** If the Animation Editor is blank after reopening Studio, go to Avatar tab, click Animation, then reselect the Figure on the pedestal.
