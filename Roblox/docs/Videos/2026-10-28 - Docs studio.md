## Summary
Roblox Studio official docs landing page. Describes Studio's bundled tools: world building, script editor, device emulation/playtesting, data model and primitives, Assistant AI tools (code/data-model edits, material and texture generation, avatar rig/cage setup), real-time team creation, group-based access, and the Creator Store asset library.

## Tips
- [page](https://create.roblox.com/docs/studio) **[[ai-and-tools]]** Use Assistant to add objects in bulk, modify scripts in place, and optimize code, instead of doing these manually.
- [page](https://create.roblox.com/docs/studio) **[[cross-platform-and-console]]** Use Studio device emulation to test a range of screen sizes and form factors before publishing, so the UI looks right on all devices.
- [page](https://create.roblox.com/docs/studio) **[[team-and-budget]]** Use group-based access to control team members' permissions, shared assets, and profit splits on a game.
- [page](https://create.roblox.com/docs/studio) **[[building-art-and-assets]]** Pull free models, meshes, images, sounds and videos from the Creator Store rather than building every asset from scratch.

## Numbers
- [page](https://create.roblox.com/docs/studio) Cost to use Studio: **Free** (Official docs state Studio is free to use)
- [page](https://create.roblox.com/docs/studio) Reach claimed: **Hundreds of millions of users** (Publishing audience across consoles, desktops, and mobile per docs)
