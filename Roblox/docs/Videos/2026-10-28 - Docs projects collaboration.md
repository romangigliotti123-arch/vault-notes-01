# Docs: projects / collaboration

[Open](https://create.roblox.com/docs/projects/collaboration.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Studio collaboration docs: age-check and age-group requirements for Team Create, permission levels (Owner/Edit/Play/No Access), group vs user-owned game access, live collaborators, comments with email digests, live scripting vs Drafts mode for scripts, script version history, auto-save intervals, and reverting/disabling Team Create.

## Tips
- [page](https://create.roblox.com/docs/projects/collaboration) **[[team-and-budget]]** Before adding collaborators via Team Create, complete an age check (ID or facial age estimation); group/game owners must do so for collaborators to join.
- [page](https://create.roblox.com/docs/projects/collaboration) **[[team-and-budget]]** Only Roblox friends can be granted Edit permission on a user-owned game; anyone can be granted Play access.
- [page](https://create.roblox.com/docs/projects/collaboration) **[[team-and-budget]]** For group games, grant Edit to specific group roles across all games (e.g., Audio Artist) or per-game for temporary access (e.g., FX Artist before release).
- [page](https://create.roblox.com/docs/projects/collaboration) **[[version-control-and-tooling]]** Enable Drafts Mode (File > Experience Settings) to edit scripts locally and commit to a shared repository, similar to source control; it is disabled by default.
- [page](https://create.roblox.com/docs/projects/collaboration) **[[version-control-and-tooling]]** In Drafts, use Compare With Server and Merge From Server to resolve conflicts before committing collaborator changes.
- [page](https://create.roblox.com/docs/projects/collaboration) **[[common-mistakes]]** Before reverting a place version, disable Team Create; otherwise other editors' auto-saves can overwrite the revert.
- [page](https://create.roblox.com/docs/projects/collaboration) **[[community-and-discord]]** Use @username tags in comments to direct feedback; mentions and replies trigger email digests, which are on by default.
- [page](https://create.roblox.com/docs/projects/collaboration) **[[development-process-and-speed]]** Use Live Collaborators > Join to jump to a teammate's location or exact script line instead of searching for it.

## Numbers
- [page](https://create.roblox.com/docs/projects/collaboration) Auto-save interval (place, cloud): **4 minutes (Team Create); scripts auto-saved every 5 minutes** (Studio collaborative session saving behaviour)
- [page](https://create.roblox.com/docs/projects/collaboration) Inactivity threshold: **5 minutes without using Studio marks a collaborator inactive** (Live Collaborators window status)
- [page](https://create.roblox.com/docs/projects/collaboration) Age group compatibility: **Under 9: under 13 only; 9–12: under 16; 13–15: 9–17; 16–17: 13+; 18+: 16+** (Default age-based collaboration pairing rules)
