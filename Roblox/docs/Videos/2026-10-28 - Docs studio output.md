# Docs: studio / output

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/studio/output.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Studio Output window reference: what it displays (script errors, Engine messages, print and warn calls) and its filters (type, context, text), clear shortcut, and detail options (timestamp, context, source, table expansion, log mode). Plugins can read and clear it via LogService.

## Tips
- [page](https://create.roblox.com/docs/studio/output) **[[testing-debugging-and-qa]]** Use the Output window's text filter with an object name to isolate messages from one script or instance while debugging.
- [page](https://create.roblox.com/docs/studio/output) **[[testing-debugging-and-qa]]** Enable Show Source in Output to see the script name and line number for each message, so you can jump straight to the failing line.
- [page](https://create.roblox.com/docs/studio/output) **[[testing-debugging-and-qa]]** Filter Output by context (Client, Server, User Plugin) to separate client and server logs when diagnosing replication or server-only errors.
- [page](https://create.roblox.com/docs/studio/output) **[[testing-debugging-and-qa]]** Enable Show Timestamp (HH:MM:SS.SSS) to correlate Output messages with timing issues or lag spikes.

## Tools
Roblox Studio Output window, LogService
