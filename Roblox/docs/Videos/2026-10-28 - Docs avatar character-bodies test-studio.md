# Docs: avatar / character-bodies / test-studio

[Open](https://create.roblox.com/docs/avatar/character-bodies/test-studio.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on testing custom character bodies in Studio with the Avatar test place and the Avatar Setup tool. Covers configuring the test place (import the body, rename the model to StarterCharacter, drag it into StarterPlayer), the UI test menus, and a checklist for movement, animation, skin tone, lighting, and clothing/accessory fit, with guidance on which modeling-tool fixes each failure points to.

## Tips
- [page](https://create.roblox.com/docs/avatar/character-bodies/test-studio) **[[building-art-and-assets]]** Test custom character bodies in both Avatar Setup and the Avatar test place regularly while iterating, not only once at the end.
- [page](https://create.roblox.com/docs/avatar/character-bodies/test-studio) **[[3d-modeling-rigging-and-animation]]** If walking, climbing, swimming, or jumping looks wrong, fix rigging/skinning and armature in the modeling tool, not in Studio.
- [page](https://create.roblox.com/docs/avatar/character-bodies/test-studio) **[[building-art-and-assets]]** If skin tone or textures look wrong under different lighting, re-adjust texture components in the modeling tool.
- [page](https://create.roblox.com/docs/avatar/character-bodies/test-studio) **[[3d-modeling-rigging-and-animation]]** If rigid or layered accessories fit badly, adjust cage mesh shapes or attachment objects on the character body.
- [page](https://create.roblox.com/docs/avatar/character-bodies/test-studio) **[[3d-modeling-rigging-and-animation]]** Test clothing in motion and in animations, and try different layer orders (e.g. jacket under a t-shirt), since clothing can layer unconventionally.
