# Docs: art / accessories / creating / modify-cage

[Open](https://create.roblox.com/docs/art/accessories/creating/modify-cage.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on modifying the outer cage for clothing (t-shirt/LongSleeve) in the Art/Accessories tooling workflow. Covers sculpting with X-axis symmetry, inflating the cage to fit the mesh, per-spot fixes in Edit mode, and tight-fit passes with wireframe. Warns against deleting cage vertices or faces.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/creating/modify-cage) **[[ugc-and-avatar-economy]]** Keep the outer cage as close as possible to the clothing mesh for best deformation and layering; a tight fit makes clothing layer accurately.
- [page](https://create.roblox.com/docs/art/accessories/creating/modify-cage) **[[ugc-and-avatar-economy]]** Never delete any vertices or faces of the provided cages; destructive edits can cause import issues and stop clothing from importing and displaying correctly.
- [page](https://create.roblox.com/docs/art/accessories/creating/modify-cage) **[[3d-modeling-rigging-and-animation]]** Enable X-Axis symmetry and use the Inflate tool in Sculpt mode to expand the cage over most of the mesh quickly; press F to resize the brush.
- [page](https://create.roblox.com/docs/art/accessories/creating/modify-cage) **[[3d-modeling-rigging-and-animation]]** After symmetric inflation, disable X-Axis symmetry and fix individual spots; the cage must always fully cover the clothing mesh.
- [page](https://create.roblox.com/docs/art/accessories/creating/modify-cage) **[[3d-modeling-rigging-and-animation]]** For small angular areas like the armpit, switch to Edit mode and move individual vertices to avoid crowding cage vertices.
- [page](https://create.roblox.com/docs/art/accessories/creating/modify-cage) **[[3d-modeling-rigging-and-animation]]** Do extra Edit-mode passes with wireframe enabled to tighten vertices against the mesh.

## Tools
Roblox Studio, Sculpt mode, Edit mode, Inflate tool
