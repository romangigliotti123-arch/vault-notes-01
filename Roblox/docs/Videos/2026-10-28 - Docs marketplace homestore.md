# Docs: marketplace / homestore

[Open](https://create.roblox.com/docs/marketplace/homestore.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs for the UGC Homestore template: a Studio template for avatar-item creators to showcase and sell marketplace items via mannequins, an integrated shop, and modular building parts. Covers mannequin attributes, shop catalog behavior, and pointing the shop at another creator's catalog.

## Tips
- [page](https://create.roblox.com/docs/marketplace/homestore) **[[ugc-and-avatar-economy]]** Use the UGC Homestore template if you already have an avatar item catalog; creators selling their own items from their own game get a larger commission split.
- [page](https://create.roblox.com/docs/marketplace/homestore) **[[ugc-and-avatar-economy]]** Mannequins take comma-separated accessoryIds and bundleIds attributes; shoes must be added as a bundle containing both left and right shoe.
- [page](https://create.roblox.com/docs/marketplace/homestore) **[[ugc-and-avatar-economy]]** Add the Mannequin tag or use attributes to script mannequin behavior; attributes load accessories and settings during playtesting.
- [page](https://create.roblox.com/docs/marketplace/homestore) **[[ugc-and-avatar-economy]]** Enable Allow Third Party Sales and set items to Marketplace and All Experiences, or add the game as a sale location, otherwise users see items but cannot buy them.
- [page](https://create.roblox.com/docs/marketplace/homestore) **[[ugc-and-avatar-economy]]** Set DEFAULT_CREATOR_NAME and FETCH_CREATOR_NAME to false in ReplicatedStorage.Settings to pin the shop to a specific creator's catalog.
- [page](https://create.roblox.com/docs/marketplace/homestore) **[[building-and-level-design]]** Duplicate, rotate and rearrange modular building parts to build larger custom shopfronts.
- [page](https://create.roblox.com/docs/marketplace/homestore) **[[ui-ux-design]]** Unpublished places show Roblox-created reference items in mannequins and shop; the catalog only shows the owner's items once published.
