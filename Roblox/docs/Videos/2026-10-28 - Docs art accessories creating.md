# Docs: art / accessories / creating

[Open](https://create.roblox.com/docs/art/accessories/creating.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Official Roblox docs tutorial on creating a layered clothing accessory: model a t-shirt in Blender from a provided mannequin template, texture it, cage it with Roblox template cages, rig it with armature templates, export, then import into Studio and convert to a Class.Accessory. Notes Marketplace listing requirements.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/creating) **[[3d-modeling-rigging-and-animation]]** Start from Roblox's provided Blender mannequin template so the clothing mesh fits the avatar body shape.
- [page](https://create.roblox.com/docs/art/accessories/creating) **[[3d-modeling-rigging-and-animation]]** Use Roblox's template cages to build the layered clothing cage; layered accessories stretch with the rig via cage meshes.
- [page](https://create.roblox.com/docs/art/accessories/creating) **[[3d-modeling-rigging-and-animation]]** Rig the clothing mesh with Roblox's armature templates so it moves with character animations and layers over other clothing.
- [page](https://create.roblox.com/docs/art/accessories/creating) **[[building-art-and-assets]]** Texture the mesh in Blender to set surface appearance and color before export.
- [page](https://create.roblox.com/docs/art/accessories/creating) **[[ugc-and-avatar-economy]]** Listing a layered accessory on the Marketplace requires a Roblox Plus or Premium account, an upload fee, and a publishing advance.
- [page](https://create.roblox.com/docs/art/accessories/creating) **[[ugc-and-avatar-economy]]** Convert the imported model into a Class.Accessory in Studio before selling, saving to toolbox, or using it in-game.

## Tools
Blender, Roblox Studio, Roblox template cages, Roblox armature templates
