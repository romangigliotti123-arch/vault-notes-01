# Docs: art / accessories / creating / sculpting

[Open](https://create.roblox.com/docs/art/accessories/creating/sculpting.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Blender sculpting tutorial for Roblox clothing meshes (t-shirt/long sleeve). Covers switching to Sculpt mode, disabling wireframe, using X-axis symmetry, and applying Elastic Deform, Cloth, and Inflate tools to fit a mesh over a mannequin.

## Tips
- [page](https://create.roblox.com/docs/art/accessories/creating/sculpting) **[[building-art-and-assets]]** Use Elastic Deform at 0.5 strength to stretch vertices so the clothing mesh fully covers the mannequin; adjust brush radius with F.
- [page](https://create.roblox.com/docs/art/accessories/creating/sculpting) **[[building-art-and-assets]]** Hide the mannequin to reach hard-to-access areas while sculpting clothing.
- [page](https://create.roblox.com/docs/art/accessories/creating/sculpting) **[[building-art-and-assets]]** Disable X-Axis symmetry before using the Cloth tool; it can produce unexpected results when symmetry is enabled.
- [page](https://create.roblox.com/docs/art/accessories/creating/sculpting) **[[3d-modeling-rigging-and-animation]]** Finish by combining Elastic Deform, Inflate and Cloth tools so the mesh sits on the body with the desired final shape.

## Numbers
- [page](https://create.roblox.com/docs/art/accessories/creating/sculpting) Elastic Deform brush strength: **0.5**

## Tools
Blender, Elastic Deform, Inflate, Cloth
