# Docs: avatar / emotes / specifications

[Open](https://create.roblox.com/docs/avatar/emotes/specifications.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox docs page on emote specifications. Emotes are a single Animation object with AnimationId set; no meshes or textures required. Lists validation requirements: under 10 seconds, limited root movement and per-frame speed, standard R15 rig only (advanced R15 in closed beta), animation sourced from CurveAnimation, and compliance with Community Standards.

## Tips
- [page](https://create.roblox.com/docs/avatar/emotes/specifications) **[[ugc-and-avatar-economy]]** Emotes need only an Animation object with AnimationId set; meshes and textures are not required for Marketplace upload.
- [page](https://create.roblox.com/docs/avatar/emotes/specifications) **[[ugc-and-avatar-economy]]** Keep emotes under 10 seconds or they may fail validation.
- [page](https://create.roblox.com/docs/avatar/emotes/specifications) **[[ugc-and-avatar-economy]]** Keep the character's joint root close to its starting position; large root movement fails validation.
- [page](https://create.roblox.com/docs/avatar/emotes/specifications) **[[ugc-and-avatar-economy]]** Keep per-frame movement speed under the platform threshold to avoid teleportation-abuse rejection.
- [page](https://create.roblox.com/docs/avatar/emotes/specifications) **[[ugc-and-avatar-economy]]** Target a standard R15 rig; advanced R15 emotes are currently closed beta only.
- [page](https://create.roblox.com/docs/avatar/emotes/specifications) **[[ugc-and-avatar-economy]]** Source the animation from a CurveAnimation, converting animation data via the Generate asset ID import flow if needed.
- [page](https://create.roblox.com/docs/avatar/emotes/specifications) **[[ugc-and-avatar-economy]]** Ensure emote content meets Community Standards and Marketplace policies before upload to avoid rejection.

## Numbers
- [page](https://create.roblox.com/docs/avatar/emotes/specifications) Maximum emote length: **Less than 10 seconds** (Emote animation duration limit for Marketplace validation)
