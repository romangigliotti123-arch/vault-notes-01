# Docs: education / lesson-plans / build-an-obby-lesson

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/education/lesson-plans/build-an-obby-lesson.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox education lesson plan: a 1-hour classroom activity building a basic obby (obstacle course) in Roblox Studio. Covers intro, login and scam/password safety, guided tutorial on parts, properties and AI Assistant prompting, peer playtesting with feedback, and wrap-up on why coding knowledge matters alongside AI.

## Tips
- [page](https://create.roblox.com/docs/education/lesson-plans/build-an-obby-lesson) **[[first-session-onboarding]]** Let students play the example obby for 2-3 minutes before building so they see the goal without going online; give one-minute warning before time's up.
- [page](https://create.roblox.com/docs/education/lesson-plans/build-an-obby-lesson) **[[playtesting-and-feedback]]** Use peer feedback format: two Stars (what they liked) and one Wish (what they want to see); then implement one change based on feedback.
- [page](https://create.roblox.com/docs/education/lesson-plans/build-an-obby-lesson) **[[playtesting-and-feedback]]** Have students switch seats and play-test each other's game, then allow five minutes to improve based on feedback.
- [page](https://create.roblox.com/docs/education/lesson-plans/build-an-obby-lesson) **[[scripting-and-performance]]** Write AI Assistant prompts in specific, plain English; small grammar or wording changes can produce different results, so examine Explorer and Properties to shape prompts.

## Numbers
- [page](https://create.roblox.com/docs/education/lesson-plans/build-an-obby-lesson) Guided tutorial timing: **1 hour total: intro 3 min, login 5-10 min, tutorial 35 min, wrap-up 5 min**
- [page](https://create.roblox.com/docs/education/lesson-plans/build-an-obby-lesson) Peer feedback round: **Two Stars and one Wish per playtest; 5 min to improve based on feedback**
- [page](https://create.roblox.com/docs/education/lesson-plans/build-an-obby-lesson) Help-seeking rule: **Ask three peers before the instructor**

## Games
- **Obby (example course)**: Classic platformer; students build jumping-puzzle obstacle courses as a first Studio project.
- **Be Internet Awesome World (Google)**: Roblox game recommended for teaching online safety and civility to students.

## Tools
Roblox Studio, Roblox Studio Assistant (AI prompting), Explorer window, Properties window
