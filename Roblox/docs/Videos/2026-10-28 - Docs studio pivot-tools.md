# Docs: studio / pivot-tools

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://create.roblox.com/docs/studio/pivot-tools.md) | Roblox Creator Docs | 0 views | 2026-10-28

## Summary
Roblox Studio documentation on pivot tools: moving/rotating pivot points with the Pivot tool, Snap to hotspots, Reset to bounding-box center, PrimaryPart effects on pivot, Properties window pivot fields, and scripting with GetPivot/PivotTo/PivotOffset.

## Tips
- [page](https://create.roblox.com/docs/studio/pivot-tools) **[[building-and-level-design]]** Set a model's PrimaryPart before rotating or scaling it; rotation and scaling then occur around the pivot point.
- [page](https://create.roblox.com/docs/studio/pivot-tools) **[[building-and-level-design]]** Clearing PrimaryPart resets the pivot to the center of the model's bounding box.
- [page](https://create.roblox.com/docs/studio/pivot-tools) **[[building-and-level-design]]** Deleting the PrimaryPart keeps the pivot in place rather than jumping, so deleting parts won't shift the model.
- [page](https://create.roblox.com/docs/studio/pivot-tools) **[[building-and-level-design]]** Use Reset after changing a model's composition to move its pivot back to the center of the new bounding box.

## Tools
Roblox Studio Pivot tool, Edit Pivot tool, Properties window pivot fields, GetPivot()
