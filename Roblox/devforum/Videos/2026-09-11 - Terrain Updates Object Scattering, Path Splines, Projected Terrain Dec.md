# Terrain Updates: Object Scattering, Path Splines, Projected Terrain Decals, and More

## Summary
Roblox Terrain roadmap post announcing upcoming features: terrain scattering system, path splines, projected PBR decals, virtual texturing, and signed distance fields (SDF). Features are targeted for the Terrain Early Access Program, with sign-up via email and DevForum updates.

## Tips
- [page](https://devforum.roblox.com/t/terrain-updates-object-scattering-path-splines-projected-terrain-decals-and-more/4865617) **[[building-art-and-assets]]** Apply to the Terrain Early Access Program to get early access to upcoming terrain features; you'll be emailed when new features are added.
- [page](https://devforum.roblox.com/t/terrain-updates-object-scattering-path-splines-projected-terrain-decals-and-more/4865617) **[[building-art-and-assets]]** Use the upcoming terrain scattering system instead of placing meshes one by one; it uses far fewer resources than instanced meshes.
- [page](https://devforum.roblox.com/t/terrain-updates-object-scattering-path-splines-projected-terrain-decals-and-more/4865617) **[[optimization-and-streaming]]** Expect virtual texturing to cache generated terrain material tiles so they aren't recomputed every frame, improving performance on any device.
