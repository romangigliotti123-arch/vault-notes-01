# Launching even more Server CPU!

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://devforum.roblox.com/t/launching-even-more-server-cpu/4044040) | Roblox DevForum | 780 views | 2025-11-03

## Summary
Roblox announcement: server CPU allocation moves from a static per-Max-Players limit to a dynamic system that scales with real-time connected player count. Rollout Nov 10–12 (2025), automatic for all experiences. Baseline CPU increased; exact formula not shared.

## Tips
- [page](https://devforum.roblox.com/t/launching-even-more-server-cpu/4044040) **[[scripting-and-performance]]** Double-check any system that scales based on number of connected players, since per-player CPU allocation now changes dynamically with player count.
- [page](https://devforum.roblox.com/t/launching-even-more-server-cpu/4044040) **[[optimization-and-streaming]]** If you notice negative server performance after the CPU change, report it in the post comments; Roblox recommends consulting its performance optimization best practices docs.
