# Roblox is coming to Meta Quest!

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://devforum.roblox.com/t/roblox-is-coming-to-meta-quest/2465291) | Roblox DevForum | 1,864 views | 2023-07-12

## Summary
Roblox announcement that the platform is coming to Meta Quest via an App Lab Open Beta (Quest 2 and Quest Pro only), with a new "VR" device type in Studio and the Creator Dashboard. Experiences using default player scripts were auto-enabled for VR; developers can opt out. PC VR experiences will eventually need the VR checkbox.

## Tips
- [page](https://devforum.roblox.com/t/roblox-is-coming-to-meta-quest/2465291) **[[ads-and-sponsored-experiences]]** Test your experience on Meta Quest before enabling the VR checkbox, since Roblox auto-enabled VR for some default-script experiences and you can uncheck it on the Access page.
- [page](https://devforum.roblox.com/t/roblox-is-coming-to-meta-quest/2465291) **[[cross-platform-and-console]]** Existing experiences using default player scripts typically run well in VR without modifications, so publishing to VR may need little extra coding.
- [page](https://devforum.roblox.com/t/roblox-is-coming-to-meta-quest/2465291) **[[cross-platform-and-console]]** Use the Access page (Creator Dashboard > Creations > select experience > Access) or Game Settings in Studio to control VR, Desktop, Mobile, Tablet and Console availability per experience.
- [page](https://devforum.roblox.com/t/roblox-is-coming-to-meta-quest/2465291) **[[trend-research-and-validation]]** Use the Open Beta on App Lab to gather feedback from VR users and iterate before the full Meta Quest Store release.

## Numbers
- [page](https://devforum.roblox.com/t/roblox-is-coming-to-meta-quest/2465291) Daily users: **66 million users join Roblox every day** (Roblox-wide daily joins across mobile, desktop and Xbox)
- [page](https://devforum.roblox.com/t/roblox-is-coming-to-meta-quest/2465291) Active experiences: **15 million by December 31, 2022** (Total active experiences on Roblox)
- [page](https://devforum.roblox.com/t/roblox-is-coming-to-meta-quest/2465291) Minimum age: **13 and older** (Age requirement for Roblox on Meta Quest)
- [page](https://devforum.roblox.com/t/roblox-is-coming-to-meta-quest/2465291) Supported Quest devices in Open Beta: **Meta Quest 2 and Meta Quest Pro** (App Lab Open Beta device support)

## Tools
Roblox Studio, Creator Dashboard, Meta Quest App Lab
