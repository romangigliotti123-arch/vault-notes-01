# How to make a clean, appealing UI

[Open](https://devforum.roblox.com/t/how-to-make-a-clean-appealing-ui/1770083) | Roblox DevForum | 187 views | 2022-04-27

## Summary
Step-by-step tutorial for a clean, simple Roblox UI using Interface Tools: a ScreenGUI with a frame, a tinted rounded background image, a white UIStroke, a red close button, and a title bar overlapping the top edge. Emphasises minimalism and rounded corners for comfortable viewing.

## Tips
- [page](https://devforum.roblox.com/t/how-to-make-a-clean-appealing-ui/1770083) **[[ui-ux-design]]** Use UICorner on frames and images (radius around 0,15) to avoid harsh corners; the author says rounded edges make the UI easier on the eyes.
- [page](https://devforum.roblox.com/t/how-to-make-a-clean-appealing-ui/1770083) **[[ui-ux-design]]** Add a white UIStroke (thickness 3, ApplyStrokeMode Contextual) to the main frame to define its edges against the game background.
- [page](https://devforum.roblox.com/t/how-to-make-a-clean-appealing-ui/1770083) **[[ui-ux-design]]** Use Interface Tools plugin to build UI quickly, and keep layouts simple and minimalistic for a clean look.
- [page](https://devforum.roblox.com/t/how-to-make-a-clean-appealing-ui/1770083) **[[ui-ux-design]]** Place the title bar label at the top-middle, hanging slightly over the frame edge, so the UI's purpose is clear at a glance.
- [page](https://devforum.roblox.com/t/how-to-make-a-clean-appealing-ui/1770083) **[[ui-ux-design]]** Build a close button as a small red TextLabel at the top-right with a UICorner (radius 0,8) and a white border stroke.
- [page](https://devforum.roblox.com/t/how-to-make-a-clean-appealing-ui/1770083) **[[ui-ux-design]]** Tint a background image with a color (29,29,209) and transparency 0.7 to add subtle color without clutter.

## Numbers
- [page](https://devforum.roblox.com/t/how-to-make-a-clean-appealing-ui/1770083) UICorner radius: **0,15 for frame/image; 0,8 for close button** (Author's specific values in tutorial)
- [page](https://devforum.roblox.com/t/how-to-make-a-clean-appealing-ui/1770083) UIStroke thickness: **3** (White stroke on frame and close button border)
- [page](https://devforum.roblox.com/t/how-to-make-a-clean-appealing-ui/1770083) Image transparency: **0.7** (Tinted background image color 29,29,209)
