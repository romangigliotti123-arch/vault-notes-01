# 5 Tricks to improve your UIs

[Open](https://devforum.roblox.com/t/5-tricks-to-improve-your-uis/1416491) | Roblox DevForum | 114 views | 2021-08-15

## Summary
Short DevForum-style tutorial with five UI design tips for Roblox: reasonable input widths, labels over placeholders, reducing form errors (fewer required fields, prefilling data, limiting input symbols), removing borders, and enlarging clickable areas with invisible hit zones.

## Tips
- [page](https://devforum.roblox.com/t/5-tricks-to-improve-your-uis/1416491) **[[ui-ux-design]]** Don't stretch text inputs to fill the full screen width; forms don't need to be 100% wide.
- [page](https://devforum.roblox.com/t/5-tricks-to-improve-your-uis/1416491) **[[ui-ux-design]]** Use visible labels instead of placeholders; placeholders vanish while typing and hurt accessibility, though they're fine in some cases.
- [page](https://devforum.roblox.com/t/5-tricks-to-improve-your-uis/1416491) **[[ui-ux-design]]** Reduce the number of required form fields so users can finish forms correctly on the first try.
- [page](https://devforum.roblox.com/t/5-tricks-to-improve-your-uis/1416491) **[[ui-ux-design]]** Pre-fill form data when known, such as the player's username, so users don't type it manually.
- [page](https://devforum.roblox.com/t/5-tricks-to-improve-your-uis/1416491) **[[ui-ux-design]]** Limit the characters an input accepts to prevent errors before submission.
- [page](https://devforum.roblox.com/t/5-tricks-to-improve-your-uis/1416491) **[[ui-ux-design]]** Remove unnecessary borders; UIs look cleaner without them. Solo developers without a designer tend to overuse borders.
- [page](https://devforum.roblox.com/t/5-tricks-to-improve-your-uis/1416491) **[[ui-ux-design]]** Increase clickable area: bigger targets are easier to hit. For small controls, add an invisible clickable area around them.
