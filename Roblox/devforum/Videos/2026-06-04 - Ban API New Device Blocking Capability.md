# Ban API: New Device Blocking Capability

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://devforum.roblox.com/t/ban-api-new-device-blocking-capability/4668265) | Roblox DevForum | 467 views | 2026-06-04

## Summary
Roblox Creator Hub announcement launching Device Blocking in the Ban API. Adding ApplyDeviceBlock=true to BanAsync blocks the banned user's desktop device (Windows/macOS) from rejoining for 24 hours, deterring ban evasion via alt accounts. Covers limits: no mobile/console, no propagation to the account, and Unban overrides the device block.
