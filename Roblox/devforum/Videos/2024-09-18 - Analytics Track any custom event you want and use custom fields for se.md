# Analytics: Track any custom event you want and use custom fields for segmentation

[Open](https://devforum.roblox.com/t/analytics-track-any-custom-event-you-want-and-use-custom-fields-for-segmentation/3163688) | Roblox DevForum | 325 views | 2024-09-18

## Summary
Roblox Creator announcement introducing custom events for analytics: track any custom UI, preference, or balance event (up to 100), view on Custom dashboard page, and segment funnel, economy, and custom events with up to three custom fields. Includes guidance on when to use custom vs funnel vs economy events.

## Tips
- [page](https://devforum.roblox.com/t/analytics-track-any-custom-event-you-want-and-use-custom-fields-for-segmentation/3163688) **[[analytics-metrics]]** Track custom events for UI clicks, player preferences, and game balance (e.g. win/loss ratio per class) that don't fit funnel or economy categories.
- [page](https://devforum.roblox.com/t/analytics-track-any-custom-event-you-want-and-use-custom-fields-for-segmentation/3163688) **[[analytics-metrics]]** Use funnel events for sequential actions like onboarding, store purchase, and level progression; use them to measure step-to-step conversion.
- [page](https://devforum.roblox.com/t/analytics-track-any-custom-event-you-want-and-use-custom-fields-for-segmentation/3163688) **[[analytics-metrics]]** Use economy events for actions that change in-game currency flow, such as gaining or spending currency.
- [page](https://devforum.roblox.com/t/analytics-track-any-custom-event-you-want-and-use-custom-fields-for-segmentation/3163688) **[[analytics-metrics]]** Use custom fields (up to three) to break down funnel, economy, and custom event charts by segment, e.g. level, player class, or weapon type.
- [page](https://devforum.roblox.com/t/analytics-track-any-custom-event-you-want-and-use-custom-fields-for-segmentation/3163688) **[[first-session-onboarding]]** Optimise onboarding funnels using funnel analytics; Fabled Legacy reached 6-month retention highs after doing so.

## Numbers
- [page](https://devforum.roblox.com/t/analytics-track-any-custom-event-you-want-and-use-custom-fields-for-segmentation/3163688) Custom events limit: **100 per experience** (Maximum number of distinct custom events you can track)
- [page](https://devforum.roblox.com/t/analytics-track-any-custom-event-you-want-and-use-custom-fields-for-segmentation/3163688) Custom fields limit: **3** (Custom fields usable to segment funnel, economy, and custom event charts)
- [page](https://devforum.roblox.com/t/analytics-track-any-custom-event-you-want-and-use-custom-fields-for-segmentation/3163688) Chart delay: **up to 24 hours** (Time before new custom event charts appear on Custom dashboard page)
- [page](https://devforum.roblox.com/t/analytics-track-any-custom-event-you-want-and-use-custom-fields-for-segmentation/3163688) Experiences using funnel/economy analytics: **over 1,000** (Since launch of funnel and economy analytics)
