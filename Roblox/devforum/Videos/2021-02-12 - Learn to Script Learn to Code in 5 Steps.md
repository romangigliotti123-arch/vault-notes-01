# Learn to Script / Learn to Code in 5 Steps

[Open](https://devforum.roblox.com/t/learn-to-script-learn-to-code-in-5-steps/1043259) | Roblox DevForum | 311 views | 2021-02-12

## Summary
Community guide (2021, updated 2022) on learning Roblox Lua/Luau in 5 steps: build a consolidated resource list, optimize the learning environment with notes and productivity rules (15-to-5, 2-Day Rule), ask specific questions, practice fundamentals, and set small achievable goals. Emphasizes metacognition and self-regulated learning.

## Tips
- [page](https://devforum.roblox.com/t/learn-to-script-learn-to-code-in-5-steps/1043259) **[[first-session-onboarding]]** Start learning with small, achievable goals (e.g., change a part's colour when a specific event happens) rather than a front-page game; progress is easier to track.
- [page](https://devforum.roblox.com/t/learn-to-script-learn-to-code-in-5-steps/1043259) **[[development-process-and-speed]]** Use the 15-to-5 Rule: work 15 minutes with full focus, then take a 5-minute break; keep break shorter than work time.
- [page](https://devforum.roblox.com/t/learn-to-script-learn-to-code-in-5-steps/1043259) **[[development-process-and-speed]]** Apply the 2 Day Rule: never take more than 2 entire days off from a project in a row; resume on the third day.
- [page](https://devforum.roblox.com/t/learn-to-script-learn-to-code-in-5-steps/1043259) **[[mindset-and-strategy]]** Ask specific questions when stuck ("what part of the script isn't working?", "what could I do to solve this?") instead of "why doesn't this work?".
- [page](https://devforum.roblox.com/t/learn-to-script-learn-to-code-in-5-steps/1043259) **[[mindset-and-strategy]]** Reduce distractions by moving your phone to another room so distracting actions take more effort, making productive work the path of least resistance.
- [page](https://devforum.roblox.com/t/learn-to-script-learn-to-code-in-5-steps/1043259) **[[mindset-and-strategy]]** Work smart rather than long: one efficient hour a day can beat eight inefficient hours if burnout is a risk.
- [page](https://devforum.roblox.com/t/learn-to-script-learn-to-code-in-5-steps/1043259) **[[development-process-and-speed]]** Keep a consolidated, searchable resource list (Google Doc or similar) and take notes on key fundamentals from each resource you study.
- [page](https://devforum.roblox.com/t/learn-to-script-learn-to-code-in-5-steps/1043259) **[[scripting-and-performance]]** Follow the Roblox Lua Style Guide on GitHub from the start to avoid bad habits that compound and make code harder to modify and debug.
- [page](https://devforum.roblox.com/t/learn-to-script-learn-to-code-in-5-steps/1043259) **[[scripting-and-performance]]** Use Lua 5.1 Reference Manual and Programming in Lua to strengthen base-language fundamentals; Luau builds on Lua 5.1.
- [page](https://devforum.roblox.com/t/learn-to-script-learn-to-code-in-5-steps/1043259) **[[mindset-and-strategy]]** Do not rely on YouTube alone; practise coding yourself, using videos as a supplementary visual aid.

## Numbers
- [page](https://devforum.roblox.com/t/learn-to-script-learn-to-code-in-5-steps/1043259) Pomodoro-style work/break cycle: **15 minutes work, 5 minutes break**
- [page](https://devforum.roblox.com/t/learn-to-script-learn-to-code-in-5-steps/1043259) Maximum consecutive days off a project: **2 days (resume on day 3)**
