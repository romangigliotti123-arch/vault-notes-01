# Roblox Requests: Simple, powerful HTTP in Roblox

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://devforum.roblox.com/t/roblox-requests-simple-powerful-http-in-roblox/355294) | Roblox DevForum | 91 views | 2019-09-22

## Summary
Introduces Roblox Requests, a Luau HTTP library modeled on Python Requests, wrapping HttpService with verb helpers, sessions, cookies, rate limiting, JSON handling, multipart uploads, caching, and Promise support. Mainly a tool showcase with install links and documentation pointers.

## Tips
- [page](https://devforum.roblox.com/t/roblox-requests-simple-powerful-http-in-roblox/355294) **[[ai-and-tools]]** Use a wrapper library like Roblox Requests instead of raw HttpService to cut boilerplate for HTTP calls, per the author's stated main purpose.
- [page](https://devforum.roblox.com/t/roblox-requests-simple-powerful-http-in-roblox/355294) **[[scripting-and-performance]]** Use configurable rate limiting to balance your game's HTTP usage so requests stay within Roblox and third-party API limits.
- [page](https://devforum.roblox.com/t/roblox-requests-simple-powerful-http-in-roblox/355294) **[[data-persistence]]** Use the library's DataStore- or MessagingService-backed global cache for large resources shared across servers instead of refetching them.
- [page](https://devforum.roblox.com/t/roblox-requests-simple-powerful-http-in-roblox/355294) **[[scripting-and-performance]]** Enable local or global response caching to avoid repeating identical HTTP requests.
