# Analytics: Track new user retention by daily and weekly cohort

[Open](https://devforum.roblox.com/t/analytics-track-new-user-retention-by-daily-and-weekly-cohort/3817030) | Roblox DevForum | 138 views | 2025-07-15

## Summary
Roblox Creator Hub announcement (July 2025) adding retention analytics: daily/weekly new-user cohort table, a unified first-play-date cohort across D1/D7/D30 charts, and a DAU/MAU stickiness metric replacing the old D1/D7/D30 stickiness charts.

## Tips
- [page](https://devforum.roblox.com/t/analytics-track-new-user-retention-by-daily-and-weekly-cohort/3817030) **[[analytics-metrics]]** Use the daily/weekly new-user cohort table to check whether big events or holidays brought in players who retain as well as your typical cohorts.
- [page](https://devforum.roblox.com/t/analytics-track-new-user-retention-by-daily-and-weekly-cohort/3817030) **[[analytics-metrics]]** Check the New User Funnel tab for 7D playtime per user, 7D payer conversion, and 7D/30D revenue per user to see if event cohorts monetise better.
- [page](https://devforum.roblox.com/t/analytics-track-new-user-retention-by-daily-and-weekly-cohort/3817030) **[[analytics-metrics]]** Read D1, D7 and D30 charts on the same date as one cohort: they now use first-play date, so the same date shows the same players over time.
- [page](https://devforum.roblox.com/t/analytics-track-new-user-retention-by-daily-and-weekly-cohort/3817030) **[[analytics-metrics]]** Track DAU/MAU stickiness; a declining ratio means new players aren't forming daily habits, so improve onboarding, use experience events, or add engagement hooks.
- [page](https://devforum.roblox.com/t/analytics-track-new-user-retention-by-daily-and-weekly-cohort/3817030) **[[retention-d1-d7]]** After a large influx of new users, expect a temporary dip in D1/D7/D30 retention for that cohort; it typically recovers over time.

## Numbers
- [page](https://devforum.roblox.com/t/analytics-track-new-user-retention-by-daily-and-weekly-cohort/3817030) Daily cohort window: **10 days** (New users returning over 10 days in daily cohort table)
- [page](https://devforum.roblox.com/t/analytics-track-new-user-retention-by-daily-and-weekly-cohort/3817030) Weekly cohort window: **10 weeks** (New users returning over 10 weeks in weekly cohort table)
- [page](https://devforum.roblox.com/t/analytics-track-new-user-retention-by-daily-and-weekly-cohort/3817030) Example cohort definitions on 6/20: **D1 = first play 6/19; D7 = first play 6/13; D30 = first play 5/21 (old method)** (Old charts mixed cohorts; new charts use first-play date so 6/20 is one cohort)
