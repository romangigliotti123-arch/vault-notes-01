# Yucon Framework || Optimization, organization, and high-level security

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://devforum.roblox.com/t/yucon-framework-optimization-organization-and-high-level-security/630895) | Roblox DevForum | 251 views | 2020-06-17

## Summary
Promotional post for the Yucon Framework, a general-purpose Roblox framework that runs all scripts through one server and one client script with a shared-code layer and object classes. A 2023 notice at the top says the framework is memory-hungry, buggy, and harmful, and recommends small single-purpose frameworks instead.

## Tips
- [page](https://devforum.roblox.com/t/yucon-framework-optimization-organization-and-high-level-security/630895) **[[code-architecture-and-frameworks]]** Avoid general-purpose frameworks. They create unnecessary memory buildup and prevent proper typechecking and autocomplete on many things.
- [page](https://devforum.roblox.com/t/yucon-framework-optimization-organization-and-high-level-security/630895) **[[code-architecture-and-frameworks]]** Use smaller frameworks that each solve one problem: a UI framework (Fusion or Roact) for UI, a remote framework for remotes, and a load-behavior framework.
- [page](https://devforum.roblox.com/t/yucon-framework-optimization-organization-and-high-level-security/630895) **[[common-mistakes]]** Do not adopt Yucon. The author says it is more memory-hungry and buggier than other frameworks.

## Tools
Yucon Framework, Yucon Editor (Roblox Studio plugin), Fusion, Roact
