# The Ultimate UI Design Guide

[Open](https://devforum.roblox.com/t/the-ultimate-ui-design-guide/1236916) | Roblox DevForum | 426 views | 2021-05-18

## Summary
Tutorial on designing and importing Roblox UI: sketch in MS Paint, prototype layout and colors in Figma, export images/gradients, then rebuild in Studio using properties tab, Gotham font substitute and AutoScale plugin. UI design only, not programming.

## Tips
- [page](https://devforum.roblox.com/t/the-ultimate-ui-design-guide/1236916) **[[ui-ux-design]]** Sketch the UI roughly first (MS Paint is fine); avoid overdetailing so the sketch stays a quick layout plan.
- [page](https://devforum.roblox.com/t/the-ultimate-ui-design-guide/1236916) **[[ui-ux-design]]** Build a layout skeleton in Figma before details so buttons and text align without overlapping elements.
- [page](https://devforum.roblox.com/t/the-ultimate-ui-design-guide/1236916) **[[ui-ux-design]]** Don't always use dark themes; use light themes for cartoony or playful UI.
- [page](https://devforum.roblox.com/t/the-ultimate-ui-design-guide/1236916) **[[ui-ux-design]]** Experiment with rounded corners on frames and buttons depending on the UI style.
- [page](https://devforum.roblox.com/t/the-ultimate-ui-design-guide/1236916) **[[ui-ux-design]]** Use a palette tool like Coolors and lock colors you like while regenerating to build a scheme.
- [page](https://devforum.roblox.com/t/the-ultimate-ui-design-guide/1236916) **[[building-art-and-assets]]** Export icons and images from Figma as PNG (or SVG for quality, but Studio needs PNG); make icons white so Studio ImageColor3 can recolor them.
- [page](https://devforum.roblox.com/t/the-ultimate-ui-design-guide/1236916) **[[building-art-and-assets]]** Copy Figma gradients into UIGradient and rounded corners into UICorner; match sizes from Figma W/H values.
- [page](https://devforum.roblox.com/t/the-ultimate-ui-design-guide/1236916) **[[ui-ux-design]]** Set Anchor Point to 0.5,0.5 on background frames and position elements via the Properties tab rather than the UI editor, which is more precise.
- [page](https://devforum.roblox.com/t/the-ultimate-ui-design-guide/1236916) **[[ui-ux-design]]** Roblox Studio cannot upload font files; pick a similar built-in font (e.g. Gotham for Montserrat).
- [page](https://devforum.roblox.com/t/the-ultimate-ui-design-guide/1236916) **[[ui-ux-design]]** Use an AutoScale plugin on UI elements so the interface scales across screen sizes.

## Numbers
