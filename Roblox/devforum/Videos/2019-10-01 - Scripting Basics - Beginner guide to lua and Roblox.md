# Scripting Basics - Beginner guide to lua and Roblox

## Summary
Beginner Roblox scripting guide by Hexcede covering Lua basics (data types, tables, booleans, numbers, variables/scope, functions, statements, loops), Roblox concepts (properties, methods with colon syntax, events, getting instances), and coding habits (googling, neat code, capitalization, service variables, copying code safely).

## Tips
- [page](https://devforum.roblox.com/t/scripting-basics-beginner-guide-to-lua-and-roblox/359838) **[[code-architecture-and-frameworks]]** Keep code neat: name variables clearly and indent, so you and others can read it later and spot improvements.
- [page](https://devforum.roblox.com/t/scripting-basics-beginner-guide-to-lua-and-roblox/359838) **[[luau-language-and-types]]** Use lowercase for variables and PascalCase for classes, Instances, and Services; keep capitalization consistent.
- [page](https://devforum.roblox.com/t/scripting-basics-beginner-guide-to-lua-and-roblox/359838) **[[luau-language-and-types]]** Store services in variables with matching names, e.g. local ServerScriptService = game:GetService("ServerScriptService"), so usages are easy to find.
- [page](https://devforum.roblox.com/t/scripting-basics-beginner-guide-to-lua-and-roblox/359838) **[[luau-language-and-types]]** Prefer local variables over globals to limit scope and avoid accidental collisions.
