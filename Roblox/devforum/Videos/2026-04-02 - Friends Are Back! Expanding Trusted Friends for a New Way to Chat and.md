# Friends Are Back! Expanding Trusted Friends for a New Way to Chat and Play

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://devforum.roblox.com/t/friends-are-back-expanding-trusted-friends-for-a-new-way-to-chat-and-play/4554217) | Roblox DevForum | 1,158 views | 2026-04-02

## Summary
Roblox DevForum announcement expanding Trusted Friends (formerly Trusted Connections): age-checked users 13+ can add younger siblings/cousins/school friends with parental approval, and cross-age-group Trusted Friends can chat in experiences. Parents auto-upgraded to Trusted Friend if linked, age-checked, and already Friends. Creators should rename "Connections" UI to "Friends"; no API changes.

## Tips
- [page](https://devforum.roblox.com/t/friends-are-back-expanding-trusted-friends-for-a-new-way-to-chat-and-play/4554217) **[[social-features-and-virality]]** Rename any custom UI labeled 'Connections' or 'Trusted Connections' to 'Friends' and 'Trusted Friends'. No API changes are required.
- [page](https://devforum.roblox.com/t/friends-are-back-expanding-trusted-friends-for-a-new-way-to-chat-and-play/4554217) **[[social-features-and-virality]]** Trusted Friends are labeled 'Trusted' in experience chat and profiles, so players can see at a glance who they can chat with.
- [page](https://devforum.roblox.com/t/friends-are-back-expanding-trusted-friends-for-a-new-way-to-chat-and-play/4554217) **[[age-ratings-moderation-and-tos]]** Cross-age chat is only between Trusted Friends; all communication is proactively monitored by Roblox. Design social features assuming chat is monitored and filtered.
- [page](https://devforum.roblox.com/t/friends-are-back-expanding-trusted-friends-for-a-new-way-to-chat-and-play/4554217) **[[age-ratings-moderation-and-tos]]** Chat availability varies by age: under 9 is off by default (parents can enable for Trusted Friends); 9–12 on by default with filtering; under 13 requires parental approval for Trusted Friends.

## Numbers
- [page](https://devforum.roblox.com/t/friends-are-back-expanding-trusted-friends-for-a-new-way-to-chat-and-play/4554217) Minimum age for adding Trusted Friends via QR scan or contacts import: **13 and older, age-checked**
- [page](https://devforum.roblox.com/t/friends-are-back-expanding-trusted-friends-for-a-new-way-to-chat-and-play/4554217) Chat default for users younger than 9: **Off by default**
- [page](https://devforum.roblox.com/t/friends-are-back-expanding-trusted-friends-for-a-new-way-to-chat-and-play/4554217) Chat default for users aged 9–12: **On by default, filtered**
