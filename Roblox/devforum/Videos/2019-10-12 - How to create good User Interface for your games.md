# How to create good User Interface for your games

[Open](https://devforum.roblox.com/t/how-to-create-good-user-interface-for-your-games/367258) | Roblox DevForum | 209 views | 2019-10-12

## Summary
Tutorial on creating Roblox HUD UI in Photoshop: tool shortcuts, 1920x1080 document, building a wooden-styled currency display via colour palette, rounded rectangles, clipping masks, cracks, and a coin icon. Stresses UI should inform players, not obstruct the view.

## Tips
- [page](https://devforum.roblox.com/t/how-to-create-good-user-interface-for-your-games/367258) **[[ui-ux-design]]** Keep on-screen UI limited to information relevant to gameplay; avoid persistent promo text like 'buy our gamepasses' that obstructs the view.
- [page](https://devforum.roblox.com/t/how-to-create-good-user-interface-for-your-games/367258) **[[ui-ux-design]]** Pick a UI style that fits the game's theme (e.g. dark, metal or concrete textures for a medieval RPG) rather than bland generic shapes.
- [page](https://devforum.roblox.com/t/how-to-create-good-user-interface-for-your-games/367258) **[[building-art-and-assets]]** Pick three colours (base, dark, light) first and reuse them across the whole HUD for visual consistency.
- [page](https://devforum.roblox.com/t/how-to-create-good-user-interface-for-your-games/367258) **[[building-art-and-assets]]** Design HUD at 1920x1080 in Photoshop, and convert shapes to smart objects so they stay sharp when scaled down then up.
- [page](https://devforum.roblox.com/t/how-to-create-good-user-interface-for-your-games/367258) **[[building-art-and-assets]]** Use clipping masks (Ctrl+Shift+N, 'Use Previous Layer to Create Clipping Mask') to paint textures confined inside a shape.
- [page](https://devforum.roblox.com/t/how-to-create-good-user-interface-for-your-games/367258) **[[building-art-and-assets]]** Use reference images (e.g. Google Images or Pinterest searches) when painting textures like wood grain.
- [page](https://devforum.roblox.com/t/how-to-create-good-user-interface-for-your-games/367258) **[[ui-ux-design]]** Use a dark inset panel behind currency numbers so the text contrasts well against the textured frame.

## Numbers
- [page](https://devforum.roblox.com/t/how-to-create-good-user-interface-for-your-games/367258) HUD document size: **1920x1080 px** (Author's standard canvas for game UI in Photoshop)
- [page](https://devforum.roblox.com/t/how-to-create-good-user-interface-for-your-games/367258) Rounded rectangle corner radius: **10 px** (Radius used for base wooden frame shape)
