# Hey experienced programmers, Nevermore Engine now can be installed in 30 seconds

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://devforum.roblox.com/t/hey-experienced-programmers-nevermore-engine-now-can-be-installed-in-30-seconds/20808) | Roblox DevForum | 71 views | 2015-12-24

## Summary
Quenty announces a 30-second install for NevermoreEngine, an open-source collection of Luau libraries and a loader that works alongside existing frameworks. Lists available libraries (camera effects, admin commands, pseudo chat, promises, signals, UI, projectiles, etc.) and suggests trying the admin commands to explore it.

## Tips
- [page](https://devforum.roblox.com/t/hey-experienced-programmers-nevermore-engine-now-can-be-installed-in-30-seconds/20808) **[[code-architecture-and-frameworks]]** Nevermore is a set of libraries plus a loader; libraries only run if you explicitly load them, so unused ones cost no processing power.
- [page](https://devforum.roblox.com/t/hey-experienced-programmers-nevermore-engine-now-can-be-installed-in-30-seconds/20808) **[[code-architecture-and-frameworks]]** Build reusable building blocks (e.g. compass model plus a GUI-animation class) rather than finished blocks, so systems stay customisable.
