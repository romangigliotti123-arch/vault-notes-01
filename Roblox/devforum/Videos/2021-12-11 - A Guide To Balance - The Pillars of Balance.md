# A Guide To Balance - The Pillars of Balance

[Open](https://devforum.roblox.com/t/a-guide-to-balance-the-pillars-of-balance/1585238) | Roblox DevForum | 46 views | 2021-12-11

## Summary
A balance-design framework for Roblox games built on six "pillars": mechanical, progressive, skill progression, comparative, conceptual, and executional balance. Uses a tank-class fighting example and Elemental Battleground and Critical Strike cases to show how to spot imbalance.

## Tips
- [page](https://devforum.roblox.com/t/a-guide-to-balance-the-pillars-of-balance/1585238) **[[core-loops-and-game-design]]** Balance on six axes: mechanical, progressive, skill progression, comparative, conceptual, and executional. Stats alone don't cover balance.
- [page](https://devforum.roblox.com/t/a-guide-to-balance-the-pillars-of-balance/1585238) **[[core-loops-and-game-design]]** List each class's or weapon's strengths and weaknesses. Check whether strengths overpower weaknesses by a severe amount, not just whether there are more strengths.
- [page](https://devforum.roblox.com/t/a-guide-to-balance-the-pillars-of-balance/1585238) **[[core-loops-and-game-design]]** A major weakness can offset many strengths. Example: high HP and damage fail if long cooldowns and low base mobility leave the class unable to catch opponents.
- [page](https://devforum.roblox.com/t/a-guide-to-balance-the-pillars-of-balance/1585238) **[[core-loops-and-game-design]]** Don't let level-ups make new players fight maxed players in PvP. Gate stat progression so starting players can compete, or the system breaks balance.
- [page](https://devforum.roblox.com/t/a-guide-to-balance-the-pillars-of-balance/1585238) **[[player-psychology-and-game-feel]]** Decide deliberately whether high-skill actions should be rewarded more heavily. Rewards satisfy skilled play but can make consistent execution second nature and unbalanced.
- [page](https://devforum.roblox.com/t/a-guide-to-balance-the-pillars-of-balance/1585238) **[[core-loops-and-game-design]]** When comparing classes or weapons, break each into attributes, weight attributes by importance, and mark each green (stronger), red (weaker), or grey (neutral).
- [page](https://devforum.roblox.com/t/a-guide-to-balance-the-pillars-of-balance/1585238) **[[core-loops-and-game-design]]** Treat a class as too strong or weak only if the issue persists against all other classes. If it is only a counter matchup, it is not a balance problem.
- [page](https://devforum.roblox.com/t/a-guide-to-balance-the-pillars-of-balance/1585238) **[[core-loops-and-game-design]]** Check whether a class's central idea fits the game's design. Example: an always-airborne class is near-invincible if most attacks can't aim vertically.
- [page](https://devforum.roblox.com/t/a-guide-to-balance-the-pillars-of-balance/1585238) **[[core-loops-and-game-design]]** Give a concept-heavy class secondary options so it is not reliant on its core gimmick. Air moves that are supplementary, not required, make the class viable.
- [page](https://devforum.roblox.com/t/a-guide-to-balance-the-pillars-of-balance/1585238) **[[common-mistakes]]** Don't assume balance means everything is even. Intentional differences between options are fine as long as no single option dominates.
- [page](https://devforum.roblox.com/t/a-guide-to-balance-the-pillars-of-balance/1585238) **[[core-loops-and-game-design]]** Test executional balance: bugs and unintuitive behaviour, such as a projectile firing off-center, make an ability feel weak and players avoid it.

## Games
- **Elemental Battleground**: Skill-point stat progression let level-40 players face fully maxed players in pure PvP, breaking progressive balance.
- **Critical Strike**: Ruler class's aerial kit was near-invincible because most abilities can't aim vertically; central idea conflicted with game design.
