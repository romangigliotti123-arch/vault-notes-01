# Text+ | Custom fonts & advanced control

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.

## Summary
Documentation page for Text+, an open-source Roblox text-rendering library supporting custom font files, per-character/word/line styling, justified alignment, spacing controls, and scaling that differs from TextScaled. Promotes showcases and related projects; no monetisation or growth advice.

## Tips
- [page](https://devforum.roblox.com/t/text-custom-fonts-advanced-control/3521684) **[[ui-ux-design]]** Use Text+ scaling instead of TextScaled when you need text to fit identically across devices; the library handles size differences more precisely.
- [page](https://devforum.roblox.com/t/text-custom-fonts-advanced-control/3521684) **[[optimization-and-streaming]]** Text+ is marketed as ultra-optimized and lag-free; evaluate it against TextScaled if text rendering causes performance issues in heavy UI.
- [page](https://devforum.roblox.com/t/text-custom-fonts-advanced-control/3521684) **[[version-control-and-tooling]]** Keep Text+ on the latest release; the author recommends updating to get new features and fixes, with releases listed on GitHub.
