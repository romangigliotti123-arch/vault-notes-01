# How to Plan, Design and Build Quality User Interfaces

[Open](https://devforum.roblox.com/t/how-to-plan-design-and-build-quality-user-interfaces/281785) | Roblox DevForum | 279 views | 2019-05-19

## Summary
Tutorial showing how to find a UI concept on Pinterest, recreate it in Adobe XD (Web 1920 artboard, shapes, rounded corners, union/rotate for symbols), export pieces, clean edges with Pixelfix, and import into Roblox Studio as a toggle UI.

## Tips
- [page](https://devforum.roblox.com/t/how-to-plan-design-and-build-quality-user-interfaces/281785) **[[ui-ux-design]]** Judge every UI concept against three principles: usable (responds to any interaction), navigable (no maze to find store or settings), and desirable (clean, no excess, fits game style).
- [page](https://devforum.roblox.com/t/how-to-plan-design-and-build-quality-user-interfaces/281785) **[[ui-ux-design]]** Build UI mockups in a vector tool like Adobe XD rather than directly in Studio, since Studio's built-in UI design tools are limited.
- [page](https://devforum.roblox.com/t/how-to-plan-design-and-build-quality-user-interfaces/281785) **[[building-art-and-assets]]** Export each UI element as a separate image and colour the symbol assets white so they can be tinted in Studio.
- [page](https://devforum.roblox.com/t/how-to-plan-design-and-build-quality-user-interfaces/281785) **[[building-art-and-assets]]** Run exported images through Pixelfix to remove dark edges caused by transparent pixels when images are scaled down.
- [page](https://devforum.roblox.com/t/how-to-plan-design-and-build-quality-user-interfaces/281785) **[[building-art-and-assets]]** Upload reusable UI assets via the Roblox website for use across games, and avoid duplicate uploads to keep the inventory uncluttered.
- [page](https://devforum.roblox.com/t/how-to-plan-design-and-build-quality-user-interfaces/281785) **[[ui-ux-design]]** Keep UI elements consistent in size and style across the whole interface by designing each element carefully against one shared spec.

## Numbers
- [page](https://devforum.roblox.com/t/how-to-plan-design-and-build-quality-user-interfaces/281785) Adobe XD artboard: **Web 1920 (1920x1080)** (Recommended starting screen size for UI concept in Adobe XD)
- [page](https://devforum.roblox.com/t/how-to-plan-design-and-build-quality-user-interfaces/281785) Toggle track size: **150x80, corner radius 40** (Rounded rectangle base of the example toggle)
- [page](https://devforum.roblox.com/t/how-to-plan-design-and-build-quality-user-interfaces/281785) Toggle knob size: **70x70** (Circle knob in the example toggle)
- [page](https://devforum.roblox.com/t/how-to-plan-design-and-build-quality-user-interfaces/281785) Cross symbol bars: **40x4, corner radius 10, unioned and rotated 45 degrees** (Cross icon built from two rounded rectangles)
- [page](https://devforum.roblox.com/t/how-to-plan-design-and-build-quality-user-interfaces/281785) Check mark bars: **Long bar plus 20x4 short bar, unioned, rotated 45 degrees** (Check icon built from two rounded rectangles)
