# Sling - A modern and reactive backpack UI

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://devforum.roblox.com/t/sling-a-modern-and-reactive-backpack-ui/4686535) | Roblox DevForum | 56 views | 2026-06-17

## Summary
Introduces Sling, an open-source reactive backpack UI library for Roblox (Vide-based) that replaces the default backpack. Covers custom tab categorization via predicate functions, custom/light/default themes, inventory and equip events, and programmatic hotbar management. Install via Wally or GitHub Releases.

## Tips
- [page](https://devforum.roblox.com/t/sling-a-modern-and-reactive-backpack-ui/4686535) **[[ui-ux-design]]** Use Sling to replace the default backpack and group inventory into tab categories (Weapons, Potions, Resources) with declarative predicate functions.
- [page](https://devforum.roblox.com/t/sling-a-modern-and-reactive-backpack-ui/4686535) **[[ui-ux-design]]** Customize theme properties or switch between built-in default and light themes rather than building a backpack UI from scratch.
- [page](https://devforum.roblox.com/t/sling-a-modern-and-reactive-backpack-ui/4686535) **[[client-server-and-remotes]]** Subscribe to backpack events (interaction, equip, item added/removed) to react to inventory changes instead of polling.
- [page](https://devforum.roblox.com/t/sling-a-modern-and-reactive-backpack-ui/4686535) **[[ui-ux-design]]** Programmatically set which items sit in the hotbar and track when players rearrange hotbar items.

## Tools
Sling, Vide, Wally, Satchel
