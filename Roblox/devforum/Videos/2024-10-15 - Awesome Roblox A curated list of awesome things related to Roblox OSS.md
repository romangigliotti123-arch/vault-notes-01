## Summary
Curated GitHub list (awesome-roblox) of open-source Roblox resources: software bootstrappers, sample experiences, plugins, and libraries grouped by use (admin, DataStore, networking, ECS, UI, tooling, package managers, syncing tools). A reference index, not a how-to; no metrics or advice given.

## Games
- **Slither**: Casual game with a soothing Catppuccin color palette, listed as an open-source sample experience.
- **Vesteria**: Fantasy MMORPG originally founded by berezaa, sk3let0n and Polymorphic in the Roblox Incubator program.
- **Miner's Haven**: Tycoon-style game where players build intricate rare mineral processing factories from machine components.
