# Roblox Scripting Roadmap & Learning Resource List

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://devforum.roblox.com/t/roblox-scripting-roadmap-learning-resource-list/808430) | Roblox DevForum | 311 views | 2020-10-06

## Summary
A Roblox scripting roadmap page (DobDobDev, 2020) listing learning topics in three tiers: Basics (Luau fundamentals, variables, functions, loops, tables, debugging), Intermediate (Remotes, services like DataStore, TweenService, UserInputService, PathfindingService, Teleport, Raycasting, plus pcall and style guides), and Advanced (plugins, metatables/OOP, string patterns, Rojo, Git, Roact, Flipper, Aero/Nevermore frameworks, memory and garbage collection). Mostly a topic index, not a guide.

## Tips
- [page](https://devforum.roblox.com/t/roblox-scripting-roadmap-learning-resource-list/808430) **[[scripting-and-performance]]** Learn Luau basics (variables, functions, loops, tables, conditionals, debugging tools) before taking on any commissions or paid scripting work.
- [page](https://devforum.roblox.com/t/roblox-scripting-roadmap-learning-resource-list/808430) **[[scripting-and-performance]]** Start with YouTube tutorials for beginner Luau, then move to the official Roblox DevHub docs as skills grow.
- [page](https://devforum.roblox.com/t/roblox-scripting-roadmap-learning-resource-list/808430) **[[data-persistence]]** Use pcall or xpcall around DataStore calls so failed saves/loads don't crash the server.
- [page](https://devforum.roblox.com/t/roblox-scripting-roadmap-learning-resource-list/808430) **[[client-server-and-remotes]]** Learn RemoteEvents/RemoteFunctions and network ownership early; they are core to intermediate Roblox scripting.

## Tools
