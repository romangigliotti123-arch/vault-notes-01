# UI Design and the Fundamentals

[Open](https://devforum.roblox.com/t/ui-design-and-the-fundamentals/1455805) | Roblox DevForum | 120 views | 2021-09-05

## Summary
A UI design tutorial covering tools (Illustrator, Photoshop, XD, Sketch, Figma, FramerX), UX vs UI definitions, and five principles: visibility, consistency, hierarchy (element and type), contrast (including color vision deficiency and text contrast). Generic design guidance, not Roblox-specific.

## Tips
- [page](https://devforum.roblox.com/t/ui-design-and-the-fundamentals/1455805) **[[ui-ux-design]]** Hide unimportant text and secondary info behind buttons, links, or menus so the main UI stays uncluttered and easier to navigate.
- [page](https://devforum.roblox.com/t/ui-design-and-the-fundamentals/1455805) **[[ui-ux-design]]** Keep fonts, colors, spacing, and icon styles consistent throughout the interface; consistent UI is received better and appears more polished.
- [page](https://devforum.roblox.com/t/ui-design-and-the-fundamentals/1455805) **[[ui-ux-design]]** Structure element hierarchy so key information is prominent and minor items are de-emphasized, preventing players from missing information.
- [page](https://devforum.roblox.com/t/ui-design-and-the-fundamentals/1455805) **[[ui-ux-design]]** Use text weight and size to establish type hierarchy, ordering text by importance so the most important reads first.
- [page](https://devforum.roblox.com/t/ui-design-and-the-fundamentals/1455805) **[[ui-ux-design]]** Build contrast using value and saturation differences rather than just complementary hues; complementary colors alone can look poor together.
- [page](https://devforum.roblox.com/t/ui-design-and-the-fundamentals/1455805) **[[ui-ux-design]]** Ensure sufficient contrast for accessibility, since color vision deficiency affects many players.
- [page](https://devforum.roblox.com/t/ui-design-and-the-fundamentals/1455805) **[[ui-ux-design]]** Avoid pure white text on black backgrounds and pure black text on white backgrounds to reduce eye strain; use softer tones like dark gray.

## Numbers
- [page](https://devforum.roblox.com/t/ui-design-and-the-fundamentals/1455805) Color vision deficiency prevalence: **1 in 12 men and 1 in 200 women (per ColourBlindAwareness.org, as stated)** (Cited to justify contrast and accessibility in palettes)
- [page](https://devforum.roblox.com/t/ui-design-and-the-fundamentals/1455805) Designer experience: **~7 years** (Author's stated background in UI design)
