# Dynamic Weather Library (Beta 1.0)

> Tagged **low-advice**: mostly entertainment/experiment; notes kept short.
[Open](https://devforum.roblox.com/t/dynamic-weather-library-beta-10/1547614) | Roblox DevForum | 646 views | 2021-11-13

## Summary
Showcase of an open-source Roblox Dynamic Weather module (Beta 1.0) that simulates weather from temperature, humidity, wind shear and atmospheric pressure. Explains the physics rationale, setup steps in ReplicatedStorage/Library, and the DynamicWeatherDatabase values for customisation. Mostly a module release page, not a growth guide.

## Tips
- [page](https://devforum.roblox.com/t/dynamic-weather-library-beta-10/1547614) **[[building-art-and-assets]]** Ensure an Atmosphere object named "Atmosphere" in Lighting and a Clouds terrain instance named "Clouds" exist; the module needs both to run.
- [page](https://devforum.roblox.com/t/dynamic-weather-library-beta-10/1547614) **[[ai-and-tools]]** Import the module into ReplicatedStorage, open Library, drag the CPI folder contents into matching services (Workspace, ServerScriptService, etc.).
- [page](https://devforum.roblox.com/t/dynamic-weather-library-beta-10/1547614) **[[optimization-and-streaming]]** Set graphics quality to high for rain splashes to appear; lower quality hides the splash effect.
- [page](https://devforum.roblox.com/t/dynamic-weather-library-beta-10/1547614) **[[building-art-and-assets]]** Tune weather behaviour by editing DynamicWeatherDatabase min/max ranges for temperature, humidity, wind shear and pressure rather than code.

## Numbers
