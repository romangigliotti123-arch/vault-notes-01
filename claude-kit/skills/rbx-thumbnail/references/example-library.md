# MrBeast thumbnail example library (55 written breakdowns)

Study set for rbx-thumbnail. Descriptions only: no thumbnail images are stored or published here; open each video link to compare. Looked at on 2026-11-08, so a few may differ from the first-day image (YouTube keeps the A/B test winner). Years run 2012 to 2026 on purpose: the early entries show the baseline the later ones grew out of. `roblox_use` is how to take the idea, never the likeness: do not draw a real person, a real brand or this channel's styling into a Roblox thumbnail. Same data as `example-library.json` (structured, for scripts; `thumb_compose.py templates` reads the `format` names).

Formats: before-after, build-reveal, charity-celebrity, chase, child-adult, colour-isolation, crowd-cast, discovery, duel, endurance-counter, event-screenshot, face-only, food-spectacle, giveaway, horror-mystery, object-only, raw-screenshot, reaction-product, reaction-text, spectacle, stunt, survival, survival-day-counter, vs-animal, vs-economy, vs-tech, vs-three-way, wholesome.
