Roblox constraints (everything shown is buildable)

UICornerUIStrokeUIGradient (linear)UIListLayoutUIGridLayoutUIPaddingUIAspectRatioConstraintUIScale + TweenServiceScreenInsetsClipsDescendantsSoundServiceFrame rotation
  • Button = Lip Frame under a Face Frame + UIStroke 3 px + UIGradient + gloss Frame + shine Frame (rotated, clipped). Press 0.07 s to 0.94, release 0.18 s Back Out.
  • Sizes are in em from one scale = one root UIScale; strokes and corners come from em.
  • Animate UIScale, Position, Rotation and Transparency only (no Size on layout children).

Not buildable as-is

  • text outline via -webkit-text-stroke + duplicate shadow copy: use UIStroke (Contextual) on the TextLabel and a second TextLabel offset 0,2 behind it.
  • repeating-linear-gradient stripes on the progress bar: UIGradient does not tile; use a tiled stripe ImageLabel (ScaleType Tile) scrolled by a looping Position tween inside a ClipsDescendants bar.
  • skewX shine bar: Frame Rotation 20 degrees with a UIGradient, clipped by the button, tweened across.
  • SVG ring (stroke-dashoffset) for hold-to-confirm: UIGradient is linear only; use two half-ring ImageLabels each clipped and rotated, or a 24-frame ring sprite sheet, or a plain fill bar.
  • canvas particles: pool 40-60 small Frames or ImageLabels (UICorner for circles, Rotation for confetti) driven by RenderStepped, or ParticleEmitters in a ViewportFrame.
  • inline SVG art: placeholder, draw as ImageLabel assets (uploaded PNG at 2x) with the same outline style.
  • box-shadow rings and lips are hard offsets only: each is a second Frame or a UIStroke; the stacked rings used for glow pulses are 2-3 transparent UIStroke Frames.
  • WebAudio synth: replaced by Sound instances in SoundService (cue names below).
  • radial-gradient (spotlight hole, vignette, bloom, soft particle glow sprites): UIGradient is linear only; use a glow ImageLabel texture (soft circle PNG) with UIGradient fades, a vignette ImageLabel, a ColorCorrectionEffect or BloomEffect in Lighting for the screen-wide look, ParticleEmitter textures for glow sprites.
  • mix-blend-mode: screen and canvas lighter (additive glow): Roblox UI has no blend modes; use glow ImageLabels with low Transparency, ImageColor3 tint and a bright centre, or BloomEffect.
  • card flip: no rotateY; the flip is a UIScale X tween 1 to 0, swap the face, 0 to 1 (a fake flip, done here the same way).
  • convolver reverb and compressor (WebAudio): ReverbSoundEffect and CompressorSoundEffect on a SoundGroup.
  • prefers-reduced-motion: a player setting plus the game's own Reduce Motion toggle.

Fidelity (research vs guessed)

  • Source: original theme (Moonlit Bakery); no image was copied. Shapes, hierarchy and motion follow the UI craft guide (kit cold file rbx-ui/ui-craft-guide.md).
  • From the research (screenshots read): thick dark outline about 1/12 of button height, coloured lip, top gloss, white outlined heavy text, one primary CTA per screen (yellow rule from Clash Royale), shared panel grammar with red square close (Pet Simulator 99, Adopt Me, Bubble Gum), rarity border + ribbon + glow only on top tiers (Bubble Gum, Blox Fruits, Grow a Garden), cream inset cards on a navy frame with thin trim (Royal Match), polaroid reveal card with rays (Adopt Me), stars filling one by one (Dress to Impress), currency flying to its counter (Royal Match), popups never fullscreen.
  • Tuned by feel (heuristics, not measured): every duration, easing, scale and stagger number; particle counts; shake amplitudes; synth sounds.
  • Guessed: item names, prices, drop weights, quest list, level curve, safe-area numbers (typical phone), tablet and desktop densities.
