## From skills/rbx-playtest-list/SKILL.md :: Vault evidence (full list with sources: `Roblox/roblox-kb/playtesting-and-feedback.md`)

- Playtest early with a rough build: validate core fun before polishing.
- Watch new players silently (relatives, kids, people unfamiliar with mobile or the game); note where they tap, get confused or stuck. Observe unaware via an alt account or hidden observer; use the visible dev account only to ask for feature feedback.
- Test with the real target audience and rotate fresh testers (QA Discord groups, pre-launch tester groups, fan groups, streamers).
- Mobile and low-end devices are the default test target, not an extra. Next steps: `/rbx-playtest` (full run), `/rbx-mentor` (what to test for this genre).
