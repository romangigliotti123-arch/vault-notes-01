# The Prompt Report: A Systematic Survey of Prompt Engineering Techniques
## Key claims
- 33 vocabulary terms, 58 text prompting techniques, 40 for other modalities; PRISMA-style review. Prompt components named: directive, examples, output formatting, style, role, additional information.
- "Empirically, better prompts lead to improved results across a wide range of tasks"; but the field "is new, and evaluation is variable and unstandardized"; meaning-preserving input changes can shift outputs.
- Disputed: structured output formats "may reduce performance on some tasks" (Tam et al. 2024) vs rebuttal that structured output can improve it.
- Advice: "It is better to start with simpler approaches first, and to remain skeptical of claims about method performance." Treat prompt engineering like ML: understand the problem, check your data/metrics represent it.
- Limitation: evidence is mostly pre-2025 models; modern Claude docs supersede many technique-specific claims.
