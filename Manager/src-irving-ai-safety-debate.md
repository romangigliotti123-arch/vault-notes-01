# AI safety via debate
## Key claims
- Two agents argue for opposing answers and a (weaker) judge picks; with optimal play debate can answer PSPACE questions with polynomial-time judges vs NP for direct judging. MNIST toy: classifier accuracy 59.4% -> 88.9% (6 pixels).
- Foundation for adversarial-reviewer ideas: it is easier to expose a flaw than to find it unaided. Empirical value for LLMs is contested.
