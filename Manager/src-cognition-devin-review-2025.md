# Devin's 2025 performance review (Cognition)
## Key claims
- Self-reported: PR merge rate 67% (up from 34% a year earlier); Devin does best on "tasks with clear, upfront requirements and verifiable outcomes" (roughly 4-8 hours of junior work: security fixes, migrations, unit tests, small tickets).
- Struggles: ambiguity (open-ended projects need more detail up front); adding requirements after it starts makes performance worse (cannot be coached mid-task like a human junior); work whose quality is not straightforwardly verifiable needs human judgment.
- Humans still check the logic of Devin-written unit tests and first-pass code reviews; engineers must scope work thoroughly before starting ("learning to manage Devin").
## Quotable
> "tasks with clear, upfront requirements and verifiable outcomes"
