# From Accuracy to Robustness: Rule- and Model-based Verifiers in Mathematical Reasoning
## Key claims
- Rule-based verifiers miss equivalent answers in other formats (false negatives); model-based verifiers are more accurate statically but misclassify some response patterns as correct and are exploited during RL.
- Takeaway: deterministic checks fail closed (false negatives), model checks fail open (false positives).
