# RAG-MCP: Mitigating Prompt Bloat in LLM Tool Selection
## Key claims
- Semantic retrieval over an external MCP tool index, only selected tool descriptions enter prompt.
- Prompt tokens cut by over 50%; tool-selection accuracy 43.13% vs 13.62% baseline (more than triple) on an MCP stress test.
- Supports 'retrieve, then expose few tools' pattern.
## Quotable
> "significantly cuts prompt tokens (e.g., by over 50%)"
