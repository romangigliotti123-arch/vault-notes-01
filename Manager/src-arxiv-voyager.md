# Voyager: An Open-Ended Embodied Agent with Large Language Models
## Key claims
- Skill library of executable code; skills are temporally extended, interpretable, compositional (curbs catastrophic forgetting).
- Iterative prompting with environment feedback, execution errors and self-verification before a skill is stored (store only verified skills).
- 3.3x more unique items, 2.3x longer distances, tech-tree milestones up to 15.3x faster than prior SOTA.
- Abstract page does not say how skills are retrieved (paper body: embedding of description; not verified here).
## Quotable
> "an ever-growing skill library of executable code for storing and retrieving complex behaviors"
