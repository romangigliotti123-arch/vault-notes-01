# Architectural Decision Records (adr.github.io)
## Key claims
- An ADR "captures a single AD and its rationale"; the ADRs of a project together form its decision log; it records trade-offs and consequences.
- The fetched page does NOT specify fields (status, context, decision, consequences) or immutability/superseding; those conventions are general practice, not verified from this page.
- Relevance: one decision per file or entry, with rationale, is the unit for the manager's decision log.
