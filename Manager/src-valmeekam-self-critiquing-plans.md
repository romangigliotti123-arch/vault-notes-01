# Can Large Language Models Really Improve by Self-critiquing Their Own Plans?
## Key claims
- GPT-4 as both generator and verifier: self-critiquing diminishes plan generation performance compared with systems using external sound verifiers; the LLM verifier produces many false positives; binary vs detailed feedback matters little.
