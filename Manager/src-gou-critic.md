# CRITIC: LLMs Can Self-Correct with Tool-Interactive Critiquing
## Key claims
- Output is validated with external tools (search engine for fact-check, code interpreter for debugging) and then revised; consistently improves QA, math program synthesis and toxicity reduction.
- Authors highlight "the crucial importance of external feedback" for self-improvement.
## Quotable
