# Task Decomposition-Guided Reranking for Adaptive Agent Skill Retrieval (SkillReranker)
## Key claims
- Decomposes task and skills into subtasks and skill transition states; builds a DAG where candidate skills are edges; cross-encoder scores skills per interval.
- Claims better task performance, fewer environment steps and fewer tokens on ALFWorld and ScienceWorld; no figures in abstract.
