# G-Eval: NLG Evaluation using GPT-4 with Better Human Alignment
## Key claims
- Chain-of-thought plus a form-filling paradigm for LLM scoring; Spearman 0.514 with humans on summarisation, beating prior methods.
- Authors flag a bias of LLM-based evaluators toward LLM-generated text.
