# One Token to Fool LLM-as-a-Judge
## Key claims
- Generative reward models/judges are fooled by superficial "master keys": non-word symbols (":" ".") or generic openers ("Thought process:", "Let's solve this problem step by step.") elicit false-positive rewards without substantive reasoning, including for GPT-o1 and Claude-4 judges.
- Training with truncated outputs as adversarial negatives produces a robust Master-RM.
