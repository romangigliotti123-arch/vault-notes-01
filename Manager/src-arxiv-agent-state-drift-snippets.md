# Agent memory state drift (snippet-only pointers)
## Key claims
- SNIPPET ONLY: defines "state drift" as an agent acting on superseded information even when the current version is already in its memory/context; claims it is a primary cause of long-run agent failure, drift rate >71% on multi-session questions. Related snippet-only: arXiv 2607.08716 "Remember When It Matters" (behavioral state decay), AMA-Bench arXiv 2602.22769 (memory techniques that beat long-context on dialogue often fail on agentic tasks).
- Implication: notes files must record dated, superseding facts ("as of 2026-10-29 X replaced Y") and be pruned; CLAUDE.md's pending-work block already shows stale/contradicting entries ("do not suspend" vs "WORKING as of").
