# Scaling LLM Test-Time Compute Optimally can be More Effective than Scaling Model Parameters
## Key claims
- Effectiveness of verifier search vs sequential revision depends on prompt difficulty; allocating test-time compute adaptively per prompt ("compute-optimal") improves efficiency more than 4x over best-of-N.
- Manager lesson: verification effort should scale with difficulty/risk, not be uniform.
