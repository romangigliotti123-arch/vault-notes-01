# ToolLLM: Facilitating LLMs to Master 16000+ Real-world APIs
## Key claims
- ToolBench: 16,464 RESTful APIs across 49 RapidAPI categories; single- and multi-tool instructions; solution paths via DFSDT.
- Trained neural API retriever recommends APIs per instruction; ToolEval automatic evaluator.
- Takeaway: purpose-trained retriever plus an eval harness over a large API pool; category taxonomy used to sample multi-tool queries.
