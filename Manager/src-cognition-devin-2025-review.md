# Devin's 2025 Performance Review: Learnings From 18 Months of Agents At Work
## Key claims
- Vendor-reported: PR merge rate 67% vs 34% the year before; "4x faster at problem solving and 2x more efficient in resource consumption"; hundreds of thousands of merged PRs.
- Works best on "tasks with clear, upfront requirements and verifiable outcomes that would take a junior engineer 4-8 hrs": migrations, vulnerability fixes, tests, small tickets, data/QA questions via Slack "@Devin". "Senior at codebase understanding but junior at execution."
- Weak at ambiguous requirements and mid-task scope change: "It usually performs worse when you keep telling it more after it starts the task." Puts "more of a responsibility on the engineer to scope work well up-front." Humans must review where output is not verifiable.
- Interaction surface: lives in Slack/Teams/Jira; fleets of Devins run the same playbook over many repos in parallel; a human writes the playbook, code owners check results.
- Cognition's own 2026 follow-ups (titles only seen): "How Cognition Uses Devin to Build Devin", "More Devins in More Places", Devin Desktop.
