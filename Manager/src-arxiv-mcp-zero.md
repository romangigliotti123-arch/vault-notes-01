# MCP-Zero: Active Tool Discovery for Autonomous LLM Agents
## Key claims
- Agent identifies its own capability gap and requests a specific tool on demand (active discovery) instead of being handed schemas.
- Hierarchical semantic routing: match request to server first, then tool. Iterative capability extension for chains.
- MCP-tools dataset: 308 MCP servers, 2,797 tools.
- 98% token reduction on APIBank; accurate selection among ~3k candidates (248.1k tokens of schemas).
## Quotable
> "98% reduction in token consumption on APIBank while maintaining high accuracy"
