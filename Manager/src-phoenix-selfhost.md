# Arize Phoenix self-hosting
## Key claims
- "Phoenix is free to self-host with no feature limitations"; "nothing is sent to Arize and can be fully air-gapped". Deploy via terminal (pip), Docker, Kubernetes, Cloud Run etc.; pin image versions in production. Page does not name licence, storage default, OTLP or Claude Code support (not verified here).
- Of the OSS trace UIs it is the lightest to start (single process), but still a service to keep up.
