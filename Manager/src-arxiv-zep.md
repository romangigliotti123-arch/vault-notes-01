# Zep: A Temporal Knowledge Graph Architecture for Agent Memory
## Key claims
- Zep (built on Graphiti) scores 94.8% on Deep Memory Retrieval vs 93.4% for MemGPT.
- LongMemEval: up to 18.5% accuracy improvement and 90% lower latency vs baseline implementations.
- Temporal handling (what was true when) is the differentiator vs plain vector memory.
