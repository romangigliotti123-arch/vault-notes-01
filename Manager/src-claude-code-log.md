# claude-code-log
## Key claims
- "A Python CLI tool that converts Claude Code transcript JSONL files into readable HTML and Markdown (plus JSON for tooling)."
- TUI to browse sessions, resume with `claude -r`; date-range filters in natural language ("today", "last week"); `--depth agent` includes sub-agents; sub-agents and rewind forks fold away as branches in the minimal theme; caching for fast reload.
- Fits: render a worker's transcript to Markdown/HTML on demand when Roman asks "what did worker X do".
