# Self-Refine: Iterative Refinement with Self-Feedback
## Key claims
- Same LLM generates, critiques and refines; ~20% absolute average improvement across 7 tasks (dialog, math, etc.) with GPT-3.5/ChatGPT/GPT-4 per authors; no training needed.
- Huang et al. later showed some gains reflect a weak initial prompt rather than genuine self-correction.
