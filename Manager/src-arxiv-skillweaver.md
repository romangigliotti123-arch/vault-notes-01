# SkillWeaver: Web Agents can Self-Improve by Discovering and Honing Skills
## Key claims
- Agent explores a website, proposes skills, practises them, distils them into reusable APIs; the library grows by repeated exploration.
- +31.8% relative success on WebArena and +39.8% on real sites; APIs from stronger agents boost weaker agents by up to 54.3% (skills transfer across models).
