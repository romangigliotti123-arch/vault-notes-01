# AJ-Bench: Benchmarking Agent-as-a-Judge for Environment-Aware Evaluation
## Key claims
- 155 tasks and 516 annotated trajectories across search, data systems and GUIs; tests judge agents on information acquisition, state verification and process verification.
- Agent judges that interact with environments/tools to collect evidence show consistent gains over LLM-as-a-Judge baselines, while "substantial open challenges" remain in agent-based verification.
