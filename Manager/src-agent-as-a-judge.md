# Agent-as-a-Judge: Evaluate Agents with Agents
## Key claims
- Judges that are themselves agents (can read files, run things, gather evidence) dramatically outperform plain LLM-as-a-Judge on code-generation tasks and are about as reliable as human evaluation.
- DevAI benchmark: 55 realistic AI-development tasks with 365 hierarchical user requirements; judging against per-requirement checklists gives intermediate, step-level signal.
