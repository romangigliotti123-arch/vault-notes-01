# The PARA Method (Forte Labs)
## Key claims
- Four buckets: Projects (short-term efforts with a goal), Areas (ongoing responsibilities), Resources (topics of interest), Archives (inactive items from the other three kept for reference).
- Organise by actionability, not by subject: material is filed under the project or area it serves so it is at hand when the task starts.
- Relevance to us: PARA is a human-filing scheme; for an agent, folder = scope of use ("projects/active" gets read, "archive" is excluded from default search) is the useful part.
## Quotable
> "organize by actionability" (the organising principle as summarised)
