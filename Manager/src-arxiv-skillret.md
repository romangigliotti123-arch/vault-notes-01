# SkillRet: A Large-Scale Benchmark for Skill Retrieval in LLM Agents
## Key claims
- 16,129 public agent skills in a two-level taxonomy (6 categories, 18 sub-categories); 63,259 training samples, 4,392 evaluation queries, disjoint pools.
- Off-the-shelf retrievers struggle; fine-tuning on it adds +12.9 NDCG@10 over the strongest prior retriever and +16.2 over the strongest off-the-shelf one.
- Premise: explicit skill naming stops working as ecosystems grow. Releases 0.6B and 8B checkpoints.
## Quotable
> "skill retrieval remains far from solved"
