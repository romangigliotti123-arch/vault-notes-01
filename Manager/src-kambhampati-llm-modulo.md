# LLMs Can't Plan, But Can Help Planning in LLM-Modulo Frameworks
## Key claims
- Position: auto-regressive LLMs cannot by themselves do planning or self-verification; use them as approximate knowledge sources in a generate-test loop with external model-based (sound) verifiers critiquing in a tight loop.
