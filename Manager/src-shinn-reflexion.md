# Reflexion: Language Agents with Verbal Reinforcement Learning
## Key claims
- Agents verbally reflect on task feedback signals and keep reflections in an episodic memory buffer; 91% pass@1 on HumanEval vs GPT-4 80%.
- The feedback signal is external (unit test results, environment rewards); Huang et al. note this oracle signal is what drives the gain. Pattern for managers: reflection helps when grounded in a real pass/fail signal.
