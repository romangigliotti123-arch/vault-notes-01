# Introduction to the Zettelkasten Method
## Key claims
- Atomicity: knowledge as discrete building blocks, one idea per note (a guiding principle, not rigid).
- Own words; unique stable IDs (timestamps, numbers, titles); links must state why they exist; "A Structure Note is a Meta-Note: it is a Zettel about other Zettel and their relationships" (entry points into the network).
- Maps well to agent notes: one fact/decision per file, stable id, typed link reasons, structure notes as the index.
## Quotable
> "Only with a unique identifier you can address Zettel individually."
