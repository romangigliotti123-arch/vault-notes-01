# Agent Skill Evaluation and Evolution: Frameworks and Benchmarks
## Key claims
- Survey of post-creation skill evaluation and improvement. Four evolution paradigms: execution feedback, trajectory distillation, compression, reinforcement learning.
- Six categories of skill benchmarks; gaps in coverage and metric richness. Argues rigorous evaluation is needed as libraries grow. Code: github.com/Cassie07/AgentSkill_Survey.
