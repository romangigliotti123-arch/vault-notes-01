# Cheating Automatic LLM Benchmarks: Null Models Achieve High Win Rates
## Key claims
- A "null model" that always outputs one constant irrelevant response achieves 86.5% LC win rate on AlpacaEval 2.0, 83.0 on Arena-Hard-Auto and 9.55 on MT-Bench, i.e. top ranks on LLM-judged benchmarks.
- Judge-based pass/fail can be gamed by an adversary who knows or guesses the judge; do not use a judge as the sole gate for outputs from an optimiser.
