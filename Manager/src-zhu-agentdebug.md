# Where LLM Agents Fail and How They Can Learn From Failures (AgentErrorTaxonomy, AgentDebug)
## Key claims
- Cascading failures: a single root-cause error propagates through later decisions. Taxonomy spans memory, reflection, planning, action and system-level errors; AgentErrorBench of annotated trajectories (ALFWorld, GAIA, WebShop).
- AgentDebug (isolate root cause, give targeted feedback) gets 24% higher all-correct accuracy and 17% higher step accuracy than the strongest baseline, and up to 26% relative task-success gains when feedback is fed back to the agent.
