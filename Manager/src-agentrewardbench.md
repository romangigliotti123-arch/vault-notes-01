# AgentRewardBench: Evaluating Automatic Evaluations of Web Agent Trajectories
## Key claims
- 1302 trajectories, 5 benchmarks, 4 LLMs, expert-labelled for success, side effects and repetitiveness; 12 LLM judges evaluated.
- No single LLM judge excels across all benchmarks; rule-based evaluation used by common benchmarks tends to underreport success.
- Secondary summary (Stanford blog, [[src-stanford-checking-agents-review]]): no judge exceeded 70% precision, i.e. roughly 3 in 10 trajectories judged successful had failed.
