# Linux Foundation announces the Agentic AI Foundation (AAIF)
## Key claims
- 2025-12-09: LF forms the Agentic AI Foundation with founding contributions from Anthropic (Model Context Protocol), Block (goose) and OpenAI (AGENTS.md). Founders: Anthropic, Block, OpenAI (per headline).
- MCP described as "the universal standard protocol for connecting AI models to tools, data and applications", with "more than 10,000 published MCP servers"; open-sourced November 2024. So MCP is now vendor-neutral governed, like A2A (also at LF, separate project, donated 2025).
- Implication: the two protocol efforts (MCP for agent-to-tool, A2A for agent-to-agent) both sit under Linux Foundation governance; they are positioned as complementary (LF A2A release says so).
