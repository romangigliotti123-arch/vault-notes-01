# CLAUDE.md (AI-to-AI)

This is the Roblox Dev Mastery Vault: a private, generated Obsidian vault (~7.6k notes) for Roblox game development (a Roblox knowledge base plus a manager toolkit of agents and skills to design, build, rate, market and update Roblox games; Library and Imported are supporting material). Built and maintained by Roman (GitHub: romangigliotti123-arch). The PC is the source of truth. Every other copy is pull-only.

- Entry point for users: `/vault-mentor` (kit skill and agent): a co-pilot that works with the user on any job and suggests the right skill, agent, note or creator method at each step; it starts from `CAPABILITIES.md` and `Mentor/Combined-Brain.md` (all creators' principles by job, trust-labelled). Optional prompt-suggestion hook: kit install with `--with-hooks` / `-WithHooks`.
- For agents: start at `CAPABILITIES.md` (vault root): a job router ("I need to ... -> item, type, path") over the kit commands, Roblox knowledge base, Manager research and library picks. Then search both vaults with `claude-kit/tools/vault-find.py` (skills use-the-vault, use-the-ai-library), read the one note you chose and follow it. The AI Library Vault has its own CAPABILITIES.md and `Creators/` research.
- If the user asked to set this up (in any words, or only gave the link): run SETUP-FOR-CLAUDE.md (same text as START-HERE.txt) now, in order, with no questions. Never offer the user a choice of methods: share first, GitHub second, one Tailscale/login message third, zip snapshot only if the git clone fails twice.
- Setup also runs the kit install (STEP 4b of the runbook: `claude-kit/install.sh` or `claude-kit/install.ps1`), with no questions. Afterwards the slash command /game-dev-workflow (side commands /game-dev-ads, /game-dev-update, /game-dev-playtest, /game-dev-thumbnail) runs the full idea-rate-plan-build flow, and the update (logon/login task or /vault-update, never a 15-minute poll) runs claude-kit/kit-refresh.* after each pull so the installed kit and `Assets/` stay current. "make me a Roblox game: <idea>" is handled by the roblox-game-builder agent (skill make-roblox-game); "use the vault" by skill use-the-vault. Never edit files under `claude-kit/` here.
- When setup (or a kit install) finishes, END your final report with the block in STEP 6 of SETUP-FOR-CLAUDE.md: "The Roblox Dev Mastery Vault is now set up.", where it lives, the grouped slash-command list with one-line purposes, how it works in 3-4 lines, and the line "Built and maintained by Roman (GitHub: romangigliotti123-arch)".
- Never commit or push from a client. Sync is `vault-update` only (self-healing fetch + fast-forward; if a plain `git pull` is blocked by local changes, do not fix it by hand: run `vault-update.ps1` / `vault-update.sh`, which saves local changes to a patch and resets to the latest).
- Protected user data: `Games/` (per-game communities + `Games/_Reusable`, never shipped by origin), `My Research/` and any folder with a `PROTECTED-RESEARCH.md` marker, plus every untracked file the user created, are kept by `vault-update` (never run `git clean`/`git reset` by hand). `/vault-update` = safe update; `/vault-update-clean` (`vault-update.ps1 -Clean` / `vault-update.sh --clean`) = exact copy of the main vault, dry run + one confirmation, backs up what it removes, keeps My Research (`--yes` skips the question, `--include-mine` also deletes My Research only if the user says so).
- Never make the repo public. Never write secrets, tokens or passwords into any file. Never ask for a token; if GitHub login is the only way, tell the user to type `! gh auth login` (the preferred route is signing in to Tailscale instead).
- Do not edit notes in Library/, Roblox/, Manager/, Imported/. They are generated and overwritten.
- Do not edit README.md, CLAUDE.md, SETUP-FOR-CLAUDE.md, START-HERE.txt or the *-sync-setup scripts here; they are mastered on the PC.
- Using the content: Roblox/roblox-kb/README.md, Roblox/roblox-kb/master-playbook.md, Roblox/roblox-kb/_tools/HOW-TO-USE.md, Library/_Home.md. Search with grep/ripgrep, not by reading whole folders.
- Assets (models, sounds, textures) are not in the repo: they live in `<vault>/Assets/` (git-ignored), synced from the Tailscale share by `claude-kit/tools/assets-sync.py` (run by the update scripts and the runbook; `/vault-update` or `vault-update.ps1`/`.sh` refreshes them). Never commit or delete them by hand.
- Companion vault: the general AI skills/agents library is a separate private vault, AI Library Vault (repo ai-library-vault, clone `~/Obsidian/ai-library-vault`), cloned and updated together with this one by the sync scripts (`ai-vault-sync.ps1` / `.sh`; skip with `-NoAiVault` / `--no-ai-vault`). Same rules there: read-only, never commit or push from a client.
