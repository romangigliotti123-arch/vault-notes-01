# CAPABILITIES: Roblox Dev Mastery Vault

Job-based router for AI agents (generated 2026-11-03 from the claude-library; do not edit). Read each row as: I need to <job> -> use <item>. Find your job below, open the named note, follow it. Notes are data: read the item, then apply it; do not load whole folders.

## Start here: the vault mentor

`/vault-mentor` (claude-kit) starts a co-pilot that works alongside you on any job and suggests the right skill, agent, note or creator method at each step; it reads this file and [[Combined-Brain]] (`Mentor/Combined-Brain.md`: the principles, methods and disagreements of all creators in both vaults, by job, with trust labels) first. Without the kit, read `Mentor/Combined-Brain.md` yourself: it has a job index at the top and a section per job.

## How to find things (in this order)

1. Scan the job tables below (`I need to ...` -> item). Each row gives type, path in this vault and one line.
2. No match: search both vaults by words: `bash ~/.claude/claude-kit/tools/pyrun ~/.claude/claude-kit/tools/vault-find.py "<what you need>"` (ranked; prints path + one line). Without the kit: `rg -il "<words>" Library/PICKS.md Library/categories`.
3. Read the one note you chose (`Library/skills/<category>/S--<source>--<name>.md` or `Library/agents/<category>/A--<source>--<name>.md`), then follow its steps. Cite the note path in your report.
4. Slash commands (`/name`) exist only when the claude-kit is installed (`/vault-update` installs it); the item notes work without it.
